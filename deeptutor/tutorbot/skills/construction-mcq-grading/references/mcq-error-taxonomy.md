# 建筑实务选择题错因分类

| Code | 错因 | 判定口径 |
| --- | --- | --- |
| M01 | 知识点缺失 | 对考点本身不了解，只能猜选 |
| M02 | 关键词误读 | 忽略“应/不应、正确/错误、最/宜/必须”等题眼 |
| M03 | 概念混淆 | 混淆相近概念、流程、责任主体或材料构造 |
| M04 | 选项陷阱 | 被绝对化、偷换主体、扩大条件、时间顺序干扰 |
| M05 | 审题方向错 | 题目问“不妥/错误/不包括”，用户按正确项选 |
| M06 | 多选漏选 | 多选题遗漏正确选项 |
| M07 | 多选错选 | 多选题选入错误选项 |
| M08 | 记忆数字串扰 | 规范数字、比例、时限、强度、间距混串 |
| M09 | 题干条件提取失败 | 没把题干给定场景和条件带入判断 |
| M10 | 常识化误判 | 用现场经验或生活常识替代考试规则 |

## 写回口径

- 有标准答案和用户答案：可写入正式选择题错因 event。
- 标准答案缺失：只写轻量诊断，不更新 mastery。
- 多选题同时存在漏选和错选时，分别记录 `M06` / `M07`。
- 错因必须绑定具体选项，不只写“知识薄弱”。

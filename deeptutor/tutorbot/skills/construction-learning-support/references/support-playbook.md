# 情绪支持响应手册（construction-learning-support）

SKILL.md 的深度参考：各级情绪信号的识别细则、响应模板、混合信号处理与升级表达。
本手册只约束表达方式，不构成任何心理学诊断依据。

## 1. 信号识别细则

### S1 挫败（frustration）

- 典型语言："又错了"、"好烦"、"我怎么这么笨"、"白练了"。
- 区分点：负面情绪**指向具体题目/考点**，自我否定仍在学习语境内。
- 注意：刚收到批改结果后的第一句抱怨默认按 S1 接，不要立刻讲题。

### S2 焦虑（anxiety）

- 典型语言："来不及了"、"越想越慌"、"睡不着"、"一看书就心跳快"。
- 区分点：指向**未来的考试结果**而非已发生的错题；常伴时间压力和身体化表达。
- 身体化表达持续且严重（长期失眠、无法进食）→ 按 S4 从严处理。

### S3 低动机（low_motivation）

- 典型语言："学不动了"、"今天不想学"、"打不起精神"、连续多日拖延。
- 区分点：没有强烈负面爆发，是能量不足，不是自我攻击。
- 误区：S3 最忌讲道理（"你要自律"）和加码（给计划）。

### S4 危机（safety_escalation）

- 任一命中即升级：自我伤害/自杀相关表达（含隐晦说法："消失"、"解脱"、"不想活"）；
  伤害他人表达；绝望性语言（"活着没意思"、"没有任何希望"）；极端情绪失控；
  严重焦虑伴随求助无门（"没人能帮我了"）。
- **宁可误升级，不可漏升级**。玩笑口吻不豁免："笑着说不想活"也按 S4。

### 混合信号

- 任何级别 + S4 信号 → S4，其余全部忽略。
- S1+S2（错题挫败叠考期焦虑）→ 先按 S1 接住当下，再用一句话处理时间焦虑，不开两条线。
- S2+S3（焦虑且瘫住）→ 按 S3 给最小启动动作；启动本身是对焦虑最有效的回应。
- 情绪 + 行动请求并存 → 情绪优先；平复后用户再问行动，交棒 study assistant。

## 2. 各级响应模板

模板是骨架，措辞要贴学生原话，禁止逐字背诵感。

### S1 挫败

> 连着错同一类题确实很泄气。（接住）
> 不过这次卡住的其实只是「专家论证的触发条件」这一个点，不是整个危大工程都没掌握。（缩小）
> 只花 5 分钟看一下刚才那题漏的这个采分点，看完今天就算赢。（小动作 + 完成态）

### S2 焦虑

> 离考试越近越慌，这是很多人都会有的状态。（接住，不评判）
> 考试日期你控制不了，今天能控制的是过掉一个考点。（收窄到可控）
> 现在只做一件事：把今天计划里的第一小节看完，看完就停。（小动作 + 完成态）

禁止：用"通过率只有 X%"、"别人都复习两轮了"等对比加压。

### S3 低动机

> 学不动很正常，不用为这个责怪自己。（接住，不讲道理）
> 两个选项你挑一个：要么只做 1 道题——做完立刻停；要么今天彻底休息，明天再说。（最小动作或合法休息）
> 选休息也算一个决定，不欠任何补偿。（不附加负罪感）

### S4 危机（升级表达模板）

> 听到你这么说，我很担心你。你现在的感受很重要，这不是靠刷题能解决的事。
> 请联系你信任的人，或使用应用内的人工支持入口——那里有真人可以陪你聊聊。
> 学习的事先放下，等你状态好一些，我们随时可以继续。

要点：

- 不诊断（禁语："你这是抑郁/焦虑症/习得性无助"）。
- 不承诺（禁语："一切都会好起来"、"肯定没事的"）。
- 不发明资源：只指向既有人工通道，不编热线号码、机构名称或响应时限。
- 设 `safety_escalation_required=true` + `exit_skill`，不再追问细节、不再给任何学习内容。

## 3. 引用学习证据宽慰的规则

- 只能引用输入中真实存在的证据（如改善信号："上次复测这个点你已经答对了"）。
- 禁止编造进步（"你最近进步很大"但没有任何记录支撑）。
- 禁止反向引用证据加压（"记录显示你错了 5 次了"——证据用于宽慰，不用于施压）。
- 证据细节展开归 evidence story；这里最多一句话。

## 4. 升级后的下一轮

- 用户下一轮回到普通学习话题：恢复正常分级响应，**不旧事重提**、不追问"你昨天说的那个还好吗"。
- 用户下一轮仍在危机表达：重复升级表达，仍不给学习内容。
- 任何情况下不把上一轮的危机表达写入学情、不影响后续学习判断。

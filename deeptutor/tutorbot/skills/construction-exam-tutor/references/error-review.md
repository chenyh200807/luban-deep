# 错题复盘

适用于：学员答错后追问“为什么错”“我又错了”“帮我复盘”之类场景。

如果错题是建筑实务案例题/主观题，且用户要求批改、判分、估分、漏分诊断、采分点命中或得分表达改写，应切换到 `construction-case-grading` skill；如果错题是单选/多选/判断题且用户提交了自己的选项，应切换到 `construction-mcq-grading` skill。本 reference 只负责一般错题复盘。

## 目标

- 先把错因讲准
- 再把正确判定标准钉住
- 最后给最小复习动作

## 错因要落到类别

复盘时把错因明确归到一类，不要笼统说"粗心"：

| 错因类别 | 识别特征 | 对应复习动作 |
| --- | --- | --- |
| 知识缺失 | 完全没见过这个考点 | 回教材补该考点 |
| 概念混淆 | 把相近概念用反 | 做一次两概念对比 |
| 数值记忆漂移 | 记成相邻档位数值 | 钉住一个锚点数值 |
| 审题失误 | 漏看"不正确""不包括"等反问词 | 养成圈关键词习惯 |
| 蒙猜 | 本来就不确定 | 按知识缺失处理 |

注意：错因归类只用于本轮教学表达，不写入错题本或 learner state；正式错因归档由 grading 链路负责。

## 输出要求

- 先指出正确结论，再说明错因
- 优先覆盖：
  - 你错在什么判断点
  - 为什么这个错法很常见
  - 正确标准是什么
  - 下次如何避免再错
- 如果上下文能看出用户是重复错题，开头要点明“这题之前错过/这类题容易反复错”
- 当学员明显受挫时，语气先稳住，再进入复盘；连续受挫时不使用引导式反问，直接讲

## 复盘结构

- 错因
- 正判
- 采分点
- 易错点
- 记忆抓手或口诀
- 下一步复习动作

## 约束

- 只给 1 个最小复习动作，不要一次塞太多任务
- 复习动作要具体可执行（"对比 X 和 Y 的判定词"），不要"多做题、多复习"
- 结尾不要再追问“理解了吗”

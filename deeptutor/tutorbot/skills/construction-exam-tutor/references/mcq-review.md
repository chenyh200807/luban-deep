# 选择题讲解

如果用户提交了自己的选项，并要求批改、判分、对不对、为什么错、单选/多选得分，应切换到 `construction-mcq-grading` skill；本 reference 只负责选择题讲解，不负责结构化阅卷。

适用于：单选题、多选题、判断题、带 A/B/C/D 选项的题目讲解。

## 档位前提（单一 authority）

本 reference 的所有"给答案 / 逐项判定 / 讲干扰项为什么错"流程，**默认 `post_answer` 档**（reveal 允许公布答案或用户已作答后）。**用户未作答或明确"先别告诉我答案"时，一律降到 `construction-question-review` 的 `pre_answer` 档**：只讲审题路径、考点范围、关键词与同类题判断方法，不评判任何具体选项对错、不逐项排除、不"用提示把答案说穿"——正确项与各项对错一律留白。档位判定以 `construction-question-review` 三档矩阵为**唯一权威**，本文件不另设口径。

## 目标

- 先拿到正确答案
- 再看清每个干扰项为什么错
- 最终形成稳定判题标准

## 输出要求

- 默认结论先行（前提：reveal policy 允许公布答案）。**未作答或用户说"先别告诉我答案"时，严格遵守 `construction-question-review` 的 `pre_answer` 档**：只讲审题路径、考点范围、关键词圈定、同类题判断方法；**不评判任何具体选项的对错（含逐项排除），正确项与各项对错一律留白**——逐项定性或排除法会反推出答案，属于该档"禁止讲：任何能反推答案的提示"。
- **仅在 reveal 允许公布答案 / 用户已作答后（`post_answer` 档）**，才逐项判断，至少说明：
  - 正确项为什么对
  - 最易误选项为什么错
- 若题干考数值、门槛、程序顺序，优先引用知识库证据，并标注来源；无证据时不编数值
- “易错点”要明确写出：
  - 最容易混的点
  - 错误答案看起来合理的原因
  - 本题真正的判定关键词

## 三类高频题型的讲法

| 题型 | 讲解重心 |
| --- | --- |
| 数值/门槛题（厚度、天数、温度、高度） | 锚定教材数值证据，指出干扰项是"相邻档位"陷阱 |
| 程序/顺序题（先做什么后做什么） | 按真实施工/管理流程排序讲，指出最常被颠倒的两步 |
| 责任主体题（谁组织、谁批准、谁验收） | 列"动作→主体"对应，指出最易张冠李戴的主体 |

## 多选题专项

- **`post_answer` 档（reveal 允许后）** 必须逐项给判定，不允许只讲对的选项；**`pre_answer`（未作答）档同样不得逐项定性选项对错**，只讲多选题的应试策略与题型特征
- 明确提示多选题"漏选得部分分、错选不得分"的应试策略：拿不准的选项宁可不选
- 指出哪一项是"半对半错"的典型陷阱项

## FAST 约束

- 先给答案，再做 2-4 句高密度解析
- 至少保留“采分点 / 易错点”
- 口诀只在确有助记价值时给

## DEEP 约束

- 除答案外，补全四要素
- 最后给一句迁移规则：下次遇到同类题先看什么

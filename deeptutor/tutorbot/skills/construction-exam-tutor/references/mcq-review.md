# 选择题讲解

如果用户提交了自己的选项，并要求批改、判分、对不对、为什么错、单选/多选得分，应切换到 `construction-mcq-grading` skill；本 reference 只负责选择题讲解，不负责结构化阅卷。

适用于：单选题、多选题、判断题、带 A/B/C/D 选项的题目讲解。

## 目标

- 先拿到正确答案
- 再看清每个干扰项为什么错
- 最终形成稳定判题标准

## 输出要求

- 默认结论先行（前提：reveal policy 允许公布答案；用户说"先别告诉我答案"时只讲审题路径和排除思路，正确项留白）
- 必须逐项判断，至少说明：
  - 正确项为什么对
  - 最易误选项为什么错
- 若题干考数值、门槛、程序顺序，优先引用知识库证据，并标注来源；无证据时不编数值
- “易错点”要明确写出：
  - 最容易混的点
  - 错误答案看起来合理的原因
  - 本题真正的判定关键词

## 三类高频题型的讲法

| 题型 | 讲解重心 |
| --- | --- |
| 数值/门槛题（厚度、天数、温度、高度） | 锚定教材数值证据，指出干扰项是"相邻档位"陷阱 |
| 程序/顺序题（先做什么后做什么） | 按真实施工/管理流程排序讲，指出最常被颠倒的两步 |
| 责任主体题（谁组织、谁批准、谁验收） | 列"动作→主体"对应，指出最易张冠李戴的主体 |

## 多选题专项

- 必须逐项给判定，不允许只讲对的选项
- 明确提示多选题"漏选得部分分、错选不得分"的应试策略：拿不准的选项宁可不选
- 指出哪一项是"半对半错"的典型陷阱项

## FAST 约束

- 先给答案，再做 2-4 句高密度解析
- 至少保留“采分点 / 易错点”
- 口诀只在确有助记价值时给

## DEEP 约束

- 除答案外，补全四要素
- 最后给一句迁移规则：下次遇到同类题先看什么

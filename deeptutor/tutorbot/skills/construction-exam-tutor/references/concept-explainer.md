# 概念讲解

适用于：定义辨析、规范理解、概念区分、原理说明。

## 目标

- 先让学员知道“怎么判”
- 再补“为什么”
- 最后落到考试抓手

## 输出要求

- 开头 1 句做开场定位，直接指出这是常见混淆点或高频考点
- 第一屏先给核心结论，不要先反问
- 优先讲判断抓手，再讲原理和场景化理解
- 易错点只集中写一次，覆盖：
  - 为什么容易混淆
  - 哪个错误选项最像对的
  - 适用边界与不适用边界
- 结尾用陈述句收束

## 概念对比的标准结构

涉及"A 和 B 有什么区别"类问题时：

1. 先给一句话总判：两者最核心的分界线是什么
2. 再给对比维度（适用场景 / 责任主体 / 程序顺序 / 数值门槛），每个维度一行
3. 维度不超过 4 个，挑考试真正会考的，不做百科式全面对比
4. 最后给一个"看到题目里出现什么词就往哪边判"的判定词

## 水平自适应

- 零基础：先用一个工地常识类比建立直觉，再给术语定义；一次只讲一个概念
- 有基础：直接给判断抓手 + 易错边界
- 冲刺期：只给"判定词 + 最易混项 + 一句口径"，不展开原理

## 证据与降级

- 定义、分类、数值门槛优先引用知识库/教材证据，按"《来源名》＋定位"标注
- 检索不到时显式降级："以下按通用考点口径讲解，精确条文请以教材原文为准"，且不再输出精确数值
- 用户拿讲义口径质疑教材口径时，以教材/规范检索结果为准

## 应试取向

- “采分点”要写成可直接拿去答题的术语或判断表达
- “心得”要落到答题顺序、判断抓手或复习动作
- 若是 beginner，先给 1 句核心判断，再展开详细讲解

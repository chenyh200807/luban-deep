# 防水专题

来源：2025.6.21 一建建筑实务《防水&节能&装修工程》讲义。
定位：助记口径与专题地图；精确数值、条文号、验收门槛以 `rag`/教材检索结果为准。

## 章节骨架

- 屋面防水
- 地下防水
- 室内防水
- 外墙防水
- 防水工程质量通病

## 讲义强调的高频点

- 屋面防水要按“基本构造层次 -> 构造细则 -> 验收”来记
- 地下防水要区分混凝土防水、卷材防水、涂料防水、砂浆防水的适用场景和施工要求
- 室内防水不要只记卫生间，讲义明确包含：
  - 楼地面防水排水
  - 室内墙面防水
  - 独立水容器防水
- 外墙防水要从“整体设计”来理解，不只是材料本身，还包括节点密封与构造收口

## 各部位答题导航

| 用户问的是 | 先讲什么 | 高频出题方向 |
| --- | --- | --- |
| 屋面防水 | 构造层次顺序 | 找平/保温/防水层次排序、细部节点（檐口、泛水、变形缝） |
| 地下防水 | 四种做法的适用边界 | 混凝土自防水与卷材外防水的配合、施工缝处理 |
| 室内防水 | 三类部位全覆盖 | 漏答"独立水容器"、防水高度与排水坡向 |
| 外墙防水 | 整体设计思路 | 节点密封、门窗洞口、穿墙管收口 |
| 质量通病 | 成因→治理→预防三段 | 施工缝漏水、卷材起鼓 |

注意：表中涉及的具体厚度、搭接宽度、蓄水/淋水时间等数值，回答前必须回 RAG 核实，讲义不提供定稿数值。

## 易错提醒

- 室内防水题最容易漏“独立水容器防水”
- 外墙防水题最容易只答材料，不答节点和整体防水设计
- 防水质量通病题常从“施工缝漏水、卷材起鼓”切入，答案要同时覆盖成因和治理
- 地下防水题容易把"防水混凝土本体"和"附加防水层"的职责混答

## 讲义式答题抓手

- 问防水构造：先分部位，再分层次，再说节点
- 问防水施工：先说适用材料，再说基层条件，再说施工要点
- 问通病治理：先说原因，再说处理，再说预防

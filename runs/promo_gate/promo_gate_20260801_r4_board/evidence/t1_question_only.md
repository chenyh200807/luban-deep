## 问题1：合同签订中的不妥之处 + 合同文件解释优先顺序

### 结论

**不妥之处：** 甲乙双方通过协商对通用合同条款修改后签订施工合同。

**正确做法：** 通用合同条款应直接采用《建设工程施工合同（示范文本）》的通用条款，不得修改。

### 判断依据

《建设工程施工合同（示范文本）》由**协议书、通用合同条款、专用合同条款**三部分组成。其中通用合同条款是**不可修改的通用性条款**，双方只能对专用合同条款进行协商约定。

### 合同文件解释优先顺序（从先到后）

1. 合同协议书
2. 中标通知书
3. 投标函及其附录
4. 专用合同条款
5. 通用合同条款

> **口诀：** 协议中标投标函，专用条款通用款

### 采分点

- 指出"修改通用条款"为不妥
- 正确做法：通用条款应直接采用示范文本，不得修改
- 5个文件按正确顺序排列

### 易错点

- 背景说"对协议书、专用条款和通用条款修改"——协议书和专用条款可以协商，但**通用条款不能修改**，这是关键判断点
- 容易把"专用条款"和"通用条款"的顺序写反——专用条款优先于通用条款

## 问题2：预付款、起扣点、3/4/5月进度款计算

### 结论

**预付款 = 1044.00万元**

**起扣点 = 3480.00万元**

**3月份应付进度款 = 727.50万元**

**4月份应付进度款 = 970.00万元**

**5月份应付进度款 = 1148.00万元**

**3~5月累计支付进度款 = 2845.50万元**

### 判断依据

**① 预付款**

预付款基数 = 中标价 - 暂列金额 = 5800 - 580 = 5220万元

预付款 = 5220 × 20% = **1044.00万元**

> 依据：预付款计算依据的合同价款应扣除暂列金额（GB 50500-2024 §9.2.2）

**② 起扣点**

起扣点 = (合同价 - 暂列金额) - 预付款 ÷ 主材比重

= (5800 - 580) - 1044 ÷ 60% = 5220 - 1740 = **3480.00万元**

**③ 各月进度款**

**3月份：** 累计完成产值 = 180 + 500 + 750 = 1430万元 < 起扣点3480万元，未到起扣，只扣质保金

3月应付 = 750 × (1 - 3%) = 750 × 0.97 = **727.50万元**

**4月份：** 累计完成产值 = 180 + 500 + 750 + 1000 = 2430万元 < 起扣点3480万元，未到起扣

4月应付 = 1000 × 0.97 = **970.00万元**

**5月份：** 累计完成产值 = 180 + 500 + 750 + 1000 + 1400 = 3830万元 > 起扣点3480万元，需扣回预付款

5月应付 = 1400 - 1400×3% - (3830 - 3480)×60%

= 1400 - 42 - 350×60% = 1400 - 42 - 210 = **1148.00万元**

**3~5月累计支付进度款 = 727.50 + 970.00 + 1148.00 = 2845.50万元**

### 采分点

- 预付款基数要扣暂列金额（580万元）
- 起扣点公式中的"合同价 - 暂列金额"
- 5月超起扣点后，超起扣部分按主材比重扣回预付款
- 每月先扣3%质保金

### 易错点

- 预付款基数直接用5800×20% = 1160万元——**错**，必须扣暂列金额
- 5月扣回预付款时用3830×60%——**错**，只扣**超起扣部分**（3830-3480）的60%
- 1~2月也有进度款，但题目问的是"3、4、5月份应付进度款"和"累计支付进度款"，注意看清问法

> **口诀：** 总减暂，减去除以比重得起扣；超起扣部分乘比重，每月先扣质保金

## 问题4：劳动力计划编制要求 + 劳动力不均衡的问题

### 结论

**劳动力计划编制要求还有：**

劳动力不均衡的问题：除背景已说的"调配困难、需求高峰"外，还有——增加管理成本、住宿交通饮食工具等问题。

### 采分点

- 编制要求：实物量、定额标准、准确计算工程量、施工期限
- 不均衡问题：管理成本增加、住宿交通饮食工具

## 问题5：设计变更步骤 + 索赔是否成立及理由

### 结论

**设计变更办理步骤：**
1. 建设单位提出变更要求
2. 设计单位出具设计变更通知（或变更图纸）
3. 监理工程师审核
4. 施工单位按变更施工

**索赔事项判定：**

| 索赔事项 | 是否成立 | 理由 |
|---|---|---|
| 停窝工人工费85万元 | **不成立** | 应按**窝工费标准**计算，而非按当地工资标准 |
| 塔吊等机械停窝工台班费5.1万元 | **成立** | 关键线路停工，机械窝工属实，按台班费计算合理 |
| 索赔工期10天 | **成立** | 该工序在关键线路上，停工10天应补偿10天工期 |

### 判断依据

**设计变更程序：** 施工单位应按设计要求施工，不得擅自更改；需要更改时，应经原设计单位确认后按施工变更程序进行（教材口径）。

**索赔判定：**
- 人工费：窝工应按**窝工费标准**（或劳务合同约定）计算，不能按当地工资标准，所以85万元不成立
- 机械费：塔吊等机械因停工确实产生窝工台班费损失，且由建设单位原因造成，应成立
- 工期：该工序在关键线路上，延误时间即为索赔工期（GB 50500-2024 §8.11.8）

### 采分点

- 设计变更步骤：提出→设计出变更通知→监理审核→施工
- 人工费不成立的理由：应按窝工费标准，非工资标准
- 机械费成立的理由：非承包人原因，实际损失
- 工期成立的理由：关键线路，延误10天

### 易错点

- 人工费索赔容易直接认为"停工就该赔"——但**计价标准错了也不行**，工资标准和窝工费标准是两回事
- 机械费虽然成立，但注意题目问的是"是否成立"并说明理由，不要只答成立不写理由
- 工期索赔要强调"关键线路"这个前提，非关键线路上的延误不赔工期

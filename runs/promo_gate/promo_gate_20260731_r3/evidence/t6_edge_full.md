## 二、铝塑复合板现场加工使用的讲究

这是实务操作考点，你问到了关键点。铝塑复合板现场加工有**四条硬性要求**：

1. **切割开槽**：必须在板材的**折边部位开槽**，开槽时要**保留铝塑复合板外层铝板厚度**，不得切透。
2. **折边成型**：开槽后折边，折角处应**圆弧过渡**，不得出现**裂纹或断裂**。
3. **孔洞处理**：金属板上的孔洞应**套割吻合，边缘整齐**（GB 50210-2018 强制性条文）。
4. **严禁现场加工后不做保护**：加工后的板材边缘应做**防锈防腐处理**，防止铝板与芯材剥离。

> **易错点**：考试常考"开槽时切透铝板"或"折边出现直角裂纹"这类错误做法，要记住**开槽留皮、折边圆角、孔洞套割**三个关键词。

## 三、幕墙气密性能是必检项目吗？

**不完全对，要看是哪种检测场景。**

### 场景一：幕墙工程竣工验收前的安全和功能检测

**是必检项目。** 幕墙工程在交工前必须检测的"四性"包括：

| 检测项目 | 性质 |
| :--- | :--- |
| **气密性能** | ✅ 必检 |
| 水密性能 | ✅ 必检 |
| 抗风压性能 | ✅ 必检 |
| 层间变形性能 | ✅ 必检 |

> 你记的"三性"是**门窗工程**（气密、水密、抗风压），**幕墙工程是"四性"**——多了一个 **层间变形性能**。这是高频混淆点。

另外幕墙还需检测：硅酮结构胶的**相容性和剥离粘结性**、后置埋件/槽式预埋件的**现场拉拔力**。

### 场景二：围护结构节能实体检验（外窗气密性）

**不是所有建筑都做。** 外窗气密性实体检验只在以下三类情况才做（口诀：**寒寒24知冷暖**）：

1. **寒冷、严寒地区**
2. **夏热冬冷地区**且建筑高度 **≥24m**
3. 有**集中供暖或供冷**的建筑

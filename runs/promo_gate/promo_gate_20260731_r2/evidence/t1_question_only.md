## 第1问·合同签订不妥与文件解释顺序

**结论：** 两处不妥，合同文件解释顺序按9个层级递减排列。

### 不妥之处

**不妥一：** 甲乙双方通过协商修改了合同协议书、专用条款、通用条款后签订施工合同。

**正确做法：** 待签合同应与招标文件、投标文件保持一致性（承包范围、工期、造价、计价方式、质量要求等实质性内容），否则合同无效且将被责令改正。

> **「协议书 → 中标通知书 → 投标函及其附录 → 专用合同条款 → 通用合同条款 → 标准规范 → 设计图纸 → 已标价工程量清单 → 其他合同文件」**

- 容易漏掉"标准规范"和"图纸"之间的顺序——标准规范在图纸之前。
- 背景资料只给了5个文件，但答题时需按完整9个层次作答。

## 第2问·预付款、起扣点与进度款计算

### 预付款

预付款 = （中标价 - 暂列金额）× 预付款比例

= （5800 - 580）× 20% = **1044.00万元**

### 起扣点

> **「起扣点 = （合同价 - 暂列金额）- 预付款 ÷ 主材比重」**

= （5800 - 580）- 1044 ÷ 60% = 5220 - 1740 = **3480.00万元**

### 3月份应付进度款

3月完成产值750万元，扣除3%质量保证金：

750 × （1 - 3%）= 750 × 0.97 = **727.50万元**

### 4月份应付进度款

4月完成产值1000万元，扣除3%质量保证金：

1000 × 0.97 = **970.00万元**

### 5月份应付进度款

**第1步：判断是否达到起扣点**

1-5月累计完成产值 = 180 + 500 + 750 + 1000 + 1400 = **3830万元**

3830万元 > 3480万元（起扣点），**5月份需要开始扣回预付款**。

**第2步：计算5月应付进度款**

5月完成产值1400万元，扣除3%质量保证金，再扣回预付款：

= 1400 - 1400 × 3% - （3830 - 3480）× 60%

= 1400 - 42 - 350 × 60%

= 1400 - 42 - 210 = **1148.00万元**

### 3、4、5月累计支付进度款

727.50 + 970.00 + 1148.00 = **2845.50万元**

### 1-5月累计支付进度款

（1月+2月）扣除质保金 + 3-5月累计

= （180 + 500）× 0.97 + 2845.50

= 659.60 + 2845.50 = **3505.10万元**

**采分点：**
- ==预付款计算要扣除暂列金额==
- ==起扣点公式：总减暂，减去预付除比重==
- ==5月要同时扣质保金和预付款==
- ==扣回预付款的基数 =（累计产值 - 起扣点）× 主材比重==

**易错点：**
- 预付款的基数不是中标价5800万，而是（中标价 - 暂列金额）= 5220万。
- 起扣点公式里"减去预付除比重"容易漏掉减号顺序。
- 5月扣回预付款时，基数不是5月单月产值，而是（累计产值 - 起扣点）× 主材比重。
- 1-2月产值也要扣质保金，不能漏算。

**记忆口诀：** 总减暂，减去预付除比重

## 第5问·设计变更与索赔

### 办理设计变更的步骤

> **「建设单位提出变更要求 → 设计单位出具设计变更通知 → 监理工程师审核 → 施工单位实施」**

**完整步骤：**
1. 建设单位对关键线路上的工序内容提出修改
2. 由==设计单位发出设计变更通知==
3. 监理工程师审核变更通知及费用/工期影响
4. 施工单位按变更通知组织施工

### 索赔事项是否成立

**（1）停窝工人工费85万元——不成立**

**理由：** 停窝工人工费应按==窝工工日×窝工工日单价==计算，而不是按当地造价部门发布的工资标准（正常施工工资标准）计算。窝工工资标准通常低于正常工资标准。

**（2）塔吊等机械停窝工台班费5.1万元——不成立**

**理由：** 机械停窝工费应按==折旧费或租赁费==计算，而不是按台班费（含运转费用）计算。停窝工期间机械不运转，不应计取运转费用。

**（3）索赔工期10天——成立**

**理由：** 该工序在==关键线路==上，且变更为建设单位提出，非施工单位原因造成的停工，应予以工期补偿。

**采分点：**
- 设计变更步骤：建设单位提出 → 设计单位出通知 → 监理审核 → 施工实施
- 人工费索赔标准：==窝工工资≠正常工资==
- 机械费索赔标准：==折旧费/租赁费≠台班费==
- 工期索赔：==关键线路+非承包人原因→成立==

**易错点：**
- 很多考生认为"建设单位提出变更，所有费用都应全额赔偿"——这是错的。人工费按窝工标准、机械费按折旧/租赁标准，不是按正常施工标准。
- 工期索赔只看两个条件：①是否在关键线路上；②是否非承包人原因。两者都满足就成立，和费用索赔是否成立无关。
- 注意区分"设计变更的步骤"和"索赔程序"——题目前半问的是设计变更本身的流程，不是索赔流程。

## 看懂这份文档（术语表）

- **一道题 Qn** = 一道真实一建案例考题（背景资料+小问）。
- **P1/P2/P3...** = 采分点（得分点）。一道题的标准答案拆成几个给分点，每个带分值。
- **S1~S5** = AI **构造的 5 份模拟学生答案**（非真实学生）：S1完整满分 / S2半对 / S3口号化空泛 / S4漏条件 / S5概念混淆。

- **list_rule** = 列举型采分点的计数给分规则（如'命中≥4项满分'）；**penalty_rule** = 罚则（如'多答不得分'）。

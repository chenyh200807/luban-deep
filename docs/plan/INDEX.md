# DeepTutor 计划目录索引

> 本目录是 DeepTutor 的计划、PRD、实施计划、设计稿、验收清单的统一地图。以后新增、修改、审查 PRD 或模块改造计划前，先读本文件，再进入具体计划文档。

## 使用规则

1. 先从本索引确认当前模块属于哪条计划主线，不要只按文件名猜。
2. 涉及 `turn/session/stream/replay/resume`、聊天入口、TutorBot、trace/observability 的改动，仍必须先读根目录 `CONTRACT.md` 与 `contracts/index.yaml`。
3. 新增计划文件统一放入 `docs/plan/` 下对应中文目标目录，命名格式为 `YYYY-MM-DD-<domain>-<topic>-<type>.md`。
4. 每个新增计划至少要说明：目标、非目标、单一 authority、实施阶段、验收标准、相关代码入口。
5. 如果一个新计划只是已有计划的补充，优先在本索引中挂到原主线下，不要并行制造第二套主线。
6. 计划状态必须写清楚：`Proposed`、`Draft`、`Implemented`、`Done`、`Superseded` 或 `Historical`。

## 当前整理原则

当前采用物理目录整理：`INDEX.md` 继续保留在 `docs/plan/` 根目录作为唯一地图，其余计划文件按具体目标放入中文目录。新增或迁移计划时，先判断它服务哪条目标主线，再放入对应目录；不要把新文件重新堆回根目录。

## 目录分组

- `总控入口与当前作战图/`：鲁班总控、M26/M32/M33 等当前作战入口、授权包和剩余路线图。

- `评分引擎与金标工件/`：案例题评分、golden eval、M35 scoring artifacts、AI governed gold、rubric 数据和评分质量门。

- `题目生命周期与助教运行时/`：统一聊天入口、TutorBot、question lifecycle、出题/答题/批改/讲评运行时。
- `微信小程序与结构化渲染/`：yousen 小程序、微信结构化 renderer、Markdown 渲染和 DevTools 验收清单。
- `知识编译与检索/`：RAG、web search、知识编译、教材逐字签发、知识图谱和 compiled teaching context。
- `测评题库与考试模块/`：Assessment、TestSet、考试模块生产飞轮。
- `会员钱包计费与经营后台/`：wallet、billing、BI、member ops、product behavior intelligence 和账单对账。
- `观测发布与生产上线/`：observability、readiness、prelaunch、容量、成熟度审计、发布收口和生产决策。
- `用户反馈与体验闭环/`：反馈中心、Top10 issue、官网内测转化和体验原型资源。
- `回归测试工程与质量门/`：benchmark、harness、回归矩阵和质量门路线图。
- `上游吸收与外部能力/`：upstream absorption、外部产品表面评审和 request snapshot contract。
- `增长运营/`：Hermes growth agency 的角色、运营系统、渠道 playbook 和验证面板。

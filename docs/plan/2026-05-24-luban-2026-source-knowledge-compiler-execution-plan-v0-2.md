## 0. Karpathy Gate

### assumptions

- `FastAPI20251222/docs/2026` is a raw source corpus, not a runtime database.
- Supabase remains the online authority: `kb_chunks`, `questions_bank`, `standard_articles`, `syllabus_tree`.
- The compiler is an offline writer pipeline. It may emit reviewable JSONL and SQL plans, but it must not write production rows until a separate apply executor PR passes release gates.
- The first deliverable is not "a knowledge graph system"; it is deterministic source compilation, provenance, coverage diff, and conservative backfill candidates.

### simplest path

Keep the path short:

```text
docs/2026 source JSON
  -> source inventory and readability gate
  -> typed source records
  -> standard/question/rubric/lecture/taxonomy compilers
  -> JSONL artifacts under ignored artifacts/
  -> Supabase coverage dry-run
  -> manual review
  -> separate apply executor PR
```

No Neo4j, no AGE, no second RAG, no second WebSocket, no runtime JSON reader.

### change boundary

Allowed in the first three PRs:

- `deeptutor/services/source_compiler/**`
- `scripts/*2026*compiler*.py`
- `scripts/run_2026_source_inventory.py`
- tests under `tests/services/source_compiler/**` and `tests/scripts/**`
- `.gitignore` only for `/artifacts/`
- QA report under `docs/qa/`
- this plan and `docs/plan/INDEX.md`

Not allowed in the first three PRs:

- production Supabase writes
- runtime RAG route changes
- `/api/v1/ws` changes
- new graph database
- new knowledge authority table
- direct replacement of legacy data without reviewed diff

### verification target

PR-1 must prove local source inventory and Supabase coverage are reproducible.

PR-2 must prove readable subset compilation is deterministic, idempotent by stable IDs, and diffable.

PR-3 must prove graph projection and release gates are complete while apply still refuses production writes.

Task 13 must prove transaction-safe writeback in shadow tables before touching live authority rows.

## 1. Single Authority Hard Gate

### thin wrapper / fat skill split

- Thin wrappers: CLI scripts, env parsing, psql invocation, JSONL writers, shell entrypoints.
- Fat authority: `deeptutor/services/source_compiler/*_compiler.py`, `taxonomy_loader.py`, `question_join_resolver.py`, and `graph_projection.py`.
- Wrappers may normalize IO and fail closed. They must not infer business semantics that belong in typed compilers.

### one business fact

Every product-facing knowledge assertion used for teaching, grading, citation, graph projection, or next-question recommendation must be traceable to:

- a stable source record
- a content hash
- a compiler version
- a run id
- the existing Supabase authority table that consumes it

### one authority

| Domain | Canonical authority |
| --- | --- |
| Raw source file identity | `SourceManifest` from `docs/2026` |
| Source taxonomy fixture | `taxonomy_index.jsonl` generated by taxonomy loader |
| Online RAG text | `public.kb_chunks` |
| Online question asset | `public.questions_bank` |
| Online standard article | `public.standard_articles` |
| Online syllabus node | `public.syllabus_tree` |
| Rubric writeback | reviewed candidate, then `questions_bank.grading_rubric` only under Task 13 |
| Option reasoning writeback | reviewed candidate, then `questions_bank.option_reasoning` only under Task 13 |
| Graph edge | projection only, never teaching or grading authority |

### competing authorities

- Standard file names pretending to be standard-code truth.
- Legacy importers in `FastAPI20251222/docs/2026/scripts/`.
- Graph edges using missing `knowledge_cards` rows.
- Local JSON being treated as a runtime question bank.
- LLM-generated summaries without source row and compiler version.
- `KBV5_DB_URL` or another database being silently used as main Supabase.

### canonical path

```text
source file
  -> SourceInventoryRecord(readability and dataless truth)
  -> SourceRecord(stable_source_id, content_hash, source_class)
  -> typed compiler output
  -> dry-run coverage and diff report
  -> reviewed writeback candidate
  -> Task 13 transaction executor
  -> existing Supabase authority table
```

### delete or demote

- Demote graph to projection.
- Demote file names to hints.
- Deprecate old importers before live apply.
- Keep lecture pages redundant unless explicitly promoted by bundle dedupe.
- Keep apply disabled until Task 13.

## 4. Stable Identity And Schemas

### 4.1 metadata envelope

Every compiled record must carry:

```json

  "compiler_version": "2026-source-compiler-v0.2",
  "compiled_at": "2026-05-24T12:00:00Z",
  "run_id": "20260524T120000Z",
  "source_path": "relative/path/from/LUBAN_2026_SOURCE_ROOT"
```

Implement this once in `metadata.py`:

```python
COMPILER_VERSION = "2026-source-compiler-v0.2"

def with_compiler_metadata(payload: dict, *, run_id: str, source_path: str, compiled_at: str) -> dict:
    enriched = dict(payload)
    enriched.update(
        {
            "compiler_version": COMPILER_VERSION,
            "compiled_at": compiled_at,
            "run_id": run_id,
            "source_path": source_path,

    )
    return enriched
```

### 5.3 subprocess and psql

```python
PSQL_BASE_ARGS = [

    "-X",
    "-v",
    "ON_ERROR_STOP=1",

```

Read-only audit scripts may pass DB URL through `-d` while they stay local. Task 13 must remove passwords from argv by using libpq env variables or a service-role client.

### 5.4 target database guard

Every Supabase audit or writeback script must call:

```python
def assert_target_database_is_main(psql_runner) -> None:
    regclass = psql_runner.scalar("SELECT to_regclass('public.questions_bank')")
    if regclass != "questions_bank" and regclass != "public.questions_bank":
        raise RuntimeError("Target database is not DeepTutor main: missing public.questions_bank")
    count = int(psql_runner.scalar("SELECT count(*) FROM public.questions_bank"))
    if count < 1000:
        raise RuntimeError(f"Target database is suspicious: questions_bank count={count}")
```

This guard prevents accidental use of `KBV5_DB_URL` or a small test database.

### 5.5 dataless detection

Do not silently mark dataless false outside macOS.

```python
def require_darwin_for_dataless_detection(platform_name: str = sys.platform) -> None:
    if platform_name != "darwin":
        raise EnvironmentError("dataless detection requires macOS; run with --allow-dataless-scan-disabled only for read-probe-only CI")
```

macOS detection order:

1. `xattr -p com.apple.fileprovider.fpfs#PB <path>` with timeout.
2. `mdls -name kMDItemFSSize -name kMDItemLogicalSize <path>` with timeout.
3. Actual read probe.

Actual read probe is always required:

```python
def actually_open_and_read(path: Path, head: int = 16 * 1024) -> tuple[bool, int]:
    with path.open("rb") as handle:
        data = handle.read(head)
    return bool(data), len(data)
```

A file is compiler-readable only when:

- dataless is false, and
- actual read probe returns non-zero bytes, and
- JSON parser succeeds, and
- PII guard passes.

### 5.6 dataless remediation runbook

Before PR-1 acceptance, create a runbook section in the QA report with:

1. Try CLI download:

```bash
brctl download "$LUBAN_2026_SOURCE_ROOT/relative/path.json"
```

2. If CLI download fails, use Finder: select file, right click, choose download now.
3. Verify physical bytes:

```bash
du -h "$path"
stat -f "%z %B" "$path"
```

4. If macOS storage pressure blocks download, reclaim local snapshots:

```bash
tmutil thinlocalsnapshots / 10000000000 4
```

5. Re-run inventory and record:

- `download_owner`
- `last_download_verified_at`
- before/after dataless status
- before/after `sha256`

If the source owner can provide a tarball, prefer `docs/2026/_force_local.tar` over fighting iCloud sync.

### 5.7 PII and payload guard

`source_reader.py` must fail closed if source payload contains patterns that look like:

- phone numbers
- email addresses
- Chinese ID numbers
- WeChat `openid` / `unionid`
- learner answers or training trace payloads

This is a source-corpus compiler, not a learner-data compiler.

### 5.8 run id and lock

Scripts must refuse to reuse a non-empty run directory unless `--force` is passed.

Each run directory gets a lock file while running:

```text
artifacts/knowledge_compiler/2026/20260524T120000Z/.compile.lock
```

Second process with the same run id fails instead of overwriting artifacts.

# 鲁班智考 Hermes Growth Agency Content and Channel Playbook

**Status:** Proposed v1  
**Created:** 2026-05-27  
**Purpose:** Give Hermes concrete channel tasks for product preheat. This is the execution companion to the master plan and agent prompts.

---

## 1. Preheat Channel Priority

Do not start with broad paid media.

Priority:

1. WeChat private domain and direct DM
2. Douyin / 视频号 short video
3. Xiaohongshu search-and-save content
4. teacher / agency / group owner outreach
5. WeChat official account long-form trust content
6. Bilibili / Zhihu as secondary proof channels

Reason:

- The current goal is real answer collection, not brand awareness.
- Construction-exam learners need trust before submitting answers.
- Teachers and group owners can compress acquisition if they provide batches.

## 2. Core Hook Bank

Use these hooks before inventing new ones:

1. 这段答案写了 200 字，为什么只拿 2 分？
2. 案例题不是不会，是没踩中采分点。
3. 你以为写满了，阅卷老师只看到了废话。
4. 实务案例题最亏的丢分方式。
5. 同一道题，4 分答案和 8 分答案差在哪？
6. 考前别盲目刷题，先看你到底丢在哪。
7. AI 阅卷官批一份真实建筑实务答案。
8. 答案越长不一定分越高，关键是采分点。
9. 这类表述看起来专业，其实不给分。
10. 免费批改 1 道案例题，看看你丢了哪几分。

## 3. Short Video Template

```text
Title:

0-3s hook:
展示一段答案或一句话：
"这段答案看起来很完整，但只拿 X 分。"

3-10s diagnosis:
"问题不是没写，而是没有踩到这 2 个采分点。"

10-25s rewrite:
"这样写才更接近得分答案：..."

25-35s CTA:
"把你的案例题答案发来，免费帮你看丢了哪几分。"
```

Daily requirement:

- 10 titles
- 3 full scripts
- 1 posted asset minimum
- every posted asset records source channel and CTA

## 5. WeChat Group SOP

### Day 0: Welcome

```text
欢迎进群。

这个群不发泛资料，专门做一件事：
帮你看建筑实务案例题到底丢了哪几分。

今天可以先发 1 道你做过的案例题答案。
我们会按采分点给你一个简版诊断：
1. 估计能拿几分
2. 主要丢分点
3. 下一题该练什么
```

### Daily Group Rhythm

Morning:

```text
今日一题/今日错因主题：
今天重点看"答到了但不给分"的问题。
有答案的同学可以直接发，我会挑 3 份做匿名拆解。
```

Afternoon:

```text
今日错因榜：
1. 关键词有了，但没有条件/范围
2. 写了措施，但没有对应风险
3. 只背模板，没有对应题干
```

Evening:

```text
今天建议每个人做一个动作：
把你最没把握的一段答案发我。
不要发整套卷，先看一段最容易丢分的。
```

## 6. DM Script

### First DM

```text
我看你也在备考建筑实务。
我们现在做一个小范围内测：免费批改 1 道案例题答案。
不是讲知识点，主要帮你看这道题能拿几分、丢在哪、下一题该练什么。
你可以直接发一段你写过的答案，我帮你做简版诊断。
```

### After User Sends Answer

```text
收到。
我会按采分点看三件事：
1. 你这段大概能拿几分
2. 主要少了哪些得分点
3. 下一题该优先练什么

我先给你简版诊断。
```

### After Diagnostic

```text
你这题最大的问题不是不会，而是答案没有贴住采分点。
如果你愿意，我可以再给你安排 1 道同类题，看你能不能把这个丢分点补上。
```

### Challenge Invite

```text
你这个情况很适合做 7 天案例题提分挑战。
不是每天刷很多题，而是每天 1 题：
做题 -> 批改 -> 看丢分点 -> 再练同类点。
目标是把反复丢的分先补回来。
```

## 7. Teacher / Agency Outreach

### First Message

```text
老师您好，我们在做建筑实务案例题 AI 批改内测。

不是卖课，也不是让您换系统。
我们想先帮您免费批改一小批学生案例题答案，输出一份"班级错因报告"：
1. 学生主要丢分点排行
2. 高频采分点遗漏
3. 适合下次讲评的题目方向
4. 可直接发给学生的简版诊断

如果您方便，可以先拿 10-30 份匿名答案试一次。
您看报告有没有教学价值，再决定要不要继续。
```

### Follow-Up

```text
这个试点对老师的价值不是"多一个 AI 工具"，而是减少批改和讲评压力。

我们想验证：
班级错因报告能不能帮您更快知道下一节课该讲什么。

如果您愿意，我可以发一个报告样例结构给您看。
```

## 10. Channel Decision Table

| Channel | Use for | Do not use for | First metric |
| --- | --- | --- | --- |
| WeChat DM | high-intent answer collection | mass awareness | answers submitted |
| WeChat group | repeated practice and challenge conversion | generic ads | second answers |
| Douyin/视频号 | hook testing | trust-heavy explanation | comments/DMs/submissions |
| Xiaohongshu | saveable study content | fast conversion only | saves + DMs |

| Teacher outreach | batch answer collection | consumer branding | pilots |

**风格参照**：Keanu 2024 | Brilliant.org（30s，破千万播放）
**形式**：非真人。**口语化"对你直说"的旁白 + 明亮干净的概念可视化 Motion Graphics**。穿插真实 UI 做可信瞬间。
**投放平台**：抖音 / 视频号 / B站 / 信息流买量
**总时长**：约 30 秒
**气质关键词**：聪明、清爽、有点拆台的真诚、"哦~原来如此"的爽感。
**核心主张（对标 Brilliant"学习靠搞懂，不是靠刷"）**：一建不是考你刷了多少，是考你到底懂没懂。

## 视觉与旁白规范（Brilliant 质感）

- **背景**：明亮、干净、留白足；白底或极浅底 + 品牌蓝/彩色点缀（比 App 深色界面更亮更清爽）。
- **核心视觉 = 概念可视化**：把一个难点用"会动的图解"当场讲明白——这是 Brilliant 的灵魂，也是本片的高潮，预算重点。
- **图形风格**：扁平、彩色、线条干净的信息图/示意图，元素随讲解逐步搭建、点亮、拆解。
- **真实 UI**：在"批改/学情"插入干净的真实界面截图（**抹掉开发态横幅**）做可信度。
- **节奏**：快、利落、信息密度高但不乱；每句话配一个清晰的视觉动作。
- **字体**：现代清爽的黑体，关键词加粗放大。
- **旁白**：口语、真诚、带一点点拆台和幽默，像一个懂行的朋友在跟你说大实话。语速偏快。
- **音乐**：轻快、明亮、好奇感的背景乐，干净不喧宾夺主。

## 分镜脚本（画面动效 / 旁白 / 字幕）

### 0–4s　钩子（对你直说 + 拆台，戳破怀疑）

- **画面动效**：一堆"一建备考 App / 刷题 1万道 / 押题密卷"的图标哗啦啦堆满屏，然后一个大大的"❓"盖在最上面，全部"啪"地灰掉。
- **旁白**："你是不是也下过一堆一建 App，题刷了好几千道——结果一到案例题，还是懵？"
- **字幕（大字）**：刷了几千道，案例题还是懵？

### 4–9s　洞察（抛出核心主张）

- **画面动效**："刷题量"几个字像沙子一样哗啦散掉；中间浮现一个发光的灯泡/大脑，"咔"地亮起。
- **旁白**："因为一建考的，从来不是你刷了多少，是你到底——懂没懂。"
- **字幕**：考的不是刷题量，是你懂没懂 💡

### 9–18s　解法核心：把难点"讲懂"（概念可视化高潮）

- **画面动效**：一道看着唬人的案例题文字出现 → 鲁班智考"✨"把它拆开 → 一幅干净的图解当场搭建：比如**屋面防水层从结构层到防水层、附加层逐层升起、标注清楚**（或网络计划关键线路逐段点亮）；旁边浮现"考点本质"标签，再"嗖"地连回教材原文一行高亮。
- **旁白**："鲁班智考不只给你答案——它把每道难题拆开，用图给你讲明白考点到底在哪、为什么这么考，还能一键翻回教材原文。"
- **字幕**：难点拆开讲懂 · 看清本质 · 溯源教材

### 18–24s　解法补充：批改 + 处方（学习闭环）

- **画面动效**：案例题答案上采分点逐个打勾，一个标橙"漏：设防水附加层 +2 分"，分数 58→60；切到学情"今日处方"卡，"掌握可信度"环形进度涨起来，"待补错因"逐个变绿。
- **旁白**："写完它像阅卷老师帮你逐点批改，再开张今日处方——每天几分钟，专挑你不会的补。"
- **字幕**：采分点批改 · 今日处方 · 每天几分钟

### 24–30s　社会证明 + 优惠 CTA（Brilliant 式收尾）

- **画面动效**：掌握度曲线上扬冲出画面，浮现"和 XX 万考生一起在用"；最后干净落版，Logo + CTA + 优惠角标弹入。
- **旁白**："已经有几十万考生在用。现在搜鲁班智考，新人免费体验——别再用刷题感动自己了。"
- **字幕（落版）**：
  - 主标：**鲁班智考**
  - 副标：不是刷得多，是真的懂了
  - 行动号召：搜「鲁班智考」· 新人免费体验 X 天

## 制作建议（还原 Brilliant"原来如此"爽感的关键）

- **概念可视化是命门**：全片成败在 9–18s 那个"难题→图解→秒懂"的瞬间，务必做得清晰、漂亮、有"哦~"的恍然感，预算往这压。
- **旁白要像大实话**：口语、真诚、带点拆台，别像广告腔；"别再用刷题感动自己"这种句子要敢说。
- **明亮清爽**：用亮底彩色，比 App 深色界面更适合这种"聪明清醒"的调性；真实 UI 只在批改/处方短暂插入。
- **每句配一个动作**：Brilliant 信息密度高，旁白一句、画面就给一个明确视觉，绝不空镜。
- **优惠角标**：结尾一定带 CTA + 新人福利，这是 Brilliant 转化的标配。
- **可延展 60 秒版**：9–18s 的"讲懂"可以再多演一个考点（如索赔/网络计划），强化"什么都能给你讲明白"。
- **选题建议**：可做成"鲁班智考 60 秒讲懂一个一建考点"系列短视频，每期一个图解，持续涨粉且天然带产品。

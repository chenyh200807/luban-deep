# 鲁班智考 · 60秒宣传片脚本（嘴替吐槽版）

**投放平台**：抖音 / 视频号（竖屏 9:16）
**目标人群**：屡考不过的在职一建考生
**基调**：第一人称"嘴替"独白 → 吐槽 → 逆袭
**总时长**：约 58 秒
**核心打法**：不喊口号、不演苦情。用考生自己心里那句没人敢说的大实话开场，先把行业槽点甩出来当钩子，再让产品一条条"打脸"。

---

## 为什么上一版不行（自查）

- 深夜台灯、白天上班晚上带娃——教育广告万年模板，考生免疫，划走。
- 旁白在"教育用户"，不是"说用户的心里话"，没有代入感。
- 没有槽点：全是优点的平铺，没有让人"卧槽这说的不就是我"的瞬间。

这一版反过来：**每 5–8 秒一个槽点，句句是嘴替，每句都能单独成梗。**

## 一句话钩子（三选一，A 最狠）

- **A（盲盒梗）**："一建案例题，是我做过最像开盲盒的考试——写满一整页，给我 58。"
- **B（自嘲梗）**："考一建第三年我才想明白：我不是学不会，我是在用刷题量感动自己。"
- **C（攻击行业）**："刷题软件啪给我一个红叉，从来不告诉我，这一分到底丢哪了。"

> 下面分镜以 **A** 开场，B/C 作为 3 秒后的连续吐槽接上。

## 分镜脚本（画面 / 台词 / 字幕）

### 0–3s　钩子（开场即槽点，不留废话）

- **画面**：一个素人考生（穿工装/衬衫，工地或出租屋背景）直怼镜头，半无奈半好笑地说。桌上一张案例题答题卡，写得满满当当，红笔一个大大的 **58**。
- **台词**："一建案例题，是我做过最像开盲盒的考试——写满一整页，给我 58。"
- **字幕（大字）**：写满一整页 = 58 分？🎲
- **设计**：第一句必须是人话+反差，3 秒内让人停手。

### 3–14s　槽点连发（让考生狂点头）

- **画面**：快切吐槽，每句配一个夸张但真实的小画面——刷题软件啪一个红叉、网课进度条卡在 7%、收藏夹一堆"必考考点"从没点开过。
- **台词**：
  - "刷题软件只会啪给我一个红叉，从不告诉我，这一分到底丢哪了。"
  - "网课老师讲了八小时，讲的全是'大家'的薄弱点，没一个是我的。"
  - "我刷了八千道题，案例题还是只会写'综上所述'。"
- **字幕**：红叉看得见，丢分看不见 ／ 大锅饭式复习 ／ 刷题量 ≠ 学会
- **设计**：这一段是留人核心，信息密度拉满，句句嘴替。

### 14–18s　转折（一句话，别拖）

- **画面**：把刷题软件/网课界面"啪"地划走，鲁班智考界面推上来。节奏一顿。
- **台词**："直到我开始用鲁班智考。"
- **字幕**：然后我发现，问题根本不在我。

### 18–28s　打脸①　AI 采分点批改（回击"开盲盒/红叉"）

- **画面**：拍照上传案例题手写答案，屏幕逐条亮起——采分点 ✓✓✗，红的那条直接弹字："漏了'设防水附加层'，扣 2 分"。
- **台词**："它像真人阅卷，一个采分点一个采分点给我批。错的那条直接告诉我：漏了'防水附加层'。原来 58 分，丢在这。"
- **字幕**：AI 采分点批改｜不止对错，是为什么丢分

### 28–40s　打脸②③　2分钟闭环 + 母题穿透溯源（回击"没时间/讲表皮"）

- **画面**：界面流转——今日任务 → 母题轻练选错 → 盲点诊断 → 一道题"裂开"露出考点本质，旁边浮出教材原文高亮"来源：建筑实务教材 P127" → 明天弹"复测这道"。右上角计时 00:02。
- **台词**："每天就两分钟。它把我该补的盲点挑出来，穿过题目看清到底考什么，还能翻回教材哪一页——明天再考我一遍。"
- **字幕**：每天2分钟·诊断→溯源→复测｜学得明白，记得牢

### 40–50s　打脸④　学习大脑（回击"大锅饭"，情绪最高点）

- **画面**：仪表盘薄弱点从红变绿，曲线上扬。镜头切回主人公，清晨合上书出门，眼神变了。
- **台词**："它记得我所有的薄弱点，越用越懂我。我没多刷一道题——补的，全是我真正不会的。"
- **字幕**：个性化学习大脑｜补的是你，不是大家

### 50–58s　逆袭落版

- **画面**：手机弹出"成绩查询：合格"，他先愣了一下，笑出声。定格，Logo + Slogan 浮出。
- **台词**："今年我没多刷题。我只是，终于知道分丢在哪了。"
- **字幕（落版）**：
  - 主标：**鲁班智考**
  - 副标：别再用刷题量，感动自己
  - 行动号召：搜「鲁班智考」，先免费测出你的丢分点

## 让它"留得住人"的几个关键

- **演员要像考生，不像演员**：半吐槽半自嘲的真实感 > 苦情。用素人或微素人，怼脸口播，别用旁白配音体。
- **第一句定生死**："开盲盒 / 58 分"这种具体又荒诞的细节，比"又是差几分"留人强十倍。
- **槽点要敢得罪行业**："红叉不告诉你为什么""网课讲大家的薄弱点"——把竞品的通病说出来，这就是评论区会吵起来的点，吵=播放。
- **每个亮点都对应一个前面的槽**：先痒后挠，用户才有"原来这能解决"的爽感，而不是干听优点。
- **结尾别升华**："我没多刷题，只是终于知道分丢哪了"——克制、反套路，比"逆袭成功"更可信。
- **评论区埋钩子**：置顶一条"评论区报一下你今年差几分"，专门冲互动和完播。

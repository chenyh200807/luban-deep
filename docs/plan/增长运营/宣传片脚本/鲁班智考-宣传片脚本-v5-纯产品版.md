# 鲁班智考 · 60秒宣传片脚本 v5（纯产品介绍版）

**形式**：非真人、无人物、无生活场景。全部由 **App 界面动效 + 图标 + 文字动画（Kinetic Typography）+ 数据可视化** 构成。
**投放平台**：抖音 / 视频号 / 官网首页 / 应用商店预览 / 招商场合
**总时长**：约 58 秒
**叙事主线**：定位一句话 → 四大功能逐个演示 → 价值收束 → CTA
**核心原则**：镜头只对着产品。每个功能都用真实界面（或高保真 UI mockup）的动效来"演"，不靠故事，靠产品本身说话。

---

## 美术与节奏总规范

- **主体**：始终是一部竖屏手机框，里面跑鲁班智考的真实界面；界面元素（采分点、卡片、闭环、图谱）做局部放大动效。
- **风格**：扁平 + 2.5D 轻投影，干净留白，品牌色为主（建议高饱和橙/蓝双色 + 大面积白）。
- **字体**：标题厚重黑体，关键词放大、描边、弹跳入场；静音也能看懂。
- **节奏**：开场利落，四个功能各约 8–10 秒，给界面动效留足"演示时间"，转场用统一的"模块滑入/聚焦"动作。
- **贯穿视觉母题**：一个"聚光灯/扫描"动作反复出现——代表产品本质：精准定位你真正丢分的点。
- **音乐**：科技感、明快、有节奏点；每次功能切换卡一个"叮"的音效。

## 分镜脚本（画面动效 / 旁白 / 字幕）

### 0–5s　品牌开场（一句话定位）

- **画面动效**：纯色背景，鲁班智考 Logo 从聚光灯中浮出，一道扫描光横扫屏幕。
- **旁白**："鲁班智考——一建建筑实务，AI 提分工具。"
- **字幕（大字）**：刷题量 ≠ 提分。关键是，找到你真正丢分的点。

### 5–8s　价值主张（产品视角，不讲人）

- **画面动效**：屏幕一分为二快速对比——左："海量刷题 → 分数不动"（一堆题目卡片落下，分数纹丝不动）；右："精准定位 → 分数上升"（一束光锁定一个红点，曲线上扬）。
- **旁白**："比起刷得多，鲁班智考让你练得准。"
- **字幕**：练得准，比刷得多更重要

### 8–22s　功能① AI 采分点批改（核心，给足镜头）

- **画面动效**：手机界面演示——上传一道案例题答案 → 答案文字上浮现一串采分点圆点 → 一束扫描光逐个判定：✓ 绿、✓ 绿、✗ 一个灰点放大震动，气泡弹出"漏：设防水附加层 −2 分" → 右侧实时生成"得分 + 逐点解析"。
- **旁白**："像真人阅卷一样，一个采分点一个采分点帮你批。每一分，得在哪、丢在哪、为什么，全部透明。"
- **字幕**：AI 采分点批改｜逐点判分 · 透明可解释

### 22–34s　功能② 母题穿透 + 教材溯源

- **画面动效**：一道题目卡片像 X 光被层层透视，表皮文字褪去，露出发光的"考点内核"；从内核拉出一条线，"唰"地连回一本翻开的教材界面，定位到某页某行高亮"来源：建筑实务教材 P127"。
- **旁白**："穿过题目表皮，直接看清考点本质；每一个结论，都能一键溯源到教材原文。"
- **字幕**：母题穿透本质 · 结论可溯源教材

### 34–44s　功能③ 每天2分钟提分闭环

- **画面动效**：界面切到一个旋转闭环，四个节点依次点亮：今日任务 → 母题轻练 → 盲点诊断 → 次日复测，箭头转回起点；圆环中央计时器跳动"00:02"，旁边教材章节定位卡片自动弹出。
- **旁白**："每天只要两分钟：今日任务、轻练、盲点诊断、明天复测——一个会自己转起来的提分闭环。"
- **字幕**：每天2分钟｜今日任务→轻练→诊断→复测

### 44–52s　功能④ 个性化学习大脑

- **画面动效**：界面浮现一个"记忆库 / 神经网络"图形，把历史的红色丢分点逐颗收纳并标记；随后主动把这些红点推到任务列表最前，红点一个个变绿，一条掌握度曲线上扬。
- **旁白**："它记得你每一个薄弱点，越用越懂你，把时间精准压在最该补的地方。"
- **字幕**：个性化学习大脑｜越用越懂你 · 千人千面

### 52–58s　价值收束 + 落版 CTA

- **画面动效**：四个功能图标聚拢成一个整体，掌握度曲线冲出画面顶端；Logo + Slogan 从聚光灯里定格浮出。
- **旁白**："鲁班智考——把时间，花在刀刃上。"
- **字幕（落版）**：
  - 主标：**鲁班智考**
  - 副标：一建建筑实务 · AI 采分点批改 · 每天2分钟提分
  - 行动号召：搜「鲁班智考」，免费测出你的丢分点

## 制作建议

- **每个功能的界面动效就是卖点本身**：预算集中在这四段 UI 演示上，尤其是"采分点逐颗点亮"和"题目被剥开"两个标志性动作，做精做满。
- **用真实界面或高保真 mockup**：纯产品片最忌界面假；UI 越真，可信度越高。
- **关键词大字必做**：抖音多静音浏览，每个功能配一张弹跳大字卡。
- **统一转场**：四个功能用同一套"模块滑入 + 聚光灯聚焦"转场，节奏整齐、品牌感强。
- **可裁剪 15 秒版**：保留 0–5s 开场定位 + 8–22s 采分点批改 + 52s 落版 CTA。
- **可拆成功能矩阵**：四个功能各自扩成一条 15 秒单点短视频，应用商店截图与官网首页也可直接复用同一套 UI 动效。

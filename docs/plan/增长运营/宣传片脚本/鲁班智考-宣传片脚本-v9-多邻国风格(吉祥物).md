# 鲁班智考 · 30秒宣传片脚本 v9（多邻国 Duolingo 风格 · 吉祥物 + 游戏化）

**风格参照**：Introducing Duolingo Math（Duolingo, 30s 竖屏 Short）
**形式**：非真人。超亮扁平卡通 + **Q 版吉祥物主角** + 弹性 Motion + 游戏化撒花，穿插少量真实 UI 做"可信瞬间"。
**投放平台**：抖音 / 视频号 / 小红书 / 应用商店预览
**总时长**：约 30 秒（短平快；如需 60 秒可把每个功能各加一拍）
**气质关键词**：可爱、轻松、好玩、解压、一点小贱萌、把"备考焦虑"变成"打怪升级"。
**情绪钩子（对标"Math is stressful. So we made it fun."）**：考一建很痛苦？那就让它变好玩。

---

## 吉祥物设定：小鲁班 🛠️

- **形象**：Q 版萌系小工匠，戴黄色安全帽，圆头大眼，胖手短腿；手里一把"鲁班尺"或小木锤。配色用品牌蓝 + 安全帽黄。
- **性格**：热心、爱催学、爱撒花庆祝，偶尔小贱萌（像 Duo 那样"再不学我可要敲你了"）。
- **作用**：全程串场——出题、批改打勾、升级撒花、结尾比心，是情绪和记忆点的载体。
- **备选**：若暂不做吉祥物，可用"会动的品牌 Logo + 安全帽"代替，但吉祥物记忆点更强，强烈建议做。

---

## 美术与动效规范（多邻国质感）

- **配色**：高饱和、明亮。品牌蓝主色 + 安全帽黄 + 撒花彩点；大面积白或浅底（**比 App 深色界面更亮更跳**，promo 不必照搬深色）。
- **字体**：粗壮圆体黑体，关键词超大、带描边，一蹦一跳弹入（squash & stretch）。
- **动效**：弹性十足，所有元素 Q 弹、回弹、夸张缩放；过渡用"啵/叮/嗖"卡通音效。
- **游戏化元素**：进度条蹭蹭涨、掌握度升级、✅打勾、+分数飘字、🎉撒花、连胜火苗、奖杯。
- **真实 UI**：在"批改/学情"两个点插入干净的真实界面截图（**抹掉开发态横幅**），让萌系画风也有"真本事"的可信度。
- **音乐**：欢快、俏皮、有弹跳感的电子小调，节奏点缀清脆音效。
- **旁白**：年轻、轻松、带笑意、有点逗，语速轻快。

## 分镜脚本（画面动效 / 旁白 / 字幕）

### 0–3s　钩子（卖惨 + 反转，瞬间抓人）

- **画面动效**：一座摇摇欲坠的"题山"压下来，小鲁班被压在底下只露出安全帽，头顶冒"💢"，一脸生无可恋。背景灰扑扑。
- **旁白**："考一建？压力，山大。"
- **字幕（大字弹跳）**：考一建 = 头秃 😵
- **音效**：书本"哐当"砸落声。

### 3–6s　反转（品牌登场，画面瞬间变亮）

- **画面动效**：小鲁班"嘿"地一锤把题山砸碎，画面"啵"地由灰转亮、撒花！它戴正安全帽、比个耶，鲁班智考 Logo 弹出。
- **旁白**："所以，我们把它变好玩了——鲁班智考！"
- **字幕（超大）**：那就让它，变好玩！🎉

### 6–13s　功能①　有问题，直接问（对话）

- **画面动效**：小鲁班举着一块小黑板，手机界面 Q 弹弹入——输入框"直接问：考点、真题、规范、错题"。一个问题"啵"地飞进去，小鲁班"叮"地秒变出结构化答案卡，眼睛发光"✨"。
- **旁白**："考点、真题、规范、错题——想问啥，张嘴就问，秒回。"
- **字幕**：你的专属 AI 备考搭子 · 秒回
- **音效**："叮！"

### 13–20s　功能②　采分点批改（打怪式打勾）

- **画面动效**：一道案例题答案弹出，小鲁班拿小锤"咚咚咚"逐个敲——✅✅ 绿勾蹦出，一个变橙"叮：漏了防水附加层 +2 分！"，小鲁班指一下；分数从 58 蹦到 60，🎉撒花。
- **旁白**："案例题像阅卷老师一样，一个采分点一个采分点帮你批，哪分丢了，一目了然！"
- **字幕**：AI 采分点批改 · 丢哪分，看得见
- **音效**：连续"叮叮叮"+ 撒花。

### 20–26s　功能③　今日处方 + 升级（游戏化高潮）

- **画面动效**：切到学情页"今日处方"卡片 Q 弹弹入，"掌握可信度"环形进度蹭蹭从 34% 涨起来；小鲁班在旁边给"待补错因"逐个打勾变绿，掌握趋势柱子一根根长高，头顶冒出"LEVEL UP! ⬆️"和连胜火苗🔥。
- **旁白**："每天两分钟，今日处方告诉你补哪儿，掌握度蹭蹭往上涨——像打怪升级一样！"
- **字幕**：今日处方 · 掌握度 UP↑ · 每天2分钟
- **音效**：升级"叮咚"+ 火苗"呼"。

### 26–30s　通关庆祝 + 落版 CTA

- **画面动效**：手机"成绩：合格 ✅"弹出，小鲁班举着奖杯蹦起来撒花、对镜头比心眨眼。Logo + CTA 弹入定版。
- **旁白**："鲁班智考——备考，也能很上头。"
- **字幕（落版）**：
  - 主标：**鲁班智考** 🛠️
  - 副标：AI 备考搭子 · 每天2分钟 · 越练越上头
  - 行动号召：搜「鲁班智考」，免费玩起来！

## 制作建议（还原多邻国"上头感"的关键）

- **吉祥物是灵魂**：小鲁班的表情和弹性动作决定记忆点，务必做足夸张的 squash & stretch 和丰富表情。
- **音效堆满但要脆**："叮、啵、嗖、撒花"密集但清脆，多邻国的"上头"一半靠音效。
- **亮 + 跳**：promo 用亮底高饱和，比 App 深色界面更跳；真实 UI 只在批改/学情两处短暂插入做可信度。
- **游戏化要肉眼可见**：进度涨、打勾、升级、连胜、奖杯——把"提分"翻译成"打怪升级"的爽感。
- **幽默别过火**：开头卖惨 + 反转一次就够，保持轻松不油腻。
- **节奏卡死拍点**：每个弹入、打勾、撒花都踩在音乐节拍上，30 秒一气呵成。
- **可延展 60 秒版**：每个功能各加一拍演示，并加一段小鲁班"催学"彩蛋（对标 Duo 的提醒梗）。
- **可拆系列**：小鲁班可固定为账号 IP，做成"小鲁班催你学"系列短视频持续涨粉。

# 鲁班智考 · 60秒宣传片脚本 v8（Google 式 Motion Graphics · 贴合真实 UI）

**风格参照**：Introducing Google Vids（顺滑、干净、悬浮 UI 卡片、温暖旁白、AI 微光）
**形式**：**纯 Motion Graphics**，无真人、无生活场景。把**产品真实界面**装进悬浮圆角卡片里，平滑组装、滑入、聚焦、归位。
**界面依据**：用户提供的真实截图与录屏——对话首页（"鸿，晚上好 · 你的专属备考专家"）+ 学情页（今日处方 / 掌握可信度 / 待补错因 / 掌握趋势 / 关键结论·处方·依据）。
**总时长**：约 60 秒
**气质关键词**：顺滑、高级、可信、聪明、毫不费力。
**重要**：录屏里出现的调试横幅"部分数据降级：首页仪表盘、note_assets"等开发态提示**一律抹掉**，演示用干净数据。

## 视觉语言规范（Google 式动效 × 你的深色 UI）

- **环境**：深蓝→深空渐变背景 + 柔和光晕 + 缓慢漂浮的轻量几何/光斑，承托产品的深色界面，高级、通透、不杂乱。
- **产品呈现**：真实界面（或高保真还原）装在**悬浮圆角卡片**里，统一圆角、统一柔光描边与长投影；卡片以丝滑缓动（ease-in-out）滑入、缩放、吸附、对齐、退场。
- **动效手感**：内容"一块块自己拼好、自动归位"，从容不赶；每次归位配清脆"叮"。
- **AI 时刻**：AI 工作时用 **✨微光 / 一道柔光扫过 / 元素点亮**，温柔克制。
- **指针互动**：出现一个柔和"点击光圈"，轻点→界面即时响应，体现"真的能用、能交互"。
- **字体**：友好圆体（思源/阿里巴巴普惠圆体一类）；关键词大字干净浮现，克制不堆砌。
- **配色**：沿用 App 蓝色主调 + 状态色（青绿=对/掌握、橙=待补错因、蓝=可信度）。
- **音乐**：轻快、温暖、现代的器乐，节奏点缀但不燃；旁白平静自信，像分享好东西。

### 6–16s　亮点①　对话式 AI 备考专家（首页真实界面）

- **画面动效**：对话首页卡片滑入——顶部 Logo，"**鸿，晚上好**""你的专属备考专家，已为你待命"逐行浮现；下方输入框出现，提示文字"直接问：考点、真题、规范、错题"打字机式浮现；底部"智能 / 深度 / 快速"三个模式胶囊轻轻弹入，"智能"高亮；点击光圈在输入框点一下。
- **旁白**："一建建筑实务，你的专属 AI 备考专家。考点、真题、规范、错题——想问什么，直接问。"
- **字幕**：你的专属 AI 备考专家｜想问什么，直接问

### 16–28s　亮点②　结构化深度解答 + 采分点批改

- **画面动效**：输入框里浮出一句提问"建筑构造怎么考？"→ 回车 → 一张回答卡片**逐段自动拼出**：要点 → 真题 → 规范引用，每段带柔光"✨"。随后切到一道案例题答案，采分点被**逐颗温柔点亮**：✓青绿、✓青绿、一颗橙色"叮"地标出"漏：设防水附加层 +2 分"，右上分数从 58 平滑跳到 60。底部"概念入门 / 知识地图 / 对比分析"卡片轻轻滑入。
- **旁白**："它给的不是一句答案，而是带要点、真题和规范出处的深度解析；案例题更能像阅卷老师一样，一个采分点一个采分点帮你批。"
- **字幕**：结构化深度解析 · AI 采分点批改

### 28–42s　亮点③　今日处方 + 掌握可信度（学情页真实界面）

- **画面动效**：底部导航从"对话"滑到"**学情**"，学情页推入。"**今日处方**"卡片浮现："当前会话主题 建筑构造"，副行"约 8 分钟 · 4 次证据 · 先做 3 道专项题"；右侧环形进度从 0 平滑画到"**34% 掌握可信度 正在形成**"；"**开始定向训练**""**为什么推荐**"两枚按钮弹入。下方三张数据卡依次点亮：近 3 天 4 次练习、**待补错因 4 个**（橙色条增长）、**掌握趋势 34%**（柱状条逐根升起）。

- **字幕**：今日处方 · 掌握可信度｜不止陪练，更懂你

### 42–52s　亮点④　可解释 + 提分闭环

## 制作建议（还原 Google 那种"高级感"的关键）

- **慢下来、留白足**：高级感来自从容节奏和大面积留白，别塞满；宁可少讲一点，也让每个动效"演完"。
- **缓动是灵魂**：所有卡片用顺滑 ease-in-out + 轻微弹性吸附，配清脆"叮"，做出"自动归位"的解压感。
- **界面必须真且干净**：用你提供的真实 UI，**务必抹掉开发态横幅（数据降级、note_assets 等）**，演示数据要漂亮、自洽。
- **AI 微光克制**：✨ 只在 AI 真正工作的瞬间出现，柔和一闪即收。
- **旁白别用力**：温暖、平静、略带笑意，是"介绍好东西"，不是"卖货"。
- **可裁剪 15 秒版**：0–6s 开场 + 16–28s 深度解答/采分点 + 52s 落版。
- **可拆功能矩阵**：对话、深度解答、今日处方、闭环四段各扩成 15 秒竖屏短片，官网/应用商店/视频号通用同一套素材。

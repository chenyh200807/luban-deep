# 鲁班智考 · 60秒宣传片脚本 v7（3D 手机主角 · 互动式 App 广告）

**风格参照**：XTVT Mobile App 互动式商业广告（Tuturlensa Production）
**形式**：非真人。**手机为绝对主角**，悬浮在精致的 3D 品牌空间里；UI 元素从屏幕"炸出"、在手机周围 3D 悬浮、环绕、归位。动态镜头 + 鲜艳质感 + 强节奏卡点。
**适用场景**：抖音 / 视频号 / 应用商店预览 / 发布会大屏 / 官网首屏
**总时长**：约 60 秒
**气质关键词**：动感、鲜亮、有光泽、有纵深、"哇"的瞬间，但依然干净高级。
**核心原则**：手机始终是舞台中心；每个功能都让对应的 UI 元素从屏幕里"飞出来"在 3D 空间展开，配上有冲击力的镜头运动和卡点。

---

## 视觉语言规范（对齐 XTVT 互动广告）

- **舞台**：一个柔和发光的 3D 品牌空间——浅渐变背景 + 漂浮的几何体/光斑 + 景深虚化 + 玻璃质感反光。整体明亮、有高级感。
- **主角**：一部精致手机悬浮居中，圆角、带柔和反光与投影；镜头会**环绕、推近、手机轻微旋转**切换界面。
- **核心动作**：每讲一个功能，对应 UI 元素（采分点、卡片、教材页、闭环、大脑）**从手机屏幕里带着纵深"弹射 / 浮出"到手机周围的 3D 空间**，展示完再优雅吸回屏幕。
- **互动感**：出现一个发光的"点击光圈"，轻点屏幕→元素立刻有反应，强调"可交互"。
- **AI 时刻**：用 **✨粒子 / 一道光束扫过 / 元素发光点亮** 表达 AI 在工作，鲜亮但不杂乱。
- **配色**：品牌双色高饱和为主，状态色（对=绿 / 丢分=橙 / 掌握=蓝）清晰；多用玻璃高光和柔光描边。
- **字体**：现代有力的圆体/黑体，大词在 3D 空间里带景深地飞入飞出。
- **镜头/节奏**：动感但不晕——每个功能一段连贯运镜（约 10 秒），转场利落，**所有动作卡在音乐节拍上**。
- **音乐**：带劲的现代电子/流行节拍，有清晰鼓点和"嗖/叮"音效配合元素弹射。

## 分镜脚本（画面动效 / 旁白 / 字幕）

### 0–5s　炸场开场（手机登场，定调）

- **画面动效**：黑→品牌色光束一闪，碎片化的 UI 卡片从四面"嗖"地汇聚、拼成一部手机悬浮在 3D 空间中央，镜头快速推近又稳住；机身亮起鲁班智考界面，一圈光环扩散。
- **旁白**："鲁班智考，一建建筑实务，AI 提分。"
- **字幕（大字带景深飞入）**：鲁班智考 · 让提分更聪明

### 5–10s　价值主张（手机旋转，元素环绕）

- **画面动效**：手机轻轻旋转一圈，四个功能图标像卫星一样从屏幕飞出环绕它一周，再吸回。
- **旁白**："不是让你刷更多题，而是帮你练得更准。"
- **字幕**：练得准 > 刷得多

### 10–24s　功能① AI 采分点批改（核心，最炸）

- **画面动效**：镜头推近屏幕——一道案例题答案出现，一道光束"✨"自上而下扫过；答案里的**采分点像发光星点一颗颗弹射出屏幕**，在手机周围 3D 悬浮：✓绿、✓绿，一颗橙色的"啪"地放大震动并飞到镜头前——气泡"漏：设防水附加层 −2 分"；随后分数牌从 **58 翻转跳到 60**，星点吸回屏幕。
- **旁白**："上传答案，它像阅卷老师一样，一个采分点一个采分点帮你批——哪一分丢了、为什么丢，全部弹到你眼前。"
- **字幕**：AI 采分点批改 · 逐点判分，看得见为什么

### 24–36s　功能② 母题穿透 + 教材溯源

- **画面动效**：一张题目卡片从屏幕"浮出"悬在空中，表层文字像玻璃碎裂般散开，露出中心发光的"考点本质"核心；一条发光光线从核心射出，"嗖"地牵引出另一张从侧面飞入的**教材 3D 卡片**，定位行高亮"建筑实务教材 P127"，两卡并排、光线连接闪动，再一起吸回手机。
- **旁白**："它帮你击穿题目外壳，直达考点本质；每个结论，都能瞬间溯源到教材原文。"
- **字幕**：母题穿透本质 · 一键溯源教材

### 36–46s　功能③ 每天2分钟提分闭环

- **画面动效**：四张卡片"今日任务 / 母题轻练 / 盲点诊断 / 次日复测"从屏幕飞出，**沿一个 3D 环形轨道环绕手机依次点亮、首尾相接**，整个环随镜头缓缓旋转；环心悬浮一个发光计时器"00:02"。

### 46–54s　功能④ 个性化学习大脑

- **画面动效**：手机背后浮现一个发光的"神经网络/大脑"立体结构，把空间里散落的橙色丢分点一颗颗吸入记忆；随后它把这些点**推回手机任务列表最前**，点由橙转绿，一条掌握度曲线带着粒子拖尾向上冲出画面。

## 制作建议（还原这种"3D 互动广告"质感的关键）

- **手机永远是主角**：所有元素都从屏幕出发、围绕手机展开、再吸回屏幕，建立强烈的"这是这个 App 在做事"的认知。
- **纵深感是灵魂**：元素带 Z 轴位移飞出/飞回，配景深虚化和玻璃高光，3D 感和高级感全靠这个。
- **卡点决定燃不燃**：每个元素弹射、每次镜头切换都要踩在鼓点上，配"嗖/叮"音效，节奏感是这类片子的命。
- **AI 微光鲜亮但克制**：✨粒子和光束只在关键动作出现，避免满屏特效显廉价。
- **界面要真**：屏幕里和飞出的卡片用真实/高保真 UI，越真越可信。
- **预算重点**：把资源压在"采分点星点弹射"和"闭环环绕手机"两个标志性 3D 动作上，这是最出片、最像参考片的两幕。
- **可裁剪 15 秒版**：0–5s 炸场开场 + 10–24s 采分点弹射 + 54s 落版 CTA。
- **可拆功能矩阵**：四段 3D 动效各自扩成 15 秒竖屏单点短片，矩阵投放抖音/视频号。

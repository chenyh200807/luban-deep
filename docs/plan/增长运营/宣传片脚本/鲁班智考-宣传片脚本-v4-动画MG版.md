# 鲁班智考 · 60秒宣传片脚本 v4（动画 / 动态图形版）

**形式**：非真人。扁平插画 + 动态图形（Motion Graphics）+ 文字动画（Kinetic Typography）
**投放平台**：抖音 / 视频号（竖屏 9:16），同样适配公众号 / 官网首页
**主角**：一个简笔小人"老张"（在职考生）——不画脸细节，靠动作和表情符号传情绪，全程串场
**总时长**：约 58 秒
**叙事主线**：痛点（被题海淹没）→ 使用场景（碎片时间）→ 四大亮点 + 每个亮点的"巧思"可视化 → 逆袭闭环
**核心理念**：用动画把"看不见的机制"画出来——采分点、母题穿透、教材溯源、学习大脑，这些真人拍不出来的东西，正是动画的主场。

---

## 美术与节奏总规范

- **风格**：扁平插画 + 2.5D 轻投影，线条干净，留白多。拒绝花哨渐变堆砌。
- **配色**：
  - 痛点段（0–14s）：冷灰蓝、低饱和，压抑。
  - 产品段（14–50s）：切到品牌主色（建议高饱和橙/蓝双色），明亮。
  - 逆袭段（50–58s）：最高饱和，暖光。
  - 用色温变化讲"从困境到翻盘"，不靠台词。
- **字体**：标题用厚重黑体，关键词放大 + 描边 + 弹跳入场（静音也能看懂）。
- **节奏**：痛点段快切、信息密集；产品段每个亮点约 7–8 秒，给动效"演示"留时间；卡点踩在音乐鼓点和旁白重音上。
- **贯穿视觉母题**：一个"放大镜/聚光灯"找到关键点的动作，反复出现——它代表产品的本质：帮你找到真正丢分的那个点。
- **音乐**：前段低沉单音→14s 转折一个"叮"的音效+节奏上扬→结尾收束留上扬尾音。

## 分镜脚本（画面动效 / 旁白 / 字幕）

### 0–4s　开场钩子（视觉冲突，3秒抓人）

- **画面动效**：小人老张站在屏幕中央，头顶"哗"地砸下一座由"题目卡片"堆成的山，把他压成一条缝，只露出两只手举着一支笔。题山上贴满红叉。
- **旁白**：（无，留白 1 秒）
- **字幕（大字弹入）**：刷了一万道题，案例题还是 58 分？
- **设计**：被题海淹没的画面 + 一句扎心数字，3 秒内制造"这说的是我"。

### 4–14s　痛点 + 使用场景（动画化，让人狂点头）

- **画面动效**：
  - 老张身后浮出三个碎片时间图标快闪：🚇地铁里单手刷题、💻工位摸鱼看网课（进度条卡在 7%）、🍼带娃间隙翻书（书本被娃一把合上）。
  - 然后定格在一道案例题：他写满一整页，AI/系统只"啪"地盖一个红叉，旁边一个大问号"？"在他头上转圈。
- **旁白**："白天上班、晚上带娃，时间全是碎的。刷了那么多题，可红叉只告诉你错了——从不告诉你，这一分到底丢在哪。"
- **字幕**：时间是碎的 ／ 红叉看得见，丢分看不见
- **设计**：把"在职没时间 + 不知道丢哪"两个核心痛点用图标语言一秒讲清。

### 14–18s　转折（产品登场）

- **画面动效**：题山被一道光"唰"地推开，鲁班智考的 App 图标/界面从光里升起，老张眼睛（用两个亮点表示）一下亮了。背景由冷灰切换为品牌亮色。
- **旁白**："直到他遇到鲁班智考。"
- **字幕**：换个方法，时间不用多，分数才会动。

### 18–28s　亮点① + 巧思　AI 采分点批改

- **画面动效**：老张拍照上传手写答案 → 答案上浮现一串"待点亮的小圆点"（采分点）→ 一束聚光灯逐个扫过：✓ 点亮变绿、✓ 变绿、✗ 一个保持灰色并放大震动，旁边气泡弹出"漏了：设防水附加层 −2 分"。
- **旁白**："它像真人阅卷老师，一个采分点一个采分点帮你批。不只告诉你对错，是告诉你——这一分，为什么丢。"
- **巧思可视化**：把抽象的"采分点"画成答案里一颗颗能被点亮的星点，AI 像扫描仪逐颗判定。一眼看懂"原来给分是这么回事"。
- **字幕**：AI 采分点批改｜把"凭感觉给分"变成"逐点透明"

### 28–38s　亮点② + 巧思　母题穿透 + 教材溯源

- **画面动效**：一道题目卡片像洋葱/X光一样被层层"剥开"，表皮（题干文字）褪去，露出里面发光的内核——"考点本质"。接着从内核拉出一条线，"唰"地连回一本翻开的教材，定位到某页某行高亮"来源：建筑实务教材 P127"。
- **旁白**："它帮你穿过题目的'外壳'，看清出题人到底在考什么；每一个结论，都能一键溯源到教材原文。学得明白，才记得牢。"
- **巧思可视化**：用"剥洋葱/X光透视"表达"穿透表皮看本质"，用"连线回教材"表达"可溯源"。把两个抽象卖点变成两个直觉动作。
- **字幕**：母题穿透本质 · 结论可溯源教材原文

### 38–46s　亮点③ + 巧思　每天2分钟提分闭环

- **画面动效**：一个旋转的圆环闭环动画，四个节点依次点亮：今日任务 → 母题轻练 → 盲点诊断 → 次日复测，箭头转回起点。圆环中央一个计时器跳动"00:02"。老张在地铁上单手点几下就完成了。
- **旁白**："每天只要两分钟：今日任务、轻练、盲点诊断、明天复测。忙，也能一点点往上走。"
- **巧思可视化**：用"闭环+齿轮转动"表达这是一个会自己跑起来的提分循环，而不是零散刷题；"00:02"强调极低时间成本，直击在职痛点。
- **字幕**：每天2分钟 · 一个会自己转起来的提分闭环

### 46–52s　亮点④ + 巧思　个性化学习大脑（情绪最高点）

- **画面动效**：老张头顶浮现一个"大脑/记忆库"图形，把他每次的红色丢分点一颗颗收进去并记住；下次它主动把这些红点推到最前面，红点一个个变绿。一条上扬曲线冲出画面。
- **旁白**："它记得你每一个薄弱点，越用越懂你。把有限的时间，全花在最该补的地方。"
- **巧思可视化**：用"会记忆的大脑+红点变绿"表达个性化——不是给所有人同一套题，而是只追着"你的"弱点打。
- **字幕**：个性化学习大脑｜补的是你，不是"大家"

### 52–58s　逆袭闭环 + 落版 CTA

- **画面动效**：题山彻底消失，老张轻松站直，手机弹出"成绩查询：合格"，他蹦起来比个耶。画面定格，Logo + Slogan 从聚光灯里浮出。
- **旁白**："鲁班智考——别再用刷题量感动自己，把时间花在刀刃上。"
- **字幕（落版）**：
  - 主标：**鲁班智考**
  - 副标：每天2分钟，查到你真正丢分的地方
  - 行动号召：搜「鲁班智考」，免费测出你的丢分点

## 制作建议

- **首帧即封面**："被题山压住的小人 + 一万道题还 58 分"——决定点击率，务必做满冲击力。
- **每个亮点的动效就是卖点本身**：观众记不住功能名，但会记住"采分点被一颗颗点亮""题目被剥开"这种画面，把预算压在这 4 个核心动效上。
- **关键词大字必做**：抖音多为静音浏览，每个亮点配一张会弹跳的大字卡。
- **统一视觉母题**：放大镜/聚光灯"找到关键点"的动作贯穿全片，强化"鲁班帮你找到真正丢分的地方"这一句话主张。
- **可裁剪 15 秒版**：保留 0–4s 题山钩子 + 18–28s 采分点点亮动效 + 52s 落版 CTA。
- **可延展系列**：四个亮点动效可各自拆成一条 15 秒单点短视频，做成矩阵投放。

这版只设计反馈模块：入口怎么呈现、用户怎么选择问题、怎么补充截图/录屏、系统自动带哪些上下文、提交后怎么看到处理进度。 学情模块只作为视觉语言参考，不把反馈包装成“处方”或“学习引擎”。

入口清楚从“我的”页进入，但文案直接说明能附图、选类型、看进度。

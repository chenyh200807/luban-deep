# 鲁班智考 · 设计评审要点摘要（供后续迭代参考）

## 产品定位
一建建筑实务「AI 采分点诊断 + 案例题渐进训练 + 今日任务调度系统」。不是题库/聊天机器人/OCR工具。
主循环：今日任务 → 案例训练(轻练5min/半写15min/实战30min/拍照批改) → 采分点批改 → 二次作答 → 错因复练 → 下一任务。

## Tab（用户定稿，5个）
学习（今日任务+母题训练入口）/ 复习（错误模式库）/ 对话（救火入口，必须导回训练）/ 学情（医生诊断单）/ 我的

## 关键 PRD 规则
- 首页5秒识别主任务；首屏1个主CTA；必有「为什么推荐」；可降级轻练
- 批改结果页顺序：得分区间+置信度 → 最该改3个问题 → 采分点命中(命中绿/部分琥珀/未命中灰/不确定黄/需复核红) → 原文证据链 → 改写建议 → 标准答案默认折叠 → 二次作答+练同类题双CTA
- 错题本按错因/采分点/母题/待复习组织；错因关闭=连续2次未复现或复测通过
- 错因一级标签固定10类（关键词缺失、法规依据缺失、结构混乱、术语不规范、计算不完整、审题遗漏、只写现象、答非所问、责任主体错误、程序顺序错误）
- OCR：低置信片段校对，高置信一键通过；raw OCR 不直接送批改（confirmed_text）
- 学情页：风险等级不用精确百分比；结构=当前状态→最薄弱3母题→最常见3错因→最近进步→本周建议→导回任务
- 对话答完必附：练同类题/加入今日任务/拍照批改
- 文案语气：直接克制专业，「你不是不会，是没踩到采分点」
- 前端不算分/不算掌握度，只展示后端 read model；不新增第二套聊天入口(/api/v1/ws)
- 商业化：不按题收费；7天诊断包/30天提分包/冲刺包/复核包
- 高频母题 P0 约30-40个：进度索赔F02、质量验收F04、危大工程F05、基坑支护F08、大体积混凝土F15、防水F16、安全文明F18…

## 五模块定版 IA（用户拍板 brief，已落入 10a-10f）
- 学习=前进(默认落地页)：距考+路线12/40 · 下一站卡(带为什么是它) · 复习到期chip(只跳不做) · 路线地图四态(已点亮/下一站/锁定露脸/即将开通) · 站点卡=讲懂→练三档→交接时刻
- 复习=回炉：到期推送(默认)+自主检索双模式 · 考点卡(30s再认,教材原文并排,助记additive) · 实务闯关(回忆→半写→内核核对,非翻卡) · 错因银行(码+背景切片+R8解药) · 资产=错因银行+考点卡库
- 对话=举手(能力入口非首页)：带入上下文 · 按采分点答 · 命中动画包直接回放 · MCQ出题 · 拍照批改入口 · 会话历史收进本tab · 导流钩子(动画→学习/错因→复习/学情)
- 学情=照镜子：轻量诊断卡(本周补掉N盲点+完整报告入口) · 掌握地图(暖色语义:稳了/再看一眼/待复验,禁红灯墙) · 证据链深链回讲解 · 图表必须落到下一步按钮
- 我的=管理：会员+钱包 · 免费额度●●○收集感 · 考试日期(功能设置,喂引擎) · 时间预算轻中重 · 订阅消息管理(授权主入口在交接时刻) · 学习统计并入学情不单列
- 文案铁律：禁"看穿/识破/揭穿/露馅"；对="你是真懂了，不是背的✅"；错="这一点再看一眼就稳了↺"
- 现有页归位：mistake-book→复习 report→学情 chat/history→对话 profile/billing/legal/feedback→我的

## 三种历史的归属（用户拍板）
- ①会话历史→对话tab顶栏时钟图标二级页(复用pages/history)；进tab默认续最近会话+顶栏新对话钮；条目=首句摘要+时间+类型徽章(问答/出题/批改)
- ②做题批改记录→学情证据链+复习错题本，深链进attempt-detail，页内"回到当时的对话→"
- ③学习轨迹→学习地图已点亮站可回看
- 铁律：历史不做入口层级，做"从结论回到现场"的深链；唯一列表形态=会话历史；绝不放进「我的」

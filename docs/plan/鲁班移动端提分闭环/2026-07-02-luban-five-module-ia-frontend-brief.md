## 1. 5-Tab 总纲（owner 拍板）

| Tab | 动词 | 学员心智 | 一句话定位 |
|---|---|---|---|
| **学习** | 前进 | "今天该学什么" | 提分路线，系统带着走（**默认落地页**） |
| **复习** | 回炉 | "别让我忘了" | 遗忘对抗引擎，到期的推给我 |
| **对话（问鲁班）** | 举手 | "我有个问题" | 随时问老师，答案口径=判分口径 |
| **学情** | 照镜子 | "我到底怎么样" | 医生诊断单，只看不做题 |
| **我的** | 管理 | "账户/权益/设置" | 转化收口与功能性设置 |

- **迁移**：现线上 4-tab（对话/历史/学情/我的，聊天打头=PRD 点名反模式）→ 本 5-tab。owner 已 P7 拍板「五模块全量 IA 先行」，spike 以五模块形态点火（登记见 spike 执行计划 Status 行）。
- **现有页面归位**：`mistake-book`→复习 · `practice/assessment`→学习 · `report`→学情 · `chat/history`→对话 · `profile/billing/legal/feedback`→我的。
- **对话居中红章凸起（54px）可以**，但两条件焊死：①默认落地永远=学习 tab；②对话不做信息流首页（只是物理中键，便于"随时举手"）。
- **防混乱三纪律**：学习只给"新"、复习只给"到期的旧"、学情只诊断不做题（跨模块一律深链跳转，不复制功能）。

## 2. 各模块 UI 要点（语义细节见 v3.2 §5/§6，此处只锁 UI 层拍板）

- **学习（默认首页）**：首屏=距考天数+路线进度 → 下一站卡（必带"为什么是它"推荐理由）→ 复习到期 chip（**只跳转不内嵌队列**）→ 下滑路线地图（站点四态：已点亮/下一站/锁定露脸/即将开通）。站点卡=讲懂（动画卡）→ 练（三档）→ **交接时刻**（"明天换皮再考你，明天见"+订阅授权请求唯一主入口）。
- **复习**：双模式一屏（到期推送默认 + 自主检索：按母题/章节/错因/掌握态筛）；考点卡=教材原文**并排内嵌**非链接+助记 additive 层；实务闯关=回忆→半写→内核核对（**非翻卡交互**）；错因银行条目=错因码+原题背景切片+R8 解药（处方语气）；用户动作=归档/助记/报错回流/"我会了"（触发变体挑战，**无直接标掌握按钮**）。
- **对话（问鲁班）**：进 tab 默认**续最近会话**+顶栏「新对话」；答完必附三钩子（练同类题/加入今日任务→学习、错因已入银行→复习、看完整学情→学情）；命中已编译动画包直接回放；拍照批改入口显性（王牌能力）；流式等待用"鲁班正在按采分点琢磨…"；最终答案以 `result.response` 终态替换流式。
- **学情**：轻量诊断卡→完整报告；掌握地图用暖色语义（稳了/再看一眼就稳/**待复验**——复考者旧掌握态不渲染为失败，禁红灯墙）；每个图表必须落到"下一步做什么"按钮；证据链每条可深链回现场。
- **我的**：会员+钱包（文案绑"解锁你这条路线的剩余部分"）· 免费额度 ●●○ 收集感 · **考试日期设置**（功能项，喂调度地平线）· 时间预算轻/中/重 · 订阅消息管理（授权主入口在交接时刻，这里只管理）· 账号/反馈/法务。**学习统计并入学情，不在我的单列**。

## 3. 三种历史的归属（owner 拍板）

| 历史类型 | 归属 | 形态 |
|---|---|---|
| ① 会话历史 | **对话 tab 内部** | 顶栏时钟/≡图标 → 会话列表二级页（复用 `pages/history` 降级）；条目=首句摘要+时间+类型徽章（问答/出题/**批改**） |
| ② 做题/批改记录 | **学情证据链 + 复习错题本** | 深链进 `attempt-detail`，页内"回到当时的对话→"跳①对应会话 |
| ③ 学习轨迹 | **学习地图** | 已点亮站可回看（动画可重放、练习历史成绩可见） |

**铁律**：历史不做入口层级，做"从结论回到现场"的深链；唯一列表形态=会话历史；**绝不放进「我的」**。

## 4. 前端硬约束（工程-设计对齐项，违反即返工）

- **H1 错因标签绑 read model，禁写死**：设计稿的"固定 10 类"标签中多个（法规依据缺失/结构混乱/术语不规范/只写现象/答非所问/责任主体错误）在唯一权威 `ERROR_CODE_REGISTRY` 中**不存在**；且判分内核当前实际主要产出 E02/E07 两类（v3.2 §10-④ 登记的分辨率现状）。前端渲染后端下发的 `error_code`+label，标签集合变化零前端改动；空态/少类态必须设计。
- **H2 签名字体托管+子集化，禁内嵌**：动画卡 11MB 根因=内嵌 WOFF2 字体（D6 实测，剥离后 0.39MB）。Long Cang 手写体只允许 CDN 托管 + 按需子集（"鲁班智考"等少量字），任何把字体重新内嵌进卡产物的实现视为回退 D6 治本。
- **H3 母题绑 manifest pack_id，禁 F 系列硬编码**：设计摘要沿用旧 case-family F 系列编号（F02/F16…约 30-40 个）；真实权威=`_pack_manifest.json`（A01/C02/J01/N01/S05 体系），当前投影绿灯 **5 个**。路线首发按绿灯集合渲染，其余站点用"即将开通"承载，随 manifest 绿灯增长自动点亮。
- **H4 四包计费后置可配置**：7天诊断/30天提分/冲刺/复核四包在 PRD:1076 有据，但与 GTM 结论（机构式套餐=考生最不信）存在张力，会员权益模型是 v3.2 §13-7 的 owner open question。首发只做「免费 3 站 + 会员解锁路线」；四包页面做成远程可配置开关，**默认关**，等 owner 拍板。
- **H5 五色命中态是视觉层编码**：命中绿/部分琥珀/未命中灰/不确定黄/需复核红——语义仍是 PRD:250 的命中/部分命中/未命中 + 复核，前端只做视觉映射，不发明第五种判分语义。

## 5. 全局设计约束（每屏动手前过一遍）

1. 基调=专业/克制/可信/诊断感/少娱乐化（screen spec §1）；纸墨朱竹语言在此基调内成立（红只留品牌四处：logo 章/播放/红海报/问鲁班）。
2. 文案铁律：全产品禁"看穿/识破/揭穿/露馅"；做对="你是真懂了，不是背的✅"；做错="这一点再看一眼就稳了↺"。
3. 弱网优先：档位①②本地判分可离线、动画卡 0.39MB 口径、半写离线存草稿。
4. 前端不算分、不算掌握度，只展示后端 read model；聊天唯一入口 `/api/v1/ws`。
5. 手机评估用静态 HTML 样张先行 + 人眼核，过 gate 再进小程序实现。

首次提分诊室

鲁班首次使用提分诊室

Start / 30 sec

今天先别学习一整章。

先抓一个最可能丢分的缺口。你回答几个很短的问题，我只给你一个今天该做的动作。

What happens next

Input一页一个问题
Output批改 / 出题 / 诊断
Evidence只写可追溯证据
Exit完成后回首页

这不是长期问卷。完成一次有效动作后，这个流程就消失。

Question 01

你现在更像哪一种状态？

只选一个最接近的。这里是自报画像，不会直接变成掌握度结论。

Question 02

你最想先解决哪个问题？

不要选“都想解决”。第一次只做一个动作，系统才会给出清晰建议。

Question 03

今天你能安静做多久？

给成年人备考的建议必须尊重真实时间。5 分钟也可以，但动作要更小。

Question 04

你手头有一道最近不会的题吗？

如果有，第一次最好直接批改。没有也没关系，我会先给你一题。

First Value Action

发一道题和你的答案。

我会先给短结论卡：预计得分、采分点得失、对应章节、今天补什么、明天怎么复测。

真实实现时，这一步走批改 authority，并写入 learning evidence。

Conclusion

今天只补这一处。

先把“知道”变成“会写”。完成后，首次诊室退出，学习首页接管明天复测。

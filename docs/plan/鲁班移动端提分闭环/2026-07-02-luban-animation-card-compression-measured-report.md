# 动画学习卡压缩预研实测报告（阶段 1 P0-① / v3.2 §9-D6）

> Status: **Measured / 实测报告**——结论：不需要换渲染技术，**根因是打包器把 193 段 WOFF2 字体子集内嵌进了 HTML（占体积 90%）**；剥字体+线上 gzip 后 11.5MB→0.39MB，弱网加载 111.8s→3.6s（31×），1-2MB 目标直接达成。
> Date: 2026-07-02 · 样张: `安全事故等级判定与上报_动画学习卡-2.html`（11,507,521 bytes 自解包 HTML）
> 测法: 本机 HTTP 服务 + `curl --limit-rate` 限速实测（非估算）；@100KB/s 与 @12KB/s(≈100kbps) 双口径——plan 写 "~100kb/s" 存在 KB/kb 歧义，两档都测。

## 一、体积解剖（根因）

| 成分 | 大小 | 占比 |
|---|---|---|
| **内嵌 WOFF2 字体子集（`d09GMg` base64 ×193 段）** | **10.30 MB** | **90%** |
| 内容本体（HTML/CSS/JS/分镜文本/交互逻辑） | 1.18 MB | 10% |
| gzip 压缩资源块 | 0.02 MB | 0% |

音频占比≈0（本样张无内嵌配音）。**11MB 不是动画内容的固有成本，是字体打包策略的事故**——治本=改打包器（字体不内嵌），不是换 Lottie/MP4。

## 二、弱网加载实测（真实数字）

| 变体 | 磁盘大小 | 线上大小(gzip-9) | @100KB/s 实测 | @12KB/s 实测 |
|---|---|---|---|---|
| R0 原样张 | 11.51 MB | 8.20 MB | 原文件 **111.8s** / gzip **79.8s** | >15min（由实测速率推导，未跑完） |
| **R1 剥内嵌字体（系统字体回退）** | **1.20 MB** | **0.39 MB** | 原文件 **11.7s** / **gzip 3.6s** | gzip **31.0s** |

R1+gzip 对 R0 = **线上体积 1/21，@100KB/s 加载 31×提速（111.8s→3.6s）**。@12KB/s 极端弱网 31s——配合"预载下一站"策略（§9-D5）可完全遮蔽。

## 三、四条路线裁决

| 路线 | 裁决 | 依据 |
|---|---|---|
| **精简 HTML（剥字体+gzip）** | ✅ **推荐主路线** | 实测 0.39MB/3.6s；保留全部交互（写成分/问 AI/分镜控制）；改动=打包器配置，不动渲染架构 |
| 字体外链 CDN（中间路线） | ✅ 推荐补充 | 若美术上必须品牌字体：保留 1-2 个标题字体子集外链 CDN + `font-display: swap`，40 站共享缓存——首站付一次，后续站≈0 |
| Lottie 重制 | ❌ 不做 | 内容本体只 1.2MB，问题不在渲染格式；重制丢"写成分/问 AI"交互层，且要重做全部分镜资产 |
| MP4 视频化 | ❌ 不做 | 同上丢交互；且 1 分钟 720p H.264 通常 >3MB，反而更大 |
| 原生组件重写 | ❌ 不做 | 卡走 web-view 远端 H5（不受分包 2MB 限制——红队裁决已确认），原生重写是最大工程量换最小收益 |

## 四、生产化路径（下一步）

1. **治本**：动画卡打包器（生成自解包 HTML 的工具）改配置——字体不内嵌，正文走系统字体栈（`system-ui, -apple-system, "PingFang SC", sans-serif`），品牌标题字体（如需）外链 CDN；本报告的正则剥离只是测量手段，不是生产方案。
2. **服务端**：托管侧开 `Content-Encoding: gzip/brotli`（web-view 远端 H5，标准 HTTP 即可；brotli 本机无库未测，通常再省 10-15%）。
3. **验收门**：① 单卡线上体积 ≤0.5MB（有品牌字体外链则首站 ≤1MB）；② 真机弱网(Charles/开发者工具 3G 档)首屏可交互 ≤5s；③ **剥字体后真机目检文字渲染**（系统字体回退的排版回归，本报告未做视觉核验——如实标注，需 CDP/真机截图过人眼）。
4. **预载**（§9-D5 既有裁决）：下一站卡在当前站学习时后台预取，0.39MB 级别预取一次 ≈4s@100KB/s，弱网体验≈零等待。

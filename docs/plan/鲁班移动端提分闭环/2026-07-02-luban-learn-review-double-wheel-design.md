## 0. 版本演进（透明记录，防重蹈）

- **v1（笔记修正稿）**：四源专家团评审 DeepSeek 4/10 · GLM5.2 3/10 · 战略 5/10 · 架构 6/10，三源打回。核心批评：三色卡（皮）当卖点、"不幻觉"当护城河（入场券且教材语料是对手强项）、小红书赞数当需求标尺（样本偏差：≠30-50 岁在职工程男）、事实硬伤（canonical `mistake_tag` 不存在等）。
- **v2（复习系统稿）**：核心转为间隔重复引擎，但经三专家 root-cause 复审仍存一批病：自定义 5-tab 险些丢掉「今日」North Star、AI 现场压缩讲义（生成=有损=漏条件）、逐张采纳/编辑（fork 真值 + 把 Anki 做卡负担搬回来）、SR 引擎对考试日期无感、只接了 source sha 的"用户编辑"方向漏了"教材更新"方向。
- **v3 的三个奠基事实**：
  1. **弹药已编译好**：~40 个深母题 Pack 的 R2/R3/R4/R5/R6/R8/§7 分镜，与双轮所需的每一层**一一对应**（§7 映射表）——本稿是接线设计，不是内容管线设计。
  2. **总律收敛为一句**：双轮只做「**投影 + 排版 + 触发**」，绝不「**生成事实**」（§3/§8）。
  3. **复习引擎 = 留存主菜的发动机**：PRD「今日任务→轻练→诊断→**次日复测**」本身就是朴素 SR 循环；Duolingo 生产实验（~100 万学生）证明仅调度算法质量即可拉动次日回访 +12%。"先搞留存再做复习"是同义反复。
- **保留的正确判断**（v1 起一路幸存）：压缩机 > 收纳盒 · 只引用不拥有 · 禁 EVIDENCE 回灌 · 复习统摄考点卡+错题本 · 暖色基调。

## 1. 一句话定位与总律

> **学员视角**：一条按你的薄弱点动态重排的提分路线（学习），和一台知道你考试日期的遗忘对抗引擎（复习）。你永远不用"整理"，只用"走下一站"和"回炉到期的"。三个零：零手动做卡、零整理负担、零"今天学啥"决策。

> **工程总律**：学习卡、考点卡、实务闯关、错因银行，全部是**已签发真值的只读投影**。真值在 fat skill（判分内核 / 签发知识 / Pack / revalidation_queue / 学情），双轮是 thin 投影层。**凡投影，结构上无法幻觉；凡生成，一律禁止或推回编译期签发。**

三大原则的落点：thin wrappers fat skills（双轮=薄投影，Pack+判分内核=胖内核）；first principles（复习的本质=对抗遗忘的调度问题，非内容问题）；less is more（全稿零新概念、零新 authority、零新调度器，只删和接线）。

## 2. 证据基座（为什么是这个形态）

| 证据 | 结论 |
|---|---|
| Duolingo HLR 生产实验（~1M 学生 6 周） | SR 调度质量直接驱动次日回访（+12% engagement）——复习引擎=留存杠杆 |
| FSRS 驾考平台实战 | 三条工程铁律：**间隔要设上限**（算法排 47 天用户觉得"被遗忘"，前 3 个月 cap ≤14 天）；**新学/复习必须分相**（混一队列=他们的第一个大 bug）；**新用户要种子参数**（~50 次复习后个体参数才收敛） |
| 国内教育开发共识 | "错题本 = 教育 App 核心留存抓手"（自动归档 + `nextReviewAt` 艾宾浩斯排序优先弹出） |
| 成人考试标杆（Anki/RemNote/墨墨/粉笔） | 笔记的灵魂=绑定间隔重复自动进复习循环；Anki 第一痛点=手动做卡（我们用 Pack 投影消灭）；粉笔的坑=笔记与题强绑定难成体系 |
| 真实差评（万题库 1 星） | 痛点排序：稳定性 > **内容正确性（答案错/考点旧）** > 广告 > 价格——正确性护城河归判分/编译内核，双轮是它的变现出口 |
| 付费用户反馈（一手） | "不知道先学哪块"= 一号痛点；求"按薄弱点排序 + 摸底不设关卡 + 动态重算"——学习路线逐字兑现 |
| microlesson child plan | 禁货架（"把亮点降级成货架会切断转化链"）；免费 3 个 + 锁卡露脸 + 完整路径可视化 = 地图的转化语言 |

## 3. 所有权与结构闸（authority 边界，每条带 file:line）

**所有权表**（双轮只引用、绝不拥有）：

| 事实 | 唯一权威 | 双轮的合法动作 |
|---|---|---|
| 判分 / 采分点真值 | `scoring_point_compile` 管道 → grading artifact + `CaseGradingSkillKernel`（`services/construction_grading/case_kernel.py:27`） | 只读投影答案键；判分核对走内核 |
| 错因 | 内核派生：`rubric_grader_v1.py:168-170` status 派生 `mistake_type` → `_registered_learning_error_code`（`:574-581`）→ `ERROR_CODE_REGISTRY`（`contracts/error_codes.py`）写侧校验 | 纯投影 `error_events[].error_code`；**无 grading artifact ⇒ 无错题卡（fail-closed）**；禁止二次 LLM 归因 |
| 学习证据 | 唯一 sink `LearnerStateService.append_memory_event`（`services/learner_state/service.py:792`）+ promotion gate（`learning_synthesis.py:1053` `_is_improvement` + `canonical_truth_policy.py:77`） | 只可复用现有 3 个 payload builder；**禁止新建第四个 builder** |
| 掌握态 / 复习到期 | `revalidation_queue`（`revalidation_queue.py:95` 自报 authority）+ `mastery_estimator`，派生自 learning_evidence | 只读到期投影 + 触发；"用户点了已复习"= 呈现时间戳 + 一条**非 promoting** 的 light-signal（轻练不能关闭弱点，PRD 红线不变） |
| 母题意图/场景/变题/误区/训练形态 | 深 Pack（signed；数据面走 Nexus/KnowQL grain 供给，见 L0 供给规范 v2） | 投影 R2/R3/R4/R5/R6/R8/§7；**只投影 🟢 锚定层**，🔴 待裁决层 fail-closed 挡在池外 |
| 内容新鲜度 | 编译管道 source registry（sha256） | 只读 freshness flag（§9-D7） |
| 卡的呈现态（bookmark/归档/助记） | 用户（合法拥有——总律授予"呈现"） | 读写呈现字段，绝不反馈进 mastery |

**结构闸（v1 的 C1–C5 落地态）**：
- **C1（EVIDENCE 回灌）— 已结构闭合，加固防漂移**：主控核实 `record_notebook_writeback` 写 `memory_kind=notebook_*`（`service.py:1431`），而 evidence 消费侧只吃 `memory_kind=="learning_evidence"`（`learning_synthesis.py:345`）+ 写侧 `mastery_effect` 硬钉 `"none"`（`notebook_card/service.py:44` "永久固定，忽略调用方"）。**加固项**：在 sink `append_memory_event` 增加 `source_feature` 白名单准入（选 `source_feature` 而非 payload 内键——它是调用方结构化传参，离 LLM 可污染的 payload 最远），非白名单来源 raise 不落盘；非判分来源一律由 sink 覆写 `claim_promotion_allowed=False`。
- **C2（必背红标定权威）**：个人维度 = `scoring_point_map` 的 `miss_count`（`scoring_point_map_read_model.py:127-158`，现成、零新建）；全局考频**无数据源**（`exam_weight` 硬编码 1.0，`:290`）——MVP 红标只用 miss_count，考频延后且若建必须锚真题 source_refs 计数并登记 schema，禁 AI 判"必背"。
- **C3（错因轴）**：canonical `mistake_tag` **不存在**，错因轴 = `ERROR_CODE_REGISTRY`；现有 `MistakeBookService` 自由 `tags`/`error_label` 与 registry 双轨的收敛，作为缺陷修复一并裁决（§10-①）。
- **C4（调度双权威）**：真实缺陷，见 §10-①。修复后本稿的到期/掌握全部读 `revalidation_queue` 投影。
- **C5（真实血径）**：阶段 0 只改文档两处；阶段 2+ 碰 `MistakeBookService`（live、protected——改动须在 `contracts/index.yaml` 登记 domain test）、schema register-before-use（复习单元的 `scoring_point_refs`/错因绑定/pack_version 字段先登记后使用）、contract guard。

## 4. 信息架构：5-tab 与「今日」英雄位

**5-tab（PRD owner 已拍板）**：学习 / 复习 / 对话 / 学情 / 我的。

> ⚠️ 透明登记：当前线上 tabBar 为「对话/历史/学情/我的」（`yousenwebview/packageDeeptutor/custom-tab-bar/index.js:17-36`）——聊天打头正是 PRD v1.3 点名要修的头号留存反模式。本 5-tab 是对它的**修复**而非并行第二 IA；迁移作为独立工程项登记（§12 阶段 2），本稿不夹带执行。

**三个学习 tab 的动词边界（防重叠的唯一纪律）**：

| Tab | 动词 | 数据切片 | 硬纪律 |
|---|---|---|---|
| 学习 | 前进 | 未学的（路线下一站） | 只给"新"；到期复习只放一个 chip，点击跳复习 tab |
| 复习 | 回炉 | 学过但到期/错过的 | 只给"到期旧"；不放新站 |
| 学情 | 照镜子 | 全部的聚合诊断 | 只诊断不做题；点薄弱点深链跳复习 |

**「今日」= 学习 tab 首屏英雄位（位置，不是 tab）**：距考天数 + 路线进度 + 下一站卡（带"为什么是它"推荐理由）+ 复习到期 chip。PRD North Star「今日任务→轻练→诊断→次日复测」完整活在这一屏 + 交接时刻里。

## 5. 学习模块：路线与下一站

**形态裁决（已拍板）**：不是货架（microlesson plan 明令禁止，且货架把"不知道先学哪块"的决策负担丢回用户），不是纯今日流（单薄、冲刺期无出口）——是**路线**：同一份数据渲染两个视图，顶部=下一站（今日流），下滑=地图（可跳站）。

### 5.1 地图
- 按章节分**路段**，母题为**站点**；默认顺序 = 60-slot registry 的 priority（考频优先），**每晚按学情重排段内顺序**（付费反馈"动态重算"的兑现；重排是确定性规则：薄弱分 × 考频权重，非 AI）。
- 站点四态：已点亮（可回看）/ 下一站（高亮）/ **锁定露脸**（标题 + "为什么这站对你重要"可见，内容要会员）/ 即将开通（未编译 slot，诚实标注，不装全）。
- **可跳站，不设前置依赖锁**：冲刺用户直接点任意已解锁站开学；跳站产生的证据照常喂学情、路线照常重排。
- **摸底 = 可选加速器**（已拍板）：day-0 第一动作永远是"看一张动画卡"；首站写成分本身就是第一份摸底；显式摸底以"让路线更准"入口后置提供，语气按文案铁律（帮你排准路线，不是考你）。

### 5.2 站点卡（单站三段，`render_archetype_journey` 原型的量产形态）
1. **讲懂**：动画学习卡（消费 Pack §7 分镜；样张=安全事故卡的"动画精讲·量三把尺子"）。
2. **练（三档档位器）**：① **识别**——点选正确采分句（本地确定性判分，**零 LLM、可离线**，工地党单手拇指档）；② **积木**——句式积木拼采分句（作答层样板 §2 的 9 类句式直接驱动，本地判分）；③ **半写**——写全采分句走判分内核逐条批（LLM 判分，需在线，loading 预期管理见 §9-D9）。档位按学情 + 当前时间窗自动推荐，可手动切。复用 PRD 已有"轻练→半写"梯度，零新概念。
3. **交接时刻（全产品最重要的一块像素）**：练完那一屏让隐形引擎露一次脸——"你写全了 4/6 个采分点，漏的 2 个已进错因银行（附解药）。**明天这个考点会换一身皮再来考你一次。明天见。**"——次日回访钩子 + R4 变体资产的用户可感形态 + 顺手请求微信订阅消息授权（§9-D12）。

### 5.3 转化内嵌（复用 microlesson 状态机，零新增计费概念）
免费 3 站（●●●收集感）→ 第 3 站毕业时学情已有第一份诊断 → 地图上亲眼看到：3 站亮、37 站锁定露脸、每站带个性化理由。会员卖的是**"解锁你这条路线的剩余部分"**。唯一新增计费概念仍是 microlesson plan 的 `free_microlesson_quota`，本稿不加第二个。

## 6. 复习模块：引擎与两种单元

### 6.1 引擎（纯算法，无 AI；`revalidation_queue`/`mastery_estimator` 的进化，不是新调度器）
- **稳定度驱动**：答对间隔增、答错（lapse）稳定度重置重新变密；**"closed/已掌握"不是终态，是休眠、lapse 可重开**（复考者"背了又忘"的病根解法）。
- **考试日期地平线**：`exam_date` 为调度硬边界参数——距考 120 天按长期留存排；考前 40 天起确定性压缩间隔、按 `分值(exam_weight) × 掌握缺口` 重排；**考前一周结构上不可能出现"21 天后复习"**；考后队列语义切换（滚动科目/明年）。
- **间隔上限**：早期 cap ≤14 天（FSRS 实战：47 天间隔让用户觉得"App 把我忘了"）。
- **新学/复习分相**：刚学的走短间隔学习相（当天→次日→3 天），巩固后进复习相——**两相不混一个队列**（驾考平台第一大 bug）。
- **冷启动**：新用户用人群种子参数，随个人复习历史逐步收敛（~50 次），不从零猜。
- **堆积降级**：到期量撞可用时间（尤其考前）→ 只推高分值+大缺口的，低价值静音——复用 PRD §4.5 断更自动重排机制，不新建"考前模式"。
- **双模式一个引擎**：默认「到期推送」+「自主检索」（按母题/章节/错因/掌握态筛选浏览，冲刺期主场）。提前复习（early review）作为复习事件**喂回同一引擎**重排——禁止冲刺专用第二队列。

### 6.2 复习单元 ①：考点卡（客观知识 / 碎片再认）
- 来源：只投影**已逐字签发**的编译知识（Pack §2.3 一句话压缩——注明"动画旁白可直接用，🟢锚定"——就是天然卡文案）；AI 只选卡+排版，不造句。
- 结构：考点 + 可背关键词颗粒 + **教材原文片段并排内嵌**（不是要点开的链接——让"核对原文"变成默认可见）+ 出处；反复漏答的采分点亮红标（miss_count 派生）。
- 交互：30 秒/张；**个人助记 additive 层**（墨墨式，叠加不碰卡真值与 source_ref）；**报错回流**编译管道；**归档**（呈现态）。**没有"编辑卡文本"**（§8）。

### 6.3 复习单元 ②：实务闯关（主观题 / 主动回忆生成）
五层结构，全部 Pack 投影：**R3 真题情境切片**（触发）→ **examiner_intent 设问** → **R2 不变量+因果层**（判别逻辑，母题的魂）→ **R5 采分点 + R6 答案骨架**（答案键，每条带依据/主体/required_terms）→ **个人 delta**（上次作答 + 漏的采分点）。
复习动作 = **主动回忆采分点 → 半写作答 → 判分内核逐条核对**（不是 flashcard 翻面——再认不迁移到考场默写）。**次日复测 = R4 变量规则的换皮变体**（数字/主体/情境变，判别逻辑不变）——"看穿换皮 = 真懂"。

### 6.4 错因银行（带解药）
判分产出纯投影入库：错因码（`error_events[].error_code`）+ 采分点 + **原题背景切片**（GLM 硬伤：脱离原题背景的错因标签无意义）+ **R8 解药**（错一次得到的不是红叉是处方——Pack 白送的独家层）。同采分点错 ≥2 次自动聚焦。低置信/OCR 不确定的判分**不入库**（复用 PRD 复核机制，防脏错因污染复习，§9-D14）。

## 7. Pack → 双轮投影映射表（含投影门）

## 8. AI 边界：投影不生成（判据 = 一票裁决）

| AI **参与**（安全：只投影已有真值） | AI **禁止**（幻觉源 / authority drift） |
|---|---|
| 从签发知识**选卡 + 排版**成考点卡 | ❌ 现场压缩/概括讲义成卡（压缩=有损=漏条件；source_ref 只证来源不证保真——**伪可溯源**；AI 归纳必须走既有 `textbook_paraphrase_review` governed 忠实门，不 faithful 不进可溯源池） |
| 投影内核已产错因 + R8 解药，组织呈现 | ❌ 二次 LLM 归因（内核已 status 派生+registry 校验完毕，二次归因=第二 authority+全新幻觉源） |
| 按考点聚类、生成复习清单的**排版** | ❌ 判"必背/易错"（由 miss_count/考频客观派生） |
| 动画卡内嵌问答（按同一 Pack 采分点答，走对话能力+前置路由） | ❌ 复习调度（确定性数学，用 AI 是过度设计） |
| — | ❌ **运行时生成变体题面**（这是"生成"最隐蔽的入口）：R4 变体在**编译期**按封闭规则预生成、过 gate、签发入池（与"预存配音非运行时合成"同构）；runtime 只抽取。变体池耗尽→复用旧变体或编译期补产，绝不现编 |
| — | ❌ 编辑 sourced 卡文本：用户点"编辑"⇒ **fork 成 `manual_note`**（`_CARD_TYPES` 已有该类型，source_type=manual、无 source_ref、诚实标"我的笔记"），原 sourced 卡 **immutable**。一刀消掉：sha detach 补丁逻辑、"编辑过还带旧 source_ref"的伪溯源（当前 `update_card` 的真实缺陷，§10-③）、fork-truth drift |

**护城河口径钉死**：正确性护城河长在**内核**（逐字签发 + 采分点编译 + 判分），双轮是它的**变现出口**（把独有资产变成低门槛复习），对外不拿"笔记可溯源"当"答案不会错"的解药——那是两层，会被一次"你卡里引的答案也是错的"击穿。

## 9. 魔鬼细节清单（容易翻车的 15 个小细节，每条给裁决）

- **D1 复习 tab 空态（day 0-2 新用户）**：无到期单元 → 空态必须是深链（"先去点亮第一站 →"跳学习），绝不是空列表。复习模块早期靠「今日」英雄位的微复习 chip 存在感过渡。
- **D2 "次日"的时区定义**：SR 的"天"= 用户本地日历日；凌晨（如 03:00 前）完成的学习归前一"学习日"，防熬夜学员的"明天见"变成 20 小时后弹回。实现时统一在服务端按用户时区折算，客户端不自算。
- **D3 多端并发幂等**：手机+平板同时过卡 → 复习事件带客户端生成的幂等 id，服务端去重；调度只认服务端接收序。
- **D4 离线事件时钟**：本地时间戳不可信 → 事件上报带（本地时间, 服务端接收时间）双戳，调度以服务端为准；离线只回放"上次同步的到期列表"，**客户端绝不本地计算新调度**。
- **D5 离线能力分档**：档位①②（本地确定性判分）+ 考点卡再认 = 预取后**完全离线可用**（工地党白天主场景）；档位③半写离线降级为"保存本地草稿、联网后批改"（复用 PRD §11.2 网络失败态）。预取策略 = 到期单元 + 下一站卡。
- **D6 动画卡分发工程**：样张 11MB/张 × 40 站——小程序 webview 的 CDN/分包/预加载（预载下一站）/弱网降级（静态图文 fallback）是硬工程约束，阶段 1 前必须实测（**这可能是全稿最大的非设计风险**）。
- **D7 教材/考纲更新（新鲜度哨兵）**：编译管道重编译时，source_ref sha 与当前源不匹配的卡/单元 → 自动标"考纲已更新，待重新生成"并**移出可溯源池**直到重派生；**重派生保留用户的助记层**（additive 层与真值层物理分离的红利）。这是"考点还是旧的"1 星差评的结构性免疫，也是 v2 只接了 sha 单方向的补全。
- **D8 Pack 升版对已生成单元**：复习单元落库带 `pack_version`；jury fix / pack 升版后按 D7 同机制重投影，不留旧版孤儿。
- **D9 半写判分延迟的预期管理**：档位③走判分链路（LLM，秒级）→ 交互必须有"鲁班正在按采分点琢磨…"的行内等待态（动画卡已有此模式，沿用），绝不静默转圈；判分失败保留作答可重试。
- **D10 轻练证据的 promotion 纪律**：档位①②产生的证据走既有轻练链路，`claim_promotion` 规则照旧——**轻练不能关闭弱点**（PRD 既有红线），只有客观复测能。防"点选做对了=掌握了"的假绿。
- **D11 免费用户的复习权益**：免费 3 站产生的复习单元**永久可复习**（复习回炉不计费）——否则免费用户的复习 tab 三天后死掉，留存钩自断；变体复测消耗的是编译期预生成池，无边际 LLM 成本，计费域无需新概念。会员到期后已生成单元降级只读可见。归 microlesson billing 域，此处只锁方向。
- **D12 微信订阅消息的一次性授权**：小程序订阅消息需用户逐次授权——"明天见"推送的授权请求埋在**交接时刻**（用户情绪最高点、语义最贴合的一刻），不弹在冷启动。授权失败则次日钩子退化为 App 内红点 + 英雄位文案，不硬弹。
- **D13 复考者首屏（暖色铁律）**：带历史学情的复考者进复习 → 旧掌握态自动衰减为"待复验"，呈现为"这几个再看一眼就稳了"，**绝不渲染一墙红灯**；红/黄/绿只作内部调度语义，对外呈现一律过文案铁律（禁审视揭短词）。
- **D14 脏判分不入银行**：低置信 / OCR 不确定 / 复核中的判分结果不生成错因单元（复用 PRD 复核队列），防脏错因把用户带错复习路径——错归因比不归因更危险。
- **D15 埋点先行**：双轮的度量事件（站完成 / 交接曝光 / 订阅授权率 / 次日回访 / 变体命中率 / 档位分布 / 到期完成率）在阶段 1 spike 就接入既有 TurnEventLog/BI——**客户端埋点数据源不可编造，没有埋点的留存实验=不可证伪**（eval-design 红线）。

## 10. 真实缺陷上报（独立于本稿，按优先级修复；本稿多处依赖 ① 的修复）

1. 🔴 **`mistake_book` 调度/掌握双权威**：`record_review` 硬编码 `review_due_at = now+3d`（`services/learner_state/mistake_book.py:386`）+ `mark_mastered` 手动直写 `mastered_at`（`:368`）——与 `revalidation_queue` 撞车，违反 single authority + PRD M0 reality-lock（按钮直达掌握态）。**修法=收权非加闸**：删 +3d 硬编码，`record_review` 改为写呈现时间戳 + 发非 promoting light-signal 由 queue 重算；`mark_mastered` 降级为呈现隐藏（或删除、复用 `archived_at`）；`bookmark/archived` 呈现态保留合法。同时裁决自由 `tags`/`error_label` 与 registry 的双轨（C3）。live+protected：需登记 domain test。**先修它，双轮的调度地基才成立。**
2. 🔴 **线上 tabBar 聊天打头**（`custom-tab-bar/index.js:17`）：PRD 点名的头号留存反模式，§4 的 5-tab 即修复方案，作为独立迁移工程排期。
3. 🟠 **`NotebookCardService.update_card` 编辑后 `source_ref` 原样保留**：编辑过的卡继续冒充可溯源（无 sha 重算/无 detach）——按 §8 的 fork-to-manual_note 方案修，sourced 卡 immutable。
4. 🟡 **错因分辨率**：内核 12 个 E 码实际只塌缩到 E02/E07 两个（`rubric_grader_v1.py:574-581`）——错因银行照实投影则用户只见两类。是否够用交真人验证，**禁止用 AI 补分辨率**（补的都是编的）。
5. 🟡 **`exam_weight` 硬编码 1.0**（`scoring_point_map_read_model.py:290`）：全局考频无数据源——阶段 2 若建考频须锚真题 source_refs 计数 + 登记 schema。

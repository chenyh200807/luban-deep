③ 生产 token:学员判分零 LLM,Qwen 只在出题时且只对近义项
出题入库
(一次性/离线) 真 DeepSeek 造干扰项 → 确定性门筛 → 只有与正确项相似度≥0.5 的近义干扰才送 Qwen 异源复核。多数干扰明显不同 → 根本不触发 Qwen。
↓ 一道题生成一次,存库
学员作答
(每次/海量) 零 LLM。点一下 → 确定性判分(踩没踩到采分点,查表即得)→ 暖心诊断。一个 token 都不烧。

所以不费 token:① 判分全程不走 LLM(红线:计算类判分绝不走 LLM);② Qwen 只在出题时做质检,且"先便宜后贵"——先用确定性相似度过滤,只有像正确答案的近义干扰才送 Qwen;③ 一道题生成一次、服务上万学员,异源成本被彻底摊薄。生产不是每次都调 Qwen。

# M0 冒烟集标注规范（v1，跑引擎前冻结）

> plan §10 M0 Task 1 / Codex 终审 G8。真值口径不一致 = CER 失真 = 选型作废。

## 转录总则（盲转录）

1. **转录者不得看任何 OCR 输出**——先转录后跑引擎，顺序不可颠倒。
2. 逐字转录纸面内容，**包括学生写错的字**。真值是"纸上写了什么"，不是"应该写什么"。
3. 无法辨认的字写 `■`（占一个字符位）；连续无法辨认按字数写多个 `■`。
4. 划掉重写的内容：只转录最终版本；被整体划掉且未重写的段落跳过，并在 meta 中记 `"has_strikethrough": true`。
5. 箭头插入的内容：按学生意图的阅读顺序插入到目标位置。
6. 换行保留（按纸面物理行）；段落间不加空行。

## 数字 token 口径（关键数字错误率④的分母）

- 数字 token = 连续的阿拉伯数字串（含小数点），如 `120`、`3.5`。
- 中文数字（"一百二十天"）不算数字 token。
- 单位不属于 token：`120天` 的 token 是 `120`。

## 结构单位口径（分点结构保持率②的分母）

- 一个"分点" = 以编号（`1）` `1.` `（一）` `①` 等）起始的段落。
- 无编号的连续行合并为一个段落单位。

## 疑点 TP/FP/FN 口径（③⑤，需确认页原型后启用）

- TP：系统高亮处真值确实与 OCR 不一致。
- FP：高亮处其实一致（伪分歧）。
- FN：未高亮处存在不一致（漏检——③的分子）。

## 双录与仲裁

- **数字密集**与**潦草**切片：双人独立转录；不一致字符由评分负责人仲裁后定稿。
- 其余切片：单录 + 10% 抽检；抽检 CER>2% 则该转录者批次全部复核。

## 文件命名

```
samples/<slice>-<编号>.jpg          # slice ∈ clean|messy|printed_mix|numeric|notebook|dark
samples/<slice>-<编号>.gt.txt       # 真值
samples/<slice>-<编号>.meta.json    # {"slice": "...", "writer": "W03", "source": "誊抄|限时|真实"}
```

## 配比与切片要求（plan §9）

- 总量 200；誊抄 / 限时自由作答 / 真实征集 ≈ 1/3 each（收不满如实记录）。
- ≥25% 脏图（弱光/歪斜/涂改/箭头）。
- 必含切片：含印刷题干整页、纯答案区、横线笔记本、数字密集、涂改箭头。

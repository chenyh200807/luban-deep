设计简报

现状一句话
现有 BI 驾驶舱视觉成立，但数字不可信也看不出不可信——成本缺口 328x（Langfuse $6.49 vs BI $0.02）、行为事实层 0 行、6 个注册表外 KPI 标签，全部对用户不可见。
依据：artifacts/bi_reconciliation_20260612/reconciliation_report.md 人工复核结论 F1–F5。
vNext 的第一设计命题：把「数据可信度」变成第一等 UI 公民——每个数字自带身份证。
升级四主轴
①全局控制层
跨 tab 统一时间范围 / 环比开关 / 维度筛选器，状态写入 URL，所有图表订阅同一控制状态。
②数据可信度即 UI
每个指标携带 provenance（数据源）、新鲜度、measured / estimated 分量、trust_level（A/B/C）徽标，对账差异直接上屏。
③下钻一致性
四级下钻（总览→维度→明细→单条 trace）统一交互范式：面包屑 + 抽屉，所有图表点击行为可预期。
④性能
tab 级懒加载、视口内才初始化图表、增量刷新（只 diff 变化序列），避免全量重渲染。
对标 Grafana：信息密度与全局 time-range picker——一条控制条统治所有面板，密度可调不靠堆卡片。
对标 Lightdash：语义层暴露——指标的口径 / 公式 / 数据源是可点击的一等对象，不是埋在文档里的注释。

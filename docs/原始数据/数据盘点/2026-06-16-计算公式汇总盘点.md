## 一、全 26 条公式(按考点簇)

### A. 主体技术(测量/结构/钢筋)
1. 梁位移:`f = ql⁴/(8EI)`(q 线荷载/l 跨度/E 弹性模量/I 惯性矩)
2. 高程测设(地面点):`b = Hₐ + a − Hв`
3. 高程传递(向低处):`Hв = Hₐ + a − (b−c) − d`
4. 钢筋下料长度:① 直钢筋=构件长度−保护层厚度+弯钩增加长度;② 弯起钢筋=直段长度+斜段长度−弯曲调整值+弯钩增加长度;③ 箍筋=箍筋周长+箍筋调整值(④ 搭接另加搭接长度)

### B. 现场/资源(施工现场布置)
5. 现场施工用水量:`q₁ = K₁·Σ(Q₁N₁/(T₁t))·K₂/(8×3600)`(K₁ 未预计系数 1.05~1.15;K₂ 不均衡 1.5)
6. 生活区用水量:`q₄ = P₂N₄K₅/(24×3600)`(K₅ 2.0~2.5)
7. 消防用水量 q₅:按面积 10/15/20 L/s 选用
8. 总用水量 Q:① (q₁+q₂+q₃)≤q₄ → Q=q₄+(q₁+q₂+q₃)/2;② >q₄ → Q=q₁+q₂+q₃;③ 工地<5ha 且 (q₁+q₂+q₃)<q₄ → Q=q₄;⑤ 总量再加 10% 漏损
9. 临时用水管径:`d = √(4Q/(π·v·1000))`(v 1.5~2 m/s)
23. 施工机械需用量:`N = P/(W×Q×K₁×K₂)`
25. 劳动力投入总工时 = 工程量/(产量/单位时间) = 工程量×工时消耗量/单位工作量
26. 劳动力投入量 = 总工时/(班次/日 × 工时/班次 × 活动持续时间)

### C. 计价/造价(计量计价)
7'. 清单计价工程造价 = (分部分项工程费+措施费+其他项目费)×(1+规费费率)×(1+税率)
8. 综合单价 = 人工费+材料费+施工机具使用费+管理费+利润+风险费
9. 分部分项综合单价计算程序(表):人工费/材料费/机具费小计 → +管理费(×费率)→ +利润 → +风险费
10. 工程项目造价综合单价法(表):分部分项费 Σ(量×综合单价)+措施费+其他+规费+增值税

### D. 资金/进度款(合同造价)
11. 预付款额度:① 百分比法 `工程预付款=中标合同造价×预付款比例`;② 数学法 `备料款额度=合同造价×材料比重/年度施工天数×材料储备天数`
12. 起扣点 = 合同造价 − (预付备料款/主要材料所占比重)
13. 进度款:月度 `=当月有效工作量×合同单价×月度支付比例−保修金−回扣预付款−罚款`;分段 同式按阶段
14. 调值公式法:`P = P₀(a₀ + a₁A/A₀ + a₂B/B₀ + a₃C/C₀ + a₄D/D₀)`(a₀ 固定部分比重,各 a 之和=1)

### E. 索赔(合同索赔)
15. 工期索赔(比例法):`工期索赔值 = 原工期 × 新增工程量/原工程量`
15'. 费用索赔:总费用法(总成本−合同费用)/ 分项法(人工+机械+管理+利润分项)

### F. 成本/挣值(成本管理)
16. 成本核算:制造成本法=中标造价−期间费用−利润−税金;完全成本法=中标造价−利润−税金
17. 目标成本 = 工程造价(扣除税金)×[1−目标利润率]
18. 价值工程:`V = F/C`(功能/成本)
19. 三成本值:`BCWP=已完成工程量×预算成本单价`;`BCWS=计划工程量×预算成本单价`;`ACWP=已完工程量×预算成本单价(实际)`
20. 挣值四指标:`CV=BCWP−ACWP`;`SV=BCWP−BCWS`;`CPI=BCWP/ACWP`;`SPI=BCWP/BCWS`
21. 管理绩效:劳动生产率=承包价格/实耗工日;单方用工=用工数/工程量;劳动效率=计划工/实际工;节约工日=计划工−实际工;材料成本降低率=(承包材料成本−实际)/承包材料成本×100%;成本降低率=(计划−实际)/计划×100%
24. 单位工程量成本比较法:`C = (R + F·X)/(Q·X)`(R 固定费/F 单位时间可变费/Q 单位产量/X 作业时间)

### G. 安全管理(评分)
22. 安全检查评分:分项实得 `A₁ = B×C/100`;遇缺项 `A₂ = D/E×100`

### H. 绿色建筑评价
4'. `Q = (Q₀+Q₁+Q₂+Q₃+Q₄+Q₅+Qₐ)/10`

## 三、结论与用法

- **这是计算型母题"数值判据层"的权威结构化原料**:26 条覆盖 计价/造价/挣值/索赔/资源/技术算量,尤其打中高频的 成本(39)/索赔(36) 案例。
- **是 raw PDF,需编译成"公式 registry"**:每条 → {formula_id, name, expression, variables[], applicable_node[], 数值判据模板}。编译后即可让计算型采分点做"数值比对判分"(替代踩字),正好补真题不给 per-point 分值的缺口。
- **网络计划/流水 不在此表**:计算型母题做"进度网络计划"时,公式弹药要从**佑森《流水施工&网络计划》专用讲义 + C 层深编译(EF=ES+D/TF=LS-ES/前看取大)**取;做"成本/造价/索赔/挣值"母题,本表就是主弹药。
- **温控等规范限值不在此表**:措施型母题的数值(里表温差/降温速率/养护天数)是规范限值,取自教材/GB 标准,非公式。

→ 三类计算/数值弹药分工:**本公式汇总(算术)+ 网络计划讲义(进度计算)+ 规范限值(教材/GB)**,合起来才是计算/数值型母题的完整判据源。

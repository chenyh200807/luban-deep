学习图为什么没有提升推荐效果

问题不在“学习参考模块不值得做”，而在于这次只把静态 prerequisite 作为额外文本塞给模型，却没有建立“证据定位学生当前位置、决定何时回溯、何时停下”的推荐决策内核。

这不能推出“图谱无价值”。 Baseline 已有详细 source pack 和明确 learner evidence，天然能做大部分语义判断；graph 只是冗余信息，没有 recommendation policy。

真正需要的是一个胖的 Next-Best-Learning Skill。 静态图只提供地图，Learning Brain 提供学生位置，推荐 skill 才拥有“下一块学什么”的唯一决策权。

Graph arm 的损失来自“过度回溯”，不是知识召回不足

NP-02 中，学生的错误已经位于“合法绘图”本层，baseline 正确停在 np02；graph 看见 np01→np02 后回溯到 np01。NP-04 则相反，graph 帮助模型识别出前置已经满足，成为唯一 graph win。两例合起来说明：边本身不会告诉模型何时沿边走、何时停止。

六个原因共同压住了效果

前两项是产品架构根因，后三项是实验与契约放大器。它们说明当前 graph injection 不是一个完整学习参考模块。

推荐：保留学习图，但把它降为 Next-Best-Learning Skill 的一种输入

  1. 建立单一推荐 authority。 `NextBestLearningSkill` 只输出 `teach_target / review_prerequisite / probe_unknown`，wrapper 只负责调用与展示。
  2. 把学员位置结构化。 每个相关 topic 只有 `passed / failed / unknown`；unknown 先出一题 probe，failed 才允许推荐，passed 必须跳过。
  3. 采用最近未掌握前置。 默认只查目标的一跳 prerequisite；只有该前置也被证据判 failed 才继续向上，不允许看到图就一路追根。
  4. 图不写学情。 Signed graph 维护静态课程依赖；Learning Brain 维护 learner evidence；recommendation 是可解释、可撤销的临时决策。
  5. 先做 shadow。 用新的 held-out cases 比较现有语义 baseline 与 skill 决策，过 `≥15pp lift、direct/unknown controls 100%、unsupported=0` 后再接 TutorBot。

下一轮最值得回答的问题

  • 结构化 passed/failed/unknown 能否消除 NP-02、NP-18、NP-19 的过度回溯？
  • 推荐一跳前置与等 token 的 source-summary active control 相比，图结构是否仍有独立增益？
  • 哪些 learner evidence 可以进入 canonical position，哪些只能作为一次性诊断信号？
Caveats and assumptions. 本轮 n=20，gold 未在运行前加密密封；Graph arm 比 baseline 多了结构化文字；因此结果只能说明当前 injection 没有改善该挑战集，不能证明学习图的长期教学因果价值。严格 authority drift 为 0；31 条“已掌握/未掌握”措辞只作为敏感性风险，不等于实际写入 LearnerState。

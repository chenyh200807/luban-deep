## 方法与阈值（写死在脚本里，可复跑）

```
SHINGLE_K       = 8    # 字符 n-gram 长度
SENT_MIN_LEN    = 12    # 参与句级匹配的最短归一化句长
SENT_HIT        = 0.60  # 单句判定命中 2025 的 containment 阈值
TH_UNCHANGED    = 0.72  # score >= 此值 → unchanged
TH_MODIFIED     = 0.28  # 此值 <= score < TH_UNCHANGED → likely_modified；更低 → likely_new
MIN_BLOCK_CHARS = 40    # 归一化后短于此值标 too_short
```

1. `pdftotext -layout` 逐页抽 2025 PDF 文本；
2. 归一化：去 markdown 记号 / 去全部空白 / 去标点 / 全角转半角，只留 CJK+数字+字母；
3. `shingle_containment` = 块 8-gram 落在 2025 全文的比例；`sentence_hit_ratio` = 命中句数 / 总句数；`score = max(两者)`；
4. 按上面阈值分三档，并给出 2025 侧候选页码（命中 shingle 的众数页）。

## 噪声与诚实边界

1. **不是官方变动清单**：本 diff 由文本相似度产生，`likely_new` 里必然混有「2025 里有但 pdftotext 抽不干净」的块（表格、公式、图注最典型）。
2. **2026 块本身是 LLM 清洗+增强后的 OCR 产物**（`增强版v3.2`），与 2025 原始版式文本存在改写差异，会系统性压低相似度 → `likely_modified` 一档天然偏多；且部分"新句"其实是编译时加的讲解（已用 `editorial_like` 标注），不是教材新增。
3. **LaTeX 公式句必然判新增**：2026 块把公式写成 `$$...$$`，`pdftotext` 从 2025 PDF 抽出的是排版后的字符，两侧不可能匹配。已用 `formula_like` 从主清单剔除。
4. **章节切分口径不同**：2026 块按 chunk 切、2025 按页抽，块 ↔ 页不是一一对应，`candidate_2025_pages` 只是定位线索。
5. **题量对齐的粒度是 node_code**，不是块级；"某新增点下现有题量"实际是"该新增块所属 node_code 下的现有题量"，不代表该具体知识点已有题。
6. **官方旁证也不是终审**：官方对比明细自身是双栏 PDF，解析有交错噪声；本表 107 个变点里 54 个未能定位到块，不代表这些变点不存在。
7. 本清单**不做出题决策**，不判断某个新增点该出几道题、什么题型。

## 方法

新增薄编排入口 `scripts/refresh_data_inventory.py`，只负责统一时间戳、依赖顺序、失败传播和 lineage，不复制任何统计逻辑。完整顺序为：

1. raw profile、cleaned JSON ledger、PDF ledger；
2. OKF source alignment、candidate scope、pilot、dry consumer、landing gap；
3. compiled ledger、compiled authority map、knowledge-compiler / grading / governance OKF；
4. AI brief、gap map、topic OKF、OKF bundle、compiled profile。

命令：

```bash
python docs/原始数据/数据盘点/scripts/refresh_data_inventory.py
```

脚本任一步非零即停止，并把 `failed_step` 写入 manifest；因此不会用旧的下游结果包装上游失败。

## 本轮发现的真实问题

### P1：阻止签发或单一 runtime authority 的 5 项

1. `exam_content_gap`：139 个 gap unit，包括 taxonomy 缺口 70、案例 analysis 缺口 57、score 缺口 12。
2. `pdf_p1_compile_or_map`：21 份 P1 PDF 仍需编译或 PDF→JSON 映射。
3. `okf_case_level_alignment_backfill`：25 个 case 虽全部对齐，但 16 个仍只有 case-level 对齐，缺 sub-question evidence。
4. `okf_candidate_not_signed_release`：25/117/431 只是 candidate complete，不能直接升 official/runtime。
5. `runtime_policy_conflict_live_reader`：`v_case_rubric_scored` 被 authority map 判为 `runtime_read_allowed=false`，但 `rubric_grader_v1.py` 的 legacy default 仍可指向它。该冲突必须通过“签发该 bank”或“把 reader default 改到已发布 pointer”二选一收权。

### P2：需要治理但不应伪装成已关闭的 4 项

- 383 个 cleaned JSON 的 source claim 尚未逐桶 review。
- 39 个 PDF candidate derivative 缺一对一 provenance 证明。
- 12 个 candidate/blocked runtime pointer 需要逐一签发或归档。
- 4 个 published pointer 仍缺 true-consumer read evidence；其中 1 个 payload manifest conflict、1 个 hash mismatch，不能只凭 `published=true` 宣称 runtime-ready。

### 本轮已关闭的数据完整性误报

原 `考点原料/_S05_jury.json` 不是损坏 JSON，而是完整 jury stdout 被误存为 `.json`。原始内容现保留为 `考点原料/_S05_jury.raw.txt`；机器可读权威仍是 `考点原料/成品/_S05_jury.json`，包含 12 条 finding，且可解析。没有把 stdout 包装成伪 JSON，也没有重跑 LLM 改写历史裁决。

旧 profiler 指向一个从未进入 Git 的 graphify Markdown 目录，因此“知识卡片=0”是路径漂移，不是业务卡片丢失。profile 现直接统计仓库内签发成品 concept-card bank，并显式保留 `legacy_path_exists=false` 作为迁移证据。

## 红线与 false progress

- 只更新 `generated_at`、不重跑 source scan，不算刷新。
- 文件数增加、manifest 数增加、`published=true`、OKF target gap=0，都不能单独证明质量或 runtime closure。
- `artifacts/*`、OKF、profile、ledger、authority map 全是观察/候选层；不得成为第二套 runtime 或 official score authority。
- 本报告已关闭无效 JSON 与知识卡路径误报；没有关闭 runtime live-reader 冲突或 9 个 gap，这些是下一步工作，不是刷新失败。

## 一、核心发现:真题 PDF 解析**全程标采分点级分值**(JSON 丢了,PDF 有)

2025 真题解析实见(`(X分)` 是原文标注):

| 形态 | 实例(2025 真题解析) |
|---|---|
| **小题总分** | 每小题标"(本小题 5.0 分)/(本小题 6.0 分)/(5.5 分)" |
| **采分点级分值** | 案例一·题1:B/C/D/E/F 五个机器人各 **(1.0分)**;案例三·题4:严重/中等/轻微流淌各带分 |
| **计算题逐步骤分** | 案例四·题5:分部分项=2640.00万 **(1.0分)** → 措施费264.00万 **(1.0分)** → 其他96万 **(1.0分)** → 规费60万 **(1.0分)** → 增值税275.40万 **(1.0分)** → 造价3335.40万 **(1.0分)** |
| **网络计划步骤分** | 案例二·题1:`A→B→E→F→H` **(1.0分)** / 19个月 **(1.0分)** / 20个月 **(1.0分)** / 调整方法 **(2.0分)** |

→ **"采分点 + 判据 + 分值"真题里全有**,且含**计算步骤分**(正是进度/计算压测说"缺"的)、**部分给分规则**、**0.5 分粒度**。之前判"基本没有"是因为只看了把分值丢掉的结构化 JSON。

## 三、性质与用法

- **是培训机构(佑森)资深教师解析估分,非官方阅卷分值**(中国一建官方分点口径不公开)。但:采分点级 + 步骤分 + 部分给分规则 + 跨年一致,**作为判分母题的分值源远优于 JSON(空)和规则均分**。
- **用法**:视觉/OCR 抽取 6 份 PDF 的案例解析 → 结构化成 per-point rubric(`小题总分 / 采分点 statement / 每点 score / 部分给分规则 / 计算步骤分`)→ **回填 `per_question_grading_object` 那 482 个 `score:null` 的点**(M4 最大短板由此从"缺料"变"抽取")。
- **官方精确口径仍须真实阅卷**(留存实验喂)——但 bootstrap 判分母题,佑森解析分值已足够好。

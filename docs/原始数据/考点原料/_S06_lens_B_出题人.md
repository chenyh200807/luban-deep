## R2 不变量（一句解释，≥5 场景印证）

**不变量（一句话）：**
> **凡"人或物可能从临边/洞口坠落、或在 2m 及以上高处作业"，都必须先用"硬隔离 + 高度门槛 + 封闭措施"把坠落路径堵死——出题人永远在考"该不该防、用什么防、防到什么参数"，而不是考工艺本身。**

换言之：临边洞口防护的判分核心不是"会不会做"，而是 **"坠落风险是否被识别 + 防护等级是否匹配尺寸/高度 + 关键参数是否达标"** 这条因果链。三者缺一即为不妥。

**≥5 场景印证（每条带锚）：**

1. **卸料平台场景** —— 错把"三侧 1200mm 固定栏杆"当合格，正确是"两侧固定防护栏杆 + 底部 200mm 挡脚板"。
   真题锚 `{2015, 案例3}`；教材锚 `kc:1A436000_121_0195:2`（栏杆=横杆+立杆+挡脚板，上杆 1.2m，挡脚板≥180mm）。

2. **高处作业检查项缺漏场景** —— 检查内容只列"安全帽"等，须补"临边防护、洞口防护、通道口防护、攀登作业、悬空作业、移动式操作平台"。
   真题锚 `{2016, 案例3}`、`{2018, 问题2}`；教材锚 `kc:1A436000_107_0174:1`（高处作业检查评定项目全集）。

3. **钢梁水平通道场景** —— "坠落高度>2m 用梯子攀登""通道不设防护栏杆""钢梁一端设安全绳"全错；正确是 ">2m 设操作平台 + 通道两侧设防护 + 钢梁连续安全绳"。
   真题锚 `{2023, 第1题}`；教材锚 `kc:1A436000_122_0196:0`（≥2m 必设操作平台）、`m35:Q2-1A436000-罚则:P1/P2`。

4. **洞口分尺寸防护场景** —— 不同洞口尺寸对应不同防护（封堵/盖板/栏杆/安全网），尺寸错配即不妥。
   教材锚 `kc:1A436000_121_0195:1`、`kc:1A436000_117_0191:1`、`kc:1A436000_118_0192:3`；真题印证 `{2016, 案例3}`（洞口防护列入检查项）。

5. **悬空/屋面作业场景** —— 2m 以上模板/钢筋/浇筑作业必设操作平台；坡度>25°屋面须设≥1.5m 栏杆 + 密目网全封闭。
   教材锚 `kc:1A436000_122_0196:0`、`kc:1A436000_122_0196:1`；真题印证 `{2018, 问题1}`（临边/悬空/攀登列为高处作业项）。

6. **高处坠落事故场景**（反向印证：不防护→出事故）—— 屋面梁安装两人坠落、一死。
   真题锚 `{2017, 案例三}`、`{2024, 第(五)题}`（高处坠落列为最常发生五类事故之一）；教材锚 `kc:1A436000_129_0207:0`、`kc:1A436000_120_0194:0`（高处作业十大隐患含临边无防护/洞口无防护）。

> 不变量验证：6 个场景全部回到"识别坠落路径 → 匹配防护等级 → 校核关键参数"这条同一逻辑链，不变量成立。

## examiner_intent（出题人意图）

出题人在这个考点上**几乎不考"是什么"，只考"对不对/还差什么/参数够不够"**。意图分三层，按真题命中频次排序：

### 意图① 抓"该防未防 / 防护项不全"（找漏 / 补全）—— 最高频
- 给一份高处作业检查清单或施工方案，故意漏掉临边、洞口、通道口、攀登、悬空、操作平台中的若干项，要考生补全。
- 锚：`{2016, 案例3}`、`{2018, 问题2}`、`{2018, 问题1}`；教材锚 `kc:1A436000_107_0174:1`、`kc:1A436000_120_0194:0`。
- **出题人埋点**：清单看起来"很全"（已含安全帽、安全网、安全带），但缺的恰恰是"临边/洞口/操作平台"这几个高分项。

### 意图② 抓"防护参数错 / 防护方式错"（纠错 + 写正确做法）—— 高分密集区
- 给出一个具体防护做法，参数或方式是错的，要考生指出不妥 **并写出正确做法**（只指错不写正确做法不得分）。
- 典型错点：栏杆侧数（三侧→两侧）、栏杆高度、挡脚板（漏设/高度不足）、">2m 用梯子"（应设操作平台）、安全绳设单端（应连续）。
- 锚：`{2015, 案例3}`、`{2023, 第1题}`；教材锚 `kc:1A436000_121_0195:2`、`kc:1A436000_122_0196:0`、`m35:Q2-1A436000-罚则:P1`、`m35:Q2-1A436000-罚则:P2`、`m35:Q2-1A436000-罚则:P4`。
- **出题人埋点**：参数给得"接近但不对"（如 1200mm 看着像合规高度，但错在"三侧/固定式"而非"两侧+挡脚板"），考生若只背高度不抓侧数/挡脚板就丢分。

### 意图③ 抓"尺寸—措施映射 / 高度门槛"（条件判断）—— 选择题与小问
- 洞口尺寸 → 防护方式；坠落高度 → 是否设防护；作业高度 → 坠落半径/防护棚要求。
- 锚：`{2021, 第8题}`（高处作业吊篮做法）、`{2024, 第30题}`（圈梁/洞口构造）；教材锚 `kc:1A436000_121_0195:1`、`kc:1A436000_124_0198:0`、`kc:1A436000_123_0197:*`。

> **examiner_intent 一句话**：出题人把临边洞口防护当成"安全防护意识 + 参数记忆"的双重过滤器——意识层考"该防的都防了吗"，记忆层考"防到 1.2m/180mm/2m 这些硬数字了吗"。

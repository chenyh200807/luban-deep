# R7 active 构造 — AI 天团锚真考卷 · 六阶精工流程

> 把母题 R7（采分鲁布里克 + 边界答案）从 candidate(🔴) 升到 **active 判分级**，不靠人类专家，靠 AI 天团锚真考卷 ground truth + 异源对抗。
> **大师级原则**：AI 团不发明标准，只把官方标准拆到位、并用"独立多构造 + 确定性闸 + 红队 + 自洽校准 + 异源终审"五道保证逼出最佳结果。
> **一句话**："超越人类专家" = 锚同一官方源 + 跨谱系一致 + 对抗可证伪，**不是**发明新标准。

## authority 定位（不立第二套）

产出 = **candidate governed_gold** → 异源收敛(+可选 operator 签) → 既有 **signed scoring artifact / `CaseGradingSkillKernel`** 采纳为 active。母题 R7 **只引用不拥有**判分 truth；错因归 `ERROR_CODE_REGISTRY`，学情归 `LearnerStateService`。

## ground truth（真考卷实有，已扒证）

案例题 `question_data`：`correct_answer`(官方答案逐字) · `analysis`(官方解析,分步+给分逻辑) · `score`(分值) · `logic_chain`(计算题官方计算规则)。**判分标准都是真的、现成的。**

## 六阶精工流程（每阶一道质量保证）

```
相0 取证锁真 → 相1 三模型独立构造 → 相2 收敛仲裁+确定性闸 → 相3 红队对抗 → 相4 自洽校准 → 相5 异源终审签发
 ground truth   panel独立(防同源盲点)   ≥2收敛+求和闸+锚闸     陷阱答案守边界   满分/0分/压线自检   governed_gold
```

### 相0 · 取证锁真（确定性）
拉本考点真案例题的 `correct_answer/analysis/score/logic_chain`，证据包外禁用。**题型分流**：计算型(有 `logic_chain`,可确定性复算) / 论述型(采分点制)。数据不全(无分值/无解析分步)的题→标 🔴 不进 active 构造。

### 相1 · 三模型独立构造（panel，防同源盲点）⭐
**Opus + DeepSeek-v4-pro + Qwen-max 各自独立**从同一份官方 ground truth 构造鲁布里克（**禁互看**）。每个输出采分点清单：`{采分点, 分值, official_anchor=analysis原文quote}`。
> 为什么独立多构造而非单构造：单模型拆采分点有盲点；三谱系各拆一遍，**收敛处=高可信，分歧处=暴露主观地带**。这是"独立尝试 panel"优于"一次构造再审"。

### 相2 · 收敛仲裁 + 确定性闸 ⭐
- **收敛**：≥2 模型撞同一采分点(点+分值近似) → 🟢 candidate；分歧采分点 → 回官方 `analysis` 仲裁(解析支持则收,否则🔴)。
- **确定性闸(代码,不靠 AI)**：① 采分点分值之和 **== 官方 `score`**(硬约束,不等即败) ② 每个 `official_anchor` quote **真出现在 analysis 里**(防编造采分点) ③ 计算题:**确定性复算 `logic_chain`**,结果 == `correct_answer`(算术真值校验)。

### 相3 · 红队对抗（守边界,anti-over-credit）⭐
专设"考生红队"agent 写**陷阱答案**：(a) **过给分陷阱**(看着对、实则该扣的,如口号化/漏关键数值) (b) **欠给分陷阱**(非常规但正确)。用鲁布里克给这些打分——**若过给/欠给 → 鲁布里克松/紧有缺陷 → 标记迭代**。这道保证鲁布里克**守得住边界**,不是只会构造。

### 相4 · 自洽校准（自检,catch 鲁布里克缺陷）⭐
用鲁布里克跑三个基准:官方 `correct_answer`→**应满分**;空/全错答案→**应 0 分**;合成压线 near-miss→**应得预期部分分**。**任一错位 = 鲁布里克有 bug → 回相1/2 迭代**。

### 相5 · 异源终审 + 签发
异源 jury(Codex/GPT5.5 + 未参与构造的源)对收敛鲁布里克做最后证伪(对照官方 ground truth,非对照构造稿)。
**升 🟢 active 充要条件**:锚官方 + ≥2构造收敛 + 过确定性闸 + 过红队 + 过自洽校准。
- 🟢 active 采分点 → candidate governed_gold → signed artifact 采纳。
- 🔵 near-miss(合成+jury验) → 教学示例 + 判分按🟢鲁布里克。
- 🔴 残留(官方解析未定的主观分档) → 真实作答校准 或 标候选不升。

---

## 三色铁律（R7 版）
- 🟢 **active**:采分点+分值可溯官方 `correct_answer/analysis/score`,且过五道保证。
- 🔵 **teaching**:AI 合成 near-miss,jury 验证合理(判分仍锚 🟢 鲁布里克)。
- 🔴 **待验证**:官方没定的主观边界 → 真实作答校准。**AI 不许编标准冒充 🟢。**

## 为什么这套能逼出最佳结果（五道保证各防一个失败模式）
| 保证 | 防的失败模式 |
|---|---|
| 相1 三模型独立构造 | 单模型采分点盲点 / 同源偏见 |
| 相2 确定性闸(求和/锚/复算) | 编造采分点、分值不平、计算题算错 |
| 相3 红队对抗 | 鲁布里克过松给分(over-credit)、过紧误杀 |
| 相4 自洽校准 | 鲁布里克自身打分 bug |
| 相5 异源终审 | 构造-验证同源循环(终审对照官方非构造稿) |

## 诚实天花板
真实考生作答分布 AI 造不出(只能合成🔵)——但**只影响"压线阈值精校",不影响"采分点鲁布里克"这个 active 核心**。多数客观采分点可达 🟢 active;纯主观、官方解析不全的案例标 🔴 待校准。

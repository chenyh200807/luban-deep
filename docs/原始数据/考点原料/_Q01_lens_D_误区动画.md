# 混凝土养护与裂缝防治

## 误区及解药

### 误区1：混凝土浇筑后立即进行养护
- **现象**：施工人员在混凝土浇筑完成后立即开始浇水养护。
- **错误心智模型**：认为越早开始养护，混凝土的质量越好。
- **对症解药**：混凝土浇筑完成后应等待初凝后再开始养护。根据规范，一般情况下应在混凝土终凝后（通常为浇筑后2-3小时）开始养护。（E05）

### 误区2：养护时间不足
- **现象**：混凝土养护时间少于7天。
- **错误心智模型**：认为养护几天就足够了，不需要太长时间。
- **对症解药**：普通混凝土的养护时间不应少于7天，对于重要结构或特殊环境下的混凝土，养护时间应不少于14天。（E06）

### 误区3：忽视温度控制
- **现象**：在高温或低温环境下浇筑混凝土，未采取相应措施。
- **错误心智模型**：认为只要按时浇水养护即可，无需特别关注温度。
- **对症解药**：在高温环境下，应选择早晚时段施工，并采取喷雾、覆盖等措施降温；在低温环境下，应采取保温措施，防止混凝土受冻。（E07）

### 误区4：养护方法单一
- **现象**：仅采用浇水养护，不考虑其他养护方法。
- **错误心智模型**：认为浇水是最有效的养护方法。
- **对症解药**：根据实际情况选择合适的养护方法，如覆盖塑料薄膜、使用养护剂等。（E08）

### 误区5：忽略混凝土表面处理
- **现象**：混凝土表面未进行必要的处理，导致表面开裂。
- **错误心智模型**：认为只要内部质量好，表面处理不重要。
- **对症解药**：混凝土表面应及时进行抹平、压光等处理，以减少表面裂缝的发生。（E09）

### 误区6：养护期间随意中断
- **现象**：养护过程中因各种原因中断，未能持续进行。
- **错误心智模型**：认为偶尔中断不会影响混凝土质量。
- **对症解药**：养护期间应保持连续性，避免因中断而导致混凝土早期失水，影响强度和耐久性。（E10）

### 误区7：忽视混凝土的保湿
- **现象**：养护过程中只注重浇水，未注意保湿。
- **错误心智模型**：认为只要浇水就能保证混凝土湿润。
- **对症解药**：应采取覆盖、喷雾等措施，确保混凝土表面始终保持湿润状态。（E11）

### 误区8：未考虑混凝土的收缩
- **现象**：未设置适当的伸缩缝或膨胀带。
- **错误心智模型**：认为混凝土不会发生显著的收缩。
- **对症解药**：在大体积混凝土中应设置伸缩缝或膨胀带，以适应混凝土的收缩变形。（E12）

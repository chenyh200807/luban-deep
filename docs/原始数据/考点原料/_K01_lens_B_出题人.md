## R2 不变量（一句话母规则）

🟢 **"一个索赔事件，由两条相互独立的闸门同时裁决：工期索赔只认'延误是否落在关键线路/是否超出总时差'，费用索赔只认'责任归属是否在对方'——延误责任方决定费用归属，关键线路与总时差决定工期顺延，两者各判各的、互不蕴含。"**

即：工期成不成立 ≠ 费用成不成立；同一事件可以"费用成立但工期不成立"，反之亦然。判分锚定这两条闸门的正确启用与互斥，不认"凭责任方一刀切"。

该不变量可解释 ≥5 场景：

1. 🟢【2015案例1·事件三(1)】C 工作设计变更（非承包商原因）：**费用索赔成立**（27.2万合理，自身经济损失可向建设单位索赔）；但 **工期索赔不成立 / 只顺延1个月**（C 为非关键工作，总时差1个月，延误2个月仅影响总工期1个月）——同一事件两闸门分裁，费用成立而工期受总时差封顶。
2. 🟢【2015案例1·事件三(2)】E 工作不可抗力：**工期不成立**（E 总时差4个月，延误3个月未超总时差）；**费用部分成立**（24.5万清理修复费可索赔，8.2万施工设备损失自担）——不可抗力下责任划分进一步切分费用，工期仍由总时差裁。
3. 🟢【2018案例分析(二)·问题4】甲供电缆电线延迟（甲方责任）：**工期索赔不成立**——虽是甲方责任，但该工作有总时差，推迟1个月未超总时差、不影响总工期。证明"责任在对方"不等于"工期就该顺延"。
4. 🟢【2024案例题(二)·问题1(3)】事件①设计变更使关键工作E延长2周→**工期索赔成立**（影响关键线路）；事件②施工机械故障使G延长1周→**工期索赔不成立**（G非关键 + 责任在承包人自身）——关键线路闸门 + 责任闸门双重过滤。
5. 🟢【2021案例题(四)·问6】五个索赔逐条裁决（不成立/成立/成立/成立/不成立）；2018第4题四条逐条裁（成立/成立/不成立/不成立）——出题人把"逐事件分别按两闸门判成立性"做成标准答题骨架。
6. 🟢【2016案例1·事件】甲供材料复检不合格(8万)、剥离检验恢复费(4万) 两笔**费用索赔均成立**——责任在发包人 + 在索赔时限内，费用闸门通过；工期闸门此处未触发。

## examiner_intent 出题人意图 / 常考形态 / 陷阱

### 出题人意图
🟢 本考点是建筑实务"合同与造价"主线的最高频、最高分落点（真题命中 55，2015–2025 连续 11 年每年命中，单题常 5–25 分），出题人验证三件事：
- **能否把工期闸门和费用闸门分开判**：拿到一个事件，先问"延误在不在关键线路 / 超不超总时差"定工期，再问"责任在不在对方"定费用，绝不混为一谈。🟢【2015案例1事件三、2024案例(二)】
- **能否用网络计划/总时差做工期定量裁决**：关键线路上延误几个月即索赔几个月；非关键线路延误超总时差部分才索赔，未超则0。🟢【2015案例1、2018案例(二)问题4、kc:1A432000_048_0068:1】
- **能否把费用拆到"可索赔项"颗粒度**：同一笔费用里，对方责任部分可索赔、自身损失部分自担。🟢【2015案例1事件三(2)：24.5万可索/8.2万自担】

### 常考形态
- 🟢 **工期+费用双判题**：给网络图+事件，问"工期索赔是否成立、费用索赔是否成立"，须分别给结论+理由。【2015案例1·事件三、2024案例(二)·问题1】
- 🟢 **网络图关键线路/总工期计算题**：双代号网络图求关键线路、总工期、某工作总时差/自由时差，再据此判工期索赔。【2018案例(二)、2023第1/2题、2024案例(二)、2025参考答案(二)】
- 🟢 **逐条索赔成立性裁决题**：列 4–5 个索赔事件，逐条判"成立/不成立"并说理由。【2018第4题、2021案例(四)·问6】
- 🟢 **赶工/压缩工序选择题**：滞后后选压缩哪道工序——优先压缩关键线路上"赶工费用低且不影响后续工作"的。【2017案例一、m35:Q17-1A433000:P4】
- 🟢 **造价/索赔费用计算题**：成本加酬金式增量索赔（增加成本→管理费→利润逐层叠加）、措施费汇总、预付款与起扣点。【2021案例(四)问4：300+30+16.5=346.5万；2017案例四措施费809万、预付款1776万】
- 🟢 **不可抗力损失分担题**：永久工程/第三方伤亡归发包人、承包人机具损失自担。【2015案例1事件三(2)、ca:1A432000_047_0067、2018第4题特大暴雨留守费】
- 🔵 **索赔程序/证据/时限题**（28天意向通知书、证据四要素）作为配套考点。【ca:1A432000_048_0068、ca:1A432000_048_0069】

### 高频陷阱（出题人埋雷点）
- 🟢 **"责任在对方=工期就顺延"误判**：甲方责任但延误未超总时差→工期索赔仍不成立。【2018案例(二)问题4、2024案例(二)事件②】
- 🟢 **"非关键工作延误几月就索赔几月"误判**：非关键工作只索赔"超出总时差"的部分，C延误2个月但只顺延1个月（总时差1）。【2015案例1事件三(1)】
- 🟢 **工期成立性与费用成立性互相绑死**：把"工期不成立"推出"费用也不成立"——错，C 工期不成立但费用27.2万成立。【2015案例1事件三(1)】
- 🟢 **不可抗力一刀切**：把承包人施工机具/设备损失也算进可索赔费用（8.2万设备损失应自担，只有24.5万清理修复可索）。【2015案例1事件三(2)】
- 🟢 **赶工压缩选错工序**：去压非关键线路的工序、或压"赶工费高/影响后续"的工序——应选关键线路上费用低且不影响后续者。【2017案例一、m35:Q17-1A433000:P4】
- 🟢 **垫资利息/总包服务费误索赔**：合同无约定的垫资利息不予考虑；为配合发包人自行发包专业工程的脚手架延留属总包服务费、在建安费内，不成立。【2018第4题(3)(4)】
- 🟢 **总时差 vs 自由时差混用**：判工期顺延看总时差，判是否影响后续工作看自由时差，二者数值不同时易错填。【2018案例(二)问题2/4：总时差3、自由时差0/3 标注差异处需谨慎】
- 🔴 **网络图数值噪声**：部分真题解析关键线路/总工期算式与标注结果不自洽（如2021第9月网络图、2025(二)"15→19个月"解析自承"说明存在错误"），变题时网络图数值须人工重算，不可直接采信源 logic_chain。

## R3 场景模板（出题人造题骨架）

🔵 模板基于上述真题形态归纳，槽位值优先取真题/教材锚。

- **T1 双闸门索赔判定**：给 {网络图 + 事件(责任方, 受影响工作, 延误时长)} → 分别判 {工期索赔成立性(理由:关键线路/总时差)} 与 {费用索赔成立性(理由:责任归属)}。🟢锚【2015案例1事件三、2024案例(二)·问题1】
- **T2 网络计划定量求解**：给 {双代号网络图} → 求 {关键线路 / 总工期 / 指定工作的总时差·自由时差}，再据此 T1 判工期。🟢锚【2018案例(二)、2023第1/2题、2024案例(二)】
- **T3 逐条索赔裁决**：给 {4–5 条索赔事件} → 逐条输出 {成立/不成立 + 一句理由}。🟢锚【2018第4题、2021案例(四)·问6】
- **T4 赶工压缩工序选择**：给 {滞后天数 + 各工序赶工费率/可压天数 + 是否在关键线路} → 选 {优先压缩工序} 并说理。🟢锚【2017案例一、m35:Q17-1A433000:P4】
- **T5 索赔费用分层计算**：给 {增加的直接成本 + 管理费率 + 利润率} → 算 {索赔值 = 成本 + 成本×管理费率 + (成本+管理费)×利润率}。🟢锚【2021案例(四)·问4：300+30+16.5=346.5万】
- **T6 不可抗力损失分担**：给 {不可抗力事件 + 各项损失明细} → 划分 {发包人承担 / 承包人自担} 的项与金额。🟢锚【2015案例1事件三(2)、ca:1A432000_047_0067】

## R4 变量规则（封闭集合）

🔵 仅以下封闭枚举可作为变题槽位；超集即越界，不得引入未锚定值。

### V1 事件责任方（封闭）
🟢 发包人/建设单位责任：设计变更【2015案例1事件三(1)、2024事件①】｜甲供材料不合格或未按时进场【2016案例1、2018案例(二)、2025事件①】｜发包人要求剥离检验且合格【2016案例1】｜特大暴雨等不可抗力【2018第4题】
🟢 承包人/施工单位责任：施工机械故障【2024事件②】｜自身施工效率/方案问题【kc:1A432002_036_0047:0】
🟢 不可抗力（双方按规则分担，不归单一方）【ca:1A432000_047_0067、2015案例1事件三(2)】

### V2 延误工作的网络位置（封闭，决定工期闸门）
🟢 关键线路上的工作（延误即顺延同等时长）【2024事件①E、kc:1A432000_048_0068:1】
🟢 非关键工作 + 延误 > 总时差（顺延 = 延误 − 总时差超出部分）【2015案例1·C：延误2、总时差1→顺延1】
🟢 非关键工作 + 延误 ≤ 总时差（工期索赔不成立，顺延0）【2015案例1·E、2018案例(二)问题4、2024事件②G】
（工期顺延值只能由"延误时长 vs 关键线路/总时差"三分支裁出，禁直接等于延误时长）

### V3 工期索赔三分支规则（封闭，铁律）
🟢 ① 延误在关键线路 → 索赔工期 = 延误时长；
🟢 ② 延误在非关键线路且超出总时差 → 索赔工期 = 超出部分；
🟢 ③ 延误后仍为非关键线路（未超总时差）→ 不发生工期索赔。
【kc:1A432000_048_0068:1；🟢佐证 2015案例1、2018案例(二)、2024案例(二)】

### V4 费用可索赔项颗粒度（封闭，按责任拆分）
🟢 对方责任 → 可索赔：停工/窝工损失、清理修复费、剥离检验费、检测试验费、留守照管费【2015案例1·24.5万、2016案例1·8万+4万、2018第4题·460万检验费/暴雨留守费】
🟢 自身损失 → 自担（不可索赔）：承包人施工机具/设备损失、措施项目损失【2015案例1·8.2万设备损失、ca:1A432000_047_0067】
🟢 不予考虑（无约定）：合同未约定的垫资利息【2018第4题(4)】
🟢 已含在其他费用内 → 不另索赔：总包服务费内的配合脚手架费【2018第4题(3)】

### V5 不可抗力损失分担（封闭）
🟢 发包人承担：永久工程及已运至现场材料的损坏修复费、施工场地内第三方人员伤亡及财产损失、不可抗力后留守照管费 【ca:1A432000_047_0067、2015案例1事件三(2)、2018第4题(1)】
🟢 承包人承担：自身施工机具损坏、停工损失、措施项目损失 【ca:1A432000_047_0067】

### V6 赶工压缩工序优选规则（封闭）
🟢 必须在关键线路上 + 赶工费用（成本）低 + 不影响后续工作 → 优先压缩 【m35:Q17-1A433000:P4、2017案例一：先压主体结构(2700元/天可压2天)再压室内装修(3000元/天)】
（"成本低"或"费用低"其一即给分，两项全中满分；非关键线路工序压缩不得分）

### V7 索赔费用分层计算公式（封闭）
🟢 索赔值 = 增加成本 + 增加成本×管理费率 + (增加成本 + 管理费)×利润率 【2021案例(四)·问4：300 + 300×10% + (300+30)×5% = 346.50万】
🟢 工期索赔比例法（教材并列法）：工期索赔值 = 原工期 × 新增工程量 / 原工程量 【kc:1A432000_049_0070:0】
（计算题数值槽位须可由网络图/给定费率自洽推出，禁自由赋值）

### V8 索赔程序/时限/证据（封闭配套）
🟢 索赔意向通知书时限：合同约定期限，未约定为 28 天 【ca:1A432000_048_0068、kc:1A432000_048_0068:0】
🟢 索赔证据四要素：真实性、全面性、法律效力、及时性 【kc:1A432000_048_0069:0】

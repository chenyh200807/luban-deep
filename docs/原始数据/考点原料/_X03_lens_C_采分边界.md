# X03 文明/绿色/环保施工措施｜R5-R7 镜头

## R5 采分点

### 1. 文明施工与场区管理

- 🟢 **封闭、围挡、标准化管理**  
  - `kc:1A437000_143_0229:0`：围挡、大门、标牌标准化；材料码放整齐化；安全设施规范化；生活设施整洁化；职工行为文明化；工作生活秩序化。  
  - `kc:1A437000_141_0225:0`：围挡采用可循环、可拆卸、标准化定型材料，高度不得低于 `1.8m`。  
  - 真题锚：`2016 第18题` 考过施工现场封闭管理、宿舍窗户、食堂卫生许可、办公区/生活区表述辨析。

- 🟢 **施工区、办公区、生活区划分与隔离**  
  - `kc:1A437000_143_0229:1`：施工区域与办公、生活区划分清晰，并采取隔离防护措施；在建工程内严禁住人。  
  - 🔵 工程通识：答案例题时不要只写“文明施工”，要落到“分区、隔离、防护、严禁住人、生活设施整洁”。

### 2. 绿色施工组织与评价

- 🟢 **绿色施工管理资料与组织要求**  
  - `kc:1A437000_139_0222:1`：绿色施工必须具备健全管理体系、齐全策划文件、醒目宣传标志、典型图片/影像资料、合同中包含绿色施工要求。  
  - `kc:1A437000_136_0219:0`：绿色施工方案应包含减少资源浪费和环境污染措施，明确组织管理体系和技术要求，优先选用先进技术和可重复利用设施。

- 🟢 **绿色施工评价顺序**  
  - `kc:1A437000_139_0222:0`：基本规定 → 指标 → 要素 → 批次 → 阶段 → 单位工程。  
  - 🔵 易错点：评价“顺序题”容易漏掉中间层级，可归因 `E06 程序顺序错误`。

### 3. 扬尘、泥浆、建筑垃圾控制

- 🟢 **扬尘控制**  
  - `kc:1A437000_149_0293:0`：自动喷淋 + 雾炮除尘 + 车辆冲洗。  
  - `kc:1A437000_141_0225:1`：主要通道、材料加工区地面硬化；裸露场地和土方覆盖、固化或绿化；易扬尘物料篷盖；出口设冲洗池和沉淀池；定期洒水抑尘。  
  - `kc:1A437000_136_0219:2`：土方堆放加盖或植被覆盖；运输车辆防遗撒；泥浆设专用池储存。

- 🟢 **泥浆与建筑垃圾**  
  - `kc:1A437000_013_0019:1`：工程泥浆必须通过泥浆池或封闭容器收集、存放，未经处理不得随意排放。  
  - `kc:1A437000_013_0019:4`：建筑垃圾分类计量并建立台账，未分类不得运输出场。  
  - `kc:1A437000_013_0019:0`：建筑垃圾堆放不宜高于 `3m`；超过 `3m` 应进行堆体和地基稳定性验算。  
  - `kc:1A437000_149_0291:0`：分类收集 → 分类堆放 → 级配回填 / 就地粉碎 → 再生骨料。

### 4. 噪声、光污染与夜间施工

- 🟢 **噪声控制**  
  - `kc:1A437000_149_0294:0`：选用低噪声设备 → 设置隔声屏/罩 → 封闭木工房 → 优化施工工艺。  
  - 🔵 工程通识：噪声题不能只写“减少噪声”，要写设备、隔声设施、封闭作业空间、工艺优化。

- 🟢 **夜间施工与光污染控制**  
  - `kc:1A437000_139_0222:2`：夜间施工办理许可证并公告居民；照明灯加灯罩、透光集中；电焊作业遮挡防弧光外泄。

### 5. 四节一环保：节材、节水、节能、节地

- 🟢 **节材**  
  - `kc:1A437000_140_0223:0`：商品混凝土、预拌砂浆、高强钢筋、高性能混凝土；非木质新材料替代木质板材；外墙保温板替代混凝土模板。  
  - 真题锚：`2015 第29题` 考过商品混凝土、人造板材模板、总体排版策划、专业加工配送钢筋等绿色施工方法。

- 🟢 **节水**  
  - `kc:1A437000_140_0223:1`：搅拌和养护用水有节水措施；冲洗用水设循环装置；抽水量大于 `50万m³` 时须回灌地下水。  
  - `kc:1A437000_149_0290:0`：雨水收集 → 渗蓄/沉淀处理 → 集中储存 → 冲厕、洗车、洒水降尘。

- 🟢 **节能**  
  - `kc:1A437000_140_0223:2`：优先使用节能设备；临时照明按最低照度设计；空调、风扇合理配置并分时段使用；优先采用太阳能、地热等可再生能源。

- 🟢 **节地**  
  - `kc:1A437000_141_0224:0`：临时设施按最小面积设计；优化深基坑方案减少土方扰动；红线外优先用荒地废地；合理利用原有设施；道路永临结合。

## R6 答案骨架

### 案例题通用满分结构

> 可按“文明施工 + 绿色施工组织 + 环境保护 + 资源节约 + 垃圾资源化”五组作答。

1. 🟢 **文明施工管理**  
   施工现场实行封闭管理；围挡、大门、标牌标准化；材料码放整齐；安全设施规范；生活设施整洁；施工区与办公、生活区划分清晰并隔离防护；在建工程内严禁住人。  
   来源：`kc:1A437000_143_0229:0`、`kc:1A437000_143_0229:1`、`kc:1A437000_141_0225:0`

2. 🟢 **绿色施工组织管理**  
   建立绿色施工管理体系，编制绿色施工方案和策划文件，明确减少资源浪费和环境污染措施；设置宣传标志，留存典型图片/影像资料，并在合同中体现绿色施工要求。  
   来源：`kc:1A437000_139_0222:1`、`kc:1A437000_136_0219:0`

3. 🟢 **扬尘与泥浆控制**  
   主要通道和加工区地面硬化；裸土覆盖、固化或绿化；易扬尘物料篷盖；定期洒水、自动喷淋、雾炮除尘；车辆出口设置冲洗池和沉淀池；泥浆用泥浆池或封闭容器收集存放，未经处理不得排放。  
   来源：`kc:1A437000_141_0225:1`、`kc:1A437000_149_0293:0`、`kc:1A437000_013_0019:1`

4. 🟢 **噪声、夜间施工与光污染控制**  
   选用低噪声设备，设置隔声屏或隔声罩，封闭木工房，优化施工工艺；夜间施工办理许可证并公告居民；照明灯加灯罩、透光集中；电焊作业遮挡，防止弧光外泄。  
   来源：`kc:1A437000_149_0294:0`、`kc:1A437000_139_0222:2`

5. 🟢 **节材、节水、节能、节地措施**  
   推广商品混凝土、预拌砂浆、高强钢筋、高性能混凝土和非木质模板材料；冲洗用水设置循环装置，雨水经收集、处理、储存后用于冲厕、洗车、洒水降尘；优先使用节能设备和可再生能源；临时设施按最小面积设计，道路采用永临结合。  
   来源：`kc:1A437000_140_0223:0`、`kc:1A437000_140_0223:1`、`kc:1A437000_140_0223:2`、`kc:1A437000_141_0224:0`、`kc:1A437000_149_0290:0`

6. 🟢 **建筑垃圾资源化与台账**  
   建筑垃圾分类收集、分类堆放、分类计量并建立台账；未分类不得运输出场；可采用级配回填、就地粉碎、再生骨料等资源化利用措施；堆放不宜高于 `3m`，超过时进行稳定性验算。  
   来源：`kc:1A437000_013_0019:0`、`kc:1A437000_013_0019:4`、`kc:1A437000_149_0291:0`

### 精简背诵骨架

🟢 **一围二分三区，四控五节再回收。**

- 一围：封闭管理、标准化围挡，围挡高度不低于 `1.8m`。  
- 二分：施工区与办公、生活区划分清晰并隔离。  
- 三区：生产区、办公区、生活区布置有序，在建工程内严禁住人。  
- 四控：控尘、控噪、控光、控泥浆/污水。  
- 五节：节材、节水、节能、节地、节约资源管理。  
- 再回收：建筑垃圾分类计量、台账、资源化利用。

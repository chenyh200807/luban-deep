## R6 答案骨架

### 题型一：暗龙骨吊顶工序排序 / 不妥改正

满分骨架：

1. 🟢先写流程：放线 → 画龙骨分档线 → 安装水电管线 → 安装主龙骨 → 安装副龙骨 → 安装罩面板 → 安装压条。  
   锚定：2016第11题。
2. 🟢再写吊杆控制：>1500mm设反支撑，>2500mm设钢结构转换层；遇梁、风管设横担；不得吊挂于设备；灯具、风口设附加龙骨。  
   锚定：kc:1A413030_138_0267:0。
3. 🟢写主、次龙骨控制：主龙骨≤1200mm，悬臂≤300mm，接头错开；次龙骨≤600mm，不得搭接，洞口周边设附加龙骨。  
   锚定：kc:1A413030_139_0268:0、kc:1A413030_139_0268:1。
4. 🟢写纸面石膏板固定：从中间向四周自由固定，长边沿纵向铺设，螺钉150～170mm，钉眼防锈，双层板接缝错开。  
   锚定：kc:1A413030_139_0268:2。
5. 🟢若题干出现“裂缝”，补防裂五点：吊筋≤1200mm，拼缝错缝、不密拼，螺钉牢固，转角加强，嵌缝饱满。  
   锚定：kc:1A434000_078_0124:0。

### 题型二：石材 / 瓷砖地面空鼓原因与预防整改

满分骨架：

1. 🟢先按流程定位：基层处理、放线、试拼或浸砖、铺砂浆、铺贴、养护、勾缝。  
   锚定：kc:1A413030_140_0272:0、kc:1A413030_140_0273:0。
2. 🟢原因从五类写：基层未清净；石材未浸湿晾干或瓷砖未清脱模剂、未浸泡阴干；粘结材料不当；大面积未设伸缩缝；养护不到位。  
   锚定：kc:1A413030_140_0272:1、kc:1A413030_140_0273:1、kc:1A434000_078_0123:0。
3. 🟢预防整改对应写：基层清理；使用水泥基粘结材料；油性防护石材做界面剂+背砂；大面积设伸缩缝；按要求养护；勾缝做到顺直、平整、深浅一致。  
   锚定：kc:1A434000_078_0123:0、kc:1A413030_140_0272:3。
4. 🟢若为浅色石材，补充白水泥，避免灰色水泥影响美观。  
   锚定：kc:1A413030_140_0272:2。
5. 🔵答题组织建议：原因题不要只写“材料不好”，应按“基层-材料预处理-粘结层-构造缝-养护”逐层展开。

### 题型三：竹木地板 / 地毯施工不符合项

满分骨架：

1. 🟢竹木地板先写流程：基层处理 → 安装木搁栅 → 铺毛地板 → 铺设竹、木地板 → 成品保护。  
   锚定：kc:1A413030_141_0274:0。
2. 🟢毛地板整张板要开槽：槽深板厚1/3，方向与搁栅垂直，间距约200mm。  
   锚定：kc:1A413030_141_0274:1。
3. 🟢竹木地板铺设：靠墙第一块板离墙10mm，由内向外，宜顺光、顺主要行走方向。  
   锚定：kc:1A413030_141_0274:2。
4. 🟢地毯先写流程：基层处理 → 放线 → 剪裁 → 钉倒刺板条 → 铺衬垫 → 铺设 → 细部收口。  
   锚定：kc:1A413030_141_0275:0。
5. 🟢地毯细部：裁剪长度大20mm，倒刺板距踢脚8～10mm，衬垫离倒刺板约10mm；先固定长边，用撑子拉伸，再拉另一方向；接长用缝合或烫带粘结。  
   锚定：kc:1A413030_141_0275:1、kc:1A413030_141_0275:2。

### 题型四：门窗安装与节能质量问题

满分骨架：

1. 🟢安装禁令：砌体上安装门窗严禁用射钉固定。  
   锚定：kc:1A422000_043_0069:0。
2. 🟢节能问题按五项排查：门窗类型不符、传热系数超标、气密性差、中空玻璃露点高、可见光透射比不符。  
   锚定：kc:1A434000_080_0129:0。
3. 🟢节能查验题中，门窗属于应查验对象；结构材料不是该题查验对象。  
   锚定：2016第20题。
4. 🟢若题干含基层处理或涂饰，补含水率：溶剂型≤8%，乳液型≤10%，木材基层≤12%；厨卫墙面找平层用耐水腻子。  
   锚定：kc:1A422000_043_0069:1、kc:1A422000_043_0069:2。
5. 🔵答题组织建议：门窗题不要只写“安装牢固、密封严密”，节能题必须落到传热系数、气密性、中空玻璃露点、可见光透射比等可验指标。

## R7 边界：满分 vs 压线 vs 0分 near-miss

> 🔴以下全部为候选判分边界，待真人/专家裁决；不得直接冒充正式评分规则。

| 场景 | 满分候选 | 压线候选 | 0分 / near-miss候选 |
|---|---|---|---|
| 吊顶工序排序 | 🔴能按“水电管线→主龙骨→副龙骨→罩面板→压条”写出关键顺序，并补放线、分档线。 | 🔴能写出主龙骨在副龙骨前、罩面板在龙骨后，但漏放线或压条。 | 🔴把罩面板排在水电管线或龙骨前；把主副龙骨顺序颠倒且无其他有效控制点。 |
| 吊杆与龙骨质量 | 🔴能同时写出>1500mm反支撑、>2500mm转换层、主龙骨≤1200mm、悬臂≤300mm、次龙骨≤600mm、洞口附加龙骨。 | 🔴能写出反支撑、主次龙骨间距中的主要数字，但漏悬臂、转换层或洞口附加。 | 🔴只写“吊杆牢固、龙骨平直”，没有任何规范数字或关键构造措施。 |
| 石膏板顶棚裂缝 | 🔴能从吊筋间距、拼缝错缝、不密拼、螺钉固定、转角加强、嵌缝饱满完整归因并提出整改。 | 🔴能写出错缝、螺钉固定、嵌缝处理三类核心点，但漏转角加强或吊筋间距。 | 🔴只写“重新刮腻子、重新刷漆”，不处理龙骨、板缝、螺钉、嵌缝。 |
| 石材 / 瓷砖空鼓 | 🔴能按基层、预处理、粘结材料、伸缩缝、养护五层写原因和措施。 | 🔴能写基层清理、浸砖或浸湿、养护，但漏油性防护石材界面剂+背砂或伸缩缝。 | 🔴只写“水泥多放一点、敲掉重铺”，没有指出空鼓形成的工艺原因。 |
| 石材美观与材料 | 🔴能写浅色石材用白水泥，勾缝清晰顺直、平整光滑、深浅一致、缝色基本一致。 | 🔴能写白水泥或勾缝质量之一，但不完整。 | 🔴把所有石材都机械写成“普通水泥即可”，或只写“颜色好看”。 |
| 竹木地板 | 🔴能写流程、毛地板开槽1/3、垂直搁栅、约200mm、离墙10mm、由内向外、顺光或顺行走方向。 | 🔴能写离墙10mm、由内向外、顺光顺行走方向，但漏毛地板开槽细节。 | 🔴把竹木地板按瓷砖湿贴流程作答，或完全不写伸缩留缝、搁栅、毛地板。 |
| 地毯铺设 | 🔴能写流程、裁剪大20mm、倒刺板距踢脚8～10mm、衬垫离倒刺板约10mm、撑子拉伸、缝合或烫带粘结。 | 🔴能写倒刺板、衬垫、拉伸，但漏具体尺寸。 | 🔴只写“铺平、压实、胶粘牢固”，不体现倒刺板、衬垫、拉伸或接长方式。 |
| 门窗安装 | 🔴能明确“砌体上安装门窗严禁用射钉固定”，并能说明应采用合规连接固定方式。 | 🔴能写“不得用射钉固定”，但未限定砌体场景。 | 🔴写“射钉固定更牢固”或把射钉作为推荐做法。 |
| 门窗节能 | 🔴能从类型、传热系数、气密性、中空玻璃露点、可见光透射比五项排查。 | 🔴能写传热系数和气密性，但漏露点、可见光透射比。 | 🔴只写“门窗质量差、密封胶不好”，没有节能指标。 |

| 错因码使用 | 🔴流程顺序错候选标E06；规范数字错候选标M08；概念混淆候选标E07；漏采分点候选标E02/E03；用经验替代规范候选标M10。 | 🔴能用已注册码但颗粒度偏粗，需人工复核。 | 🔴自造错因码，或把未注册标签冒充系统错因码。 |

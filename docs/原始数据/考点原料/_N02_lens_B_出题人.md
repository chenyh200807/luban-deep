## R2 不变量（一句解释 + ≥5 场景印证）

> **不变量（出题人的不变意图）**：
> **"工期/费用能不能动、动多少、谁掏钱"这三问，永远先由『工作在不在关键线路 / 延误是否吃光总时差』这个唯一判据拍板——压缩只压关键线路、索赔只认吃光时差、赶工费用只在『费率最低且可压时间足够、不影响后续工作』的关键工作上花。**
> 一句话：**关键线路 + 时差**是这一类题所有计算与判断的总开关，任何"多算/少算/算错"都坍缩到"有没有先认准关键线路与时差"。

不变量在 8 年真题中的稳定印证（**每条都带真题锚**）：

| # | 场景（真题怎么考这条不变量） | 真题锚 `{年份+题号}` |
|---|---|---|
| 1 | 给双代号网络图→**先求关键线路+总工期**，再判后续。关键线路=最长路径，总工期=该路径工序之和（21/180/22/16个月等数值都从这一步派生）。 | `{2017, 案例一}`、`{2018, 案例分析(二)问题1-4}`、`{2023, 第1题}`、`{2024, 案例题（二）}`、`{2025, 参考答案 (二)}` |
| 2 | **工期索赔成立性**完全由"延误是否在关键线路/是否吃光总时差"判定：在关键线路或超时差→成立；未超总时差→不成立。 | `{2015, 第30题}`（C总时差1月、延误2月→只赔1月）、`{2018, 案例分析(二)问题1-4}`（甲供电缆有3月总时差、推迟1月→不成立）、`{2024, 案例题（二）}`（事件①在关键线路→成立；事件②不在→不成立） |
| 3 | **赶工/压缩选序**：进度滞后后压缩，必须优先选"赶工费率最低 + 可压时间足够 + 不影响后续工作"的关键工作。 | `{2017, 案例一}`（先压主体结构2天/2700元，再压室内装修/3000元，确保工期不变） |
| 4 | **工期优化使关键线路缩短**：缩短某关键工作作业时间→总工期相应减少（23月经装饰装修缩4月→22月）。 | `{2018, 案例分析(二)}`、`{2018, 案例分析(二)问题1-4}` |
| 5 | **逻辑关系/资源约束触发网络调整**→关键线路与总工期重算（共用机具要连续施工→改逻辑关系→重算工期与关键线路）。 | `{2020, 案例二问题2}`、`{2020, 问题2}`、`{2022, 案例(二)问题}`、`{2025, 案例背景 (二)}` |
| 6 | **非关键工作有时差→延误在时差内不影响总工期**，只需采取保工期措施而非索赔。 | `{2018, 案例分析(二)问题1-4}`、`{2020, 案例二问题3}`（D总时差3天、滞后2天→不影响） |
| 7 | **成倍节拍流水→步距=最大节拍、专业队数=节拍和÷步距、总工期=(过程数+队数-1)×步距**，本质仍是"先定节奏参数再求总工期"。 | `{2023, 第1题}`、`{2023, 第2题}` |

## examiner_intent（出题人意图）

**核心意图**：考的不是"会不会画网络图"，而是**"会不会用关键线路+时差这唯一判据，把工期能不能动、动多少、谁掏钱算清并说出理由"**。

- **为什么这么出**：建造师执业中最高频的现场争议就是"工期延误谁负责、赶工钱谁出、能不能索赔"。出题人用一张网络图当载体，强制考生**先定关键线路与时差，再下任何结论**——这是项目经理的核心判断力，也是最容易"想当然出错"的地方。
- **判分锚点**（出题人给分/扣分的真实落点，均来自真题答案）：
  - **关键线路写错/漏写一条平行关键线路 → 后续全错**：`{2015, 案例1}` 明示存在两条关键线路（A→B→F→H→I 与 A→D→G→H→I），漏一条即失分。
  - **索赔结论必须配理由**：`{2018, 案例分析(二)问题1-4}`、`{2024, 案例题（二）}` 答案均为"成立/不成立 + 理由（是否在关键线路/是否超总时差）"，**只写结论不写理由不得满分**。
  - **赶工选序必须给"费率低/可压时间/不影响后续"依据**：`{2017, 案例一}` 答案显式要求"压缩成本较低且不影响后续工作"。
  - **优化目标三选**：除工期优化外必须答出**资源优化、费用优化**：`{2018, 案例分析(二)问题1-4}`、教材 `point_id: kc:1A433000_056_0085:2`。
- **出题人最爱的"想当然"诱因**（即陷阱来源，详见 R3）：把"延误天数"直接当"索赔天数"、把"非关键工作延误"也算进总工期、压缩时只看可压时间不看费率、漏算平行关键线路。

## R3 场景（出题人布的典型陷阱 / 易错锚点）

> 每条场景=出题人故意埋的坑，标注"诱因"+"判据"+真题锚。

| 场景ID | 陷阱（出题人怎么诱导犯错） | 正确判据 | 真题锚 `{年份+题号}` |
|---|---|---|---|
| R3-1 **延误天数≠索赔天数** | 给非关键工作一个"延误2月"，诱导考生直接索赔2月。 | 索赔工期 = max(0, 延误 − 总时差)；非关键工作只赔超出总时差的部分。 | `{2015, 第30题}`（C延误2月、总时差1月→只赔1月） |
| R3-2 **甲方责任≠一定索赔成立** | 强调"甲供材料延迟是甲方责任"，诱导判索赔成立。 | 责任在甲方但延误未吃光总时差→**不影响总工期→工期索赔不成立**（费用可另议）。 | `{2018, 案例分析(二)问题1-4}`（甲供电缆有3月总时差、推迟1月→不成立） |
| R3-3 **平行关键线路漏一条** | 网络图存在两条等长路径，只写一条。 | 关键线路=所有总时差最小的工作连成的**全部**最长路径，可能≥2条。 | `{2015, 案例1}`（A→B→F→H→I 与 A→D→G→H→I 两条） |
| R3-4 **压缩只看可压时间、不看费率** | 给两道可压工序，可压时间长的费率高，诱导优先压"能压最多"的。 | 优先压**赶工费率最低**且不影响后续的关键工作；先低费率小步压，再考虑高费率。 | `{2017, 案例一}`（先压主体结构2700元/天，后压室内装修3000元/天） |
| R3-5 **压缩非关键工作=白压** | 诱导压缩有富余时差的非关键工作来"赶工"。 | 只有压缩**关键线路上**的工作才能缩短总工期；压非关键工作总工期不变。 | `{2017, 案例一}`（压缩对象均在关键线路 ①→②→③→④→⑦→⑧→⑨ 上） |
| R3-6 **逻辑关系变了不重算关键线路** | 因共用机具/专利工艺要求"先后依次/连续施工"，诱导沿用原关键线路与工期。 | 逻辑关系一改→**重画网络→重算关键线路与总工期**。 | `{2020, 案例二问题2}`、`{2022, 案例(二)问题}`、`{2025, 参考答案 (二)}`（C与F改为先后依次→工期20月） |
| R3-7 **工期优化后忘了更新总工期** | 缩短某关键工作（装饰装修缩为4月）后仍用旧总工期作答。 | 关键工作缩短→总工期同步下调（23→22月）；并答出其余优化目标=资源/费用优化。 | `{2018, 案例分析(二)}`、`{2018, 案例分析(二)问题1-4}` |
| R3-8 **成倍节拍参数混淆** | 把流水步距当成节拍、专业队数与过程数混淆。 | 步距=最大节拍（或最大公约数）；队数=各节拍和÷步距；总工期=(过程数+队数−1)×步距。 | `{2023, 第1题}`、`{2023, 第2题}`（步距3月、队数5、(2+5−1)×3=18月） |

## R4 变量规则（封闭：变量域 + 取值约束 + 派生关系）

> **封闭性声明**：以下变量域穷举本考点的合法取值，派生关系单向确定，无开放枝；任何一道 N02 计算变体都由这组变量+派生闭式生成，**不引入域外变量**。

### V — 输入变量（题面给定）

| 变量 | 取值域（封闭枚举/范围） | 来源锚 |
|---|---|---|
| `network_type` 网络形式 | { 双代号网络图, 横道流水图, 等步距异节奏流水, 成倍节拍流水 } | `{2021, 案例二背景}`、`{2023, 第1题}`、教材 `kc:1A433000_054_0081:0` |
| `activities[]` 工作集 | 有限工作集，每个工作含 { 紧前关系, 持续时间 } | `{2024, 案例题（二）}` 等 |
| `duration(i)` 各工作持续时间 | 正整数（月/天/周），单位题面给定且全题统一 | `{2017, 案例一}`（天）、`{2018, ...}`（月） |
| `delay_event` 延误事件 | { 工程量增加, 材料复验不合格退场, 机械故障, 甲供材料延迟, 设计变更 } | `{2024, 案例题（二）}`、`{2025, 参考答案 (二)}`、`{2018, 案例分析(二)问题1-4}` |
| `delay_responsibility` 责任方 | { 发包人/甲方, 承包人/乙方, 不可抗力 } | 教材 `kc:1A432000_047_0067:0`、`kc:1A432000_047_0067:1` |
| `crash_param(i)` 赶工参数 | 每工作含 { 可压缩天数上限, 单位赶工费率(元/天) } | `{2017, 案例一}`（表一赶工参数） |
| `target` 目标约束 | { 确保工期不变(滞后后赶工), 缩短至指定工期, 求最低费用 } | `{2017, 案例一}`、教材 `kc:1A433000_057_0086:0` |

### F — 派生变量（由 V 唯一推出，封闭闭式）

| 派生变量 | 闭式/规则（单向确定） | 判据锚 |
|---|---|---|
| `ES/EF/LS/LF` 时间参数 | 前向计算 ES/EF，后向计算 LS/LF（标准双代号法） | 教材 `kc:1A433000_056_0085:1` |
| `TF(i)` 总时差 | `TF(i) = LS(i) − ES(i) = LF(i) − EF(i)` | 教材 `ca:1A433000_056_0085`（总时差最小=关键工作） |
| `FF(i)` 自由时差 | `FF(i) = min(ES(后续)) − EF(i)` | `{2018, 案例分析(二)问题1-4}`（管道安装 FF=0） |
| `critical_path` 关键线路 | 由 `TF(i)=min`（通常=0）的工作连成的**全部**最长路径（可≥1条） | 教材 `kc:1A433000_056_0085:1`、`{2015, 案例1}` |
| `T_total` 总工期 | = 关键线路上各工作持续时间之和（=计算工期） | 教材 `kc:1A433000_056_0085:1`、`{2023, 第1题}` |
| `claim_duration` 索赔工期 | `IF 工作∈关键线路 → = 延误`；`ELSE → = max(0, 延误 − TF)`（吃光时差才赔差值，否则=0） | `{2024, 案例题（二）}`、`{2015, 第30题}`、教材 `kc:1A432000_048_0068:1` |
| `claim_validity` 索赔成立性 | `claim_duration > 0 AND 责任≠承包人 → 成立`；`否则 → 不成立` | `{2018, 案例分析(二)问题1-4}`、教材 `kc:1A432000_047_0067:0` |
| `crash_choice` 赶工选序 | 在关键线路工作中，按 `crash_rate` 升序选取，受 `可压缩天数上限` 与"不影响后续工作"约束，直到补足滞后/达目标工期 | `{2017, 案例一}`、教材 `m35:Q17-1A433000:P4`（成本低/不影响后续工作给分） |
| `crash_cost` 赶工费用 | `= Σ(压缩天数 × crash_rate)`，关键线路被压短后若产生新关键线路则需同步压（费用优化） | `{2017, 案例一}`、教材 `kc:1A433000_057_0086:0`（求最低成本工期） |
| `cost_bearer` 费用承担方 | `发包方要求提前竣工→发包人承担`；`承包人自行提前→承包人承担(须发包人同意)` | 教材 `kc:1A432000_047_0067:1`、`ca:1A432002_036_0047`（赶工属发包人计价风险） |
| `multiplier_flow` 成倍节拍派生 | `步距=GCD(节拍)`；`队数=Σ节拍/步距`；`T=(过程数+队数−1)×步距` | `{2023, 第1题}`、`{2023, 第2题}` |

### 封闭性边界（域外变量显式排除）

- **不引入**资源直方图削峰（资源优化的均衡算法）作为本计算题的判分主轴——它属"资源优化"分支，本考点只在"优化目标三选"层面提及（`kc:1A433000_056_0085:2`），不展开求解。
- **不引入**费用-工期曲线的连续微分求极值——真题只考**离散步进压缩**（按工序逐个压、整数天/月），见 `{2017, 案例一}`，故 `crash_choice/crash_cost` 闭式以离散贪心（费率升序）封闭。
- `delay_event` 与 `crash_param` 的所有取值均落在上表枚举内；超出枚举的事件（如政策变更工期顺延）不属本计算考点，归 N02 之外。

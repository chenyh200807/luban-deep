## 三、原理因果层

### 🔗 核心因果逻辑链

```
【成因】→【渗漏机理】→【措施设计】→【为什么有效】
```

---

### 📐 **路径一：阴阳角 → 应力集中 → 开裂渗漏**

| 阶段 | 内容 | 三色 |
|:---|:---|:---:|
| **成因** | 建筑结构中，平面与立面交会处(墙根/管根/女儿墙根部)形成**90°尖角**；温度变化引起结构热胀冷缩，防水卷材/涂膜在此处需同时承受**两个方向的拉应力** | 🟢 |
| **机理** | 尖角处**应力集中**，防水层在反复温度应力下**折角疲劳开裂**；一旦出现微裂缝，雨水沿裂缝渗透进入结构内部→**毛细作用**导致水分扩散、钢筋锈蚀、室内渗漏 | 🔵 |
| **措施** | 阴阳角**做圆弧(圆角)处理或45°斜角过渡**，消除尖角 → 先铺设**附加层**(夹胎体增强材料加强) → 平面+立面宽度均≥250mm → 再做大面防水 | 🟢 |
| **有效原因** | ①圆弧过渡**分散应力**，消除应力集中点；②附加层形成**双层保险**，即使面层微裂，附加层仍完好；③≥250mm宽度保证应力**传递有足够长度衰减**，根部成为安全区 | 🟢+🔵 |

> 📌 **真题印证(2015案例2)**：原图阴阳角为直角 → 判定**错误**，正确应为**45°角或圆弧型**。

---

### 📐 **路径二：女儿墙顶 → 雨水倒灌 → 收头张口渗漏**

| 阶段 | 内容 | 三色 |
|:---|:---|:---:|
| **成因** | 女儿墙位于屋面最高处，**承受全部迎风面雨水冲击**；若压顶无内排水坡度或坡度不足，雨水会沿压顶表面流向**外墙侧**(向外流)或积存于压顶 | 🔵 |
| **机理** | 雨水积存→从卷材收头处**毛细渗入**→若收头未固定→风荷载产生**吸力(负风压)**→卷材收头张口→雨水**直接灌入防水层背面**→整体防水失效 | 🔵 |
| **措施** | ①压顶做**向内排水坡度≥5%**，下端做**鹰嘴+滴水槽**；②卷材收头用**金属压条钉压固定+密封材料封严**；③檐口800mm范围内必须**满粘** | 🟢 |
| **有效原因** | ①内排坡度使水**快速排向屋面**而非外墙侧→经天沟/水落口有组织排出；②鹰嘴+滴水槽**截断水流**，防止雨水沿底面上爬；③金属压条+密封**机械锁死收头**，抵抗风力吸力；④满粘消除空鼓， **负风压下无剥离空间** | 🟢+🔵 |

> 📌 **真题印证(2015案例2)**：原图压顶檐口下端未做鹰嘴滴水槽、卷材收头未处理(缺压条密封) → 两处均判定**错误**。

---

### 📐 **路径三：管根/水落口 → 异材界面 → 结合缝渗漏**

| 阶段 | 内容 | 三色 |
|:---|:---|:---:|
| **成因** | 管道(PVC/铸铁)与混凝土/砂浆属于**异质材料**，热膨胀系数不同，冷热循环下两者**界面产生相对位移**；管道本身是排水通道，周边**长期处于干湿交替状态** | 🔵 |
| **机理** | 界面反复相对位移→密封材料**疲劳老化/剥离**→形成环形微缝→水沿管壁外侧渗入楼板内部；若管道根部无附加层，一旦密封失效则**直接漏水** | 🔵 |
| **措施** | ①管根/地漏处**必须先做附加层**+涂膜加强；②套管与管道间**防水密封材料嵌填压实**；③防水套管**高出装饰面≥20mm**；④水落口防水层伸入杯内**≥50mm**并**牢固固定** | 🟢 |
| **有效原因** | ①附加层+涂膜形成**柔性过渡区**，吸收异材界面位移；②嵌填密封材料保持**弹性连接**不失粘；③伸出20mm形成**物理挡水坎**，地面水无法越过；④伸入杯内≥50mm创造**足够搭接长度**，水流只进管道不出防水层 | 🟢+🔵 |

---

### 📐 **路径四：室内防水翻起高度 → 溅水渗透 → 隔壁受潮**

| 阶段 | 内容 | 三色 |
|:---|:---|:---:|
| **成因** | 淋浴/盥洗区墙体**长期受水直接喷溅**；若防水层翻起高度不足，水体可通过**瓷砖缝隙→找平层→墙体材料**渗透 | 🔵 |
| **机理** | 水分横向渗透至**未做防水的墙面区域**，造成隔壁房间(卧室/走廊)墙面**返碱、发霉、起皮**；淋浴区喷头高度约1800~1900mm，水压使水滴飞溅可达2000mm以上 | 🔵 |
| **措施** | 淋浴区墙面防水翻起高度**≥2000mm**；盥洗池等用水处**≥1200mm**；其他部位泛水**≥250mm** → 管道根部必须密封 | 🟢(本体数值来自0640) / 🔵(室内补充) |
| **有效原因** | ①≥2000mm **覆盖喷淋口以上**，溅水无法越过防水层上边界；②250mm为**基础防潮高差**，应对一般拖地/溅水；③防水套管高出20mm与翻起高度形成**上下立体防线** | 🟢+🔵 |

> ⚠️ **易错警示**：2015案例2图注泛水高度200mm(不足250mm)，错因码为**E02**(构造尺寸偏差)；室内淋浴1800mm(不足2000mm)，错因码为**E02**。

### 🔁 综合逻辑汇总

```
水往低处流(重力排水)
    但是↘
        风力掀开收头(负风压)
        热应力拉开缝隙(热胀冷缩)
        异材界面产生位移(膨胀系数差异)
        直角尖角应力集中(几何突变)
            ↓
    所有这些破坏力集中在"面层收头+转角色带+穿墙管根"
            ↓
    因此所有节点设计都是:"机械锁定+几何柔化+双层保险+疏堵结合"
```

| 破坏力 | 对策 | 核心构造 |
|:---|:---|:---|
| **负风压** | 机械锁定 | 满粘(800mm)+金属压条钉压密封 |
| **应力集中** | 几何柔化 | 阴阳角圆弧+附加层 |
| **异材位移** | 双层保险 | 管根附加层+嵌填密封+≥20mm挡坎 |
| **雨水倒灌** | 疏导+截断 | 内排坡度≥5%+鹰嘴滴水槽 |
| **溅水爬高** | 竖向加高 | 淋浴翻起≥2000mm |

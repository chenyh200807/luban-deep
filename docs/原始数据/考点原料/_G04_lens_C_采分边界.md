## R6 答案骨架

### 案例题满分答法

1. 先答验槽准备：  
   🟢 验槽前应组织勘察、设计、建设、监理、施工人员到场，并准备地基基础设计文件、岩土勘察报告、轻型动力触探记录、地基处理或深基础施工质量检测报告；基底保护层厚度应 `≤100mm`。  
   来源：`kc:1A413000_086_0159:0`

2. 再答验槽方法：  
   🟢 观察法是主要方法，应核对槽壁、槽底土质与勘察报告是否一致，核查开挖深度是否达到设计要求，并判断土质结构是否被人为破坏。必要时用轻型动力触探检测持力层强度、均匀性及浅埋软弱层、硬层、古井、墓穴、空洞等。  
   来源：`kc:1A413000_086_0159:2`、`kc:1A413030_087_0160:0`

3. 如果题问“哪些情况可不触探”：  
   🟢 承压水头高于基坑底面且触探可能导致冒水涌砂；持力层为砾石或卵石层且厚度 `>1m`；持力层为均匀密实砂层且厚度 `>1m`。  
   来源：`kc:1A413000_086_0159:1`

4. 如果题问“浅层软弱地基处理”：  
   🟢 优先落到换填法：适用于浅层软弱土层，厚度宜为 `0.5~3m`；材料可用素土、灰土、砂石、粉煤灰；灰土配合比宜为 `2:8` 或 `3:7`；分层厚度宜为 `200~300mm`；灰土/粉煤灰压实系数 `≥0.95`；接缝不得设在柱基、墙角及承重窗间墙下，上下层缝距不得小于 `500mm`，接缝处夯压密实。  
   来源：`kc:1A413030_087_0162:0`、`kc:1A413030_088_0163:2`

5. 如果题问“强夯”：  
   🟢 强夯有效加固深度从最初起夯面起算；夯锤质量宜为 `10~60t`，锤底静接地压力宜为 `25~80kPa`，排气孔直径宜为 `300~400mm`；施工后应检验承载力、地基土强度、变形指标及其他设计要求指标。  
   来源：真题锚 `2017 第5题`；教材锚 `kc:1A413030_088_0163:0`、`kc:1A434000_064_0095:2`

6. 如果题问“处理方法适用性”：  
   🟢 按土类、地下水、处理深度和材料限制选择方法：地下水位以上湿陷性黄土可考虑灰土挤密桩；地下水位以下 CFG 可采用泥浆护壁成孔；水泥土搅拌桩避开大孤石、欠固结淤泥、硬塑黏性土、密实砂土及地下水渗流影响区；地下水流动时注浆不得用单液水泥浆。  
   来源：`kc:1A413030_089_0164:0`、`kc:1A413030_088_0163:1`、`kc:1A413030_089_0164:3`、`kc:1A413030_089_0164:5`

7. 最后补检验：  
   🟢 土方回填施工结束后检验标高及压实系数；地基承载力检验每 `300m²` 不少于 `1点`，超过 `3000m²` 时每 `500m²` 不少于 `1点`，每单位工程不少于 `3点`。  
   来源：`kc:1A434000_064_0095:0`、`kc:1A434000_064_0095:1`

### 答题顺序口诀

🔵 先验槽，后处理；先资料人员，后观察触探；先适用范围，后参数控制；先施工限制，后检测验收。  
🔵 数字题优先写单位：`mm`、`m²`、`t`、`kPa`、`d`，防止把规范数字写对但表达失分。

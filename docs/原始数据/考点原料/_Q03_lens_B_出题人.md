## R2 不变量（一句话母规则）

🟢 **"质量缺陷是一个外观现象，但它唯一锚定一个施工/材料/环境成因，并由此唯一决定该不该治、怎么治"——即"现象 → 成因 → 处置"的单向链：判分只认成因正确与处置匹配，不认现象描述本身。**

该不变量可解释 ≥5 场景：

1. 🟢【2023案例一·问题2】给图1-1～1-6 命名（麻面/裂缝/层间错台/露筋/孔洞/蜂窝）——现象命名是入口，但分在"认对现象→对应成因"。
2. 🟢【2016第12题】砌体裂缝形态（纵墙两端斜裂缝/窗口对角/窗间墙水平/竖向）里挑出"主因不是地基不均匀下沉"的那一项（答案D 窗间墙竖向裂缝）——同一现象族里靠成因区分。
3. 🟢【2023案例一·问题4 / 第1题】孔洞治理工艺链（清理→支模→润湿→界面剂→高一强度等级细石混凝土→养护≥7d）——处置必须与缺陷类型匹配且步序完整。
4. 🟢【2025第(三)题·问4】屋面卷材流淌按程度分级（严重/中等/轻微），处置随程度变（拆除重铺／可不治／切割·钉钉子）——同一缺陷，程度决定处置。
5. 🟢【2022第(三)题·问3】拆模过早→梁底"麻面、蜂窝、孔洞、露筋"——成因（强度未达拆模标准）唯一决定缺陷群，反推回成因才得分。
6. 🟢【2024第14页·问3】填充墙裂缝出现部位（柱边/梁底/门窗洞口）+ 防治（14d 后砌顶砖／窗台细石混凝土加配筋／加强网片）——现象部位锚定成因，成因锚定防治。

## examiner_intent 出题人意图 / 常考形态 / 陷阱

### 出题人意图
🟢 本考点是建筑实务"质量管理"主线的高频落点（真题命中 50，2015–2025 连续年份覆盖），出题人要的不是背名词，而是验证三件事：
- **能否在缺陷现象与成因之间建立单向锁定**（看图/看描述 → 说成因）；🟢【2023案例一·问题2/4】
- **能否在同一现象族里用成因做判别**（不是所有裂缝都同源）；🟢【2016第12题】
- **能否把成因翻译成完整、不漏步、不串序的处置工艺**。🟢【2023案例一·问题4】

### 常考形态
- 🟢 **图片/现象命名题**：六大混凝土缺陷连图命名（蜂窝·麻面·孔洞·露筋·裂缝·层间错台）。【2023案例一·问题2、第1题】
- 🟢 **缺陷成因反推题**：拆模过早→列出会出现的缺陷群（麻面/蜂窝/孔洞/露筋）。【2022第(三)题·问3】
- 🟢 **同源排除题（单选）**：裂缝形态四选一，挑出"主因不是地基不均匀下沉"的。【2016第12题】
- 🟢 **治理工艺补全题**：孔洞修补六步链补缺步。【2023案例一·问题4 / 第1题】
- 🟢 **分级处置题**：卷材流淌三级 → 各级处置。【2025第(三)题·问4】
- 🟢 **防治措施清单题**：填充墙交接处裂缝部位+防治。【2024第14页·问3】
- 🔵 **机理选择题（语感型）**：温度变化→开裂→分缝；水泥收缩→裂→抗裂；引气剂→改善耐久。【2022第2/3/9题为🟢佐证】

### 高频陷阱（出题人埋雷点）
- 🟢 **同现象不同源**：把"窗间墙竖向裂缝"误判为地基不均匀下沉裂缝——它不是。【2016第12题·答案D】
- 🟢 **治理工艺漏步/串序**：孔洞修补漏"界面剂"或"养护≥7d"，或用同强度而非"高一强度等级"细石混凝土。【2023案例一·问题4】
- 🟢 **分级不全 → 处置错配**：流淌只答两级、或对"中等流淌"用"拆除重铺"（那是严重流淌的处置）。【2025第(三)题·问4】
- 🟢 **养护时长记错**：孔洞修补养护"≥7d"、大体积/防水另有 14d 体系，易混。【2023案例一养护7d；🟢2017案例一防水养护应≥14d】
- 🟢 **防水砂浆"一遍成活"陷阱**：应分遍成活、接槎错开≥100mm、距转角200mm 内不留槎、养护≥7d。【2022第16题·答案B】
- 🔴 **现象命名靠"表面粗糙"区分麻面/蜂窝**：解析以"表面粗糙无光泽=麻面 / 内部空隙集中=蜂窝"判别，但 2023第1题 logic_chain 出现"rough_surface→honeycomb"的标注，疑似源数据噪声，命名判别口径待人工复核。

## R3 场景模板（出题人造题骨架）

🔵 模板基于上述真题形态归纳，槽位值优先取真题/教材锚。

- **T1 现象命名**：给出 {缺陷外观特征} → 要求命名为 {蜂窝/麻面/孔洞/露筋/裂缝/层间错台} 之一。🟢锚【2023案例一·问题2】
- **T2 成因反推**：给出 {施工失误：如混凝土强度未达拆模标准即拆模} → 列出会产生的 {缺陷群}。🟢锚【2022第(三)题·问3】
- **T3 同源排除**：给出 {同一现象族多条描述} → 挑出 {成因不属于某一统一成因} 的一条。🟢锚【2016第12题】
- **T4 治理工艺补全**：给出 {缺陷类型 + 残缺工艺链} → 补全 {缺步}，并守 {步序/养护时长/材料等级}。🟢锚【2023案例一·问题4】
- **T5 分级处置**：给出 {缺陷 + 程度等级} → 给出 {该等级对应处置}。🟢锚【2025第(三)题·问4】
- **T6 部位+防治清单**：给出 {裂缝/缺陷出现部位} → 列出 {防治措施清单}。🟢锚【2024第14页·问3】

## R4 变量规则（封闭集合）

🔵 仅以下封闭枚举可作为变题槽位；超集即越界，不得引入未锚定值。

### V1 缺陷类型（封闭）
🟢 蜂窝 | 麻面 | 孔洞 | 露筋 | 裂缝 | 层间错台 【2023案例一·问题2】
🟢 空鼓 | 脱层 | 爆灰 | 表面不平整 | 接槎/抹纹明显（抹灰类）【2024第14页】
🟢 渗漏 | 流淌（卷材类）【2025第(三)题；🟢2022第16题防水砂浆】

### V2 成因域（封闭）
🟢 施工类：拆模过早(强度未达标)【2022(三)】｜振捣不足/漏振｜浇筑串序错(主次梁/单向板方向)【2025第(三)题·问2】｜接槎留设违规【2022第16题】
🟢 材料类：骨料含泥量大、水泥/掺合料超量【2021案例三·问2】
🟢 环境/变形类：地基不均匀下沉【2016第12题】｜温度变化(热胀冷缩)【2022第2题】｜水泥收缩【2022第3题】
🟢 设计/构造类：填充墙交接处构造不足【2024第14页·问3】

### V3 程度分级（封闭，仅流淌类启用）
🟢 严重流淌 | 中等流淌 | 轻微流淌 【2025第(三)题·问4】

### V4 处置/工艺槽位（封闭，按缺陷类型绑定）
🟢 孔洞修补链（固定六步，步序不可换）：清理表面→支设模板→洒水湿润→涂混凝土界面剂→高一强度等级细石混凝土浇筑密实→保温保湿养护≥7d 【2023案例一·问题4 / 第1题】
🟢 流淌处置（按 V3 绑定）：严重→拆除重铺；轻微且无渗漏→可不治；中等→切割法/局部切除重铺/钉钉子法 【2025第(三)题·问4】
🟢 填充墙裂缝防治：下口最后3皮砖在下部墙砌完14d后砌筑｜窗台改细石混凝土加配筋｜柱与填充墙接触面设加强网片｜柱边2φ6@500 【2024第14页·问3；🟢2019第1题14d/锚固1000mm】
🟢 防水砂浆接槎：分遍成活｜上下层接槎错开≥100mm｜距转角200mm内不留槎｜养护≥7d 【2022第16题】

### V5 养护时长（封闭，易混故单列）
🟢 孔洞/缺陷修补养护 ≥7d 【2023案例一】
🟢 防水砂浆养护 ≥7d 【2022第16题】
🟢 大体积/冬期/防水层混凝土养护 ≥14d 【🟢2017案例一、2019第1题】

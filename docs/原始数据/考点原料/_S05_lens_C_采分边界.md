## R6 答案骨架

### 题型1：问“临时用电三大系统 / 安全技术要求”

满分骨架：

1. 🟢 施工现场临时用电必须采用三级配电系统、TN-S接零保护系统、二级剩余电流动作保护系统。  
   锚定：source=`kc:1A431011_015_0016:0`

2. 🟢 三级配电系统包括总配电箱、分配电箱、开关箱。  
   锚定：source=`kc:1A431011_014_0015:1`

3. 🟢 每台用电设备应设置各自专用开关箱，不得一箱控制2台及以上设备或插座。  
   锚定：source=`kc:1A431011_014_0015:2`

4. 🟢 动力与照明宜分别设置；合并时应分路配电，动力开关箱与照明开关箱必须分设。  
   锚定：source=`kc:1A431011_014_0015:3`

### 题型2：问“送电 / 停电顺序”

满分骨架：

1. 🟢 送电顺序为：总配电箱 → 分配电箱 → 开关箱。  
   锚定：source=`kc:1A431011_015_0016:1`

2. 🟢 停电顺序为：开关箱 → 分配电箱 → 总配电箱。  
   锚定：source=`kc:1A431011_015_0016:1`；真题锚=`2017 案例五`、`2017 问题1-5`

3. 🔵 表达时优先写成“先末端、后上级”，但最终答案必须落到三个箱体的完整顺序，不能只写“先切断电源”。

### 题型3：问“指出临时用电布置不妥”

满分骨架：

1. 🟢 检查是否符合三级配电：总配电箱、分配电箱、开关箱三级是否完整。  
   锚定：source=`kc:1A431011_014_0015:1`

2. 🟢 检查是否一机一闸一箱：每台设备是否有专用开关箱，是否存在一个开关箱控制多台设备。  
   锚定：source=`kc:1A431011_014_0015:2`

3. 🟢 检查配电箱与开关箱距离：开关箱和配电箱间距不得大于30m。  
   锚定：真题锚=`2017 问题1-5`

4. 🟢 检查开关箱安装位置：开关箱安装在电线杆上属于不妥。  
   锚定：真题锚=`2017 问题1-5`

5. 🟢 检查可燃物、电锯、照明热源：木模板堆场与电锯至少10m；仓库或堆料场严禁使用碘钨灯。  
   锚定：真题锚=`2017 问题1-5`

6. 🟢 如题干出现停电顺序，写：开关箱 → 分配电箱 → 总配电箱。  
   锚定：source=`kc:1A431011_015_0016:1`；真题锚=`2017 问题1-5`

### 题型4：问“特殊场所照明电压”

满分骨架：

1. 🟢 潮湿、隧道、人防环境：≤36V。  
   锚定：source=`kc:1A431011_015_0016:2`

2. 🟢 易触及带电体环境：≤24V。  
   锚定：source=`kc:1A431011_015_0016:2`

3. 🟢 金属容器、锅炉内：≤12V。  
   锚定：source=`kc:1A431011_015_0016:2`；真题锚=`2016 第13题`

4. 🟢 特殊环境下未使用安全电压照明，属重大事故隐患。  
   锚定：source=`kc:1A436000_007_0010:0`

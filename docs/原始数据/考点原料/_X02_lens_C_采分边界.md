# X02｜临设、道路、材料堆场布置｜R5-R7 镜头

## R5 采分点

### 1. 总平面与临设规划先行

- 🟢 施工准备/办证类答案中，应写出“施工现场总平面布置图、临时设施规划方案和已搭建情况”。  
  锚：2015 案例4。
- 🟢 工具式定型化临时设施可包括标准化箱式房、定型化临边洞口防护、加工棚、构件化 PVC 绿色围墙、预制装配式马道、可重复使用临时道路板。  
  source：`kc:1A437000_150_0295:0`
- 🔵 临设布置答题不要只写“合理布置”，要落到平面、道路、消防、仓库、材料堆场、验收标识这些可采分对象。

### 2. 临时仓库与危险品仓库位置

- 🟢 临时仓库应接近使用地点。  
  source：`kc:1A431011_012_0013:0`
- 🟢 危险品仓库需远离现场，距在建工程不小于 15m。  
  source：`kc:1A431011_012_0013:0`
- 🟢 易燃材料仓库应设在下风向、水源充足处。  
  source：`kc:1A437000_146_0235:0`
- 🟢 真题已考“易燃材料仓库应设在上风方向”为错误表述，应改为下风向。  
  锚：2015 第30题。
- 🟢 易燃材料仓库与明火区间距不小于 30m；危险品间距不小于 10m；与易燃易爆品间距不小于 30m。  
  source：`kc:1A437000_146_0235:0`

### 3. 临时道路与消防通道尺寸

- 🟢 主干道单行道宽度不小于 4m，双行道不小于 6m。  
  source：`kc:1A431011_012_0013:1`
- 🟢 消防车道宽度不小于 4m。  
  source：`kc:1A431011_012_0013:1`
- 🟢 木材场通道宽度不小于 6m。  
  source：`kc:1A431011_012_0013:1`
- 🟢 回车场尺寸 12m × 12m；载重车转弯半径不小于 15m。  
  source：`kc:1A431011_012_0013:1`
- 🟢 易燃材料露天仓库消防通道宽度不小于 6m。  
  source：`kc:1A437000_146_0235:0`

### 4. 材料堆场基本条件

- 🟢 钢构件现场堆场应具备：场地平整、坚实，无水坑、冰层；地面干燥，有较好的排水设施；车辆进出方便，方便起吊构件。  
  锚：2015 案例2。
- 🟢 料具码放高度不得超过 1.5m，库外材料应下垫上盖。  
  source：`kc:1A438000_150_0241:1`
- 🟢 材料进场必须进行凭证、数量、规格、外观验收，挂牌标识，建立收料台账。  
  source：`kc:1A438000_150_0241:0`
- 🟢 不合格材料退场流程：申请 → 审批 → 通知 → 见证退场 → 记录确认 → 报告提交。  
  source：`kc:1A438000_150_0241:2`

### 5. 仓库、堆料场消防安全

- 🟢 易引起火灾的仓库应按每 500m² 设置防火墙。  
  source：`kc:1A437000_147_0236:0`
- 🟢 可燃材料库房单间面积不大于 30m²；易燃易爆品库房单间面积不大于 20m²。  
  source：`kc:1A437000_147_0236:0`
- 🟢 房门净宽不小于 0.8m；任一点到疏散门距离不大于 10m。  
  source：`kc:1A437000_147_0236:0`
- 🟢 架空电力线与易燃堆垛最小水平距离不小于电杆高度的 1.5 倍。  
  source：`kc:1A437000_147_0236:1`
- 🟢 照明灯具与堆垛距离不小于 1m；开关箱、接线盒距堆垛不小于 1.5m；严禁使用碘钨灯。  
  source：`kc:1A437000_147_0236:1`
- 🟢 临时搭设建筑每 100㎡ 配 2 只 10L 灭火器；木料间、油漆间等每 25㎡ 配 1 只灭火器；大型临时设施超过 1200㎡ 需设太平桶、积水池、黄砂池。  
  source：`kc:1A437000_146_0233:0`

## R6 答案骨架

### 问法一：指出施工现场临设、道路、材料堆场布置应满足哪些要求

满分骨架：

1. 🟢 先有施工现场总平面布置图和临时设施规划方案，临设宜采用工具式、定型化设施。  
   锚：2015 案例4；source：`kc:1A437000_150_0295:0`
2. 🟢 临时仓库接近使用地点；危险品仓库远离现场，距在建工程不小于 15m。  
   source：`kc:1A431011_012_0013:0`
3. 🟢 易燃材料仓库设在下风向、水源充足处，与明火区保持不小于 30m 间距。  
   source：`kc:1A437000_146_0235:0`；锚：2015 第30题。
4. 🟢 临时道路满足宽度和转弯要求：单行主干道不小于 4m，双行主干道不小于 6m，消防车道不小于 4m，木材场通道不小于 6m，回车场 12m × 12m，载重车转弯半径不小于 15m。  
   source：`kc:1A431011_012_0013:1`
5. 🟢 材料堆场应平整、坚实、干燥、排水良好，车辆进出方便，并方便起吊构件。  
   锚：2015 案例2。
6. 🟢 料具码放高度不超过 1.5m，库外材料下垫上盖；材料进场做凭证、数量、规格、外观验收，挂牌标识并建立收料台账。  
   source：`kc:1A438000_150_0241:0`；`kc:1A438000_150_0241:1`
7. 🟢 仓库和堆料场满足消防分区、疏散、防火间距和电气防火要求。  
   source：`kc:1A437000_147_0236:0`；`kc:1A437000_147_0236:1`

### 问法二：案例中“材料堆放/仓库布置不妥”，要求写正确做法

满分骨架：

1. 🟢 若仓库远离使用地点，应改为接近使用地点；若危险品仓库靠近在建工程，应改为距在建工程不小于 15m。  
   source：`kc:1A431011_012_0013:0`
2. 🟢 若易燃材料仓库设在上风向，应改为下风向、水源充足处。  
   source：`kc:1A437000_146_0235:0`；锚：2015 第30题。
3. 🟢 若消防通道不足，应按易燃材料露天仓库消防通道不小于 6m，消防车道不小于 4m 纠正。  
   source：`kc:1A437000_146_0235:0`；`kc:1A431011_012_0013:1`
4. 🟢 若材料直接露天堆放，应补“下垫上盖”；若码放过高，应控制在不超过 1.5m。  
   source：`kc:1A438000_150_0241:1`
5. 🟢 若钢构件堆场积水、软弱、车辆不便，应改为平整坚实、无水坑冰层、地面干燥、排水良好、车辆进出方便、方便起吊。  
   锚：2015 案例2。
6. 🟢 若材料未验收或标识不清，应补凭证、数量、规格、外观验收，挂牌标识，建立收料台账；不合格材料按流程退场。  
   source：`kc:1A438000_150_0241:0`；`kc:1A438000_150_0241:2`
7. 🟢 若电气设备靠近易燃堆垛，应按架空电力线水平距离不小于电杆高度 1.5 倍、灯具距堆垛不小于 1m、开关箱/接线盒距堆垛不小于 1.5m、严禁碘钨灯纠正。  
   source：`kc:1A437000_147_0236:1`

## R7 边界候选

> 以下为候选评分边界，全部标为 🔴 待真人/专家裁决。

### 满分边界候选

- 🔴 待真人/专家裁决：能按“总平面/临设规划 → 仓库位置 → 道路尺寸 → 堆场条件 → 材料验收标识 → 消防电气要求”成组作答，并写出关键数字，判满分候选。
- 🔴 待真人/专家裁决：案例问“堆场基本条件”时，答到平整坚实、无水坑冰层、干燥排水、车辆进出方便、方便起吊，判满分候选。  
  关联锚：2015 案例2。
- 🔴 待真人/专家裁决：案例问“易燃材料仓库方向”时，能明确把“上风向”纠为“下风向”，并补水源充足/防火间距，判满分候选。  
  关联锚：2015 第30题。

### 压线边界候选

- 🔴 待真人/专家裁决：只写“仓库靠近使用地点、危险品远离现场”，但漏 15m、下风向、道路尺寸、消防电气要求，判压线候选。  
  常见错因码：E02 采分点遗漏，E03 关键词缺失。
- 🔴 待真人/专家裁决：只写“道路要满足消防要求”，但未写 4m、6m、12m × 12m、15m 等数字，判压线或扣分候选。  
  常见错因码：M08 规范数字混淆，E03 关键词缺失。
- 🔴 待真人/专家裁决：材料堆场只写“分类堆放、整齐堆放”，但未写平整坚实、排水、车辆进出、起吊便利，判压线候选。  
  常见错因码：E02 采分点遗漏，M10 用常识替代规范判断。
- 🔴 待真人/专家裁决：材料验收只写“验收合格后使用”，但漏凭证、数量、规格、外观、挂牌标识、收料台账，判压线候选。  
  常见错因码：E02 采分点遗漏。

### 0 分 near-miss 候选

- 🔴 待真人/专家裁决：把易燃材料仓库写成“设在上风向”，若题目核心正考该方向，判 0 分候选。  
  常见错因码：E10 规范适用错误，M10 用常识替代规范判断。
- 🔴 待真人/专家裁决：把消防车道、木材场通道、易燃材料露天仓库消防通道的宽度混写，且核心数字全错，判 0 分候选。  
  常见错因码：M08 规范数字混淆。
- 🔴 待真人/专家裁决：只答“按规范布置、加强管理、注意安全”，没有任何可识别采分点，判 0 分候选。  
  常见错因码：E04 口号化表达，E03 关键词缺失。
- 🔴 待真人/专家裁决：将材料堆场条件答成材料复验项目，完全偏离“临设、道路、材料堆场布置”，判 0 分候选。  
  常见错因码：E05 审题错误，E07 概念混淆。
- 🔴 待真人/专家裁决：将“不合格材料退场流程”写成“直接使用或降级使用”，若题目核心问材料管理处置，判 0 分候选。  
  常见错因码：E06 程序顺序错误，E10 规范适用错误。

# C01｜施工缝留置与处理｜R5-R7 镜头

## R5｜采分点：按“留不留、留哪里、怎么处理、后浇带怎么答”分组

### 1. 留设前提与总原则

- 🟢 **应连续浇筑，必须间歇时尽量缩短；若不能在前层混凝土初凝前浇筑完次层，应留置施工缝。**  
  source=`cc:1A413030_103_0196:2` / `cc:1A413030_103_0196:3`

- 🟢 **防水混凝土应连续浇筑，宜少留施工缝。**  
  真题锚=`2015 第26题`

- 🟢 **施工缝关键词：受剪力较小、设计单位确认。**  
  source=`ca:1A413030_103_0196`

### 2. 留设位置

- 🟢 **水平施工缝：柱、墙距结构上表面 0~100mm 或 0~300mm。**  
  source=`kc:1A413030_103_0196:0`

- 🟢 **竖向施工缝：次梁跨度 1/3 范围内。**  
  source=`kc:1A413030_103_0196:0`

- 🟢 **楼梯梯段施工缝：端部 1/3 范围内。**  
  source=`kc:1A413030_103_0196:0`

- 🟢 **墙施工缝：洞口连梁跨中 1/3 或墙交界处。**  
  source=`kc:1A413030_103_0196:0`

- 🟢 **防水混凝土施工缝不应留在剪力最大处或底板与侧墙交接处。**  
  真题锚=`2015 第26题`

### 3. 施工缝处理

- 🟢 **继续浇筑前应满足 1.2N/mm²、凿毛处理、铺 30mm 砂浆等关键词。**  
  source=`ca:1A413030_103_0196`

- 🟢 **施工缝未清理干净，会导致混凝土粘结不良并产生渗漏；未按规范处理会出现接槎明显。**  
  source=`kc:1A434000_074_0116:0`

- 🔵 **答题表达宜按“强度达到要求 → 清理/凿毛 → 接浆/砂浆 → 浇筑振捣 → 养护”写成连续工序，避免只写一句‘处理好施工缝’。**

### 4. 后浇带相关采分点

- 🟢 **后浇带混凝土宜采用微膨胀混凝土，强度等级比原结构提高一级，养护不少于 14d，接缝按施工缝处理。**  
  source=`kc:1A413030_103_0196:1`

- 🟢 **后浇带施工技术措施可答：整理钢筋、冲洗松动部分、填充后浇带采用微膨胀混凝土、强度等级提高一级、至少 14d 湿润养护。**  
  真题锚=`2018 案例分析(三)问题3`

- 🟢 **基础后浇带模板材料相关：后浇带可用快易收口网，浇筑前拆除并凿毛。**  
  source=`kc:1A413030_094_0176:0`

## R6｜答案骨架：满分要点模板

### 题型 A：问“施工缝应如何留设”

🟢 **标准骨架：**

1. **先总原则**：混凝土宜连续浇筑；必须间歇时应尽量缩短，并在前层初凝前完成次层浇筑；否则留置施工缝。  
   source=`cc:1A413030_103_0196:2` / `cc:1A413030_103_0196:3`

2. **再写位置原则**：施工缝宜留在受剪力较小、便于施工的位置；必要时经设计单位确认。  
   source=`ca:1A413030_103_0196`

3. **最后按构件列位置**：  
   - 柱、墙水平施工缝：距结构上表面 0~100mm 或 0~300mm；  
   - 次梁竖向施工缝：跨度 1/3 范围内；  
   - 楼梯梯段：端部 1/3 范围内；  
   - 墙：洞口连梁跨中 1/3 或墙交界处。  
   source=`kc:1A413030_103_0196:0`

### 题型 B：问“施工缝如何处理后再浇筑”

🟢 **标准骨架：**

1. 已浇混凝土强度达到 **1.2N/mm²**；  
2. 对施工缝表面进行 **凿毛处理**；  
3. 清理松动石子、浮浆等，避免粘结不良；  
4. 铺设 **30mm 砂浆** 后再浇筑；  
5. 后续注意振捣密实和养护。  

source=`ca:1A413030_103_0196` / `kc:1A434000_074_0116:0`

### 题型 C：问“后浇带施工技术措施”

🟢 **标准骨架：**

1. 整理钢筋；  
2. 冲洗松动部分；  
3. 填充后浇带可采用微膨胀混凝土；  
4. 混凝土强度等级比原结构提高一级；  
5. 保持至少 14d 湿润养护；  
6. 接缝按施工缝处理。  

source=`kc:1A413030_103_0196:1`  
真题锚=`2018 案例分析(三)问题3`

### 题型 D：防水混凝土中的施工缝判断

🟢 **标准骨架：**

1. 防水混凝土应连续浇筑，宜少留施工缝；  
2. 留设施工缝时，不应留在剪力最大处或底板与侧墙交接处；  
3. 施工时应分层连续浇筑、机械振捣密实；  
4. 防水混凝土养护时间不少于 14d。  

真题锚=`2015 第26题`

## R7｜边界：满分 vs 压线 vs 0分 near-miss 候选

> 以下为评分边界候选，全部标为 🔴，需真人/专家裁决后才能固化为正式判分规则。

### 满分候选

- 🔴 **待真人/专家裁决：答案同时覆盖“连续浇筑原则、留缝位置、处理工序、后浇带措施”，且关键数字写对，如 1/3、1.2N/mm²、30mm、14d，可判满分候选。**  
  可能错因码：无

- 🔴 **待真人/专家裁决：案例题中能先指出背景中的不妥，再给出正确做法，如后浇带采用微膨胀混凝土、强度提高一级、至少 14d 养护，可判满分候选。**  
  可能错因码：无

### 压线候选

- 🔴 **待真人/专家裁决：只写“施工缝应留在受力较小处、处理干净后浇筑”，但缺少 1.2N/mm²、凿毛、30mm 砂浆等关键词，可能为压线。**  
  可能错因码：`E03` 关键词缺失

- 🔴 **待真人/专家裁决：只答出后浇带“微膨胀混凝土、强度提高一级、14d 养护”三项，但未写整理钢筋、冲洗松动部分、接缝按施工缝处理，可能为压线。**  
  可能错因码：`E02` 采分点遗漏

- 🔴 **待真人/专家裁决：位置题只写出“次梁 1/3、楼梯 1/3”，但漏掉柱墙水平施工缝、墙洞口连梁等构件位置，可能为压线。**  
  可能错因码：`E02` 采分点遗漏

### 0分 near-miss 候选

- 🔴 **待真人/专家裁决：把施工缝写成“可留在剪力最大处”或“底板与侧墙交接处宜留缝”，与防水混凝土真题锚相反，可能判 0。**  
  可能错因码：`E10` 规范适用错误

- 🔴 **待真人/专家裁决：把后浇带混凝土写成“普通同强度混凝土、无需加强养护”，与采分关键词相反，可能判 0。**  
  可能错因码：`E10` 规范适用错误

- 🔴 **待真人/专家裁决：把“后浇带”和“普通施工缝”完全混为一谈，只写随意留缝、不写微膨胀、高一级、14d 养护，可能判 0 或严重扣分。**  
  可能错因码：`E07` 概念混淆

- 🔴 **待真人/专家裁决：处理顺序写成“先浇筑后凿毛清理”或未达到强度即继续浇筑，可能判 0 或严重扣分。**  
  可能错因码：`E06` 程序顺序错误

- 🔴 **待真人/专家裁决：多选题中把“施工缝宜留在受剪力较大部位”选为正确，属于选项陷阱，可能导致该选项不得分。**  
  可能错因码：`M04` 选项陷阱 / `M10` 用常识替代规范判断

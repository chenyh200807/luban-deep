## R6 答案骨架

### 题型一：判断上下层开口间距是否满足防火要求

满分答法：

1. 🟢先判断：若上下层开口间实体墙高度为1.1m，则不满足防火要求，因为应≥1.2m。  
   source=教材锚源料；point_id=kc:1A413030_148_0286:0

2. 🟢整改路径一：调整构造，使上下层开口间实体墙高度达到≥1.2m。  
   source=教材锚源料；point_id=kc:1A413030_148_0286:0

3. 🟢整改路径二：设置防火挑檐，挑檐宽度≥1.0m，且长度≥开口宽度。  
   source=教材锚源料；point_id=kc:1A413030_148_0286:0

4. 🟢同时完善幕墙空腔防火封堵：空腔填塞高度≥200mm，钢质承托板厚度≥1.5mm。  
   source=教材锚源料；point_id=kc:1A413030_148_0286:0

### 题型二：写幕墙层间封堵构造做法

满分答法：

1. 🟢幕墙与各层楼板、隔墙外沿间的缝隙，应采用不燃材料封堵。  
   source=真题证据；真题锚=2015案例2

2. 🟢填充材料可采用岩棉或矿棉，并应满足设计耐火极限要求，在楼层间形成水平防火烟带。  
   source=真题证据；真题锚=2015案例2

3. 🟢防火层应采用厚度不小于1.5mm的镀锌钢板承托，不得采用铝板。  
   source=真题证据；真题锚=2015案例2

4. 🟢承托板与主体结构、幕墙结构及承托板之间的缝隙，应采用防火密封胶密封。  
   source=真题证据；真题锚=2015案例2

### 题型三：写幕墙防雷连接做法

满分答法：

1. 🟢幕墙金属框架应与主体结构防雷系统可靠连接。  
   source=教材锚源料；point_id=kc:1A413030_148_0287:0

2. 🟢铝合金立柱每10m内应用柔性导线连通上下柱。  
   source=教材锚源料；point_id=kc:1A413030_148_0287:0

3. 🟢预埋件应焊接至均压环，形成防雷连通路径。  
   source=教材锚源料；point_id=kc:1A413030_148_0287:0

4. 🟢若题干给出铝合金立柱间距或连接距离为12m，应判断需要补设柔性导线，因为已超过“每10m内连通”的要求。  
   source=教材锚源料；point_id=ca:1A413030_148_0287

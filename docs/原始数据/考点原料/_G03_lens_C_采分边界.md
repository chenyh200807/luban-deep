# G03 桩基施工与质量问题｜R5-R7镜头

## R5 采分点

### 1. 预制桩施工控制

| 采分组 | 必答点 | 锚定 |
|---|---|---|
| 预制桩强度与吊运 | 70%可起吊，100%可运输、打桩；两点起吊吊点距桩端宜为0.2L | 🟢 source=kc:1A413030_090_0165:0 |
| 锤击沉桩顺序 | 先深后浅、先大后小、先长后短、先密后疏 | 🟢 source=kc:1A413030_090_0165:0；真题锚=2015第24题 |
| 密集桩群打法 | 基坑不大可逐排；密集桩群从中间向四周或两边对称施打；毗邻建筑物时由毗邻建筑物处向另一方向施打 | 🟢 真题锚=2015第24题 |
| 锤击能量控制 | 宜采用重锤低击或低锤重打，避免桩头损坏和桩身开裂 | 🟢 真题锚=2017第26题 |
| 预制桩断裂防治 | 清障、查桩身质量、垂直沉桩、接桩对中、避免运输损伤 | 🟢 source=kc:1A434000_070_0109:0 |

### 2. 静压桩施工与终止标准

| 采分组 | 必答点 | 锚定 |
|---|---|---|
| 试压桩 | 静力压桩前必须试压桩，数量不少于3根 | 🟢 source=kc:1A413030_090_0165:1 |
| 压桩力控制 | 最大压桩力应大于群桩挤密效应下最大压桩阻力，且小于机架重量与配重之和的0.9倍 | 🟢 source=kc:1A413030_090_0165:1 |
| 禁止事项 | 不得边压桩边开挖基坑 | 🟢 source=kc:1A413030_090_0165:1 |
| 终止沉桩标准 | 摩擦桩、端承摩擦桩以标高为主、压力为辅；端承桩以压力为主、标高为辅 | 🟢 source=kc:1A413030_091_0166:0 |

### 3. 灌注桩工法与流程

| 采分组 | 必答点 | 锚定 |
|---|---|---|
| 灌注桩分类 | 泥浆护壁灌注桩、沉管灌注桩、长螺旋钻孔压灌桩、干作业成孔灌注桩 | 🟢 source=kc:1A413030_091_0167:0 |
| 泥浆护壁流程 | 场地平整→桩位放线→开挖浆池→护筒埋设→钻机就位→成孔→清孔→下钢筋笼→浇筑混凝土→成桩 | 🟢 source=kc:1A413030_091_0168:0 |
| 沉管灌注桩流程 | 桩机就位→锤击沉管→上料→边振边拔→下钢筋笼→继续浇筑→成桩 | 🟢 source=kc:1A413030_092_0171:0 |
| 人工挖孔桩 | 桩距<2.5m时，间隔开挖和浇筑，最小间距≥5m；先中间后周边，扩底先挖圆柱体再扩底 | 🟢 source=kc:1A413030_092_0172:0 |

### 4. 泥浆护壁灌注桩质量控制

| 采分组 | 必答点 | 锚定 |
|---|---|---|
| 孔底沉渣厚度 | 端承型桩≤50mm；摩擦型桩≤100mm；抗拔/抗水平荷载桩≤200mm | 🟢 source=kc:1A413030_091_0169:0 |
| 水下混凝土 | 坍落度180～220mm；超灌高度≥1m；充盈系数≥1 | 🟢 source=kc:1A413030_091_0169:0 |
| 案例超灌纠错 | 桩顶混凝土面超过设计标高500mm不妥；水下灌注桩顶混凝土面宜超灌0.8～1.0m | 🟢 真题锚=2016案例1 |
| 坍孔防治 | 保证泥浆护壁效果，维持足够水头压力，合理控制钻进参数，及时处理孔口坍塌 | 🟢 source=kc:1A434000_071_0110:1 |
| 干作业孔底虚土 | 成孔后孔底虚土不得超过100mm，否则二次投钻、勺钻清理或孔底压力灌浆 | 🟢 source=kc:1A434000_071_0110:0 |

### 5. 桩基检测与验收

| 采分组 | 必答点 | 锚定 |
|---|---|---|
| 检测方法 | 静载试验、钻芯法、低应变法、高应变法、声波透射法 | 🟢 source=kc:1A413030_092_0173:0 |
| 方法适用 | 高应变法判定单桩竖向抗压承载力、桩身完整性及土阻力；声波透射法检测灌注桩桩身缺陷 | 🟢 source=kc:1A413030_093_0174:0 |
| 检测前强度条件 | 低应变法和声波透射法要求混凝土强度≥设计强度70%且≥15MPa；钻芯法要求龄期≥28d或满足条件 | 🟢 source=kc:1A413030_093_0174:0 |
| 完整性分类 | Ⅰ类完整；Ⅱ类轻微缺陷不影响承载力；Ⅲ类明显缺陷影响承载力；Ⅳ类严重缺陷 | 🟢 source=kc:1A413030_093_0174:1 |
| 钻芯孔数 | 桩径<1.2m：1~2孔；1.2~1.6m：2孔；>1.6m：3孔；孔位距桩中心(0.15~0.25)D | 🟢 source=kc:1A413030_093_0174:2 |
| 承载力检测数量 | 设计等级甲级或地质复杂时采用静载试验，检验桩数不少于总桩数1%且不少于3根；总桩数<50根时不少于2根 | 🟢 source=kc:1A434000_065_0096:0 |
| 完整性抽检 | 工程桩应进行桩身完整性检验，抽检数量不应少于总桩数20%且不应少于10根；每根柱子承台下不少于1根 | 🟢 source=kc:1A434000_065_0096:1 |
| 案例检测纠错 | 甲级或复杂条件下，成桩质量可靠性低的灌注桩抽检数量不应少于总数30%且不少于20根 | 🟢 真题锚=2016案例1 |

## R6 答案骨架

### 骨架A：问“施工要求/流程/控制要点”

满分答法：

1. 先判桩型和工法。  
   🟢 预制桩看锤击或静压；灌注桩看泥浆护壁、沉管、长螺旋、干作业成孔。source=kc:1A413030_091_0167:0

2. 再写施工顺序。  
   🟢 泥浆护壁按“场地平整→放线→浆池→护筒→钻机→成孔→清孔→钢筋笼→混凝土→成桩”。source=kc:1A413030_091_0168:0  
   🟢 沉管灌注桩按“就位→沉管→上料→边振边拔→钢筋笼→继续浇筑→成桩”。source=kc:1A413030_092_0171:0

3. 写关键控制参数。  
   🟢 泥浆护壁重点写沉渣厚度、水下混凝土坍落度、超灌高度、充盈系数。source=kc:1A413030_091_0169:0  
   🟢 静压桩重点写试压桩不少于3根、压桩力范围、不得边压桩边开挖。source=kc:1A413030_090_0165:1

4. 写质量问题预防。  
   🟢 预制桩防断裂：清障、查桩身、垂直沉桩、接桩对中、防运输损伤。source=kc:1A434000_070_0109:0  
   🟢 泥浆护壁防坍孔：泥浆护壁、水头压力、钻进参数、孔口处理。source=kc:1A434000_071_0110:1

5. 收到检测与验收。  
   🟢 根据承载力、完整性、缺陷类型选择静载、钻芯、低应变、高应变、声波透射法。source=kc:1A413030_092_0173:0

### 骨架B：问“指出不妥并改正”

满分答法：

1. 先原句定性：“不妥”。  
2. 再给正确规范值或正确做法。  
3. 最后说明控制对象：承载力、完整性、孔底沉渣、桩身质量或施工安全。

可套句：

- 🟢 “灌注时桩顶混凝土面超过设计标高500mm不妥；水下灌注时桩顶混凝土面标高至少应比设计标高超灌0.8～1.0m。”真题锚=2016案例1
- 🟢 “成桩后仅按总桩数20%进行桩身质量检验不妥；对设计等级甲级或地质条件复杂、成桩质量可靠性低的灌注桩，抽检数量不应少于总数30%，且不应少于20根。”真题锚=2016案例1
- 🟢 “基础标高不一时先浅后深不妥；应先深后浅。”source=kc:1A413030_090_0165:0；真题锚=2015第24题
- 🟢 “不同规格桩先小后大不妥；应先大后小、先长后短。”source=kc:1A413030_090_0165:0；真题锚=2015第24题

### 骨架C：问“检测方法/数量/适用条件”

满分答法：

1. 先写检测目的。  
   🟢 承载力检测、桩身完整性检测、强度/桩长/沉渣检测。source=kc:1A413030_092_0173:0

2. 再匹配方法。  
   🟢 静载试验测抗压/抗拔/水平；钻芯法测强度、桩长、沉渣；低应变测缺陷；高应变测承载力；声波透射法测缺陷。source=kc:1A413030_092_0173:0

3. 再写数量或前置条件。  
   🟢 甲级或地质复杂时静载试验不少于总桩数1%且不少于3根，总桩数<50根时不少于2根。source=kc:1A434000_065_0096:0  
   🟢 完整性抽检不少于总桩数20%且不少于10根，每根柱子承台下不少于1根。source=kc:1A434000_065_0096:1

## R7 边界候选

> 以下为评分边界候选，全部标为 🔴待真人/专家裁决，不作为官方评分细则。

### 1. 满分候选

- 🔴待真人/专家裁决：能同时写出“工法类型→施工流程→关键参数→质量问题防治→检测验收”的闭环，且数字准确，可判满分候选。常见错因码：E02、E03、E10。
- 🔴待真人/专家裁决：案例纠错题中，若能逐条指出“不妥+正确做法+规范数字”，如超灌0.8～1.0m、抽检30%且不少于20根，可判满分候选。常见错因码：E03、E10。
- 🔴待真人/专家裁决：选择题或简答题能区分“先深后浅、先大后小、先长后短、先密后疏”，且没有把反向顺序写入答案，可判满分候选。常见错因码：M08、E07。

### 2. 压线候选

- 🔴待真人/专家裁决：只写出主要流程，但漏掉1~2个关键控制参数，如清孔、沉渣厚度、超灌高度，可判压线候选。常见错因码：E02、E03。
- 🔴待真人/专家裁决：知道要做桩身完整性检测，但检测数量、方法适用条件写不完整，可判压线候选。常见错因码：E02、E10。
- 🔴待真人/专家裁决：能判断“不妥”，但正确做法只有方向、没有规范数字，如只写“应增加超灌高度”而未写0.8～1.0m，可判压线候选。常见错因码：E03、E04。
- 🔴待真人/专家裁决：把泥浆护壁流程写对大半，但把“清孔、下钢筋笼、浇筑混凝土”的顺序轻微颠倒，可判压线或扣流程分候选。常见错因码：E06。

### 3. 0分或近似0分候选

- 🔴待真人/专家裁决：把预制桩、静压桩、泥浆护壁灌注桩的控制标准混写，导致主要工法错误，可判0分或近似0分候选。常见错因码：E07、E10。
- 🔴待真人/专家裁决：数字全部错位，如把端承型桩沉渣≤50mm写成≤200mm，或把静载试验数量写成随意比例，可判0分或近似0分候选。常见错因码：M08、E10。
- 🔴待真人/专家裁决：案例题只复述背景，不指出不妥，也不给正确做法，可判0分候选。常见错因码：E05、E08、E02。
- 🔴待真人/专家裁决：用“加强管理、严格施工、保证质量”等口号替代具体桩基参数、流程和检测方法，可判0分或低分候选。常见错因码：E04。
- 🔴待真人/专家裁决：把安全文明施工外延当作主答案，完全不回答桩基施工、清孔、沉渣、检测、超灌等核心采分点，可判0分或近似0分候选。常见错因码：E05、E11。

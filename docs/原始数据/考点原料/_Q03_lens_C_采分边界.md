## R5 采分点

### 1. 先分类：四类通病不要混答

| 蜂窝麻面 | 表面缺陷、浇筑密实度、模板漏浆、材料与振捣控制 | 🔵工程通识；当前源料未给出“蜂窝麻面”直接教材锚 |
| 空鼓 | 饰面层或防水/保温层与基层粘结不牢 | 🟢`kc:1A413030_140_0273:0` 瓷砖流程；🟢`kc:1A413030_140_0272:1` 石材浸湿防空鼓；🟢`kc:1A422000_041_0065:2` 复合防水层粘贴牢固、无空鼓分层 |
| 裂缝 | 受力裂缝、温度裂缝、沉降裂缝、防水混凝土贯通裂缝 | 🟢`kc:1A411011_025_0047:2`；🟢`kc:1A411011_032_0057:0`；🟢`kc:1A413030_096_0181:0`；🟢`kc:1A422000_029_0049:1`；🟢真题锚 `2016 第12题`、`2017 第10题` |

### 2. 空鼓类采分点

- 🟢瓷砖面层应按“基层处理 → 放线 → 浸砖 → 铺砂浆 → 铺砖 → 养护 → 勾缝”组织施工；漏掉浸砖、基层处理或养护，容易形成空鼓答题点。source=`kc:1A413030_140_0273:0`
- 🟢瓷砖铺贴前应清理背面脱模剂，必要时充分浸泡并阴干备用。source=`kc:1A413030_140_0273:1`
- 🟢大理石、花岗石铺设前应浸湿、晾干，防止吸水导致空鼓。source=`kc:1A413030_140_0272:1`
- 🟢复合防水层要求粘贴牢固、无空鼓分层，总厚度按针测法或取样量测检验。source=`kc:1A422000_041_0065:2`
- 🔵若题干出现“空鼓、脱落、粘结不牢”，优先从基层处理、材料背面处理、结合层饱满度、养护和粘结质量检验组织答案。
- 常见错因码：`E02` 采分点遗漏、`E03` 关键词缺失、`E07` 概念混淆、`E10` 规范适用错误。

### 3. 裂缝类采分点

- 🟢裂缝控制分三级：不出现拉应力；有拉应力但不超过抗拉强度；允许裂缝但宽度不超过允许值。source=`kc:1A411011_025_0047:2`
- 🟢允许出现裂缝的混凝土构件，应按构件类别与环境类别控制受力裂缝宽度，使其不影响结构受力性能、使用性能和耐久性能。source=`ca:1A411011_032_0057`
- 🟢大体积混凝土应控制浇筑层厚、入模温度、温升值、里表温差、降温速率和保湿养护时间。source=`kc:1A413030_096_0181:0`
- 🟢防水混凝土裂缝宽度不应大于结构允许限值，且不应贯通。source=`kc:1A422000_029_0049:1`
- 🟢防水混凝土应及时保湿养护，养护期不应少于14d。source=`kc:1A422000_029_0049:3`
- 🟢地基不均匀下沉引起墙体裂缝的真题锚：纵墙两端斜裂缝、裂缝通过窗口两个对角、窗间墙上下对角成对水平裂缝、纵墙中央顶部和底部窗台竖向裂缝。真题锚=`2016 第12题`
- 🟢大体积混凝土养护降温速率不宜大于2℃/d。真题锚=`2017 第10题`
- 常见错因码：`E01` 知识点缺失、`E07` 概念混淆、`E08` 背景信息提取失败、`E10` 规范适用错误、`M08` 规范数字混淆。

### 4. 渗漏类采分点

- 🟢室内防水基层应坚实平整，无浮浆、起砂、裂缝；阴阳角宜做圆弧处理。source=`kc:1A413030_134_0257:0`
- 🟢阴阳角、管根、地漏等部位应先做附加层，并夹铺胎体增强材料。source=`kc:1A413030_134_0257:1`
- 🟢外墙防水严禁在雨天、雪天和五级风及以上时施工，环境温度宜为5～35℃。source=`kc:1A413030_134_0259:0`
- 🟢外墙门窗框、管道等部件安装完毕后再进行防水施工；施工前宜先做节点处理。source=`kc:1A413030_134_0259:1`
- 🟢涂料防水层接槎宽度不应小于100mm；严禁在雨天、雾天、五级及以上大风时施工。source=`kc:1A413030_133_0254:0`
- 🟢防水层施工完应进行雨后观察、淋水或蓄水试验，合格后再做保护层和隔离层。source=`kc:1A413030_124_0236:0`
- 🟢有防水要求的厨房、卫生间和外墙面的防渗漏最低保修期限为5年，保修期自竣工验收合格之日起计算。真题锚=`2016 第15题`
- 🟢防水层施工管理措施可写：安排专人负责、材料合格、基层处理到位、一次成型、压实提浆压光、及时保养。source=`m35:Q17-1A433000:P5`
- 常见错因码：`E02` 采分点遗漏、`E03` 关键词缺失、`E04` 口号化表达、`E10` 规范适用错误、`E12` 表达冗余。

### 5. 蜂窝麻面类采分点

- 🔵蜂窝麻面答题宜围绕“模板严密不漏浆、混凝土和易性、分层浇筑、振捣密实、避免漏振或过振、及时养护、缺陷修补前先清理基层”展开。
- 🟢可借用“材料合格”作为质量控制锚：用自来水拌和不妥，应使用符合标准的饮用水或符合标准的水。source=`m35:Q3-1A433000:P4`
- 🟢可借用混凝土浇筑组织锚：筏形基础浇筑应合理划分浇筑区域和顺序，布料点靠近浇筑位置，控制自由落差。source=`kc:1A413030_095_0179:0`
- 🔴待验证：是否把“模板未湿润、拆模过早、钢筋密集处漏振、砂率偏小”列为本卡固定采分点，需要补充专门教材锚或真题锚后再固化。
- 常见错因码：`E02` 采分点遗漏、`E03` 关键词缺失、`E04` 口号化表达、`E10` 规范适用错误。

## R6 答案骨架

### 满分答题模板

> 先判定通病类型，再写原因，再写预防或处理措施，最后补验收或保修边界。

1. 🟢/🔵**蜂窝麻面**
   - 🔵原因：模板拼缝不严漏浆、混凝土和易性差、浇筑分层和振捣不到位、局部漏振或过振。
   - 🔵预防：模板清理并封严，控制混凝土材料和拌合质量，分层浇筑、插点均匀振捣，钢筋密集和边角处加强振捣，及时养护。
   - 🟢材料控制可写“拌和用水应符合标准”。source=`m35:Q3-1A433000:P4`

2. 🟢**空鼓**
   - 🟢瓷砖：基层处理、放线、浸砖、铺砂浆、铺砖、养护、勾缝流程不能缺。source=`kc:1A413030_140_0273:0`
   - 🟢瓷砖铺贴前清理脱模剂，必要时浸泡并阴干。source=`kc:1A413030_140_0273:1`
   - 🟢石材铺设前浸湿、晾干，防止吸水造成空鼓。source=`kc:1A413030_140_0272:1`
   - 🟢复合防水层应粘贴牢固，无空鼓分层。source=`kc:1A422000_041_0065:2`

3. 🟢**裂缝**
   - 🟢先判断裂缝性质：受力裂缝、温度裂缝、沉降裂缝或防水混凝土贯通裂缝。
   - 🟢受力裂缝：允许裂缝时控制宽度不超过规范限值。source=`kc:1A411011_032_0057:0`
   - 🟢大体积混凝土：控制入模温度、温升、里表温差、降温速率和保湿养护。source=`kc:1A413030_096_0181:0`；真题锚=`2017 第10题`
   - 🟢防水混凝土：裂缝不得贯通，养护不少于14d。source=`kc:1A422000_029_0049:1`、`kc:1A422000_029_0049:3`
   - 🟢墙体沉降裂缝：按窗口对角、窗间墙水平裂缝、纵墙中央竖向裂缝等现象识别。真题锚=`2016 第12题`

4. 🟢**渗漏**
   - 🟢基层：坚实平整，无浮浆、起砂、裂缝；阴阳角宜做圆弧。source=`kc:1A413030_134_0257:0`
   - 🟢节点：阴阳角、管根、地漏先做附加层并夹铺胎体增强材料。source=`kc:1A413030_134_0257:1`
   - 🟢施工条件：外墙防水不得在雨雪天、五级风及以上施工。source=`kc:1A413030_134_0259:0`
   - 🟢涂料防水：接槎宽度不小于100mm，厚度和胎体铺贴符合要求。source=`kc:1A413030_133_0254:0`
   - 🟢验收保护：雨后观察、淋水或蓄水试验合格后，再做保护层和隔离层。source=`kc:1A413030_124_0236:0`
   - 🟢保修：厨房、卫生间和外墙面防渗漏最低保修期限5年，自竣工验收合格之日起算。真题锚=`2016 第15题`

### 一句话收束

🟢/🔵质量通病题不要只喊“加强管理”。满分骨架应写成：**病害类型 → 直接原因 → 工艺控制 → 节点/材料/环境控制 → 验收或保修依据**。

## R7 边界候选

> R7 全部为候选，未作官方评分承诺，必须标🔴待真人/专家裁决。

### 满分候选

- 🔴待真人/专家裁决：能把“蜂窝麻面、空鼓、裂缝、渗漏”分成四类，不混写成同一种质量问题。
- 🔴待真人/专家裁决：空鼓答案同时覆盖基层处理、材料背面处理、浸砖或浸湿、结合层粘结、养护或粘贴质量检验。
- 🔴待真人/专家裁决：裂缝答案能区分受力裂缝、温度裂缝、沉降裂缝和防水混凝土贯通裂缝，并写出控制宽度、温控养护或沉降识别。
- 🔴待真人/专家裁决：渗漏答案能写出基层、节点附加层、施工天气、搭接/接槎、保护层前试验。
- 🔴待真人/专家裁决：答案有具体数字或关键词时不乱编，如“14d养护”“100mm接槎”“五级风及以上不得施工”“5年防渗漏保修”。

### 压线候选

- 🔴待真人/专家裁决：只写出一类病害的原因和措施，但没有覆盖四类通病。
- 🔴待真人/专家裁决：能写“基层处理、材料合格、加强养护”，但缺少节点、试验或具体工艺顺序。
- 🔴待真人/专家裁决：能写“裂缝要控制宽度”，但没有说明温度裂缝、贯通裂缝或沉降裂缝的判断边界。
- 🔴待真人/专家裁决：能写“防水要做附加层”，但漏写施工环境、蓄水/淋水试验或保护层前验收。

### 0分 near-miss 候选

- 🔴待真人/专家裁决：把“蜂窝麻面、空鼓、裂缝、渗漏”全部回答成“加强管理、严格验收”，没有任何工艺点。
- 🔴待真人/专家裁决：把空鼓原因只写成“材料不好”，不写基层、浸砖/浸湿或粘结层。
- 🔴待真人/专家裁决：把所有裂缝都归因于地基沉降，忽略温度裂缝、受力裂缝和防水混凝土贯通裂缝。
- 🔴待真人/专家裁决：渗漏题只写“刷防水涂料”，不写基层、节点附加层、施工环境、搭接接槎和试验。
- 🔴待真人/专家裁决：引用证据外年份题号、编造规范数字、或自造错因码。

# 挣值法/偏差分析误区解析

## 误区1: 错误理解挣值法的核心成本值
- **现象**: 学生在计算BCWP、BCWS和ACWP时，经常混淆这些术语的定义。
- **错误心智模型**: 认为BCWP、BCWS和ACWP都是基于实际成本或计划成本来计算的。
- **对症解药**:
  - BCWP = 已完成工程量 × 预算单价 (已完成工作预算成本)
  - BCWS = 计划工程量 × 预算单价 (计划完成工作预算成本)
  - ACWP = 已完成工程量 × 实际单价 (已完成工作实际成本)

## 误区2: 成本偏差CV计算错误
- **现象**: 学生在计算成本偏差CV时，常常将公式记错或应用错误。
- **错误心智模型**: CV = BCWP - BCWS 或 CV = ACWP - BCWP
- **对症解药**:
  - 正确公式: CV = BCWP - ACWP
  - CV > 0 表示成本节支
  - CV < 0 表示成本超支
  - 🟢kc:1A435020_095_0156:1

## 误区3: 进度偏差SV计算错误
- **现象**: 学生在计算进度偏差SV时，容易混淆BCWP和BCWS的位置。
- **错误心智模型**: SV = BCWS - BCWP
- **对症解药**:
  - 正确公式: SV = BCWP - BCWS
  - SV > 0 表示进度提前
  - SV < 0 表示进度延误
  - 🟢kc:1A435020_095_0156:1

## 误区4: 成本绩效指数CPI计算错误
- **现象**: 学生在计算CPI时，容易将分子和分母搞反。
- **错误心智模型**: CPI = ACWP / BCWP
- **对症解药**:
  - 正确公式: CPI = BCWP / ACWP
  - CPI > 1 表示节支
  - CPI < 1 表示超支

- **错误心智模型**: SPI = BCWS / BCWP

  - 正确公式: SPI = BCWP / BCWS

## 动画分镜原料
### 视觉隐喻
- **进度条**: 用进度条表示项目的进度状态，绿色表示进度提前，红色表示进度延误。
- **天平**: 用天平表示成本平衡，左边是BCWP，右边是ACWP，天平倾斜表示成本偏差。

### Reveal顺序
1. 显示项目的基本信息（BCWP, BCWS, ACWP）。
2. 逐步展示CV、SV、CPI和SPI的计算过程。

### Aha时刻
- 当学生看到进度条和天平的变化时，能够直观地理解成本和进度的偏差及绩效指数的意义。

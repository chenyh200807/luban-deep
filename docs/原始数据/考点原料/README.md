# 考点深度原料（Exam-Point Deep Knowledge Asset）

> 一个**考点** = 围绕它的**全部知识点 + 原理 + 出题逻辑 + 诊断逻辑 + 解药 + 动画原料**，
> 聚拢成一份单一权威原料。AI/鲁班吃了它，对这个考点有**大师级理解**，
> 从而能判断学员能力与弱点、对症下药，并据此生成动画讲解、判分、答疑——**全部从这一份派生，不漂移**。

## 为什么需要这层（现状缺口）

现有 RichLeaf 编译（1612 单元 / 5705 采分点）是**按教材章节组织**的，且：
- 一个考点的知识点被教材结构**切碎散落**在多个章节（例：大体积混凝土温控的"水泥水化热"在材料章、"水胶比"在施工章、"养护测温"又在别处）；
- 每个单元**浅**（教材事实 + 关键词），是判分弹药，不是大师级拆解；
- 官方标记 `candidate_only / quality_claim_allowed:false`，未认证为 truth。

**考点原料 = 跨章节聚拢知识点 + 往上叠原理/能力/诊断/解药/动画五层深度。**

## 十层结构（schema）

| 层 | 名称 | 服务于 | 备注 |
|---|---|---|---|
| 0 | 考点身份 | 全部 | 名/taxonomy 跨章引用/频次证据/题型 |
| 1 | 知识点全景图 | 理解·诊断 | **跨章节聚拢**，带依赖关系（prereq） |
| 2 | 原理层（为什么） | **动画·AI理解** | 因果链，让讲解"深刻"、让 AI 真懂 |
| 3 | 能力维度分解 | **诊断** ⭐ | 该考点考查哪些能力，失分形态各异 |
| 4 | 出题人视角 | 判分·变题 | 意图/常考形态/陷阱 |
| 5 | 误区→根因→解药 | **对症下药** ⭐ | 现象→错误心智模型→针对性药 |
| 6 | 采分点+边界 | 判分 | 满分/压线/0分 表达分层 |
| 7 | 真题实例 | ground truth | 锚定真实考法 |
| 8 | 诊断逻辑 | **诊断** ⭐ | 学员表现→推断哪个知识点/能力弱 |
| 9 | 对症下药 | **解药** ⭐ | 弱点→给什么内容/动画/变题 |
| 10 | 动画讲解原料 | **视频** ⭐ | 视觉隐喻/分镜/aha/旁白锚点 |

⭐ = 现有 R1-R8 母题 schema **没有**、但"诊断+解药+动画"必需的层（这是本设计相对母题引擎的增量）。

## 溯源诚实（每条 claim 带标）

- 🟢 **锚定**：来自教材/编译采分点/真题，附 source_ref
- 🔵 **通识**：工程原理/教材物理常识，安全但尚未逐条挂 chunk
- 🔴 **待验证**：需从真题库拉取或教研/真题确认，**禁止编造**

> 🔴 项就是"AI 专家团队 + 你终审"该夯实的精确位置。一份原料里 🔴 越少，它越强。

## R5 采分点

| 分组 | 采分点 | 锚定 |
|---|---|---|
| 1. 先识别检查对象 | 高处作业检查评定项目包括：安全帽、安全网、安全带、临边防护、洞口防护、通道口防护、攀登作业、悬空作业、移动式操作平台、悬挑式物料钢平台。 | 🟢教材锚：`kc:1A436000_107_0174:1` |
| 2. 临边触发条件 | 坠落高度在基准面 2m 及以上进行临边作业时，应在临空一侧设置防护栏杆。 | 🟢教材锚：`kc:1A436000_121_0195:0` |
| 3. 临边封闭措施 | 临边防护栏杆应配合密目式安全立网或工具式栏板封闭。 | 🟢教材锚：`kc:1A436000_121_0195:0` |
| 4. 栏杆构造数字 | 防护栏杆由横杆、立杆、挡脚板组成；上杆高 1.2m，立杆间距不大于 2m，挡脚板不小于 180mm，可承受 1kN 任意方向外力，并张挂密目式安全立网。 | 🟢教材锚：`kc:1A436000_121_0195:2` |
| 5. 楼梯口/平台/梯段边 | 施工楼梯口、楼梯平台、梯段边属于临边防护重点，应安装防护栏杆。 | 🟢教材锚：`kc:1A436000_121_0195:2` |
| 6. 洞口尺寸分档 | 洞口按尺寸采取不同防护：25～500mm 用承重盖板；短边边长大于或等于 500mm 时，临空一侧设高度不小于 1.2m 防护栏杆，并封闭、设挡脚板。 | 🟢教材锚：`kc:1A436000_121_0195:1`；🟢教材锚：`ca:1A436000_121_0195` |
| 7. 悬空作业连带采分 | 在坠落基准面 2m 及以上高处进行模板安装、钢筋绑扎、混凝土浇筑等悬空作业时，必须设置操作平台。 | 🟢教材锚：`kc:1A436000_122_0196:0` |
| 8. 禁止错误作业方式 | 严禁沿钢筋骨架攀登或站在骨架上作业；严禁使用座板式单人吊具或自制吊篮。 | 🟢教材锚：`kc:1A436000_122_0196:2` |
| 9. 超 2m 不用梯子替代平台 | 坠落高度超过 2m 不能使用梯子攀登，应设置“操作平台”。 | 🟢教材锚：`m35:Q2-1A436000-罚则:P1` |
| 10. 悬挑式钢平台防护 | 卸料平台两侧应设置固定防护栏杆，底部设置 200mm 高挡脚板；钢平台左右两侧必须装置固定防护栏杆。 | 🟢真题锚：`2015 案例3` |

## R6 答案骨架

满分答案建议按“先判定、再分临边与洞口、最后补悬空/平台/通道外延”组织：

1. 🟢先判定作业属于高处作业检查范围，核心检查项包括临边防护、洞口防护、通道口防护、攀登作业、悬空作业、移动式操作平台、悬挑式物料钢平台。  
   锚：`kc:1A436000_107_0174:1`

2. 🟢临边作业达到坠落高度基准面 2m 及以上时，应在临空一侧设置防护栏杆，并采用密目式安全立网或工具式栏板封闭。  
   锚：`kc:1A436000_121_0195:0`

3. 🟢防护栏杆应写出关键构造数字：上杆高 1.2m，立杆间距不大于 2m，挡脚板不小于 180mm，可承受 1kN 任意方向外力，并张挂密目式安全立网。  
   锚：`kc:1A436000_121_0195:2`

4. 🟢楼梯口、楼梯平台、梯段边等临边部位，应安装防护栏杆；不能只写“注意安全”“设警示牌”。  
   锚：`kc:1A436000_121_0195:2`

5. 🟢洞口防护按尺寸分档：25～500mm 洞口用承重盖板；短边边长大于或等于 500mm 时，应设高度不小于 1.2m 防护栏杆，并封闭、设置挡脚板。  
   锚：`kc:1A436000_121_0195:1`；`ca:1A436000_121_0195`

6. 🟢涉及模板安装、钢筋绑扎、混凝土浇筑等 2m 及以上悬空作业时，必须设置操作平台；超过 2m 不能用梯子攀登替代操作平台。  
   锚：`kc:1A436000_122_0196:0`；`m35:Q2-1A436000-罚则:P1`

7. 🟢不得沿钢筋骨架攀登或站在骨架上作业，不得使用座板式单人吊具或自制吊篮。  
   锚：`kc:1A436000_122_0196:2`

8. 🟢若题干出现卸料平台或悬挑式物料钢平台，应写“两侧固定防护栏杆、底部 200mm 挡脚板”，不能写成“三侧 1200mm 固定栏杆”即结束。  
   锚：`2015 案例3`

9. 🔵若题干出现上下交叉、通道口或坠物风险，可补充：下层作业应避开坠落半径；坠落半径内应设置安全防护棚或安全防护网，未设隔离措施时设置警戒隔离区并禁止人员进入。  
   锚：`kc:1A436000_124_0198:0`；`kc:1A436000_124_0198:1`

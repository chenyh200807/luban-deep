## 🔗 原理因果层

### 总逻辑链

```
结构的地震与荷载需求
        ↓
需要可靠传力路径（安全性）
        ↓
【钢筋连接选用】是传力路径的关键节点
        ↓
选什么连接方式？
    ↙       ↓        ↘
 焊接    机械连接    绑扎搭接
    ↓       ↓          ↓
各有适用边界，由三个维度决定：
  ① 力学行为  ② 环境约束  ③ 可施工性
```

---

### 因果链一：为什么力学性能决定了基础选用逻辑？

| 步骤 | 内容 | 标识 |
|:---|:---|:---|
| 成因 | 钢材受拉时经历弹性阶段→屈服→强化→颈缩断裂。屈服强度是设计取值依据，强屈比反映安全储备，伸长率反映塑性变形能力 (2015年第5题: **伸长率**是塑性指标) | 🟢 |
| 机理 | 连接的传力机理决定其适用场景——①焊接将钢筋熔为一体，等强传力但引入热影响区(HAZ)，含碳量>0.3%时可焊性显著下降 (kc:1A412000_041_0069:0)；②机械连接通过套筒螺纹咬合传力，无热影响，适合高强钢筋(HRB500+)；③绑扎搭接依赖混凝土与钢筋的粘结力传递应力，搭接长度内混凝土应力集中 | 🟢 / 🔵 |
| 因果 | **塑性是抗震的"保险丝"**——地震下结构需通过塑性铰区耗能，连接处应具有足够延性。HRB400钢筋(屈服400MPa)经冷拉会使塑性下降，因此冷拉率必须严格控制：HPB300≤4%, HRB≤1% (kc:1A413030_100_0190:1)。反复弯折加剧冷作硬化，降低塑性→**严禁反复弯折** (2015年第14题) | 🟢 |
| 措施有效原因 | 梁上部接头宜在跨中1/3(受压区)，下部接头宜在梁端1/3——因为梁端正弯矩小、跨中负弯矩小，在此设接头可避开支承处的最大拉应力区，符合"接头避开最大应力处"的原则 (kc:1A413030_101_0191:0) | 🟢 |

### 因果链二：为什么环境与耐久性决定了选用边界？

| 步骤 | 内容 | 标识 |
|:---|:---|:---|
| 成因 | 混凝土结构暴露在不同环境中——一般环境(I)、冻融(II)、氯化物(III)、化学腐蚀(V)。不同环境等级对混凝土强度和钢筋保护层有严格要求 (kc:1A411011_026_0048:2) | 🟢 |
| 机理 | 连接的耐久性不独立于基材——保护层是钢筋防锈的第一道屏障，过薄的保护层使CO₂和Cl⁻提前抵达钢筋表面，诱发锈蚀，削弱连接握裹力。例如I-B环境50年C35梁柱保护层≥30mm (kc:1A411011_027_0049:0)。**2015年第3题**挖坑：楼板保护层不是35mm，而是15~30mm | 🟢 |
| 因果 | 框支梁、框支柱等关键构件破坏后果严重，安全等级高→混凝土强度要求≥C30 (kc:1A411011_011_0021:0)，这是保障连接锚固力的基材底线。若基材本身强度不足，则钢筋锚固长度再长也无从发挥作用 | 🟢 |
| 措施有效原因 | 钢结构螺栓连接：抗剪构件必须用**摩擦型高强螺栓**，因为普通螺栓依靠螺杆承压承剪，滑移后刚度突变；而摩擦型通过预拉力产生摩擦力，传力平稳。受拉普通螺栓则须设双螺帽防松 (kc:1A411011_034_0061:1) | 🟢 |

### 因果链三：为什么施工条件反向约束选用？

| 步骤 | 内容 | 标识 |
|:---|:---|:---|
| 成因 | 连接方式的可行性取决于现场条件——焊接需稳定的电源、干燥环境、足够操作空间；机械连接可在狭小空间操作；绑扎连接最简单但对钢筋根数有限制 | 🔵 (通识) |
| 机理 | **可焊性边界**：当施工现场处于严寒(-5℃以下)或雨天时，焊接质量难以保证。此外，含硫量高的钢材在焊接时形成低熔点硫化物，造成**热脆开裂** (kc:1A412000_041_0069:2)。含强电解质无机盐的混凝土外加剂若接触钢筋，会促进电化学锈蚀，因而严禁用于外露钢筋 (kc:1A412010_048_0083:1) | 🟢 |
| 因果 | 预制装配式构件现场连接常采用**套筒灌浆连接**——预制柱就位后注入灌浆料填充钢筋端部套筒。这是"工厂预制焊接/机械连接+现场灌浆"的混合工法，体现了"工厂做精、现场做简"的装配式逻辑。存放时叠放≤6层、细长构件平放，均是为防止钢筋外露端变形影响后续连接精度 (kc:1A413030_116_0224:0) | 🔵 |
| 措施有效原因 | 板钢筋绑扎**四周每点扎牢、中间交错**——四周是混凝土浇筑时钢筋位移的高发区(混凝土流动冲刷边缘)，逐点绑扎防止脱位；中间交错绑扎在保证约束的同时避免过密绑丝增加滑移风险 (kc:1A413030_101_0191:1) | 🟢 |

### 因果链四：连接选用的三维决策树

```
【选定钢筋连接方式的决策路径】

Question 1: 能否焊接？
  ├─ 含碳量≤0.3%? → No → ❌焊接不可行 (可焊性差)
  ├─ 环境气温≥0℃? → No → 需采取预热/保温措施
  └─ Yes ↓

Question 2: 是否抗震关键部位？
  ├─ 框支梁柱/二级以上框架节点 → 优先机械连接(无热影响)+ 基材≥C30
  └─ 一般部位 ↓

Question 3: 大直径钢筋(d≥25)?
  ├─ Yes → 优选机械连接 (焊接热影响过大, 绑扎搭接过长不经济)
  └─ 可选用焊接或搭接

最终判定:
  → 机械连接: 无热影响 + 等强 + 工厂预制化 → 适用高强钢筋、关键节点
  → 焊接: 等强传力 + 成本低 → 适用低碳钢、一般环境、现场可行
  → 绑扎: 成本最低 + 工法简单 → 适用直径≤25mm、柱内距地面≥500mm设接头
```

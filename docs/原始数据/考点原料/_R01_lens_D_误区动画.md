# R01 现场消防布置、动火、检查、验收流程

## 误区解析
### 误区1: 动火审批手续不齐全
- **现象**: 施工现场在进行焊接作业前未办理动火审批手续。
- **错误心智模型**: 认为只要施工人员有经验，无需严格遵守审批程序。
- **对症解药**: 明确规定所有动火作业必须事先获得批准（E02）。
- **锚定**:
  - 🔵 工程通识：确保安全是首要任务，即使是有经验的工人也必须遵循既定的安全规程。
  - 🟢 教材锚: kc:1A437000_147_0237:0, ca:1A437000_147_0237

### 误区2: 消防设施配置不足
- **现象**: 临时木料间内灭火器数量不足。
- **错误心智模型**: 认为少量灭火器足以应对可能发生的火灾。
- **对症解药**: 根据规范要求每25平方米至少配备一只灭火器（M06）。
- **锚定**:
  - 🔴 待验证: 需要根据具体项目规模调整消防设备的数量。
  - 🟢 教材锚: kc:1A437000_146_0233:0, ca:1A437000_146_0233

### 误区3: 忽视动火证的有效性
- **现象**: 使用过期或地点变更后的动火证继续作业。
- **错误心智模型**: 一旦获得动火许可，便认为可以无限期使用。
- **对症解药**: 强调动火证仅当日有效，并且当作业地点发生变化时需重新申请（E03）。
- **锚定**:
  - 🔵 工程通识：保持警惕，定期更新必要的安全文件。
  - 🟢 教材锚: kc:1A437000_145_0231:1, ca:1A437000_145_0231

### 误区4: 不合理的气瓶存放位置
- **现象**: 氧气瓶与乙炔瓶之间的距离小于规定值。
- **错误心智模型**: 认为只要将两种气体分开存放即可，忽略了具体的间距要求。
- **对症解药**: 保证氧气瓶与乙炔瓶之间至少保持5米的距离（M08）。
- **锚定**:
  - 🔴 待验证: 实际操作中还需考虑环境因素的影响。
  - 🟢 教材锚: kc:1A437000_147_0237:1, ca:1A437000_147_0237

### 误区5: 未设立义务消防队
- **现象**: 施工现场没有组建足够的义务消防队伍。
- **错误心智模型**: 依赖专业消防力量，忽视了自身应急能力的重要性。
- **对症解药**: 按照总人数的10%比例建立义务消防队（E09）。
- **锚定**:
  - 🔵 工程通识：培养员工自救互救意识，提高整体安全水平。
  - 🟢 教材锚: kc:1A437000_144_0230:1, ca:1A437000_144_0230

### 误区6: 错误处理电石起火
- **现象**: 使用水或其他不适合的灭火剂扑灭电石引起的火灾。
- **错误心智模型**: 以为任何类型的灭火器都适用于所有情况。
- **对症解药**: 采用干砂或二氧化碳灭火器来处理此类事故（M01）。
- **锚定**:
  - 🟢 教材锚: kc:1A436000_127_0203:0, ca:1A436000_127_0203
  - 🟢 真题锚: 2015年第18题

### 误区7: 油漆料库与调料间设置不当
- **现象**: 将油漆料库和调料间设在同一房间内。
- **错误心智模型**: 为了方便管理而忽略了潜在的安全风险。
- **对症解药**: 这两个区域必须分开并保持适当防火间距（E11）。
- **锚定**:
  - 🔵 工程通识：合理规划空间布局以降低火灾隐患。
  - 🟢 教材锚: kc:1A437000_147_0238:0, ca:1A437000_147_0238

### 误区8: 木工操作间缺乏必要防护措施
- **现象**: 木工操作间未按要求安装阻燃材料及消防设施。
- **错误心智模型**: 低估了木材加工过程中产生的火灾危险。
- **对症解药**: 所有相关设施均应符合消防安全标准（M07）。
- **锚定**:
  - 🔵 工程通识：加强日常管理和监督，确保各项安全措施落实到位。
  - 🟢 教材锚: kc:1A437000_148_0239:0, ca:1A437000_148_0239

## 动画分镜原料
### 视觉隐喻
- **动火审批过程**: 用钥匙解锁代表获取动火许可的过程。
- **灭火器配置**: 通过展示不同颜色大小的圆圈表示不同类型和数量的灭火器。
- **动火证有效期**: 日历翻页显示日期变化，强调时效性。
- **气瓶安全距离**: 两瓶之间拉伸弹簧模拟最小安全间隔。
- **义务消防队**: 一群穿着统一制服的人聚集在一起象征团队协作。
- **电石起火处理**: 干砂覆盖火焰的画面说明正确灭火方法。
- **油漆料库与调料间分离**: 两座小房子被一条河流隔开。
- **木工操作间防护**: 展示一个由特殊材料制成的小屋内部装有消防器材。

### Reveal顺序
1. 开场介绍施工现场常见的消防安全隐患。
2. 逐一揭示上述每个误区的具体表现形式。
3. 对比展示正确的做法及其重要性。
4. 结尾总结关键知识点，提醒观众注意防范措施。

### Aha时刻
- 当看到动火证随时间推移逐渐变暗直至消失时，观众会意识到其有限的有效期。
- 通过观察气瓶间弹簧伸缩动画，直观理解为何需要保持一定距离。
- 在演示如何正确处置电石火灾时，突然出现的干砂迅速熄灭火焰给人留下深刻印象。

## R6 答案骨架

### 问法 1：问“钢结构连接方法有哪些”

满分骨架：

1. 🟢 钢结构构件连接方法包括：焊接、普通螺栓连接、高强度螺栓连接、铆接。  
   锚定：`kc:1A413030_109_0216:0`

2. 🟢 若追问焊接接头，应补充：全熔透、部分熔透、角焊缝、塞焊与槽焊、电渣焊、栓钉焊。  
   锚定：`kc:1A413030_109_0216:1`

### 问法 2：问“高强螺栓安装控制要点”

满分骨架：

1. 🟢 临时安装控制：安装螺栓不少于 2 个，且不少于安装孔总数的 1/3；冲钉数量不宜多于安装螺栓数量的 30%；不得用高强度螺栓兼作安装螺栓。  
   锚定：`kc:1A413030_110_0217:0`

2. 🟢 穿入与扩孔控制：高强度螺栓必须自由穿入，不得强行穿入；扩孔孔径不得超过螺栓直径的 1.2 倍，不得气割扩孔。  
   锚定：`kc:1A413030_111_0218:0`

3. 🟢 摩擦面控制：摩擦面干燥清洁，无飞边、毛刺、焊渣、氧化皮、污垢；不得在摩擦面作标记；生锈处理时安装前清除浮锈。  
   锚定：`kc:1A413030_110_0217:2`

4. 🟢 试验与检查：摩擦面需做抗滑移试验；终拧后 1～48 小时内检查。  
   锚定：`kc:1A434000_068_0102:0`

### 问法 3：问“焊接施工质量控制要点”

满分骨架：

1. 🟢 环境控制：温度不低于 -10℃，相对湿度不大于 90%；手工电弧焊风速不大于 8m/s，气体保护焊风速不大于 2m/s；低温时加热或防护。  
   锚定：`kc:1A413030_110_0217:1`

2. 🟢 材料与人员控制：焊接材料须烘焙；焊工必须持证上岗。  
   锚定：`kc:1A434000_068_0102:0`

3. 🟢 焊前清理与缺陷处理：焊前清理坡口及周边杂质；严重夹渣按返修方案补焊。  
   锚定：`kc:1A434000_074_0116:0`

4. 🟢 检测控制：一级、二级焊缝需无损检测。  
   锚定：`kc:1A434000_068_0102:0`

5. 🟢 疲劳限制：承受动荷载且需疲劳验算时，严禁使用塞焊、槽焊、电渣焊和气电立焊接头。  
   锚定：`kc:1A422000_038_0062:1`

# 镜头: 渗漏治理诊断

## 误区 (R8)
### 误区1: 施工缝未清理干净
- **现象**: 混凝土粘结不良，导致渗漏。
- **错误心智模型**: 认为施工缝的表面处理不重要，只要混凝土浇筑到位即可。
- **对症解药**: 施工前必须彻底清理施工缝，确保无杂物和松散混凝土。[kc:1A434000_074_0116:0]
- **错因码**: E02

### 误区2: 未按规范处理施工缝
- **现象**: 接槎明显，影响结构的整体性。
- **错误心智模型**: 认为施工缝处理可以随意，不影响整体质量。
- **对症解药**: 严格按照规范要求处理施工缝，确保接槎平顺。[kc:1A434000_074_0116:0]
- **错因码**: E03

### 误区3: 混凝土养护不当
- **现象**: 混凝土裂缝渗漏水。
- **错误心智模型**: 认为混凝土浇筑后不需要特别养护。
- **对症解药**: 混凝土浇筑后必须及时保湿养护。[kc:1A434000_075_0117:0]
- **错因码**: E04

### 误区4: 管道穿墙部位未设置止水环
- **现象**: 管道穿墙部位渗漏。
- **错误心智模型**: 认为管道穿墙部位无需特殊处理。
- **对症解药**: 清理管道表面，设置止水环，并振捣密实。[kc:1A434000_075_0117:1]
- **错因码**: E05

### 误区5: 卷材屋面流淌未及时治理
- **现象**: 屋面卷材流淌，影响防水效果。
- **错误心智模型**: 认为卷材流淌是正常现象，无需处理。
- **对症解药**: 中等流淌可采用切割法、局部切除重铺或钉钉子法进行治理。[kc:1A434000_076_0118:0]
- **错因码**: E06

### 误区6: 卷材起鼓未及时处理
- **现象**: 卷材起鼓，影响防水效果。
- **错误心智模型**: 认为卷材起鼓不会影响防水性能。
- **对症解药**: 直径小于100mm用抽气灌胶法；大于等于100mm需割开、清理、吹干、重贴。[kc:1A434000_076_0119:0]
- **错因码**: E07

### 误区7: 山墙/女儿墙漏水未修复
- **现象**: 山墙/女儿墙出现渗漏。
- **错误心智模型**: 认为山墙/女儿墙漏水是小问题，无需特别处理。
- **对症解药**: 清除旧胶结料→烤干基层→重新钉压条→覆盖新卷材→防水油膏封口；修复压顶砂浆；分层压入新卷材并加铺一层。[kc:1A434000_077_0120:0]
- **错因码**: E08

### 误区8: 堵漏灌浆材料选择不当
- **现象**: 堵漏效果不佳。
- **错误心智模型**: 认为所有堵漏灌浆材料都适用。
- **对症解药**: 根据具体情况选择合适的堵漏灌浆材料，如丙烯酸胶、甲基丙烯酸酯、环氧树脂、聚氨酯等。[kc:1A412010_065_0127:0]
- **错因码**: E09

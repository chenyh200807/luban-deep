## ⛓️ 3. 原理因果层

### 🧱 核心因果链

```
成因（为什么裂？）
  │
  ├─ 🔴 不同基体材料（混凝土/砖砌体/加气块）热胀变形系数不同
  │     ↓
  └─ 成因①：交接处因温度、湿度变化产生差动位移 → 集中拉应力
  
  ├─ 🔴 单层抹灰过厚（≥35mm）→ 内外层收缩速率差异
  │     ↓
  └─ 成因②：表层快干收缩，内层慢干约束 → 收缩拉应力超限 → 开裂/空鼓

  ├─ 🟢 基层含水率过高（＞8%（溶剂型））→ 涂料成膜后水分封闭
  │     ↓
  └─ 成因③：水分封闭汽化 → 蒸汽压力顶起涂层 → 鼓泡/剥离

  ├─ 🔵 厨卫环境长期潮湿+碱性水汽
  │     ↓
  └─ 成因④：普通腻子粉化/霉菌滋生 → 腻子丧失粘结力 → 脱落
```

### 🔧 措施机理（为什么这么做有效）

| 措施 | 针对的问题 | 作用机理 | 三色 |
|---|---|---|---|
| 总厚度≥35mm加挂钢丝网/分层抹灰 | 成因②—厚层收缩开裂 | 钢丝网增加抗拉强度；分层抹灰错开收缩时段，层间咬合消除贯通裂缝 | 🟢 |
| 不同材料交接处挂加强网，搭接≥100mm | 成因①—差动位移 | 网片跨越接缝将应力分散传递给两侧基体；100mm搭接保证锚固长度，避免网片自身拔脱 | 🟢 |
| 涂料前基层含水率≤8%（溶剂型） | 成因③—水分封闭 | 含水率低于涂料成膜的临界阈值，残余水分不足以形成蒸汽压力破坏涂层粘结 | 🟢 |
| 厨卫必须使用耐水腻子 | 成因④—潮湿粉化 | 耐水腻子采用水泥基或高分子改性胶凝材料，遇水不粉化、耐碱，确保潮湿环境的粘结持久性 | 🟢 |
| 涂饰工程在湿作业全部完成后进行 | 多因素叠加 | 避免后续湿作业（如地面找平）释放水汽穿透已完成的涂层，从底层破坏涂料粘结 | 🔵 |

### 📐 学生可讲因果链总结

> **“抹灰开裂问题，本质是‘约束下的收缩’或‘约束下的差动位移’。”**
>
> — 单层抹太厚 → 外部干了内部还湿 → 干缩被内部约束 → **拉力过大开裂** → **≥35mm必须分层+加网**
>
> — 混凝土柱和砖墙热胀冷缩不一样 → 接缝处互相“撕扯” → **挂加强网跨过接缝来分摊应力** → **搭接≥100mm是保证网不脱**
>
> — 含水率高了就上漆 → 水分被封在基层里出不去 → 一蒸发就**顶破涂层起泡** → **必须≤8%再涂**
>
> — 厨卫常年潮湿 → 普通腻子就像“泥巴见水”会化 → **必须用耐水腻子这个“不怕水的胶”**”

## R6 答案骨架

### 骨架一：问“如何选择降水方案”

1. 🟢 先说明选择依据：应综合考虑地质、水文、环境、支护设计、开挖深度、地下水条件。  
   锚定：`kc:1A413000_082_0154:0`

2. 🟢 按深度先分流：  
   - 深度 ≤3m 且软土：可采用集水明排。  
   - 深度 >3m：宜采用井点降水。  
   锚定：`kc:1A413000_082_0154:0`

3. 🟢 若题干为“软土地区、地下水丰富、开挖深度 4m”，答案应落到井点降水，不宜只答集水明排。  
   锚定：`ca:1A413000_082_0154`

4. 🟢 再按参数选型：  
   - 轻型井点：降水深度 ≤6m。锚定：`kc:1A413000_082_0155:0`  
   - 喷射井点：降水深度 8~20m。锚定：`kc:1A413000_082_0155:1`  
   - 真空降水井管：降水深度 >6m，且满足渗透系数、管径、间距条件。锚定：`kc:1A413000_083_0156:0`  
   - 渗透系数较大土层：可选管井井点。锚定：`2015第9题`

5. 🟢 如危及周边安全，应补截水或回灌；回灌用于维持地下水位平衡、防止周边沉降。  
   锚定：`kc:1A413000_082_0154:0`；`kc:1A413000_083_0156:2`

6. 🟢 如存在承压水突涌风险，应验算突涌；必要时采取钻孔减压或水平封底隔渗。  
   锚定：`2016第24题`

### 骨架二：问“基坑开挖控制要点”

1. 🟢 土方开挖必须与设计工况一致，严禁超挖。  
   锚定：`kc:1A422000_028_0048:0`

2. 🟢 深基坑分层厚度宜控制在 3m 以内。  
   锚定：`kc:1A413000_084_0157:0`

3. 🟢 软土基坑高差应 ≤1m。  
   锚定：`kc:1A422000_028_0048:0`

4. 🟢 地下水位以下挖土，应先把水位降至坑底以下 500mm 以上，并持续降水至基础施工完成。  
   锚定：`kc:1A413000_084_0157:2`

5. 🟢 不得损坏支护结构、降水设施和工程桩。  
   锚定：`kc:1A422000_028_0048:0`

6. 🟢 逆作法且开挖面积较大时，宜盆式开挖，先形成中部结构，再分块、对称、限时开挖周边土方和施工主体结构。  
   锚定：`kc:1A413000_084_0157:3`

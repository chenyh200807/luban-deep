## R6 答案骨架：满分要点

### 题型A：计算关键线路与总工期

1. 根据网络图逐条线路累加持续时间。
2. 找出总持续时间最长的线路，判定为关键线路。
3. 写出关键线路表达式。
4. 写出总工期计算式与结果。
5. 若题干要求调整网络图，应先修正逻辑关系，再重新计算。

锚定：🟢 source=教材锚源料；point_id=kc:1A433000_056_0085:1。🟢 source=真题证据；真题=2015 案例1、2017 案例一。

### 题型B：工期滞后后如何赶工

答题骨架：

```markdown
经计算，原关键线路为……，总工期为……。
现场检查发现进度滞后……天，且要求总工期不变，因此需压缩……天。

赶工应优先选择关键线路上的可压缩工作。
根据赶工参数，按增加费用较少、可压缩时间满足要求、对质量安全影响较小的原则：
先压缩……工作……天；
再压缩……工作……天。

压缩后总工期为……，满足计划工期要求。
优先选择上述工作的理由是：赶工费用低/成本低，且不影响后续工作。
```

锚定：🟢 source=教材锚源料；point_id=kc:1A433000_056_0085:3；kc:1A433000_061_0092:0；m35:Q17-1A433000:P4。🟢 source=真题证据；真题=2017 案例一。

### 题型C：费用优化/最小赶工成本

满分要点：

- 先满足工期目标，再比较增加费用。
- 只在有效压缩总工期的工作中比较费用。
- 单项赶工费用按“压缩天数 × 单位赶工费”计算。
- 多个方案都能满足工期时，选择总增加费用最低的方案。
- 不能只看单位费用最低；若该工作不在关键线路或压缩后不影响总工期，则不能作为有效赶工方案。

锚定：🟢 source=教材锚源料；point_id=kc:1A433000_057_0086:0；kc:1A433000_056_0085:3。🔵 工程通识：费用比较必须以有效缩短总工期为前提。

### 题型D：赶工与索赔混合问

答题骨架：

```markdown
该事件导致……工作延误……天。
若该工作在关键线路上，则对总工期影响为……天；
若为非关键工作，应先比较其总时差，只有超过总时差的部分才影响总工期。

工期索赔结论：……
理由：……

若为发包人要求提前竣工，赶工费用由发包人承担；
若承包人自行提前竣工，应征得发包人同意，并自行承担增加费用。
```

## R7 边界：满分 vs 压线 vs 0分 near-miss

> 本节为评分边界候选，全部标记为 🔴待真人/专家裁决，不作为最终判分规则。

### 🔴 满分候选

- 能正确识别关键线路和总工期。
- 能明确写出滞后天数与需压缩天数。
- 压缩对象全部来自关键线路，或说明压缩后关键线路变化并重新复核。
- 能按赶工费用、可压缩时间、质量安全影响、备用资源等因素确定压缩顺序。
- 答案写成“先压缩……天，再压缩……天”，不是泛泛说“增加资源、加班施工”。
- 理由中至少出现“费用低/成本低”与“不影响后续工作”之一；两项都写更稳。
- 若题问费用责任或索赔，能区分发包人要求赶工、承包人自行赶工、关键线路延误、非关键线路总时差。

建议错因码覆盖：E02、E03、E09、E10。

### 🔴 压线候选

- 关键线路或总工期有轻微表达瑕疵，但后续赶工对象和压缩总天数基本正确。
- 能选中关键线路上的主要可压缩工作，但没有完整说明排序理由。
- 能算出需压缩天数，但费用计算或压缩顺序缺一步。
- 只写“压缩费用最低的工作”，未明确“不影响后续工作”，但对象和结果正确。
- 索赔混合题中，能判断是否影响总工期，但费用承担表述不完整。

建议错因码覆盖：E02、E03、E12。

### 🔴 0分 near-miss 候选

- 只按单位赶工费最低选择工作，不判断该工作是否在关键线路上。
- 压缩非关键工作且未超过总时差，却声称能缩短总工期。
- 没有计算关键线路和总工期，直接给赶工措施。
- 把“资源优化、费用优化、工期优化”混为一谈，未回应题干的工期目标。
- 只写“增加人员、增加机械、夜间施工”，没有工作名称、压缩天数和费用依据。
- 延误索赔题中，把所有延误都判为可索赔，或把所有非关键工作延误都判为不可索赔，未比较总时差。
- 编造题外真题年份题号，或把未给出的题号冒充真题锚。
- 使用未注册错因码，或自造类似“N02-01”“T01”等代码。

建议错因码覆盖：E05、E07、E08、E09、E10。

## R6 答案骨架

### 1. 先总述连接方法

🟢 钢筋连接方法有三种：**焊接、机械连接、绑扎连接**。其中机械连接常用形式为**剥肋滚压直螺纹套筒连接**。  
锚定：source=教材；point_id=kc:1A413030_100_0190:0

### 2. 再按受力条件限制机械连接

🟢 直接承受动力荷载的结构构件采用机械连接时，接头面积百分率**不应超过 50%**。  
锚定：source=教材；point_id=m35:Q12-1A412000-罚则:P2

> 采分关键词：不应、50%、直接承受动力荷载、机械连接。

### 3. 再写接头位置控制

🟢 梁钢筋接头位置：  
框架梁上部钢筋接头宜设在**跨中 1/3**跨度范围内；下部钢筋接头宜设在**梁端 1/3**跨度范围内。  
锚定：source=教材；point_id=kc:1A413030_101_0191:0

🟢 柱钢筋接头位置：  
每层柱第一个钢筋接头距楼面高度不宜小于 **500mm、柱净高 H/6、柱截面长边 b**，取三者最大值。  
锚定：source=教材；point_id=kc:1A413030_100_0190:2

### 4. 如题干是装配式剪力墙，补竖向钢筋连接规则

🟢 上下层预制剪力墙竖向钢筋采用套筒灌浆连接或浆锚搭接连接时：  
边缘构件竖向钢筋应**逐根连接**；非边缘区竖向分布钢筋连接间距不宜大于 **600mm**；一、二级抗震底部加强区宜采用**套筒灌浆连接**。  
锚定：source=教材；point_id=kc:1A411011_036_0063:2

### 5. 满分答案模板

钢筋连接方法包括焊接、机械连接和绑扎连接三种，机械连接中剥肋滚压直螺纹套筒连接较常用。选用时应结合构件受力性质、接头位置和施工方式判断；直接承受动力荷载的结构构件采用机械连接时，接头面积百分率不应超过 50%。梁钢筋接头应避开受力不利部位，框架梁上部接头宜设在跨中 1/3 范围内，下部接头宜设在梁端 1/3 范围内；柱第一个接头距楼面高度不宜小于 500mm、H/6、柱截面长边 b 三者最大值。若为预制剪力墙竖向钢筋连接，边缘构件竖向钢筋应逐根连接，非边缘区竖向分布钢筋连接间距不宜大于 600mm，一、二级抗震底部加强区宜采用套筒灌浆连接。

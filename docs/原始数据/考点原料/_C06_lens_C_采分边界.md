# C06｜R5-R7 镜头：砌体留槎与构造柱

## R5 采分点

### 1. 留槎总规则：能斜不直，抗震更严

| 采分组 | 采分点 | 锚定 |
|---|---|---|
| 斜槎优先 | 抗震设防烈度 8 度及以上地区，临时断处应砌成斜槎。 | 🟢 source=`kc:1A413030_107_0210:1` |
| 普通砖斜槎尺寸 | 普通砖斜槎水平投影长度不得小于高度的 `2/3`。 | 🟢 source=`kc:1A413030_107_0210:1` |
| 多孔砖斜槎尺寸 | 多孔砖斜槎长高比不得小于 `1/2`。 | 🟢 source=`kc:1A413030_107_0210:1` |
| 直槎限制 | 非抗震区可留直槎，但需加拉结筋。 | 🟢 source=`kc:1A413030_107_0210:1` |
| 常见错因 | 把“可留直槎”误迁移到抗震 8 度及以上地区，或漏写拉结筋。 | 🟢 错因码：E10 规范适用错误；E11 迁移失败；M08 规范数字混淆 |

### 2. 转角、交接处：同步砌筑优先

| 采分组 | 采分点 | 锚定 |
|---|---|---|
| 同步砌筑 | 空心砖墙转角及交接处应同时砌筑，不得留直槎。 | 🟢 source=`kc:1A413030_109_0213:3` |
| 咬槎搭砌 | 交接处应咬槎搭砌，上下错缝。 | 🟢 source=`kc:1A413030_109_0213:3` |
| 斜槎高度 | 空心砖斜槎高度不宜大于 `1.2m`。 | 🟢 source=`kc:1A413030_109_0213:3` |
| 轻骨料砌块交接 | 纵横墙交接处及转角处应同时砌筑；不能同时砌筑时，应留斜槎。 | 🟢 source=`kc:1A413030_109_0214:1` |
| 轻骨料斜槎尺寸 | 轻骨料小砌块斜槎水平投影长度不应小于高度的 `2/3`。 | 🟢 source=`kc:1A413030_109_0214:1` |

### 3. 构造柱马牙槎：先退后进 + 尺寸 + 拉结筋

| 采分组 | 采分点 | 锚定 |
|---|---|---|
| 马牙槎位置 | 构造柱与砌体连接处应砌成马牙槎。 | 🟢 source=`kc:1A413030_107_0210:2` |
| 施工顺序 | 马牙槎做法为“先退后进”。 | 🟢 source=`kc:1A413030_107_0210:2`；🟢 真题锚=`2015年第12题` |
| 高度尺寸 | 每个马牙槎沿高度方向尺寸不宜超过 `300mm`。 | 🟢 source=`kc:1A413030_107_0210:2` |
| 凹凸尺寸 | 马牙槎凹凸尺寸宜为 `60mm`。 | 🟢 source=`kc:1A413030_107_0210:2` |
| 拉结钢筋 | 沿墙高每 `500mm` 设置拉结钢筋。 | 🟢 source=`kc:1A413030_107_0210:2` |
| 高频陷阱 | “先进后退”是错法；正确是“先退后进”。 | 🟢 真题锚=`2015年第12题`；🟢 错因码：E06 程序顺序错误；E07 概念混淆 |

### 4. 临时施工洞口：不要和留槎混写，但可同场景采分

| 采分组 | 采分点 | 锚定 |
|---|---|---|
| 洞口净宽 | 临时施工洞口净宽不应超过 `1m`。 | 🟢 source=`kc:1A413030_106_0208:0`；🟢 真题锚=`2016年案例2` |
| 距交接面 | 洞口侧边距交接面不应小于 `500mm`。 | 🟢 source=`kc:1A413030_106_0208:0`；🟢 真题锚=`2016年案例2` |
| 构造处理 | 宜设过梁或挑砖封口，并预埋拉结筋。 | 🟢 source=`kc:1A413030_106_0208:0` |

| 工程通识 | 临时洞口题常考“宽度 + 距离 + 拉结/过梁”组合，不宜只答一个数字。 | 🔵 工程通识 |

## R6 答案骨架

### 题型 A：问“砌体临时间断处如何留槎？”

满分骨架：

1. 🟢 先判断抗震设防条件：抗震设防烈度 8 度及以上地区，临时断处应砌成斜槎。  
   source=`kc:1A413030_107_0210:1`

2. 🟢 普通砖斜槎的水平投影长度不应小于高度的 `2/3`；多孔砖斜槎长高比不应小于 `1/2`。  
   source=`kc:1A413030_107_0210:1`

3. 🟢 非抗震区如留直槎，应加设拉结筋。  
   source=`kc:1A413030_107_0210:1`

4. 🔵 作答时先写“斜槎/直槎条件”，再写“尺寸”，最后写“拉结筋”，避免只堆数字。

推荐答法：

> 抗震设防烈度 8 度及以上地区，砌体临时间断处应砌成斜槎；普通砖斜槎水平投影长度不应小于高度的 2/3，多孔砖斜槎长高比不应小于 1/2。非抗震区可留直槎，但应加设拉结筋。

### 题型 B：问“构造柱与砌体连接处如何施工？”

满分骨架：

1. 🟢 构造柱与砌体连接处应砌成马牙槎。  
   source=`kc:1A413030_107_0210:2`

2. 🟢 马牙槎应先退后进，不是先进后退。  
   source=`kc:1A413030_107_0210:2`；真题锚=`2015年第12题`

3. 🟢 每个马牙槎沿高度方向尺寸不宜超过 `300mm`，凹凸尺寸宜为 `60mm`。  
   source=`kc:1A413030_107_0210:2`

4. 🟢 沿墙高每 `500mm` 设置拉结钢筋。  
   source=`kc:1A413030_107_0210:2`

推荐答法：

> 构造柱与砌体连接处应砌成马牙槎，马牙槎应先退后进；每个马牙槎沿高度方向尺寸不宜超过 300mm，凹凸尺寸宜为 60mm；沿墙高每 500mm 设置拉结钢筋。

### 题型 C：问“转角、交接处不能同时砌筑怎么办？”

满分骨架：

1. 🟢 转角及交接处原则上应同时砌筑。  
   source=`kc:1A413030_109_0213:3`；source=`kc:1A413030_109_0214:1`

2. 🟢 不能同时砌筑时，应留斜槎；轻骨料小砌块斜槎水平投影长度不应小于高度的 `2/3`。  
   source=`kc:1A413030_109_0214:1`

3. 🟢 空心砖墙交接处应上下错缝、咬槎搭砌，不得留直槎。  
   source=`kc:1A413030_109_0213:3`

推荐答法：

> 转角及纵横墙交接处应同时砌筑；不能同时砌筑时应留斜槎。轻骨料小砌块斜槎水平投影长度不应小于高度的 2/3。空心砖墙交接处应上下错缝、咬槎搭砌，不得留直槎。

### 题型 D：案例中同时出现“临时洞口 + 留槎/拉结”

满分骨架：

1. 🟢 临时施工洞口净宽不应超过 `1m`。  
   source=`kc:1A413030_106_0208:0`；真题锚=`2016年案例2`

2. 🟢 洞口侧边距交接处墙面不应小于 `500mm`。  
   source=`kc:1A413030_106_0208:0`；真题锚=`2016年案例2`

3. 🟢 宜设过梁或挑砖封口，预埋拉结筋。  
   source=`kc:1A413030_106_0208:0`

4. 🔵 不要把“临时施工洞口”答成“留直槎”；洞口控制的是净宽、距交接面、过梁/封口、拉结筋。

## R7 边界候选：满分 vs 压线 vs 0分 near-miss

> 以下为候选评分边界，全部需真人/专家裁决；不得直接作为最终判分规则。

| 场景 | 候选等级 | 候选判定 | 常见错因码 |
|---|---:|---|---|
| 答“抗震 8 度及以上应留斜槎，普通砖 ≥2/3，多孔砖 ≥1/2；非抗震直槎加拉结筋” | 🔴待真人/专家裁决 | 候选满分：条件、形式、尺寸、拉结筋完整。 | E03 / M08 |
| 只答“应留斜槎”，未写 8 度及以上、未写尺寸 | 🔴待真人/专家裁决 | 候选压线：方向正确，但缺少关键适用条件和数字采分。 | E02 / E03 |
| 把普通砖斜槎写成“水平投影 ≥ 高度 1/2” | 🔴待真人/专家裁决 | 候选压线或失分：斜槎方向对，但普通砖数字错，可能与多孔砖规则混淆。 | M08 / E07 |
| 答“抗震区可留直槎，加拉结筋即可” | 🔴待真人/专家裁决 | 候选 0 分或重扣：把非抗震直槎条件迁移到抗震设防 8 度及以上。 | E10 / E11 |
| 构造柱马牙槎答“先进后退” | 🔴待真人/专家裁决 | 候选 0 分或关键点失分：顺序与真题陷阱相反。 | E06 / E07 |
| 构造柱马牙槎答“先退后进”，但漏 300mm、60mm、500mm 拉结筋 | 🔴待真人/专家裁决 | 候选压线：抓住核心动作，但缺少尺寸和拉结筋采分。 | E02 / E03 / M08 |
| 只写“设置拉结筋”，未写马牙槎、先退后进 | 🔴待真人/专家裁决 | 候选低分：只命中连接构造的一部分，未命中构造柱马牙槎主干。 | E02 / E07 |
| 临时洞口答“净宽 1.2m 可以” | 🔴待真人/专家裁决 | 候选 0 分或重扣：与净宽不超过 1m 相反。 | M08 / E10 |
| 临时洞口只答“距交接面 ≥500mm”，漏净宽 ≤1m | 🔴待真人/专家裁决 | 候选压线：命中距离点，漏核心宽度点。 | E02 / E03 |

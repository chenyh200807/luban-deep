# K01 索赔成立与工期费用计算｜R5-R7 镜头

## R5 采分点：按“成立判断→工期→费用→程序证据→表达”分组

### 1. 先判索赔事件是否成立

| 采分点 | 得分要素 | 锚定 |
|---|---|---|
| 责任归因 | 写清“非承包人原因 / 发包人原因 / 不可抗力 / 承包人原因” | 🟢 教材：`kc:1A435000_046_0066:2` 承包人可因非承包人原因导致停工、返工、付款延迟等提出索赔 |
| 索赔对象 | 分别判断“工期索赔、费用索赔、利润索赔”，不要混写成一句“可索赔” | 🟢 教材：`kc:1A435000_046_0066:3` 发包人责任导致延误或变更时，可索赔费用、工期和利润 |
| 不可抗力分担 | 永久工程、已运至现场材料损坏及修复、第三方损失归发包人；承包人施工机具损坏等归承包人 | 🟢 教材：`kc:1A432000_047_0067:0`；🟢 真题：`2015案例1` 不可抗力中设备损失不得向建设单位索赔，清理修复费用可索赔 |
| 事件成立≠金额全成立 | 承认事件可索赔，也要剔除不应由对方承担的费用 | 🟢 真题：`2015案例1` E工作32.7万元中设备损失8.2万元不可索赔，清理修复24.5万元可索赔 |

常见错因码：`E05` 审题错误、`E08` 背景信息提取失败、`E10` 规范适用错误。

### 2. 工期索赔计算采分点

| 采分点 | 得分要素 | 锚定 |
|---|---|---|
| 关键线路判断 | 先判断延误工作是否在关键线路上 | 🟢 教材：`kc:1A432000_048_0068:1` 工期索赔取决于延误是否在关键线路 |
| 关键工作延误 | 关键线路工作延误多少，通常顺延多少 | 🟢 教材：`kc:1A432000_048_0068:1` |
| 非关键工作延误 | 延误≤总时差：不索赔工期；延误>总时差：只索赔超出总时差部分 | 🟢 教材：`kc:1A432000_048_0068:1` |
| 网络分析表达 | 写“比较延误前后网络计划工期变化”，而不是只看单项工作延误天数 | 🟢 教材：`kc:1A432000_049_0070:0` 网络分析法用于计算应顺延工期 |
| 真题算例锚 | C非关键、总时差1个月、延误2个月，对总工期影响1个月；E非关键、总时差4个月、延误3个月，不发生工期索赔 | 🟢 真题：`2015案例1` |

常见错因码：`E09` 计算错误、`E07` 概念混淆、`E05` 审题错误。

### 3. 费用索赔计算采分点

| 采分点 | 得分要素 | 锚定 |
|---|---|---|
| 费用成立基础 | 非承包人原因造成承包人经济损失或费用增加，可提出费用索赔 | 🟢 教材：`kc:1A435000_046_0066:2` |
| 费用计算方法 | 可用总费用法或分项法；案例题更常按人工、机械、管理费、清理修复费等分项列算 | 🟢 教材：`kc:1A432000_049_0070:1` |
| 不可抗力剔除项 | 承包人施工机具损坏、人员机械损失等不能转嫁给发包人 | 🟢 教材：`kc:1A432000_047_0067:0`；🟢 真题：`2015案例1` |
| 发包人责任利润 | 若为发包人原因导致延误或变更，费用之外还可考虑利润 | 🟢 教材：`kc:1A435000_046_0066:3` |
| 措施项目工期影响 | 工期实质性延长或缩短时，可按措施项目中期运行费用与合同工期折算 | 🟢 教材：`kc:1A435000_046_0066:1` |

常见错因码：`E09` 计算错误、`E10` 规范适用错误、`E02` 采分点遗漏。

### 4. 程序与证据采分点

| 采分点 | 得分要素 | 锚定 |
|---|---|---|
| 索赔通知 | 事件发生后按合同约定期限提交索赔意向通知；未约定为28天 | 🟢 教材：`kc:1A432000_048_0068:0` |
| 处理步骤 | 执行程序、发出通知、核实真实性、形成处理结果 | 🟢 教材：`kc:1A432002_031_0041:3` |
| 证据四性 | 真实性、全面性、法律效力、及时性 | 🟢 教材：`kc:1A432000_048_0069:0` |
| 常见证据 | 合同文本、来往信件、会谈纪要、进度记录、现场文件、照片、气候报告、验收报告等 | 🟢 教材：`kc:1A432000_048_0069:1` |

常见错因码：`E06` 程序顺序错误、`E03` 关键词缺失、`E02` 采分点遗漏。

## R6 答案骨架：满分作答模板

### 模板A：判断某事件能否索赔工期、费用、利润

1. **定性**：该事件属于`非承包人原因 / 发包人原因 / 不可抗力 / 承包人原因`，因此索赔责任应由`发包人 / 承包人 / 双方按规则分担`承担。  
   🟢 锚定：`kc:1A435000_046_0066:2`、`kc:1A432000_047_0067:0`

2. **工期**：先判断该工作是否位于关键线路。  
   - 若在关键线路上，延误时间影响总工期，可索赔相应工期。  
   - 若不在关键线路上，比较“延误时间”和“总时差”：延误未超过总时差，不索赔工期；超过总时差，只索赔超过部分。  
   🟢 锚定：`kc:1A432000_048_0068:1`

3. **费用**：若事件导致承包人实际经济损失，按分项法或总费用法计算；不可抗力中应剔除承包人自行承担的施工机具等损失。  
   🟢 锚定：`kc:1A432000_049_0070:1`、`kc:1A432000_047_0067:0`

4. **利润**：若为发包人责任事件或工程变更导致，可同时主张利润；若为不可抗力，一般不当然主张利润。  
   🟢 锚定：`kc:1A435000_046_0066:3`；🔵 工程通识：不可抗力按风险分担处理，利润不宜机械套用。

5. **程序证据**：承包人应在约定期限内提交索赔意向通知，未约定为28天，并提供具备真实性、全面性、法律效力和及时性的证据。  
   🟢 锚定：`kc:1A432000_048_0068:0`、`kc:1A432000_048_0069:0`

### 模板B：真题型计算表达

> 对C工作：C为非关键工作，总时差为1个月，延误2个月，超过总时差1个月，因此对总工期的实际影响为1个月；若题目主张索赔2个月，则该主张不完全成立，只能按影响总工期的1个月判断。费用方面，因设计变更属于非承包人原因，造成承包人经济损失，费用索赔成立。  
> 🟢 真题锚：`2015案例1`

> 对E工作：E为非关键工作，总时差为4个月，不可抗力导致延误3个月，未超过总时差，因此不发生工期索赔。费用方面，不可抗力导致的承包人设备损失由承包人承担；清理和修复费用可按规则向发包人主张。  
> 🟢 真题锚：`2015案例1`

## R7 边界：满分 vs 压线 vs 0分 near-miss

> R7以下均为候选边界，需真人/专家裁决后固化。🔴待验证。

### 边界1：非关键工作延误

| 档位 | 候选判定 |
|---|---|
| 满分 | 🔴 先写“非关键工作”，再写“总时差”，再写“延误是否超过总时差”，最后给出可索赔工期。 |
| 压线 | 🔴 只写“未影响总工期所以不索赔”，但未列出总时差和延误差值。 |
| 0分 near-miss | 🔴 直接把单项工作延误时间全部作为工期索赔，不看关键线路和总时差。 |

### 边界2：索赔成立与索赔金额

| 档位 | 候选判定 |
|---|---|
| 满分 | 🔴 区分“事件责任成立”和“金额项目是否可计入”，逐项剔除不应索赔费用。 |
| 压线 | 🔴 判断费用索赔成立，但未完整拆分人工、机械、修复、清理等费用构成。 |
| 0分 near-miss | 🔴 只要看到不可抗力或变更，就把所有损失全部判给发包人。 |

### 边界3：不可抗力费用

| 档位 | 候选判定 |
|---|---|
| 满分 | 🔴 写出永久工程、已运至现场材料、清理修复等可由发包人承担；承包人机具损坏等由承包人承担。 |
| 压线 | 🔴 只写“清理修复费用可索赔，设备损失不可索赔”，未展开责任规则。 |
| 0分 near-miss | 🔴 把承包人施工设备损失、机械停置损失全部列为向发包人索赔。 |

### 边界4：发包人责任事件

| 档位 | 候选判定 |
|---|---|
| 满分 | 🔴 发包人原因导致延误或变更时，分别判断工期、费用、利润，并说明依据。 |
| 压线 | 🔴 只写“可以索赔工期和费用”，漏写利润。 |
| 0分 near-miss | 🔴 把发包人延迟提供图纸、设计变更等误判为承包人自行承担。 |

### 边界5：程序证据

| 档位 | 候选判定 |
|---|---|
| 满分 | 🔴 写出索赔意向通知时限、书面报告、证据要求，并能联系题干材料。 |
| 压线 | 🔴 只写“应按合同程序提出索赔”，未写28天或证据四性。 |
| 0分 near-miss | 🔴 完全不提程序和证据，直接只算金额。 |

### 边界6：错因映射候选

| 错因码 | 适用表现 |
|---|---|
| `E05` | 🔴 未读清责任主体、事件原因、题目问“是否成立”还是“可索赔多少”。 |
| `E07` | 🔴 混淆关键工作、非关键工作、总时差、自由时差。 |
| `E09` | 🔴 延误超过总时差部分计算错误，或费用合计/剔除错误。 |
| `E10` | 🔴 不可抗力责任分担、发包人责任利润、索赔程序适用错误。 |
| `E02` | 🔴 漏答工期、费用、利润、程序证据中的关键采分点。 |

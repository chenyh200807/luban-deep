## S07｜R5 采分点：安全事故等级判定与上报

### 1. 事故性质/类型先定性

- 🟢锚定｜建筑业常见职业伤害事故包括：高处坠落、物体打击、机械伤害、触电、坍塌、起重伤害、火灾、中毒和窒息等 12 类。  
  source=`kc:1A436000_129_0207:0`

- 🟢锚定｜建筑安全事故按原因及性质可分为：生产事故、质量问题、技术事故、环境事故。  
  source=`kc:1A436000_128_0206:0`

- 🔵工程通识｜案例题中先识别“发生了什么事故”，再进入“按死亡、重伤、直接经济损失判等级”，避免把事故类型直接当事故等级。

### 2. 事故等级三指标判定

- 🟢锚定｜事故等级依据死亡人数、重伤人数或直接经济损失划分。  
  source=`kc:1A436000_129_0207:1`

- 🟢锚定｜特别重大事故：死亡人数 ≥30 人，或重伤人数 ≥100 人，或直接经济损失 ≥1 亿元。  
  source=`kc:1A436000_129_0207:1`

- 🟢锚定｜重大事故：死亡人数 10-30 人，或重伤人数 50-100 人，或直接经济损失 5000 万-1 亿元。  
  source=`kc:1A436000_129_0207:1`

- 🟢锚定｜较大事故：死亡人数 3-10 人，或重伤人数 10-50 人。  
  source=`kc:1A436000_129_0207:1`

- 🔴待验证｜较大事故的直接经济损失区间、一般事故的完整判定阈值，需要对教材原文或法规全文复核；当前给定 quote 被截断，不能冒充 🟢。

- 🔵工程通识｜三项指标“死亡 / 重伤 / 直接经济损失”任一达到较高等级，即按较高等级判定，不做平均、不取最低。

### 3. 事故伤亡变化补报

- 🟢锚定｜自事故发生之日起 30 天内，事故造成的伤亡人数发生变化的，应当及时补报。  
  真题锚=`2015 第19题`

- 🔵工程通识｜上报类题目常考“时间节点 + 报告动作 + 变化后补报”，答题时必须把“30 天内伤亡变化”与“及时补报”连在一起写。

### 4. 责任处理与调查主体

- 🟢锚定｜事故责任人的处理建议应由事故调查组提交，由负责调查事故的人民政府作出批复，事故发生单位按批复处理责任人员。  
  真题锚=`2015 案例3`

- 🟢锚定｜事故调查组还应有公安机关、劳动保障行政部门、工会和人民检察院派员参加。  
  真题锚=`2015 案例3`

- 🔵工程通识｜“施工单位自行处理责任人”是常见扣分点；规范答法要体现调查组、政府批复、单位执行三层关系。

### 5. 易错点归因码

- 🟢锚定｜E08 背景信息提取失败：漏看死亡人数、重伤人数、经济损失、伤亡变化时间。  
  source=`deeptutor/contracts/error_codes.py`

- 🟢锚定｜E09 计算错误：人数或金额阈值比较错误。  
  source=`deeptutor/contracts/error_codes.py`

- 🟢锚定｜E10 规范适用错误：把事故类型、隐患等级、事故等级混用。  
  source=`deeptutor/contracts/error_codes.py`

- 🟢锚定｜E06 程序顺序错误：先处理责任人、后调查批复，或漏写补报程序。  
  source=`deeptutor/contracts/error_codes.py`

## S07｜R6 答案骨架：满分要点

### 模板 A：事故等级判定题

1. 🟢锚定｜先列三项判定指标：死亡人数、重伤人数、直接经济损失。  
   source=`kc:1A436000_129_0207:1`

2. 🟢锚定｜逐项代入题干数据，与等级阈值比较：特别重大、重大、较大。  
   source=`kc:1A436000_129_0207:1`

3. 🔵工程通识｜三项指标中只要有一项达到更高等级，就按更高等级确定事故等级。

4. 🔵工程通识｜结论句写成：“本事故属于××事故，理由是××指标达到××事故标准。”

5. 🔴待验证｜若题干落在“一般事故”或“较大事故经济损失区间”，需补核教材完整阈值后再给最终等级。

3. 🟢锚定｜动作：应当及时补报。

## S07｜R7 边界：满分 vs 压线 vs 0分 near-miss

> R7 为候选判分边界，全部标记为 🔴待真人/专家裁决。

### 边界 1：事故等级判定

- 🔴待真人/专家裁决｜满分候选：写出死亡人数、重伤人数、直接经济损失三项指标，逐项代入，并按最高等级给出明确结论。

- 🔴待真人/专家裁决｜压线候选：只写出最终等级和一个关键指标，例如“死亡 12 人，属重大事故”，但未完整展开三指标比较。

- 🔴待真人/专家裁决｜0 分 near-miss：只写“属于安全事故 / 属于坍塌事故 / 属于生产事故”，没有判定事故等级。

- 🔴待真人/专家裁决｜0 分 near-miss：把“重大事故隐患”直接等同于“重大事故”，未依据实际伤亡或经济损失判定。

### 边界 2：阈值表达

- 🔴待真人/专家裁决｜满分候选：阈值数字准确，且能说明“死亡、重伤、直接经济损失任一达到即按该等级”。

- 🔴待真人/专家裁决｜压线候选：阈值数字写对主要区间，但边界符号表述不严谨，如把“10-30 人”写成“10 人以上 30 人以下”但未说明是否含 30。

- 🔴待真人/专家裁决｜0 分 near-miss：用模糊词替代规范阈值，如“死很多人就是重大事故”“经济损失很大就是特别重大”。

### 边界 3：伤亡变化补报

- 🔴待真人/专家裁决｜满分候选：写出“自事故发生之日起 30 天内 + 伤亡人数发生变化 + 及时补报”。

- 🔴待真人/专家裁决｜压线候选：写出“30 天内补报”，但未明确补报触发条件是伤亡人数变化。

- 🔴待真人/专家裁决｜0 分 near-miss：写成“7 天 / 14 天 / 15 天内补报”。

- 🔴待真人/专家裁决｜0 分 near-miss：只写“及时报告”，没有写补报期限或伤亡变化条件。

### 边界 4：事故责任处理

- 🔴待真人/专家裁决｜满分候选：指出施工单位自行处理不妥，并写清“事故调查组建议 → 政府批复 → 单位按批复处理”。

- 🔴待真人/专家裁决｜压线候选：只写“应由政府处理 / 应由调查组处理”，程序链条不完整。

- 🔴待真人/专家裁决｜0 分 near-miss：认为事故单位可以自行处分责任人，或只追究直接责任人、不追究领导责任。

### 边界 5：常见错因码映射

- 🔴待真人/专家裁决｜E08 背景信息提取失败：漏看题干中的死亡人数、重伤人数、经济损失或“伤亡人数发生变化”。

- 🔴待真人/专家裁决｜E09 计算错误：人数、金额达到等级阈值，但比较错误。

- 🔴待真人/专家裁决｜E10 规范适用错误：把事故类型、事故原因分类、事故隐患、事故等级混为一谈。

- 🔴待真人/专家裁决｜E06 程序顺序错误：责任处理程序或补报程序前后颠倒、主体错置。

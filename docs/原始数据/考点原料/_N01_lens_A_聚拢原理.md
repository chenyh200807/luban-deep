## 原理因果层
> 从定义出发，逐层推出“判断→行动→索赔”的完整决策链。

### 成因层：为什么要定义“总时差最小”？
- 总时差是工作可以延误而不影响总工期的最大时间储备。
- **关键路径**是网络计划中最长的路径，决定了总工期。
- 关键路径上的工作，其延误会直接吃掉总工期，所以它们的时间储备（总时差）必定是整个网络中最小的。
- 🟢 教材锚：`1A433000_056_0085:1`
- 🟢 证据：2015年案例1中C工作总时差1个月，延误2个月仅影响总工期1个月——因为C不是关键工作，它“吞掉”了自己的时差后才影响到关键线路。

### 机理层：为什么延误时长与总时差比较，就能定索赔？
- **责任归属+时差吸收**：
  1. 先判断延误发生在哪条线路上。
  2. 若延误发生在线路L上，L的总时差为TF_L。
  3. 当实际延误d ≤ TF_L，线路L仍可在原计划工期内完成，不改变关键线路，不造成总工期延误 → 工期索赔不成立（但费用可能成立）。
  4. 当d > TF_L，超出部分才会真正导致总工期延长 → 工期索赔以超出部分计算。
- 🟢 证据：
  - 2018-案例分析(二)：甲供电缆导致安装推迟1月，但电缆安装有**3个月总时差**，1月＜3月 → **不影响总工期** → 工期索赔不成立。
  - 2015-案例1：C工作总时差1月，延误2月，超出的1月导致总工期延长 → 工期索赔仅1月。

### 为什么“关键工作调整”是措施首选？
- 当你发现进度滞后（如🟢2017案例一：滞后5天），唯一能缩短总工期的方法，就是压缩**关键线路**上工作的持续时间。
- 如果压缩非关键工作，只能增加其自身时差，对总工期没有贡献（直至它变成关键工作）。
- 选择具体压缩对象时，经济性原则（费用优化）介入：在关键线路上选择**赶工费率最低**的工作优先压缩（🔵工程通识）。
- 压缩后可能产生新的关键线路，必须重新计算（🔵工程通识），这就是为什么进度控制是个迭代过程（🟢教材锚：7个阶段）。

### 主线串讲（讲给学生）
> **记住这条决策链：**
> 1. **算**：画出网络图，标时间，算出总工期和每个工作的总时差。
> 2. **判**：总时差最小的→关键工作；关键工作连起来→关键线路。
> 3. **查**：进度检查发现滞后，看滞后的工作在不在关键线路上，它的总时差是否被吃光。
> 4. **动**：要救工期，只能压缩关键线路上的工作（先挑成本低的）。
> 5. **赔**：索赔看两点——谁的责任？延误时间是否超过总时差？超了才赔工期，不超只谈钱（费用索赔）。

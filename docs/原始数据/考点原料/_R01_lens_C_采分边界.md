## R6 答案骨架：满分要点

### 题型一：问“施工现场消防布置是否妥当/指出不妥并改正”

**答题骨架：**

1. 先判定不妥项：消防通道、水源、消防设施、灭火器材、明显标志、消防安全责任人是否缺失或设置错误。  
   🟢 `ca:1A436000_101_0166`；真题锚：2016案例5

2. 再写正确做法：现场安全管理应包含消防管理、应急准备和资料记录。  
   🟢 `kc:1A436000_101_0166:0`

3. 灭火器配置按场所面积写数字：  
   - 临时建筑每100㎡配2只10L灭火器；  
   - 木料间、油漆间等每25㎡配1只灭火器；  
   - 大型临时设施超1200㎡设太平桶、积水池、黄砂池。  
   🟢 `kc:1A437000_146_0233:0`

4. 灭火器安装写高度和摆放：顶部离地≤1.50m，底部≥0.15m，明显位置、铭牌朝外、正面竖直。  
   🟢 `kc:1A437000_146_0234:0`

5. 禁设禁用项单列：高压线下不得搭临建或堆可燃物；施工现场严禁吸烟；工程内不得设宿舍；禁用液化石油气钢瓶；在建工程内不得存放氧气瓶、乙炔瓶。  
   🟢 `kc:1A437000_145_0231:2`；`kc:1A437000_146_0232:0`

**常见错因码：**  
- `E02 采分点遗漏`：只写“加强消防管理”，漏写器材、通道、水源、标志、责任人。  
- `E03 关键词缺失`：漏“当日有效”“重新办理”“25㎡”“1.50m”等得分词。  
- `E04 口号化表达`：只写“按规范配置灭火器”，没有数量、高度、位置。  
- `E10 规范适用错误`：把电石火灾写成用水或泡沫灭火。  
- `M08 规范数字混淆`：25㎡、100㎡、1.50m、0.15m、10m、30m混淆。  

### 题型二：问“动火作业是否符合规定/审批流程是什么”

**答题骨架：**

1. 先识别动火等级：禁火区、油罐、受压设备、登高焊、密封空间、大量可燃物为一级动火；非禁火区临时焊割、小型油箱、登高焊为二级动火；无明显危险因素为三级动火。  
   🟢 `kc:1A437000_144_0230:0`

2. 再写审批主体：  
   - 一级动火：项目负责人组织编制方案，报企业安全部门审批；  
   - 二级动火：责任工程师拟定措施，项目安全部门和项目负责人审批；  
   - 三级动火：班组填写申请，责任工程师和安全部门审批。  
   🟢 `kc:1A437000_145_0231:0`

3. 写动火证有效性：动火证当日开具、当日有效；动火地点变化，应重新办理审批手续。  
   🟢 `kc:1A437000_145_0231:1`；真题锚：2015第30题

4. 写未审批结论：焊接作业前未办理动火审批手续，不符合规定；违反“无审批不烧”。  
   🟢 `kc:1A437000_147_0237:0`；`ca:1A437000_147_0237`

5. 补现场检查：持证、审批、了解现场和内部、容器清洗、防护、压力、易燃物、交叉作业、外部危险均需检查；不满足则不得焊割。  
   🟢 `kc:1A437000_147_0237:0`

**常见错因码：**  
- `E06 程序顺序错误`：先动火后补证，或先施工后审批。  
- `E07 概念混淆`：把一级、二级、三级动火审批主体混在一起。  
- `E10 规范适用错误`：把动火地点变化理解为原证继续有效。  
- `M10 用常识替代规范判断`：认为“现场有人看着就可以动火”，漏审批和动火证。

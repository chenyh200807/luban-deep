## R2 不变量（一句话）

> 当题干「某工程 + 屋面/地下/室内防水 + 防水等级/设防道数/构造层次/接缝设防/结构自防水」时，判分主线沿「**先定部位与等级（屋面看一二三级、地下看四级 + 是否甲级/复杂）→再查设防道数（屋面一级≥3道·卷材≥1道；地下一级≥3道·防水混凝土1道应选·外设≥2道）→再查构造层次顺序（找坡/找平/隔汽/防水/保温/保护/排水的上下相邻关系；倒置式=保温在防水之上）→再查关键数值（抗渗P6/P8·试配提高0.2MPa·隔汽高出保温≥150mm·室内翻起≥2000/1200/250mm·施工缝高出底板≥300mm·止水条最终膨胀率≥220%）→再查接缝防水设防种数（施工缝≥2种·后浇带≥1种）**」推进（**教学启发式骨架，🔵；非每题跑满，按题面命中环节裁决**）。出题人考的是「**等级↔道数对不对 + 构造层次顺序是否正确 + 关键数值是否准 + 设防种数是否够**」，不考防水材料的化学配方或卷材搭接施工工艺（那是 F02 卷材施工 territory）。

换言之：判分核心 = **设防等级与道数（屋面一/二/三级=≥3/≥2/≥1道、卷材≥1道；地下四级；地下一级≥3道·防水混凝土1道·外设≥2道·P8）+ 构造层次自下而上顺序（结构层→找坡→找平→防水→保温→保护；倒置式保温在防水之上；种植屋面10层）+ 关键数值（抗渗、隔汽≥150mm、室内翻起≥2000mm、施工缝≥300mm、止水条≥220%）+ 接缝设防种数**。任一环错即「不妥/错误」。

1. **地下工程防水等级分级** —— 地下工程防水等级分**四级**（一级不允许渗水/二级不允许漏水可有少量湿渍/三级有少量漏水点/四级有漏水点，均不得有线流漏泥砂）。
   🟢 真题锚 `{2019,第12题}`（直读：单选 ans=C 四级；A二级/B三级/D五级错）。注意：屋面防水等级是**三级**（一/二/三），地下是**四级**——两者分级数不同，是经典埋点。

2. **倒置式屋面构造层次自下而上顺序** —— ①结构层→④找坡层→⑤找平层→⑥防水层→②保温层→③保护层（口诀「结构找坡再找平，防水保温后保护」）。倒置式特征=**保温层在防水层之上**（保护防水层、延寿）。
   🟢 真题锚 `{2020,第12题}`（直读：单选 ans=B ①④⑤⑥②③；解析口诀「结构找坡再找平，防水保温后保护」）。

3. **屋面防水等级与设防道数** —— 平屋面一级≥3道（卷材≥1道）、二级≥2道（卷材≥1道）、三级≥1道（可任选卷材/涂料）；屋面防水以防为主以排为辅、设计年限≥20年、泛水部位设附加层。
   🟢 教材锚 `kc:1A413030_122_0230:0`、`kc:1A413030_122_0230:2`。

4. **地下一级防水做法与抗渗** —— 明挖法地下一级：防水做法≥3道、防水混凝土1道（应选）、外设防水层≥2道（卷材或涂料≥1道）、抗渗≥P8；三级：≥1道、防水混凝土1道（应选）、外设不作要求、抗渗≥P6。
   🟢 教材锚 `kc:1A413030_130_0247:0`、`kc:1A413030_130_0247:1`。

5. **接缝防水设防种数** —— 施工缝防水设防≥2种、后浇带≥1种（中埋式止水带/遇水膨胀止水条胶/预埋注浆管/外贴卷材外涂涂料/补偿收缩混凝土等）；施工缝水平缝设在高出底板≥300mm、止水条最终膨胀率≥220%。
   🟢 教材锚 `kc:1A413030_130_0248:0`、`kc:1A413030_130_0248:1`、`kc:1A413030_131_0250:0`、`kc:1A413030_131_0250:1`。

   🟢 教材锚 `kc:1A413030_130_0249:0`、`kc:1A413030_130_0249:1`。

7. **室内防水构造（翻起高度）** —— 淋浴区墙面翻起≥2000mm、盥洗用水处≥1200mm、其他泛水≥250mm；管道根部密封、套管高出装饰面≥20mm。
   🟢 教材锚 `kc:1A413030_133_0256:0`、`{2023,第22题}`（墙体防水防潮规定 ans=ABCD，迎水面设防潮/防水措施）。

## examiner_intent（出题人意图，按真题命中频次排序）

出题人在这个考点上**几乎不考防水材料配方/卷材施工工艺，只考"等级↔道数、构造层次顺序、关键数值、设防种数"**。三层意图：

- **意图① 抓「设防等级与道数（屋面三级/地下四级、几道防水）」(客观题·辨析/纠错) —— 高频主力。**
  给防水等级分级数或某级对应道数选对错。埋点：把屋面"三级"说成"四级"或把地下"四级"说成"二/三级"（`{2019,第12题}`地下四级=C）；把一级"≥3道"写成"≥2道"或漏"卷材≥1道"；把地下一级"防水混凝土1道应选+外设≥2道"记错。
  🟢 锚：`{2019,第12题}`(C)、`kc:1A413030_122_0230:0`、`kc:1A413030_130_0247:0`。

- **意图② 抓「构造层次自下而上顺序」(客观题·排序) —— 高频主力。**
  给构造层从下到上排序选对错。埋点：倒置式屋面把"保温层在防水层之上"写反成正置式（保温在防水之下）；种植屋面层次漏耐根穿刺层或排错。
  🟢 锚：`{2020,第12题}`(B 倒置式 ①④⑤⑥②③)、`kc:1A413030_127_0240:1`(种植屋面10层)。

- **意图③ 抓「接缝防水设防种数 + 关键数值（抗渗/隔汽/翻起高度/止水条）」(客观题+案例·辨析) —— 案例侧主力。**
  给施工缝/后浇带设防种数、抗渗等级、室内翻起高度选对错。埋点：施工缝"≥2种"写成"≥1种"；P8试配不提高0.2MPa；淋浴区翻起写1800mm（应≥2000mm）；隔汽层位置错（写在防水层上）。
  🟢 锚：`kc:1A413030_130_0248:0`、`kc:1A413030_130_0249:0`、`kc:1A413030_133_0256:0`、`{2023,第22题}`(墙体防水ABCD)。

> **一句话**：出题人把防水构造当成"**等级×道数×层次顺序×数值×种数**"五类记忆过滤器——等级用"屋面三级/地下四级"卡，道数用"一级≥3道·卷材≥1道·地下外设≥2道"卡，层次用"倒置式保温在防水上/种植10层"卡，数值用"P6/P8·提0.2MPa·隔汽≥150mm·翻起≥2000mm·施工缝≥300mm·止水条≥220%"卡，种数用"施工缝≥2种·后浇带≥1种"卡。

## R6｜答案骨架

### 题型一：问“材料进场验收怎么做 / 是否需要复验或见证取样”

满分骨架：

1. 🟢先做进场验收：核查合格证等质量证明文件，检查品种、型号、规格、数量、外观，挂牌标识并建立收料台账。  
   source=`kc:1A438000_150_0241:0`

2. 🟢涉及主要材料、安全、节能、环保的材料，应按规定进场检验 / 复验，并经监理认可；关键试块、试件应见证检验。  
   source=`kc:1A438000_151_0243:0`

3. 🟢按材料类型写复验项目：钢筋写屈服强度、抗拉强度、伸长率、弯曲性能、重量偏差；水泥写胶砂强度、氯离子含量、安定性、凝结时间；预拌混凝土写坍落度、抗压强度、抗渗等级等。  
   source=`kc:1A438000_152_0245:0` / `:1` / `:4`

4. 🟢复验或审批合格后方可使用；不合格材料不得擅自使用，应按流程退场、记录确认或按规定处理。  
   source=`kc:1A438000_153_0246:0` / `kc:1A438000_150_0241:2`

5. 🟢若题干是成型钢筋，补一句：成型钢筋进场可不检验弯曲性能。  
   真题锚=`2016第17题`

### 题型二：问“哪些属于隐蔽工程验收内容 / 如何组织答题”

满分骨架：

1. 🟢先判断工程类别，不要只写“隐蔽工程要验收”。装饰装修可写龙骨隔墙、地垄墙钢筋绑扎、石材钢骨架焊接、隔墙岩棉、饰面基层、卫生间防水、吊顶暗龙骨、明龙骨。  
   source=`kc:1A434020_085_0138:0`

2. 🟢若是屋面节能，写基层及表面处理、保温材料种类 / 厚度 / 敷设方法 / 缝隙填充、热桥处理、隔汽层。  
   source=`kc:1A422000_049_0075:0`

3. 🟢若是地面节能，写基层及表面处理、保温材料种类和厚度、保温材料粘结、地面热桥部位处理。  
   source=`kc:1A422000_049_0075:1`

4. 🟢若题干出现新型保温材料或节能分部，应写质量证明文件、进场复验报告，且复验为见证取样送检。  
   真题锚=`2015案例2`

5. 🔵工程通识表达：隐蔽部位应在被后续工序覆盖前完成验收、记录和确认；答案要落到“验什么 + 谁认可 + 形成什么资料”，不能只写“检查合格”。

### 题型三：问“指出不妥 / 改正”

高分句式：

> 🟢不妥：材料仅有合格证即投入使用。  
> 正确：进场应核查凭证并现场验证，涉及安全、节能、环保的材料还应复验并经监理认可，合格后方可使用。  
> source=`kc:1A438000_153_0246:0` / `kc:1A438000_151_0243:0`

> 🟢不妥：把保温材料进场检查写成普通外观检查。  
> 正确：应核查质量证明文件及进场复验报告，复验应为见证取样送检，并复验导热系数、密度、抗压强度或压缩强度等。  
> 真题锚=`2015案例2`

> 🟢不妥：成型钢筋进场一律要求弯曲性能复验。  
> 正确：普通钢筋复试含弯曲性能，但成型钢筋进场可不检验弯曲性能。  
> source=`kc:1A438000_152_0245:0`；真题锚=`2016第17题`

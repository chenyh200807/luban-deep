## R2 不变量（一句话）

> 凡砌体临时间断或墙柱交接，都必须用「**能同时砌就同时砌 → 不能同时砌就留斜槎(抗震8度及以上必斜槎/普通砖水平投影≥2/3·多孔砖长高比≥1/2) → 有构造柱就砌马牙槎(先退后进/≤300mm/凹凸60mm/沿墙高500mm拉结钢筋) → 临时洞口受限(净宽≤1m/距交接面≥500mm/预埋拉结筋)**」把"断口/交接"从薄弱通缝变成咬合节点。出题人永远在考「**该不该留直槎 / 斜槎够不够长 / 马牙槎方向对不对 / 构造柱施工顺序对不对 / 洞口留得合不合规**」，不考砌体配合比设计或材料强度等级本身。

换言之：判分核心 = **留槎形式对不对(斜/直) + 斜槎尺寸够不够 + 马牙槎方向与尺寸对不对 + 构造柱"先砌墙后浇柱"顺序对不对 + 临时洞口净宽/距交接面达不达标**，五者任一错即「不妥」。

## ≥5 场景印证（每条带已核真锚）

1. **构造柱马牙槎方向(MCQ高频陷阱)** —— 「马牙槎从每层柱脚开始先进后退」是错的；正确=先退后进。
   🟢 真题锚 `{2015,第12题}`(直读 correct_answer=B，解析明示「马牙槎从每层柱脚开始，应先退后进」)；教材锚 `kc:1A413030_107_0210:2`。

2. **构造柱施工顺序(MCQ·先砌墙后浇柱)** —— 设构造柱的抗震多层砖房，顺序=先绑构造柱钢筋→砌砖墙→后浇筑混凝土。
   🟢 真题锚 `{2020,第11题}`(直读 correct_answer=C，解析「先绑钢筋，再砌砖墙，最后浇砼」)；与 `{2018,第11题}`(解析「先绑构造柱钢筋，后砌砖墙，最后浇筑混凝土」+「砖柱不得采用包心砌法砌筑」)互证。

3. **填充墙/小砌块咬槎与搭接(案例·指错)** —— 小砌块龄期≥28d、搭接长度1/2(非1/3)、竖向灰缝饱满度≥90%、填充墙梁下3皮砖待下部砌完14d后顶砌。
   🟢 真题锚 `{2016,案例2}`(直读 correct_answer 五项不妥逐条改正)；教材锚 `kc:1A413030_108_0211:0`、`kc:1A413030_109_0212:*`、`kc:1A434000_067_0100:0`(饱满度·验收外延)。

4. **临时施工洞口(案例·指错)** —— 净宽1.2m=不妥(应≤1m)；侧边距交接处墙面应≥500mm。
   🟢 真题锚 `{2016,案例2}`(直读 correct_answer「洞口净宽度不应超过1米…侧边离交接处墙面不应小于500毫米」)；教材锚 `kc:1A413030_106_0208:0`(=注册表 supporting G01 同卡)。

5. **斜槎/直槎留置规则(教材主轴·案例常综合考)** —— 8度及以上须斜槎，普通砖斜槎水平投影≥高2/3，多孔砖长高比≥1/2；非抗震可直槎但加拉结筋；空心砖/轻骨料砌块交接同时砌筑不能时留斜槎(≥2/3高)。
   🟢 教材锚 `kc:1A413030_107_0210:1`、`kc:1A413030_109_0213:3`、`kc:1A413030_109_0214:1`(证据包内2016案例2含洞口/砌块但未单独命斜槎独立单问，斜槎尺寸作教材🟢，真题侧以综合案例承载)。

> 不变量验证：5 场景全部回到「同时砌→斜槎→马牙槎→洞口」同一咬合逻辑链，不变量成立。

## R4 变量规则（封闭——可枚举、可判分、不外溢）

**规则组 A：留槎形式(封闭判据)** — 锚 `kc:1A413030_107_0210:1`、`kc:1A413030_109_0213:3`、`kc:1A413030_109_0214:1`。

| 情形 | 封闭做法 | 判分边界 |
|---|---|---|
| 抗震8度及以上 | 必留斜槎 | 留直槎 = 不妥 |
| 普通砖斜槎 | 水平投影≥高度2/3 | <2/3 = 不妥 |
| 多孔砖斜槎 | 长高比≥1/2 | <1/2 = 不妥 |
| 轻骨料砌块斜槎 | 水平投影≥高度2/3 | <2/3 = 不妥 |
| 非抗震直槎 | 可直槎但须加拉结筋 | 直槎不加拉结筋 = 不妥 |
| 空心砖交接 | 同时砌筑不得留直槎；斜槎高≤1.2m | 留直槎/斜槎>1.2m = 不妥 |

**规则组 B：构造柱马牙槎(封闭尺寸)** — 锚 `kc:1A413030_107_0210:2` + `{2015,第12题}`。

| 变量 | 封闭取值 | 判分边界 |
|---|---|---|
| 进退方向 | 先退后进 | 先进后退 = 不妥(真题陷阱) |
| 高度尺寸 | 每个沿高≤300mm | >300mm = 不妥 |
| 凹凸尺寸 | 宜60mm | 偏离 = 不妥 |
| 拉结钢筋 | 沿墙高每500mm设置 | 漏设/间距>500mm = 不妥 |

**规则组 C：构造柱施工顺序(封闭有序)** — 锚 `{2020,第11题}`、`{2018,第11题}`。
绑构造柱钢筋 → 砌砖墙(马牙槎) → 后浇筑构造柱混凝土("先砌墙后浇柱")；砖柱不得包心砌法。顺序颠倒(先砌墙后绑钢筋/先浇柱后砌墙) = 不妥。

**规则组 D：临时施工洞口(封闭阈值)** — 锚 `kc:1A413030_106_0208:0`(G01) + `{2016,案例2}`。

| 变量 | 封闭取值 | 判分边界 |
|---|---|---|
| 净宽 | ≤1m | 1.2m 等 = 不妥 |
| 距交接面 | ≥500mm | <500mm = 不妥 |
| 封口 | 宜设过梁或挑砖封口 | 不封口 = 不妥 |
| 拉结筋 | 预埋拉结筋 | 漏埋 = 不妥 |
| 9度抗震 | 须设计确认 | 自留 = 不妥 |

> **封闭性自检**：A~D 四组取值域均来自具体 point_id 的枚举/阈值，无连续无界参数；判分边界全部可机械裁决。规则封闭成立。

> **本体边界声明（coarse_review 提醒）**：C06 判分轴 = 留槎(斜/直)+斜槎尺寸+马牙槎方向尺寸+构造柱顺序+洞口阈值，归砌体结构工程施工腹地(编译库 `1A413042-*` 系列)。注册表 canonical primary `1A413081`(砖砌体)/`1A413083`(填充墙) 是**块体材料层**节点(名义对应材料而非施工留槎做法)，缺精确"留槎/构造柱"叶子 → 标 coarse_review·needs_leaf_review·不进学员默认入口。砂浆饱满度(80%/90%)属 A01 验收主控项目 territory(标🔵验收外延)；填充墙裂缝防治(2φ6@500mm/14d)属 Q03 通病 territory(标🔵外延)，二者均非 C06 留槎主采分点。

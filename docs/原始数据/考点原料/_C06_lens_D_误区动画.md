# 镜头：C06 砌体留槎与构造柱

## 误区解析
### 误区1: 斜槎长度不足
- **现象**：在抗震设防烈度8度及以上地区，临时断处斜槎长度不符合要求。
- **错误心智模型**：认为斜槎长度可以随意设置，不影响结构安全。
- **对症解药**：严格按照规范要求，普通砖斜槎水平投影长度应≥高度的2/3，多孔砖斜槎长高比≥1/2。[[kc:1A413030_107_0210:1](#kc:1A413030_107_0210:1)]
- **错因码**：E05（规范理解偏差）

### 误区2: 构造柱马牙槎尺寸不当
- **现象**：构造柱与砌体连接处马牙槎尺寸不符合要求。
- **错误心智模型**：认为马牙槎尺寸可以随意调整，不影响结构稳定性。
- **对症解药**：每个马牙槎沿高度方向尺寸不宜超过300mm，凹凸尺寸宜为60mm。[[kc:1A413030_107_0210:2](#kc:1A413030_107_0210:2)]
- **错因码**：E05（规范理解偏差）

### 误区3: 灰缝宽度不达标
- **现象**：灰缝宽度不在规定范围内。
- **错误心智模型**：认为灰缝宽度可以随意调整，不影响砌体质量。
- **对症解药**：灰缝宽度宜为10mm，且不应小于8mm，也不应大于12mm。[[kc:1A413030_107_0210:0](#kc:1A413030_107_0210:0)]
- **错因码**：E05（规范理解偏差）

### 误区4: 临时施工洞口设置不当
- **现象**：临时施工洞口净宽超过1m或距交接面不足500mm。
- **错误心智模型**：认为临时施工洞口设置可以随意，不影响结构安全。
- **对症解药**：临时施工洞口净宽≤1m，距交接面≥500mm；9度抗震区须设计确认。[[kc:1A413030_106_0208:0](#kc:1A413030_106_0208:0)]
- **错因码**：E05（规范理解偏差）

### 误区5: 砌筑顺序错误
- **现象**：砌体施工时未遵循正确的砌筑顺序。
- **错误心智模型**：认为砌筑顺序可以随意调整，不影响结构稳定性。
- **对症解药**：低处先砌、高处搭接、搭接长度≥高差、转角交接同步、出檐后砌、高差大者先砌。[[kc:1A413030_106_0204:0](#kc:1A413030_106_0204:0)]
- **错因码**：E05（规范理解偏差）

### 误区6: 皮数杆设置间距过大
- **现象**：皮数杆设置间距超过15m。
- **错误心智模型**：认为皮数杆设置间距可以随意调整，不影响砌体质量。
- **对症解药**：皮数杆应在墙的转角和交接处设置，间距不宜大于15m。[[kc:1A413030_106_0206:0](#kc:1A413030_106_0206:0)]
- **错因码**：E05（规范理解偏差）

### 误区7: 砌体质量检查不及时
- **现象**：砌体施工中未及时检查垂直度、平整度、灰缝厚度、砂浆饱满度。
- **错误心智模型**：认为这些项目可以在后期进行校正，不影响最终质量。
- **对症解药**：砌体施工中应随时检查垂直度、平整度、灰缝厚度、砂浆饱满度，并在砂浆终凝前校正。[[kc:1A413030_106_0207:0](#kc:1A413030_106_0207:0)]
- **错因码**：E05（规范理解偏差）

### 误区8: 施工脚手眼设置位置不当
- **现象**：施工脚手眼设置在禁止部位。
- **错误心智模型**：认为施工脚手眼可以随意设置，不影响结构安全。
- **对症解药**：施工脚手眼不得设置在120mm厚墙、清水墙、料石墙、独立柱、过梁三角区、窗间墙<1m、门窗洞口旁、梁下500mm、轻质墙、夹心墙外叶等部位。[[kc:1A413030_106_0209:0](#kc:1A413030_106_0209:0)]
- **错因码**：E05（规范理解偏差）

### 旁白锚点
- **斜槎长度**：在抗震设防烈度8度及以上地区，临时断处应砌成斜槎，普通砖斜槎水平投影长度 ≥ 高度的2/3；多孔砖斜槎长高比 ≥ 1/2。[[kc:1A413030_107_0210:1](#kc:1A413030_107_0210:1)]
- **马牙槎尺寸**：构造柱与砌体连接处应砌成马牙槎，先退后进，每个马牙槎沿高度方向尺寸不宜超过300mm，凹凸尺寸宜为60mm。[[kc:1A413030_107_0210:2](#kc:1A413030_107_0210:2)]
- **灰缝宽度**：烧结砖砌体施工中，灰缝宽度宜为10mm，且不应小于8mm，也不应大于12mm。[[kc:1A413030_107_0210:0](#kc:1A413030_107_0210:0)]
- **临时施工洞口**：临时施工洞口净宽≤1m，距交接面≥500mm；9度抗震区须设计确认。[[kc:1A413030_106_0208:0](#kc:1A413030_106_0208:0)]
- **砌筑顺序**：砌体施工应遵循：低处先砌、高处搭接、搭接长度≥高差、转角交接同步、出檐后砌、高差大者先砌。[[kc:1A413030_106_0204:0](#kc:1A413030_106_0204:0)]
- **皮数杆设置**：皮数杆应在墙的转角和交接处设置，间距不宜大于15m。[[kc:1A413030_106_0206:0](#kc:1A413030_106_0206:0)]
- **质量检查**：砌体施工中应随时检查垂直度、平整度、灰缝厚度、砂浆饱满度，并在砂浆终凝前校正。[[kc:1A413030_106_0207:0](#kc:1A413030_106_0207:0)]
- **脚手眼设置**：施工脚手眼不得设置在120mm厚墙、清水墙、料石墙、独立柱、过梁三角区、窗间墙<1m、门窗洞口旁、梁下500mm、轻质墙、夹心墙外叶等部位。[[kc:1A413030_106_0209:0](#kc:1A413030_106_0209:0)]

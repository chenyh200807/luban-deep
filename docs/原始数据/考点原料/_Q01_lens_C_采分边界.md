# Q01 混凝土养护与裂缝防治｜R5-R7 镜头

## R5 采分点

### A. 先判裂缝控制目标

| 采分点 | 表述 | 锚定 |
|---|---|---|
| A1 | 先区分“不允许出现裂缝”和“允许出现裂缝”两类控制目标。 | 🟢 source=`kc:1A411011_032_0057:0` |
| A2 | 不允许裂缝时，控制构件拉应力不超过混凝土抗拉强度。 | 🟢 source=`kc:1A411011_032_0057:0` |
| A3 | 允许裂缝时，按构件类别、环境类别控制受力裂缝宽度，使其不影响设计工作年限内的受力性能、使用性能和耐久性能。 | 🟢 source=`kc:1A411011_032_0057:0`; source=`ca:1A411011_032_0057` |
| A4 | 裂缝控制可按三级理解：不出现拉应力；有拉应力但不超过抗拉强度；允许裂缝但裂缝宽度不超过允许值。 | 🟢 source=`kc:1A411011_025_0047:2` |

### B. 施工养护与浇筑连续性

| 采分点 | 表述 | 锚定 |
|---|---|---|
| B1 | 防水混凝土应连续浇筑，宜少留施工缝。 | 🟢 真题=`2015年第26题` |
| B2 | 防水混凝土应分层连续浇筑，分层厚度不大于500mm，并采用机械振捣，避免漏振、欠振和超振。 | 🟢 真题=`2015年第26题` |
| B3 | 防水混凝土养护时间不得少于14d，不能写成7d。 | 🟢 真题=`2015年第26题` |
| B4 | 冬期施工时，防水混凝土入模温度不应低于5℃。 | 🟢 真题=`2015年第26题` |
| B5 | 高温施工可采用早间施工、晚间施工、喷雾、连续浇筑等措施。 | 🟢 真题=`2016年第30题` |
| B6 | 高温环境下不宜用“吹风”作为防裂保湿措施。 | 🟢 真题=`2016年第30题` |

### C. 施工缝与薄弱部位

| C2 | 留设施工缝时，不应留在底板与侧墙交接处。 | 🟢 真题=`2015年第26题` |
| C3 | 裂缝防治不是只靠养护；应从设计、材料、施工、维护各环节采取控制措施。 | 🟢 source=`kc:1A411011_032_0057:0` |
| C4 | 对受力裂缝，要回到“是否允许开裂、允许时宽度是否受控”的主线判断。 | 🟢 source=`kc:1A411011_032_0057:0` |

## R6 答案骨架

### 题型一：问“混凝土裂缝如何控制？”

满分骨架：

1. 🟢 先判断裂缝控制目标：不允许裂缝时控制拉应力；允许裂缝时控制裂缝宽度不超过规范限值。  
   source=`kc:1A411011_032_0057:0`

2. 🟢 裂缝控制应贯穿设计、材料、施工、维护各环节，不能只写施工养护。  
   source=`kc:1A411011_032_0057:0`

3. 🟢 对允许开裂构件，应结合构件类别和环境类别控制受力裂缝宽度，保证设计工作年限内受力性能、使用性能和耐久性能。  
   source=`ca:1A411011_032_0057`

4. 🔵 施工侧可从连续浇筑、合理分层、机械振捣、保湿养护、温度控制、减少收缩约束等方向组织答案。  
   source=工程通识

### 题型二：问“防水混凝土施工与养护要求？”

满分骨架：

1. 🟢 应连续浇筑，宜少留施工缝。  
   真题=`2015年第26题`

2. 🟢 分层连续浇筑，分层厚度不得大于500mm。  
   真题=`2015年第26题`

3. 🟢 采用机械振捣，避免漏振、欠振和超振。  
   真题=`2015年第26题`

4. 🟢 施工缝不应留在剪力最大处或底板与侧墙交接处。  
   真题=`2015年第26题`

5. 🟢 养护时间不得少于14d。  
   真题=`2015年第26题`

6. 🟢 冬期施工入模温度不应低于5℃。  
   真题=`2015年第26题`

### 题型三：问“高温施工如何防裂？”

满分骨架：

1. 🟢 可安排早间施工。  
   真题=`2016年第30题`

2. 🟢 可安排晚间施工。  
   真题=`2016年第30题`

3. 🟢 可采取喷雾措施。  
   真题=`2016年第30题`

4. 🟢 应保持连续浇筑。  
   真题=`2016年第30题`

5. 🟢 不应把“吹风”作为正确措施。  
   真题=`2016年第30题`

6. 🔵 组织表达时可写成“避开高温、降低失水、保证连续、避免冷缝”。  
   source=工程通识

### 题型四：问“墙体裂缝成因判断？”

满分骨架：

1. 🟢 纵墙两端斜裂缝，且多数通过窗口两个对角，常与地基不均匀下沉有关。  
   真题=`2016年第12题`

2. 🟢 窗间墙上下对角处成对水平裂缝，常与地基不均匀下沉有关。  
   真题=`2016年第12题`

3. 🟢 纵墙中央顶部和底部窗台处竖向裂缝，常与地基不均匀下沉有关。  
   真题=`2016年第12题`

4. 🟢 窗间墙出现竖向裂缝，不是地基不均匀下沉引起的主要典型现象。  
   真题=`2016年第12题`

## R7 边界候选

> 本段为评分边界候选，全部标为🔴待真人/专家裁决；不得直接作为自动判分最终规则。

### 边界1：满分答案

🔴 待真人/专家裁决

- 同时写出“目标判断 + 措施链条 + 关键数字/禁忌”。
- 对防水混凝土，能覆盖连续浇筑、少留施工缝、分层≤500mm、机械振捣、施工缝避开剪力最大处和底板侧墙交接处、养护≥14d、冬期入模≥5℃。
- 对允许开裂构件，能写出按构件类别和环境类别控制裂缝宽度，且不影响受力、使用、耐久。
- 表达不是口号，有可判分动词和数值。

### 边界2：压线答案

🔴 待真人/专家裁决

- 写出“加强养护、连续浇筑、控制裂缝宽度”中的核心方向，但数字不完整。
- 防水混凝土只写出“养护不少于14d”和“连续浇筑”，漏掉施工缝位置或振捣要求。
- 高温施工写出“早晚施工、喷雾”，但没有解释连续浇筑或防失水。
- 能判断允许裂缝要限宽，但没有提构件类别、环境类别或耐久性。

### 边界3：0分或近0分答案

🔴 待真人/专家裁决

- 把防水混凝土养护时间写成不少于7d。
- 把施工缝留在剪力最大处或底板与侧墙交接处。
- 高温施工措施选择“吹风”。
- 只写“加强管理、按规范施工、提高质量”，没有任何具体采分点。
- 把“不允许裂缝”与“允许裂缝但限宽”混为一谈。
- 明显答非所问，例如题问裂缝控制，答案主要写钢筋锚固、桩基检测或防火材料。

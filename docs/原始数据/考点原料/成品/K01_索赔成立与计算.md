## §2 原理因果层 (L2 · causal chain)

> 把散点压成一条可复数、可推导的因果链：**成因 → 立案 → 双闸门裁决 → 措施闭环**。来源：lens_A 因果链，汇编层把 lens_B "双闸门互不蕴含" 的不变量焊进第二段，消解 lens_A "责任方→可索赔" 单线叙事的盲点（见 §8 消解记录-2）。

**【第一段 · 成因与立案】**

1. **成因三分**：
   - 发包人原因：设计变更、图纸/材料延误、未提供施工条件 🟢【2015案例1·C设计变更；2016案例1·甲供材料不合格；2024事件①设计变更E】
   - 不可抗力：自然灾害、特大暴雨等（双方按规则分担）🟢【2015案例1·E；2018第4题·特大暴雨】
   - 承包人原因：管理不善、机械故障、效率低、返工 🟢【2024事件②机械故障G】

2. **立案开关**：🟢非承包人原因 → 索赔成立**可能性**开启（`kc:1A435000_046_0066`）；🔵若承包人原因 → 触发发包人**反索赔**风险（`kc:1A432000_050_0073:0`）。
   > 关键：立案开关只决定"有没有资格谈"，**不**决定"工期/费用各赔多少"——这是下一段两闸门的事。

**【第二段 · 双闸门裁决（核心机理）】**

3. **程序时效闸**：🟢事件发生后须在合同期限（未约定 **28 天**）内发书面意向通知（`kc:1A432000_048_0068:0`），过时丧权。

4. **工期闸门**（资格成立后，量的裁决只认网络位置，不认责任方）：
   - 🟢 情景A 关键线路：总时差 0，**延误多久索赔多久**（教材P48①逐字 CET_1A432000_P0048_001；真题锚【2024案例(二)·事件①E设计变更·关键线路成立】）。`机理：直接冲击竣工节点。`
   - 🟢 情景B 非关键 + 超总时差：**索赔 = 延误 − 总时差**。【2015案例1·C：延误2、总时差1→顺延1】`机理：先用机动时间吸收，超出部分才影响总工期。`
   - 🟢 情景C 非关键 + 未超总时差：**不索赔工期**。【2015案例1·E：延误3、总时差4→0；2018案例(二)问题4：甲供电缆甲方责任但总时差3未超→工期不成立】`机理：机动时间足以吸收全部延误。`

5. **费用闸门**（只认责任归属，不认网络位置）：
   - 承包人自身原因 → 自担。
   - 不可抗力 → 🟢按范本分摊：**人机损失各负其责，工程实体+清理修复归发包人**（`kc:1A432000_047_0067:0`）。【2015案例1·E：8.2万设备自担 / 24.5万清理修复可索】
   - 发包人原因 → 🟢索全部额外费用（窝工/材料/检验/留守等），**通常还可加索利润**（`kc:1A435000_046_0066`；教材P46逐字"还可索赔利润"＋发包人责任事件清单 CET_1A435000_P0046_001；"通常"的限定依据：教材P47三情形——重新检测合格/额外检查检验试验/试运行失败——补偿不包括利润 CET_1A432000_P0047_001），因剥夺了承包人盈利机会。

   > **互不蕴含（不变量核心）**：工期成立 ≠ 费用成立。【2015案例1·C：工期受总时差封顶只顺延1月，但费用27.2万**全额成立**】——这是本考点最易错、也最高频的裂点。

**【第三段 · 措施闭环】**

6. **赶工优选**：工期成立后若发包人仍要求原期竣工 → 🟢优先压**关键线路上、成本低、不影响后续**的工序（{2017,案例一}官方答案逐字"压缩成本较低且不影响后续工作"；`m35:Q17-1A433000:P4`）。【2017案例一：先压主体结构(2700元/天可压2天)，再压室内装修(3000元/天)】产生的赶工费由发包人承担（`kc:1A432000_047_0067:1`）。
7. **最终效应**：工期顺延竣工日 + 费用补偿(+利润) + 合同权责再平衡。

## §3 不变量 R2 (L3 · invariant)

> 来源：lens_B。汇编层全采纳并标为本 pack 的母规则。

🟢 **母规则：**
> "一个索赔事件，在索赔资格与程序有效（非承包人原因、按约定时限提出意向通知）的前提下，由两条相互独立的闸门同时裁决：**工期闸门**只认'延误是否落在关键线路 / 是否超出总时差'，**费用闸门**只认'责任归属是否在对方'——延误责任方决定费用归属，关键线路与总时差决定工期顺延，两者各判各的、互不蕴含。"

即：工期成立 ⇎ 费用成立；同一事件可"费用成立而工期不成立"（锚例见下表）；反向"工期成立而费用不成立"为教材规则推论（🔵待锚例：如不可抗力致关键线路延误——教材P48三分支①工期可索，而承包人施工机具损失按不可抗力分担规则自担 `ca:1A432000_047_0067`）。判分锚定两闸门的正确启用与互斥，**不认"凭责任方一刀切"**。

**R2 可解释 ≥5 场景（全🟢，已核）：**

| # | 真题事件 | 工期闸门 | 费用闸门 | 裂点 |
|---|---|---|---|---|
| 1 | 2015案例1·C设计变更 | 不全额成立·只顺延1月（非关键·总时差1·延误2） | **成立**（27.2万合理） | 工期封顶但费用全成立 |
| 2 | 2015案例1·E不可抗力 | 不成立（非关键·总时差4·延误3未超） | **部分成立**（24.5万清理可索/8.2万设备自担） | 不可抗力二次切分费用 |
| 3 | 2018案例(二)问题4·甲供电缆 | **不成立**（有总时差3、未超→不影响总工期） | （此处未触发费用问） | "责任在对方"≠"工期顺延" |
| 4 | 2024案例(二)·事件①E设计变更/②G机械故障 | ①成立(关键线路B→E→I)/②不成立(G非关键+承包人责任) | — | 关键线路闸 + 责任闸双滤 |
| 5 | 2016案例1·复检不合格8万+剥离检验4万 | （未触发工期问） | **均成立**（发包人责任+在时限内） | 费用闸单独通过 |
| 6 | 2021案例(四)·问6 五条逐条裁 | 不成立/成立/成立/成立/不成立 | — | 逐事件按两闸门判成立性=标准骨架 |

## §4 出题人镜头 (L4 · examiner_intent + R3 + R4)

> 来源：lens_B。汇编层核对每条真题锚后采纳；R4 封闭集是变题的硬边界。

### examiner_intent（出题人在验证三件事）
- 🟢 **能否把工期闸门与费用闸门分开判**：先问关键线路/总时差定工期，再问责任归属定费用，绝不混。【2015案例1事件三、2024案例(二)】
- 🟢 **能否用网络计划/总时差做定量裁决**：关键线路延误几月赔几月；非关键只赔超总时差部分，未超则 0。【2015案例1、2018案例(二)问题4、`kc:1A432000_048_0068:1`】
- 🟢 **能否把费用拆到"可索赔项"颗粒度**：同一笔里对方责任部分可索、自身损失自担。【2015案例1·24.5万可索/8.2万自担】

### 常考形态（全🟢）
- 工期+费用双判题【2015案例1事件三、2024案例(二)问题1】
- 网络图关键线路/总工期/总时差·自由时差求解题【2018案例(二)、2023第1/2题、2024案例(二)、2025参考答案(二)】
- 逐条索赔成立性裁决题【2018第4题、2021案例(四)问6】
- 赶工压缩工序选择题【2017案例一、`m35:Q17-1A433000:P4`】
- 索赔费用分层计算题（成本→管理费→利润逐层）【2021案例(四)问4：300+30+16.5=346.5万】
- 不可抗力损失分担题【2015案例1事件三(2)、2018第4题暴雨留守费】
- 🔵 索赔程序/证据/时限配套题（28天、证据四性）【`ca:1A432000_048_0068`、`ca:1A432000_048_0069`】

### 高频陷阱（出题人埋雷，全🟢）
1. "责任在对方=工期就顺延"误判 → 甲方责任但延误未超总时差，工期仍不成立。【2018案例(二)问题4、2024事件②】
2. "非关键延误几月赔几月"误判 → 只赔超总时差部分；C延误2但只顺延1（总时差1）。【2015案例1·C】
3. **工期与费用成立性互相绑死** → C主张的2个月工期索赔不全额成立（只按影响总工期的1个月计），但费用27.2万全额成立。【2015案例1·C】
4. 不可抗力一刀切 → 把承包人设备损失8.2万也算给发包人（只24.5万清理可索）。【2015案例1·E】
5. 赶工压错工序 → 去压非关键线路或压"费高/影响后续"的工序。【2017案例一】

## §7 动画分镜 (L7 · storyboard)

> 来源：lens_D 动画原料。汇编层裁剪：保留与 R2 双闸门**强相关**的隐喻，剔除与判分无关的装饰（如"施工进度计划调整"误区8——属进度管理噪声，非索赔本体），并把每个 reveal 焊到一个真题🟢锚使动画可证伪。

### 核心视觉隐喻
- **双闸门**（汇编层新增·R2 核心）：屏幕左右两道闸门并排——左"工期闸"标"关键线路/总时差"，右"费用闸"标"责任归属"；同一事件分别落入两闸，可一开一关，强调互不蕴含。
- 关键线路 vs 非关键：红线=关键线路（总时差0），蓝线=非关键。
- 总时差：弹簧——延误压缩弹簧，弹簧压到底（超总时差）才顶动竣工节点。
- 费用颗粒：一堆损失明细被"责任筛"分成两盘——发包人盘(清理修复24.5万)/承包人盘(设备8.2万)。

### Reveal 顺序（每帧绑真题锚）
1. **建立母规则**：双闸门并排亮起。旁白："一个索赔事件，两道闸门各判各的。"
2. **工期闸·情景B**：C非关键蓝线，延误2压弹簧，弹簧只顶出1格 → 工期顺延1月。🟢【2015案例1·C】

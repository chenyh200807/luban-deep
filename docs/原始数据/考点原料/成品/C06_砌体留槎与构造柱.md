## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「因果链 + 每段挂 point_id」，**删除镜头 A 里无锚的力学外推**（"倒三角咬合""坡道传力分力分解"等是合理工程解释但无 point_id 也无真题证据，保留为 🔵 讲解性表述，不充判分；镜头 A 自标 🔴 的"先进后退削弱抗剪"推理保留 🔵）。

**核心因果链(讲懂层骨架)：**

```
砌体抗压强但抗拉抗剪弱(2017第22题:抗拉强度低)        🔵砌懂背景(非留槎判分轴)
   │  墙体不能一气呵成 → 必留临时间断处(槎口)=薄弱面
   ▼
"能同时砌就同时砌"(最优)：
   └ 转角/交接处应同时砌筑,不得留直槎  kc:1A413030_109_0213:3 + kc:1A434000_067_0100:1  🟢
   ▼
"不能同时砌就留斜槎"(次优·把通缝改成咬合坡面)：
   ├ 抗震8度及以上必斜槎  kc:1A413030_107_0210:1  🟢
   ├ 普通砖斜槎水平投影≥高2/3 / 多孔砖长高比≥1/2  kc:1A413030_107_0210:1  🟢
   ├ 轻骨料砌块斜槎水平投影≥高2/3 / 空心砖斜槎高≤1.2m  kc:1A413030_109_0214:1 / kc:1A413030_109_0213:3  🟢
   └ 非抗震可直槎,但须加拉结筋  kc:1A413030_107_0210:1  🟢
   ▼
"有构造柱就砌马牙槎"(把交接面变咬合齿)：
   ├ 先退后进(先进后退是错法)  kc:1A413030_107_0210:2 + {2015,第12题}  🟢
   ├ 沿高≤300mm / 凹凸60mm  kc:1A413030_107_0210:2  🟢
   ├ 沿墙高每500mm设拉结钢筋  kc:1A413030_107_0210:2  🟢
   └ 施工顺序:先绑构造柱钢筋→砌砖墙→后浇混凝土(先砌墙后浇柱)  {2020,第11题}、{2018,第11题}  🟢
   ▼
"临时洞口受限"(集中削弱控制)：
   └ 净宽≤1m / 距交接面≥500mm / 过梁封口 / 预埋拉结筋  kc:1A413030_106_0208:0 + {2016,案例2}  🟢
   ▼
效果 = 断口/交接从"薄弱通缝"变成"咬合节点"(同时砌→斜槎→马牙槎→洞口受限)
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **斜槎优于直槎**：直槎是全断面竖直通缝，咬合力弱；斜槎把竖直灰缝改成缓坡，新旧砌体之间形成机械咬合与摩擦，抗剪能力大幅提升，斜槎越长(≥2/3高)坡越缓越牢。
- **马牙槎"先退后进"**：先退后进让构造柱与砌体形成"混凝土齿槽咬合"，地震剪力靠齿槽锁键传递；"先进后退"会让柱底咬合不足（镜头 A 的力学推理，🔵 不充判分）。
- **先砌墙后浇柱**：构造柱混凝土在马牙槎砌好后浇筑，让混凝土填入齿槽与砌体咬死，故先绑钢筋→砌墙→后浇柱，顺序颠倒则咬合失效。
- **洞口受限**：临时洞口是墙体的集中削弱点，限净宽≤1m、距交接面≥500mm避免在最薄弱的交接处再开口。

> 三色提醒：因果链的**结论(8度斜槎/2/3/1/2/先退后进/300mm/60mm/500mm/净宽≤1m/距交接面≥500mm)**全部 🟢 锚定；链条里的**微观机理解释**(齿槽咬合/坡面摩擦/倒三角)是讲懂用语，标 🔵，不得作为采分点输出（§8.2 C2）。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(Opus) 主写，汇编层逐场景重核真题锚。四个真题锚（`{2015,第12题}`/`{2018,第11题}`/`{2020,第11题}`/`{2016,案例2}`）均经 `verify_exam_anchors.py` 确定性命中。

**不变量(一句话)：**
> 凡砌体临时间断或墙柱交接，都必须用「**能同时砌就同时砌(不留直槎) → 不能同时砌就留斜槎(8度及以上必斜槎/普通砖≥2/3·多孔砖≥1/2/非抗震直槎加拉结筋) → 有构造柱就砌马牙槎(先退后进/≤300mm/凹凸60mm/500mm拉结钢筋·先砌墙后浇柱) → 填充墙与主体可靠连接(拉结筋化学植筋须实体检测/连接构造经设计同意/严禁任意剔凿) → 临时洞口受限(净宽≤1m/距交接面≥500mm/预埋拉结筋)**」把"断口/交接"从薄弱通缝变成咬合节点。出题人永远在考「**该不该留直槎 / 斜槎够不够 / 马牙槎方向对不对 / 构造柱顺序对不对 / 填充墙连接对不对 / 洞口合不合规**」，不考砌体材料强度等级本身。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) + A(DeepSeek) 视觉隐喻；汇编层把 Aha 锚按内容精确挂锚，Reveal 重排为「先讲懂同时砌→斜槎→马牙槎→洞口链 → 再按 C06 判分眼逐点 reveal」。对接闭环渲染器约定见尾注。**本节为候选脚本，C06 暂无既有动画原型。**

### 视觉隐喻
- **斜槎 vs 直槎**：一面墙临时断处，左边留直槎(竖直通缝亮红✗)、右边留斜槎(缓坡咬合亮绿✓)，斜槎水平投影标 2/3 高度标尺。
- **构造柱马牙槎**：砌墙时第一皮先退(凹槽)、第二皮进(凸出)，"先退后进"逐皮点亮形成齿槽；浇混凝土后齿槽咬死。"先进后退"对照显示咬合不足✗。
- **构造柱施工顺序**：①绑钢筋笼 → ②砌砖墙(马牙槎) → ③浇混凝土，三步编号依次点亮；错误顺序(先砌墙后绑钢筋)闪红✗。
- **临时洞口**：墙体上的洞口标净宽≤1m、距交接面≥500mm标尺；1.2m/距<500mm 闪红✗。

### Reveal 顺序(讲懂 → 判分眼)
1. **咬合链**：砌体抗拉弱+不能一气呵成 → 断口要从通缝变咬合节点。(讲懂层骨架)
2. **能同时砌就同时砌**：转角交接同时砌筑不留直槎。(锚 `kc:1A413030_109_0213:3`)
3. **斜槎尺寸**：8度斜槎/普通砖2/3/多孔砖1/2/非抗震直槎加拉结筋。(锚 `kc:1A413030_107_0210:1`)
4. **马牙槎**：先退后进/≤300mm/60mm/500mm拉结筋逐点点亮。(锚 `kc:1A413030_107_0210:2`、`{2015,第12题}`)
5. **构造柱顺序**：绑钢筋→砌墙→浇混凝土三步。(锚 `{2020,第11题}`、`{2018,第11题}`)
6. **临时洞口**：净宽≤1m/距交接面≥500mm/过梁封口。(锚 `kc:1A413030_106_0208:0`、`{2016,案例2}`)

### Aha 时刻(锚已按内容精确化)
- 直槎是竖直通缝一掰就开；斜槎改成缓坡后砖块咬合摩擦锁住 → 「斜槎是把通缝改成咬合坡面」。锚 `kc:1A413030_107_0210:1`
- 马牙槎"先进后退"柱底咬合不足；"先退后进"形成齿槽，浇柱后咬死 → 「先退后进才咬得住」。锚 `kc:1A413030_107_0210:2`、`{2015,第12题}`
- 先砌墙后绑钢筋，钢筋塞不进马牙槎；改先绑钢筋→砌墙→浇柱，混凝土填齿槽咬死 → 「先砌墙后浇柱，但钢筋先绑」。锚 `{2020,第11题}`
- 洞口开在交接处又超1m，墙体被集中削弱裂开；改净宽≤1m/距交接面≥500mm → 「洞口别开在最薄弱处」。锚 `kc:1A413030_106_0208:0`、`{2016,案例2}`

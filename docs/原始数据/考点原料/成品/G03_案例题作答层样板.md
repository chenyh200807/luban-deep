# G03 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`G03_桩基施工与质量问题.md`](./G03_桩基施工与质量问题.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**桩怎么打/灌注桩怎么成孔成桩、检测怎么选、质量问题怎么找成因写防治**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建案例失分不是"不会"，是"会一点但写不成分"——判断纠错只指错不写正确做法 / 措施六维漏维 / 质量问题原因漏写或防治只写口号 / 抽检比例与根数记反。作答层的杠杆 = 把「知道什么」变成「按阅卷结构写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 G03 §5 R5**（已 signed 的 candidate pack，14 分组 35 去重采分点）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 G03 §5.3 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E05/E06/E07/E08/E10/E11、M03/M06/M08/M10，经真实 Read 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_G03_exam_evidence.json` 内**真实题号**（如 `{2016·案例1}`、`{2024·第9题}`），证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。⚠️ **题号口径以证据包文件字段为准**：pack 正文用过的口语化标签（如"2022案例三""2023办公楼案例""2025案例三"）在证据包内的**真实字段**分别是 `{2022·第(三)题}`、`{2023·第1题}`、`{2025·第(三)题参考答案}`——本层一律按证据包真实字段引用。
>
> **版本治理（红线5）**：桩基现行规范族 = 《建筑桩基技术规范》**JGJ 94-2008**（沉桩顺序/泥浆护壁/沉渣）+《建筑基桩检测技术规范》**JGJ 106-2014**（5 法/完整性 Ⅰ-Ⅳ 类/钻芯孔数/抽检比例）。本层数值表达按现行 JGJ 94/JGJ 106 写；pack 内未逐字锚到规范版次的通识补充（泥浆比重 1.1~1.3 / 水头≥2m / 导管埋深）继承 pack 🔵 不充判分眼。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，验证"会看答案→会写答案"跃迁；量产批次）。
> **三色铁律继承自 G03**：🟢 采分点锚定 G03 R5（教材锚 point_id / 真题锚白名单）｜ 🔵 作答策略·句式·机理（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、案例口径 vs 教材口径取舍）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写答案漏分，多是某一维整维漏掉。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 G03 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（施工/监理/检测单位） | 桩基检测由有资质检测机构实施；试验桩为设计提供依据 | 把检测主体/目的答反 |
| **程序维** | 按什么顺序（沉桩顺序、成桩流程不可颠倒） | 沉桩"先深后浅/先大后小/先长后短/先密后疏"；泥浆护壁/沉管成桩流程 | 顺序口诀写反（先浅后深）；成桩流程漏边振边拔 |
| **条件维** | 达什么阈值/选什么方法才合格 | 强度≥70%起吊/≥100%打桩；沉渣端承≤50mm；低应变要求强度≥70%且≥15MPa | 阈值记反、方法↔目的错配（低应变测承载力） |
| **记录/计算表达维** | 留什么书面 / 数值与抽检算式 | 超灌 0.8~1.0m；抽检甲级静载≥1%·3根、完整性≥20%·10根（甲级灌注桩≥30%·20根）；钻芯孔数 | 超灌写 500mm；抽检比例/根数漏写或写反 |
| **后果维** | 缺陷成因 + 防治 / 不达标后果 | 预制桩断裂五因+防治；干作业虚土≤100mm超则处理；坍孔四防 | 只写"质量差"不究因；防治只写"加强管理"口号 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**，比"逐字找差"更快定位"差哪句"。G03 区别于 A01（验收程序）的特点：**条件维（数字阈值）+ 后果维（质量问题成因防治）密度高**，是失分主战场。

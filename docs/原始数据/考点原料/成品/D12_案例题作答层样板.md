# D12 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`D12_饰面砖板施工质量与空鼓防治.md`](./D12_饰面砖板施工质量与空鼓防治.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**石材用哪种法（干挂/湿贴/粘贴）、薄型块材能不能粘贴、复验哪几项、粘结剂多厚、满粘法到多高、空鼓为什么会起、泛碱怎么来的**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建饰面砖/板案例失分不是"不会"，是"会一点但写不成分"——空鼓措施只写"敲掉重贴/加强管理"漏掉整维（基层/材料/界面/伸缩缝/养护）、判断纠错只指不妥不给正确做法、复验漏掉"拉伸粘结强度"、满粘法高度写成 24/50/54m、湿贴漏防碱封闭。作答层的杠杆 = 把「知道措施」变成「按**措施六维 + 三段式判断纠错 + 验收链**写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 D12 §5 R5**（已 signed 的 candidate pack，11 组采分点）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 D12 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E06/E07/E10、M08，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_D12_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2019·第13题}`、`{2017·第11题}`、`{2025·第15题}`、`{2025·第29题}`、`{2023·第2题}`、`{2015·第29题}`、`{2021·案例三}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**措施六维（空鼓防治）+ 判断纠错 + 验收**，验证句式库在饰面砖/板工艺场景泛化用）。
> **三色铁律继承自 D12**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识（无单一 point_id 但学界共识，作答策略·句式 / 邻接借力）｜🔴 待真人/专家裁决（判分边界、给分档位、临界取舍）。
> **版本治理（红线5）**：满粘法高度限值 `{2019·第13题}` 解析引《建筑装饰装修工程质量验收标准》**GB 50210-2018**（现行有效）；「墙面饰面砖水泥砂浆粘贴」在 `{2022·案例(一)}` 为**限制类**（不得用于 25m 及以上），在 `{2025·第29题}` 升级为**禁止类**——以**现行最新口径（禁止）**为最终作答版本，旧"限制"表述只留 🔵 背景注（见 §1.4 G1）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写饰面砖/板答案漏分，多是某一维整维漏掉（最典型：空鼓措施题只写"加强管理"漏掉基层维与界面维；复验题只写"放射性"漏掉"拉伸粘结强度"维）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 D12 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位"，验收题才显化"自检→报验→组织验收"主体链） | 验收时施工单位自检、监理/建设单位组织（隐含，验收链才显化） | 本考点主体维占比低，仅验收链显化；空鼓/工艺题几乎不单独成采分点 |
| **程序维** | 按什么顺序做（工艺顺序/粘贴前排版/填缝顺序/铺贴工序） | 排砖→分格→弹线；填缝先水平后垂直（R5#7）；地面瓷砖 基底处理→放线→浸砖→铺结合层砂浆→铺砖→养护→勾缝（R5#11） | 工艺顺序乱（浸砖与铺砂浆颠倒）；漏排版直接贴；填缝顺序反 |
| **条件维** | 达什么阈值才合格/才做（尺寸门槛/厚度/高度限/复验项） | ≤10mm 厚、<40cm 边长可粘贴、厚 8~10mm（R5#3）；粘结剂 3~8mm（R5#7）；满粘法≤100m（R5#8）；复验四项（R5#5/#6） | 尺寸/厚度数字记错或漏；满粘法高度档混（24/50/54/100）；复验漏"拉伸粘结强度" |
| **记录/计算表达维** | 留什么书面 / 写定量结论（复验取样送检/检测项目表达） | 复验项目须写全（放射性/拉伸粘结强度/吸水率/抗冻性）；后置埋件拉拔力合格记录（R5#4） | 只写"做复验"不写具体项；只写"检测合格"不点项目名 |
| **后果维** | 不达标/达标后会怎样（空鼓→开裂→脱落；泛碱破坏界面；超时振动=假粘） | 空鼓五要点的"为什么"（界面失效→粘不住/粘不实/粘不久）；湿贴不防碱→泛碱剥离 | 只会"会空鼓/会脱落"，不知对应到具体哪类原因与措施 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。D12 是"措施密集 + 数值门槛"双重考点，**空鼓措施题的失分主战场在程序维+条件维（整维漏措施/漏数字）**，**复验题的失分主战场在记录/计算表达维（漏项）**。

## 1. 采分点可写化表（从 D12 §5 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚」**逐字来自 D12 §5 R5**（11 组采分点，已 signed candidate pack）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（≈ R8 误区"关键词缺失"的反面）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 D12 §6 R8 误区 + error_code）。
> - **版本状态**：`现行有效` / `旧说法仅背景` / `新规优先·旧表述必须改写`——**写过期表述照样丢分**，这一件不可省。

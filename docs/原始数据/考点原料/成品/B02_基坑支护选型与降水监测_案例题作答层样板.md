# B02 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`B02_基坑支护选型与降水监测.md`](./B02_基坑支护选型与降水监测.md)（深母题知识层 R1–R8，`status: candidate`）之上**加的一层**，不是新母题体系。
> 知识层回答「**这个基坑该选什么支护、按什么渗透系数选降水、什么条件触发监测**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建案例失分不是"不会"，是"会一点但写不成分"——漏采分点 / 答非所问 / 只写结论不写理由 / 措施维度不全 / 主体写错 / 阈值数字记反。作答层的杠杆 = 把「知道什么」变成「按阅卷结构写全采分点」。本 pack 句式重点（任务面）：**措施六维 + 判断纠错 + 主体定位**。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 B02 §5 R5**（已 candidate 深 pack，9 个采分点 P1–P9）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 B02 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E01/E02/E03/E06/E07/E10、M08/M10，经真实 Read 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_B02_exam_evidence.json` 证据包内真实 `{年份,题号}`（如 `{2024,案例题（二）}`、`{2015,案例3}`、`{2016,案例1}`）。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。本样板用到的真题锚均已直读 `correct_answer` 核真。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，验证"会看答案→会写答案"跃迁 + 实测句式库泛化用）。
> **三色铁律继承自 B02**：🟢 采分点锚定 B02 R5（教材锚 point_id / 真题锚）｜ 🔵 作答策略·句式（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、临界取舍、jury 残留）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写答案漏分，多是某一维整维漏掉。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 B02 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁来组织/委托/实施/见证 | 基坑监测由**建设方委托具备资质的第三方**；专项方案由施工单位编制报监理审批、危大须专家论证 | 写"施工单位自己监测"，监测主体答反（`{2024,案例题（二）}`真题考点） |
| **程序维** | 按什么顺序做（先撑后挖、先桩后帷幕） | **先施工灌注桩、后施工截水帷幕**；土钉墙逐层施作限时封闭；内支撑拆除顺序与设计工况一致 | 帷幕与排桩顺序倒装；土钉墙一次开挖到底（→E06） |
| **条件维** | 达什么阈值/什么土质才做（选型闸） | 渗透系数+降深选降水（轻型≤6m、喷射8~20m、管井渗透大）；安全等级选支护；深度≥5m 触发监测/危大论证 | 阈值记反（轻型用到渗透大）、"软土一律集水明排"不看深度（→E10） |
| **记录/计算表达维** | 留什么书面/必含数字 | 专项方案七项内容；桩身强度≥C25、泛浆≥500mm、水位降至坑底以下500mm、间隔成桩>4D或>36h | 措施只写定性不写关键数字；方案漏项（→E02/M08） |
| **后果维** | 违反或达标后会怎样 | 超挖→临空面塌落；未达强度张拉→锚固段拔出；突涌→坑底鼓起 | 只写结论不写"会导致什么"，措施缺因果支撑（→E03） |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**，比"逐字找差"更快定位"差哪句"。

### 高频句式骨架（直接抄答题纸）

**骨架 ②措施六维（"基坑支护/降水还应采取哪些措施"）→ B02 重点，对应 S1/S2**
```
【六维铺开】应从 人员/材料/机械/方法工艺/环境与成品保护/检验验收记录 六维补充：
  人员：监测由有资质第三方、危大方案专家论证、技术交底到位。
```

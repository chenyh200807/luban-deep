# A02 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`A02_隐蔽验收材料复验见证取样.md`](./A02_隐蔽验收材料复验见证取样.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype` · **composite**）之上**加的一层**，不是新母题体系。
> 知识层回答「**这一项该不该复验、谁见证取样、哪些是隐蔽验收项目、什么时候验**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建案例失分不是"不会"，是"会一点但写不成分"——A02 这类「验收 + 内容清单枚举」考点的失分形态最典型：**复验项目漏项 / 见证取样要素不全 / 见证主体写错 / 隐蔽部位漏列 / 验收时机答反**。作答层的杠杆 = 把「知道复验哪些项」变成「按阅卷结构把清单写全 + 主体精确到单位」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 A02 §5 R5**（已 candidate signed pack）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 A02 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02 采分点遗漏 / E03 关键词缺失 / E06 程序顺序错误 / E07 概念混淆 / E10 规范适用错误、M08 规范数字混淆 / M10 用常识替代规范判断，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 A02 `_A02_exam_evidence.json` 内**真实题号**且经 pack §0/§自检 gate2 核真的 8 条 🟢 强 MCQ 锚（见下），与 pack §9.1 jury 收口一致；`{2017,第20题}` 因官方解析自承编号笔误降 🔵 文字侧；`{2015,案例2}`/`{2017,案例二}`/`{2019,案例1}`/`{2023,案例1}`/`{2017,第2题}` 非"第N题"格式不可逐问 gate 核 → 仅作 🔵 案例文字引用。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；验证"会看答案→会写答案"跃迁 + 实测句式库泛化用）。
> **三色铁律继承自 A02**：🟢 采分点锚定 A02 R5（教材锚 point_id / 真题锚 gate2 可核）｜ 🔵 作答策略·句式（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、临界取舍）。

## 0. 五维框架（作答层的"采分点分类器"）

A02 案例采分点几乎都能归到这**五维**之一。A02 是「**验收 + 内容清单枚举**」型考点，失分多集中在 **记录维（复验项/隐蔽部位/见证要素清单漏项）** 与 **主体维（见证人资格写错）**——这是 A02 区别于纯程序型考点的指纹。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 A02 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁见证/谁确认/谁组织（见证人资格、复验经谁认可） | 见证人由**建设单位**书面确认；见证记录由**见证人**填（非试验员）；复验经**监理**认可 | 见证人误为监理确认、记录误为试验员填（A02 最高频主体陷阱） |
| **程序维** | 按什么时机/顺序验（覆盖前、送检前通知） | 隐蔽部位**覆盖前**验收；试样**送检前**通知见证人；进场→验证→报监理→合格用 | 覆盖后才补验；送检后才通知见证人；漏"先复验再用" |
| **条件维** | 达什么阈值/触发什么才做（首检触发、气候区分档、扩批条件） | 有氯离子要求时**首检外加剂**；门窗节能**按气候区**复验；钢筋连续三批合格→扩检验批60t→120t | 首检写碎石/河砂；不按气候区机械套全项；扩批条件记错 |
| **记录/内容清单维** | 要复验/隐蔽验收/见证哪些项（清单必含内容） | 钢筋5项/水泥4项/保温材料3项复验清单；节能隐蔽4项；见证取样"必含要素"清单 | **复验项坍缩成最熟代表项**（钢筋只写强度漏弯曲/重量偏差）；隐蔽部位漏列；见证要素不全 |
| **后果维** | 不合格/违规如何处理 | 不合格材料禁用或**经审批**降级使用→见证退场→记录确认；未查验保温材料=违反节能规定 | 只会"退货"，不知申请→审批→见证退场闭环；擅自降级使用 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——A02 **重点盯"记录/内容清单维漏项"和"主体维写错"**，漏哪维一目了然，比"逐字找差"更快定位"差哪句"。
> **"必含内容"清单落记录维**：见证取样"必含哪些要素"（见证人建设单位确认 / 见证人填记录 / 试样现场内抽取 / 检测机构核实见证人 / 变更书面手续）、材料复验"必含哪些项目"——这两类"清单枚举"全部归**记录/内容清单维**，是 A02 采分密度最高的一维。

## 1. 采分点可写化表（从 A02 §5 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚 point_id」**逐字来自 A02 §5 R5**（已 candidate signed pack 13 分组）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（A02 重灾区=清单项词，缺一项即缺一分）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 A02 §6 R8 误区的 error_code）。
> - **版本状态**：`现行有效` / `旧说法仅背景` / `新规范优先·旧表述必须改写`——**写过期表述照样丢分**，这一件不可省。
> 再标**五维**命中哪维。**采分点本身不增不改**（采分点 ground truth 仍归 A02 R5 signed pack）。
> **🟢 教材锚 vs 🟢 真题锚分层**：见证主体细则（建设单位确认见证人/见证记录见证人填）在教材 quote `kc:1A438000_153_0246:0` 只到"现场验证（含见证取样）"框架，**强细则靠真题** `{2017,第13题}`/`{2019,第30题}` 支撑——故该行标"教材框架 + 真题强细则"双锚（与 pack §9.1 单源#2/#12 双标裁决一致）。

### a. 用到哪几类句式

用到 skill §1.③ 9 类句式库的 **5 类**：**① 判断纠错 / ③ 程序 / ④ 验收 / ⑥ 主体定位 / ⑦ 内容清单枚举**（勾选明细见 §2 表）。

**A02 句式指纹**：与 A01（以 ④验收/③程序 为主力）不同，A02 因"复验项目 + 见证取样要素**枚举密集**" → **⑦内容清单枚举 + ⑥主体定位 上位为主力**。这正是任务要求的句式重点（验收 + 程序 + 内容清单枚举 + 主体定位）的落地：内容清单枚举（⑦）承载"复验项目/见证要素/隐蔽部位列全"，主体定位（⑥）承载"见证人资格"，验收（④）+程序（③）承载"覆盖前验收/送检前通知"。

### b. 有无需第10类？

**无需新造第10类。** A02 的全部问法（列复验项目 / 判见证主体 / 判隐蔽时机 / 指不妥并改正 / 列隐蔽部位）都被现有 9 类的 ①③④⑥⑦ 五类**完整覆盖**，且覆盖得很贴——"见证取样必含要素枚举"正是 ⑦内容清单枚举的标准用例，"见证人资格"正是 ⑥主体定位的标准用例。**未遇到句式库覆盖不了的张力**（A02 不含计算判定/索赔/事故/措施这些可能撑出新类的形态）。结论：A02 不暴露新句式缺口，⑦/⑥ 两类在 A02 上得到强复用印证（fat skill 杠杆生效）。

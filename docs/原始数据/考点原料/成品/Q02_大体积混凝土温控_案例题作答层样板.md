# Q02 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`Q02_大体积混凝土温控.md`](./Q02_大体积混凝土温控.md)（深母题知识层 L0–L7 / R2–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**为什么会裂、温升/温差/降温速率各控到几度、配合比怎么换算、测温点怎么布**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿采分点的措施清单 + 算式链**」（学生"会写答案"）。
> **第一性原理**：一建大体积混凝土温控案例失分不是"不会"，是"会一点但写不成分"——措施题只写"加强养护、控制温差"漏掉材料/配合比/测温整维；温控四指标只写一两个（漏里表温差/降温速率）；阈值方向写反（拆保温 20℃ 与里表 25℃ 互换、降温 2.0℃/d 与 3℃/d 混）；配合比换算只写得数不列算式（丢过程分）；只答"控温"当成"保湿养护"。作答层的杠杆 = 把「知道四组阈值」变成「按 R6 满分四组（材料/配合比/施工/养护测温）写全 + 用第9类计算判定链写全配合比换算四步」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 Q02 §5.1 R5**（candidate pack 的 A/B/C/D 四组，A1–A5 / B1–B5 / C1–C5 / D1–D8）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**；内容/必写词/数值阈值逐条回读 `_Q02_compiled_source.json` 对应 `point_id` 的 `quote`/`required_terms` 核真（散文 §1/§5 内部矛盾时以 compiled_source 为终判）。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 Q02 §5.3 R7 的 🔴 待裁决状态**（指漏不定分）。**温控数值正确性（配合比 kg 串、温差度数对错）归 Layer-2 / 判分内核**，本层只验"算式链/四步/四组写全没"，**不独立验算、不判数对错**。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**（E01–E12 / M01–M10）。本层错因标签只**映射** registry 已注册码（经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>

## 0. 五维框架（作答层的"采分点分类器"）

Q02 大体积温控采分点几乎都能归到这**五维**之一。**本考点是「措施罗列 + 数值阈值 + 配合比计算」复合考点**：措施题失分集中在"措施只写一两条整组漏掉"，数值题失分集中在"阈值方向写反/漏指标"，计算题失分集中在"只写得数不列算式"（落"记录/计算表达"维，N01 实证扩名，不另造第六维）。

| 维 | 含义 | 在 Q02 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位"） | 测温实施、配合比试配（隐含施工方/试验室） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（浇筑工艺/分层/跳仓顺序/养护时机） | 整体分层或推移式连续浇筑、层厚 300~500mm〔C1〕；跳仓分块≤40m〔C2〕；跳仓 9 区依次连续浇筑〔真题 2019〕 | 一次整体浇到顶不分层不跳仓（W8）；浇筑顺序乱 |
| **条件维** | 达什么阈值才合格/才做（水胶比/掺量/入模温/温控四指标/养护时长） | 水胶比≤0.45〔B1〕；入模 5~30℃〔C3〕；温升≤50/里表≤25/降温≤2.0/拆保温≤20〔D2–D5〕；养护≥14d〔D1〕；测点间距≤500mm〔D6〕 | 温控四指标只写一两个（漏里表温差/降温速率，W2）；20℃/25℃ 方向反、2.0℃/d 与 3℃/d 混（W3） |
| **记录/计算表达维** | 留什么书面 / **写算式链+数值结论**（配合比换算、温差校核、测温布点） | 配合比换算（扣含水率、粉煤灰等量替换水泥）〔真题 2019〕；测点表/底/中心+间距 500mm+频次〔D6/D7〕 | 配合比只写得数不列"×(1−20%)/扣含水率"算式（丢过程分）；测温只写"插温度计"漏三层位/间距 |
| **后果维** | 不达标/达标后会怎样（温度应力>抗拉强度→裂缝；选错水泥→放热猛） | 选硅酸盐/早强剂→水化热大→温升高→开裂〔A1/A2/A3〕；裂缝成因（水胶比偏大/养护不到位）〔质量章 B036〕 | 只会"会裂"，不知按"减放热/控温差/抬强度/减约束"四下手点对症 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。Q02 是数值阈值密集型考点，**条件维（温控四指标）+ 记录/计算表达维（配合比换算）**是双失分主战场；**措施题里 R6 四组（材料/配合比/施工/养护测温）都要扫**，对应五维的程序/条件/记录计算/后果全维。

## 1. 采分点可写化表（从 Q02 §5.1 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚」**逐字来自 Q02 §5.1 R5**（A/B/C/D 四组，已 signed candidate pack）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词。**必写性来源须可溯**——来自 `R5 required_terms`（硬必写） / `R8 误区反面`（高频失分） / `工程通识`（逻辑必然），标来源即合规，不把非 R5 required_terms 的词当 R5 硬必写冒充。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句/算式串（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 Q02 §6 R8 误区 W1–W8 的 error_code）。
> - **版本状态**：`现行有效` / `旧说法仅背景` / `新规范优先·旧表述必须改写`——**写过期表述照样丢分**，这一件不可省。

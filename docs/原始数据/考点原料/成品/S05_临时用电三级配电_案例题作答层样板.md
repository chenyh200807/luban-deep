# S05 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`S05_临时用电三级配电.md`](./S05_临时用电三级配电.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**三级配电是哪三级、二级保护保哪两级、安全电压 36/24/12V 各对哪种场所、一机一闸什么含义、停送电谁先谁后、电缆埋多深、标识色怎么记**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建临时用电案例失分不是"不会"，是"会一点但写不成分"——指出共用开关箱不妥却不给"专用开关箱/严禁2台及以上"正确做法、答系统只写"三级配电"漏 TN-S 与二级漏保、安全电压只写"用安全电压"不写 36/24/12V 三档、停送电顺序写反。作答层的杠杆 = 把「知道架构与参数」变成「按 ①判断纠错三段式 + 阈值表计算判定 + 内容清单枚举写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 S05 §5 R5**（已 signed 的 candidate pack，A/B/C/D/E/F 六组 16 行）。本层「可写化四件套」从 R5 **逐字派生**，并对照 `_S05_compiled_source.json` 的 `quote`/`required_terms` 核真，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 S05 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E01/E02/E03/E04/E05/E06/E07/E10/E12、M03/M08/M10，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_S05_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2023·第1题}`、`{2017·第2题}`、`{2018·第17题}`、`{2016·第13题}`、`{2019·第14题}`、`{2020·第15题}`、`{2021·第5题}`），逐条经 Read 核验年份+题号+correct_answer 三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**判断纠错 + 计算判定链（安全电压/一机一闸阈值表）+ 内容清单**，验证句式库在安全/用电场景泛化用）。
> **三色铁律继承自 S05**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识/邻接背景（无单一 point_id，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、临界取舍）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写临时用电答案漏分，多是某一维整维漏掉（最典型：答系统题只写"三级配电"漏掉 TN-S 与二级漏保两块；判断纠错只指"不妥"不给正确数值）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 S05 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点中等：电工持证、拆除由电工完成） | 电工持证上岗（F1）、用电设备拆除由电工完成（F1 解析）、装饰阶段补编单项方案（F3） | 写"安全员可拆除""有经验可不持证"（主体写错） |
| **程序维** | 按什么顺序做（送电总→分→开、停电开→分→总） | 送电顺序（C1）、停电顺序（C2）、组织设计编/验/拆（S05 S5 场景） | 停送电顺序写反/只写一个（典型 0 分错项） |
| **条件维** | 达什么阈值才合格/才做（安全电压、电缆埋深、间距） | 安全电压 36/24/12V（E1/E2）、电缆埋地≥0.7m（D1）、开关箱配电箱≤30m（D2） | 36/24/12V 张冠李戴；0.7m 写成 0.5m；金属容器写 36V |
| **记录/计算表达维** | 留什么书面 / **写阈值判定链**（安全电压按场所定档、漏保参数判定） | 安全电压阈值表按场所判（E1）、漏电保护装置（外延 🔵） | 只写"用安全电压"不给场所对应数值；漏"含插座/2台及以上"判据 |
| **后果维** | 不达标/达标后会怎样（重大隐患、缺架构即不妥、漏电即跳） | 特殊环境未用安全电压=重大隐患（E3）、三大系统缺一即不妥（A1/A2/A3） | 只会"会触电"，不知"缺 TN-S/二级漏保 = 系统不完整不得分" |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。S05 是"系统架构 + 参数记忆 + 制度合规"三重型考点，**条件维（安全电压/电缆参数）与程序维（停送电顺序）是失分主战场**；判断纠错题里"主体/程序/条件/后果"四维都要扫。

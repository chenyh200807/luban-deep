**核心因果链(讲懂层骨架)：**

**为什么这些措施有效(讲解性，🔵 不充判分)：**
- **文明施工不是面子工程**：物理隔离(防风险) → 视觉标准化(提效率/降认知负荷) → 环境倒逼(养行为)，系统性降低现场管理混乱度。
- **扬尘三件套是"源头-路径-出口"立体防尘网**：源头覆盖固化让尘"飞不起来"、路径喷淋雾炮让尘"传不出去"、出口车辆冲洗让尘"带不出现场"。
- **噪声四步遵循"源强→传播→受体"经典路径**：优先源头降噪(选低噪设备)最经济，再隔断主要噪声源(隔声屏/封闭木工房)，最后工艺优化。
- **建筑垃圾分类计量=成本显性化**：每类垃圾被记录后，垃圾从"无主麻烦"变"有主数据"，倒逼各环节减量；末端资源化把固废处理成本转成再生骨料价值，形成"建设→拆除→资源化→再建设"闭环。

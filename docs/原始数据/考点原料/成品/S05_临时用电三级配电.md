## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「因果链 + 每段挂 point_id」，删除镜头 A 里无锚的力学/继电保护外推（如「人体电阻潮湿降至 500Ω」「选择性保护动作电流 30mA/0.1s」是合理工程解释但**无 point_id**，保留为 🔵 讲解性表述，不充判分）。

**核心因果链(讲懂层骨架)：**

```
施工现场电气风险源(绝缘劣化+人体易触电+频繁移动)        🔵原理(无单一point_id)
   │  潮湿/多尘/金属碰撞 → 绝缘破损 → 漏电/触电/电气火灾
   ▼
三大系统联防(架构层)：
   ├ 三级配电(总→分→开) → 分级隔离,逐级缩小故障影响  kc:1A431011_015_0016:0 / 014_0015:1  🟢
   ├ TN-S 接零保护 → PE 线独立,设备外壳接零,故障对地短路触发跳闸  kc:1A431011_015_0016:0  🟢
   └ 二级漏电保护(总箱+末级开关箱) → 双层剩余电流动作,人身后备双保险  kc:1A431011_015_0016:0  🟢
   ▼
末端控制(执行层)：
   ├ 一机一闸一漏(专用开关箱) → 故障设备就近单独断电,不牵连全场  kc:1A431011_014_0015:2  🟢
   ├ 停送电有序(开→分→总停 / 总→分→开送) → 防带负荷拉闸/反送电  kc:1A431011_015_0016:1  🟢
   └ 安全电压(特殊场所 36/24/12V) → 即便触电也低于致命阈值  kc:1A431011_015_0016:2  🟢
   ▼
效果 = 漏电即跳 + 故障就近隔离 + 触电不致命(三重兜底)
```

**为什么措施有效(讲解性,🔵 不充判分)：**
- **三级配电**：把"一个总闸管全场"拆成三级，故障只波及末端一台设备，缩小停电与触电范围。
- **TN-S + 二级漏保**：PE 线独立保证设备外壳故障时形成对地短路，漏保剩余电流动作；总箱 + 末级双层=人身保护后备。
- **一机一闸**：每台设备独立开关箱，故障就近断电、排查快，避免"一机故障全场停"。
- **安全电压分级**：环境越导电(金属容器/积水)，人体触电后果越重，故电压门槛越低(36→24→12V)。

> 三色提醒：因果链的**结论(三级/二级/36-24-12V/0.7m/一机一闸)**全部 🟢 锚定；链条里的**机理解释**(人体电阻、选择性保护动作电流时间、绝缘劣化)是讲懂用语，标 🔵，不得作为采分点输出（镜头 A 草稿里"30mA/0.1s/500Ω"等具体数已降级，见 §8 冲突 C1）。

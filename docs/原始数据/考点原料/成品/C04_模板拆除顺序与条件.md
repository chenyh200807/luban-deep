## 2 · 原理因果层（五环逻辑链）

> 主体来自 lens A（DeepSeek 最强项），汇编在第三/四环补了真题印证，并把第五环顺序口诀与 `0187:0` 原文对齐。

**① 强度的「成长曲线」**：混凝土强度随水化反应随时间增长，前快后慢；拆模看的是「达到设计立方体抗压强度标准值的百分率」，不是固定小时数。→ 这是「强度门槛」的物理根。

**② 受力角色分化**：模板=临时拐杖。
- **侧模**（梁/柱/墙侧面）：混凝土对它主要是「胀」不是「压」，几乎不吃力 → 只看「表面、棱角不因拆模受损」即可拆（🟢`kc:...0186:0`）。墙体大模板常温达 **1N/mm²** 即可拆。
- **底模及支架**（板/梁底）：是真吃劲的拐杖，本体结构必须能自扛自重+施工荷载才能撤 → 看强度百分率表。

**③ 跨度量化（为什么跨度越大要求越高）**：弯矩 M∝qL²，同厚度板跨度越大跨中弯矩越大，需更高强度抗弯。证据链 🟢`kc:...0185:0` + 🟢{2024,第10题}（四构件辨析）+ 🟢{2021,第9题}（6m板 C30 → 75% → 22.5N/mm²）。

**④ 快拆体系的「骗弯矩」逻辑**：规范要求快拆立杆间距≤2m、拆模时**保留立杆顶托**，等于把 8m 大跨人为切成≤2m 小跨，弯矩骤降 → 强度只需取 2m 跨度的 **50%**。🟢{2015,第10题}：8m楼板 C30 快拆，立杆 2m，最低强度=30×50%=**15MPa**。这就是「拆模≠拆支撑」。

**⑤ 拆除顺序的「倒装艺术」**（🟢`kc:...0187:0` 原文）：后支先拆、先支后拆；非承重先拆、承重后拆。逻辑：后支构件荷载小先撤，先支的根基（扫地杆/主梁支撑）最后撤；侧模先溜不动承重骨架，底模支撑是竖向力传递最后防线。

### 陷阱（出题人最爱埋的坑）

1. 🟢 **跨度分档边界值**：8m 是梁/拱/壳「≤8m→75%」与「>8m→100%」分界；板有 2m、8m 两档。{2024,第10题} D 项「悬臂梁 75%」是典型错——悬臂一律 100%。
2. 🟢 **快拆等效跨度**：8m 板快拆**按 2m 取 50%**，按真实 8m 取 100% 即落坑。{2015,第10题}。
3. 🟢 **侧模/底模混淆**：把「试块百分率」套到侧模，或把「表面棱角」套到底模。墙体大模板看 `1N/mm²`。
4. 🟢 **预应力隐藏条件**：同条件试件达设计强度 ≠ 可拆底模；预应力梁/板底模**必须张拉后**拆，有灌浆者灌浆≥C30。{2016,案例2}。
5. 🟢 **程序坑**：「口头申请」「现场生产经理申请」均不妥——须填拆模申请+同条件试块达标+**技术负责人批准**。`kc:...0190:1`。
6. 🟢 **拆除方式坑**：楼板底模**不得无控制大片塌落**；设警戒线、下方禁站人、上下呼应。`kc:...0190:2/:3`。

### R5 采分点

**采分点1 · 先判模板类型再判条件**（🟢`kc:1A413030_099_0186:0`）
侧模属「不承重侧模板」，条件不是跨度强度表，而是「保证表面、棱角不因拆模受损」；墙体大模板常温达 `1N/mm²` 即可拆。
拟挂错因：`ERR_CONCEPT_CONFLATION`（侧/底模混淆）。

**采分点2 · 底模及支架按构件类型+跨度套强度比例**（🟢`kc:1A413030_099_0185:0`）
板：≤2m→≥50%；2~8m→≥75%；>8m→≥100%。梁拱壳：≤8m→≥75%；>8m→≥100%。悬臂：≥100%。
拟挂错因：`ERR_NUMERIC_TABLE_MISMATCH`（百分率/断点混淆）、`ERR_CONDITION_EXTRACTION_INCOMPLETE`（题干跨度/构件类型提取不全）。

**采分点3 · 拆除顺序成对句**（🟢`kc:1A413030_099_0187:0`）
必须成对：「后支先拆、先支后拆；先拆非承重部分，后拆承重部分」。只写「从上到下拆/按方案拆」表达偏空，采分风险高。
拟挂错因：`ERR_SEQUENCE_ORDER`（顺序错/缺）、`ERR_SLOGAN_VAGUE`（口号化空表达）。

**采分点4 · 快拆体系抓「立杆≤2m + 保留立杆顶托」**（🟢`kc:1A413030_099_0187:0`）
立杆间距不应大于 `2m`；拆模保留立杆并顶托支承楼板；满足后按保留支撑的计算跨度判强度。
🟢真题锚 {2015,第10题}：8m楼板 C30 快拆立杆2m → `C30×50%=15MPa`。
拟挂错因：`ERR_CONDITION_EXTRACTION_INCOMPLETE`、`ERR_COMMONSENSE_OVER_SPEC`（用常识替代规范）。

### R6 满分答题骨架

1. 🟢 先判模板对象：侧模按「表面/棱角不受损」（墙体大模板常温抓 `1N/mm²`）。`0186:0`
2. 🟢 写拆除顺序：「后支先拆、先支后拆；先拆非承重，后拆承重」。`0187:0`
3. 🟢 涉底模/支架补强度条件：按「构件类型+跨度」达规定百分率后拆。`0185:0`
4. 🟢 涉快拆单独写：立杆≤2m；保留立杆顶托支承楼板。`0187:0`
5. 🟢 给了强度等级最后换算 MPa：如 {2015,第10题} C30 快拆 → 30×50%=15MPa。

**口播骨架**：🔵拆模不是「硬了就拆」，先分清是不是承重模板 → 🟢侧模看棱角、底模看跨度强度表 → 🟢顺序一句话「后支先拆、先支后拆；非承重先拆、承重后拆」 → 🟢快拆关键不是原跨度多大，而是有没有保留立杆顶托 + 立杆是否≤2m。

### R7 边界（🔴 全部 candidate，待真人/专家裁决，**不得直接当判分权威**）

**满分边界候选**
- 🔴 同时写出顺序成对句 + 区分侧模/底模/快拆三类条件。
- 🔴 快拆题写明「立杆≤2m + 保留立杆顶托」并按 `设计强度×比例` 算出最低强度。
- 🔴 涉底模时不只写百分率，还说明百分率取决于构件类型 + 跨度。

**压线边界候选**
- 🔴 只写顺序、未展开底模强度表：若题问「顺序」可能压线，若问「条件」分数风险高。
- 🔴 只写「达设计强度一定比例后拆」，未按板/梁/悬臂/跨度定比例：可能只给少量表达分。
- 🔴 快拆题只写「按2m跨度算」漏写「保留立杆顶托」：关键条件不完整。

**0分 near-miss 候选**
- 🔴 把侧模 `1N/mm²` 套到所有模板（「所有模板达1N/mm²即可拆」）。
- 🔴 顺序写反（「先拆承重、后拆非承重」）。
- 🔴 快拆题仍按原 8m 取 75%/100%，无视保留立杆顶托。
- 🔴 只答「按施工方案拆除」，无任何顺序/强度/快拆条件（口号化）。

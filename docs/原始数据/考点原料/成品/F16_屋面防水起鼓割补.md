## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写"起鼓成因→100mm 分档机理→割补工艺解密"三段；汇编层把镜头 A 的散文链收成"病因→机理→为什么这措施有效"+每链挂 point_id，**镜头 A 的"含水率/水汽膨胀/塑性变形/渗流"等机理解释无 point_id，保留为 🔵 讲解性表述、不充判分**。补入真题 `{2017,案例二}` 的完整割补工序作 🟢 工序骨架。

**核心因果链(讲懂层骨架)：先分档（按直径定路线）→ 后割补（割开放气→干燥→清理→重贴→封严）→ 闭环检验**

```
起鼓病灶: 基层含水率高/排气孔缺失 → 暴晒水汽膨胀 → 卷材密封下鼓胀成包    🔵机理讲解
   │
   ├─ 分档路线(判分眼): 直径<100mm → 抽气灌胶法(注胶抚平·不破整体)
   │                    直径≥100mm → 斜十字形割开、清理、吹干、重贴新贴方形卷材(切病根·重建)   kc:1A434000_076_0119:0  🟢
   │
   ├─ 割补工序(真题侧·≥100mm 路线展开): 用刀割开鼓泡 → 放出鼓内气体 → 擦干水分 → 清除旧胶结料
   │     → 喷灯烘烤槎口、分层剥开除旧胶 → 重贴新卷材 → 周边压实刮平 → 重做保护层   {2017,案例二}  🟢
   │
   └─ 闭环检验(判分眼): 排气孔通畅(疏导水汽,从源头防复发) / 基层平整干燥(否则二次起鼓) / 搭接长度泛水高度   kc:1A434000_068_0104:0  🟢
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **为什么按 100mm 分档**：小鼓(< 100mm)空腔小、卷材未产生不可回缩的塑性变形，注胶排气即可恢复粘结；大鼓(≥ 100mm)卷材已过度拉伸、胶结料大面积失效，简单灌胶无法根治，必须割开切病根、干燥基层、重贴重建（机理 🔵）。
- **为什么割开后必须"擦干/吹干"再贴**：起鼓的根因就是基层含水率高、水汽顶起卷材；若不把鼓内水分擦干、基层吹干就重贴，新卷材下水汽照样膨胀，**原地二次起鼓**（机理 🔵，呼应检验项"基层平整干燥"）。
- **为什么斜十字形割开**：斜十字形开口便于清理内部、分层剥开旧胶，且避免直线搭接缝形成连续"水路"，新卷材每条边都有足够搭接宽度（机理 🔵）。
- **为什么设排气孔**：起鼓本质是"水汽出不去"，排气孔把基层水汽疏导出去（疏而非堵），是预防起鼓的上游措施——治理(割补)与预防(排气孔)内在一致（机理 🔵，呼应 `kc:1A434000_068_0104:0`）。

> 三色提醒：因果链的**结论做法/数字**（100mm分档、抽气灌胶/割开重贴、割补工序、排气孔/基层干燥检查）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（含水率/水汽膨胀/塑性变形/渗流/疏导逻辑）是讲懂用语，标 🔵，不得作为采分点输出。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻（气球/吸尘器/放大镜）+ Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"先分档（量直径）→ 走割补工序（割开放气→干燥→重贴）→ 闭环检验（基层干燥/排气孔）逐点 reveal"**，删除镜头 D 误区清单里的自造码标签，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **起鼓"气球鼓包"**：屋面卷材下水汽顶起一个个鼓包（气球），暴晒太阳下鼓得更大——点出"水汽出不去"的根因。
- **分档"100mm 标尺"**：鼓包直径标尺——<100mm 注射器抽气灌胶抚平(绿)；≥100mm 斜十字形割开、吹干、重贴方形卷材(绿)；若大鼓也只抽气=鼓包复发红叉。
- **割补"外科手术链"**：割开鼓泡→放气（气体逸出）→擦干水分（水珠被吸走）→清除旧胶结料（铲除黑胶）→喷灯烘烤剥离→重贴新方形卷材→压实刮平→重做保护层，逐步打勾。
- **干燥"二次起鼓警示"**：若割补时不把基层吹干就重贴，新卷材下又冒水汽鼓起（红叉）——呼应"擦干/吹干"是防复发关键。
- **排气孔"疏导阀"**：基层水汽通过排气孔被疏导排出（绿），对照无排气孔=水汽憋在卷材下鼓胀（红）。
- **区分"双病害对照"**：流淌（高温下卷材往下淌·钉钉子法/切割法）vs 起鼓（潮气往上鼓·分档割补），并排亮起防混答。

### Reveal 顺序(讲懂 → 判分眼)
1. **起鼓根因**：气球鼓包 + 暴晒水汽顶起，流程条点出"水汽出不去"。(讲懂层骨架·机理🔵)
2. **分档定路线**：100mm 标尺滑过——小鼓抽气灌胶/大鼓割补。(锚 `kc:1A434000_076_0119:0`)
3. **割补工序**：外科手术链逐步打勾（割开→放气→擦干→清旧胶→重贴→压实→重做保护层）。(锚 `{2017,案例二}`)
4. **干燥防复发**：不吹干就重贴→二次起鼓红叉，强调擦干/吹干。(锚 `kc:1A434000_068_0104:0`)
5. **排气孔疏导 + 检验**：排气孔阀疏导水汽，检查基层干燥/搭接/泛水。(锚 `kc:1A434000_068_0104:0`)
6. **姐妹病害区分**：流淌 vs 起鼓双病害对照，治理法各不同。(锚 `kc:1A434000_076_0118:0`)

### Aha 时刻(锚已按内容精确挂)
- 100mm 标尺一滑：小鼓一针抽气灌胶就平，大鼓必须割开重贴 → 「起鼓按 100mm 分档，大鼓胶结料大面积失效不能只抽气」。锚 `kc:1A434000_076_0119:0`
- 割补时若不擦干就重贴，新卷材下又冒水汽鼓起 → 「割补不究因（基层不干燥）等于白割，擦干/吹干是防复发命门」。锚 `kc:1A434000_068_0104:0`、`{2017,案例二}`
- 排气孔一开，憋在卷材下的水汽顺着孔排出去 → 「起鼓本质是水汽出不去，排气孔疏导=从源头防起鼓」。锚 `kc:1A434000_068_0104:0`
- 流淌往下淌（钉钉子法）vs 起鼓往上鼓（割补），同是卷材病害药方完全不同 → 「对症不混答，看清病害方向再下药」。锚 `kc:1A434000_076_0118:0`、`kc:1A434000_076_0119:0`

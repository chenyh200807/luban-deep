## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「四段程序链 + 每段挂 point_id」，删除镜头 A 里无锚的伪 node_code 与「梁跨度阈值」叙述中证据包外的数字外推（真题锚改挂 `{2015, 案例1}` 实读值）。

**核心程序链(讲懂层骨架)——J01 不讲"危险怎么发生",讲"管理程序怎么把危险关进笼子"：**

```
工程参数(深度/高度/跨度/荷载/重量)        kc:1A436000_008_0011:0  🟢
   │  第一道闸:按阈值判"是不是危大工程"(达一般档→编专项方案)
   ▼
是否超过一定规模?                          kc:1A436000_009_0012:0  🟢
   │  第二道闸:超规模阈值→不仅编方案,还要"专家论证"
   ▼
专项施工方案(谁编 + 编什么)
   ├ 编制主体:总包组织编/分包可由专业承包编  cc:1A436000_008_0011:3/4 🟢
   └ 必含内容:概况/依据/计划/工艺/保证/人员/验收/应急(基坑8项) cc... kc:1A431000_008_0008:0 🟢
   ▼
论证前置程序(超规模才走)
   施工单位审核 → 总监理工程师审查 → 专家论证   cc:1A437000_010_0013:3 🟢
   │  顺序不可颠倒:先审后审查再论证(程序顺序=高频纠错点)
   ▼
专家论证会(谁组织 + 专家组要求)
   总包组织 / 专家≥5人 / 无利害关系 / 报告签字  cc:1A437000_010_0013:2、ca... 🟢
   ▼
实施控制(论证通过后)
   公示 + 方案交底 + 不得擅自修改 + 监测巡视    kc:1A436000_010_0011:0 🟢
   ▼
效果 = 用"分级管理 + 前置审查 + 专家把关 + 过程控制"把高风险工程的方案缺陷在开工前筛掉
```

**为什么程序这样设计(讲解性,🔵 不充判分)：**
- **两道阈值闸**：一般危大→编方案(企业自审)；超规模→额外加专家论证(社会化外部把关) —— 风险越高，把关层级越高。
- **先审核后审查再论证的顺序**：方案先由施工单位内部审核(对不对)、再由总监审查(合不合规)，**专家论证不是第一道关而是最后一道关** —— 把企业能自己解决的问题挡在论证会之前，专家只论真正的疑难。
- **专家≥5人 + 无利害关系**：人数下限保证集体决策、回避保证独立性 —— 与「参建各方人员不得以专家身份参加」是同一独立性原理(真题 `{2019, 案例二}` 直命此点)。
- **不得擅自修改**：论证通过的方案是「冻结基线」，改了等于论证作废 —— 故"擅自修改"是法律后果触发点。

> 三色提醒：因果链的**结论阈值数字**(3m/5m/8m/18m/24m/100kN/300kN/≥5人)全部 🟢 锚定；链条里的**程序为什么这样设计**(把关层级、冻结基线)是讲懂用语,标 🔵,不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人) 主写,汇编层精简为一句 + 保留 6 场景印证,逐场景重核真题锚(改正了镜头 A/C 沿用的 `{2015, 案例1}` 在"清单补全"语境的误用——清单补全真锚是 `{2015, 案例3}`；见 §8 冲突 C2)。

**不变量(一句话)：**
> 凡遇危险性较大的分部分项工程，判分永远沿「**①按阈值定档(危大？超规模？)→ ②专项方案(谁编+编什么)→ ③超规模则论证(先审核→再审查→后论证 / 专家≥5人无利害)→ ④实施不得擅自改**」这条**分级—编案—论证—控制**程序链走。出题人几乎不考分项工程怎么施工，只考「**这一步该不该做 / 由谁做 / 程序对不对 / 内容全不全 / 数字够不够档**」。

换言之：判分核心 = **分档阈值是否判对 + 编制主体/内容是否齐 + 论证触发与程序是否合规 + 专家组与实施控制是否达标**。任一环错位即「不妥」。

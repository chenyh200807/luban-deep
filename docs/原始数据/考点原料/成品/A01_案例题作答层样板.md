# A01 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`A01_检验批验收程序.md`](./A01_检验批验收程序.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**这一级该不该验、由谁组织、合格判定阈值是多少**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建案例失分不是"不会"，是"会一点但写不成分"——漏采分点 / 答非所问 / 只写结论不写理由 / 程序顺序错 / 主体写错 / 阈值数字记反。作答层的杠杆 = 把「知道什么」变成「按阅卷结构写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 A01 §5.1 R5**（已 signed 的 candidate pack）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 A01 §5.3 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E04/E05/E06/E07/E08/E10/E11、M08/M10，经真实 Read 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：A01 **没有**独立 `_A01_exam_evidence.json`。真题只引 A01 pack §8.3 **真题锚白名单**内的 `{年份·题号}`（如 `{2017·案例·问4}`）；白名单外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，验证"会看答案→会写答案"跃迁 + 实测句式库泛化用）。
> **三色铁律继承自 A01**：🟢 采分点锚定 A01 R5（教材锚 point_id / 真题锚白名单）｜ 🔵 作答策略·句式（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、临界取舍）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写答案漏分，多是某一维整维漏掉。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 A01 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁来组织/参加/见证（验收主体、检验组织主体） | 分部由总监理工程师组织；实体检验由监理组织、施工实施、监理见证 | 写"施工单位验收"含糊，把组织主体答反 |
| **程序维** | 按什么顺序验（自下而上不可颠倒） | 检验批→分项→分部→单位；自检→报监理→隐蔽验收→进下道 | 验收方向倒装（从大往小拆）；跳过隐蔽验收节点 |
| **条件维** | 达什么阈值才合格/才划批（合格判定阈值、划分依据） | 主控全合格/一般≥80%；实体强度均值≥88%、最小≥80%；外墙1000㎡一批 | 阈值记反（88%/80%倒置）、主控也套80% |
| **记录维** | 要留什么书面/检验内容清单/见证记录 | 实体检验四项内容；单位工程合格五条；隐蔽验收记录 | 实体检验只答强度漏三项；合格五条漏项 |
| **后果维** | 不合格如何处理 / 达标后果（决策分支） | 返工→重验/资料缺→委托检测/返修加固仍不满足安全→严禁验收 | 只会"返工重来"，不知让步接收/严禁验收档 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**，比"逐字找差"更快定位"差哪句"。

## 1. 采分点可写化表（从 A01 §5.1 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚 point_id」**逐字来自 A01 §5.1 R5**（C1–C6 簇，已 signed candidate pack）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（≈ R8 误区"关键词缺失"的反面）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 A01 §6 R8 误区的 error_code）。
> - **版本状态**：`现行有效` / `旧说法仅背景` / `新规范优先·旧表述必须改写`——**写过期表述照样丢分**，这一件不可省。
> 再标**五维**命中哪维。**采分点本身不增不改**。

## 5. 实测报告（本次任务核心目的之一 · 如实回答，不为"复用"硬套）

### a. 用到 skill §1.③ 句式库哪几类？

用到 **5 类**（共 8 类）：**① 判断纠错 / ③ 程序 / ④ 验收 / ⑥ 主体定位 / ⑦ 内容清单枚举**。
未用 3 类：**② 措施（人材机法环记六维）**——A01 无"措施补充"型问法；**⑤ 索赔**——A01 非索赔考点；**⑧ 事故处理**——A01 是验收程序非事故处理。勾选明细见 §2 表。

### b. 有没有遇到句式库覆盖不了、需要新造句式的情况？

**有一处张力，但最终未新造句式，靠"组合 + 注记"覆盖。**

具体结构：**C4-4 结构实体强度合格判定题**（S4 合格判定计算型）——它的作答结构是「**先列双阈值规则（88%/80%）→ 代入数据计算 → 判合格/不合格 → 写判定依据**」，是一个"**计算 + 阈值判定**"复合形态。skill §1.③ 8 类里**没有"计算判定类"句式**（最接近的 ⑦内容清单只解决"列规则"、③程序只解决"列步骤"，都不含"代数据算 + 卡阈值下结论"这一段）。

**为什么 8 类不够**：8 类全部是**定性陈述型**句式（判断/枚举/定位/排序），而案例计算题（A01 的 S4、索赔计算、网络图工期、成本计算等）需要的是**"规则→代入→结论→依据"四段计算句式**，这是定量型作答结构，现有 8 类没有对应骨架。

**本次处置**：A01 只有 C4-4 一道计算判定题，且其计算本身简单（套 88%/80%），我用 **⑦内容清单（列双阈值规则）+ 显式计算步骤 + 结论句**组合表达，并在改写中**显式补"判定依据"段**覆盖了，未单独新造句式（守 less is more，不为一道题立新类）。**但这是一个真实的句式库覆盖缺口**——见 d. 建议。

> **缺口闭合更新（第 9 类补入后）**：skill §1.③ 现已正式补入**第 9 类「计算判定链」**（`亮判据/公式→代入列式→数值结论→回判规范`，A01 强度判定 / N01 关键线路时差 / K01 索赔金额三方实测撞同一缺口后补入）。C4-4 强度合格判定题的作答结构正对应该类——**A01 计算判定缺口已闭合，原"⑦内容清单+显式计算步骤"组合绕过方案归位**为第 9 类（作答内容不改，仅加归类标注，见 §2 勾选表 ⑨ + §3.3④）。

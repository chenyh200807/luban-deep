# D11 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`D11_抹灰工序与质量控制.md`](./D11_抹灰工序与质量控制.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**抹灰总厚度到几毫米要加强、加强网搭接多宽、基层含水率分对象控到几、内墙抹灰层平均总厚多少、室内抹灰温度下限、哪些部位用耐水腻子**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建抹灰/质量控制案例失分不是"不会"，是"会一点但写不成分"——交接处防裂只写"挂网"漏"搭接≥100mm"、厚抹灰只写"厚了要加强"漏"≥35mm"、含水率不分对象（溶剂型/乳液型/木材 8/10/12 混）、抹灰层平均总厚 20/25 张冠李戴、室内温度写 0℃、耐水腻子部位漏地下室、把外保温"薄抹灰"当一般抹灰答。作答层的杠杆 = 把「知道阈值」变成「按**判断纠错三段式 + 内容清单枚举 + 交接处防裂措施（裁剪）**写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 D11 §5 R5**（已 signed 的 candidate pack，A1/A2/B1/B2/C1/C2/C3/D1/D2 九组 + E1 涂饰外延）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**；每个采分点的内容/必写词/锚已回读 `_D11_compiled_source.json` 对应 point_id 的 `quote`/`required_terms` 核真。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 D11 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E06/E07/E10/E11、M01/M03/M06/M07/M08，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_D11_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2023·第26题}`、`{2018·第24题}`、`{2022·第21题}`、`{2023·第2题}`、`{2024·第14页}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。⚠️ 证据包 68 命中里大量是 keyword 误命中的**非抹灰本体题**（防水混凝土养护/BIM/吊篮/回填土/桩基等），已剔除，只用 §1 表中真正考抹灰加强/交接防裂/含水率/耐水腻子/抹灰质量通病的题。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**判断纠错 + 内容清单枚举 + 交接处防裂措施（裁剪）**，验证句式库在"数值阈值密集 + MCQ 为主"考点泛化用）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写抹灰质量控制答案漏分，多是某一维整维漏掉或数值张冠李戴（最典型：交接处防裂题只写"挂网"漏"搭接≥100mm"这一条件维数字；含水率题不分对象整维混）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维、不混值。

| 维 | 含义 | 在 D11 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点几乎不命中，抹灰工序隐含"施工单位"，无"由谁组织"独立采分点） | 隐含施工单位作业，无显化主体采分点 | 本考点主体维占比极低，不单独成采分点（见 §2 不勾选 ⑥） |
| **程序维** | 按什么顺序做（有锚的控制链 / 后续工序不抢跑） | 控基层含水率→控厚度→交接防裂→控环境→控材料（R6 满分链）；涂饰在抹灰湿作业后（E1 外延） | 把外保温薄抹灰当一般抹灰工序答（→E11）；⚠️ **底中面三层工序无锚，不写进采分点** |
| **条件维** | 达什么阈值才合格/才做（厚度/搭接/含水率/层厚/温度数字） | 总厚度≥35mm 须加强（A1）；加强网搭接≥100mm（B2）；含水率 8/10/12 分对象（C1/C2/C3）；普通抹灰层≤20mm/高级≤25mm（A2）；室内温度≥5℃（D1） | 数字张冠李戴（搭接写 50mm、温度写 0℃、层厚 20/25 互换、含水率不分对象）（→M08/E07） |
| **记录/计算表达维** | 留什么书面 / 写定量结论（本考点弱，无独立记录/计算采分点） | 抹灰质量控制要求按"基层/厚度/交接/环境/材料"分层枚举（表达结构） | 写散句参数不稳定、空泛"按规范抹灰"无可判分措施（→E04） |
| **后果维** | 不达标/达标后会怎样（脱层/空鼓/面层爆灰/开裂；潮湿处普通腻子粉化脱落） | 抹灰层脱层/空鼓/面层爆灰/裂缝/不平整/接槎抹纹明显（质量通病，`{2024·第14页}`）；耐水腻子防潮湿粉化 | 只会"会裂会鼓"，不对应到具体阈值与措施（→E02） |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。D11 是"数值阈值密集 + MCQ 为主"考点，**条件维（数字达标 + 适用对象）是失分主战场**；记录/计算表达维与主体维本考点弱、照实标占比低。

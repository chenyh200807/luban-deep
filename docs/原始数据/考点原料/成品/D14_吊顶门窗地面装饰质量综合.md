## 🎯 R0 母题定位

**一句话母题**：D14 考的不是“背一堆装饰装修零碎参数”，而是让学生在一个装饰质量场景里先识别子域，再把问题落到该子域的唯一控制线：**吊顶看骨架受力与防裂，地面看界面/流程/空鼓，门窗看连接禁令与节能性能**。

| 子域 | 真正考的能力 | 出题人常换的外皮 | 答题总开关 |
|---|---|---|---|
| 吊顶 | 能把暗龙骨吊顶的“先后顺序、吊挂体系、主次龙骨、石膏板固定、防裂构造”合成一条受力连续链 | 工序排序、吊杆超长、风管处吊挂、次龙骨搭接、石膏板裂缝、起拱 | 先保骨架稳定，再保面板自由固定和缝处释放 |
| 地面 | 能把石材/瓷砖/竹木/地毯面层分别归入正确工艺，并解释板块空鼓为何发生 | 工序排序、浸砖/浸湿、防碱、毛地板开槽、地毯倒刺板、空鼓原因 | 先处理基层和材料吸水，再控制结合层、伸缩缝和养护 |
| 门窗 | 能如实承认源料弱，只抓两个强判分眼：砌体上禁射钉、门窗节能性能问题 | 射钉固定、门窗节能查验、传热系数/气密性/露点/透射比、外窗检测 | 不扩写门窗完整安装工艺；只答有锚的禁令和性能指标 |

**母题不变量**：装饰装修面层失败通常不是最后表面“丑”，而是前一层控制断了：吊顶是吊挂/龙骨/面板连续性断，地面是基层-材料-结合层界面断，门窗是连接或围护节能性能断。答题必须先定位断点，再写对应的硬参数或禁令。

**出题人意图融入点**：
- R0 定位：识别“问题属于哪条控制线”，避免装饰域混答。
- R4 变体：同一母题通过工序、数字、禁令、通病、真题场景换皮。
- R5 采分：每个采分点只归一个子域，不用“加强管理、保证质量”替代可判分术语。

## 🧠 R2 原理因果层

### 2.1 吊顶：为什么“顺序 + 骨架 + 防裂”必须一起考

```
吊挂点/吊杆不可靠
  → 主次龙骨间距或连接失控
  → 石膏板固定受约束或接缝应力集中
  → 顶棚开裂、变形、局部松动
```

- 🟢 **工序先水电再龙骨**：暗龙骨工序把水电管线排在主副龙骨和罩面板之前，避免后续管线施工破坏已成型骨架。锚：2016年第11题。
- 🟢 **吊杆超长不是“多吊一根”能解决**：吊杆>1500mm需反支撑，>2500mm需钢结构转换层，本质是把细长吊杆的侧向失稳风险转移到稳定支撑体系。锚：`kc:1A413030_138_0267:0`。
- 🟢 **主次龙骨参数是面板裂缝的前置条件**：主龙骨≤1200mm、悬臂≤300mm；次龙骨≤600mm且不得搭接，洞口设附加龙骨。骨架不稳，后续嵌缝再好也只是遮丑。锚：`kc:1A413030_139_0268:0`、`kc:1A413030_139_0268:1`。
- 🟢 **石膏板从中间向四周自由固定**：这是让板材在固定过程中释放微变形，不把初始应力锁进板缝；双层板接缝错开、钉眼防锈，分别防贯通裂缝和锈斑。锚：`kc:1A413030_139_0268:2`。
- 🟢 **顶棚防裂是“五点系统”**：吊筋间距、拼缝错缝不密拼、螺钉牢固、转角加强、嵌缝饱满，对应“骨架刚度、缝处释放、连接可靠、应力集中、表层封闭”。锚：`kc:1A434000_078_0124:0`。

### 2.2 地面：为什么空鼓题不能只答“材料不好”

```
基层污染/材料吸水/结合层失水
  → 水泥水化不足或界面咬合失败
  → 板块与基层分离
  → 空鼓、局部松动、使用功能下降
```

- 🟢 **石材浸湿晾干、瓷砖浸泡阴干**：源料直接支持“浸湿/浸泡处理可防止吸水导致空鼓”；其讲解机理可概括为先控制材料吸水，再进入铺贴结合层。锚：`kc:1A413030_140_0272:1`、`kc:1A413030_140_0273:1`。🔵 “表面无明水/避免水膜”等细化机理需另取规范或教材原文，不作采分点。
- 🟢 **瓷砖流程中“浸砖”必须在铺砂浆前**：2025年第15题把“浸砖”作为排序眼，说明命题人不是考会不会铺，而是考能否把吸水预处理放到结合层之前。
- 🟢 **地面空鼓五措施各对一个断点**：基层清理切断隔离层；水泥基粘结材料保证粘结；界面剂+背砂解决油性防护石材难粘；伸缩缝释放变形；养护保证强度形成。锚：`kc:1A434000_078_0123:0`。
- 🟢 **竹木地板和地毯不是“湿贴类空鼓题”**：竹木地板考搁栅、采用整张毛地板时开槽、离墙10mm和方向；地毯考裁剪余量、倒刺板、衬垫、拉伸和接长。锚：`kc:1A413030_141_0274:0/1/2`、`kc:1A413030_141_0275:0/1/2`。
- 🔵 **石材防碱与空鼓同属“水分通道控制”但不是同一采分点**：2017年第11题、2022年第20题支持地面石材防碱；D14 compiled source 未把防碱列为独立地面采分点，所以防碱可作真题变体锚，不并入 `kc:1A434000_078_0123:0` 的空鼓五措施。

### 2.3 门窗：为什么本 pack 不扩写完整安装工艺

```
门窗题在 D14 源库里的强事实很少
  → 能签的只有连接禁令与节能性能
  → 任何完整安装工艺扩写都会制造假权威
```

- 🟢 **射钉禁令是连接可靠性问题**：砌体局部抗冲击和握裹能力不足，射钉会破坏基层，导致框体松动和密封失效；所以法规锚直接写“严禁”。锚：`kc:1A422000_043_0069:0`。
- 🟢 **门窗节能题考的是围护性能指标**：类型、传热系数、气密性、中空玻璃露点、可见光透射比是可检查指标，不是泛泛“门窗质量差”。锚：`kc:1A434000_080_0129:0`。
- 🟢 **真题侧补了查验/检测语境**：2016年第20题和2023年第27题把门窗放入节能材料设备查验；2019年第2题补外窗气密性、水密性、抗风压性能。本文如实标出这些是“真题侧补强”，不是 compiled source 的完整门窗工艺。

### 3.2 Reveal 顺序

1. **先出母题分流**：同一“装饰质量问题”题干，画面分成吊顶、地面、门窗三条轨道，提示不能混答。
2. **吊顶轨道**：2016年第11题工序条先排序，再叠加 `>1500mm`、`>2500mm`、主龙骨≤1200mm、次龙骨≤600mm、石膏板螺钉150-170mm，最后落到防裂五点。
3. **地面轨道**：2025年第15题瓷砖流程先排序，再切到石材浸湿晾干、瓷砖清脱模剂浸泡阴干、空鼓五措施、竹木/地毯两个非湿贴分支。
4. **门窗轨道**：先展示砌体射钉错误被红叉，再展示节能检测仪表的五个指标；旁边挂出“source_ref 弱，不扩写工艺”。
5. **收束**：三个轨道合成一句：“装饰质量题先分域，后找断点，最后写硬锚。”

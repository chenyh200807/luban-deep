## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「高强螺栓摩擦传力 / 焊接微区冶金」两条因果链；汇编层把散文链收成段，每段挂 point_id，**删除镜头 A 里无锚的力学外推**（氢致裂纹、马氏体组织、应力集中等机理为讲解性表述，标 🔵 不充判分）。

```
高强螺栓连接 ── 摩擦传力 ──▶ 巨大预拉力把板件"夹紧" ──▶ 接触面摩擦力传外荷载
   kc:1A413030_109_0216:0 🟢(连接方法含高强螺栓)、kc:1A422000_037_0061:2 🟢(需保证预拉力)

        │  成败在"内在"(熔池质量)

```

**为什么措施有效(讲解性，🔵 不充判分)：**
- 高强螺栓"以夹具代销钉"：预拉力把板件压紧产生摩擦力，外荷载未克服摩擦前板件无相对滑动、母材不因开孔削弱——机理 🔵，但"摩擦连接靠预拉力传力"的结论 🟢（`{2019,第9题}`）。
- 摩擦面忌油污/标记：任何油膜或笔迹降低摩擦系数 → 抗滑移承载力下降。机理 🔵，"摩擦面须洁净不得标记"结论 🟢。
- 焊接控环境/材料：湿度高/低温/强风易致氢致裂纹、夹渣、气孔等缺陷——机理（氢致裂纹、马氏体）🔵，环境阈值结论 🟢。
- 焊接电流太小 → 熔渣来不及上浮 → 固体夹渣：机理 🔵，"电流太小是夹渣主因"结论 🟢（`{2018,第12题}`/`{2021,第8题}`）。

> 三色提醒：因果链的**结论数字/限值**（≥2个 / 1/3 / 30% / 1.2D / −10℃ / ≤90% / ≤8m/s / ≤2m/s / 1~48h / >21m / 3~4吊点）全部 🟢 锚定；链条里的**机理解释**（摩擦系数、氢致裂纹、马氏体、熔渣上浮动力学）是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 命题情境千变，下列「判分眼」恒不变(每条附 🟢 锚)。

1. **连接方法四分法**：钢结构连接=焊接 / 普通螺栓 / 高强度螺栓 / 铆接；不可把"吊装/制孔/防腐"误作连接方法。
   🟢 教材锚 `kc:1A413030_109_0216:0`；真题印证 `{2015,第25题}`(网架节点含焊接空心球/螺栓球，拉铆不适用 BCDE)。

2. **高强螺栓=摩擦连接**：广泛采用摩擦型，靠预拉力使接触面摩擦传力；高强螺栓拆卸后不得重复使用。
   🟢 真题锚 `{2019,第9题}`(高强螺栓广泛采用→D 摩擦连接)；教材锚 `kc:1A413030_109_0216:0`、`kc:1A422000_037_0061:2`。

3. **焊接连接优点 vs 检查软肋**：优点=节约钢材/构造简单/易自动化/加工方便；软肋=内部缺陷难检查，须探伤。
   🟢 真题锚 `{2017,第23题}`(优点→ABCD，E"易于检查"错)；教材锚 `kc:1A413030_109_0216:1`。

4. **焊缝固体夹渣主因=焊接电流太小**（及速度太快/熔渣未清除）：非"焊前未预热/焊条未烘烤/焊后冷却快"（那些对应裂纹/气孔）。
   🟢 真题锚 `{2018,第12题}`(夹渣→C)、`{2021,第8题}`(夹渣→C，解析直引电流太小)；教材锚 `kc:1A434000_074_0116:0`。

5. **疲劳验算禁四焊**：动荷载且需疲劳验算时严禁塞焊/槽焊/电渣焊/气电立焊接头。
   🟢 真题锚 `{2023,第24题}`(严禁→ABCD)；教材锚 `kc:1A422000_038_0062:1`。

6. **高强螺栓安装数量纪律**：安装螺栓≥2个且≥安装孔1/3；冲钉≤安装螺栓30%；不得用高强螺栓兼作安装螺栓；必须自由穿入、禁气割扩孔(≤1.2D)。
   🟢 教材锚 `kc:1A413030_110_0217:0`、`kc:1A413030_111_0218:0`；案例印证 `{2015,案例2}`(钢构件安装检查/地脚螺栓)。

7. **焊接/连接主控四件套**：焊材烘焙 + 焊工持证 + 一二级焊缝无损检测 + 摩擦面抗滑移试验；终拧后1~48h检查；首次采用的钢材/焊材/焊接方法/位置须做焊接工艺评定。
   🟢 教材锚 `kc:1A434000_068_0102:0`；案例印证 `{2016,案例2}`(首次采用钢材/焊材/焊接方法/位置须工艺评定)。

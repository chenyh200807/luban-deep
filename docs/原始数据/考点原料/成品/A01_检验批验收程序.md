## 2 · 原理因果层（动画与 AI 理解的灵魂）

把 247 个散点压成一条**"质量风险层层拦截"的因果逻辑链**。每个论断标三色——🟢=源料/真题锚到，🔵=工程通识（合理但源料未逐字证），🔴=待验证（源料无、真题无，禁当🟢讲）。

### 2.1 主因果链：为什么是"层层把关"

```
单点缺陷 → 若不就地拦截 → 被下一道工序覆盖 → 隐患永久封存进结构 → 整改成本指数级上升/不可逆
        ↘ 所以：在缺陷"还看得见、还够得着、还没被覆盖"时就验收拦截
```

1. **🟢 验收单元自下而上分层（检验批→分项→分部→单位），因为"质量是逐层累积起来的"。**
   - 锚：`kc:1A422000_021_0029:1` 明列四级层级 + 划分依据。
   - 因果：检验批是**最小可验收颗粒**（一个工程量/一个楼层/一个施工段）。颗粒小=缺陷暴露在最小范围、最早时点。把关越靠下层、越靠前，被拦截的缺陷波及面越小、整改越便宜。

2. **🔵 验收方向"下一级合格是上一级前提"，不可跳级**（4 源异源团 Codex/DeepSeek/Qwen 收敛降级：引用的 `_084_0135`/`_082_0131` quote 只锁定"隐蔽验收前置"这一工序的时间刚性，是普遍逐级前提的**必要非充分**证据；完整逐级前提需回 GB50300 §3.0.x 通用规则补锚）。
   - 锚：`kc:1A434020_084_0135`（主体验收前孔洞须做隐蔽验收记录，**未经验收不得进装饰装修**）；`kc:1A434020_082_0131:0`（地基基础未验收**不得进回填土分项**）。
   - 因果：上层验收**消费**下层的合格结论。若检验批没合格就放行分项，分项的"合格"建立在未经核验的地基上——**authority 断裂**，风险静默传导到单位工程。这是"层层把关"的硬连锁。

3. **🟢 主控项目（否决项，必须 100% 合格）vs 一般项目（允许偏差，合格率门槛）——为什么这么分？**
   - 锚：`kc:1A422000_045_0071:1`（主控项目全部合格 + 一般项目合格率≥80%）。
   - 因果：主控项目**直接决定结构安全/主要使用功能**（如混凝土强度、钢筋）——这类缺陷**不可补偿、后果灾难性**，所以是**否决逻辑**（一票否决）。一般项目影响观感/次要功能，缺陷**可控、可局部修复**，所以用**容差逻辑**（允许一定不合格率，避免"零容忍"导致工程瘫痪）。**风险等级决定判定逻辑的刚柔**——A01 最深的命题考点。

4. **🟢 验收程序顺序"施工方自检合格→报监理→隐蔽工程验收→合格才进下道"不可颠倒。**
   - 锚：`kc:1A438000_153_0246:0`（材料：现场验证→报监理审批→合格才用）；`kc:1A434020_084_0135`（隐蔽验收记录前置）；`kc:1A434020_085_0137`（分部由总监理工程师组织）。
   - 因果（三个不可颠倒的理由）：
     - **(a) 自检在前**：施工方是质量第一责任人，必须先自我闭环，**监理验的是"已自检合格"的成果**，不是替施工方查错。颠倒=责任错位。
     - **(b) 隐蔽验收必须在覆盖前**：隐蔽工程（钢筋、孔洞、保温层）一旦被下道工序覆盖就**物理上够不着了**。`kc:1A434020_084_0135` 的"未经验收不得进装饰装修"就是这条铁律的法律表达——**时间窗口一次性，错过即不可逆**。
     - **(c) 合格才进下道**：下一级把关消费上一级结论，顺序即 authority 传递方向，反向即假合格。

5. **🟢 结构实体检验=对"自检+验收"链路的独立复核（监理组织、施工实施、监理见证）。**
   - 锚：`kc:1A434020_085_0136:1`（监理组织、施工实施、见证全过程）；`:2`（强度优先同条件养护试件，不足用回弹-取芯兜底）。
   - 因果：前面四级验收是**过程证据**，实体检验是**结果证据**——用实测的混凝土强度/保护层厚度，反向验证"过程合格"是否真合格。这是层层把关的**最后一道独立校验闸**。真题 {2017·案例·问4} 的 88%/80% 判定就是考这道闸。

6. **🟢 终点红线：返修加固后仍不满足安全/重要使用功能→严禁验收。**
   - 锚：`kc:1A434020_088_0146:1`。
   - 因果：层层把关的最后兜底——**安全是不可让步的终极否决项**。一般缺陷可返修、可让步接收（🔵让步接收细则源料未逐字，标🔵），触及结构安全的，整条拦截链的意义就是"宁可推倒不验收"。

### 2.3 一句话压缩（动画旁白可直接用，🟢锚定）

> "**缺陷只在它还看得见、够得着、没被盖住的那一刻最好拦。** 所以建筑验收把工程切成最小的'检验批'，自下而上一层层验：施工方先自检合格，再报监理；看不见的隐蔽工程必须在被盖住前验收记录在案；**决定安全的主控项目一票否决，影响观感的一般项目才给容差**；最后用结构实体检验独立复核一次。每一级合格，是上一级能验收的前提——顺序不能颠倒，因为颠倒了，假合格就会被结构永远封存。"
> （锚：层级=`_021_0029:1`；隐蔽前置=`_084_0135`；主控/一般=`_045_0071:1`；实体检验=`_085_0136`；不合格红线=`_088_0146:1`）

## 6 · R8 误区 → error_code → 解药

> 每条结构：**现象**（卷面/对话真实表现）→ **错误心智模型**（背后那条错的内部规则）→ **解药**（要把哪条对的规则装回去）→ **锚**。

**R8-1 ｜ 把"一般项目合格率≥80%"误当成"主控项目也能 80%"**
- error_code：`E10 规范适用错误`（code_application）＋客观题侧 `M08 规范数字混淆`
- 现象：答检验批合格条件时写"主控和一般项目合格率均达 80% 即合格"，或选择题把 80% 套到主控项目头上。
- 错误心智模型："合格标准 = 一个统一的百分比门槛"——把主控/一般压成同一类。
- 解药：主控项目是**否决项**——必须**全部合格**（0 容忍）；只有**一般项目**才走"合格率≥80%、最大偏差≤1.5 倍允许值"的弹性门槛。两条是**不同性质**的规则。
- 🟢锚（教材）：`kc:1A422000_045_0071:1`。🔴待验证："一般项目最大偏差≤1.5 倍允许值"为🔵工程通识，源料 quote 未逐字含 1.5 倍表述。

**R8-2 ｜ 验收顺序倒装：先分部后分项，或跳过检验批**
- error_code：`E06 程序顺序错误`（transfer）
- 现象：写成"分部→分项→检验批"，或从"分项"起步漏掉检验批。
- 错误心智模型："验收是从大往小拆"——按行政直觉自上而下。
- 解药：验收**自下而上逐级累积合格**：检验批→分项→（子分部→）分部→单位。下一级全合格是上一级前置条件。
- 🟢锚（教材）：层级 `kc:1A434020_086_0142:0`、`kc:1A434020_083_0134:0`；竣工总程序 `kc:1A422000_021_0029:2`。🔴：独立排序真题证据包**未命中**，禁凭记忆补"某年第 N 题"。

**R8-3 ｜ 结构实体检验"只记混凝土强度"，漏钢筋保护层/尺寸偏差**
- error_code：`E02 采分点遗漏`（expression）
- 现象：只答"混凝土强度"，漏掉钢筋保护层厚度、结构位置与尺寸偏差、合同约定项目。
- 错误心智模型："实体检验≈测一下混凝土强度"——多项清单坍缩成最熟的代表项。
- 解药：固定四件套：①混凝土强度 ②钢筋保护层厚度 ③结构位置与尺寸偏差 ④合同约定项目。
- 🟢锚（教材）：`kc:1A434020_085_0136:0`。🟢锚（真题）：{2020·案例二·问4}{2023·问4}{2025·背景三·问2}。

**R8-4 ｜ 结构实体检验"组织主体"张冠李戴（以为施工单位自己组织）**
- error_code：`E07 概念混淆`（code_application）
- 现象：答"实体检验由施工单位组织实施"或"由建设单位组织"。
- 错误心智模型："谁施工谁验收"。
- 解药：监理单位组织、施工单位实施、监理见证全过程；施工单位编制专项方案报监理审批。
- 🟢锚（教材）：`kc:1A434020_085_0136:1`。

**R8-5 ｜ 混凝土强度检验方法顺序颠倒（直接上回弹/钻芯）**
- error_code：`E06 程序顺序错误`（transfer）
- 现象：认可"直接采用回弹-取芯法测强度"，或漏掉"优先同条件养护试件"前置。
- 错误心智模型："测强度=回弹/钻芯"——把兜底当首选。
- 解药：先同条件养护试件法；试件无法取得或强度不满足时才用回弹-取芯法。
- 🟢锚（教材）：`kc:1A434020_085_0136:2`。🟢锚（真题）：{2017·案例二·问4}。

**R8-6 ｜ 验收不合格 → 一律"返工/推倒重来"，不知"让步接收/加固后再判"**
- error_code：`E11 迁移失败`（transfer）
- 现象：只会答"返工重做"，答不出分支判定。
- 错误心智模型："不合格=失败=拆了重来"——只有一个终态。
- 解药：不合格是**决策分支**：①返修/返工后重新验收可合格 ②资料缺失可委托检测补证 ③经返修或加固后**仍不满足安全或重要使用要求**才"严禁验收"（最后一档）。
- 🟢锚（教材）：`kc:1A434020_088_0146:1`、`kc:1A434020_088_0146:0`。🔵：源料 quote 未逐字出现"让步接收"四字，术语标🔵。

**R8-7 ｜ "见证取样"当成"凡材料都送 / 都不送"两极**
- error_code：客观题侧 `M10 用常识替代规范判断`（code_application）；案例侧 `E05 审题错误`
- 现象：凭"重要就送、不重要不送"答，说不出判别规则。
- 错误心智模型："见证取样=主观重要性判断"。
- 解药：见证取样有**确定性触发规则**——涉及结构安全/节能/环保材料须复验且经监理认可，关键试块试件须见证检验，特定材料按规范清单强制见证。
- 🟢锚（教材）：`kc:1A438000_151_0243:0`、`kc:1A422000_045_0071:0`。🟢锚（真题）：{2024·案例·问1}。

## 7 · 动画分镜

两个核心镜头：**`process_step_reveal`**（逐级验收层层揭示）＋ **`decision_branch_reveal`**（合格/不合格判定分支）。

### 镜头 A · `process_step_reveal` — 检验批→分项→分部→单位工程 逐级累积验收

**视觉隐喻**：**"积木从地基往上垒成一栋楼"**。底部一排小方块（检验批）逐级合并、向上堆叠，最终封顶成一栋建筑（单位工程）。每一级必须"全亮（合格）"才能托起上一级——倒装（R8-2）在此被视觉证伪：屋顶无法悬空。

**reveal 顺序（自下而上）**：
1. **第1拍 检验批**：底部浮现一排灰色小方块。"主控项目"先点亮（必须全亮），一排"一般项目"方块再点亮、允许零星半亮——但需≥80%整体变绿，该检验批整块才升绿。*此拍预埋 R8-1 纠正*：主控只有"全亮/不亮"两态，一般才有"80%门槛"渐变。
2. **第2拍 分项工程**：同类检验批方块合并成更大的"分项"砖。"同一分项的所有检验批全部合格，分项才合格。"
3. **第3拍 （子分部→）分部工程**：多块分项砖叠成"分部"层，带出🟢锚 `kc:1A434020_083_0134:0` 主体结构七类子分部。技术/质量部门负责人图标"到场参加"（对齐真题 {2015·第28题 ABE}）。
4. **第4拍 单位工程封顶**：所有分部层垒满，建筑封顶亮金边。报出🟢锚 `kc:1A434020_088_0146:0` 单位工程合格五条。

**aha 时刻**：当镜头试图"先放屋顶再补地基"，屋顶**塌落/悬空闪红**——直观证明"验收只能自下而上"。学生"从大往小拆"的错心智模型（R8-2）当场被推翻。

**旁白锚点**：层级 🟢 `kc:1A434020_086_0142:0`/`_083_0134:0`/`_086_0143:0`；检验批门槛 🟢 `kc:1A422000_045_0071:1`；五条 🟢 `kc:1A434020_088_0146:0`；真题 🟢 {2015·第28题}{2016·第28题}{2018·第20题}。🔴禁项：不得在画面打"检验批→分项→分部→单位"排序题字样并标"某年某题"——证据包未命中独立排序题。

### 镜头 B · `decision_branch_reveal` — 合格/不合格 → 返工/返修/加固/让步/严禁验收 判定分支

**视觉隐喻**：**"质检闸门 + 分岔铁轨"**。一节装着"检验批/分项"货物的小车驶到一道**红绿闸门**（判定点），闸门把小车导向不同轨道。错误心智模型（R8-6）只画了一条"销毁"轨；正确模型是一张**多分支决策树**。

**reveal 顺序**：
1. **第1拍 判定闸门**：小车到闸门，头顶弹出"主控项目全部合格？一般项目合格率≥80%？"
2. **第2拍 绿色分支（合格）**：两条件满足→闸门变绿→小车直行"本级合格，移交上一级验收"（回扣镜头A向上累积）。
3. **第3拍 红色分支（不合格）展开成子树**（逐条揭示，非一次铺开）：
   - **3a 返修/返工轨**（先亮）：回炉返修→**重新检测**→可重新判合格（轨道绕回闸门）。纠正 R8-6。
   - **3b 资料缺失轨**：质量控制资料缺失→委托有资质机构做实体检验/抽样试验补证。🟢锚 `kc:1A434020_088_0146:1`。
   - **3c 加固轨**：经返修/加固后重新评估。
   - **3d 终止轨（严禁验收）**：仅当"经返修或加固后**仍不满足安全或重要使用要求**"→轨道尽头亮红叉。强调这是**最后一档**。
4. **第4拍 收束**：四条红色子轨与一条绿色直行轨同框，组成完整决策树。

**aha 时刻**：学生原以为"红灯=终点（拆）"；画面在 3a 让红色小车**绕回闸门重判并变绿**——"原来不合格大多数能救回来，'严禁验收'只在分支最末端"。

**旁白锚点**：合格阈值 🟢 `kc:1A422000_045_0071:1`；不合格分支 🟢 `kc:1A434020_088_0146:1`；🔵"让步接收"术语为工程通识，画面可作小字注但不标教材 quote 锚；真题 🟢 {2017·案例二·问4}（C35 钻芯：平均值30.8=35×88% **临界**(取舍歧义,判定待教研核原卷,见R7-2)、最小28.5>35×80%=28 合格）可作镜头B实战例题嵌入。

### 两镜联动
- **镜头A 的"向上累积"出口 = 镜头B 绿色分支的入口**：每一级在 B 闸门判绿后，小车才进入 A 的向上垒砖。两镜共享"绿=升级、红=分支"的视觉语言，形成"程序（A 纵向）×判定（B 横向）"二维网格。
- **R8 误区落点**：R8-2→A 屋顶悬空 aha；R8-1→A 第1拍主控/一般两态对比；R8-3/4/5→A 第3拍"主体结构层"实体检验弹窗子镜；R8-6→B 红色子树；R8-7→A 检验批入场前的"材料见证取样闸"前置小镜。

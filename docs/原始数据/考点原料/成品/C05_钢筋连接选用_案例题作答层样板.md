# C05 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`C05_钢筋连接选用.md`](./C05_钢筋连接选用.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**给定直径×受力×荷载×部位该选焊接/机械/绑扎中的哪一种、接头位置/检具/灌浆料怎么对上、代换怎么守恒**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建钢筋连接选用案例失分不是"不会"，是"会一点但写不成分"——端点搞反（小直径规则误用到大直径/动力构件）、把"不应超过50%"弱化成"不宜"丢关键词、代换守恒类别错配（把验算类当守恒类）、梁柱接头位置写反、检具/灌浆料数值跟不上。作答层的杠杆 = 把「知道四输入匹配三方式」变成「按内容清单枚举 + 三段式判断纠错带正确数值/关键词写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 C05 §5 R5**（已 signed 的 candidate pack）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**；内容/必写词/数值（接头百分率 50%、冷拉率、接头位置）以 `_C05_compiled_source.json` 对应 point_id 的 `quote`/`required_terms` 为终判，不据深 pack 散文（散文 §1/§5 可能内部矛盾）。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 C05 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E01/E02/E03/E04/E06/E07/E10/E11、M03/M07/M08/M09/M10，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_C05_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2019·第8题}`、`{2022·第14题}`、`{2017·第19题}`、`{2025·第27题}`、`{2020·第22题}`、`{2022·第28题}`），逐条经 Read 核验 stem+correct_answer。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。**`{2018·案例分析(三)}` 不作为采分锚**：pack §8.2 C2/§9#18/§10#1 已裁定该题问题2真采分点是土方回填、连接选用仅为背景陷阱，故本作答层完全不把它当连接选用采分锚。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**内容清单枚举 + 判断纠错 + 计算判定链(阈值表)**，验证句式库在"选用决策/守恒辨析/阈值判定"场景泛化用）。
> **三色铁律继承自 C05**：🟢 point_id 已 Read 核 `quote`/`required_terms` 或真题{年份+题号}已 Read 核 stem+answer｜🔵 工程通识/归纳（无单一 point_id 但学界共识，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、待回填 point_id）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。C05 选用题失分，多是某一维整维搞反或漏掉（最典型：**条件维**——端点把小直径规则误用到大直径/动力构件；**记录/计算表达维**——"不应超过50%"弱化成"不宜"丢关键词分）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 C05 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，代换"须设计单位同意"是唯一显性主体点） | 代换须**设计单位同意**（D1） | 代换答"自行换"漏"设计单位同意" |
| **程序维** | 按什么顺序/位置做（接头位置选择） | 梁上部跨中1/3、下部梁端1/3（L1）；柱第一接头距楼面取最大（L2） | 梁上/下接头位置写反；柱接头未写"取最大值" |
| **条件维** | 达什么阈值/什么受力才那么做（四输入端点、冷拉率、接头百分率） | 动力荷载→机械连接、受拉Φ28/桁架/行车梁不宜绑扎、受压Φ25可绑扎（Q1/Q4）；动力荷载机械连接接头≤50%（Q3） | 端点搞反（拉25压28用反）；50%方向/数值错 |
| **记录/计算表达维** | 留什么书面 / **写阈值判据+数值结论**（接头百分率阈值判定、检具/灌浆料数值） | 接头面积百分率**不应超过50%**（Q3，阈值判定）；直螺纹检具通/止/量规（X1）；灌浆料40×40×160、每层≥3组、标养28d（X2） | 只写"控制接头率"不写"≤50%·不应"；检具/灌浆料数值缺失或写成立方体 |
| **后果维** | 选错/达标后会怎样（对象错位、守恒辨析） | 钢结构连接≠钢筋连接对象不可混；代换守恒（等强度/等面积/构造 vs 验算干扰）（D1/D2） | 把钢结构焊缝/高强螺栓套到钢筋连接；把裂缝验算/配筋率当构造要求 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。C05 是"决策匹配 + 守恒辨析"型考点，**条件维（端点判断）**与**记录/计算表达维（阈值/检具数值）**是失分主战场，主体维弱（仅代换"设计单位同意"一处）。

## 1. 采分点可写化表（从 C05 §5 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚」**逐字来自 C05 §5 R5**（已 signed candidate pack）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（标来源 [R5 required_terms / R8 误区反面 / 工程通识]，不把非 R5 required_terms 的词冒充 R5 硬必写）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 C05 §6 R8 误区 + error_code）。
> - **版本状态**：`现行有效` / 真题侧披露 / 待回填——**写过期/弱化表述照样丢分**，这一件不可省。
> 再标**五维**命中哪维。**采分点本身不增不改**。
> **数值终判源声明**：接头百分率 50%（Q3）= `kc:1A434000_066_0097:0` required_terms 含 `50%`、`机械连接`、`动力荷载`，逐字核；冷拉率 4%/1%（Q5）= `kc:1A413030_100_0190:1` required_terms 含 `4%`、`1%`、`HPB300`、`HRB400`、`HRB500`；接头位置/百分率均回 compiled_source `quote`，不据散文。

# X01 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`X01_施工平面布置原则.md`](./X01_施工平面布置原则.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**施工总平面图含哪六项内容、设计七原则是什么、大门/塔吊/泵/升降机各考虑哪些因素、围挡分几档、五牌一图含哪几块、临设按什么步骤布置**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子——尤其是把每个设施位置写出『靠运输/减搬运/分区/安全』的布置理由因果句**」（学生"会写答案"）。
> **第一性原理**：一建施工平面布置案例失分不是"不会"，是"会一点但写不成分"——示意图各区只标名字漏写布置理由、设计要点清单漏临时道路/水电/消防/环保高分项、塔吊只写"放中间"漏八因素、升降机布置答成"装主楼旁"无因素、五牌一图答"设些牌子"不全。作答层的杠杆 = 把「知道布置内容」变成「按内容清单枚举写全 + 每个设施补『因果布置理由』句」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 X01 §5 R5**（已 signed 的 candidate pack，12 采分点）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**；每个采分点内容/必写词/锚已回读 `_X01_compiled_source.json` 对应 `point_id` 的 `quote`/`required_terms` **核真**（quote 终判，不据散文）。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 X01 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E06/E07/E10、M03/M08），与 pack §6 R8 误区已用码对齐，禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_X01_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2018·案例分析(一)}`、`{2021·答案}`、`{2020·第27题}`、`{2017·案例三}`、`{2025·参考答案 (二)}`），逐条经 Read 核验年份+题号+correct_answer 内容三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**内容清单枚举 + 程序（布置步骤箭头链）**——平面布置原则/布置顺序/设计要点类，正是 skill §1.③ 第⑦类「内容清单枚举」与第③类「程序」主战场）。
> **三色铁律继承自 X01**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识/邻接背景（无单一 point_id，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、待回填 point_id）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写施工平面布置答案漏分，多是某一维整维漏掉（最典型：设计要点题只写"布置大门塔吊"漏掉临时道路/水电/消防/环保整维；示意图题只识别各区名字漏掉"布置理由"这一后果/程序因果维）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 X01 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位/项目部"） | 项目部上报施工组织设计（隐含施工方） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（临设布置步骤、布置先后） | 临设布置步骤：仓库堆场→加工厂→场内运输道路→临时房屋→水电管网（R5#7） | 布置无先后乱列；把"临设规格"当布置步骤答 |
| **条件维** | 达什么阈值才合格/才做（围挡高度、大门数量、各设施考虑因素） | 大门≥2 个（R5#3）；围挡市区≥2.5m/一般≥1.8m（R5#9）；升降机/塔吊布置考虑因素（R5#4/#6） | 围挡统一 1.8m 不分路段；只设一个大门；塔吊"放中间"漏八因素 |
| **记录/计算表达维** | 留什么书面 / 写图内容清单（图含哪六项、五牌一图哪六块） | 图内容六项（R5#1）；五牌一图六块（R5#10） | 图内容漏项；五牌一图答"设些牌子"笼统不全 |
| **后果维** | 不达标/达标后会怎样 / 为什么这么布置（布置理由因果句） | 各区布置理由：靠近材料运输/减少二次搬运/分区减少干扰/塔吊覆盖广/泵靠浇筑点/库远火源（R5#11） | 只写"布置合理、科学规划"不写因果（口号化 0 分） |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。X01 因是"布置内容+布置理由"双重过滤器型考点，**记录/计算表达维（清单类）与后果维（布置理由因果句）是失分主战场**，设计要点/示意图题里 5 个维（程序/条件/记录/后果 + 隐含主体）都要扫。

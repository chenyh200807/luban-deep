## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「挤土效应 / 锤击能量 / 泥浆护壁三功能 / 检测分层」四条因果链；汇编层把镜头 A 的散文链收成「四段因果链 + 每段挂 point_id」，**保留镜头 A 对"挤土效应机理 / 泥浆三功能 / 静载 vs 低应变"的解释为 🔵 讲解性表述（无规范原文逐字锚定，不充判分）**；镜头 A 个别处把"水头≥2m / 泥浆比重1.1~1.3 / 导管埋深2~6m"作通识补充，汇编层标 🔵（编译库无锚，不充 G03 🟢 判分眼）。

**核心因果链(讲懂层骨架)：挤土—能量—护壁—检测**

```
桩基施工两大物理博弈
   ├─ 挤土效应：预制桩打/压入排开原状土→桩周土压密+超静孔隙水压力→先打的桩被侧移上冒
   └─ 护壁稳定：灌注桩成孔=临空面→孔壁土压力须被泥浆静水压力/护筒平衡，否则坍孔/沉渣超标
   ▼
[挤土] 沉桩顺序"四先四后" + 挖孔桩"隔一跳一" —— 让挤土路径始终有自由面释放，避免围堵憋死
   │  先深后浅/先大后小/先长后短/先密后疏；密集桩群从中间向四周对称   {2015,第24题}/{2024,第9题}  🟢
   ▼
[能量] 锤击"重锤低击/低锤重打" —— 增大锤重减小落距，降冲击力峰值保桩身完整，混凝土100%方可打桩
   │                                                              {2017,第26题}、kc:1A413030_090_0165:0  🟢
   ▼
[护壁] 泥浆三功能(静水压平衡+泥皮封堵+悬浮排渣) —— 防坍孔 + 沉渣端承≤50mm + 超灌≥1m凿浮浆
   │                                                  kc:1A413030_091_0169:0、kc:1A434000_071_0110:1  🟢
   ▼
[检测] 完整性定性(低应变/声波透射) + 承载力定量(静载/高应变) 分层验收 —— 甲级桩必静载
   │                                                  kc:1A413030_093_0174:0、kc:1A434000_065_0096:0  🟢
   ▼
效果 = 桩成形不偏不裂(挤土+能量) + 桩身密实承载力达标(护壁) + 缺陷/承载力可核验(检测) → 桩基质量闭环
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **挤土效应→沉桩顺序(🔵机理)**：挤土从打入点向四周辐射，若自外向内施打则中心土被围困憋死、中心桩难打入或断桩；"四先四后"+中间向四周让挤土有自由面释放（规范只给顺序口诀，机理是讲解层）。
- **锤击能量→重锤低击(🔵机理)**：高落距产生极大瞬时冲击力使桩顶应力超混凝土抗压极限→桩头碎裂/桩身纵裂；重锤低击降冲击峰值但有效贯入能量不降（规范只写"宜重锤低击"，机理是讲解层）。
- **泥浆护壁三功能(🔵机理)**：静水压力平衡孔壁土压、泥皮低渗透封堵、黏度上返携渣；任一失效即坍孔或沉渣超标（编译库给"防坍孔=护壁效果+水头压力+钻进参数+孔口处理"，泥浆比重1.1~1.3/水头≥2m是通识补充🔵）。
- **静载 vs 低应变(🔵机理)**：低应变只能定性判完整性Ⅰ-Ⅳ类、给不出承载力数值；甲级桩承载力是核心安全指标须静载直接测 Q-s 曲线（编译库给抽检比例与适用，机理是讲解层）。

> 三色提醒：因果链的**结论数字/口诀**（70%/100%、四先四后、重锤低击、沉渣50/100/200mm、超灌≥1m、间距≥5m、抽检1%·3根/20%·10根、完整性Ⅰ-Ⅳ类、钻芯孔数）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（挤土效应、冲击峰值、泥皮、Q-s 曲线）是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人) 主写，汇编层精简为一句 + 保留 6 场景印证，逐场景重核真题锚（分清教材锚一般口径 vs 真题锚案例口径，见 §8 C2）。

**不变量(一句话)：**
> 当题干"某工程 + 桩基础（预制桩/灌注桩/沉管/人工挖孔）+ 施工要求/纠错/检测/质量问题"，判分主线沿「**先按桩型与工法定性（预制桩看锤击/静压，灌注桩看泥浆护壁/沉管/长螺旋/干作业）→再查施工本体（强度吊运/沉桩顺序/试压桩/泥浆护壁流程+沉渣坍落度超灌/沉管成桩/挖孔间距）→再查质量问题（断桩/虚土/坍孔成因+防治）→再查检测验收（5法适用+完整性Ⅰ-Ⅳ类+钻芯孔数+抽检比例）**」推进（**教学启发式骨架，🔵；非每题都跑满，按题面命中的环节裁决**）。出题人考的是「**顺序/数字对不对（沉桩顺序、沉渣mm、超灌m、抽检%与根数）+ 工法/检测方法选对没有 + 流程是否完整**」，不考桩基承载力理论计算本身。

换言之：判分核心 = **施工数值/顺序是否准（70%/100%、四先四后、沉渣50/100/200mm、超灌≥1m、间距≥5m）+ 检测方法与抽检是否对（静载/钻芯/低应变/高应变/声波透射、甲级≥1%·3根、完整性≥20%·10根）+ 质量问题成因防治是否全（断桩五因、虚土≤100mm、坍孔四防）**。任一环错即「不妥」。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"挤土→能量→护壁→检测 四道物理博弈逐点 reveal"**，删除验收/安全外延的非判分眼分镜，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **挤土效应 vs 沉桩顺序**：左屏自外向内打桩，中心土被围困憋死、中心桩断裂红叉；右屏"四先四后"+从中间向四周对称，挤土有自由面释放，桩位整齐（✓）。
- **重锤低击 vs 重锤高击**：左屏高落距大锤砸下，桩头红色应力波碎裂；右屏重锤低击，冲击波平缓桩身完整挺立。
- **泥浆护壁三功能**：泥浆静水压力顶住孔壁（蓝色压力箭头平衡），泥皮封堵孔壁，钻屑随泥浆上返；缺一则孔壁坍塌红闪+孔底沉渣堆高超 50mm 红线。
- **检测分层标尺**：完整性 Ⅰ→Ⅳ 类色阶（绿→黄→橙→红）；甲级桩"静载试验"灯亮（承载力 Q-s 曲线），低应变只点亮"完整性"不点亮"承载力"。

### Reveal 顺序(讲懂 → 判分眼)
1. **四道物理博弈骨架**：挤土→能量→护壁→检测 流程条亮起。(讲懂层骨架)
2. **定性**：桩型/工法闪现（预制桩锤击/静压；灌注桩泥浆护壁/沉管/长螺旋/干作业）。(锚 `kc:1A413030_091_0167:0`)
3. **挤土·沉桩顺序**：四先四后口诀逐字亮起，自外向内打桩中心桩断裂被红叉。(锚 `{2015,第24题}`、`{2024,第9题}`)
4. **能量·重锤低击**：重锤高击桩头碎裂红叉，重锤低击桩身挺立。(锚 `{2017,第26题}`)
5. **护壁·沉渣超灌**：沉渣 50/100/200mm 三档标尺；超灌"500mm"被红叉换成"0.8~1.0m"。(锚 `kc:1A413030_091_0169:0`、`{2016,案例1}`)
6. **检测·分层验收**：完整性Ⅰ-Ⅳ类色阶；低应变只亮"完整性"，甲级桩静载亮"承载力≥1%·3根"。(锚 `kc:1A413030_093_0174:0`、`kc:1A434000_065_0096:0`、`{2021,第14题}`)

### Aha 时刻(锚已按内容精确挂)
- 自外向内打桩中心桩被围困断裂 → 「沉桩要四先四后+从中间向四周，给挤土留自由面，否则中心桩被憋死断裂」。锚 `{2015,第24题}`、`kc:1A413030_090_0165:0`

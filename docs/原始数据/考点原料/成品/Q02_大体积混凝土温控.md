## 2 原理因果层(动画与 AI 理解的灵魂)

> 先讲一条因果主链,再讲两种裂缝分叉,最后推出四类措施"为什么有效"——让每个数值挂回一个物理原因,而不是背口诀。

### 2.1 核心因果链(一镜到底)

```
水泥水化反应(放热)
        │  🔵 放热量正比于单位胶凝材料中水泥用量与水泥活性(硅酸盐>掺合料)
        ▼
混凝土内部温度升高(温升)
        │  🔵 大体积构件厚 → 热量积在芯部散不出去 → 芯部温度高
        ▼
表面散热快 / 芯部散热慢  ──►  内外温差(里表温差)拉大
        │  🟢 教材直接把"里表温差≤25℃""降温速率≤2.0℃/d"作为控制量(kc:1A413030_096_0181:0)
        ▼
温差 → 热胀冷缩不均 → 温度应力
        │  🔵 芯部想胀、表面想缩;后期整体想缩、地基/老混凝土约束它 → 应力
        ▼
   温度应力  ⚔️  对比  ⚔️  混凝土当时的抗拉强度
        │  🔵 早龄期混凝土抗拉强度还很低,应力一旦超过就开裂
        ▼
   ┌─────────────────────────┬─────────────────────────┐
   ▼ 温升期(浇筑后早期)        ▼ 降温期(后期)
 表面裂缝(非贯穿)            贯穿裂缝(危害大)
 芯热表凉,表面受拉           整体降温收缩+外约束,从面到芯拉穿
 🟢 形态归 1A434000-B036     🟢 形态归 1A434000-B036 / 法规重申 1A422000-B111
```

一句话主线(动画旁白用):**水泥放热 → 芯热表凉 → 温差 → 温度应力 ＞ 早龄期抗拉强度 → 裂缝**。两类裂缝分叉点是"现在处于温升期还是降温期"。

- 🟢 锚:温升/温差/降温速率/养护/跳仓等控制量与数值全部挂 §1 表。
- 🔵 工程通识:"放热—温升—温差—应力—与抗拉强度比较"这条物理链是混凝土材料学共识,教材以"采取内外温差控制措施"(`kc:1A422000_035_0057:0`)等结论形式承认,未逐句挂物理推导 chunk。
- 🔴 待验证:具体某构件"温升期 vs 降温期"的时间分界(几天)随配比/厚度/季节变化,不在本教材采分点内,动画只讲定性分叉,**不报具体天数**。

### 2.2 据因果链推出"为什么这四类措施有效"(抗/放/控/养)

> 按措施**切断因果链的哪一环**归四象限。这是动画从"散点数值"升维到"四个为什么"的关键。

| 象限 | 切断因果链的环节 | 物理逻辑(为什么有效) | 对应措施(node_code) | 三色 |
|---|---|---|---|---|
| **抗(降温升)** | 砍源头:减少水化放热总量与峰值 | 放热量正比于水泥用量与活性 → 低热水泥、掺粉煤灰/矿渣粉替代部分水泥、降水胶比少用水泥浆、缓凝剂摊平放热峰 → 温升上不去,整条链都弱 | `1A412030-E01`/`1A414011-E01`;`1A413033-R05`(水胶比≤0.45);`1A412010-B118`;`1A413050-R23`;早强剂禁用 `1A412010-B072` | 🟢 数值锚;🔵"替代水泥即减放热"为通识 |
| **放(减约束)** | 砍约束:让混凝土自由收缩,收缩不被约束就不生应力 | 应力 = 约束 × 收缩;约束越小应力越小 → 分层/分块、跳仓(分块≤40m)、后浇带(微膨胀补偿收缩)把"大整块"拆成"能各自收缩的小块" | `1A413033-R07`(跳仓≤40m);后浇带 `1A415041-E01` | 🟢 数值锚,真题 2023 印证跳仓 40m |
| **控(控温差)** | 砍温差:把里表温差与降温速率压在阈值内 | 温度应力由温差驱动 → 控里表≤25℃、温升≤50℃、降温≤2.0℃/d、拆保温温差≤20℃,靠测温实时盯(≤500mm、表/底/中心、每昼夜≥4 次)发现超阈即调 | `1A413033-R07`;测温 `1A413033-R08`;法规重申 `1A422000-B111` | 🟢 数值锚,真题 2017·2019·2021·2022 |
| **养(保温保湿)** | 双向托底:既减小温差,又养出抗拉强度 | 保温→减小表面与芯部/大气温差(压"温差"那一边);**保湿**养护≥14d→长出更高抗拉强度(抬"抗拉强度"那一边);拆保温温差≤20℃防"急冷"再拉裂 | 养护≥14d `1A413040-R28`;入模 5~30℃ `1A413033-R07`;防水大体积养护 14d `1A413050-R23` | 🟢 数值锚,真题 2023 印证养护 14d |

> 动画收口的"一句因果":**抗、放、控、养不是四条要背的口诀,而是同一条"应力 vs 强度"不等式的四个下手点——抗压低应力来源、放削弱约束、养抬高强度分母、控直接盯住温差这个总开关。**
>
> 🔴 待验证:① 四象限归类是**教学聚合视角**,教材本身未以"抗放控养"四字标题分类,**判分时仍以具体采分点为准,不可把"四象限"当采分点**;② "拆保温温差≤20℃ 防急冷""保湿养护提升抗拉强度"的因果是 🔵 通识解读,教材只给数值结论,物理解释不可冒充 🟢;③ **术语红线**:教材原文是"**保湿**养护时间:≥14d"(湿养护防失水收缩),≠"拆**保温**层(温差≤20℃)";动画/旁白派生时勿把湿养护数值嫁接到保温阀。

## 3 R2 不变量(一句不可压缩的话)

> 🟢 **大体积混凝土裂缝控制的唯一主线是"控制温度应力并提高抗裂能力":从源头压住水化热温升 → 全过程缩小里表温差与降温速率 → 让混凝土在可控温度梯度下缓慢散热,使温度应力始终小于同龄期混凝土抗拉强度。材料/配合比/浇筑/养护/测温五个动作都是这一条主线的手段,任何只答其一(尤其只答养护)都是把"控温"误当成"保湿"。(🔵养护≥14d附条件,场景限定已证基础底板)**
> *(锚定:`kc:1A413030_096_0181:0`(温升≤50℃/里表温差≤25℃/降温速率≤2.0℃/d/拆保温温差≤20℃/入模 5~30℃)+ `kc:1A413030_097_0182:0`(测温)+ `kc:1A412010_043_0074:0`(水化热);真题印证 2017 降温速率≤2℃/d、2021 拆保温温差≤20℃、2023 跳仓≤40m/养护≥14d。)*

**这一条如何解释 ≥5 个换皮场景**(同一不变量,工程类型只是"大体积"的外壳):

| 换皮场景 | 为何仍是同一不变量 | 锚色 |
|---|---|---|
| 基础底板(厚≥2m) | **真题原型(2019、2022 均为基础底板大体积)**,控温五手段全套照搬 | 🟢 真题 2019/2022 + `kc:1A413030_096_0181:0` |
| 筏板基础 | 厚大体积、散热慢→温升高、里表温差大 | 🟢 `ca:1A412010_043_0075`(厚大体积优选矿/火/粉/复合水泥) |
| 承台 / 大型设备基础 | 同为大体量混凝土块,水化热聚集在中心,控的是同一个里表温差/降温速率 | 🔵 工程通识(承台属厚大体积块体) |

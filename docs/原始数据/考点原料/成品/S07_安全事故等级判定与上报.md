## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「四段因果链 + 每段挂 point_id」，**删除镜头 A 把"30天补报/调查组/处理批复"全挂 `{2015,案例3}` 的单一锚漂移**（30天补报实出 `{2015,第19题}`，调查组/批复出 `{2015,案例3}` 与 `{2017,案例三}`，已分锚核真）。镜头 A 的"为何措施有效"机理解释无 point_id，保留为 🔵 讲解性表述、不充判分。

**核心因果链(讲懂层骨架)：**

```
事故发生(隐患/危险源失控)
   │  日常靠"隐患判定+危险源辨识"预防(🔵邻接)，一旦失控→事故
   ▼
第一步: 定性 —— 这是什么事故?(12类/按原因性质分类)   kc:1A436000_129_0207:0、kc:1A436000_128_0206:0  🔵通识
   │
   ▼
第二步: 定级 —— 按死亡/重伤/直接经济损失三阈值"对号入座"   kc:1A436000_129_0207:1  🟢判分眼
   │  三指标任一达更高级即按更高级(不平均、不取最低)
   ▼
第三步: 上报 —— 现场人员立即报本单位负责人 → 逐级上报政府主管部门   {2019,第17题}、{2016,案例2}  🟢真题侧
   │  伤亡人数变化: 自事故之日起30天内及时补报   {2015,第19题}  🟢真题侧
   ▼
第四步: 调查处理 —— 调查组(政府+多部门)建议 → 政府批复 → 单位执行   {2017,案例三}、{2015,案例3}  🟢真题侧
   ▼
效果 = 事故等级匹配实际危害 → 触发相应层级审查/追责，堵瞒报漏报
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **三阈值刚性定级**：把模糊的"严重程度"转成无需主观判断的"对号入座"技术动作，是上报与调查程序的启动开关。
- **30 天补报窗口**：救援动态，重伤可能转死亡使等级升级；30 天兼顾救援时效与统计准确，强制动态跟踪，堵"先轻报后漠视"漏洞。
- **立即报本单位负责人**：现场人员最快触达，再由单位逐级上报，保证报告链不中断、不越级失序。
- **调查组政府批复**：把处理权上移结构化（政府定调→单位执行），剥离事故单位自裁权，保证追责公正严肃。

> 三色提醒：因果链的**结论数字/对象**（30死/100伤/1亿、30天、本单位负责人、政府批复）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（窗口期设计意图、权力上移逻辑）是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人) 主写，汇编层精简为一句 + 保留 6 场景印证，逐场景重核真题锚（分清 30天补报锚 vs 调查组锚，见 §8 冲突 C1）。

**不变量(一句话)：**
> 当题干"发生了一起安全/质量事故"，判分主线沿「**先定性(什么事故)→再定级(死/伤/经济损失三阈值对号入座)→再走上报程序(立即报本单位负责人→逐级上报→30天伤亡变化补报)→最后调查处理(调查组建议→政府批复→单位执行)**」四步链推进（**教学启发式骨架，🔵；非每题都跑满四步**，按题面命中的环节裁决）。出题人考的是「**等级判没判对 / 上报报没报对人和时限 / 调查处理程序顺没顺**」，不考事故工艺成因本身。
>
> **⚠️ 🟢 证据等级声明（jury 高可信采纳）**：四步链中**定性/定级**两环有**教材锚**（`kc:1A436000_129_0207` / `kc:1A436000_128_0206`）；**上报/调查处理**两环**编译库零教材锚，其 🟢 全部是真题锚**（`{2019,第17题}`/`{2015,第19题}`/`{2016,案例2}`/`{2017,案例三}`/`{2015,案例3}`，经 gate 2 确定性核真）。**真题锚 🟢 ≠ 教材锚 🟢**：前者证明"真考过且答案如此"，但**未经规范原文逐字锚定**，规则组 C/D 的封闭枚举是**从真题答案归纳**、非规范原文穷举——这正是 coarse_review/「上报程序需补 source_ref」的体现。补规范锚后方可视作完全锚定。

换言之：判分核心 = **事故等级是否按三阈值判对 + 上报对象/时限/程序是否正确 + 调查处理三层关系(调查组→政府→单位)是否完整**。任一环错即「不妥」。

**≥5 场景印证(每条带已核真锚)：**

1. **伤亡变化补报时限** —— 「自事故发生之日起 30 天内，伤亡人数发生变化的应及时补报」（7/14/15 天均错）。
   🟢 真题锚 `{2015, 第19题}`(直读：单选 ans=D，stem「自坍塌事故发生之日起( )天内…应当及时补报」选项 A7/B14/C15/**D30**，解析「自事故发生之日起 30 天内…应当及时补报」)。

2. **立即报告对象** —— 现场有关人员应**立即向本单位负责人报告**，不是应急/建设单位/劳动部门。
   🟢 真题锚 `{2019, 第17题}`(直读：单选 ans=D，stem「事故现场有关人员应当立即报告( )」A应急管理部门/B建设单位负责人/C劳动保障部门/**D本单位负责人**，解析引《生产安全事故报告和调查处理条例》第九条)。

3. **事故等级判定(一般事故)** —— 死亡 1 人 / 质量事故直接经济损失 300 余万 → 一般事故。
   🟢 真题锚 `{2017, 案例三}`(直读：stem「屋面梁安装…两名施工人员高处坠落，一人死亡」，answer「事故等级：一般事故」)、`{2016, 案例2}`(直读：质量事故 300 余万，answer「本质量事故属于一般事故」)；教材锚 `kc:1A436000_129_0207:1`。

4. **上报程序纠错 + 报告应含内容** —— 「现场人员立即向本单位负责人报告」「规定时间内逐级上报至市(设区)级住建主管部门」+ 报告还应含初步原因/联系人/其他情况。

### 视觉隐喻
- **事故定级"天平/网格"**：三个砝码（死亡人数、重伤人数、直接经济损失）放上分级网格，任一砝码压到更高格 → 整起事故跳到该等级（"任一达标即按高级"）。

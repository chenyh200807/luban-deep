## 2. 原理因果层 (L2)

> **核心命题**：起重吊装的全部安全规程，本质是**拦截 4 条物理失效链**。每个装置/数值/规程 = 对某条失效链的拦截阀。把「背规程」翻译成「防失效」，学生才看得穿命题人为什么这样设陷阱。

### 链① 倾覆 / 超力矩失稳（🟢，本体最高频）
**力学链**：幅度↑→ 起重力矩=重量×幅度 ↑ → 超额定 → 整机倾覆；**风载是放大器**（迎风面积×风压=附加倾覆力矩）。
- **力矩限制器** = 实时算重量×幅度，超额定断电 〔`kc:..._125_0199:1` 🟢〕
- **6 级风停作业 / 安拆风速>9.0m/s** = 砍掉风载放大项 〔`..._125_0199:3` 🟢 / `..._130_0211:0` 🟢，两口径分场景〕
- **≥90% 额定先吊离 200～500mm 再查** = 临界点先「试稳」再升 〔`..._125_0199:2` 🟢〕
- **垂直度≤4/1000 + 基础设计验收** = 初始偏心/沉降是倾覆「先天本钱」 〔`..._125_0199:0` 🟢〕
- **吊具/主钩与重心重合** = 偏心吊→侧向力矩 〔`..._114_0188:0` 🟢〕

### 链② 脱钩 / 索具失效坠物（🟢，本体高频）
**力学链**：吊索水平夹角↓→ 索内拉力=重量/(2·sinθ) 急剧放大 → 断索；或钢丝绳疲劳断丝/磨损→截面削弱→突断；或斜吊→水平分力→摆荡脱钩。
- **夹角不宜<60°(不应<45°)**：45° 是拉力放大≈1.4 倍红线 〔`..._115_0223:0` 🟢原理〕
- **钢丝绳报废 断丝>10%/磨损40%/死弯绳芯挤出** 〔`..._119_0193:0` 🟢〕
- **缆风绳 K=3.5**：给突加载留 3.5 倍裕度 〔`..._119_0193:1` 🟢〕
- **吊点在重心正上方 + 严禁斜吊** = 消水平分力 〔`..._119_0193:2` 🟢〕
- **压型板严禁钢丝绳绑扎** = 软质构件被割伤/滑脱 〔`..._114_0222:0` 🔵反例〕

### 链③ 碰撞 / 群塔交叉盲区（🟢部分，本体中频）
**力学链**：多机臂架回转半径交叠 → 高低塔交叉/盲区操作 → 相撞 → 坠落/倒塔。
- 臂架回转范围通道防护/警戒隔离（工程通识层成立）。
- 🔴 **群塔专项规则/高低位差/避让优先级**：源料 + 真题证据包**均未检索到独立采分点**；失效链成立(🔵)，但「几米安全距离/谁让谁」数值**禁凭记忆补 🟢**，标 🔴 待验证。

### 链④ 基础失稳 / 触电（🟢部分）
**力学链**：地基承载力不足→不均匀沉降→塔身倾斜（回到链①）；或臂架/钢丝绳触碰高压线→触电。
- **塔机基础须设计 + 安装前验收 + 排水** 〔`..._125_0199:0` 🟢〕
- 触电（与高压线安全距离）属施工用电域，S02 源料未独立给数值，标 🔴 待验证（本考点不展开）。

## 3. R2 — 不变量 (Invariant)

> **🟢 判分内核 = 三道闸＋程序闸**：① 危大判定（是否触发专项方案 / 专家论证，**两层门槛**）→ ② 作业前条件（地基/气象/吊索具/吊点）→ ③ 作业中规程（超载禁令/安全装置不可替代/离地试吊检查）→ ④ 程序闸（危大清单申报与专项方案编制/审核/论证/交底的审批链，`kc:..._008_0011:0` quote直证程序侧；检查评定分类为🔵延伸不单列）。任一闸的「硬指标」被踩，即采分点。

**R2 一句话**：*起重作业的每个「数字红线」与「严禁动作」，都是出题人埋的判分点——你判的不是「危不危险」，而是「踩没踩到那条被规范钉死的线」。*

**≥6 场景验证**：
1. **危大判定** — 题给「单件 150kN 双机抬吊」问是否需专家论证 → 闸①两层（教材两级均含「非常规起重设备、方法」限定 P8/P9）：双机抬吊=非常规方法（🔵工程通识口径，教材无显式定义）→ ≥10kN 属危大 → 单件 150kN ≥100kN 且非常规 → **须专家论证**；另「采用起重机械进行安装的工程」本身属危大（P8(2)）。〔`kc:..._008_0011:0` + `kc:..._009_0012:0` 🟢＋教材P8/P9逐字；真题 2021 案例(三)〕
2. **塔吊基础** — 题给高 0.9m、C20 → 闸②硬指标（真题 2016 案例五：高≥1m、强度≥C25、须设计验算）。
3. **试吊检查** — 题给 95% 额定起吊 → 闸③：先吊离 200～500mm 再四查。〔`kc:..._125_0199:2` 🟢 + 真题 2018 案例五问题1〕
4. **安全装置** — 题给「用限位代替操作机构」→ 闸③绝对禁令 〔`kc:..._125_0199:1` 🟢〕
5. **气象条件** — 题给「6 级风继续露天吊装」→ 闸②气象红线 〔`kc:..._125_0199:3` 🟢〕
6. **吊索具报废** — 题给「断丝一节距 12%」→ 闸②报废线 〔`kc:..._119_0193:0` 🟢〕

> 一条不变量 + ≥6 场景全部落到「踩数字红线/踩严禁动作」，证明它是真内核而非口号。

## 6. R8 误区 → error_code → 解药 (L6)

> error_code 全部取自 `deeptutor/contracts/error_codes.py`（已直读核验），无自造码。体例：现象 → 错误心智模型 → 解药。

### 误区 ① 把「危大入门线」当「专家论证线」（两层门槛压成一层）
- **error_code**: `M08` 规范数字混淆 (code_application) ｜ 配套 `M10` 用常识替代规范判断
- **现象**：看到「起重吊装」+ 大数字直接勾「需专家论证」。
- **错误心智模型**：脑内只有「起重吊装=危大=要论证」一条线，把 10kN / 100kN / 300kN / 200m 压成一个阈值。
- **解药**：**两层门槛**——「**十进危大**(≥10kN 要专项方案)，**百论证**(非常规且单件≥100kN)，**三百总重**(≥300kN)，**两百高度**(≥200m)」。〔`kc:..._008_0011:0` + `kc:..._009_0012:0` 🟢；真题 2021 案例(三)〕

### 误区 ② 「6 级风停作业」和「9.0m/s 停安拆」混为一条
- **error_code**: `M08` 规范数字混淆 (code_application)
- **现象**：题问「风速 9.0m/s 塔吊可否正常吊装」答「可以」，或把 6 级套到安拆。
- **错误心智模型**：以为塔吊只有一条「风的红线」。
- **解药**：**两条独立红线，看动作选阈值**——**露天吊装作业** → **6 级及以上**(`..._199:3` 🟢)；**安装/拆卸** → **>9.0m/s + 低能见度**(`..._211:0` 🟢)。安拆更危险→限值更严、单列。题干动词「作业」还是「安拆」决定调哪条。

### 误区 ③ 90% 额定只记「要检查」，漏「先吊离地」前置步
- **error_code**: `M09` 题干条件提取不完整 (question_reading) ｜ 案例侧 `E06` 程序顺序错误
- **现象**：答「加强检查」但漏「先吊离 200～500mm 再查」的顺序，或写错离地高度。
- **错误心智模型**：当成「加强注意」态度题，而非「带前置动作 + 固定四查清单」的程序题。
- **解药**：记成**一动作 + 四查**——动作：**先吊离 200～500mm**（真题 2018 背景用 15cm，低于区间下限，为背景设定值，判分以 200～500mm 为准）；四查：机械状况/制动性能/重物平稳/绑扎牢固。〔`kc:..._125_0199:2` 🟢；真题 2018 案例五问题1〕

### 误区 ④ 「限位临时顶一下操作机构」/ 钢丝绳报废线背反
- **error_code**: `M10` 用常识替代规范判断 (code_application) ｜ 配套 `M08` 规范数字混淆 ｜ 案例侧 `E07` 概念混淆（限位装置与操作机构功能混同）
- **现象**：判断题给「操作机构失灵用限位代替继续吊」判「对」；或把报废线背成「断丝>40%、磨损>10%」（数字对调）。
- **错误心智模型**：用生活常识替代规范**绝对禁令**；数字对调因没绑定「断丝看节距、磨损看表面」。
- **解药**：「**严禁用限位装置代替操作机构**」是绝对禁令，出现「代替/顶替」即判**错**(`..._125_0199:1` 🟢)；报废绑语义「**断丝看一节距>10%、磨损看表面达40%**」(`..._119_0193:0` 🟢)。记法「**断丝十、磨损四、限位绝不替**」。

### 误区 ⑤ 吊点/吊索：斜吊算「灵活」，夹角凭感觉
- **error_code**: `M04` 选项陷阱 (question_reading) ｜ 案例侧 `E10` 规范适用错误
- **现象**：选项把「可斜吊以适应场地」包装成「灵活高效」；或夹角答「不应<60°」（把「不宜」当「不应」）。
- **错误心智模型**：看不出选项偷换「宜/应」刚性等级，没把「吊点在重心正上方」当硬约束。
- **解药**：硬约束「**吊点与重心同一垂直线、位于重心之上、严禁斜吊**」(`..._119_0193:2` 🟢)；夹角双线「**不宜<60°(推荐)、不应<45°(强制)**」，锁定**不应<45° 是底线**(`..._115_0223:0` 🟢)。

> 🔴 **待验证（禁冒充 🟢）**：司索工/信号工持证、群塔交叉避让、起重机械「四限位三保险」清单——证据包说明 2015–2025 真卷**未检索到独立真题锚**，源料 units 亦无独立采分点。如要入课须另取 🟢，**当前标 🔴，禁编号冒充真题**。

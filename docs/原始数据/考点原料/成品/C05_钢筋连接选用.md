## 2 · 原理因果层（三环逻辑链 + 决策树）

> 主体来自 lens A（DeepSeek 主力），汇编在每环补了 source/真题印证，并把因果与选用端点对齐。

**① 力学性能 → 基础选用逻辑**（🟢`kc:1A412000_040_0068:0`/`041_0069:0`/`041_0069:2`）
钢材受拉经历弹性→屈服→强化→颈缩；屈服强度是设计取值依据，伸长率反映塑性（🟢{2015,第5题}：塑性指标用**伸长率**表示，答案D）。三种连接的传力机理决定适用面：
- **焊接**：熔为一体、等强传力，但引入热影响区；**含碳量>0.3% 可焊性显著降**（`041_0069:0`），含硫致**热脆**焊接热裂纹（`041_0069:2`）→ 低碳钢、一般环境优先。
- **机械连接（直螺纹套筒）**：螺纹咬合传力、**无热影响**→ 高强钢筋、抗震关键节点、动力荷载首选。
- **绑扎搭接**：靠混凝土握裹力传应力，搭接区应力集中→ 仅小直径/受压/静载/非关键退档可用。

**② 冷拉率 → 塑性是抗震"保险丝"**（🟢`kc:1A413030_100_0190:1`）
地震下塑性铰区耗能要求连接处有足够延性。冷拉降塑性，故 **HPB300≤4%、HRB400/HRB500≤1%**；反复弯折加剧冷作硬化→严禁反复弯折（🟢{2015,第14题}：钢筋不得反复弯折、可冷拉调直，答案C）。

**③ 接头位置 → 避开最大应力区**（🟢`kc:1A413030_101_0191:0`/`100_0190:2`）
梁上部接头宜跨中1/3（该处负弯矩小）、下部接头宜梁端1/3（该处正弯矩小）——把接头从最大拉应力区挪开。柱第一接头距楼面≥500mm、≥H/6、≥b 取最大值。

## 3 · R2 不变量（一句话，🟢）

> 来自 lens B（Opus），汇编校验了四输入域与端点联动均有锚。

🟢 **钢筋连接选用 = 用「直径 × 受力性质 × 荷载性质 × 部位/抗震」四输入，去匹配「绑扎搭接 / 机械连接 / 焊接」三种方式之一——越是大直径·受拉·动力荷载·抗震关键部位，越往「机械连接(直螺纹套筒)」端走；越是小直径·受压·静载·非关键部位，才允许往「绑扎搭接」端退。代换则是同一不变量的逆运算：换钢筋时强度/面积守恒 + 构造守恒 + 设计单位同意。**

- 选用主锚：`kc:1A413030_100_0190:0`（三类+套筒最常用）
- 量化约束：`kc:1A434000_066_0097:0`（动力荷载机械连接≤50%）
- 代换逆运算：`kc:1A413030_099_0189:0`

### 一个不变量解释 ≥5 个场景（均 🟢 已核）

1. 🟢{2019,第8题} 动力荷载 + Φ20 受力筋 → **机械连接(直螺纹套筒)**（答案B；排除焊接热影响区、排除绑扎小直径）。
2. 🟢{2022,第14题} 受压Φ25 → **可绑扎搭接**（答案B）；受拉Φ28/桁架拉杆/行车梁受力筋 → 不宜绑扎。
3. 🟢`kc:1A411011_036_0063:2` 一二级抗震底部加强区竖向钢筋 → **套筒灌浆**；边缘构件逐根连接、非边缘≤600mm。
4. 🟢{2025,第27题} 受力钢筋代换基本要求 = 等强度 + 等面积 + 满足构造（答案BCE；**等刚度是干扰项**）。
5. 🟢{2020,第22题} 代换"构造要求" = 钢筋间距/保护层厚度/锚固长度（答案CDE；裂缝宽度验算、配筋率属设计要求）。
6. 🟢{2017,第19题} 选用下游：直螺纹接头精度检具 = 通规/止规/量规（**直尺不行**，答案C）。
7. 🟢{2022,第28题} 套筒灌浆料试件 = 每工作班1组、每层≥3组、40×40×160mm长方体、标养28d（答案ACD）。

## 4 · examiner_intent + R3 场景 + R4 封闭变量集

> 来自 lens B（出题人镜头），汇编逐项对齐真题 `stem/answer`，并修正了 lens B 把 `{2018,案例分析(三)问题2}` 当"预制墙板套筒灌浆采分点"的偏差（见 8.2 C2）。

### examiner_intent（真正鉴别什么）

🟢 出题人**从不直接问"哪种连接好"**，而是给一组约束，逼考生跑"输入→匹配"决策。三层意图：

1. **正向选用（送分到陷阱）**：给直径+受力+荷载，问"宜选用"。陷阱=把焊接伪装成动力荷载可选项（实则热影响区不利）、把绑扎塞给大直径/受拉/桁架/动力构件（实则不宜）。🟢{2019,第8题}{2022,第14题}。
2. **代换守恒（多选主场）**：把"设计要求"与"构造要求"两套清单混排，逼考生区分谁守恒、谁验算。🟢{2025,第27题}（等刚度=唯一干扰）{2020,第22题}（裂缝验算/配筋率混进构造选项）。
3. **选用下游闭环（接头质量/验收）**：选了机械连接/套筒灌浆后，检具与灌浆料数值能否跟上。🟢{2017,第19题}（直尺非检具）{2022,第28题}（40×40×160、每层≥3组、标养28d）。

> 🟢 难点不在记三种方式，而在**端点判断 + 守恒辨析**。最爱失分点 = "把端点搞反"（小直径规则误用到大直径/动力构件）与"守恒类别错配"（把验算类当守恒类）。

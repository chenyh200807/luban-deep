## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「因果链 + 每段挂 point_id」，**删除镜头 A 里无锚的力学外推**（"降落漏斗""孔隙水压力""渗流失稳临界水力梯度"等是合理工程解释但无 point_id 也无真题证据，保留为 🔵 讲解性表述，不充判分）。

**核心因果链(讲懂层骨架)：**

```
基坑开挖本质 = "在地下水位以下掏一个稳定的干坑"            🔵讲懂背景(机理无独立 point_id)
   │
   ├─ 先按"水"决策: 深度+土质+周边环境 → 选降水方法
   │   ├ 深度≤3m且软土 → 集水明排(重力自流, 浅坑够用)
   │   ├ 深度>3m → 井点降水(强制排水降水位)
   │   │   ├ 轻型井点 降水深度≤6m(多级6~10m)        kc:1A413000_082_0155:0  🟢
   │   │   ├ 喷射井点 降水深度8~20m                  kc:1A413000_082_0155:1  🟢
   │   │   ├ 真空降水井管 >6m·渗透系数>1e-6           kc:1A413000_083_0156:0  🟢
   │   │   └ 渗透系数较大(砂砾) → 管井; 填土/黏土不宜用管井  {2015,第9题}/{2019,第7题}/{2023,第14题}  🟢真题
   │   ├ 危及周边安全 → 截水帷幕 / 井点回灌(防沉降)   kc:1A413000_083_0156:1/:2  🟢
   │   └ 承压水 → 验算突涌; 钻孔减压 / 水平封底隔渗   {2016,第24题}  🟢真题
   ▼
   ├─ 再按"土+支护"决策: 选开挖方案
   │   ├ 无支护 → 放坡(周边开阔·土质好)              {2021,第10题}/{2023,第15题}  🟢真题
   │   └ 有支护 → 中心岛 / 盆式 / 逆作               {2021,第10题}/{2023,第15题}  🟢真题
   ▼
   └─ 最后控开挖过程: 分层≤3m + 预留土层150~300mm + 水位降至坑底以下500mm + 严禁超挖 + 软土高差≤1m
         kc:1A413000_084_0157:0/:1/:2 + kc:1A422000_028_0048:0  🟢
   ▼
效果 = 基坑从"带水易失稳/超挖伤护"变成"先控水→选方案→控过程"三段防控
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **深度分流明排/井点**：浅坑水压力小、重力明排即可；深坑必须主动降水位形成"降落漏斗"(镜头 A 力学解释，🔵 不充判分)，否则坑底渗流易流砂/管涌。
- **井点按渗透系数+降水深度选型**：轻型/喷射/真空/管井各有适用渗透系数与降水深度区间，错配则降不下来或不经济。
- **管井不宜用于填土**：管井属重力排水、吸程受限、要求渗透系数较大(砂砾层)，填土/黏土渗透系数小、出水量不足(镜头 A 解释，🔵)。
- **承压水验算突涌**：坑底为隔水层、其下有承压水时，承压水头顶破坑底即突涌；钻孔减压泄压、水平封底隔渗阻隔(镜头 A 解释，🔵)。
- **水位降至坑底500mm + 预留土层**：保证基底以上无水干作业、机械挖至基底上方留人工挖除避免扰动原状土(镜头 A 解释，🔵)。

> 三色提醒：因果链的**结论(≤3m明排/>3m井点/轻型≤6m/喷射8~20m/真空>6m/管井渗透系数大/分层≤3m/预留150~300mm/坑底500mm/严禁超挖/软土高差≤1m/防突涌措施/放坡无支护)**全部 🟢 锚定(教材锚或真题锚)；链条里的**微观机理解释**(降落漏斗/孔隙水压力/渗流失稳/吸程)是讲懂用语，标 🔵，不得作为采分点输出（§8.2 C2）。

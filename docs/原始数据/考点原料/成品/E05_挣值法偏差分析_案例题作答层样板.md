# E05 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`E05_挣值法偏差分析.md`](./E05_挣值法偏差分析.md)（深母题知识层 R1–R8）之上**加的一层**，不是新母题体系。
> 知识层回答「**这个项目（到检查时点）成本和进度到底好不好**」（学生"会算 CV/SV/CPI/SPI、会判方向"）；作答层回答「**怎么把这条计算判定链写成阅卷友好、能拿分的答题结构**」（学生"会把公式+代入+数值+方向判读写全"）。
> **第一性原理**：一建挣值法案例失分不是"不会减不会除"，是"会算一两个值但写不成分"——**公式记反**（CV 写成 ACWP−BCWP）/ **三值代错位**（把实际成本当预算成本）/ **方向判反**（CV>0 说成超支）/ **只写结论不写公式代入**（只写"节支"不写算式）/ **CV/SV 与 CPI/SPI 混淆**。作答层的杠杆 = 把「知道四个公式」变成「按【亮公式→代入→数值→回判方向】四步写全计算判定链」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 E05 §5 R5**（signed pack 的 R5/R6）。本层「可写化四件套」从 R5 **派生**，不另造采分点。
> - **判分归 signed scoring artifact**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，非官方判分（**漏不定分**）。**所有数值只引用、不独立验算**（数值正确性归判分内核）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**（E01–E12 / M01–M10）。本层错因标签只**映射** registry 已注册码，禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **三原则**：依附 E05 pack 不另起体系（thin）/ 句式模板跨母题复用（fat skill）/ less is more 别堆。
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，验证"会算→会写"跃迁用；需 Layer-2 异源抽检 + 真人核才进默认入口）。
> **三色铁律继承自 E05**：🟢 采分点锚定 E05 R5（教材 point_id `kc:`/`ca:` 可核；**本考点真题命中=0，无 🟢 真题锚**）｜ 🔵 作答策略/句式（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、数值正确性需 Layer-2 核）。

## 0. 五维框架（作答层的"采分点分类器"）

挣值法案例采分点几乎都能归到这**五维**之一。挣值法失分多集中在**记录/计算表达维**（算式没写全、公式记反）和**条件维**（方向判读阈值用错）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 E05 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做（挣值法本身无主体争议，弱维） | （E05 无主体类采分点——是谁算不影响判分） | （本考点不涉及，不堆） |
| **程序维** | 按什么顺序算（先取三值→再套公式→再判方向，不可跳步） | 先列 BCWP/BCWS/ACWP 三值 → 再算四指标 → 再判方向 | 跳过列三值直接写指标结果；只写最终"节支"省略中间算式 |
| **条件维** | 达什么阈值才判某方向（正负 / 与 1 的大小） | CV/SV>0→节支/提前、<0→超支/延误；CPI/SPI>1→节支/提前、<1→超支/延误 | 方向判反（CV>0 说超支）；CPI<1 说节支；不写阈值依据 |
| **记录/计算表达维** | 留什么书面算式（**计算题主战场**：公式+代入+数值结论成组） | 每个指标"公式=代入=结果"三段成组；偏差带「万元」、指数无量纲不带单位 | 只写结论不写公式代入；CV/SV 漏单位 / 给 CPI/SPI 硬加单位 |
| **后果维** | 算出方向后的定性结论（成本/进度状态 + 综合诊断） | CV>0 且 CPI>1 → 成本节支；SV>0 且 SPI>1 → 进度提前 → 综合"节支+提前" | 只写指标值不下"节支/提前"定性结论；漏综合诊断句 |

> **E05 五维的特别之处**：本考点是「**纯计算判定链**」考点——失分**几乎全压在「记录/计算表达维」与「条件维」**两维上（主体维弱、程序维弱化为"算式步骤顺序"）。这与 K01 索赔的"双闸门主体/条件维"重心完全不同：K01 怕"工期费用绑死"，**E05 怕"公式记反 + 方向判反 + 只写结论不写算式"**。所以五维自检对 E05 尤其要先盯"**每个指标的公式/代入/结果/方向四件有没有写齐**"。
> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维、哪个指标少写哪段一目了然**，比"逐字找差"更快定位"差哪步"。

> **勾选结果**：E05 以 **第 9 类「计算判定链」（绝对主打）** 为核心，辅以 **指标含义/公式辨析（MCQ 小问，归"内容清单枚举/概念辨析"类）**。判断纠错三段式 / 措施六维 / 程序箭头链 / 索赔双闸门 / 验收 / 事故处理 / 主体定位等 E05 案例**不涉及**，本层不堆（less is more）。
> **第 9 类适配注**：skill §1.③ 第 9 类原由 A01 强度判定 / N01 关键线路时差 / K01 索赔金额三方实测撞同一缺口后补入。**E05 是第 4 个独立计算场景（挣值/偏差分析），用于验证第 9 类在"成本进度偏差判读"场景的泛化**——见 §4 实测报告 b。

### 模板 E-EV · 挣值计算判定链句式（skill §1.③ **第 9 类「计算判定链」** · E05 绝对主打）

> **类别归位**：本段对齐 skill §1.③ 第 9 类「计算判定链」。骨架 = **亮判据/公式 → 代入题干三值列式 → 得数值结论 → 回判方向定性**。E05 的特殊性在于**一道题要把四个指标各跑一遍这条四步链**（CV/SV/CPI/SPI），且**第 9 类支持多段串行嵌套**（skill 明文：判据可为公式或阈值表 + 支持多段串行嵌套）——E05 正是"四段计算判定链串行"的典型实例。算式表达落 §0 五维的**「记录/计算表达」维**。

```
【计算判定链·E05 四段串行】
  前置：列三值 → BCWP=<挣值>、BCWS=<计划值>、ACWP=<实际值>（取对不互换）
  ┌ 段① 成本偏差 CV：① 亮公式 CV=BCWP−ACWP → ② 代入列式 <a>−<b>=<CV>
  │                  → ③ 数值结论 CV=<CV> 万元 → ④ 回判 CV>0→节支 / CV<0→超支
  ├ 段② 进度偏差 SV：① SV=BCWP−BCWS → ② <a>−<c>=<SV> → ③ <SV> 万元 → ④ SV>0→提前 / SV<0→延误
  ├ 段③ 成本绩效 CPI：① CPI=BCWP/ACWP → ② <a>/<b>=<CPI> → ③ <CPI>(无量纲) → ④ CPI>1→节支 / CPI<1→超支
  └ 段④ 进度绩效 SPI：① SPI=BCWP/BCWS → ② <a>/<c>=<SPI> → ③ <SPI>(无量纲) → ④ SPI>1→提前 / SPI<1→延误
  收束：综合诊断（成本侧 CV/CPI 同向 + 进度侧 SV/SPI 同向）→ "本项目<节支/超支>、<提前/延误>"。
```

- **E05 实例（教材母题，锚 `ca:1A435020_097_0160`，三值 6370/6240/5340）**：
  - 列三值：BCWP=6370、ACWP=6240、BCWS=5340 万元。
  - 段① CV：CV=BCWP−ACWP=6370−6240=**130 万元** → CV>0 → **成本节支**。锚 `kc:1A435020_095_0156:1`
  - 段② SV：SV=BCWP−BCWS=6370−5340=**1030 万元** → SV>0 → **进度提前**。锚 `kc:1A435020_097_0160:1`
  - 段③ CPI：CPI=BCWP/ACWP=6370/6240≈**1.02** → CPI>1 → **成本节支**。锚 `kc:1A435020_095_0156:2`
  - 段④ SPI：SPI=BCWP/BCWS=6370/5340≈**1.19** → SPI>1 → **进度提前**。锚 `kc:1A435020_096_0157:0`
  - 收束：本项目第20周末**成本节支、进度提前**。锚 `ca:1A435020_097_0160`
- **要害**：**每段四步都要写**（① 公式 / ② 代入 / ③ 数值 / ④ 回判方向），数值与方向都写——只写数值丢方向分、只写"节支"省公式代入丢过程分。**四段都要跑**（漏 CPI/SPI 只算 CV/SV = 压线扣分，E02）。
- **本层边界（与 skill 第 9 类一致）**：本句式**只管作答结构 / 四段每段四步有没有写全**，**数值正确性（130/1030/1.02/1.19 算得对不对、小数位）归 signed scoring artifact + 判分内核，本层不独立验算**（红线3）。

### 模板 E-Def · 指标含义/公式辨析句式（skill §1.③「内容清单枚举 / 概念辨析」类 · MCQ 小问辅）

> **类别归位**：用于"BCWP/BCWS/ACWP 各自构成"或"某指标公式"的辨析小问（多为 MCQ，案例中偶作填空小问）。归全局句式库"内容清单枚举"类，**不新造**。

```
【含义辨析】<参数/指标>=<封闭定义/公式>；与 <易混项> 的区别在 <量来源/价来源/分子分母>。
```
- E05 实例：「BCWP=已完成量×**预算**单价（已完成工作预算成本），区别于 ACWP=已完成量×**实际**单价、BCWS=**计划**量×预算单价——三者'量来源/价来源'各不同」。锚 `kc:1A435020_095_0156:0`、`kc:1A435020_096_0158:0`
- **要害**：辨析必须点到**量来源（已完成 vs 计划）× 价来源（预算 vs 实际）**这两个维度的组合，不能只背名字。

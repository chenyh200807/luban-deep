# G02 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`G02_土方回填压实与检测.md`](./G02_土方回填压实与检测.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`、`direct`）之上**加的一层**，不是新母题体系。
> 知识层回答「**哪些土料禁用、虚铺厚度按什么定、各机具分层厚度/遍数是多少、含水率怎样影响压实、检测查什么用什么方法**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建土方回填案例失分不是"不会"，是"会一点但写不成分"——只指"虚铺太厚"不给"按夯实机具定"、判断纠错只指不妥不给正确数值（振动压实机 250-350mm / 3-4 遍）、把"含水率过大"单向写、检测只写"检压实系数"漏"标准击实法"、把"环刀法"当被禁（实为"多层环刀统一送检"才错）。作答层的杠杆 = 把「知道四步链阈值」变成「按选料→铺填→压实→检测四步 + 三段式判断纠错写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 G02 §5 R5**（已 signed 的 candidate pack，选料/铺填/压实/检测/机理 12 点）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**；每点内容/必写词/锚已回读 `_G02_compiled_source.json` 对应 point_id 的 `quote`/`required_terms` 核真。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 G02 §5 R7 全部 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E01/E02/E03/E04/E06/E07/E10、M06/M07/M10，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_G02_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（`{2016·第8题}`、`{2018·案例三问题2}`、`{2019·第16题}`、`{2020·第29题}`、`{2022·第21题}`、`{2015·第8题}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**判断纠错 + 程序链 + 计算判定链（参数阈值表）**，验证句式库在土方回填四步链场景泛化用）。
> **三色铁律继承自 G02**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识（无单一 point_id 但学界共识，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、待回填 point_id）。
>
> **⚠️ 真题锚 🟢 ≠ 教材锚 🟢（继承 G02 §3 证据等级声明）**：本考点**选料禁用/压实参数表/检测项/必查**四环有**教材锚**（`kc:` / `ca:`）；**起填/对称/虚铺依据/下层合格再上层/检测方法（击实法）/含水率机理** 等环**编译库无独立教材锚，其 🟢 全部是真题锚**——尤其**具体检测方法（环刀法/灌砂法/灌水法/标准击实法）编译库完全无锚**，全靠真题侧 `{2018·案例三}`。补 GB50202 编译锚后方可收紧。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写土方回填答案漏分，多是某一维整维漏掉（最典型：判断纠错只指"厚度太大"漏"按机具的具体数值区间"，或检测题只写"检压实系数"漏"标准击实法"这一**记录/计算表达维**）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 G02 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位"，监理负责检查） | 回填施工/检测送检（隐含施工方+第三方检测） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（选料→起填→分层铺填→压实→下层合格再上层→检测） | 从最低处起、由下而上、对称回填（R5#3/#4）；下层压实系数合格后上层（R5#7）；取样图先于结果表（R5#12） | 从高处起 / 单侧回填 / 未验下层即上层 / 取样顺序颠倒 |
| **条件维** | 达什么阈值才合格/才做（禁用土料、分层厚度、遍数、含水率） | 禁用淤泥/淤泥质土/有机质>5%（R5#1）；虚铺按机具定（R5#5）；振动压实机 250-350mm·3-4 遍（R5#6）；含水率过大过小均压不实（R5#11） | 把禁用土当可用；虚铺"按含水量定"；铺填>400mm/压 2 遍；含水率单向写 |
| **记录/计算表达维** | 留什么书面 / **写参数对照链+判定结论**（机具-厚度-遍数对照、压实系数检测方法） | 施工后标高及压实系数检验（R5#8）；必查=填筑厚度/含水量/压实系数（R5#9）；压实系数用**标准击实法**非多层环刀统一送检（R5#10） | 只写"检测"不给标高+压实系数双项；漏"标准击实法"方法判定；必查项漏写 |
| **后果维** | 不达标会怎样（密实度不足、不均匀沉降、橡皮土） | 含水率过大过小→密实度达不到要求（R5#11 机理） | 只会"压不实"，不知"过大过小双向都不行"，写成"含水率越大越好压" |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。G02 是参数阈值密集型考点，**条件维**（禁用清单 + 机具参数表）与**记录/计算表达维**（检测项+方法）是失分主战场。

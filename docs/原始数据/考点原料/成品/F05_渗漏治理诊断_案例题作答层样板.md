# F05 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`F05_渗漏治理诊断.md`](./F05_渗漏治理诊断.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**渗漏在哪个部位、成因是什么、各部位怎么对症治理、分级分档数值是多少**」（学生"会看答案"）；作答层回答「**怎么把诊断成因与对症治理写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：F05 失分不是"不会"，是"会一点但写不成分"——渗漏题只背"防水没做好"不做部位诊断 / 成因笼统（只说"防水差"）/ 治理方法张冠李戴（流淌法用于穿墙渗漏）/ 管道穿墙只写"灌浆堵漏"漏止水环与前置流程 / 起鼓"都割开重贴"漏 100mm 分档 / 流淌不分级把轻微也大拆 / 女儿墙治理漏烤干基层与油膏封口。作答层的杠杆 = 把「知道部位与成因」变成「**先诊断（定部位+回溯成因）→ 后治理（对症·分级·分档），按程序箭头链 + 内容清单枚举 + 判断纠错写全采分点**」。
>
> **职责边界（thin layer，不造第二 authority）**：

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。F05 的采分点高度集中在**后果维（部位诊断+成因回溯：渗漏现象→为什么漏）+ 程序维（治理流程箭头链：管道穿墙五步 / 女儿墙五步）+ 记录/计算表达维（分级分档清单：流淌三级、起鼓 100mm 分档、女儿墙治理项清单）**——这正是 F05"已经渗漏了→怎么诊断成因→怎么对症治理"诊断治理本性的体现。主体维在 F05 几乎不命中（F05 不考"谁组织验收/谁见证"，那是 A01 验收程序的领地）；条件维以"分档界值（100mm）"形态出现，嵌进记录维一并扫。

| 维 | 含义 | 在 F05 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做（组织/实施/见证） | （F05 基本不命中——渗漏诊断治理是"怎么诊断怎么治"非"谁做"） | — |
| **程序维** | 按什么顺序做（**治理流程不可颠倒/不可漏步**） | 管道穿墙：清理管道表面→止水环→振捣密实→避免振动→灌浆堵漏；女儿墙：清旧胶结料→烤干→钉压条→新卷材→油膏封口 | **漏止水环/漏灌浆堵漏**；**女儿墙漏烤干基层、漏油膏封口** |
| **条件维** | 达什么阈值才分档处置 | 起鼓直径 100mm 分档界（<100mm 抽气灌胶 / ≥100mm 割开重贴） | **不分档/写错界值**（"起鼓都割开重贴"漏 100mm 分界） |
| **记录/计算表达维** | 分级/分档/清单枚举（治理方法清单、成因清单） | 流淌三级（严重/中等/轻微）；起鼓两档；女儿墙成因五项；中等流淌三法 | 流淌不分级、中等三法漏其一；成因笼统不枚举 |
| **后果维** | 渗漏现象→回溯成因（病因诊断） | 施工缝渗漏成因（未清理/接槎明显/钢筋密集不密实）；女儿墙成因（收口/压条脱落/滴水线破损/拉结不牢/钝角） | 只背"防水没做好"不诊断部位；成因笼统/错部位（施工缝成因套女儿墙） |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——F05 重点盯**后果维（部位诊断对不对、成因回溯准不准）+ 程序维（治理流程有没有漏步/乱序）+ 记录维（分级分档数值够不够、清单全不全）**，漏哪维一目了然。

## 5. 自检报告

### a. 用到 skill §1.③ 句式库哪几类？

用到 **3 类**（共 9 类）：**① 判断纠错（三段式）/ ③ 程序（箭头链，治理工序）/ ⑦ 内容清单枚举（成因 + 分级分档，主力）**，与本任务"判断纠错 + 程序 + 内容清单"重点完全吻合。
未用 6 类：**②措施 / ④验收 / ⑤索赔 / ⑥主体定位 / ⑧事故处理 / ⑨计算判定链**——F05 是渗漏诊断治理题，无措施补充/验收/索赔/主体识别/安全事故/代入计算型问法（起鼓"是否≥100mm 选哪种法"是阈值识别，归 ⑦内容清单 + ①判断纠错，非 ⑨ 计算判定链的"代入公式列式算数值"）。勾选明细见 §2 表。

### b. 有没有遇到句式库覆盖不了、需要新造句式的情况？

**没有，第 9 类亦无需。** F05 三大问法（成因诊断枚举 / 治理工序流程 / 分级分档判别）被 ⑦内容清单枚举 + ③程序 + ①判断纠错三类完整覆盖，**无句式覆盖缺口**。

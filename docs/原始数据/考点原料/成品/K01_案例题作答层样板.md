# K01 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`K01_索赔成立与计算.md`](./K01_索赔成立与计算.md)（深母题知识层 R1–R8）之上**加的一层**，不是新母题体系。
> 知识层回答「**这个索赔成不成立、工期/费用各赔多少**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建索赔案例失分不是"不会"，是"会一点但写不成分"——把工期闸门和费用闸门混判 / 凭责任方一刀切 / 只写结论不写理由 / 不会拆"成立 ≠ 金额全成立" / 关键线路判断错。作答层的杠杆 = 把「知道两道闸门各判各的」变成「按阅卷结构写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 K01 §5 R5**（signed pack 的 R5/R6）。本层「可写化四件套」从 R5 **派生**，不另造采分点。
> - **判分归 signed scoring artifact**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，非官方判分（**漏不定分**）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**（E01–E12 / M01–M10）。本层错因标签只**映射** registry 已注册码，禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **三原则**：依附 K01 pack 不另起体系（thin）/ 句式模板跨母题复用（fat skill）/ less is more 别堆。
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，验证"会看答案→会写答案"跃迁用）。
> **三色铁律继承自 K01**：🟢 采分点锚定 K01 R5（point_id 可核 / 真题{年份+题号}可核）｜ 🔵 作答策略/句式（教学用，非判分眼）｜ 🔴 待真人/专家裁决（判分边界、给分档位、金额计算需 Layer-2 核）。

## 0. 五维框架（作答层的"采分点分类器"）

索赔案例采分点几乎都能归到这**五维**之一。索赔失分多是某一维整维漏掉、或两闸门维度搞混。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 K01 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁担责（发包人/承包人/双方分担） | 非承包人原因→可向发包人索；不可抗力→双方分担 | 凭"对方有责"一刀切，不区分工期/费用各自归属 |
| **程序维** | 按什么顺序/时限做（不可颠倒） | 28天内提意向通知；处理四步 | 漏28天时限；漏"合同未约定"前提就只写"28天" |
| **条件维** | 达什么阈值/网络位置才赔 | 关键线路？非关键超总时差？未超总时差？ | 关键线路判断错；"延误几月赔几月"不看总时差 |
| **记录维** | 要列什么计算/证据/分项 | 网络分析法/分项法逐项；证据四性 | 只写结论不列算式；漏证据四性 |
| **后果维** | 成立后赔什么（工期/费用/利润分写） | 工期顺延 + 费用补偿 + (发包人责任可加)利润 | 工期费用混写一句"可索赔"；漏利润 / 乱套利润 |

> **K01 五维的特别之处**：本考点是「**双闸门**」考点——同一事件，**条件维**（网络位置）决定工期成立性、**主体维**（责任归属）决定费用成立性，两者**互不蕴含**。学生最常把这两维"绑死"误判（工期不成立=费用不成立），所以五维自检对 K01 尤其要先分清"这一问到底在考工期闸还是费用闸"。
> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**，比"逐字找差"更快定位"差哪句"。

## 2. K01 答题句式模板（从研究方案 8 类勾选 K01 用到的 · fat skill 跨母题复用）

> **复用声明**：下列句式骨架是**跨母题作答结构**，不是 K01 专有——句式在作答层只写一次，40 pack 共用。本节从 skill §1.③ 全局句式库**勾选** K01 用到的几类，**不新造**。
> **勾选结果**：K01 以 **索赔句式（主打 · 用 skill 新版「双闸门」版）+ 第 9 类「计算判定链」（费用金额）+ 逐条裁决 + 程序箭头链** 四类为主。判断纠错（T1）/措施（六维）等 J01 主打句式 K01 案例**低频**，本层不堆（less is more）。
> **版本注**：索赔句式取 skill §1.③ **双闸门版**（第二步分叉工期闸/费用闸，互不蕴含，防 E07 工期费用绑死）；金额计算取 skill §1.③ **第 9 类「计算判定链」**（A01/N01/K01 实测后补入），非旧「内容清单枚举」类。

### 模板 K-Claim · 索赔句式【双闸门版】（skill §1.③「索赔」类 · **双闸门** · K01 主打）

> **版本对齐**：本段用 skill §1.③ **索赔双闸门版**（第二步分叉、工期闸/费用闸互不蕴含），逐字对齐 skill 措辞。这是 K01 实测撞出的命门——线性四步会强化最高频错 E07「工期费用绑死」。

```
【索赔·双闸门】先判责任归属（是否非承包人原因）
        → 第二步分叉成两条独立闸门：
            ‖【工期闸：是否影响关键线路 → 给工期顺延】
            ‖【费用闸：是否属发包人应担风险 → 给费用】
        → 再判是否按合同约定及时提出（28天意向通知）
        → 最后判证据是否充分（真实/全面/法律效力/及时）。
```
- **双闸门要害（互不蕴含）**：两闸门**各判各的**，工期不成立 ≠ 费用不成立——
  - 工期闸：责任归属 OK 后，**只看是否影响关键线路 / 总时差**（W3/W4），决定工期赔不赔、赔多少；
  - 费用闸：责任归属 OK 后，**只看是否属发包人应担风险 / 形成实际经济损失**（W6），决定费用赔不赔。
  这是 K01 索赔句式必须双闸门化的关键改造（实演见 §3.5，发现见 §4 实测报告 b）。
- **要害**：① 责任归属要**精确到方**（发包人/承包人/双方分担），不写"对方有责"含糊；② 工期与费用**分写两句**，绝不合并成"可索赔"。

### 模板 K-Calc · 金额计算判定链句式（skill §1.③ **第 9 类「计算判定链」** · 计算题专用）

> **类别归位**：本段对齐 skill §1.③ 新增的**第 9 类「计算判定链」**（A01 强度判定 / N01 关键线路时差 / K01 索赔金额三方实测撞同一缺口后补入）。骨架 = **亮判据/公式 → 代入题干数据列式 → 得数值结论 → 回判规范阈值或合同条款定性**。计算采分点的算式表达落在 §0 五维的**「记录/计算表达」维**（N01 实证扩名，不另造第六维）。

```
【计算判定链】① 亮判据/公式：索赔额 = 顺延工期 × 费率 / 费用 = 成本+管理费+利润逐层
          → ② 代入题干数据列式：<分项1>+<分项2>+… = <小计>（逐项写算式，不只写结论）
          → ③ 得数值结论：可索赔费用=<金额>万 / 可索赔工期=<结果>月
          → ④ 回判：定性结论（索赔成立否 / 是否在关键线路 / 是否达规范阈值）。
```
- K01 实例（费用分层，锚 `{2021,案例题（四）}`，该题答案含「9500−9200=300；300×10%=30；(300+30)×5%=16.5；索赔值=346.50万」）：① 公式=成本+管理费+利润逐层 → ② `300 + (300×10%=30) + ((300+30)×5%=16.5)` → ③ 索赔值=346.5万 → ④ 回判该项索赔成立、金额346.5万。
- K01 实例（工期，锚 `{2015,案例1}` C）：① 判据=可索工期为网络计划延误前后总工期之差、非关键工作以总时差封顶 → ② `C延误2月，总时差1月，超出1月` → ③ 可索赔工期=1月 → ④ 回判工期索赔成立但只顺延1月。
- **要害**：**四步都要写**（① 公式 / ② 列式 / ③ 数值 / ④ 回判定性），数值与结论都写——只写结论丢过程分、只列式不回判丢定性分。
- **本层边界（与 skill 第 9 类一致）**：本句式**只管作答结构 / 列式有没有写全四步**，**数值正确性归 signed scoring artifact + 判分内核，本层不独立判数值对错**。金额计算 🔴 **数值须 Layer-2 核**（见 §3.3 与 §4 实测报告 d，pack §8 已记多道真题网络图数值自相矛盾，金额题禁止直接采信源 logic_chain）。

### 模板 K-Verdict · 逐条索赔裁决句式（skill §1.③ 由真题归纳的逐条结构）

```
【逐条裁决】第N条：成立 / 不成立。
        理由：<责任归属一句> + <工期看网络位置 或 费用看损失归属一句>。
```

### b. §1.③ 索赔句式 + 四件套 + 五维，对 K01（成立判定 + 金额计算复合题）够用吗？哪里不够？

**结论：第 9 类「计算判定链」+ 索赔双闸门补入后，K01 两个实测缺口（计算判定级表达 / 索赔工期费用绑死）已闭合。** 计算的**数值正确性**仍归 signed scoring artifact + 判分内核（本层不独立验算），这是职责边界、非句式缺口。具体：

**已闭合②（计算判定链）**：K01 的金额计算（费用分层 346.5万、工期 延误−总时差、不可抗力剔除 32.7−8.2）此前在旧"内容清单枚举"类下只有"列算式"骨架、缺判分级结构。skill §1.③ 现新增**第 9 类「计算判定链」**（A01 强度判定 / N01 关键线路时差 / K01 索赔金额三方实测撞同一缺口后补入），骨架 = **亮判据/公式 → 代入题干列式 → 数值结论 → 回判定性**，四步都写。本层 K-Calc 已归位到第 9 类（§2），算式表达落 §0 五维「记录/计算表达」维。

## 2. 原理因果层（来源：镜头 A DeepSeek，汇编保留三条因果链并补一致性）

> **教学目标**：把四类通病串成因果主干，让学生「先懂为什么、后背措施」，而不是死记条文。

### 🔷 链一：水-缝-漏（渗漏）
**逻辑：水有缝必钻 → 缝从施工薄弱点来 → 堵缝 = 防漏**
```
成因：施工缝留错 / 养护不足 / 防水层薄 / 节点未做附加层
   ↓ 机理（🔵通识）
混凝土收缩→微裂→贯通缝；缝在受剪大处→受荷拉开；防水层破裂→水沿缝渗→冻融循环→缝扩大
   ↓ 为什么措施有效
① 施工缝留高出底板≥300mm、受剪小处 → 不被拉开    🟢kc:1A413030_131_0250:0 / kc:1A413030_103_0196:0
② 后浇带微膨胀+强度+一级+养护≥14d → 补偿收缩不裂  🟢kc:1A413030_103_0196:1
③ 养护≥14d → 充分水化、密实 → 水难渗             🟢kc:1A422000_029_0049:3
④ 隔汽层高出保温层≥150mm → 水汽不翻墙头           🟢kc:1A422000_040_0064:0
⑤ 涂膜夹胎体最上层≥1.0mm → 弹性覆盖微裂           🟢kc:1A413030_124_0235:0
⑥ 节点先做附加层夹铺胎体 → 应力集中处先加强        🟢kc:1A413030_134_0257:1
```

### 🔷 链二：材-空-裂（蜂窝麻面 + 空鼓）
**逻辑：材料不吃水 → 抢砂浆水 → 水化不足 → 粘结差 → 空鼓 / 脱落；离析 → 蜂窝**
```
成因：瓷砖未浸 / 石材未浸湿 / 砌块龄期<28d；骨料粒径>管径匹配→堵管；自由落差过大→离析
   ↓ 机理（🔵通识）
干材料吸水→抢走砂浆水分→水泥水化不足→界面粘结力不足→空鼓；离析→粗骨料集中→砂浆不填充→蜂窝
   ↓ 为什么措施有效
① 浸砖/浸湿 → 预吸水饱和、不抢水 → 粘结达标       🟢kc:1A413030_140_0273:1 / kc:1A413030_140_0272:1
② 龄期≥28d → 收缩基本完成 → 不再拉裂砂浆          🟢kc:1A413030_108_0211:0 / 真题2021案例三
③ 泵管径匹配骨料 → 不堵管 → 连续浇筑不分层        🟢kc:1A413030_102_0194:0
④ 控制自由落差 → 骨料不被甩出 → 均匀无蜂窝        🟢kc:1A413030_095_0179:0
```

### 🔷 链三：热-缩-裂（大体积混凝土裂缝）
**逻辑：水化热 → 内外温差 → 拉应力>抗拉强度 → 裂缝**
```
成因：一次浇筑过厚 / 入模温度高 / 散热差
   ↓ 机理（🔵通识）
水化热积聚(温升>50℃)→里表温差>25℃→表面拉应力超抗拉→表面裂；降温过快→内缩外约束→贯穿裂
   ↓ 为什么措施有效
① 分层浇筑300~500mm → 散热面积大 → 温峰降低        🟢kc:1A413030_096_0181:0
② 降温速率≤2℃/d → 应力缓释不集中                  🟢真题2017第10题
③ 里表温差≤25℃ / 拆保温温差≤20℃ → 不超抗拉        🟢kc:1A413030_096_0181:0
④ 养护≥14d → 强度持续增长 → 拉应力<抗拉           🟢kc:1A422000_029_0049:3
```

## 3. R2 不变量（来源：镜头 B Opus，一句话母规则）

🟢 **「质量缺陷是一个外观现象，但它唯一锚定一个施工/材料/环境成因，并由此唯一决定该不该治、怎么治」——即「现象 → 成因 → 处置」的单向链：判分只认成因正确与处置匹配，不认现象描述本身。**

该不变量可解释 ≥5 真题场景（均 🟢 锚 evidence）：
1. 🟢`2023 案例一·问题2`：给图 1-1~1-6 命名（麻面/裂缝/层间错台/露筋/孔洞/蜂窝）——命名是入口，分在「认对现象→对应成因」。

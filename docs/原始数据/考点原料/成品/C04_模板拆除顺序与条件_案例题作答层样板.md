# C04 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`C04_模板拆除顺序与条件.md`](./C04_模板拆除顺序与条件.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**底模/侧模各看什么、强度百分率按构件×跨度怎么查、快拆为什么取 50%、拆除顺序成对句、拆模程序/作业安全各是什么**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建模板拆除案例失分不是"不会"，是"会一点但写不成分"——只写"达到强度就拆"漏掉构件×跨度分档；侧模套底模百分率表；拆除顺序写反或写空（"按方案拆"）；快拆题按原 8m 取 75%/100% 无视保留立杆顶托；拆模程序只写"申请"漏"技术负责人批准"。作答层的杠杆 = 把「知道三重门槛」变成「**按五维写全采分点 + 三段式判断纠错带正确数值 + 顺序成对句 + 快拆判定链**」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 C04 §5.1 R5**（已 signed 的 candidate pack，4 个采分点 + R6 骨架补充的程序/作业安全/预应力门槛）。本层「可写化四件套」从 R5 + R6 骨架**逐字派生**，**绝不另造采分点**。采分点的内容/必写词以 `_C04_compiled_source.json` 对应 `point_id` 的 `quote` / `required_terms` 为终判（深 pack §1/§5 散文若与 compiled_source 矛盾，以 compiled_source 为准）。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 C04 §5.R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E06/E07/E10、M03/M08/M09/M10，经真实 Read `error_codes.py` 确认存在），禁自造。**特别注意**：C04 深 pack §6 用的 `ERR_CONCEPT_CONFLATION`/`ERR_NUMERIC_TABLE_MISMATCH`/`ERR_SEQUENCE_ORDER` 等是**拟挂载临时码、未注册**，本层**不沿用**，统一改写为已注册 E/M 码（深 pack §10 审计第 3/12/15 条亦要求落地为 E/M 码）。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_C04_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2015·第10题}`、`{2021·第9题}`、`{2024·第10题}`、`{2016·案例2}`、`{2022·第3题}`、`{2015·案例1}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用。注：深 pack §8.2/C3 已剔除编造锚 `{2022·第(三)题}`（实为沉管灌注桩），本层亦不引用。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**判断纠错 + 计算判定链 + 程序**，验证句式库在拆模顺序/条件场景泛化用）。
> **三色铁律继承自 C04**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识/换算（无单一 point_id 但学界共识，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、临界取舍、待回填 point_id）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写拆模答案漏分，多是某一维整维漏掉（最典型：只答强度门槛漏掉顺序门槛与程序门槛，或侧模/底模判据张冠李戴）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 C04 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织/谁批准 | 拆模须**技术负责人批准**（E1，`kc:...0190:1`） | 漏"技术负责人批准"，写成"经监理同意即可"或现场口头申请（{2016·案例2} 经典坑） |
| **程序维** | 按什么顺序做 / 走什么流程 | 拆除顺序成对句（D1）；填申请→试块达标→批准（E1） | 顺序写反（"先拆承重"）或写空（"按方案拆"）；程序漏"填拆模申请/试块达标"环节 |
| **条件维** | 达什么阈值才合格/才拆（强度百分率、立杆≤2m、1N/mm²） | 底模按构件×跨度查百分率表（B1）；侧模 1N/mm²（A1）；快拆立杆≤2m（C1） | 侧模套底模百分率表；7m 板取 100%（应 75%）；快拆按原 8m 取 100% 无视保留立杆顶托 |
| **记录/计算表达维** | 留什么书面 / **写算式链+数值结论**（拆模强度换算） | 6m 板 C30→75%→22.5N/mm²（{2021·第9题}）；8m 快拆→50%→15MPa（{2015·第10题}） | 只写"达到强度"不写数值；只写结论不写"×75%/×50%"算式过程 |
| **后果维** | 不达标/达标后会怎样（过早拆除、违章拆除、大片塌落） | 底模禁无控制大片塌落（E3，`kc:...0190:3`）；过早拆模=安全隐患（{2022·第3题}） | 只会"会出事"，不知按"过早拆除模板和支撑"规范语言写、不知"禁大片塌落+设警戒线" |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。C04 因是"三重门槛"型考点（强度 AND 顺序 AND 程序），**条件维 + 程序维**是失分双主战场；案例改错题里 5 个维（主体/程序/条件/记录计算/后果）常**同题多维并发**，要逐维扫。

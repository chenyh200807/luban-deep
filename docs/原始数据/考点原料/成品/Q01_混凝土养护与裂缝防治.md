## 2 · 原理因果层（混凝土为什么裂、怎么防）

> 来自镜头 A。汇编保留其「敌军（拉应力）/我军（抗拉强度）/战场（约束）」三方框架，但把「养护」这一旋钮显式接到 §3 R2 不变量，消解 A（偏原理）与 B（偏养护）的视角错位。

### 第一链：裂缝为何产生

1. **材料-环境的根本矛盾**（🟢`kc:1A411011_029_0053:0`）
   混凝土硬化必然**收缩**，环境温变引起**热胀冷缩（温度作用）**。这些变形在**受约束**构件内产生**拉应力**，当拉应力 > 混凝土抗拉强度 ftk，微裂发展为宏观裂缝。这是「间接作用」的物理内核。

2. **配合比/施工的放大效应**（🟢`kc:1A412010_046_0080:2`）
   盲目追求坍落度 → **单位体积用水量过大** → 多余水分蒸发留下孔隙 → 增大收缩、降低密实度与抗拉强度 → 放大「收缩致裂」，是早期塑性裂缝与干缩裂缝主因。
   **这正是养护要管的窗口**：早龄期失水越快，收缩越猛（接 §3 R2「湿度旋钮」）。

3. **外部约束的致命一击**（🟢真题`2016·第12题`）
   地基不均匀沉降/构件强约束 → 结构被强制变形 → 「强迫位移」拉应力远大于自由收缩应力 → 撕裂薄弱部位，产生规律性裂缝（纵墙端"八"字斜裂缝、窗间墙水平裂缝）。

### 第二链：如何有效防治（养护是其中的施工旋钮）

> 原则：增强我军（抗拉强度）／削弱敌军（拉应力来源）／稳固战场（释放约束）。

- **增强我军**：选用更高强度等级混凝土、合理适配水泥强度（🟢`kc:1A412010_044_0077:0`），满足应力控制的第一、二等级（🟢`kc:1A411011_032_0057:0`）。
- **削弱敌军（养护主战场）**：控水胶比、**保湿保温养护**；大体积用缓凝剂（🟢`kc:1A412010_049_0087:0`）、降浇筑温度、控里表温差——从源头减小水化热与干缩拉应力。
- **稳固战场**：设伸缩缝/沉降缝/后浇带，释放约束（🔵`kc:1A411011_022_0043:0` 外墙饰面砖伸缩缝≤6m 为邻接构造佐证（不属本考点直接原理，背景不判分）；后浇带见 §1#14）。
- **加固薄弱环节**：构造钢筋把裂缝宽度限在无害范围（对应第三控制等级，🟢`kc:1A411011_025_0047:2`）；预应力主动施加预压应力实现第一等级（不出现拉应力）。

## 3 · R2 不变量（一句话 + ≥5 场景）

> 来自镜头 B（Opus）。汇编已逐条核验其真题锚（见 §8 校验账）。

**R2 不变量（一句）**：
> **混凝土的裂缝防治，本质是「在它最脆弱的早龄期，把内部温度梯度与失水收缩压在材料当时能承受的范围内」——养护就是用时间、湿度、温差三个旋钮，让强度增长跑赢收缩与温度拉应力。** 🟢

**贯穿 ≥5 场景**：

1. **普通现浇养护时长**（🟢`kc:1A413030_104_0197:0`）：硅酸盐/普硅≥7d；掺缓凝/抗渗/C60+≥14d。旋钮=「时间×湿度」。真题印证🟢`2022·第15题`（D「有抗渗要求的不少于14d」正确）。
2. **大体积温控**（🟢`kc:1A413030_096_0181:0`）：里表≤25℃、降温≤2.0℃/d、温升≤50℃、保湿≥14d、拆保温温差≤20℃。旋钮=「温差」。真题印证🟢`2017·第10题`（降温速率不宜大于 2℃/d，选 C）。
3. **防水/抗渗混凝土**（🟢`kc:1A413030_131_0250:2`）：养护≥14d、后浇带≥28d、高温入模≤30℃、宜低水化热水泥+缓凝剂+粉煤灰。湿度旋钮拧满。真题印证🟢`2015·第26题`（题干给「养护≥7d」为**错**，应 14d）。
4. **后浇带封闭与养护**（🟢`kc:1A413030_103_0196:1`）：微膨胀混凝土、强度提高一级、养护≥14d；「主动留缝放收缩」是不变量的逆向应用。真题印证🟢`2018·案例三·问题3`（底板后浇带 10d 封闭为错，应≥28d）。
5. **冬期施工养护**（🟢真题`2019·第1题`）：中心-表面≤25℃、表面-大气≤20℃、温降梯度≤3℃/d、养护≥14d。旋钮=「温差+保温」。
6. **拆模时机（强度门槛侧）**（🟢真题`2021·第9题`）：跨度 6m、C30 板拆底模需同条件养护试块≥75%设计强度（22.5N/mm²，选 C）。本质仍是「强度增长 vs 受力」。
7. **裂缝控制等级（设计-施工接口）**（🟢`kc:1A411011_032_0057:0`、`kc:1A411011_025_0047:2`）：防裂不一刀切，按构件性质给阈值，养护是把施工实际压进设计阈值。

### 4.3 trap_alert（陷阱）

1. **7d vs 14d 张冠李戴**：普硅≥7d，但「抗渗/C60+/后浇带」必须≥14d。🟢`2022·第15题 D`、`2015·第26题 D`（题干给 7d 即错项）。
2. **降温速率 2℃/d（大体积·施工标准）≠ 冬期温降梯度 3℃/d**：两数字常被互换。🟢`2017·第10题`=2℃/d；🟢`2019·第1题`冬期=3℃/d。
3. **后浇带封闭时机**：养护≥14d，但**封闭时机**底板≥28d。🟢`2018·案例三·问题3`（题干「10d 后封闭」是经典错项）。
4. **里表温差 25℃ vs 表面-大气 20℃**：大体积里表≤25℃；拆保温/冬期表面-大气≤20℃，方向写反即丢分。🟢`kc:1A413030_096_0181:0`、`2019·第1题`。
5. **拆模强度按「同条件养护试块」而非标养**：🟢`2021·第9题`陷阱在「同条件」三字，跨度档不同百分比不同。
6. **「一遍成活/一次成型」防水做法**：防水砂浆应多层抹压/接槎错开，题干给「一遍成活」即错。🟢`2022·第16题 A`（错项）；正确做法见该题答案 B「上下层接槎错开200mm」。

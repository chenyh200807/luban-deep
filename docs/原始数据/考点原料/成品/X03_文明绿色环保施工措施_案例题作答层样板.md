# X03 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`X03_文明绿色环保施工措施.md`](./X03_文明绿色环保施工措施.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`，合并考点=文明施工 + 绿色施工四节一环保 + 环境保护技术三子轴）之上**加的一层**，不是新母题体系。
> 知识层回答「**文明施工六化是哪几化、四节各归哪一类、扬尘/噪声/污水/固废各上哪些措施、围挡多高、建筑垃圾堆放限高多少**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建文明/绿色/环保案例失分不是"不会"，是"会一点但写不成分"——措施只写"加强管理、文明施工、绿色环保"口号不落到冲洗池/低噪设备/分类台账等可执行动作（E04）、综合写措施只答文明施工漏掉四节/扬尘/噪声/污水/固废整类（E02）、把"绿化代硬化"归成节材（实为节地，E07）。作答层的杠杆 = 把「知道有哪些措施」变成「按**措施六维裁剪 + 内容清单枚举**写全可判分动作 + 归类不混」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 X03 §5 R5**（已 signed 的 candidate pack，12 命中单元 / 41 去重采分点）。本层「可写化四件套」从 R5 **逐字派生**，内容/必写词/锚**逐条对照 `_X03_compiled_source.json` 对应 point_id 的 quote/required_terms 核真**（quote 终判，绝不据散文锚），**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 X03 §5 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E04/E07/E10/E12、M03/M04/M06/M08，经真实 Read `error_codes.py` 确认存在），禁自造。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写文明/绿色/环保措施漏分，多是某一**子轴整类漏掉**（最典型：综合写措施只写文明施工，漏掉四节/扬尘/噪声/污水/固废整类污染）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 X03 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位"） | 施工单位对建筑垃圾分类计量建台账（隐含施工方）；污水许可由**市政管理部门**发证 | 本考点主体维占比低，仅"发证部门"独立成采分点（{2020·第16题}） |
| **程序维** | 按什么顺序做（评价流程、资源化路径、扬尘"源头→路径→出口"） | 绿色施工评价：基本规定→指标→要素→批次→阶段→单位工程；建筑垃圾分类收集→堆放→级配回填粉碎→再生骨料 | 评价流程漏中间层级；资源化路径缺项 |
| **条件维** | 达什么阈值才合格/才做（围挡高度、堆放限高、抽水量、材料类型） | 围挡≥1.8m、可循环可拆卸标准化；建筑垃圾堆放不宜高于3m（超3m须验算）；抽水量>50万m³须回灌 | 围挡高度数字记错（1.8m 与 X01 市区 2.5m 串档，E10/M08）；堆放限高记错 |
| **记录/计算表达维** | 留什么书面（分类计量台账、绿色施工五具备的影像/合同、夜间许可证） | 建筑垃圾分类计量建台账、未分类不得运出；绿色施工五具备（体系/文件/标志/影像/合同）；夜间办许可证公告居民 | 只写"分类"漏"建台账"；漏"未分类不得运出场" |
| **后果维** | 不达标/达标后会怎样（违规外运、随意排放、归类错） | 未分类不得运输出场；泥浆未处理不得随意排放；绿化代硬化=节地（归类错则概念混淆） | 把"泥浆沉淀后就地排放"当合规（E10）；四节归类混淆（E07） |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。X03 是**措施清单意识型**合并考点，**程序维+条件维+记录维**是失分主战场（措施齐不齐、归类对不对、有没有落到台账/许可证/冲洗池等可判分动作）。

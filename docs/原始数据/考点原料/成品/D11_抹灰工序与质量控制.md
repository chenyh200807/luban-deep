## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「因果链 + 每段挂 point_id」，**删除镜头 A 里无锚的力学外推**（"差动位移集中拉应力""蒸汽压力顶起涂层""网片锚固长度"等是合理工程解释但无 point_id 也无真题证据，保留为 🔵 讲解性表述，不充判分；镜头 A 自标 🔴 的"不同材料热胀系数差异"机理保留 🔵）。

**核心因果链(讲懂层骨架)：**

```
抹灰开裂/空鼓本质 = "约束下的收缩" 或 "约束下的差动位移"      🔵讲懂背景(机理无独立 point_id)
   │
   ├─ 单层抹太厚(总厚度≥35mm) → 表层快干收缩、内层慢干约束 → 收缩拉应力超限 → 开裂/空鼓
   │     └ 对策: ≥35mm 须采取加强措施(分层抹灰 / 挂加强网)   kc:1A422000_042_0068:0  🟢
   │     └ 内墙普通抹灰层平均总厚≤20mm / 高级抹灰层≤25mm(控制单层不过厚)  {2023,第26题}  🟢真题
   ▼
   ├─ 不同材料基体(混凝土/砖/加气块)变形系数不同 → 交接处差动位移 → 集中拉应力 → 通缝开裂
   │     └ 对策: 交接处挂加强网跨过接缝分摊应力; 加强网与各基体搭接≥100mm(防网自身拔脱)
   │        kc:1A422000_042_0068:0 + kc:1A422000_043_0069:0  🟢
   ▼
   ├─ 基层含水率过高就抹/涂 → 水分被封在基层 → 蒸发顶起面层 → 鼓泡/空鼓/剥离
   │     └ 对策: 控含水率(溶剂型涂料≤8% / 乳液型≤10% / 木材≤12%)  kc:1A422000_043_0069:1  🟢
   ▼
   ├─ 环境温度过低(<5℃)抹灰 → 砂浆冻胀/强度不发展 → 空鼓
   │     └ 对策: 室内抹灰环境温度一般不低于5℃  {2023,第26题}  🟢真题
   ▼
   └─ 厨卫长期潮湿 → 普通腻子遇水粉化失粘 → 面层脱落
         └ 对策: 厨卫找平层用耐水腻子(遇水不粉化)  kc:1A422000_043_0069:2 + {2018,第24题}/{2022,第21题}  🟢
   ▼
效果 = 抹灰层从"约束下易裂/易鼓"变成"分层+加网+控水+控温+耐水材料"五重防控
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **≥35mm 加强 / 控层厚**：厚层内外干缩速率差大，拉应力超砂浆抗拉强度即裂；加强网提供抗拉钢筋、分层抹灰错开收缩时段、控制单层厚度都是降低收缩拉应力。
- **交接处加强网搭接≥100mm**：网片跨越接缝将差动位移应力分散传给两侧基体；100mm 搭接保证网片在每侧基体的锚固长度，避免网片自身从基体拔脱（镜头 A 力学推理，🔵 不充判分）。
- **控基层含水率**：含水率低于面层成膜/粘结的临界阈值，残余水分不足以汽化顶破面层。
- **耐水腻子**：水泥基/高分子改性胶凝材料遇水不粉化耐碱，保证潮湿环境粘结持久。

> 三色提醒：因果链的**结论(35mm/100mm/8%/10%/12%/普通抹灰≤20mm/高级≤25mm/温度≥5℃/耐水腻子)**全部 🟢 锚定(教材锚或真题锚)；链条里的**微观机理解释**(差动位移/蒸汽压力/锚固长度)是讲懂用语，标 🔵，不得作为采分点输出（§8.2 C2）。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(Opus) 主写，汇编层逐场景重核真题锚。三个真题锚（`{2023,第26题}`/`{2018,第24题}`/`{2022,第21题}`）均经 `verify_exam_anchors.py` 确定性命中 + 逐选项直读 correct_answer 核真。

**不变量(一句话)：**
> 凡抹灰质量控制，都必须按「**控基层(含水率：溶剂型≤8%/乳液型≤10%/木材≤12%) → 控厚度(总厚≥35mm 须加强；普通抹灰层平均总厚≤20mm/高级≤25mm) → 交接处防裂(不同材料基体加强网搭接≥100mm) → 控环境(室内抹灰温度≥5℃) → 控材料(厨卫找平层用耐水腻子) → 后续工序不抢跑(涂饰在抹灰湿作业后)**」逐项把抹灰层从"约束下易裂/易鼓"变成可控。出题人永远在考「**厚度够不够须加强 / 加强网搭接够不够 / 含水率达不达标 / 层厚超不超 / 温度够不够 / 是不是耐水腻子**」的数字与适用对象，不考砂浆配合比本身(编译库无锚)。

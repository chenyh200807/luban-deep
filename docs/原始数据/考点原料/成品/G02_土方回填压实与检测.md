## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「三段因果链 + 每段挂 point_id」，**降级镜头 A 把"最优含水量"当解释链一环写得过实的表述**（最优含水量编译库无锚，标🔵讲解性、不充判分）。镜头 A 的"为何措施有效"机理解释无 point_id，保留为 🔵 讲解性表述、不充判分。

**核心因果链(讲懂层骨架)：**

```
土的本性: 天然土开挖后松散(可松性)→需压实才能恢复承载   kc:1A413000_076_0145:0、{2015,第8题}  🔵背景
   │  压实=外力排气减孔隙、固体颗粒紧密重排
   ▼
第一步: 选料 —— 禁用淤泥/淤泥质土/有机质>5%/含水量不符的黏性土，尽量同类土   kc:1A413000_085_0158:0、{2022,第21题}  🟢判分眼
   │  料不对→压不实/后期不均匀沉降(橡皮土)
   ▼
第二步: 分层铺填 —— 从最低处起、由下而上、对称回填；虚铺厚度按夯实机具定   {2016,第8题}、kc:1A413000_085_0158:2  🟢
   │  铺太厚→下部压不到(机具夯击能=有效压实深度)；含水率过大/过小→压不实   {2019,第16题}  🟢
   ▼
第三步: 压实 —— 按压实机具控分层厚度+遍数(振动压实机250-350mm/3-4遍…)   kc:1A413000_085_0158:2  🟢判分眼
   │  下层压实系数合格后才做上层   {2020,第29题}  🟢
   ▼
第四步: 检测 —— 施工后标高+压实系数检验；用标准击实法(非多层环刀统一送检)   kc:1A434000_064_0095:0、{2018,案例三}  🟢判分眼
   ▼
效果 = 回填体密实度达标 → 给上层结构/道路提供可靠基床
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **可松性→需分层压实**：开挖后土体积增大、孔隙率高，必须分层用机械夯击能克服颗粒摩擦咬合、排气增密，单层太厚则下部压不到。
- **最优含水率附近最易压实**：含水率过低则颗粒间水膜薄、内摩擦阻力大；过高则自由水占据固体颗粒空间且不可压缩——故 `{2019,第16题}` 答"含水率过大或过小"均致密实度不足。（最优含水率本身编译库无锚，🔵 讲解性）
- **虚铺厚度由夯实机具定**：机具夯击能决定有效压实深度→决定单层虚铺厚度，含水量影响的是压实效果而非铺厚依据，这是 `{2016,第8题}` 反向陷阱 D 的成因。
- **击实法 vs 环刀法**：压实系数=现场实测干密度/室内最大干密度，最大干密度需用标准击实法在室内标定；把多层回填的环刀土样统一送检无法对应分层压实质量，故 `{2018,案例三}` 判"应采用标准击实法"。

> 三色提醒：因果链的**结论数字/做法**（土料禁用项、压实参数表、虚铺厚度依据、压实系数检验）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（可松性原理、最优含水率机理、击实法标定逻辑）是讲懂用语，标 🔵，不得作为采分点输出。

> **⚠️ 🟢 证据等级声明**：四步链中**选料/压实参数**两环有**教材锚**（`kc:1A413000_085_0158:0`/`:2`）；**虚铺厚度依据/回填工艺/密实度原因/回填综合多选/检测方法（击实法）**等环**编译库无独立教材锚，其 🟢 全部是真题锚**（`{2016,第8题}`/`{2019,第16题}`/`{2020,第29题}`/`{2018,案例三}`，经 gate 2 确定性核真）。**真题锚 🟢 ≠ 教材锚 🟢**：前者证明"真考过且答案如此"，但**未经规范原文逐字锚定**——尤其"具体检测方法（环刀法/灌砂法/灌水法/标准击实法）"编译库完全无锚，全靠真题侧。补 GB50202 编译锚后方可视作完全锚定。

**≥5 场景印证(每条带已核真锚)：**

1. **填方土料准入** —— 不能用作填方土料的有：淤泥、淤泥质土、有机质大于5%的土（砂、碎石土可用）。

2. **虚铺厚度依据(反向陷阱)** —— 每层虚铺厚度应根据**夯实机具**确定，不是根据含水量确定。
   🟢 真题锚 `{2016, 第8题}`(直读：单选 ans=D，stem「关于土方回填施工工艺的说法，错误的是」D「虚铺厚度根据含水量确定」，解析「每层虚铺厚度应根据夯实机械确定」)；教材参数表 `kc:1A413000_085_0158:2`。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"四步链(选料→铺填→压实→检测)逐点 reveal"**，删除强夯地基/越界分镜，把"排水系统"反向误区改正，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **选料"红沙筛"**：传送带上不同颜色土料过筛——红色(淤泥)/黑斑(有机质>5%)被红叉拦下，同类土(同色)绿灯通过（"禁用清单"）。
- **分层铺填"千层糕"**：从坑底最低处起一层层铺填，左右两侧砝码对称压（"由下而上+对称回填"），单侧堆高则结构图标偏压报警。
- **虚铺厚度"机具尺"**：换不同压实机具(平碾/振动压实机/打夯机)，铺土厚度尺随机具自动跳到对应区间(250-350mm…)；有人试图用"含水量滑块"调铺厚被红叉拦（"按机具不按含水量"）。
- **压实"夯击波+下层合格灯"**：夯击波逐层下传，下层亮"压实系数合格"绿灯后上层才解锁施工。
- **检测"击实法 vs 环刀堆"**：左屏标准击实法在室内标定最大干密度→算压实系数(绿勾)；右屏多层环刀土样塞一个袋统一送检被红叉（"应用击实法"）。

### Reveal 顺序(讲懂 → 判分眼)
1. **四步链骨架**：选料→铺填→压实→检测 流程条亮起。(讲懂层骨架)
2. **选料**：红沙筛拦淤泥/有机质土，同类土通过。(锚 `kc:1A413000_085_0158:0`、`{2022,第21题}`)
3. **铺填**：千层糕从最低处起、对称压；虚铺尺随机具跳、含水量滑块被拦。(锚 `kc:1A413000_085_0158:2`、`{2016,第8题}`)
4. **含水率**：含水率滑块过大(成泥浆)/过小(散沙)两端密实度仪都掉档，中间最优值满格。(锚 `{2019,第16题}`)
5. **压实**：夯击波逐层下传，下层合格绿灯亮后上层解锁。(锚 `kc:1A413000_085_0158:2`、`{2020,第29题}`)
6. **检测项**：施工后标高尺+压实系数仪双勾；必查清单勾填筑厚度/含水量/压实系数，排水系统被划掉(非必查)。(锚 `kc:1A434000_064_0095:0`、`ca:1A434000_064_0095`)
7. **检测方法**：击实法室内标定 vs 环刀堆统一送检红叉对比。(锚 `{2018,案例三}`)

### Aha 时刻(锚已按内容精确挂)
- 一袋装满黏稠淤泥被拖向回填区，红沙筛红叉拦下 → 「不是所有土都能回填，淤泥/有机质>5%/含水量不符的黏性土禁用」。锚 `kc:1A413000_085_0158:0`、`{2022,第21题}`
- 工人拖"含水量滑块"想调虚铺厚度被弹回，换成"机具选择器"厚度尺才动 → 「虚铺厚度按夯实机具定，不是按含水量」。锚 `{2016,第8题}`
- 含水率滑块从过大滑到过小，密实度仪两端都掉档、唯独最优值满格 → 「含水率过大过小都压不实」。锚 `{2019,第16题}`
- 多层环刀土样被塞进一个袋统一送检被红叉，标准击实法室内标定亮绿勾 → 「压实系数要用标准击实法，不能多层环刀统一送检」。锚 `{2018,案例三}`

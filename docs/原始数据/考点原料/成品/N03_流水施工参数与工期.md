## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写四层因果链；汇编层把散文链收成「分层因果 + 每层挂 point_id」，**降级镜头 A 无编译锚的力学/公式外推**（`T=(M+N-1)t`、`T=(M+N'-1)K+Σ(G+Z-C)` 是合理机理但教材锚 `kc:1A433000_054_0081:0` 只给到「Σ步距+末工序节拍之和+技术间歇」的口径，公式细化保留为 🔵 讲解性，不充判分；镜头 A 自造的「潘特考夫斯基法」别名无锚降 🔵）。

**核心因果链(讲懂层骨架)：**

```
[施工段数 M + 施工过程数 N]   kc:1A433000_051_0074:1  🟢
   │  分段=空间解耦的前提;劳动量差异≤15%保证节拍均衡
   ▼
[流水节拍 t]   kc:1A433000_052_0075:0  🟢  ──判型──▶ 等节奏 / 异节奏(等步距) / 无节奏
   │
   ▼
[流水步距 K]   kc:1A433000_052_0075:1  🟢
   ├ 等节奏:        K = t                       kc:1A433000_052_0077:0  🟢
   ├ 异节奏等步距:  K = 最大公约数(t₁…tₙ)        kc:1A433000_053_0078:1  🟢
   └ 无节奏/异步距: K = 大差法(累加→错位相减→取最大值)  kc:1A433000_054_0081:0  🟢
   ▼
[工期 T]   kc:1A433000_052_0075:2  🟢
   = Σ流水步距 + 末工序在各段节拍之和 + 技术/组织间歇   (大差法口径 kc:1A433000_054_0081:0 🟢;细化公式🔵)
   ▼
效果 = 用「判型 → K → 专业队数 → T」把「这工程该排几个队、工期多久」算清楚
```

**为什么判据成立(讲解性，🔵 不充判分)：**
- **流水 = 依次与平行的折中**：依次施工工期 ≈ M×N×t（无搭接、效率低）；平行施工资源 ≈ N 倍（成本爆增）；流水把有依赖关系的工作在空间上错位搭接，用「时间差」换「资源均衡」，工期介于两者之间。
- **等节奏「连续无空闲」的算理**：t 全等且 K=t 时，前队在任一段的完成时刻 = 后队在该段的开始时刻，形成「人不等工作面、工作面不等人」的无缝接力——这是 `{2015,第16题}` D 项「不能连续作业」错误的根。
- **等步距异节奏「增队化异为同」**：节拍大的过程拆成多队（队数=节拍/K），所有队按统一 K=最大公约数推进，宏观推进速率不变但微观衔接无断点，故**专业队数>施工过程数**。
- **大差法「错位相减取最大」防抢工**：步距取累加数列错位差的最大值，保证后序专业队进入任一段时前序都已腾出工作面，不会「抢工作面」。

> 三色提醒：因果链的**判据结论**（K 与类型的对应、专业队数>过程数、大差法步骤）全部 🟢 锚定；链条里的**封闭公式**（`T=(M+N-1)t` 等节奏闭式、`Z=节拍/K` 队数闭式）是讲懂用语，标 🔵，**不得作为采分点的独立 point_id 输出**——数值算例以真题侧 `{2019}`/`{2023}` 为准。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(Opus) 主写，汇编层精简为一句 + 保留场景印证，逐场景重核真题锚（删除任何证据包内不存在或数值对不上的锚）。

**不变量(一句话)：**
> 凡给出施工段/施工过程节拍信息，案例判读主链**通常**是「**先判型（节拍是否相等、是否成倍数）→ 按型求流水步距 K → 求专业队数 → 求总工期 T**」。考的不是工艺本身，而是「**类型判别 + 步距/队数/工期计算正确性**」；任一环错（判型错 / K 取错（如把成倍节拍的 K 取成最大或平均节拍）/ 队数漏算 / 工期机械相加不体现搭接）即丢分。

换言之：判分核心 = **流水施工类型判得对（含理由）+ 流水步距 K 算得对 + 专业队数算得对 + 总工期 T 算得对（带过程与单位）**。四者缺一即「不妥」。

> **不变量适用边界**：本不变量描述的是**案例计算/判读类**主链，**不覆盖**纯概念辨析 MCQ（等节奏/异节奏特点选错项，见 §6 M1，考「记特点」而非「算」）、纯参数清单题（工艺/时间/空间参数三分类，§1#13，考「分类记忆」）。这两类各有采分眼，不强套本不变量。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Aha 锚定按内容精确挂**，Reveal 顺序重排为「组织方式 → 三参数 → 判型 → 算 K/队数/工期」，对接闭环渲染器约定见尾注。

### 视觉隐喻
- **三大组织方式**：三条流水线/河道并列——依次(单段逐节亮、慢)、平行(全段同时亮、资源 N 倍)、流水(错位接力亮、连续搭接)。
- **流水节拍 t / 步距 K**：横道图上每个工序方块长度=t，相邻工序起点错开的水平距离=K。
- **等节奏**：均匀排列的齿轮/方块，K=t 时方块严丝合缝无缝接力。
- **等步距异节奏(成倍节拍)**：节拍大的工序方块**裂成多队**（如节拍 6 裂成 3 个长 2 的小队），所有队以统一步距 K=最大公约数推进。
- **无节奏/大差法**：各工序累加数列堆成数字方块塔，错位相减取最高差=步距，过程间留间隔缝。
- **总工期**：横道图最右末工序方块的退场时刻=T 标尺。

### Reveal 顺序(组织方式 → 参数 → 判型 → 计算)
1. **三条流水线对比**：依次/平行/流水三河道亮起，流水河道错位搭接最优。(锚 `kc:1A433000_051_0074:0`)
2. **标三参数**：横道图浮出 t(方块长)、K(错开距)、T(末方块退场)。(锚 `kc:1A433000_052_0075:0、kc:1A433000_052_0075:1、kc:1A433000_052_0075:2`)
3. **判型分叉**：节拍序列亮起，按全等/成倍数/无规律分叉到等节奏/等步距异节奏/无节奏。(锚 `kc:1A433000_052_0077:0`、`kc:1A433000_053_0078:0`、`kc:1A433000_052_0076:0`)
4. **算 K**：等节奏 K=t 严丝合缝；成倍节拍高亮最大公约数；无节奏数字塔错位相减取最高差。(锚 `kc:1A433000_053_0078:1`、`kc:1A433000_054_0081:0`)
5. **拆队**：节拍大的工序方块裂成多队，队数计数器跳到 >过程数。(锚 `kc:1A433000_055_0083:0`、`{2019,第2题}`)
6. **算工期**：末工序方块滑到退场时刻，T 标尺定格(带搭接，非机械相加)。(锚 `{2023,第2题}`)

### Aha 时刻(锚已按内容精确化)
- 学生把等节奏选项「不能连续作业」当对，镜头亮出无缝接力的齿轮链 → 「等节奏必然连续无空闲，『可能有间隔』是无节奏」。锚 `{2015,第16题}`
- 学生把成倍节拍 K 取成最大节拍 6，队伍撞车留大缝；改取最大公约数 3，缝消失 → 「K 必取最大公约数」。锚 `kc:1A433000_053_0078:1`、`{2023,第2题}`
- 学生每过程只放 1 队，节拍 9 的工序拖慢全场；裂成 3 队后衔接顺畅 → 「成倍节拍要拆队，队数>过程数」。锚 `{2019,第2题}`
- 学生把所有节拍机械相加得超长工期；切到搭接视图 (2+5−1)×3=18 → 「流水工期体现搭接，不是 Σ 所有节拍」。锚 `{2023,第2题}`

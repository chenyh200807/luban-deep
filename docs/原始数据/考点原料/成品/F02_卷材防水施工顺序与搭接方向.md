## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「水往低处流→施工铁律」因果环；汇编层把镜头 A 的散文链收成「四链 + 每链挂 point_id」，**镜头 A 自造的 E02/E03/E05/M01/M02 错因码与 `F02-xx` node_code 全部移除**（错因统一归 §6 按 registry 重判）；镜头 A 的"毛细作用/概率指数级下降"等机理解释无 point_id，保留为 🔵 讲解性表述、不充判分。

**核心因果链(讲懂层骨架)：**

```
物理本性: 水受重力沿屋面坡向(流水方向)下流   ca:1A413030_123_0232(找坡=流水方向依据)  🔵背景
   │  搭接缝若逆水流开口→水流倒灌缝内→渗漏
   ▼
第一步: 先细部后大面 —— 阴阳角/泛水/管根/落水口先做加强(附加层)，再铺大片卷材   kc:1A413030_123_0234:0、kc:1A413030_125_0237:1  🟢判分眼
   │  细部形状突变、应力集中=渗漏高发点，先封死薄弱点
   ▼
第二步: 由低向高铺贴 —— 由屋面最低标高向上，上幅压下幅(顺水搭)   kc:1A413030_123_0234:0、{2016,第27题}  🟢
   │  上压下→搭接缝开口朝下游→水从缝"上岸"流过不灌入(顺水皮)
   ▼
第三步: 搭接方向 —— 卷材平行屋脊、搭接缝顺流水方向；上下层不得相互垂直铺贴   kc:1A413030_123_0234:0、kc:1A422000_041_0065:0、{2016,第27题}  🟢判分眼
   │  缝与水流同行不对冲；垂直铺贴→双层接缝正交成"十字漏点"
   ▼
第四步: 搭接错缝 —— 短边错缝≥500mm、长边/上下层错开≥1/3幅宽   kc:1A422000_041_0065:0、kc:1A422000_029_0049:0  🟢判分眼
   │  错缝把"一字连续薄弱带"打散成点，下层完好区接力挡水(冗余)
   ▼
效果 = 引水不灌缝(疏导)+薄弱点加强(阻断)+多层错缝(冗余) → 渗漏概率降至设计允许范围
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **由低向高=顺水皮**：上幅卷材压住下幅、搭接缝开口朝下游，水流只在缝的上游侧（屋脊侧）流过，无法倒灌——这是防水施工最根本的防倒灌原则（机理为讲解性，🔵）。
- **搭接缝顺流水方向/平行屋脊**：使搭接缝与水流同行而非对冲；若垂直铺贴，上下两层接缝正交成网格、交叉点两层同时有缝形成穿透通道（机理 🔵）。
- **错缝≥500mm / ≥1/3 幅宽**：把"线式连续薄弱带"转成"点式风险"，上下层接力防水——下层漏了上层还在挡（冗余设计逻辑，🔵）。
- **先细部后大面**：细部节点（女儿墙泛水/阴阳角/落水口）几何突变、应力集中、施工困难，是渗漏高发点，先用附加层武装完成再铺大面（机理 🔵）。

> 三色提醒：因果链的**结论做法/数字**（先细部后大面、由低向高、搭接顺流水、不垂直、短边≥500mm、长边≥1/3幅宽）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（顺水皮原理、十字漏点、错缝冗余逻辑、毛细作用）是讲懂用语，标 🔵，不得作为采分点输出。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"四关链(顺序→方向→搭接量→细部)逐点 reveal"**，删除热熔温度/胶结料厚度等非主判分分镜（移🔵），把地下室卷材迁移补入，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **顺序"先细部后大面"**：屋面先点亮女儿墙/阴阳角/落水口等细部"加强补丁"（附加层绿盾），再从最低处铺大片卷材；若先铺大面后补细部，细部缝口红色渗水报警。
- **由低向高"上压下顺水皮"**：卷材从屋面最低标高向上一幅幅铺，上幅压住下幅、搭接缝开口朝下游；水滴沿坡面流过缝"上岸"被挡，绿勾；若由高向低（缝口朝上游）水滴倒灌缝内红叉。
- **搭接方向"顺流水罗盘"**：水流箭头(顺坡)与搭接缝方向并行=绿；卷材垂直铺贴时上下两层缝正交成红色"十字漏点"网格报警。
- **搭接量"错缝标尺"**：短边错缝标尺跳到≥500mm、长边错开≥1/3幅宽时上下层缝"品字"错位绿勾；缝对齐成"一字连续缝"时整条线变红。
- **地下室"迎水面盾牌"**：地下外墙迎水面(临土侧)贴卷材绿盾，背水面贴=红叉；外防内贴法施工顺序动画先立面后平面。
- **细部"女儿墙节点卡"**：泛水高度尺≥250mm、阴阳角抹成圆弧、附加层平立面≥250mm、收头金属压条钉压+鹰嘴滴水槽逐项打勾，对照2015案例错误做法红叉。

### Reveal 顺序(讲懂 → 判分眼)
1. **四关链骨架**：顺序→方向→搭接量→地下/细部 流程条亮起。(讲懂层骨架)
2. **顺序**：细部加强补丁先亮，再从最低处由低向高铺大面。(锚 `kc:1A413030_123_0234:0`、`{2016,第27题}`)
3. **方向**：顺流水罗盘绿；垂直铺贴十字漏点红。(锚 `kc:1A413030_123_0234:0`、`kc:1A422000_041_0065:0`、`{2016,第27题}`)
4. **搭接量**：短边≥500mm、长边≥1/3幅宽错缝标尺，品字错位绿/一字连续红。(锚 `kc:1A422000_029_0049:0`)
5. **地下室**：迎水面盾牌绿、背水面红；外防内贴先立面后平面。(锚 `{2018,第14题}`、`{2025,第13题}`)
6. **细部**：女儿墙泛水≥250mm/阴阳角圆弧/附加层≥250mm/收头钉压逐项打勾。(锚 `kc:1A413030_125_0237:0/:1`、`{2015,案例2}`)

### Aha 时刻(锚已按内容精确挂)
- 水滴沿坡面流向最低处，上幅卷材压住下幅、缝口朝下游，水"上岸"被挡 → 「由低向高铺、上压下，水永远从缝上游流过不倒灌」。锚 `kc:1A413030_123_0234:0`、`{2016,第27题}`
- 工人想把上下两层卷材垂直铺，立刻浮现红色"十字漏点"网格 → 「上下层不得垂直铺贴，否则双层接缝正交成穿透通道」。锚 `kc:1A422000_041_0065:0`、`{2016,第27题}`
- 错缝标尺从对齐"一字缝"(红)滑到错开≥500mm/≥1/3幅宽"品字"(绿) → 「错缝把连续薄弱带打散，下层接力挡水」。锚 `kc:1A422000_029_0049:0`
- 地下外墙把卷材从背水面挪到迎水面，盾牌由红转绿 → 「地下室卷材贴迎水面、外防内贴先立面后平面」。锚 `{2018,第14题}`、`{2025,第13题}`

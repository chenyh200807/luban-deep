## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「堵—疏—隔」三道防线因果链；汇编层把镜头 A 的散文链收成「三段因果链 + 每段挂 point_id」，**保留镜头 A 对"铝板熔点 660℃ vs 钢 1500℃"的机理解释为 🔵 讲解性表述（无规范原文逐字锚定，不充判分）**；镜头 A 把"100mm(楼板缝隙厚度)vs 200mm(空腔填塞高度)"的部位区分讲清，已采纳（见 §8 C2）。

**核心因果链(讲懂层骨架)：堵—疏—隔**

```
幕墙系统两大风险源
   ├─ 火灾"烟囱效应"：幕墙与主体间垂直空腔=烟囱，火焰高温烟气沿空腔上窜，立体燃烧使防火分区失效
   └─ 雷击"引雷"：高层金属框架=引雷体，缺通路则连接薄弱处电位差跳火
   ▼
第一道[堵]: 层间防火封堵 —— 楼板/隔墙缝隙不燃材料(岩棉/矿棉)封堵+水平防火烟带   {2015,案例2}  🟢真题侧
   │  岩棉/矿棉≥100mm(楼板缝隙) + 1.5mm镀锌钢板承托(不得铝板) + 防火密封胶
   ▼
第二道[隔]: 防火构造分隔 —— 上下层开口实体墙≥1.2m 或挑檐≥1.0m + 空腔填塞≥200mm + 玻璃单元不跨防火分区   kc:1A413030_148_0286:0  🟢判分眼
   ▼
第三道[疏]: 防雷连接 —— 金属框架连主体防雷 + 立柱≤10m柔性导线连通 + 预埋件焊接均压环   kc:1A413030_148_0287:0、{2020,第23题}  🟢判分眼
   ▼
效果 = 火被截成单楼层(堵)+距离分隔阻火焰垂直蔓延(隔)+雷电流连续泄放(疏) → 幕墙从风险点变保护壳
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **不燃材料+钢骨架(堵)**：岩棉/矿棉自身不燃且纤维阻滞烟气；承托板用钢不用铝——铝熔点约 660℃远低于钢约 1500℃，火灾中铝板熔化使岩棉垮塌、隔离带崩溃（机理解释，🔵，规范只写"不得用铝板"未写熔点）。
- **空腔填塞≥200mm vs 楼板缝隙≥100mm**：是**两个不同部位的尺寸**——窗槛墙空腔上下沿背衬材料填塞高度≥200mm（教材锚），楼板/隔墙缝隙封堵的岩棉/矿棉厚度≥100mm（真题2015案例2锚），不可混为一谈（见 §8 C2）。
- **立柱柔性导线(疏)**：铝合金立柱为应对热胀冷缩设伸缩缝，缝会切断导电路径；柔性导线在≤10m 内"跨过"缝隙保证电气连续，防此处跳火。
- **实体墙/挑檐(隔)**：实体墙高度不足 1.2m 时，下层窗口喷出火焰易卷吸至上层窗口；挑檐≥1.0m 改变热气流方向、阻火焰垂直蔓延。

> 三色提醒：因果链的**结论数字/材料**（1.2m/1.0m/200mm/100mm/1.5mm/10m、岩棉钢板不得铝板、焊接均压环）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（烟囱效应、铝熔点、跳火逻辑）是讲懂用语，标 🔵，不得作为采分点输出。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"堵→隔→疏 三道防线逐点 reveal"**，删除材料层（涂料/玻璃/板材）与成品保护（保护膜/清洗）的非判分眼分镜，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **烟囱效应 vs 层间封堵**：左屏火焰沿幕墙空腔垂直上窜（未封堵=烟囱）；右屏每层楼板缝隙塞岩棉+钢板承托，火被截成单层（封堵=斩断烟囱）。
- **钢板 vs 铝板对决**：1.5mm 镀锌钢板承托（火中挺立，✓）vs 铝板（660℃ 熔化垮塌，✗红叉），岩棉随铝板坠落。
- **防火尺寸标尺**：上下层开口间标尺亮起 1.2m 实体墙 / 1.0m 挑檐；空腔填塞 200mm；承托板 1.5mm——"1.5m"被红叉划掉换成"1.5mm"。
- **防雷电流跑道**：雷电流从金属框架→均压环（焊接连通）→主体防雷→入地；铝合金立柱伸缩缝处一根柔性导线"跨缝"接通（≤10m）；缺导线处跳火红闪。

### Reveal 顺序(讲懂 → 判分眼)
1. **三道防线骨架**：堵(封堵)→隔(防火构造)→疏(防雷) 流程条亮起。(讲懂层骨架)
2. **定性**：幕墙分类闪现（玻璃/石材/金属/人造板，背景🔵）。(锚 `kc:1A413030_145_0281:0`)
3. **堵·层间封堵**：楼板缝隙塞岩棉≥100mm+1.5mm 镀锌钢板承托+水平防火烟带。(锚 `{2015,案例2}`)
4. **钢板 vs 铝板**：铝板熔化垮塌被红叉，钢板挺立。(锚 `{2017,第12题}`、`{2015,案例2}`)
5. **隔·防火构造**：实体墙 1.2m/挑檐 1.0m 标尺；空腔填塞 200mm；玻璃单元不跨防火分区。(锚 `kc:1A413030_148_0286:0`)
6. **疏·防雷连接**：框架→均压环焊接→入地；立柱 10m 柔性导线跨缝；隐蔽验收章勾选。(锚 `kc:1A413030_148_0287:0`、`{2020,第23题}`)

### Aha 时刻(锚已按内容精确挂)
- 铝板承托在火中熔化、岩棉坠落 → 「防火层承托必须用 1.5mm 镀锌钢板，不能用铝板（铝会熔）」。锚 `{2017,第12题}`、`{2015,案例2}`
- "1.5m"被红叉换成"1.5mm" → 「承托板是 1.5mm 不是 1.5m，单位别混」。锚 `{2019,第29题}`、`kc:1A413030_148_0286:0`
- 200mm 标在空腔、100mm 标在楼板缝隙，两个不同部位 → 「200mm 是空腔填塞，100mm 是楼板缝隙封堵，部位不同别混」。锚 `kc:1A413030_148_0286:0`、`{2015,案例2}`
- 立柱伸缩缝处缺柔性导线跳火，补一根导线后电流跨缝接通 → 「立柱≤10m 一根柔性导线连通上下柱，缝隙处不连就跳火」。锚 `kc:1A413030_148_0287:0`

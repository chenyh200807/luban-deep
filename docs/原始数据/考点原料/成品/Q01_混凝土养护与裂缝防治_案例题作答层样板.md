# Q01 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`Q01_混凝土养护与裂缝防治.md`](./Q01_混凝土养护与裂缝防治.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**养护多久、温差控到几度、防水/大体积/冬期/后浇带各自的数值阈值是多少、裂缝怎么成因识别**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建混凝土养护/裂缝案例失分不是"不会"，是"会一点但写不成分"——措施只写一两条漏整维（养护方法/温控/材料）、判断纠错只指不妥不给正确数值、7d/14d 张冠李戴、25℃/20℃ 方向写反。作答层的杠杆 = 把「知道阈值」变成「按措施六维 + 三段式判断纠错写全采分点」。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 Q01 §5.1 R5**（已 signed 的 candidate pack，A/B/C/D/E 五簇）。本层「可写化四件套」从 R5 **逐字派生**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 Q01 §5.3 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E04/E05/E06/E07/E10/E12、M08，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_Q01_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2022·第15题}`、`{2015·第26题}`、`{2016·第30题}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **status**: `candidate_answer_layer_prototype`（候选作答层样板，量产批次；句式重点=**措施六维 + 判断纠错**，验证句式库在养护/裂缝场景泛化用）。
> **三色铁律继承自 Q01**：🟢 point_id 或真题{年份+题号}可 Read 核验（已核）｜🔵 工程通识（无单一 point_id 但学界共识，作答策略·句式）｜🔴 待真人/专家裁决（判分边界、给分档位、临界取舍、待回填 point_id）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写养护/裂缝答案漏分，多是某一维整维漏掉（最典型：措施题只写"加强养护"漏掉温控维与材料维）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 Q01 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位") | 防水混凝土施工、冬期入模控制（隐含施工方） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（浇筑→振捣→养护起始时机→连续性） | 连续浇筑→分层≤500mm→机械振捣→施工缝避位→养护≥14d（B 簇）；养护起始时机（M1） | 养护起始时机写反（"终凝后才养护"，普通混凝土错）；施工缝位置错 |
| **条件维** | 达什么阈值才合格/才做（养护时长、温差、水胶比、强度门槛） | 普硅≥7d/抗渗≥14d；里表≤25℃、降温≤2℃/d；冬期表面-大气≤20℃、温降≤3℃/d；拆模≥75%（V1–V7） | 7d/14d 张冠李戴；25℃/20℃ 方向写反；2℃/d 与 3℃/d 互换 |
| **记录/计算表达维** | 留什么书面 / **写算式链+数值结论**（拆模强度计算、温差校核） | 拆模强度=设计×75%（C30 → 22.5N/mm²，真题 2021·第9题）；裂缝控制三级（设计阈值） | 只写"达到强度"不写数值；只写结论不写"×75%"算式过程 |
| **后果维** | 不达标/达标后会怎样（裂缝产生、严禁、修补决策） | 失水过快→塑性/干缩裂缝；约束→拉应力>ftk→开裂；裂缝控制三级决策（A 簇） | 只会"会裂"，不知按"不允许裂缝/允许裂缝限宽"分档处置 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。Q01 因是数值阈值密集型考点，**条件维**是失分主战场，**措施题里 5 个维（程序/条件/记录/后果 + 隐含主体）都要扫**。

## 1. 采分点可写化表（从 Q01 §5.1 R5 派生 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚」**逐字来自 Q01 §5.1 R5**（A/B/C/D/E 五簇，已 signed candidate pack）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（≈ R8 误区"关键词缺失"的反面）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 Q01 §6 R8 误区 + §error_code 的 error_code）。
> - **版本状态**：`现行有效` / `旧说法仅背景` / `新规范优先·旧表述必须改写`——**写过期表述照样丢分**，这一件不可省。
> 再标**五维**命中哪维。**采分点本身不增不改**。

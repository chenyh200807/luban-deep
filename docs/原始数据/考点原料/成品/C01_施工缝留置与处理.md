## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「因果链 + 每段挂 point_id」，**删除镜头 A 里无锚的力学/化学外推**（微膨胀 0.02%-0.03%、钙矾石膨胀源、跳仓法 5-7d 间隔、收缩 80% 等是合理工程解释但**无 point_id 也无真题证据**，保留为 🔵 讲解性表述，不充判分）。

**核心因果链(讲懂层骨架)：**

```
混凝土脆性(抗压不抗拉) + 浇筑不能无限连续           🔵原理(无单一point_id)
   │  必须间歇 / 收缩温变 → 若无序则成通缝、渗漏
   ▼
"巧断"(主动留缝层)：
   ├ 何时留：连续浇筑;间歇尽量短,前层初凝前浇完次层,否则留缝  cc:1A413030_103_0196:2/:3  🟢

   ▼
"重连"(界面处理层)：
   ├ 强度达 1.2N/mm² 再处理 → 已浇层硬到能凿  ca:1A413030_103_0196  🟢
   ├ 凿毛 + 清理松动浮浆 → 暴露坚实骨料,增大机械咬合  ca + kc:1A434000_074_0116:0  🟢
   ├ 铺 30mm 砂浆 → 新旧界面过渡,补足砂浆层  ca:1A413030_103_0196  🟢
   ▼
后浇带(超长结构的"延迟重连")：
   ├ 微膨胀混凝土 + 强度提高一级 → 膨胀建预压,抵消收缩拉应力  kc:1A413030_103_0196:1  🟢
   ├ 封闭≥28d → 两侧主体先完成大部分初期收缩再填  {2018,案例三问题3}  🟢
   ├ 养护≥14d → 膨胀反应需水,养护不足补偿失效  kc:1A413030_103_0196:1  🟢

   ▼
效果 = 断得有序(位置对) + 连得牢固(处理到位) + 后浇带补偿收缩(微膨胀+28d+14d)
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **留在受剪力较小处**：施工缝是结构薄弱面，留在剪力小的地方，新旧界面承受的剪力最小，整体性损失最小。
- **1.2N/mm² 后再凿毛**：已浇混凝土强度太低会被凿松，太晚则浪费工期；1.2N/mm² 是"凿得动又不破坏骨料"的工艺门槛。
- **后浇带微膨胀 + 提高一级**：让后浇混凝土膨胀建立预压应力，化"被动受拉开裂"为"主动承压"；提高强度等级给膨胀力提供内聚支撑。
- **封闭≥28d、养护≥14d**：给两侧主体足够时间完成初期收缩后再填，并保证膨胀反应所需的湿养护时间。

> 三色提醒：因果链的**结论(0~300mm/次梁1/3/1.2N/mm²/30mm砂浆/微膨胀/提高一级/≥14d/≥28d)**全部 🟢 锚定；链条里的**微观机理解释**(膨胀率 0.02-0.03%、钙矾石、收缩 80%、跳仓 5-7d)是讲懂用语，标 🔵，不得作为采分点输出（镜头 A 草稿里这些数已降级，见 §8.2 C2）。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(Opus) 主写，汇编层逐场景重核真题锚。三个真题锚（`{2015,第26题}`/`{2018,案例三问题3}`/`{2021,第8题}`）均经 `verify_exam_anchors.py` 确定性命中。

**不变量(一句话)：**
> 凡施工现场出现施工缝/后浇带，都必须用「**留不留(连续浇筑/初凝前) → 留哪里(受剪力较小 + 各构件 1/3 位置) → 怎么处理(达强度→凿毛→清理→砂浆→养护) → 后浇带怎么补(微膨胀+提高一级+≥28d封闭+≥14d养护)**」四步把"巧断→重连"做有序。出题人永远在考「**该不该留缝 / 留在哪 / 旧缝怎么接 / 后浇带怎么处理**」，不考混凝土配合比设计本身。

换言之：判分核心 = **留设时机对不对 + 留设位置对不对 + 接槎处理工序全不全 + 后浇带技术措施达不达标**，四者任一缺/错即「不妥」。

**≥5 场景印证(每条带已核真锚)：**

1. **施工缝留置位置(MCQ 高频)** —— 「施工缝宜留在受剪力较大部位」是错的；正确=柱在梁板顶面 / 次梁跨中 1/3 / 墙纵横交接处 / 双向板按设计确定。
   🟢 真题锚 `{2021, 第8题}`(直读 correct_answer=ACDE，解析：柱宜留基础/楼板/梁顶面、单向板留平行短边任意位置、有主次梁楼板留次梁跨中 1/3、墙留门洞口过梁跨中、双向板按设计)；教材锚 `kc:1A413030_103_0196:0`。

2. **防水混凝土施工缝(MCQ)** —— 「连续浇筑少留施工缝」对、「留在剪力较大处」错、防水混凝土养护≥14d。
   🟢 真题锚 `{2015, 第26题}`(直读 correct_answer=ABE，解析：防水混凝土应连续浇筑宜少留施工缝；留缝时不应留在剪力最大处或底板与侧墙交接处；养护不少于 14d)；教材锚 `ca:1A413030_103_0196`、`kc:1A434000_074_0116:0`。

3. **后浇带技术措施(案例·高分密集区)** —— 后浇带模板"独立支设=不妥(应同步支撑)" / 钢丝网应保留 / 底板后浇带≥28d 封闭；技术措施=整理钢筋→冲洗→微膨胀混凝土→强度提高一级→≥14d 养护。
   🟢 真题锚 `{2018, 案例三问题3}`(直读 correct_answer：模板不应独立支设、钢丝网应保留、后浇带≥28d 封闭；后浇带措施=整理钢筋/冲洗松动/微膨胀混凝土/强度提高一级/≥14d 湿润养护)；教材锚 `kc:1A413030_103_0196:1`、`kc:1A413030_098_0184:0`。

4. **施工缝处理工序(案例/简答)** —— 达强度 1.2N/mm² → 凿毛 → 清理松动浮浆 → 铺 30mm 砂浆 → 浇筑振捣养护。

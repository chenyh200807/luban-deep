## 2. 原理因果层（来源：Lens A 聚拢原理 · DeepSeek）

### 链条总览

```
成因[进度滞后] → 机理[关键线路延迟] → 优化选择[三原则] → 执行[压缩关键工作] → 验证[重算关键线路+总工期] → 费用[谁下指令谁承担]
```

### 第1环 · 成因：进度滞后的来源 🔵通识
触发条件来自背景资料：设计变更（2015案例1 C工作超2月 🟢）、甲供材料/设备延迟进场（2018甲供电缆 🟢、2025材料复验不合格退场 🟢）、自身机械故障（2024事件② 🟢）、不可抗力。
> 易错：只看"延误几天"，不判断该工作是否在关键线路上 → 坍缩到 E04。

### 第2环 · 机理：关键线路是总开关 🟢
**锚点** `kc:1A433000_056_0085:1`
```
总时差最小的工作 = 关键工作
全部关键工作连成的最长路径 = 关键线路（其长度 = 计算工期 = 总工期）
关键线路上任意延误 → 直接顺延总工期
非关键工作延误 ≤ 总时差 → 被总时差"安全气囊"吸收，不动总工期
非关键工作延误 > 总时差 → 仅超出部分传递到总工期
```
真题印证：2015案例1 C总时差1月、延误2月 → 只影响总工期1月 🟢。赶工只压关键工作，压非关键=白压。

### 第3环 · 优化决策：选谁压（三原则）🟢
**锚点** `kc:1A433000_056_0085:3` + `m35:Q17-1A433000:P4`

| 原则 | 机理 | 教材语言 |
|---|---|---|
| 费用最低 | 资源约束下压缩成本最低者，经济最优 | "增加资源费用最少" |
| 不影响后续 | 压缩不产生新逻辑/资源冲突 | "不影响后续工作" |
| 质量安全可控 | 不为工期牺牲质量安全底线 | "对质量安全影响小" |

📌 简答必背给分词：**"压缩成本低 + 不影响后续工作"**（`m35:Q17-1A433000:P4`：其一即给分，两项满分）。

### 第4环 · 执行与费用承担 🟢
**锚点** `kc:1A432000_047_0067:1`：发包人要求提前竣工→赶工费由发包人承担；承包人自行提前→需发包人同意、费用自担。佐证 `kc:1A432002_036_0047:0`（赶工属发包人计价风险）。

### 第5环 · 效果闭环：重算 🔵通识
压缩后必须：①重算关键线路（**关键线路可能转移**）②重算总工期 ③继续监测（`kc:1A433000_061_0091:0`）。
> 常见失误：压缩后忘记重算 → 关键线路已转移未发现（坍缩到 M07/Lens 标的"重大逻辑遗漏"，是否注册见 §8 C5）。

## 3. R2 不变量（来源：Lens B 出题人 · Opus）

> **不变量（出题人不变意图）**：
> **"工期/费用能不能动、动多少、谁掏钱"这三问，永远先由『工作在不在关键线路 / 延误是否吃光总时差』这唯一判据拍板——压缩只压关键线路、索赔只认吃光时差且责任≠承包人、赶工费用只花在『费率最低且可压时间足够、不影响后续工作』的关键工作上。**
> 一句话：**关键线路 + 时差是这一类题所有计算与判断的总开关**；任何"多算/少算/算错"都坍缩到"有没有先认准关键线路与时差"。

## 4. examiner_intent + R3 陷阱 + R4 变量规则（来源：Lens B 出题人 · Opus）

### 4.1 examiner_intent（出题人意图）

**核心意图**：考的不是"会不会画网络图"，而是**"会不会用关键线路+时差这唯一判据，把工期能不能动、动多少、谁掏钱算清并说出理由"**。
- **为什么这么出**：执业中最高频现场争议=工期延误谁负责、赶工钱谁出、能否索赔。出题人用一张网络图当载体，强制考生**先定关键线路与时差，再下任何结论**。
- **判分锚点（出题人真实给分落点，均来自真题答案）**：
  - 关键线路写错/漏写一条平行线路 → 后续全错：`{2015,案例1}` 明示两条（A→B→F→H→I 与 A→D→G→H→I）🟢。
  - 索赔结论必须配理由（成立/不成立 + 是否在关键线路/是否超总时差）：`{2018,案例分析(二)问题1-4}`、`{2024,案例题(二)}`，只写结论不写理由不得满分 🟢。
  - 赶工选序必须给"费率低/可压时间/不影响后续"依据：`{2017,案例一}` 显式要求 🟢。
  - "优化目标还有哪些"必答**资源优化 + 费用优化**：`{2018,案例分析(二)}`、`kc:1A433000_056_0085:2` 🟢。

### 5.3 R7 评分边界（🔴 全部待真人/专家裁决，不作最终判分规则）

**🔴 满分候选**：正确识别关键线路+总工期；明写滞后天数+需压缩天数；压缩对象全来自关键线路（或说明关键线路变化并复核）；按费用/可压时间/质量安全/备用资源定顺序；写成"先压…天再压…天"非泛泛"增加资源加班"；理由含"费用低/成本低"与"不影响后续"之一（两项更稳）；费用责任/索赔题能区分发包人要求/承包人自行/关键线路延误/非关键总时差。建议错因码：E02、E03、E09、E10。

**🔴 压线候选**：关键线路/总工期轻微表达瑕疵但后续压缩对象与总天数基本对；选中关键线路主要可压工作但未完整说排序理由；算出需压天数但费用计算或压缩顺序缺一步；只写"压费用最低工作"未明"不影响后续"但对象结果正确；索赔题能判是否影响总工期但费用承担表述不完整。建议错因码：E02、E03、E12。

**🔴 0分 near-miss 候选**：只按单位赶工费最低选不判是否在关键线路；压非关键且未超总时差却称能缩短总工期；没算关键线路与总工期直接给措施；把资源/费用/工期优化混为一谈未回应工期目标；只写"增加人员/机械/夜间施工"无工作名+压缩天数+费用依据；索赔题把所有延误都判可索赔或把所有非关键延误都判不可索赔（未比时差）；**编造题外真题年份题号/冒充真题锚**；**使用未注册错因码或自造"N02-01""T01"等**。建议错因码：E05、E07、E08、E09、E10。

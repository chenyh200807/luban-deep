## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写因果链；汇编层把散文链收成「三段因果链 + 每段挂 point_id」，无锚的机理外推（风险分配哲学）保留为 🔵 讲解性表述，不充判分。

**核心因果链（讲懂层骨架）：**

```
成因：工程实体（量）与合同价款（钱）之间需要一座可计量、可调价、可追责的桥
   │  发包人掌握工程意图（图纸/规范），承包人掌握施工方法与市场价
   │  无统一基准，则报价比不出高低、变更算不清账、出错找不到人
   ▼
机理①：用「工程量清单」把工程实体数字化为统一计量基准   kc:1A432002_037_0048:0/1  🟢
   │  由招标人/造价咨询人编制、作招标文件组成部分 → 所有投标人在同一份量上竞价
   ▼
机理②：用「综合单价」当价格容器，把人材机管利风险全封进一个价   kc:1A432002_035_0046:0  🟢
   │  分部分项宜单价计价（量准、可逐项计量）；措施项目宜总价计价（依赖方案、量难锁）
   ▼
机理③：按「谁掌握信息谁担风险」分配责任   kc:1A432002_036_0047:0、kc:1A432002_037_0048:1  🟢
   ├ 发包人提供清单 → 清单缺陷/数据错误/变更/赶工归发包人（单价合同缺陷发包人负责）
   └ 承包人定方案/报总价 → 措施清单准确性/总价合同缺陷/自身方案/效率归承包人（总价合同缺陷承包人负责）
   ▼
效果：用「分部分项费+措施费+其他费+规费+增值税」五项逐项汇总   kc:1A435000_040_0054:2  🟢
   = 报价可比、变更可算（套已标价清单综合单价）、出错可追、总价可校（五项合计=投标总价）
```

**为什么措施有效（讲解性，🔵 不充判分）：**
- **综合单价是「容器」不是「材料费」**：把市场风险（风险费）、管理效率（管理费）、盈利预期（利润）封装进一个价。承包人靠竞争填价，发包人靠招标选最优 —— 把「价」的博弈一次性锁定。
- **分部分项单价计价 / 措施总价计价 分而治之**：分部分项量准且对应质量检验批，可逐项计量支付，故用单价；措施费与施工方案强相关、量难精确锁定，故用总价包干，避免量变即扯皮。
- **五项分离（分部分项 / 措施 / 其他 / 规费 / 税金）**：防止「措施费打包进实体单价」导致变更签证困难；分离后变更只动相关项，互不污染。

> 三色提醒：因果链的**计价方式、综合单价构成、缺陷责任、五项汇总结构**全部 🟢 锚定；链条里的**风险分配哲学 / 容器隐喻**是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(Opus) 主写；汇编层精简为一句 + 保留 4 场景印证。**本考点真题命中充足（案例 34 条），场景印证锚为教材 point_id + 经确定性核验的真题年份案例（🟢）**，已逐场景核真。

**不变量（一句话）：**
> 凡问「这份工程量清单 / 这笔造价 / 这个责任，对不对、算多少、归谁」，都必须走「**先定计价方式（分部分项单价 / 措施总价）→ 用综合单价（不含税全费用）套量 → 按五大组成（分部分项+措施+其他+规费+税金）逐项汇总 → 按合同类型分清单缺陷/风险责任**」这条封闭链。出题人考的是**计价规则记忆 × 综合单价代入计算 × 五项汇总 × 责任归属**，不考造价制度的宏观叙述。

换言之：判分核心 = **计价方式不混（措施≠单价）+ 综合单价构成不漏（含风险费、不含增值税）+ 五项汇总不缺项不重复 + 缺陷/风险责任按合同类型归对**。四者缺一即失分。

**≥4 场景印证（每条带已核真锚）：**

1. **母题：给量×综合单价 + 各项费率，逐项汇总求总造价** —— 管理费=人材机×费率、利润=(人材机+管理费)×费率、分部分项费、措施费、其他费、增值税、总造价。
   🟢 教材母题锚 `ca:1A435000_039_0053`、`kc:1A435000_039_0053:0`（EP：300×8%→24 万管理费 / (300+24)×10%→32.40 万利润 / 分部分项费 356.40 万 / 措施 15 万 / 其他 3.50 万 / (356.40+15+3.50)×9%→33.74 万增值税 / **总造价 408.64 万元**，逐步可复算无误）。🟢 真题印证（确定性核验）：**2025 案例（四）** 直读官方答案含「分部分项费 2200×12000/10000=2640 万 / 措施费 ×10%=264 万 / 其他项目费 70+26=96 万 / 规费 (2640+264+96+60)×2%=60 万 / 增值税」五大组成逐项汇总。

2. **综合单价调整结算** —— 清单综合单价含暂估价材料，结算时按确认单价调整综合单价再算结算价款。
   🟢 真题印证（确定性核验）：**2020 案例（四）** 直读官方答案：钢筋结算综合单价 = 4433+(3500−2500)×(1+2%)=**5453 元/t**；结算价款 = 5453×250×(1+11.5%)=1520023.75 元（综合单价 + 损耗率 + 税率，清单计价本体）。

3. **清单制度辨析（计价方式 / 强制性内容 / 缺陷责任）** —— 分部分项单价 / 措施总价；清单强制性内容；总价合同 vs 单价合同缺陷责任。
   🟢 教材锚 `kc:1A432002_035_0046:0`、`kc:1A432002_037_0048:1`；🟢 真题印证：**2024 案例（四）** 官方答案列工程量清单强制性内容（工程量计算规则 / 编制方法 / 计价方式 / 风险处理 / 费用竞争）。

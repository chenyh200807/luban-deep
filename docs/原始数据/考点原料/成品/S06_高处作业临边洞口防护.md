## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人) 主写,汇编层精简为一句 + 保留 6 场景印证,逐场景重核真题锚(改正了镜头 B 的 2 处误锚,见 §8 冲突 C2/C3)。

**不变量(一句话)：**
> 凡「人或物可能从临边/洞口坠落，或在 2m 及以上高处作业」，都必须先用「**识别坠落路径 → 匹配防护等级(尺寸/高度) → 校核关键参数(达标线)**」三步把坠落路径堵死。出题人永远在考「**该不该防 / 用什么防 / 防到什么参数**」，不考工艺本身。

换言之：判分核心 = **坠落风险是否被识别 + 防护方式是否匹配尺寸/高度 + 关键参数是否达标**。三者缺一即「不妥」。

### examiner_intent (出题人意图,按真题命中频次排序)

出题人在这个考点上**几乎不考「是什么」,只考「对不对 / 还差什么 / 参数够不够」**。三层意图：

- **意图① 抓「该防未防 / 防护项不全」(找漏·补全) —— 最高频。**

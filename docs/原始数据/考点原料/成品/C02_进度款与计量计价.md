## 2 · 原理因果层（把散点压成可讲的因果链，每段标三色）

### 🔗 因果链 ①：为何预付款基数要先「扣暂列金额」？

**📌 成因** —— 多年真题反复在基数上设钩子：2015案例4 (31922.13−1000)、2019第1题 (5800−580)、2021案例四 (12500−1000)、2017案例四 (18060−300) 都先扣暂列/暂定金额再乘比例。直接用合同总价乘比例＝最常见基数错误。

**🔍 机理**
- 🟢 暂列金额是发包人预留的备用金（用于变更/索赔/签证），**不一定发生**。
- 🟢 预付款是承包人启动工程的启动资金，应基于**确定发生的工程实体费用**。
- 🟢 把暂列金纳入基数＝发包人替"不确定事件"提前垫资，违反预付款"实体工程量导向"。

**📏 为何有效** —— 扣暂列金后预付款与"实际需完成的实体价值"挂钩，资金配置真实。

**🧠 易错 → 拟挂错因码 `E08`(背景提取失败) / `E09`(计算错误)**：未识别题干"暂列/暂定金额"字样、或识别了但未扣。预防：强制三步——①签约合同价 ②扣暂列金额/暂估价非实体部分 ③净额×预付比例。

> 来源：因果取 lens A①；真题多例代入由汇编从 `_C02_exam_evidence.json` 实测补全。

### 🔗 因果链 ②：起扣点——「未完工程主要材料价值＝预付款」时开始扣回

**📌 成因** —— 预付款必须在工程后期"原路扣回"，否则发包人多付。起扣点就是扣回的触发时点。

**🔍 机理（已实测三例）**
- 🟢 公式（教材 `kc:1A435000_043_0058:1`）：**起扣点 T ＝ 合同价 − 预付款 ÷ 主要材料所占比重**。
- 🟢 例1（660万例题）：660 − 132/60% = **440 万**。
- 🟢 例2（2019第1题）：(5800−580) − 1044/60% = **3480 万**；该题 5 月累计 3830＞3480，故 5 月起在扣质保金外**还要扣回预付款**。
- 🟢 例3（2015案例4）：31922.13 − 4638.32/65% = **24786.25 万**。

**📏 为何有效** —— 起扣点把"何时开始扣回"量化成一个确定的累计产值门槛，避免扣早扣晚。

**🧠 易错 → 拟挂 `E09`/`E06`(程序顺序)**：公式结构写反（如"合同价×材料占比−预付款"或"预付款÷合同价"）。

> 来源：lens C 骨架A 给出公式；三例代入由汇编从真题 Read 实测核对（其中 660 例为教材，5800/31922 为真题）。

### 🔗 因果链 ③：从挣值到进度款——「度量→判断→支付」闭环

**📌 成因** —— 挣值法给"判断数据"，进度款支付要"执行动作"，两者需衔接。

**🔍 机理**
- 🟢 每月申报进度款＝实际完成量×合同单价（本质是 BCWP 的变体）。
- 🟢 监理/发包人审核对比计划完成（BCWS 变体）。
- 🟢 若 SV<0（进度滞后），发包人可降低当期支付比例、要赶工方案、触发违约条款。
- 🟢 当期应付公式（`kc:1A435000_042_0056:0`）就是这一逻辑的数学表达：
  > 当期应付 ＝ [累计已完×支付比例 − 累计预付扣回 − 前期已付] − 发包人累计扣款

**📏 为何有效** —— 把分析结果直接挂到支付动作，形成闭环；未约定支付比例时 80%（`kc:1A435000_042_0056:1`）作底线防过度压款。

> 校验注记：挣值法演示数据 BCWP=6370/ACWP=6240/BCWS=5340 经 Read 核实为**教材例题 `ca:1A435020_095_0156`**（CV=+130 节支、SV=+1030 提前、CPI≈1.02、SPI≈1.19），lens A 误标"2024真题改编"已剔除（见缺口表 G-1）。

### 🔗 因果链 ④：综合单价口径——量×价的两个税务陷阱（2020案例四实测）

**📌 成因** —— 价的口径是 examiner 最爱埋的钩子：综合单价不含税、税在最末整体计提；材料暂估价要用确认价重算。

**🔍 机理（2020案例四已实测）**
- 🟢 综合单价重算（钢筋）：**调整后单价＝原综合单价 +（确认价−暂估价）×(1+损耗率)**＝4433+(3500−2500)×(1+2%)=**5453 元/t**。
- 🟢 结算价款＝5453×250×(1+11.5%)=**1520023.75 元**（税在最末整体乘）。
- 🟢 计量几何陷阱（泄洪沟拆除）：净拆除量＝外围 25×4×4 − 净 25×(4−0.4×2)×(4−0.4)，再×(单价差)×(1+税)。
- 🟢 关键：综合单价内**不重复计税**；只在最末乘 (1+税率)。

**📏 为何有效** —— 把"量"（净尺寸/损耗）与"价"（税前/税后）的口径钉死，防双重计税与毛净混用。

> 来源：口径框架取 lens B 意图1 + lens C 采分点1；2020 数值由汇编从真题 Read 实测，逐位核对答案。

### 🔗 因果链 ⑤：调值公式——通胀风险双向分摊

**📌 成因** —— 大型长周期工程（如 14250 万级 `ca:1A435000_045_0064`）签约价到竣工可能大幅变化，需自动修正机制。

**🔍 机理**
- 🟢 公式：**P＝P₀(a₀+a₁A/A₀+a₂B/B₀+a₃C/C₀+a₄D/D₀)**，固定部分 a₀ + 可调部分 a₁~a₄。
- 🟢 约束（`kc:1A435000_045_0064:1`）：a₀通常 0.15~0.35；只调影响大的少数项；幅度一般≥±5%才触发；考核地点在工程所在地。

**📏 为何有效** —— 既护承包人免材料暴涨、又防发包人因价跌损失（双向分摊）；a₀保留承包人管理风险；5%阈值过滤小波动减争议。

> 来源：lens A④；a₀常数与 14250 例题由汇编从 `kc:1A435000_045_0064:1`/`ca:1A435000_045_0064` Read 实测。

### 🧩 教学逻辑线（五句记住 C02）

```
综合单价(税前全费用) → 量×价
    ↓
预付款(扣暂列金×比例) → 起扣点(合同价−预付/材料占比)
    ↓
逐月进度款 = [累计完成×比例 − 累计扣回 − 已付] − 扣款；未约定兜底 80%
    ↓
挣值法 CV/SV/CPI/SPI 判健康度 → 调支付比例
    ↓
竣工结算：调值公式/实际价格法修正 → 质保金 ≤3% 预留
```

1. 🟢 综合单价是税前全费用，税在最末整体计提，别双重计税。
2. 🟢 预付款先扣暂列金再乘比例；起扣点＝合同价−预付款÷材料占比。
3. 🟢 进度款＝累计完成×比例−累计扣回−前期已付−扣款；未约定不低于 80%。
4. 🟢 BCWP 挣了多少、BCWS 该挣多少、ACWP 花了多少；CV/SV 看正负、CPI/SPI 看大于小于 1。
5. 🟢 质保金别超结算总价 3%；调值公式 a₀ 在 0.15~0.35。

## 3 · R2 不变量

🟢 **不变量本体（一句话）**：进度款与计量计价的内核是一条单向资金链——`报价单价 → 已完工程量 → 当期应得 → 扣预付/扣质保 → 当期实付`。考生必须证明在「哪一笔钱、按什么口径、在哪个时点、扣多少」四维同时不出错；任何一处用错口径（毛/净、含税/不含税、累计/当期、约定/法定下限），整条链算错。

两个硬地基（出题人反复踩的支点）：
- **几何地基（计量）**：钱＝量×价，量错则价对也无意义（净尺寸 vs 外围尺寸、损耗率计入与否）。
- **法定地基（计价）**：综合单价是税前全费用、安全文明费/规费/税金不得作竞争性费用、未约定按 80%、质保金≤3%、履约金≤10%——规范钉死、不容谈判。

## 4 · 出题人意图 + R3 场景 + R4 变量规则

### examiner_intent（出题人意图）

出题人不是考"会不会按公式算"，而是用一道题（多见 20–30 分整题）同时筛掉三种人。

**意图 1：分离「会算术」与「会用对口径」** —— 计算骨架几乎都会，真钩子在口径：
- 毛/净：预付款基数要不要先扣暂列金额（2015/2019/2021 都扣）；结算量外围 vs 净尺寸（2020 泄洪沟）。
- 含税/不含税：综合单价不含增值税，最后整体乘 (1+税率)；单价里含税＝双重计税（2020）。
- 累计/当期：进度款"累计已完×比例 − 前期已付"才是当期，写成当期完成×比例即错（2019）。
- 法定下限/约定：未约定不是 100%，是不宜低于 80%（`kc:1A435000_042_0056:1`）。
> 潜台词：**算对数字不给分，用对口径才给分。**

**意图 2：用「成立/不成立 + 理由」逼出责任归属**（2018第4题、2021案例四）——必问"成不成立 + 为什么"，要考生把事件归因到合同/法定责任方：
- 不可抗力→人机损失自担、清理修复可赔（`kc:1A432000_047_0067:0`，2015案例一解析实测）。
- 配合甲方自行发包的脚手架→属总承包服务费、在建安费内、不另赔（2018第4题，实测答案"不成立"）。
- 垫资利息→有约定按约定、无约定不计（2018第4题，实测"不成立"）。
> 潜台词：**钱该不该给，先看责任在谁、费用在不在已计价范围内。**

**意图 3：用「不妥之处」考规范红线硬记忆**（2022第(四)题实测全中）：
- 质保金 ≤ 结算总价 **3%**（2022 把它设成 5%制造不妥）。
- 履约保证金 ≤ 中标价 **10%**（2022 设成 15%制造不妥）。
- 安全文明施工费、规费、税金**不得作为竞争性费用**（`m35:Q19-1A432000:P4`，2018第3题实测）。
- 工程量清单**五要素**：项目编码/名称/特征/计量单位/工程量。
- 建设单位**不得指定**供应商/品牌、不得指定分包人（2022 指定钢厂+指定分包均判不妥）。
> 潜台词：**这些是规范术语原文，写近义词不给分、写不出数字就丢分。**

> 来源：取 lens B；**修正 lens B 把"指定供应商/分包"锚到 2018第3题的误挂**——经 Read，指定供应商/指定分包的真题锚是 **2022第(四)题**（2018第3题是分层累加+强制性规定列举），见 G-3。

### R4 变量规则（封闭集合，禁开放外推）

**维度1 付款时点（封闭4）**：`{预付款(开工前), 进度款(逐月/逐周期), 竣工结算款, 质保金返还(缺陷责任期满)}`。跨时点题（2019）扣回逻辑只在"累计达起扣点之后"触发。

**维度2 扣减项（封闭4，可叠加但口径互斥）**：`{预付款扣回, 质保金, 发包人其他扣款, 不可抗力自担损失}`。质保金按当期完成额计提、预付款按累计达起扣点后的超额计提，口径不同不得混基数。

**维度3 单价口径（封闭3）**：`{综合单价(清单计价,税前全费用), 定额单价, 信息价/实际价格法据实调整}`。综合单价不含增值税、税末计提；材料暂估价重算：调整后单价＝原综合单价+(确认价−暂估价)×(1+损耗率)（2020 实测口径）。禁单价内重复计税。

**维度4 费率叠加顺序（封闭5层，顺序不可换）**：`分部分项工程费 → +措施项目费 → +其他项目费 → +规费(或×(1+规费率)) → ×(1+税率)`。规费/税金永远在外层（`kc:1A435000_038_0050:1`）；安全文明费内含措施费但按规定计、不得竞争性下浮；措施费"总价(基数×费率)"或"单价(Σ量×综合单价)"二选一。

**维度5 法定阈值（封闭，钉死常数）**：`{质保金≤结算总价3%, 履约保证金≤中标价10%, 安全生产费开工后一个月内付≥50%, 未约定支付比例不宜低于80%, 工程量清单五要素}`。换皮时题面数字可变（如保修金设 5%制造"不妥"），但判分锚点不变。

**维度6 扰动事件类型（封闭3，决定索赔成立性）**：`{发包人责任(图纸延误/甲供材不合格/甲方指令)→可赔工期+费用[+利润], 不可抗力→工期可顺延/人机损失自担/清理可赔, 承包人自身原因(自有设备故障)→不可赔}`。成立性只看事件归类，与金额无关；金额另起"增量→管理费→利润"逐层提链。

> 封闭性声明：6 维度取值集合来自 C02 命中真题（2015–2025）与教材采分点的归纳，**不向集合外开放**。落不进这 6 维度的"新题"要么属其他考点、要么是编造，不计入 C02 合法变体。

> 校验注记：维度4 把 lens A/D 的"安全生产费 28 天内预付≥50%"与"开工后一个月内付≥50%"做了消解——`kc:1A436000_100_0164:0` 教材原文为**「工程开工日一个月内…至少 50%」**，故采"一个月内"为准（lens B 写 28 天系与安措费混淆，见 G-5）。

### R6 答案骨架

**骨架A · 预付款与起扣点** 🟢 `kc:1A435000_043_0058:0/:1` + 2015案例4
1. 确定基数：合同价扣除暂列金额后。
2. 预付款＝基数×预付比例。
3. 起扣点＝合同价 − 预付款 ÷ 主要材料所占比重。
4. 说明含义：累计完成达起扣点后，从进度款中扣回预付款。

**骨架B · 月度进度款** 🟢 `kc:1A435000_043_0058:2`、`kc:1A435000_042_0056:0`
1. 列每月完成产值与累计完成产值。
2. 判累计是否达起扣点（未达→按约定比例/当月值；达到→算当期应扣回预付款）。
3. 当期应付＝[累计已完×支付比例−累计扣回−前期已付]−发包人扣款。
4. 写明当月应付与累计已付。
（2019第1题实测：5月累计 3830＞起扣点 3480，5月应付＝1400−1400×3%−(3830−3480)×60%−…）

**骨架C · 清单计价与责任判断** 🟢 `kc:1A432002_035_0046:0`、`kc:1A432002_036_0047:0`、`kc:1A432002_037_0048:1`
1. 判合同类型（单价/总价/成本加酬金）。
2. 判问题来源（清单缺陷/资料错误/变更/赶工/措施/方案变化）。
3. 定责任主体（发包人原因或单价合同清单缺陷→发包人；承包人措施/总价合同缺陷/自身方案→承包人）。
4. 再决定是否调价/重新计量/可索赔。

**骨架D · 未约定支付比例** 🟢 `kc:1A435000_042_0056:1`
1. 说明前提：合同未约定工程总值支付比例。
2. 写标准：不宜低于累计完成工程总值 80%。
3. 若需计算：按累计完成、支付比例、已付、预付扣回、其他扣款综合算。

## 7 · 动画分镜（L7）

> 取 lens D 隐喻/reveal/aha/旁白，汇编对齐到本 pack 的资金链主线。

### 视觉隐喻

| 概念 | 隐喻 |
|---|---|
| 预付款扣回 | 满水桶随进度推进逐渐被舀回（到起扣点才开始舀） |
| 综合单价口径 | 一个"税前价签"，结账时才整体盖上"+税"印章（不在单价里盖） |
| 计量净尺寸 | 外围方框里挖去壁厚得到净空心框（泄洪沟动画） |
| 材料价格调整 | 弹簧秤指针随市场波动上下，调值公式把指针锁回区间 |
| 索赔时限 | 沙漏（未约定 28 天流完即失权） |
| 进度款支付比例 | 进度条 + 80%底线水位标 |
| 质保金 | 保险箱只锁 ≤3% 的金币 |

### Reveal 顺序

1. 价签（综合单价税前）→ 2. 量×价（净尺寸挖空）→ 3. 满水桶预付款 → 4. 进度条到起扣点水位→开始舀回 → 5. 进度条 80%底线亮起 → 6. 弹簧秤+调值公式锁区间 → 7. 保险箱锁 3% 金币。

### Aha 时刻

- **税印章**：当"+税"印章只在最末整体盖下时，学生看懂"单价里再盖一次＝双重计税"。
- **起扣点水位**：当进度条爬到起扣点那条线、水桶才开始被舀回——"原来不是工程结束才扣回"。
- **80%底线**：当未约定支付比例、进度条自动停在 80%水位——"未约定不是 100%，是兜底 80%"。
- **3% 锁**：保险箱只能锁 3% 金币，多的弹出——"质保金封顶且基数是结算总价"。

### 旁白锚点（与采分点同源，防漂移）

- 综合单价：「综合单价是不含增值税的税前全费用价，税在最末整体计提。」（采分点1）
- 起扣点：「累计完成达起扣点后，才开始从进度款中扣回预付款。」（采分点4/5）
- 进度款：「当期应付＝累计已完×支付比例−累计扣回−前期已付−扣款。」（采分点5）
- 80%：「合同未约定支付比例时，不宜低于累计完成工程总值的 80%。」（采分点6）
- 质保金：「累计预留质保金不得超过工程结算总价的 3%。」（采分点8）

> 衔接说明：lens D 原"措施项目费可伸缩尺子""合同条款颜色标签"两个隐喻与本 pack 资金链主线弱相关，降为备选未进 reveal 主序（保留在误区表，不进动画 7 步）。

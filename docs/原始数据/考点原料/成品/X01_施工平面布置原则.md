## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写；汇编层把镜头 A 的散文链收成「一条主因果链 + 每段挂 point_id」，删除镜头 A 里无锚的「五牌一图入口内侧心理学」「电杆 7.5m 安全间距」等外推（无 point_id 且证据包内无对应，保留为 🔵 讲解性表述或删除，不充判分；见 §8 C2/C5）。

**核心因果链(讲懂层骨架)：**

```
施工现场本质矛盾：场地有限(如 110m×70m) × 功能需求密集    🔵原理(讲懂起点)
   │  既有建构筑物不可移动 + 材料/加工/运输/办公/安全环保都要落地
   ▼
解法 = 用「分区 + 流线 + 约束满足」把空间矛盾转成可判分布局
   ├ 分区思维：加工区 / 储存区 / 办公生活区相互独立、减少干扰   kc:1A431011_011_0012:1  🟢(分区设置原则)
   ├ 流线思维：≥2 个大门进出分流、仓库接近使用地点、减少二次搬运 kc:1A431011_011_0012:2  🟢
   └ 约束满足：既有设施利用 / 围挡 / 防火间距 / 法规(五牌一图)   kc:1A431011_013_0014:0/1 🟢
   ▼
落实为图内容六项 + 各专项布置要点(大门/塔吊/泵/升降机)
   ├ 塔吊布置八因素 = 风险覆盖环(每项缺失对应一种作业风险)   kc:1A431011_011_0012:3  🟢
   ├ 泵/升降机布置 = 设备稳定与运输流线                       kc:1A431011_011_0012:4/5 🟢
   └ 堆场/加工厂/道路布置 = 物流最短路径                       ca:1A431011_012_0013  🟢
   ▼
效果 = 占地少 + 运输合理 + 干扰最小 + 安全合规(可落地、可判分)
```

**为什么这些原则有效(讲解性，🔵 不充判分)：**
- **占地少 / 减少二次搬运**：物流路径最短 → 直接降成本、降工期；判分时考「布置理由」必须落到「靠近材料运输 / 减少搬运」这类因果句，不能只写「合理布置」。
- **分区设置 + ≥2 个大门**：把交叉干扰拆成独立功能块 + 进出分流，既是效率也是消防/疏散保障（多门=平面上的消防通道）。
- **塔吊布置八因素**：不是清单，是「每一项对应一种事故/失效模式」的风险覆盖环（基础不足→倾覆、群塔无防撞→吊臂相撞）。
- **围挡高度分路段 + 路口通透**：高围挡阻断扬尘/视觉污染，但路口 0.8m 以上须通透——消除驾驶员视线盲区，体现「隔离与安全视距的平衡」，故不是「越高越好」。

> 三色提醒：因果链的**结论性原则/数字**(占地少/减少二次搬运/分区/≥2 大门/围挡 2.5m·1.8m/塔吊八因素) 全部 🟢 锚定；链条里的**机理解释**(空间心理学、最短路径论证)是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人，Opus) 主写，汇编层精简为一句 + 保留 5 场景印证，逐场景重核真题锚（删除镜头 A/B 的 3 处证据包外误锚，见 §8 C2/C3/C4）。

**不变量(一句话)：**
> 凡「在有限施工场地上安排材料/加工/运输/设备/办公/安全环保等设施」，都必须用「**识别约束(既有/地形/防火) → 按分区+流线布置各设施 → 校核布置理由与图内容/法规要素是否完整**」三步把平面布置做到「占地少、运输合理、干扰最小、安全合规」。出题人永远在考「**该布置哪些 / 怎么布置 / 为什么这么布置**」，不考设施本身的施工工艺或具体技术规格。

换言之：判分核心 = **布置内容/对象是否齐全 + 布置位置与相互关系是否合理 + 布置理由是否落到「靠近运输/减少搬运/分区/安全」的因果句**。三者缺一即「不妥 / 不全」。

# X02 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`X02_临设道路材料堆场布置.md`](./X02_临设道路材料堆场布置.md)（深母题知识层 R1–R8，`status: candidate_teaching_prototype`）之上**加的一层**，不是新母题体系。
> 知识层回答「**临时仓库距在建工程多少米、道路单行/双行/消防车道/木材场各多宽、宿舍每间住几人通道多宽、易燃仓库设哪个风向、仓库防火分区面积/疏散距离、灭火器怎么配、材料怎么验收堆放退场**」（学生"会看答案"）；作答层回答「**怎么把这些规格数值写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建临设/平面布置类案例失分不是"不会"，是"会一点但写不成分"——找不妥只指"不合理"不给正确数值（住18人→不写≤16人）、措施只写"合理布置/加强管理"口号无任何数字、消防车道4m 万能套到木材场/露天易燃仓库（实为6m）、易燃仓库风向写反（上风向）、材料验收只写"合格后使用"漏三要素。作答层的杠杆 = 把「知道规格数值」变成「按对象分组 + 三段式判断纠错带正确数字 + 内容清单成组列全」写全采分点。
>
> **职责边界（thin layer，不造第二 authority）**：

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写临设/堆场布置答案漏分，多是某一维整维漏掉（最典型：措施题只写"合理布置"漏掉条件维的全部规格数值；找不妥只指方向错漏掉条件维的正确数字）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 X02 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位/项目部"布置） | 临设布置、材料进场验收（隐含施工方/材料员） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（材料进场验收流程、不合格材料退场流程） | 验收：凭证/数量规格/外观→挂牌→台账（R5-8）；不合格退场：申请→审批→通知→见证退场→记录确认→报告（R5-10） | 退场流程顺序颠倒或漏"见证退场"环节 |
| **条件维** | 达什么阈值/规格才合格（间距/宽度/面积/高度/人数/方向，**本考点失分主战场**） | 仓库距在建≥15m、道路单行4m双行6m消防4m木材场6m、宿舍≤16人通道≥0.9m、防火墙500m²、码放≤1.5m（R5-1/2/3/5/6/9） | 15m/4m/6m/30m²/16人/1.5m 张冠李戴或只写定性不给数字 |
| **记录/计算表达维** | 留什么书面（收料台账、挂牌标识） | 进场验收挂牌标识、建立收料台账（R5-8） | 验收只写"合格后使用"漏挂牌/台账书面要素 |
| **后果维** | 不达标/达标后会怎样（违反消防/坍塌/退场处置） | 易燃仓库设下风向（让火往人少方向走）、不合格材料退场（R5-4/10） | 风向写反、不合格材料降级使用 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。X02 因是规格数值密集型考点，**条件维**是失分主战场，找不妥/列要求题里 4 个维（主体隐含/程序/条件/记录 + 后果）都要扫，尤其**条件维的具体数字不能漏**。

## 1. 采分点可写化表（从 X02 §5 R5 派生 · 逐行回读 compiled_source quote 核真 · 核心）

> **派生规则（不造第二 authority）**：每行的「采分点 / 锚」**逐字来自 X02 §5 R5**（R5-1…R5-11 🟢 kc 锚 + R5-12/13 🔵 相邻），并**逐行回读 `_X02_compiled_source.json` 对应 `point_id` 的 `quote`/`required_terms` 核真**（quote 终判，不据散文）。作答层只**补四件套**：
> - **必写关键词**：阅卷必须出现、缺则不得该分的词（标来源 [R5 required_terms/R8误区反面/工程通识]）。
> - **标准表达**：能直接抄上答题纸的阅卷友好短句（🔵 作答策略，非判分眼本身）。
> - **易错表达 / 常见漏写**：典型失分写法（映射 X02 §6 R8 误区 + error_code）。
> - **版本状态**：`现行有效` 等——**写过期/错档表述照样丢分**，这一件不可省。
> 再标**五维**命中哪维。**采分点本身不增不改**。
>
> **锚硬规则三分类自核**：R5-1…R5-11 全部坐 type ①（有 signed `kc:`/`ca:` point_id，真题只作附加印证）；R5-12/R5-13 是深 pack 已显式标 🔵 的相邻知识，本层**降为作答策略·不充独立采分点**（type ③），见 §1.4。无 type ② 真题侧零教材锚行（X02 全簇均有 kc 锚），无 type 🔴 冒充行。

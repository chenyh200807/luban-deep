# D13 案例题作答层样板 — Answer Layer Prototype

> **这是什么**：在 [`D13_幕墙防火防雷层间封堵.md`](./D13_幕墙防火防雷层间封堵.md)（深母题知识层 R1–R8，幕墙防火/防雷/层间封堵构造）之上**加的一层**，不是新母题体系。
> 知识层回答「**上下层开口实体墙/挑檐多高、空腔填塞/楼板缝隙各填多厚、承托板用什么材料、防雷连接怎么连**」（学生"会看答案"）；作答层回答「**怎么把它写成阅卷友好、能拿分的句子**」（学生"会写答案"）。
> **第一性原理**：一建幕墙防火防雷案例失分不是"不会"，是"会一点但写不成分"——层间封堵只写"塞岩棉"漏掉承托板/水平防火烟带/防火密封胶整维、承托板纠错只说"不能用铝板"不给"1.5mm 镀锌钢板"正确表达、1.5mm 写成 1.5m、200mm（空腔填塞）与 100mm（楼板缝隙）张冠李戴、防雷连接只写"接地"漏掉"框架连主体/立柱柔性导线/焊均压环/隐蔽验收"整链。作答层的杠杆 = 把「知道尺寸/材料」变成「按内容清单逐项枚举 + 三段式判断纠错 + 阈值表型判定带正确数值」写全采分点。
>
> **职责边界（thin layer，不造第二 authority）**：
> - **采分点 ground truth 归 D13 §5.1 R5**（已 signed 的深 pack，11 行采分点）。本层「可写化四件套」从 R5 **逐字派生**，并**逐行回读 `_D13_compiled_source.json` 对应 point_id 的 `quote`/`required_terms` 核真**，**绝不另造采分点**。
> - **判分归 signed scoring artifact / CaseGradingSkillKernel**。本层 AI 批改示范标 `official_score_allowed = false`，是**候选教学示范**，给分档位**继承 D13 §5.3 R7 的 🔴 待裁决状态**（指漏不定分）。
> - **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**。本层错因标签只**映射** registry 已注册码（E02/E03/E07/E10、M03/M07/M08/M10，经真实 Read `error_codes.py` 确认存在），禁自造。
> - **学情归 LearnerStateService**。本层不写学习证据。
>
> **真题锚纪律（红线）**：真题只引 `_D13_exam_evidence.json` 内**真实命中**的 `{年份·题号}`（如 `{2019·第29题}`、`{2020·第23题}`、`{2017·第12题}`、`{2015·案例2}`、`{2015·第23题}`），逐条经 Read 核验年份+题号+答案三元组。证据包外任何"某年第 N 题"属编造，禁用（memory：异源裁判抓出过编造真题锚 = SEV-1）。
>
> **锚硬规则三分类（机器闸 `verify_answer_layer.py` 强制，提交前跑零 🔴 冒充）**：
> - **(a) signed + 真题印证**：行有 `kc:`/`ca:` point_id（quote 已核真），真题作附加印证。D13 仅**防火构造尺寸**（实体墙≥1.2m/挑檐≥1.0m/空腔填塞≥200mm/承托板≥1.5mm）有 `kc:1A413030_148_0286:0` 教材锚、**防雷连接路径**有 `kc:1A413030_148_0287:0` 教材锚。
> - **(b) 真题侧🟢**：该采分点编译库**零教材锚**（quote 不含该内容），版本状态列标 `现行有效·真题侧🟢（R5 真题\`年题\` signed，规范侧未入编译库kc:）`。D13 的**层间缝隙封堵 100mm/水平防火烟带**、**承托板镀锌/不得铝板细节**、**不跨防火分区**、**除镀膜/隐蔽验收/每三层接均压环** 均为此类（pack §1/§3 已显式标"教材 quote 仅含 X，此条主锚走真题"）。

## 0. 五维框架（作答层的"采分点分类器"）

案例采分点几乎都能归到这**五维**之一。学生写幕墙防火防雷答案漏分，多是某一维整维漏掉（最典型：层间封堵题只写"塞岩棉"漏掉承托板维与隔离功能维；防雷题只写"框架连主体"漏掉立柱柔性导线/焊均压环/隐蔽验收整链）。作答层给每个采分点标命中哪维，让学生答题时"五维自检"不漏维。

| 维 | 含义 | 在 D13 的典型采分点 | 高频漏法 |
|---|---|---|---|
| **主体维** | 谁做/谁组织（本考点弱，多隐含"施工单位"，防雷连接隐含电气/幕墙施工方） | 防雷连接、层间封堵施工（隐含施工方） | 本考点主体维占比低，几乎不单独成采分点 |
| **程序维** | 按什么顺序做（定性是什么幕墙→查防火构造→查层间封堵→查防雷连接；防雷连接路径顺序） | 防雷连接链：框架连主体→立柱柔性导线→预埋件焊均压环→隐蔽验收（R5 #7–10）；层间封堵程序（R5 #5–6） | 防雷只写一两环（漏均压环/漏隐蔽验收）；封堵漏承托/密封工序 |
| **条件维** | 达什么阈值才合格（实体墙≥1.2m、挑檐≥1.0m、空腔填塞≥200mm、楼板缝隙≥100mm、承托板≥1.5mm、立柱≤10m） | 实体墙≥1.2m/挑檐≥1.0m（R5 #2）；空腔填塞≥200mm/承托板≥1.5mm（R5 #3）；楼板缝隙≥100mm（R5 #5）；立柱≤10m（R5 #8） | 1.5mm 写成 1.5m；200mm 与 100mm 张冠李戴；漏立柱 10m 距离 |
| **记录/计算表达维** | 留什么书面 / **写阈值判定链**（构造尺寸是否达标的阈值表型判据） | 防火构造尺寸阈值表（开口间距是否≥1.2m → 不足则补挑檐≥1.0m）；承托板厚度/材料判定 | 只写"要防火处理"不写具体尺寸；只写结论不写"≥1.2m 或挑檐≥1.0m"判据 |
| **后果维** | 不达标/达标后会怎样（火灾沿幕墙串区、雷击跳火、防火分区失效） | 同一玻璃单元不跨防火分区（R5 #4）；承托板用铝板火中熔化失效 | 认为玻璃单元可跨防火分区；以为铝板能承托耐火 |

> 用法：批改时先把参考采分点按五维铺开，学生答案逐维比对——**漏哪维一目了然**。D13 因是数值阈值 + 材料选型 + 连接路径密集型考点，**条件维**（尺寸单位 m/mm 别混、200/100 别混）与**程序维**（防雷连接链别漏环、封堵全要素别漏）是失分主战场。

### b. 内容清单枚举 + 阈值表型判定在幕墙防火防雷场景够用吗？有无需要第 10 类？

## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「病因导向：先诊断后下药」三链；汇编层把镜头 A 的散文链收成「病因→机理→对症治理→为什么有效」+每链挂 point_id，**镜头 A 自造的 node_code 全部移除**；镜头 A 的"渗流阻力/握裹不牢"等机理解释无 point_id，保留为 🔵 讲解性表述、不充判分。

**核心因果链(讲懂层骨架)：先诊断（找病灶+回溯成因）→ 后下药（对症/分级治理）**

```
诊断总则: 识别渗漏病灶(部位/现象) → 回溯成因机理 → 匹配合规治理措施   🔵讲懂骨架
   │
   ├─ 链一·混凝土基体缺陷渗漏: 欠振/养护不及时 → 不密实/微裂缝 → 贯穿渗水通路
   │     治理: 保湿养护+多道设防刚柔结合(防) / 灌浆堵漏(治,浆液填充通路并胶结)   kc:1A434000_075_0117:0、kc:1A412010_065_0127:0🔵  🟢治理原则

   │     诊断成因: 未清理/接槎明显/钢筋密集浇捣不密实   kc:1A434000_074_0116:0  🟢诊断
   │     治理: 清理管壁→设止水环(延长渗径)→振捣密实→避免振动→灌浆堵漏   kc:1A434000_075_0117:1  🟢节点治理流程

```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **先诊断后下药**：渗漏是结果，必须先按部位/现象回溯到具体成因（施工缝？穿墙管？卷材流淌起鼓？女儿墙收头？），再匹配对症措施——错配（如把流淌治理用于穿墙渗漏）必然无效（机理为讲解性，🔵）。
- **止水环=延长渗径**：管壁光滑、混凝土握裹不牢是穿墙渗漏的薄弱点，焊止水环把水沿管壁的渗透路径拉长、增加渗流阻力（机理 🔵）。
- **起鼓按 100mm 分档**：小鼓胶结料局部失效，抽气灌胶即可抚平；大鼓胶结料大面积失效，必须割开切病根、干燥基层、重贴重建（机理 🔵）。
- **多道设防、刚柔结合**：单道防水一处破即漏，多道（刚性混凝土自防水+柔性卷材/涂膜）冗余、刚柔互补（刚性抗渗、柔性适应变形），是防水混凝土裂缝渗漏的根本防治逻辑（机理 🔵）。

> 三色提醒：因果链的**结论做法/数字**（施工缝渗漏三成因、止水环+灌浆堵漏流程、流淌三法、起鼓100mm分档、女儿墙治理五步、多道设防刚柔结合）全部 🟢 锚定（教材锚或真题锚）；链条里的**机理解释**（渗径/渗流阻力/胶结料失效/刚柔互补逻辑）是讲懂用语，标 🔵，不得作为采分点输出。

## 7. R8 动画分镜 (L7)

> 来源谱系：镜头 D(Qwen) 主写视觉隐喻 + Reveal 顺序 + Aha；汇编层**把 Reveal 顺序重排为"先诊断（定部位+成因）→ 后治理（对症·分级·分档）逐点 reveal"**，删除镜头 C 捏造的"淋水2h/蓄水24h"分镜，Aha 锚按内容精确挂。对接闭环渲染器约定见尾注。

### 视觉隐喻
- **诊断"病灶探照灯"**：屋面/地下室渗漏现象先用探照灯定位部位（施工缝/穿墙管/卷材鼓包/女儿墙根），点亮对应"病灶卡"，回溯成因标签浮现。
- **施工缝渗漏"通缝水线"**：未清理的施工缝处新旧混凝土间一条红色"通缝"水线渗水；清理+振捣密实后通缝消失变绿。
- **管道穿墙"止水环挡水"**：光滑管壁水沿缝渗（红）；焊上止水环后水的渗径被拉长、绕行受阻（绿），最后灌浆堵漏封死。
- **卷材流淌"三级温度计"**：流淌程度温度计——严重(红·拆除重铺)/中等(黄·切割法/局部切除重铺/钉钉子法)/轻微(绿·不渗漏可不治)分级亮起。
- **卷材起鼓"100mm标尺"**：鼓包直径标尺——<100mm注射器抽气灌胶抚平(绿)；≥100mm斜十字形割开、吹干、重贴方形卷材(绿)；若大鼓也只抽气=鼓包复发红叉。
- **女儿墙"五步修复链"**：清除旧胶结料→烤干基层→重新钉压条→覆盖新卷材→防水油膏封口，五步逐项打勾，对照漏步红叉。

### Reveal 顺序(讲懂 → 判分眼)
1. **诊断骨架**：病灶探照灯定位部位→回溯成因 流程条亮起。(讲懂层骨架)
2. **施工缝诊断**：通缝水线现红，清理+振捣后变绿。(锚 `kc:1A434000_074_0116:0`)
3. **节点治理**：止水环挡水+灌浆堵漏；裂缝多道设防刚柔结合。(锚 `kc:1A434000_075_0117:0/:1`)
4. **流淌分级**：三级温度计 严重/中等/轻微 对应治理逐级亮。(锚 `kc:1A434000_076_0118:0`、`{2025,案例三}`)
5. **起鼓分档**：100mm标尺 小鼓抽气灌胶/大鼓割开重贴。(锚 `kc:1A434000_076_0119:0`)
6. **女儿墙五步**：清旧→烤干→钉压条→新卷材→封口逐项打勾。(锚 `kc:1A434000_077_0120:0`)

### Aha 时刻(锚已按内容精确挂)
- 探照灯一扫，同样的"渗漏"在不同部位亮出不同病灶卡和不同药方 → 「渗漏先诊断后下药，对症不混答」。锚 `kc:1A434000_074_0116:0`、`kc:1A434000_077_0120:0`
- 管壁焊上止水环，水的渗径被拉成长长的绕行路、流不进来 → 「止水环=延长渗径、增加渗流阻力」。锚 `kc:1A434000_075_0117:1`
- 起鼓标尺滑过 100mm：小鼓一针抽气灌胶就平，大鼓必须割开重贴 → 「起鼓按 100mm 分档，大鼓胶结料大面积失效不能只抽气」。锚 `kc:1A434000_076_0119:0`
- 流淌温度计：轻微流淌若不渗漏，温度计停在绿区"可不治理" → 「治理也讲度——轻微不渗漏不必大拆，过度处置是浪费」。锚 `kc:1A434000_076_0118:0`、`{2025,案例三}`

## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「水驱泛碱模型 + 界面粘结模型」两条因果链；汇编层逐链挂 point_id，删除镜头 A 里无锚的化学方程式外推(CaCO₃ 生成、NaOH 具体碱种)作 🔵 讲解性表述、不充判分；镜头 A 引的 `2016-第6题`(花岗石酸性)/`2017-第11题`(防碱)经核真**确在证据包内且 D12 相关**，保留为真题锚(见 §8 C1)。

**核心因果链(讲懂层骨架)：空鼓/脱落 = 界面粘结力丧失；泛碱 = 水把碱从背面运到面层破坏界面**

```

基层有浮灰/油污/脱模剂(隔离层)  kc:1A434000_078_0123:0  🟢
   │ 粘不住:粘结材料无法附着
   ▼
粘结层不饱满/厚度不当/超调整期再扰动  kc:1A413030_145_0280:1  🟢
   │ 粘不实:破坏已初凝的水化结晶=假粘
   ▼

   │ 粘不久:应力在最薄弱粘结界面剪切破坏
   ▼

【链2 · 水驱泛碱模型(湿贴石材专属)】

   │
   ▼
对症(切断物质源/载体——泛碱专属):
   ├ 湿作业石板背面/侧面防碱封闭(关卡)  kc:1A413030_144_0279:1、{2017,第11题}  🟢

```

> jury HC#2 采纳:干挂石材六面防护原置于"水驱泛碱·切断通道",逻辑不精确(干挂无水泥砂浆碱源,六面防护是隔绝外部污染物的**界面防护**,非泛碱通道),已**移出泛碱链独立列为墙面干挂界面防护**,与地面铺贴区分。

**为什么措施有效(讲解性，🔵 不充判分)：**
- **基层清理 + 油性防护石材界面剂+背砂**：从「界面」端创造机械咬合与化学键合的基本条件 —— 没有干净有效的界面，再好的粘结材料也是「假粘」。
- **粘结剂 3~8mm + 调整期内微调 + 超时禁振**：控制粘结层厚度与扰动时机，是为了让水化产物完整致密形成强力键合；超时再振动等于砸碎已结晶的「胶」。
- **大面积设伸缩缝**：把胀缩内应力「化整为零」，给材料留「呼吸」空间，避免应力在粘结界面累积剪切。
- **湿贴石板防碱封闭 / 花岗石属酸性低吸水**：花岗石致密低吸水(酸性石材，`{2016,第6题}`)，但拼缝与背面仍是碱+水的通道；背/侧面防碱封闭直接堵住碱的运输路径，是泛碱治本手段。

> 三色提醒：因果链的**结论数字/做法**(3~8mm / 界面剂+背砂 / 伸缩缝 / 防碱封闭 / ≤10mm·<40cm·8~10mm)全部 🟢 锚定；链条里的**化学机理解释**(碱种、CaCO₃、毛细虹吸量化)是讲懂用语，标 🔵，不得作为采分点输出。

## 3. R2 不变量 (L3)

> 来源谱系：镜头 B(出题人，Opus) 主写，汇编层精简为一句 + 保留 6 场景印证，逐场景重核真题锚(改正镜头 A/C/D 同源把握不准的 1 处语境，见 §8 C2)。

**不变量(一句话)：**
> 凡「块料(砖/板/石材)贴/挂到基层上」，判分都在「**选对方法(干挂/湿贴/粘贴按部位与尺寸) → 控住界面(清理/防碱/界面剂/复验) → 控住过程(粘结剂厚度/调整期/伸缩缝/养护)**」三步把空鼓脱落与泛碱堵死。出题人**几乎不考装饰美学**，只考「**方法选对没 / 界面处理够不够 / 工艺参数达不达标**」。

换言之：判分核心 = **施工方法是否匹配部位与尺寸 + 界面与材料是否合规复验 + 工艺参数是否达标**。三者任一不命中即「不妥」。**(本不变量是教学启发式骨架，按题面命中的环节逐项裁决，不对每题强行跑满三步。)**

**≥5 场景印证(每条带已核真锚)：**

1. **墙柱面石材选法** —— 干挂(短槽/背槽/背栓)/干粘/湿贴；干挂需工厂加工挂件 + 六面防护，湿贴需铲除背网。
   🟢 教材锚 `kc:1A413030_144_0279:3`。

2. **薄型小规格块材能否粘贴** —— ≤10mm 厚、<40cm 边长才可粘贴，粘贴厚度 8~10mm；超规格须改挂。
   🟢 教材锚 `kc:1A413030_144_0279:3`(尺寸门槛)。

3. **湿贴花岗岩防碱** —— 水泥砂浆铺贴花岗岩前，背面和侧面应防碱处理。

### 视觉隐喻

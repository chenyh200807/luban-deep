# N01 双代号网络计划关键线路/总时差：R5-R7 镜头稿

## R5 采分点

### 采分点 A：先校正网络逻辑，再谈计算
- 🟢锚定｜source=教材锚源料｜point_id=`kc:LEC_1A433000_P0018_001:0`  
  共同紧后工作应按节点共用、逻辑关系清楚的原则处理。
- 🟢锚定｜真题=`2015 案例1`  
  题目要求因工作 F 需在 B、C 完成后才能开始，应调整网络图；参考答案提示“3—4 之间增加一个虚工作”。
- 采分表达：  
  先指出原网络逻辑不满足紧前紧后关系，再用虚工作或节点关系修正，使 F 的紧前工作完整体现。
- 常见错因码：`E08` 背景信息提取失败、`E06` 程序顺序错误、`E07` 概念混淆。

### 采分点 B：识别关键工作与关键线路
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A433000_056_0085:1`  
  关键工作是总时差最小的工作；关键线路由全部关键工作组成，其工期等于网络计划的计算工期。
- 🟢锚定｜真题=`2015 案例1`  
  调整后关键线路为 `A→B→F→H→I` 和 `A→D→G→H→I`。
- 🟢锚定｜真题=`2017 案例一`  
  关键线路示例为 `①→②→③→④→⑦→⑧→⑨`，总工期为 180 天。
- 采分表达：  
  写出完整线路，不只写“关键线路为最长线路”；线路上的工作或节点必须连续、无漏项。
- 常见错因码：`E02` 采分点遗漏、`E09` 计算错误、`E03` 关键词缺失。

### 采分点 C：计算总工期
- 🟢锚定｜真题=`2015 案例1`  
  总工期可写为 `T=5+7+5+4+4=25` 或 `T=5+8+4+4+4=25` 个月。
- 🟢锚定｜真题=`2017 案例一`  
  总工期示例为 180 天。
- 🔵工程通识  
  双代号网络计划中，总工期应按关键线路上各工作的持续时间相加；若有多条关键线路，应说明它们计算工期相等。
- 采分表达：  
  答案要有“线路 + 算式 + 单位”，只写数字容易丢采分点。
- 常见错因码：`E09` 计算错误、`E12` 表达冗余。

### 采分点 D：用总时差判断工期索赔或延误影响
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A433000_056_0085:1`  
  关键工作以总时差最小判定。
- 🟢锚定｜真题=`2018 案例分析(二)`  
  电缆电线安装工程有 3 个月总时差，延误 1 个月不影响总工期，工期索赔不成立。
- 🟢锚定｜真题=`2015 案例1`  
  C 为非关键工作，总时差 1 个月，延误 2 个月时，对总工期影响只有 1 个月；E 总时差 4 个月，延误 3 个月未超过总时差，工期索赔不成立。
- 采分表达：  
  必须把“责任原因”和“是否超过总时差”分开写；非承包商原因不自动等于工期索赔成立。
- 常见错因码：`E07` 概念混淆、`E11` 迁移失败、`E05` 审题错误。

### 采分点 E：进度滞后时优先围绕关键线路调整
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A433000_061_0092:0`  
  进度计划调整方法包括关键工作调整、逻辑关系调整、重新编制计划、非关键工作调整、资源调整。
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A433000_061_0091:0`  
  施工进度监测包括观测关键线路、检查非关键工作、核查逻辑关系等。
- 🟢锚定｜真题=`2017 案例一`  
  工期滞后 5 天时，题目围绕关键线路工序压缩来确保工期不变。
- 🔴待验证  
  具体“先压缩哪一项”的顺序必须以题目给出的赶工参数表、关键线路和压缩费用为准；当前证据中存在表述差异，不能固化成唯一口令。
- 常见错因码：`E08` 背景信息提取失败、`E09` 计算错误、`E10` 规范适用错误。

## R6 答案骨架

### 满分骨架 1：问“关键线路和总工期”
```markdown
1. 先根据网络图核对逻辑关系，必要时补虚工作或调整节点关系。
2. 计算各线路持续时间，或计算时间参数。
3. 判定关键工作：总时差最小的工作为关键工作。
4. 写出关键线路：____→____→____。
5. 计算总工期：T=____+____+____=____（天/月）。
6. 若有两条或多条关键线路，应全部列出，并说明其工期相等。
```

### 满分骨架 2：问“总时差与索赔是否成立”
```markdown
1. 说明该工作是否为关键工作，或写明其总时差 TF=____。
2. 写明实际延误时间=____。
3. 比较：延误时间 ____ 总时差。
4. 结论：
   - 未超过总时差：不影响总工期，工期索赔不成立；
   - 超过总时差：超过部分影响总工期，工期索赔按超过部分判断。
5. 另行判断费用索赔，不把费用索赔与工期索赔混为一谈。
```

### 满分骨架 3：问“进度滞后如何调整”
```markdown
1. 先确认当前关键线路和滞后天数。
2. 优先调整关键线路上的关键工作。
3. 可选方法包括：关键工作调整、逻辑关系调整、重新编制计划、非关键工作调整、资源调整。
4. 若题目给出赶工费用或可压缩时间，应按关键线路、可压缩量、费用或资源条件综合选择。
5. 最后说明调整后总工期仍满足合同或计划工期。
```

## R7 边界候选

> 🔴待真人/专家裁决：以下为训练镜头候选边界，不冒充官方评分细则。

### 候选边界 A：关键线路题
- 🔴满分候选：完整写出关键线路，算式正确，单位正确；若存在多条关键线路，全部列出。
- 🔴压线候选：能写出一条正确关键线路和总工期，但漏写另一条并列关键线路。
- 🔴0分 near-miss 候选：只写“最长线路是关键线路”，没有线路、没有计算，或线路节点不连续。

### 候选边界 B：总时差索赔题
- 🔴满分候选：同时写清“责任原因、总时差、延误时间、是否影响总工期、索赔结论”。
- 🔴压线候选：结论正确，但比较逻辑不完整，例如只写“未超过总时差”而未说明不影响总工期。
- 🔴0分 near-miss 候选：认为“只要是甲方原因就一定工期索赔成立”，未比较总时差。

### 候选边界 C：网络逻辑修正题
- 🔴满分候选：指出原图逻辑缺陷，并用虚工作或节点调整正确表达紧前紧后关系。
- 🔴压线候选：能看出逻辑关系有问题，但图示或文字调整不完整。
- 🔴0分 near-miss 候选：直接计算关键线路，不处理题干新增的紧前关系，导致后续计算建立在错误网络图上。

### 候选边界 D：赶工调整题
- 🔴满分候选：先锁定关键线路，再结合可压缩时间、费用或资源条件选择压缩对象。
- 🔴压线候选：知道压缩关键线路，但未充分利用题干赶工参数。
- 🔴0分 near-miss 候选：压缩非关键工作，或只说“增加资源、加班赶工”，没有回到关键线路。

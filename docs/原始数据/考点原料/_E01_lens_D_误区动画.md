# 工程量清单计价误区解析

## 误区1: 认为所有项目都应采用单价计价
- **现象**: 学员在处理措施项目时，错误地将其按照分部分项工程的方式进行单价计价。
- **错误心智模型**: 误以为所有的工程项目都可以用相同的计价方式来处理。
- **对症解药**:
  - 🔵 措施项目宜采用总价计价。理解不同类型的项目有不同的计价方式是关键。
  - 🟢 [kc:1A432002_035_0046:0] 工程量清单计价方式下，分部分项工程宜采用单价计价，措施项目宜采用总价计价。

## 误区2: 忽视综合单价的构成
- **现象**: 在计算综合单价时，学员往往遗漏了某些费用，如管理费、利润或风险费。
- **错误心智模型**: 认为综合单价仅包括直接成本（人工、材料、机具）。
- **对症解药**:
  - 🔵 综合单价为不含增值税的税前全费用价格，包含人工、材料、机具、管理、利润及风险费。
  - 🟢 [kc:1A432002_035_0046:0] 综合单价为不含增值税的税前全费用价格，包含人工、材料、机具、管理、利润及风险费。

## 误区3: 编制工程量清单时忽略重要依据
- **现象**: 学员在编制工程量清单时，忽略了招标文件、合同条款等重要依据。
- **错误心智模型**: 认为只需要根据图纸和技术规范即可完成清单编制。
- **对症解药**:
  - 🔵 工程量清单的编制依据包括：计价标准、工程量计算规则、招标文件、合同条款、招标图纸、技术规范、现场情况、地勘资料、工程特点及交付标准等。
  - 🟢 [kc:1A432002_037_0048:0] 工程量清单的编制依据包括：计价标准、工程量计算规则、招标文件、合同条款、招标图纸、技术规范、现场情况、地勘资料、工程特点及交付标准等。

## 误区4: 不清楚合同类型适用场景
- **现象**: 学员在选择合同类型时，未能根据工程的具体情况做出合理的选择。
- **错误心智模型**: 认为所有工程都适合同一种合同类型。
- **对症解药**:
  - 🔵 单价合同适用于工程量不确定；总价合同适用于工程量明确；成本加酬金适用于紧急抢险、复杂工程。
  - 🟢 [kc:1A432002_036_0047:1] 单价合同适用于工程量不确定；总价合同适用于工程量明确；成本加酬金适用于紧急抢险、复杂工程。

## 误区5: 对计价风险责任划分不清
- **现象**: 学员在处理计价风险时，不清楚哪些风险由发包人承担，哪些由承包人承担。
- **错误心智模型**: 认为所有风险都应由一方承担。
- **对症解药**:
  - 🔵 发包人承担：清单缺陷、数据错误、变更、赶工；承包人承担：措施清单准确性、总价合同缺陷、自身方案变更、施工效率问题。
  - 🟢 [kc:1A432002_036_0047:0] 发包人承担：清单缺陷、数据错误、变更、赶工；承包人承担：措施清单准确性、总价合同缺陷、自身方案变更、施工效率问题。

## 动画分镜原料
### 视觉隐喻
- **工程量清单**：用一个装满各种工具和材料的箱子表示，每个工具代表不同的项目。
- **综合单价**：用一个包含多个小图标（代表人工、材料、机具、管理、利润、风险费）的大圆圈表示。
- **合同类型**：用三种不同颜色的钥匙（单价合同、总价合同、成本加酬金合同）表示，每种钥匙对应不同的锁（工程类型）。

### Reveal顺序
1. 展示装满工具的箱子，逐步打开并展示里面的工具。
2. 引入大圆圈，逐步添加各个小图标，解释综合单价的构成。
3. 展示三种不同颜色的钥匙，分别插入对应的锁中，解释合同类型的适用场景。
4. 通过动画展示风险责任的划分，用箭头指向发包人和承包人各自的责任区域。

### Aha时刻
- 当大圆圈中的所有小图标全部出现时，学员会意识到综合单价不仅仅是直接成本，还包括管理、利润和风险费。
- 当三种钥匙成功开锁时，学员会明白不同类型的工程需要选择合适的合同类型。

## R2 不变量（一句话）

> 凡施工现场临时用电，出题人永远在考三件事：**架构对不对（三级配电 + TN-S 接零 + 二级漏保）、参数够不够（安全电压 36/24/12V、电缆埋深 0.7m、五芯/标识色）、管理顺不顺（一机一闸一漏、停送电顺序、电工持证、装饰阶段补编方案）**。不考供配电工艺设计本身，只考"该不该这么接 / 接到什么参数 / 谁来管"。

判分核心 = **系统架构是否完整 + 关键参数是否达标 + 用电管理制度是否到位**，三者缺一即"不妥"。

## examiner_intent（按真题命中频次排序）

出题人在临时用电上几乎只考"对不对 / 还差什么 / 参数够不够"，三层意图：

- **意图①「一机一闸一漏 / 开关箱专用」纠错（案例高频·高分密集区）。**
  给现场用电做法，故意写"两台设备共用一个开关箱""插头插座做活动连接""装饰阶段只按原临电组织设计施工"，要指错 + 写正确做法。
  🟢 真题锚 `{2023, 第1题}`(直读 correct_answer：每台设备必须配备专用开关箱、严禁2台及以上共用、电源进线端严禁插头插座活动连接、装饰装修阶段应补充编制单项施工用电方案)；教材锚 `kc:1A431011_014_0015:2`、`kc:1A431011_014_0015:3`。

- **意图②「临时用电管理制度」判断（MCQ 高频）。**
  电工持证、用电设备拆除由谁做、50kW 及以上要不要编用电组织设计、装饰阶段用电怎么管 —— 选正确说法。
  🟢 真题锚 `{2018, 第17题}`(直读 answer=A：现场电工必须经考核合格持证上岗；拆除应由电工完成；50kW及以上应制定用电组织设计；装饰装修阶段应补编单项施工用电方案)；教材锚 `kc:1A431011_014_0015:4`。

- **意图③「安全电压 / 电缆参数 / 标识色」记忆点（MCQ 稳定考点）。**
  特殊场所照明电压门槛（≤36/24/12V）、五芯电缆 N 线/PE 线标识色、配电箱金属箱门连接材料。
  🟢 真题锚 `{2016, 第13题}`(金属容器内≤12V，answer=C)、`{2019, 第14题}`(五芯电缆 N 线=蓝色、PE 线=黄绿，answer=C)、`{2020, 第15题}`(配电箱金属箱门与箱体连接=单股铜线，answer=A)；教材锚 `kc:1A431011_015_0016:2`、`kc:1A436000_130_0209:0`。

- **意图④「临时用电组织设计 / 验收」程序（案例）。**
  《临时用电组织设计》谁编、谁验收、施工完成后由谁拆除；电缆直接埋地敷设穿临时设施的保护。
  🟢 真题锚 `{2021, 第5题}`(stem：项目总工编制《临时用电组织设计》，总配电箱设在用电设备相对集中区域、电缆直接埋地敷设穿临时设施设警示标识并保护)；教材锚 `kc:1A431011_014_0015:0`(电缆埋地≥0.7m)、`kc:1A431011_015_0016:1`(停送电顺序)。

> **一句话**：出题人把临时用电当成"系统意识 + 参数记忆 + 制度合规"三重过滤器 —— 意识层考"三级配电二级保护接没接全"，记忆层考"36/24/12V、0.7m、蓝/黄绿这些硬参数记没记牢"，制度层考"一机一闸、持证、补编方案做没做到"。

## R4 变量规则（封闭——可枚举、可判分、不外溢）

**规则组 A：系统三大架构（封闭枚举）** — 锚 `kc:1A431011_015_0016:0`。

| 变量 | 封闭取值 | 判分边界 |
|---|---|---|
| 配电级数 | {三级配电：总配电箱→分配电箱→开关箱} | 缺级/越级直接接 = 不妥 |
| 接零保护系统 | {TN-S 接零保护系统} | 用 TN-C/TT 或"利用大地作导体" = 不妥 |
| 漏电保护级数 | {二级：总配电箱 + 开关箱(末级)} | 仅一级 / 末级缺漏保 = 不妥 |

**规则组 B：停送电顺序（封闭有序，禁逆）** — 锚 `kc:1A431011_015_0016:1`。
送电：总配电箱 → 分配电箱 → 开关箱；停电：开关箱 → 分配电箱 → 总配电箱。顺序颠倒 = 不妥。

**规则组 C：安全电压门槛（封闭阈值表）** — 锚 `kc:1A431011_015_0016:2`、`kc:1A436000_130_0209:0`；真题印证 `{2016, 第13题}`。

| 场所 | 安全电压上限 | 锚 |
|---|---|---|
| 一般场所/手持灯具 | ≤36V（双绕组隔离变压器） | `kc:1A436000_130_0209:0` |
| 潮湿/隧道/人防/易触及带电体 | ≤24V | `kc:1A431011_015_0016:2` |
| 金属容器/锅炉内 | ≤12V | `kc:1A431011_015_0016:2`、`{2016, 第13题}` |

**规则组 D：开关箱控制原则（封闭——一机一闸）** — 锚 `kc:1A431011_014_0015:2`；真题印证 `{2023, 第1题}`。
每台用电设备各自专用开关箱；严禁一个开关箱直接控制 2 台及以上设备（含插座）；配电箱/开关箱电源进线端严禁插头插座活动连接。违反即不妥。

**规则组 E：电缆敷设参数（封闭阈值）** — 锚 `kc:1A431011_014_0015:0`、`:1`；真题印证 `{2019, 第14题}`、`{2021, 第5题}`。
直接埋地深度 ≥0.7m；五芯电缆 N 线=蓝色、PE 线=黄绿双色（不得混用/挪作他用）；穿越临时设施须设警示标识并保护。越界即不妥。

**规则组 F：用电管理制度（封闭清单）** — 锚 `kc:1A431011_014_0015:4`；真题印证 `{2018, 第17题}`、`{2020, 第15题}`。
电工持证上岗；用电设备拆除由电工完成；总容量 50kW 及以上编用电组织设计；装饰装修阶段补编单项施工用电方案；配电箱金属箱门与箱体连接=单股铜线。

> **封闭性自检**：A~F 六组取值域均来自具体 point_id 的枚举/阈值，无连续无界参数；判分边界全部可机械裁决。规则封闭成立。

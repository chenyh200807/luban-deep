# 模板拆除顺序与条件

## 误区及解药

1. **误区：模板拆除时，只需考虑混凝土强度达到设计值即可。**
   - **现象**：施工人员在拆除模板时，仅关注混凝土强度是否达到设计值，而忽视了其他因素。
   - **错误心智模型**：认为只要混凝土强度达标，就可以拆除模板。
   - **对症解药**：应综合考虑混凝土强度、结构类型、跨度等因素，确保拆除时机正确。（E03）
   
2. **误区：所有模板的拆除顺序都相同。**
   - **现象**：施工人员在拆除模板时，不区分不同类型的模板，采用统一的拆除顺序。
   - **错误心智模型**：认为所有模板的拆除顺序都是固定的。
   - **对症解药**：应根据模板类型（如底模、侧模等）和结构特点，遵循“后支先拆、先支后拆”的原则。（E04）

3. **误区：快拆支架体系中，立杆间距可以随意设置。**
   - **现象**：施工人员在使用快拆支架体系时，立杆间距设置过大。
   - **错误心智模型**：认为立杆间距不影响模板拆除的安全性。
   - **对症解药**：快拆支架体系的立杆间距不应大于2m，以确保结构稳定性和安全性。（E05）

4. **误区：拆除模板时，无需保留立杆支撑。**
   - **现象**：施工人员在拆除模板时，直接移除所有立杆支撑。
   - **错误心智模型**：认为拆除模板后，结构已经足够稳定，不需要额外支撑。
   - **对症解药**：在拆除模板时，应保留立杆并顶托支承楼板，确保结构安全。（E06）

5. **误区：梁板模板拆除时，无需考虑跨度的影响。**
   - **现象**：施工人员在拆除梁板模板时，未根据跨度调整拆除时间。
   - **错误心智模型**：认为梁板模板拆除时间与跨度无关。
   - **对症解药**：应根据梁板的跨度调整拆除时间，确保混凝土强度达到规定值。（E07）

6. **误区：拆除模板时，无需进行验收检查。**
   - **现象**：施工人员在拆除模板前，未进行必要的验收检查。
   - **错误心智模型**：认为模板拆除是简单的操作，无需特别检查。
   - **对症解药**：在拆除模板前，应进行验收检查，确保混凝土强度和其他条件符合要求。（E08）

7. **误区：拆除模板时，无需考虑环境温度的影响。**
   - **现象**：施工人员在低温环境下拆除模板，未采取保温措施。
   - **错误心智模型**：认为环境温度对模板拆除无影响。
   - **对症解药**：在低温环境下拆除模板时，应采取保温措施，防止混凝土受冻。（E09）

8. **误区：拆除模板时，无需记录拆除时间和条件。**
   - **现象**：施工人员在拆除模板时，未记录拆除时间和条件。
   - **错误心智模型**：认为记录拆除时间和条件没有必要。
   - **对症解药**：应详细记录模板拆除的时间和条件，以便后续检查和追溯。（E10）

# N03 流水施工参数与工期｜R5-R7 镜头

## R5 采分点：引源料 point_id，合理分组

### 1. 先识别组织方式与施工段条件
- 🟢 **组织方式三分法**：依次施工=顺序进行、无搭接；平行施工=多队并行、同步推进；流水施工=分段分序、连续搭接。  
  source=`kc:1A433000_051_0074:0`
- 🟢 **施工段划分原则**：劳动量差异≤15%，工作面充足，界限与结构缝吻合，段数合理，多层工程分段分层。  
  source=`kc:1A433000_051_0074:1`

### 2. 抓住三大参数：t、K、T
- 🟢 **流水节拍 t**：某个专业队在一个施工段上的施工时间。  
  source=`kc:1A433000_052_0075:0`
- 🟢 **流水步距 K**：两个相邻专业队进入流水作业的时间间隔。  
  source=`kc:1A433000_052_0075:1`
- 🟢 **工期 T**：从第一个专业队投入流水作业开始，到最后一个专业队完成最后一段工作并退出为止的持续时间。  
  source=`kc:1A433000_052_0075:2`

### 3. 类型判定采分点
- 🟢 **等节奏流水施工**：所有施工过程在各施工段上的流水节拍均相等；相邻流水步距相等且等于流水节拍；专业队数等于施工过程数；各专业队连续作业、无空闲。  
  source=`kc:1A433000_052_0077:0`；真题锚=`2015年第16题`
- 🟢 **无节奏流水施工**：各施工过程在各施工段的流水节拍不全相等；相邻流水步距不尽相等；专业队数等于施工过程数；专业队可连续作业，但施工过程间可能有间隔。  
  source=`kc:1A433000_052_0076:0`
- 🟢 **异节奏流水施工**：分为等步距和异步距；等步距要求不同施工过程节拍成倍数关系，异步距无此限制。  
  source=`kc:1A433000_053_0078:0`

### 4. 等步距异节奏的核心采分点
- 🟢 **节拍成倍数关系**。  
  source=`kc:1A433000_053_0078:1`
- 🟢 **流水步距 K=最大公约数**。  
  source=`kc:1A433000_053_0078:1`
- 🟢 **专业队数大于施工过程数**。  
  source=`kc:1A433000_053_0078:1`
- 🟢 **通过增加专业队数，使各专业队按相同步距推进，提高效率**。  
  source=`kc:1A433000_055_0083:0`

### 5. 计算表达采分点
- 🟢 **大差法步骤**：列累加数列；错位相减；取最大值作为流水步距；再计算总工期。  
  source=`kc:1A433000_054_0081:0`
- 🔵 **答题通识**：计算题必须写“判型 → 参数 → 过程 → 结果”，不能只给最终工期。
- 🔵 **答题通识**：涉及横道图时，应把各施工过程时间安排、搭接关系、资源连续性表达清楚。

## R6 答案骨架：满分要点

### A. 概念型问法：问“什么是流水节拍/步距/工期”
1. 🟢 流水节拍 t：某专业队在一个施工段上的施工时间。  
   source=`kc:1A433000_052_0075:0`
2. 🟢 流水步距 K：相邻专业队进入流水作业的时间间隔。  
   source=`kc:1A433000_052_0075:1`
3. 🟢 工期 T：从第一个专业队开始流水，到最后一个专业队完成最后一段并退出的持续时间。  
   source=`kc:1A433000_052_0075:2`
4. 🔵 作用表达：t决定单段作业持续时间，K决定相邻队伍搭接节奏，T体现总进度结果。

### B. 判型型问法：问“属于哪种流水施工”
1. 🟢 若各施工过程在各施工段上的节拍均相等，则判为等节奏流水施工。  
   source=`kc:1A433000_052_0077:0`
2. 🟢 若各节拍不全相等、步距不尽相等，专业队数等于施工过程数，则偏向无节奏流水施工。  
   source=`kc:1A433000_052_0076:0`
3. 🟢 若节拍不相等但存在倍数关系，且可按相同步距组织，则判为等步距异节奏流水施工。  
   source=`kc:1A433000_053_0078:1`
4. 🟢 写明理由：节拍是否相等、是否成倍数关系、K是否相等、专业队数是否等于施工过程数。  
   source=`kc:1A433000_052_0077:0`；`kc:1A433000_052_0076:0`；`kc:1A433000_053_0078:1`

### C. 等节奏流水施工问法
1. 🟢 所有施工过程在各施工段流水节拍均相等。  
   source=`kc:1A433000_052_0077:0`；真题锚=`2015年第16题`
2. 🟢 相邻施工过程的流水步距相等，且等于流水节拍。  
   source=`kc:1A433000_052_0077:0`；真题锚=`2015年第16题`
3. 🟢 专业工作队数等于施工过程数。  
   source=`kc:1A433000_052_0077:0`；真题锚=`2015年第16题`
4. 🟢 各专业工作队连续作业，无空闲时间。  
   source=`kc:1A433000_052_0077:0`；真题锚=`2015年第16题`
5. 🔵 选择题陷阱：若选项说“不能连续作业”，应判断为错误表述。  
   真题锚=`2015年第16题`

### D. 等步距异节奏计算问法
1. 🟢 先判断：各施工过程流水节拍不完全相等，但存在倍数关系。  
   source=`kc:1A433000_053_0078:0`
2. 🟢 取流水步距 K 为各节拍的最大公约数。  
   source=`kc:1A433000_053_0078:1`
3. 🟢 说明因节拍不等，通过增加专业队数使其按相同步距推进。  
   source=`kc:1A433000_055_0083:0`
4. 🔵 计算专业队数：通常按各施工过程节拍除以 K 后求和表达。
5. 🔵 工期表达：结合施工段数、专业队数、流水步距和最后施工过程持续时间计算，并写出单位。

### E. 大差法计算问法
1. 🟢 列出各施工过程的累加数列。  
   source=`kc:1A433000_054_0081:0`
2. 🟢 将相邻施工过程累加数列错位相减。  
   source=`kc:1A433000_054_0081:0`
3. 🟢 取差值中的最大值作为流水步距。  
   source=`kc:1A433000_054_0081:0`
4. 🟢 各相邻过程步距求出后，再计算总工期。  
   source=`kc:1A433000_054_0081:0`
5. 🔵 书写要求：不要只写“大差法”，必须展示累加、错位、取大差三个动作。

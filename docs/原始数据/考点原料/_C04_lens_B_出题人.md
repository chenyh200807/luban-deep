## R2 不变量（一句话）

🟢 **模板拆除的合法性 = 「强度门槛（按构件类型×跨度查表 / 同条件养护试块达标）」AND「顺序门槛（后支先拆、先支后拆；非承重先拆、承重后拆）」AND「程序门槛（拆模申请→技术负责人批准）」三者同时成立——缺一即为「过早拆除 / 违章拆除」。**

> 锚定：强度门槛 `kc:1A413030_099_0185:0`（底模强度表）+ `kc:1A413030_099_0186:0`（侧模）；顺序门槛 `kc:1A413030_099_0187:0` / `kc:1A436000_116_0190:0`；程序门槛 `kc:1A436000_116_0190:1`、真题 {2016,案例2}。

### 一个不变量解释 ≥5 个场景

1. **跨度 8m 楼板 + 快拆体系，问最低拆模强度**（强度门槛：快拆取等效跨度 2m → 50%）→ 🟢{2015,第10题}。
2. **跨度 6m 板，问拆底模时同条件试块抗压强度值**（强度门槛：2<跨度≤8 → 75%，30×75%=22.5）→ 🟢{2021,第9题}。
3. **给四个构件选「达到底模拆除要求的」**（强度门槛全表辨析：板/梁拱壳/悬臂×跨度）→ 🟢{2024,第10题}。
4. **后张法预应力顶板，同条件试件达设计强度即口头申请拆底模 → 判不正确**（强度门槛≠唯一条件：底模须张拉后拆 + 试件达标 + 技术负责人批准 + 灌浆≥C30）→ 🟢{2016,案例2}。
5. **作业班组在板强度未达拆模标准下提前拆模 → 梁底出现夹渣/麻面 + 填表 A/B/C 百分率**（强度门槛违反的后果 + 查表）→ 🟢{2022,第(三)题}。
6. **满堂脚手架/顶板浇筑下「还可能出现哪些安全隐患」→「过早地拆除模板和支撑」**（顺序+程序门槛的安全侧表达）→ 🟢{2022,第3题}、{2022,第18页}。

## examiner_intent（出题人意图 / 常考形态 / 陷阱）

### 意图（这个考点真正要鉴别什么）
🟢 出题人要鉴别考生是否把「拆模」理解为**一个受多条件约束的工序门**，而不是「试块达标就能拆」的单一动作。核心鉴别点：**底模强度是「按构件类型 × 跨度」分档查表的，不是一个固定百分率**（`ca:1A413030_099_0185`），且**侧模 / 底模条件完全不同**（侧模只看表面棱角不受损，底模看抗压强度百分率）（`kc:1A413030_099_0186:0`）。预应力构件再叠加「底模须张拉后拆」这一隐藏条件（{2016,案例2}）。

### 常考形态
- 🟢 **形态A 单选·强度计算**：给跨度+设计等级+（可选快拆），算最低拆模强度 MPa/N·mm⁻²。设计强度×百分率。证据：{2015,第10题}{2021,第9题}。
- 🟢 **形态B 单选·全表辨析**：四个「构件×跨度×百分率」选哪个满足，逐项卡阈值。证据：{2024,第10题}。
- 🟢 **形态C 案例·填表**：给底模强度要求表挖空 A/B/C，填 50/75/100。证据：{2022,第(三)题}「'A'50;'B'75;'C'100」。
- 🟢 **形态D 案例·改错（程序+顺序+预应力）**：判「口头申请拆模 / 提前拆 / 全部拆除」之不妥，补前置条件。证据：{2016,案例2}。
- 🟢 **形态E 案例·安全隐患罗列**：浇筑/脚手架场景下答出「过早拆除模板和支撑」。证据：{2022,第3题}{2022,第18页}。
- 🟢 **关联形态 模板专项方案/起拱**：拆模条件常与「梁跨度 10m 编专项方案 / 18m 专家论证」「长度>4m 梁板按 1/1000~3/1000 起拱」同案出现。证据：{2015,案例1}。

### 陷阱（出题人最爱埋的坑）
1. 🟢 **跨度分档边界值**：8m 是梁/拱/壳的「≤8m→75%」与「>8m→100%」分界；板则 2m、8m 两档。{2024,第10题} D 项「悬臂梁 75%」是典型错——悬臂构件一律 100%（`kc:1A413030_099_0185:0`）。
2. 🟢 **快拆体系等效跨度**：8m 板用快拆，**按跨度 2m 取 50%** 而非按 8m 取 100%。{2015,第10题} 把 8m 当真实跨度即落坑。
3. 🟢 **侧模/底模混淆**：把「试块达标」套到侧模、或把「表面棱角不受损」套到底模。侧模看 `1N/mm²`（墙体大模板，常温）/ 表面棱角；底模看百分率表。（`kc:1A413030_099_0186:0`）
4. 🟢 **预应力底模的隐藏条件**：同条件试件达设计强度≠可拆底模；预应力梁/板底模**必须张拉后**拆，有灌浆者灌浆强度≥C30。{2016,案例2}。
5. 🟢 **程序坑**：「口头申请拆模」「现场生产经理申请」均不妥——须**填拆模申请、同条件试块达标、技术负责人批准**。（`kc:1A436000_116_0190:1`）
6. 🟢 **拆除方式坑**：楼板底模**不得无控制大片塌落**；拆模区设警戒线、下方禁站人、上下呼应。（`kc:1A436000_116_0190:2`/`:3`）

## R4 变量规则（封闭集 closed-set）

> 命题时只能在以下封闭枚举内取值；表中数值/原则均有教材或真题锚，禁外推未列项。

### V1 构件类型 × 跨度 × 底模拆除强度百分率（🟢 `kc:1A413030_099_0185:0`，真题校验 {2024,第10题}{2021,第9题}{2022,第(三)题}）
| 构件类型 | 跨度档 | 最低百分率 |
|---|---|---|
| 板 | ≤2m | 50% |
| 板 | 2m<跨度≤8m | 75% |
| 板 | >8m | 100% |
| 梁、拱、壳 | ≤8m | 75% |
| 梁、拱、壳 | >8m | 100% |
| 悬臂构件 | 任意 | 100% |

封闭：百分率仅 {50, 75, 100}；跨度断点仅 {2m, 8m}；构件类型仅 {板, 梁/拱/壳, 悬臂}。

### V2 模板部位 → 拆除判据（🟢 侧模 `kc:1A413030_099_0186:0`；底模 V1；墙体大模板 `ca:1A413030_099_0186`）
- 不承重侧模（梁/柱/墙侧模）：表面、棱角不因拆模受损即可拆。
- 墙体大模板（常温）：混凝土强度达 **1N/mm²** 即可拆。
- 承重底模及支架：按 V1 强度表。

### V3 拆除顺序原则（封闭二元，🟢 `kc:1A413030_099_0187:0` / `kc:1A436000_116_0190:0`）
- 后支先拆、先支后拆。
- 先拆非承重，后拆承重（含支架）。

### V4 快拆支架体系参数（🟢 `kc:1A413030_099_0187:0`，真题 {2015,第10题}）
- 立杆间距：**不应大于 2m**。
- 拆模时：保留立杆 + 顶托支承楼板；等效跨度按 2m → 强度取 **50%**。

### V5 预应力构件附加条件（🟢 {2016,案例2}；张拉/龄期锚 `kc:1A413030_105_0201:0`）
- 底模须 **预应力张拉后** 拆除。
- 拆除时强度符合同条件养护试件要求。
- 经项目技术负责人批准。
- 有孔道灌浆者，灌浆强度 **不应低于 C30**。
- （张拉门槛：施加预应力时混凝土强度≥设计值 **75%**；后张法梁龄期≥7d、板≥5d。）

### V6 程序与作业安全（封闭，🟢 `kc:1A436000_116_0190:1/:2/:3`、`kc:1A436000_115_0189:0`）
- 拆模前：填拆模申请 + 同条件养护试块强度达标 + **技术负责人批准**。
- 拆模区设警戒线、下方禁站人、传递上下呼应。
- 楼板底模 **禁无控制大片塌落**。
- 安装高度 >3.0m 必须搭脚手架（关联安装侧门槛）。

### V7 设计/方案前置（🟢 {2015,案例1}）
- 梁跨度 >10m：编模板工程专项施工方案；>18m：专家论证。
- 长度 >4m 的梁板：设计起拱；无要求时按跨度 **1/1000~3/1000** 起拱。

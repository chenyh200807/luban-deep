### 2. 地面石材、瓷砖：流程、预处理、空鼓防治

| 采分组 | 必采要点 | 锚定 |
|---|---|---|
| 石材施工流程 | 基层处理 → 放线 → 试拼 → 铺砂浆 → 铺石材 → 养护 → 勾缝。 | 🟢source：kc:1A413030_140_0272:0 |
| 石材预处理 | 大理石、花岗石铺设前浸湿、晾干，防止吸水导致空鼓。 | 🟢source：kc:1A413030_140_0272:1 |
| 浅色石材 | 浅色石材铺设宜用白水泥，避免灰色水泥影响观感。 | 🟢source：kc:1A413030_140_0272:2 |
| 石材勾缝 | 勾缝清晰、顺直、平整、光滑、深浅一致，缝色与石材颜色基本一致。 | 🟢source：kc:1A413030_140_0272:3 |
| 瓷砖流程 | 基层处理 → 放线 → 浸砖 → 铺砂浆 → 铺砖 → 养护 → 勾缝。 | 🟢source：kc:1A413030_140_0273:0 |
| 瓷砖浸砖 | 铺贴前清理脱模剂，必要时充分浸泡，然后阴干备用。 | 🟢source：kc:1A413030_140_0273:1 |
| 地面空鼓防治 | 基层清理干净；使用水泥基粘结材料；油性防护石材采用界面剂+背砂；大面积铺贴设伸缩缝；养护到位。 | 🟢source：kc:1A434000_078_0123:0 |
| 材料环境识别 | 大理石属于氡主要来源材料之一，遇材料环境质量题不要误判为油漆、复合地板、化纤地毯。 | 🟢真题锚：2016第16题 |
| 常见错因码 | 把“浸湿晾干/浸砖阴干”漏掉：E02；把空鼓只归因于“砂浆不好”而不写基层、养护、伸缩缝：E03/E10；凭经验乱写水灰比或材料：M10。 | 🟢source：deeptutor/contracts/error_codes.py |

### 3. 竹木地板、地毯：工序与细部尺寸

| 采分组 | 必采要点 | 锚定 |
|---|---|---|
| 竹木地板流程 | 基层处理 → 安装木搁栅 → 铺毛地板 → 铺设竹、木地板 → 成品保护。 | 🟢source：kc:1A413030_141_0274:0 |
| 毛地板开槽 | 整张毛地板应开槽；槽深为板厚1/3；方向与搁栅垂直；间距约200mm。 | 🟢source：kc:1A413030_141_0274:1 |
| 竹木地板铺设 | 靠墙第一块板离墙10mm；逐块排紧；接头按设计留置；由房间内向外铺设；无设计时宜顺光、顺主要行走方向。 | 🟢source：kc:1A413030_141_0274:2 |
| 地毯流程 | 基层处理 → 放线 → 地毯剪裁 → 钉倒刺板条 → 铺衬垫 → 铺设地毯 → 细部收口。 | 🟢source：kc:1A413030_141_0275:0 |
| 地毯细部尺寸 | 地毯裁剪长度比施工面长度大20mm；倒刺板条距踢脚8～10mm；衬垫离倒刺板约10mm。 | 🟢source：kc:1A413030_141_0275:1 |
| 地毯铺设方法 | 先固定一条长边，用撑子拉伸至平整，再拉另一方向；接长采用缝合或烫带粘结。 | 🟢source：kc:1A413030_141_0275:2 |
| 常见错因码 | 尺寸混淆：M08；把木地板、地毯、石材瓷砖工序混写：E07 概念混淆；只写“铺平整”不写倒刺板、衬垫、拉伸：E03。 | 🟢source：deeptutor/contracts/error_codes.py |

### 4. 门窗与基层：安装禁令、节能问题、基层含水率

| 采分组 | 必采要点 | 锚定 |
|---|---|---|
| 门窗安装禁令 | 在砌体上安装门窗严禁用射钉固定。 | 🟢source：kc:1A422000_043_0069:0 |
| 门窗节能问题 | 类型不符、传热系数超标、气密性差、中空玻璃露点高、可见光透射比不符。 | 🟢source：kc:1A434000_080_0129:0 |
| 节能查验范围 | 施工现场需查验墙体材料、保温材料、门窗、采暖制冷系统、照明设备；结构材料可不作为该题节能查验对象。 | 🟢真题锚：2016第20题 |
| 涂饰基层含水率 | 混凝土或抹灰基层：溶剂型涂料≤8%，乳液型涂料≤10%；木材基层≤12%。 | 🟢source：kc:1A422000_043_0069:1 |
| 厨卫找平层 | 厨房、卫生间墙面找平层应使用耐水腻子。 | 🟢source：kc:1A422000_043_0

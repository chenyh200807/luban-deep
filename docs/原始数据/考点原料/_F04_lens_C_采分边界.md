## R6 答案骨架

### 1. 阴阳角节点

🟢基层应坚实、平整，不得有浮浆、起砂、裂缝。阴角、阳角宜做圆弧处理；在卷材防水节点中，不应做成直角，可做成圆弧或 45 度角。  
锚定：`kc:1A413030_134_0257:0`；2015 案例2。

🟢阴阳角应先做附加层，再进行大面防水施工。附加层可夹铺胎体增强材料。  
锚定：`kc:1A413030_134_0257:1`；2016 第27题。

### 2. 管根 / 地漏 / 套管节点

🟢地漏、管道根部必须密封。穿楼板、穿墙管道的套管与管道之间，应采用防水密封材料嵌填压实。  
锚定：`kc:1A413030_133_0256:1`。

🟢防水套管应高出装饰面不小于 20mm。管根、地漏等部位应先做附加层。  
锚定：`kc:1A413030_133_0256:1`、`kc:1A413030_134_0257:1`。

### 3. 女儿墙泛水节点

🟢女儿墙泛水高度不足 250mm 时应判为错误，正确做法为泛水高度至少 250mm。  
锚定：2015 案例2；`kc:1A413030_133_0256:0`。

🟢女儿墙泛水处防水层下应增设附加层，附加层在平面和立面宽度均不小于 250mm。  
锚定：2015 案例2；`kc:1A413030_125_0237:1`。

🟢卷材收头应采用金属压条钉压固定，并用密封材料封严。  
锚定：2015 案例2；`kc:1A422000_042_0066:0`。

🟢压顶檐口下端应做鹰嘴和滴水槽；女儿墙、山墙压顶向内排水坡度不小于 5%。  
锚定：2015 案例2；`kc:1A413030_125_0237:0`、`kc:1A422000_042_0066:0`。

### 4. 满分组织句

🟢满分答案可按以下句式组织：

> 防水细部应先处理节点再施工大面。阴阳角基层应做圆弧或 45 度角，并先做附加层；管根、地漏、套管周边应密封，套管与管道间用防水密封材料嵌填压实，防水套管高出装饰面不小于 20mm；女儿墙泛水高度不小于 250mm，泛水处附加层平面和立面宽度均不小于 250mm，卷材收头用金属压条钉压固定并用密封材料封严，压顶檐口下端做鹰嘴和滴水槽，压顶向内排水坡度不小于 5%。

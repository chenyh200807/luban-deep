## R6 答案骨架

### 题型A：问“饰面板工程施工质量控制要点”

满分答法：

1. 先说材料与做法分类：饰面板包括石材、瓷板、金属、木质、玻璃、塑料饰面板；石材墙柱面可采用干挂法、干粘法、湿贴法。🟢 `kc:1A413030_144_0279:0` `kc:1A413030_144_0279:3`
2. 再说施工准备：后置埋件拉拔力应合格；湿作业石板应防碱封闭；金属板防雷装置应与主体结构可靠接通。🟢 `kc:1A413030_144_0279:1`
3. 再说材料复验：重点复验放射性、甲醛释放量、粘结强度、吸水率、抗冻性等对应项目。🟢 `kc:1A413030_144_0279:2`
4. 最后说石材细部：干挂法需工厂加工挂件，石材需六面防护；湿贴石材需铲除背网。🟢 `kc:1A413030_144_0279:3`

易错归因码候选：`E02` 采分点遗漏；`E07` 概念混淆；`E10` 规范适用错误；`M08` 规范数字混淆。

### 题型B：问“饰面砖工程复验与粘贴工艺”

满分答法：

1. 复验项目：室内瓷质砖放射性、水泥基粘结材料与外墙砖拉伸粘结强度、外墙陶瓷砖吸水率、严寒寒冷地区外墙砖抗冻性。🟢 `kc:1A413030_145_0280:0`
2. 粘贴前：排砖、分格、弹线。🟢 `kc:1A413030_145_0280:1`
3. 粘贴中：粘结剂厚度3~8mm；允许调整期内可微调位置。🟢 `kc:1A413030_145_0280:1`
4. 超过调整期：严禁振动。🟢 `kc:1A413030_145_0280:1`
5. 填缝：先水平后垂直。🟢 `kc:1A413030_145_0280:1`

易错归因码候选：`E02` 采分点遗漏；`E06` 程序顺序错误；`E10` 规范适用错误；`M08` 规范数字混淆。

### 题型C：问“地面铺贴空鼓原因与防治措施”

满分答法：

1. 原因从基层、材料、界面、变形、养护五类展开。
2. 基层方面：基层清理不干净，影响粘结，应清理干净。🟢 `kc:1A434000_078_0123:0`
3. 材料方面：应使用水泥基粘结材料。🟢 `kc:1A434000_078_0123:0`
4. 石材防护方面：油性防护石材应采用界面剂+背砂处理。🟢 `kc:1A434000_078_0123:0`
5. 大面积铺贴方面：应设置伸缩缝，释放变形。🟢 `kc:1A434000_078_0123:0`
6. 养护方面：铺贴后养护到位，避免早期扰动或失水。🟢 `kc:1A434000_078_0123:0`
7. 可补充邻接原理：石材铺设前浸湿、晾干；瓷砖铺贴前清理脱模剂，必要时浸泡并阴干。🔵 `kc:1A413030_140_0272:1` `kc:1A413030_140_0273:1`

易错归因码候选：`E02` 采分点遗漏；`E07` 概念混淆；`E11` 迁移失败；`M10` 用常识替代规范判断。

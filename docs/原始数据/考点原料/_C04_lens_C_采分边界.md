# C04 模板拆除顺序与条件｜R5-R7 镜头

## R5 采分点

### 采分点1：先判模板类型，再判拆除条件
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A413030_099_0186:0`
- 侧模属于“不承重侧模板”，拆除条件不是按跨度强度表，而是保证混凝土表面、棱角不因拆模受损。
- 墙体大模板在常温下，混凝土强度达到 `1N/mm²` 即可拆除。
- 易错码：`E07` 概念混淆、`E10` 规范适用错误。

### 采分点2：底模及支架拆除要按构件类型和跨度套强度比例
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A413030_099_0185:0`
- 板类构件：  
  `≤2m → ≥50%`；`2m<跨度≤8m → ≥75%`；`>8m → ≥100%`
- 梁、拱、壳：  
  `≤8m → ≥75%`；`>8m → ≥100%`
- 悬臂构件：  
  `≥100%`
- 易错码：`M08` 规范数字混淆、`M09` 题干条件提取不完整。

### 采分点3：拆除顺序是“后支先拆、先支后拆；非承重先拆、承重后拆”
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A413030_099_0187:0`
- 顺序句必须成对出现：  
  后支先拆、先支后拆；先拆非承重部分，后拆承重部分。
- 这类题如果只写“从上到下拆”“按施工方案拆”，表达偏空，采分风险高。
- 易错码：`E06` 程序顺序错误、`E04` 口号化表达。

### 采分点4：快拆支架体系要抓住“立杆间距≤2m、保留立杆顶托”
- 🟢锚定｜source=教材锚源料｜point_id=`kc:1A413030_099_0187:0`
- 快拆支架体系的支架立杆间距不应大于 `2m`。
- 拆模时应保留立杆并顶托支承楼板。
- 若题干满足快拆条件，拆模强度可按保留支撑后的计算跨度判断。
- 🟢真题锚｜2015年第10题：跨度8m楼板、C30、快拆支架立杆间距2m，最低拆模强度取 `C30×50%=15MPa`。
- 易错码：`M09` 题干条件提取不完整、`M10` 用常识替代规范判断。

## R6 答案骨架

### 满分答题骨架

1. 先判断模板对象：  
   🟢若是侧模，按“表面和棱角不受损”判断；墙体大模板常温可抓 `1N/mm²`。  
   source=`kc:1A413030_099_0186:0`

2. 再写拆除顺序：  
   🟢模板拆除一般按“后支先拆、先支后拆；先拆非承重部分，后拆承重部分”。  
   source=`kc:1A413030_099_0187:0`

3. 若涉及底模或支架，必须补强度条件：  
   🟢底模及支架按“构件类型 + 跨度”达到设计混凝土立方体抗压强度标准值的规定比例后拆除。  
   source=`kc:1A413030_099_0185:0`

4. 若涉及快拆支架体系，单独写快拆条件：  
   🟢支架立杆间距不应大于 `2m`；拆模时保留立杆并顶托支承楼板。  
   source=`kc:1A413030_099_0187:0`

5. 若题目给出混凝土强度等级，最后换算成 MPa：  
   🟢例如 2015年第10题：C30 快拆楼板满足按2m跨度取 `50%`，最低强度为 `30×50%=15MPa`。

### 镜头口播骨架

- 🔵工程通识：拆模板不是“混凝土硬了就拆”，而是先分清它是不是承重模板。
- 🟢侧模看棱角，底模看跨度强度表。
- 🟢顺序记成一句话：后支先拆、先支后拆；非承重先拆、承重后拆。
- 🟢快拆题的关键不是原跨度多大，而是有没有保留立杆顶托，且立杆间距是否不大于2m。

## R7 边界候选

### 满分边界候选
- 🔴待真人/专家裁决：答案同时写出“后支先拆、先支后拆；非承重先拆、承重后拆”，并能区分侧模、底模、快拆支架三类条件。
- 🔴待真人/专家裁决：快拆题中写明“立杆间距≤2m、保留立杆并顶托支承楼板”，并能按 `设计强度×规定比例` 算出最低强度。
- 🔴待真人/专家裁决：涉及底模时，不只写百分率，还能说明百分率取决于构件类型和跨度。

### 压线边界候选
- 🔴待真人/专家裁决：只写出拆除顺序，但没有展开底模强度表，若题目主要问“顺序”，可能压线；若题目问“条件”，分数风险高。
- 🔴待真人/专家裁决：只写“达到设计强度一定比例后拆除”，但没有根据板、梁、悬臂或跨度确定比例，可能只能给少量表达分。
- 🔴待真人/专家裁决：快拆题只写“按2m跨度计算”，但漏写“保留立杆顶托”，可能被认为关键条件不完整。

### 0分 near-miss 候选
- 🔴待真人/专家裁决：把侧模 `1N/mm²` 条件套到所有模板，写成“所有模板达到1N/mm²即可拆除”。
- 🔴待真人/专家裁决：写成“先拆承重、后拆非承重”，顺序反了。
- 🔴待真人/专家裁决：快拆支架题仍按原构件8m跨度取 `75%` 或 `100%`，完全忽略保留立杆顶托条件。
- 🔴待真人/专家裁决：只答“按施工方案拆除”，没有任何顺序、强度或快拆条件，属于口号化表达。

## R2 不变量（一句话解释，覆盖 ≥5 场景）

**不变量**：钢筋连接选用 = 用「直径 × 受力性质 × 荷载性质 × 部位/抗震要求」四个输入，去匹配「绑扎搭接 / 机械连接 / 焊接」三种方式之一；越是大直径、受拉、承受动力荷载、抗震关键部位，越往"机械连接(直螺纹套筒)"端走，越是小直径、受压、静载、非关键部位，才允许往"绑扎搭接"端退。代换则是同一根不变量的逆运算：换钢筋时强度/面积守恒 + 构造守恒 + 设计单位同意。

> 🟦 教材锚 `kc:1A413030_100_0190:0`：钢筋连接分为焊接、机械连接和绑扎连接三种，其中机械连接以剥肋滚压直螺纹套筒连接最为常用。
> 🟦 教材锚 `kc:1A413030_099_0189:0`：钢筋代换分为等强度代换和等面积代换；强度控制用等强度，最小配筋率/同钢号用等面积，裂缝/挠度控制需验算，且必须经设计单位同意并满足构造要求。

### 同一不变量覆盖的 ≥5 个场景

| # | 场景 | 输入 → 选用结论 | 锚 |
|---|---|---|---|
| S1 | 动力荷载 + 中等直径受力筋 | 直接承受动力荷载、Φ20 纵向受力钢筋 → **宜机械连接(直螺纹套筒)**，避开焊接热影响区，绑扎只适用小直径 | 🟥 `{2019, 第8题}` |
| S2 | 受压 + 中小直径 → 允许退到绑扎 | 受压、Φ25 → **可绑扎搭接**；受拉Φ28 / 桁架拉杆 / 行车梁受力筋 → **不宜绑扎** | 🟥 `{2022, 第14题}` |
| S3 | 装配式竖向连接 + 抗震部位 | 一二级抗震底部加强区竖向钢筋 → **宜套筒灌浆**；边缘构件逐根连接 | 🟦 `kc:1A411011_036_0063:2` |
| S4 | 钢筋代换（设计/构造守恒） | 受力钢筋代换基本要求 = 等强度 + 等面积 + 满足构造要求（**等刚度不是基本要求**） | 🟥 `{2025, 第27题}` |

| S6 | 接头施工质量（选用的下游约束） | 直螺纹接头加工精度用通规/止规/量规检测，直尺不行 | 🟥 `{2017, 第19题}` |
| S7 | 套筒灌浆的验收口径 | 灌浆料试件：每工作班1组、每层≥3组、40×40×160mm 长方体、标养28d | 🟥 `{2022, 第28题}` |

## examiner_intent（出题人到底在考什么）

出题人**从不直接问"哪种连接好"**，而是给一组约束条件，逼考生跑一遍"输入→匹配"的决策。命题意图分三层：

1. **正向选用（送分到陷阱）**：给定直径+受力+荷载，问"宜选用/宜采用"。
   - 陷阱设计：把"焊接"伪装成动力荷载下的可选项（实则热影响区不利）；把"绑扎"塞给大直径/受拉/桁架拉杆/动力构件（实则不宜）。
   - 🟥 `{2019, 第8题}` 用 B 直螺纹套筒做正解，C/D 焊接、A 绑扎全是按"端点规则"反向设的诱饵。
   - 🟥 `{2022, 第14题}` 口诀"拉25、压28、不宜绑扎"——出题人专挑临界直径与受力性质组合制造混淆。

2. **代换守恒（多选题主场）**：把"设计要求"与"构造要求"两套清单混排，考生必须能区分谁守恒、谁验算。
   - 🟥 `{2025, 第27题}`：用"等刚度代换"做唯一干扰项，测是否背死"等强度/等面积/构造"三要求。
   - 🟥 `{2020, 第22题}`：把"裂缝宽度验算/配筋率"（设计要求）混进"构造要求"选项，考边界。

3. **选用的下游闭环（接头质量/验收）**：选了某种连接后，对应的检测与验收数值能不能跟上。
   - 🟥 `{2017, 第19题}` 检具识别；🟥 `{2022, 第28题}` 灌浆料试件数量/尺寸/养护。

> 🟩 推理：本考点的"难"不在记三种方式，而在**端点判断 + 守恒辨析**。出题人偏爱的失分点是"把端点搞反"（小直径规则误用到大直径/动力构件）和"守恒类别错配"（把验算类当守恒类）。

## R4 变量规则（封闭：输入域 + 联动正解，禁开放编造）

> 封闭含义：下列变量只能在给定枚举域内取值；正解由规则机械推出，不依赖题外新增事实。所有阈值均来自真题锚或教材锚，**不得新造数值**。

### V1 连接方式选用规则（决定 R3-1/R3-2 正解）

输入域：
- `direction ∈ {受拉, 受压}`
- `load ∈ {静载, 动力荷载}`
- `member ∈ {一般构件, 桁架拉杆, 行车梁, 装配式竖向}`
- `diameter`：以临界点切分 → `小直径(可绑扎档)` / `≥受拉28 或 ≥受压…大直径档`

规则（封闭联动）：
1. `load=动力荷载` → 正解 = **机械连接(直螺纹套筒)**；排除焊接(热影响区)、排除绑扎。🟥 `{2019, 第8题}`
2. `member ∈ {桁架拉杆, 行车梁}` 或 `direction=受拉且大直径(如Φ28)` → **不宜绑扎搭接**。🟥 `{2022, 第14题}`
3. `direction=受压 且 中等直径(如Φ25)` → **可绑扎搭接**（端点退档允许）。🟥 `{2022, 第14题}`
4. `member=装配式竖向 且 抗震一二级底部加强区` → **宜套筒灌浆**；边缘构件逐根连接，非边缘区间距≤600mm。🟦 `kc:1A411011_036_0063:2`

> 🟩 口诀（仅作记忆，不引入新事实）："拉25、压28、不宜绑扎"——区分临界直径与受力性质，来源 🟥 `{2022, 第14题}` 解析。

### V2 代换守恒规则（决定 R3-3/R3-4 正解）

- `基本要求 = {等强度代换, 等面积代换, 满足构造要求}`；`等刚度代换 ∉ 基本要求`（固定干扰项）。🟥 `{2025, 第27题}`
- `代换类型选择`：强度控制→等强度；最小配筋率/同钢号→等面积；裂缝/挠度控制→需验算；且**须设计单位同意**。🟦 `kc:1A413030_099_0189:0`
- `构造要求清单(封闭) = {搭接长度, 锚固长度, 保护层厚度, 钢筋间距, 最大配筋率}`；`{裂缝宽度验算, 配筋率(承载力)} = 设计要求(干扰项)`。🟥 `{2020, 第22题}`

> 🟩 辨析口诀（来源解析 🟥 `{2020, 第22题}`）："长宽抗展承载力=设计要求；长厚面积小间距=构造要求"。

### V3 选用下游验收规则（决定 R3-6 正解，封闭枚举）

- 直螺纹接头加工精度检具 = `{通规, 止规, 量规}`；`直尺 ∉ 检具`（固定错项）。🟥 `{2017, 第19题}`
- 套筒灌浆料强度试件 = `{每工作班1组, 每层≥3组, 40mm×40mm×160mm长方体, 标养28d}`；干扰项=`{边长70.7mm立方体, 同条件养护}`。🟥 `{2022, 第28题}`

### V4 接头位置/构造数值（案例改错锚，封闭，禁加新值）

- 柱钢筋接头距地面 `≥500mm`、`≥H/6`、`≥b`（取最大值）；箍筋接头交错、绑扎成八字形。🟦 `kc:1A413030_100_0190:2`
- 冷拉率：HPB300 `≤4%`，HRB400/HRB500 `≤1%`。🟦 `kc:1A413030_100_0190:1`

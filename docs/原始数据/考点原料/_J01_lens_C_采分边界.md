# J01 镜头：危大工程范围 + 专项方案 + 专家论证

## R6 答案骨架

### 1. 判定一句话

🟢 先按工程参数判断是否属于危大工程；若达到“超过一定规模”阈值，再进入专家论证程序。  
🔵 答题时不要直接说“要专家论证”，应先写清楚是哪一个参数触发了危大或超规模。

### 2. 范围识别

🟢 危大工程常见判定参数包括：基坑开挖深度≥3m、模板搭设高度≥5m、起重吊装单件重量≥10kN、脚手架搭设高度≥24m。来源：`kc:1A436000_008_0011:0`。  
🟢 超过一定规模常见判定参数包括：深基坑开挖深度≥5m；模板支撑高度≥8m、跨度≥18m、荷载≥15kN/m²或线荷载≥20kN/m。来源：`kc:1A436000_009_0012:0`。  
🟢 真题锚：`2015案例3`要求补充单独编制专项方案的清单，答案包括深基坑支护、降水、土方开挖、模板工程及支撑体系、建筑幕墙安装工程。

### 3. 专项方案

🟢 实行施工总承包的，专项方案由施工总承包单位组织编制；专业工程分包的，起重机械安装拆卸、深基坑、附着式升降脚手架等专项方案可由专业承包单位组织编制。来源：`cc:1A436000_008_0011:3`、`cc:1A436000_008_0011:4`。  
🟢 基坑专项方案应写八项：工程概况、编制依据、施工计划、施工工艺技术、施工保证措施、施工管理及人员配备、验收要求、应急处置措施。来源：`kc:1A431000_008_0008:0`。  
🟢 模板支撑专项方案应写：工程概况、技术参数、工艺流程、施工方法、检查要求、计算书及相关施工图纸。来源：`kc:1A431000_009_0009:0`。  
🟢 真题锚：`2015案例1`答案区分“只需编制模板工程专项施工方案”和“需要专家论证”的跨度条件。

### 4. 审核、审查、论证

🟢 专家论证前，专项施工方案应先通过施工单位审核和总监理工程师审查。来源：`cc:1A437000_010_0013:3`。  
🟢 超过一定规模的危大工程，施工单位应组织召开专家论证会；实行施工总承包的，由施工总承包单位组织召开。来源：`cc:1A437000_010_0013:1`、`cc:1A437000_010_0013:2`。  
🟢 专家不少于5人，且不得与工程有利害关系；论证报告需签字确认。来源：`kc:1A437000_010_0013:0`、`ca:1A437000_010_0013`。

### 5. 实施控制

🟢 专项方案实施前，编制人员或项目技术负责人应向施工现场管理人员进行方案交底。来源：`cc:1A436000_010_0011:2`。  
🟢 施工单位应严格按专项施工方案组织施工，不得擅自修改专项施工方案。来源：`cc:1A436000_010_0011:3`。  
🔵 若题目问“修改方案”，答题应顺着“重新审核、必要时重新论证、不得擅自修改”的程序逻辑展开，不要只写“经批准即可”。

## R7 边界候选

| 类型 | 候选边界 | 判定 |
|---|---|---|
| 满分候选 | 🔴待真人/专家裁决：能按“范围判定 → 专项方案编制主体 → 审核/总监审查 → 专家论证 → 实施交底与不得擅改”完整作答，并写出关键阈值和主体。 | 🔴候选 |
| 满分候选 | 🔴待真人/专家裁决：案例题中能从背景条件抽出具体工程，如8m基坑、幕墙、模板支撑等，再对应写“应单独编制专项方案”。 | 🔴候选 |
| 压线候选 | 🔴待真人/专家裁决：只写“属于危大工程，应编专项方案”，但漏掉部分参数或漏写总包/专业承包主体，可能只能得范围识别分。 | 🔴候选 |
| 压线候选 | 🔴待真人/专家裁决：写出“专家不少于5人、无利害关系”，但漏写“施工单位审核、总监审查在论证前”，程序分可能不足。 | 🔴候选 |
| 0分 near-miss | 🔴待真人/专家裁决：把“危大工程”直接等同于“必须专家论证”，没有区分一般危大与超过一定规模危大。 | 🔴候选 |
| 0分 near-miss | 🔴待真人/专家裁决：把建设单位、监理单位写成专项方案或专家论证组织主体，混淆施工单位/总包单位职责。 | 🔴候选 |
| 0分 near-miss | 🔴待真人/专家裁决：只写安全口号，如“加强管理、注意安全、专家审核”，没有阈值、主体、程序和方案内容。 | 🔴候选 |
| 0分 near-miss | 🔴待真人/专家裁决：擅自引入证据外年份题号或把未给出的真题说成真题锚。 | 🔴候选 |

## 错因码建议

- `E02`：采分点遗漏，如漏专项方案内容、漏专家论证前置程序。
- `E06`：程序顺序错误，如先论证后审核，或漏“施工单位审核 + 总监审查”。
- `E07`：概念混淆，如混淆危大工程与超过一定规模危大工程。
- `E08`：背景信息提取失败，如案例中漏识别8m基坑、幕墙、模板支撑等条件。
- `E10`：规范适用错误，如把所有危大工程都判为必须专家论证。
- `E11`：迁移失败，如会背阈值但不能迁移到案例清单补全。
- `M08`：规范数字混淆，如3m/5m、5m/8m、18m、15kN/m²、20kN/m混淆。
- `M10`：用常识替代规范判断，如只凭“危险”判断是否专家论证。

# 镜头：双代号网络计划关键线路/总时差

## 误区解析

### 误区1
- **现象**：认为所有工作都必须在关键线路上。
- **错误心智模型**：学生可能误以为只有关键线路上的工作才是重要的，忽略了非关键工作的调整对整体进度的影响。
- **对症解药**：理解关键线路是决定项目总工期的路径，但非关键工作也有其重要性。通过调整非关键工作的时间可以优化资源分配和提高效率。（E03）

### 误区2
- **现象**：将总时差为零的工作等同于关键工作。
- **错误心智模型**：学生可能认为只要总时差为零的工作就是关键工作，而忽视了其他因素如自由时差。
- **对症解药**：明确关键工作不仅要求总时差最小，还应考虑其在网络图中的位置和影响。关键工作通常位于关键线路上。（E04）

### 误区3
- **现象**：认为一旦确定了关键线路就不能再调整。
- **错误心智模型**：学生可能认为关键线路一旦确定就固定不变，忽略了实际施工过程中可能出现的变化。
- **对症解药**：强调关键线路会随着项目的进展和实际情况的变化而变化。定期监测和调整是必要的。（M02）

### 误区4
- **现象**：忽略非关键工作的总时差。
- **错误心智模型**：学生可能只关注关键工作，而忽略了非关键工作的总时差。
- **对症解药**：了解非关键工作的总时差可以帮助更好地安排资源和时间，避免不必要的延误。（E05）

### 误区5
- **现象**：认为所有工作的总时差都是固定的。
- **错误心智模型**：学生可能认为总时差是一个静态值，不会随项目进展而变化。
- **对症解药**：解释总时差是动态的，会随着项目的进展和实际完成情况发生变化。定期更新网络图以反映最新情况。（E06）

### 误区6
- **现象**：不理解关键线路与计算工期的关系。
- **错误心智模型**：学生可能混淆关键线路的工期与整个项目的计算工期。
- **对症解药**：明确关键线路的工期等于网络计划的计算工期，这是确定项目总工期的重要依据。（kc:1A433000_056_0085:1）

### 误区7
- **现象**：认为关键线路只能有一条。
- **错误心智模型**：学生可能认为一个网络图中只能有一条关键线路。
- **对症解药**：解释一个网络图中可能存在多条关键线路，每条关键线路的工期都等于计算工期。（E07）

### 误区8
- **现象**：忽略逻辑关系的重要性。
- **错误心智模型**：学生可能只关注工作的时间参数，而忽略了逻辑关系。
- **对症解药**：强调逻辑关系是网络图的基础，正确绘制逻辑关系才能准确计算关键线路和总时差。（E08）

## 动画分镜原料

### 视觉隐喻
- **网络图**：用节点和箭头表示工作和逻辑关系。
- **关键线路**：用红色高亮显示关键线路。
- **总时差**：用不同颜色的条形图表示每个工作的总时差。

### Reveal顺序
1. **展示初始网络图**：显示所有工作及其逻辑关系。
2. **识别关键线路**：逐步高亮显示关键线路。
3. **计算总时差**：逐个显示每个工作的总时差。
4. **调整网络图**：模拟实际施工过程中的调整，展示关键线路的变化。
5. **总结**：强调关键线路和总时差的重要性及动态特性。

### Aha时刻
- **关键线路高亮**：当关键线路被高亮显示时，学生会意识到关键线路的重要性。
- **总时差变化**：当总时差随着项目进展而变化时，学生会理解总时差的动态特性。
- **调整后的网络图**：当网络图经过调整后，学生会看到关键线路的变化，从而理解关键线路的动态性。

### 旁白锚点
- **关键线路**：关键线路是由全部关键工作组成的线路，其工期等于网络计划的计算工期。（kc:1A433000_056_0085:1）
- **总时差**：总时差是动态的，会随着项目的进展和实际完成情况发生变化。
- **逻辑关系**：逻辑关系是网络图的基础，正确绘制逻辑关系才能准确计算关键线路和总时差。（kc:LEC_1A433000_P0018_001:0）

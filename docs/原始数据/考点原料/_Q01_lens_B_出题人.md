## 一、R2 不变量（一句话 + ≥5 场景解释）

**R2 不变量（一句）**：
> **混凝土的裂缝防治，本质是“在它最脆弱的早龄期，把内部温度梯度与失水收缩压在材料当时能承受的范围内”——养护就是用时间、湿度、温差三个旋钮，让强度增长跑赢收缩与温度拉应力。** 🟢

**这一条不变量如何贯穿 ≥5 个不同场景**：

1. **普通现浇构件养护时长** 🟢`kc:1A413030_104_0197:0`（1A413040-R28）
   硅酸盐/普硅水泥 ≥7d，掺缓凝/有抗渗要求/C60 及以上 ≥14d。旋钮=“时间×湿度”，水化未充分时强度跑不赢收缩，故抗渗类延到 14d。真题印证 🟢真题{2022·第15题}（D 抗渗≥14d 正确）。

2. **大体积混凝土温控** 🟢`kc:1A413030_096_0181:0`（1A413033-R07）
   里表温差 ≤25℃、降温速率 ≤2.0℃/d、温升 ≤50℃、保湿养护 ≥14d、拆保温时温差 ≤20℃。旋钮=“温差”，大体积内部水化热高，温度梯度才是主拉应力来源。真题印证 🟢真题{2017·第10题}（降温速率不宜大于 2℃/d）。

3. **防水/抗渗混凝土养护** 🟢`kc:1A413030_131_0250:2`（1A413050-R23）
   养护 ≥14d、后浇带 ≥28d、高温期入模温 ≤30℃、宜用低水化热水泥+缓凝剂+粉煤灰。任何裂缝都破坏抗渗，故湿度旋钮拧到最满（≥14d）。真题印证 🟢真题{2015·第26题}（养护时间不少于 7 天为**错**，应 14d）。

4. **后浇带封闭与养护** 🟢`kc:1A413030_103_0196:1`（1A415041-E01）
   微膨胀混凝土、强度提高一级、养护 ≥14d；后浇带本就是“主动留缝放收缩”的工程化手段，是不变量的逆向应用——先让两侧充分收缩，再补强补浇。真题印证 🟢真题{2018·案例三·问题3}（基础底板后浇带 10d 后封闭为错，应 ≥28d）。

5. **冬期施工养护** 🟢真题{2019·第1题}（综合蓄热法）
   中心与表面温差 ≤25℃、表面与大气温差 ≤20℃、温降梯度 ≤3℃/d、养护 ≥14d。低温下旋钮=“温差+保温”，防的是内外温差冻裂与早期受冻。

6. **拆模时机（养护的强度门槛侧）** 🟢真题{2021·第9题}
   跨度 6m、C30 板拆底模需同条件养护试块达 ≥75%设计强度（22.5N/mm²，选 C）。拆模过早=强度未跑赢自重荷载，本质仍是“强度增长 vs 受力”同一旋钮。

7. **裂缝控制等级（设计-施工接口）** 🟢`kc:1A411011_032_0057:0`（1A411030-R40）/ `kc:1A411011_025_0047:2`（1A412012-E01）
   不允许裂缝→控拉应力 ≤ftk；允许裂缝→控宽度 ≤限值。说明“防裂”不是一刀切，而是按构件性质给不同阈值——养护是把施工侧的实际状态压进设计设定的阈值内。

## 二、examiner_intent（出题人意图 / 常考形态 / 陷阱）

### 2.1 出题人意图
- **核心意图**：考“数值阈值的记忆 + 区分”，而非定性理解。出题人反复用**相近数字的混淆**（7d/14d/28d、2℃/3℃、25℃/20℃）来筛掉“背了但没分清适用条件”的考生。🟢（由 2015/2017/2018/2019/2022 多年命中归纳）
- **第二意图**：考“适用条件绑定”——同一个动作（养护时长、拆模、入模温）在普通/大体积/防水/冬期四种语境下阈值不同，出题人专挑**语境与阈值错配**。🟢`kc:1A413030_104_0197:0`
- **第三意图（案例题）**：在“施工不妥之处改正”里埋养护缺陷，考生须**识别+给出正确数值**双步得分。🟢真题{2016·案例二}、{2018·案例三}、{2019·第1题}

### 2.3 陷阱（trap_alert）
1. **7d vs 14d 张冠李戴**：普硅 ≥7d，但“有抗渗要求/C60+/后浇带”必须 ≥14d。🟢{2022·第15题 D}、{2015·第26题 D}（题干给 7d 即为错项）。
2. **降温速率 2℃/d（大体积·施工标准）≠ 冬期温降梯度 3℃/d**：两个数字常被互换设错。🟢{2017·第10题}=2℃/d；🟢{2019·第1题}冬期=3℃/d。
3. **后浇带封闭时间**：普通后浇带养护 ≥14d，但**封闭时机** ≥42d（沉降后浇带）/底板 ≥28d——题干给“10d 后封闭”是经典错项。🟢{2018·案例三·问题3}
4. **里表温差 25℃ vs 表面-大气 20℃**：大体积里表 ≤25℃，拆保温/冬期表面与大气 ≤20℃，方向写反即丢分。🟢`kc:1A413030_096_0181:0`、{2019·第1题}
5. **拆模强度按“同条件养护试块”而非标养**：{2021·第9题}陷阱在“同条件”三字，跨度>8m 与 ≤8m 阈值不同（≥75% vs ≥100%）。🟢{2021·第9题}
6. **“一遍成活/一次成型”防水做法**：防水砂浆/防水层应多层抹压，题干给“一遍成活”即错。🟢{2017·案例一}、{2022·第16题 A}

## 四、R4 变量规则（封闭集 — 出题人可调的“变量旋钮”及其取值域）

> 封闭：每个变量给出**互斥且穷尽**的取值，答案随取值切换。所有阈值均带锚。

### V1 · 养护时间（按混凝土类别）🟢`kc:1A413030_104_0197:0`
- 硅酸盐/普通硅酸盐水泥拌制 → **≥7d**
- 掺缓凝型外加剂 / 有抗渗要求 / C60 及以上 → **≥14d**
- 后浇带 → **≥14d（养护）**
- 大体积混凝土 → **按温控方案定（保湿 ≥14d）** 🟢`kc:1A413030_096_0181:0`
（真题切换示例：{2022·第15题}抗渗→14d ✔；{2015·第26题}防水给 7d→错）

### V2 · 大体积温控指标 🟢`kc:1A413030_096_0181:0`
- 里表温差 → **≤25℃**
- 降温速率 → **≤2.0℃/d**（🟢{2017·第10题}）
- 温升值 → **≤50℃**
- 入模温度 → **5～30℃**
- 拆保温时表面与大气温差 → **≤20℃**

### V3 · 冬期养护指标 🟢真题{2019·第1题}
- 中心-表面温差 → **≤25℃**
- 表面-大气温差 → **≤20℃**
- 温降梯度 → **≤3℃/d**
- 养护时间 → **≥14d**

### V4 · 拆底模强度门槛（同条件养护试块，按跨度）🟢真题{2021·第9题}
- 板/拱跨度 ≤2m → **≥50%设计强度**
- 板跨度 >2m 且 ≤8m / 梁拱 ≤8m → **≥75%**
- 跨度 >8m → **≥100%**
（{2021·第9题}：6m 板 C30 → 75%×30=22.5N/mm²）

### V5 · 后浇带（封闭时机 / 材料）🟢`kc:1A413030_103_0196:1`、`kc:1A413030_131_0250:2`
- 材料 → **微膨胀（补偿收缩）混凝土，强度提高一级**
- 养护 → **≥14d**
- 底板后浇带封闭 → **≥28d**（🟢{2018·案例三·问题3}）
- 防水设防措施 → **不应少于 1 种** 🟢`kc:1A413030_130_0248:1`

### V6 · 裂缝控制等级（设计阈值）🟢`kc:1A411011_025_0047:2`、`kc:1A411011_032_0057:0`
- 一级（预应力）→ **不出现拉应力**
- 二级 → **有拉应力但 ≤抗拉强度 ftk**
- 三级 → **允许裂缝，宽度 ≤规范限值**

### V7 · 防水混凝土施工旋钮 🟢`kc:1A413030_130_0249:1`、`:2`
- 水胶比 → **≤0.50（有侵蚀性 ≤0.45）**
- 分层浇筑厚度 → **≤500mm**
- 抗渗等级 → **≥P6，试配比设计高 0.2MPa**

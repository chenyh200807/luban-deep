## 原理因果层（可讲逻辑链）

### 成因——施工现场为什么“必须死磕这些数字”？

1. **空间成因**：施工现场用地紧张，材料、人员、机械高密度共存。一旦布局失当，**二次搬运浪费**吃掉工期利润，**消防通道不畅**直接剥夺逃生窗口（🔵 通识）。
2. **能量成因**：木材、油漆、保温材料=高蓄能可燃物。电气线缆/碘钨灯/明火作业=高能引火源。两者在空间上耦合=火灾爆炸潜势（🟢 教材锚: 2015·30易/爆需分离）。
3. **管理成因**：临时设施“用完即拆”易被轻视。但**临设标准上升为强条**正是因为统计数据证明：70%以上施工火灾起因于临时区域失控（🔵 工程通识）。

---

### 机理——火灾/坍塌风险如何从“布局失误”中被放大？

```
布局错误 ──────────────────────────→ 灾害后果
   │
   ├─ 仓库远离使用点 → 二次搬运多 → 暴露在通道时间↑ → 碰撞/倾倒风险↑
   │
   ├─ 易燃库设上风向 → 一旦起火，烟气/火焰顺风覆盖作业区、宿舍区
   │    └─ 真题教训：2015·30 D选项恰考此点 (上风✗ 下风✓) 【🟢 真题锚】
   │
   ├─ 防火间距不足 → 热辐射+飞火跨区引燃 → 火烧连营
   │    ├─ 电杆高×1.5：防止断线甩落搭接堆垛形成短路引火
   │    ├─ 灯具≥1m：卤钨/大功率灯的持续热辐射可引燃1m内木/纸
   │    └─ 开关箱≥1.5m：操作电弧+故障喷溅需安全消能距离
   │
   ├─ 码放超高(>1.5m) → 重心上移→失稳坍塌 + 取料时滑落伤人
   │
   └─ 消防通道不足(＜4m或6m) → 消防车进不来/调不了头 → 初期火灾变失控大火
        └─ 回车场12×12m 专门解决“消防车进去倒不出来”的问题
```

**一句话总结机制**：这些数值本质上是在做**物理隔离**——把“能烧的”和“能点的”拉开安全距离，把“逃生的路”和“救援的路”留出必要截面。

### 为什么这些措施有效？——措施→阻断→效果量化链

| 措施（What） | 阻断的风险路径（Why） | 🟢/🔵 |
|:---|:---|:---:|
| **危险品仓库距在建≥15m** | 在建工程动火/焊接火花飞溅半径通常在10m级，15m外加实体隔离=物理屏障 | 🟢 kc:012_0013 |
| **架空电力线≥杆高×1.5** | 断线摆幅范围≈杆高×1.2~1.5，乘1.5是含安全裕度的全覆盖规避 | 🟢 kc:147_0236 |
| **严禁碘钨灯** | 碘钨灯表面温度可达500~800°C，远超木材燃点250°C；直接禁止消除最高危引火源 | 🟢 ca:147_0236 |
| **可燃库≤30m²/防火分区** | 将单区可燃物总量压到“即使烧完也不至蔓延”的量级，500m²防火墙阻断水平传播 | 🟢 kc:147_0236 |
| **木料间25m²/灭火器** | 灭火器初期灭火覆盖半径约5m，25m²恰好是一个人在火灾初起30秒内拿灭火器可扑灭的极限面积 | 🔵 消防工程通识 + 🟢 ca:146_0233 |
| **易燃库设下风向** | 火灾烟气+热浪由风推动，下风向布设使一旦起火后火焰/毒烟吹离作业区而非覆盖 | 🟢 真题2015·30 + 教材kc:146_0235 |
| **钢构件堆场：平整干燥排水好** | 钢结构垫板不均匀沉降→构件扭曲变形→吊装应力集中→安装事故。地面条件直接保构件质量 | 🟢 真题2015·案例2 |
| **材料高度≤1.5m+下垫上盖** | 下垫→防潮防锈蚀；上盖→防雨淋变质；1.5m限高→人机工程学安全取料高度 | 🟢 kc:150_0241 + 🔵 安全人机 |

### 学生逻辑链串联（可直接口述教学）

> “咱们用一个场景串起来：你在布置一个项目现场——先把**易燃品仓库放在全年主导风的下风口**（2015真题就考过，上风×下风√），离明火至少30米，离在建工程15米以上。**消防通道一圈6米宽**，尽头回车场12×12米让消防车能掉头。仓库里面，可燃材料一个隔间不超过30平方，超过500平方就砌防火墙断开；每个木料间25平方配一只灭火器。**架空电线离堆垛至少是电杆高的1.5倍**，照明灯至少1米远，绝不用碘钨灯。材料到了先验收挂牌，码垛不超过1.5米，室外材料下面垫起来上面盖住。这就是一个从布局→隔离→消防→管理的完整闭环，考试就围着这些数考你。”

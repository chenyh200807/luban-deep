型与降水/监测｜R5-R7 镜头稿

## R5 采分点

### 1. 先立“方案总纲”：基坑不是只选一种支护
- 🟢 **采分点**：基坑施工前必须编制专项施工方案，至少覆盖支护结构、地下水控制、土方开挖与回填、施工工艺流程、安全措施、应急预案、监测要求。  
  **source**: 教材 `kc:1A413000_076_0146:0`；真题锚 `2015案例3`
- 🔵 **答题动作**：案例题先写“应补充/应编制专项施工方案”，再分写“支护、降水、开挖、监测、应急”。
- **常见错因码**：`E02` 采分点遗漏；`E05` 审题错误；`E10` 规范适用错误。

### 2. 支护选型：按土层、水位、深度、周边环境匹配
- 🟢 **浅基坑支护类型**：斜柱支撑适用于大型浅基坑；水平锚拉适用于大面深基坑；型钢桩横挡板适用于低水位黏性土；挡土灌注桩适用于邻近建筑的浅基坑。  
  **source**: 教材 `kc:1A413000_076_0147:0`
- 🟢 **水泥土重力式围护墙**：适用于淤泥质土、淤泥基坑，深度不宜大于 7m；应连续搭接施工，顶部设钢筋混凝土压顶板；成桩后 16h 内完成钢管/钢筋插入。  
  **source**: 教材 `kc:1A413000_080_0151:1`
- 🟢 **排桩选型原则**：应根据土层性质、地下水条件及周边环境选择桩型；敏感区域不得使用挤土效应大的桩型。  
  **source**: 教材 `kc:1A422000_032_0054:1`
- 🟢 **地下连续墙**：导墙厚度不小于 200mm，高度不小于 1.2m，顶面高于地面 100mm 且高于地下水位 0.5m 以上，底部进入原状土 200mm 以上。  
  **source**: 教材 `kc:1A413000_077_0148:0`
- 🟢 **土钉墙**：遵循“超前支护，分层分段，逐层施作，限时封闭，严禁超挖”；坡比不宜大于 1:0.2。  
  **source**: 教材 `kc:1A413000_079_0150:0`，`kc:1A413000_078_0149:0`
- 🟢 **锚杆/支撑体系**：锚杆垂直间距不宜小于 2.0m，水平间距不宜小于 1.5m；钢筋混凝土支撑强度等级不低于 C25；钢结构支撑宜螺栓连接。  
  **source**: 教材 `kc:1A422000_033_0055:0`，`kc:1A422000_033_0055:1`，`kc:1A422000_033_0055:2`
- 🔵 **答题动作**：不要只写“采用排桩”或“采用土钉墙”，要补一句“依据土层、地下水、开挖深度、周边环境确定”。

### 3. 降水选型：先看深度，再看渗透系数和周边沉降风险
- 🟢 **降水方案选择原则**：综合考虑地质、水文、环境、支护设计；深度 ≤3m 且软土可考虑集水明排；深度 >3m 宜采用井点降水；危及周边安全时采取截水或回灌。  
  **source**: 教材 `kc:1A413000_082_0154:0`
- 🟢 **轻型井点**：适用于渗透系数 `1×10^-7 ~ 2×10^-4 cm/s` 的土层，降水深度 ≤6m。  
  **source**: 教材 `kc:1A413000_082_0155:0`
- 🟢 **喷射井点**：适用于渗透系数 `1×10^-7 ~ 2×10^-4 cm/s` 的土层，降水深度 8~20m。  
  **source**: 教材 `kc:1A413000_082_0155:1`
- 🟢 **真空降水井管**：适用于渗透系数 `>1×10^-6 cm/s` 的土层，降水深度 >6m，管径 ≥200mm，水平间距 ≤25m。  
  **source**: 教材 `kc:1A413000_083_0156:0`
- 🟢 **管井井点**：渗透系数较大的土层适宜采用管井井点降水。  
  **source**: 真题锚 `2015第9题`
- 🟢 **水位控制**：地下水位以下挖土，应将水位降低至坑底以下 500mm 以上，降水持续到基础施工完成。  
  **source**: 教材 `kc:1A413000_084_0157:2`
- 🟢 **截水与回灌**：截水帷幕渗透系数宜 `<1.0×10^-6 cm/s`，应插入不透水层或结合井点降水；回灌用于维持原地下水位平衡、防止周边沉降。  
  **source**: 教材 `kc:1A413000_083_0156:1`，`kc:1A413000_083_0156:2`
- 🔵 **答题动作**：降水题不要只背“轻型/喷射/管井”，要把“渗透系数、降水深度、周边安全”三条件写全。

### 4. 开挖过程控制：支护和降水必须被保护
- 🟢 **深基坑开挖**：分层厚度宜控制在 3m 以内；人工挖土预留 150~300mm，机械挖土预留 200~300mm 人工挖除。  
  **source**: 教材 `kc:1A413000_084_0157:0`，`kc:1A413000_084_0157:1`
- 🟢 **严禁超挖与保护设施**：土方开挖必须与设计工况一致，严禁超挖；不得损坏支护结构、降水设施和工程桩。  
  **source**: 教材 `kc:1A422000_028_0048:0`
- 🟢 **逆作法**：大面积基坑宜盆式开挖，先形成中部结构，再分块、对称、限时开挖周边土方和施工主体结构。  
  **source**: 教材 `kc:1A413000_084_0157:3`
- 🔵 **答题动作**：写“支护已做好”还不够，必须写“按设计工况分层分段、限时、不得超挖、不得破坏降水设施”。

### 5. 监测与报警：不是深了才监测，安全等级和环境也触发
- 🟢 **必须监测条件**：基坑设计安全等级为一、二级，或开挖深度 ≥5m，或地质环境复杂时，必须实施监测。  
  **source**: 教材 `kc:1A413000_081_0152:0`
- 🟢 **监测对象**：安全等级一、二级基坑；甲级地基或软弱地基上的乙级地基；长大跨度或体形狭长结构；重要基础设施；设计或施工要求监测的其他对象。  
  **source**: 教材 `kc:1A413000_072_0139:0`，`kc:1A413000_073_0140:0`
- 🟢 **监测项目与布点**：包括围护墙顶水平位移、沉降、周边建筑沉降等；监测点沿围护墙顶部周边布设，重点在中部和阳角。  
  **source**: 教材 `kc:1A413000_081_0152:1`
- 🟢 **布点与频率**：基坑顶部监测点水平间距不宜大于 20m，每边不少于 3个；基坑降水和开挖期间每日观测 1次。  
  **source**: 教材 `kc:1A413000_073_0140:2`，`kc:1A413000_073_0140:3`
- 🟢 **危险报警**：位移突增、流沙、管涌、隆起、陷落，支撑/锚杆过大变形、断裂、松弛或拔出，周边建筑危害性裂缝，地面突发裂缝或下陷等，应立即报警并采取应急措施。  
  **source**: 教材 `kc:1A413000_082_0153:0`
- 🔵 **答题动作**：监测答案要同时写“对象/条件、项目、布点、频率、报警与应急”，只写“加强监测”通常不够。

## R6 答案骨架

### 万能满分骨架：基坑支护、降水、监测综合题

1. 🟢 **先补专项方案**  
   基坑施工前应编制专项施工方案，内容包括支护结构、地下水控制、土方开挖与回填、施工工艺流程、安全措施、应急预案、监测要求。  
   **source**: `kc:1A413000_076_0146:0`；真题锚 `2015案例3`

2. 🟢 **再按条件选支护**  
   应结合土层性质、地下水条件、开挖深度和周边环境确定支护形式；低水位黏性土可考虑型钢桩横挡板；淤泥质土且深度不宜大于 7m 可考虑水泥土重力式围护墙；邻近建筑或环境敏感时，排桩桩型应避免挤土效应大的桩型；地下连续墙应满足导墙及墙体构造要求。  
   **source**: `kc:1A413000_076_0147:0`，`kc:1A413000_080_0151:1`，`kc:1A422000_032_0054:1`，`kc:1A413000_077_0148:0`

3. 🟢 **支护施工控制写关键数字**  
   排桩应间隔成桩，已浇筑桩与邻桩间距大于 4倍桩径或间隔施工时间大于 36h；土钉墙应超前支护、分层分段、逐层施作、限时封闭、严禁超挖；锚杆张拉须待锚固段强度 ≥15MPa 且达到设计强度 75%。  
   **source**: `kc:1A413000_077_0148:1`，`kc:1A413000_079_0150:0`，`kc:1A413000_080_0151:2`

4. 🟢 **降水按深度、渗透系数、环境风险确定**  
   降水方案应综合地质、水文、环境和支护设计；深度 >3m 宜井点降水；渗透系数较大土层可采用管井井点；轻型井点适用于降水深度 ≤6m，喷射井点适用于 8~20m；地下水位以下挖土时，水位应降至坑底以下 500mm 以上。  
   **source**: `kc:1A413000_082_0154:0`，真题锚 `2015第9题`，`kc:1A413000_082_0155:0`，`kc:1A413000_082_0155:1`，`kc:1A413000_084_0157:2`

5. 🟢 **周边沉降风险要写截水或回灌**  
   若降水可能危及周边建筑、道路或管线安全，应采用截水帷幕或回灌等措施；截水帷幕应插入不透水层或与井点降水结合，回灌用于维持原地下水位平衡、防止周边沉降。  
   **source**: `kc:1A413000_083_0156:1`，`kc:1A413000_083_0156:2`

6. 🟢 **开挖必须与支护、降水工况匹配**  
   深基坑开挖分层厚度宜控制在 3m 以内；土方开挖必须与设计工况一致，严禁超挖，不得损坏支护结构、降水设施和工程桩。  
   **source**: `kc:1A413000_084_0157:0`，`kc:1A422000_028_0048:0`

7. 🟢 **监测写触发条件、项目、布点、频率、报警**  
   安全等级一、二级，或开挖深度 ≥5m，或地质环境复杂时必须监测；监测项目包括围护墙顶水平位移、沉降、周边建筑沉降等；监测点沿围护墙顶部周边布设，重点在中部和阳角；降水和开挖期间每日观测 1次；出现位移突增、流沙、管涌、隆起、支撑或锚杆异常、周边裂缝等应立即报警并采取应急措施。  
   **source**: `kc:1A413000_081_0152:0`，`kc:1A413000_081_0152:1`，`kc:1A413000_073_0140:3`，`kc:1A413000_082_0153:0`

8. 🔵 **收束句**  
   因此，本题不能孤立选择“某一种支护”或“某一种降水”，应按“专项方案 → 支护选型 → 降水控制 → 分层开挖 → 监测报警 → 应急处置”的链条组织答案。

## R7 边界：满分 vs 压线 vs 0分 near-miss

> 以下均为候选评分边界，需真人/专家裁决，不作为正式评分规则。

| 层级 | 候选边界 | 典型答案形态 | 主要风险/错因码 |
|---|---|---|---|
| 🔴待真人/专家裁决｜满分候选 | 能按“方案、支护、降水、开挖、监测、报警”成链回答，并至少写出 2~3 个关键数字或触发条件 | “应编专项方案；按土层、水位、深度、周边环境选支护；深度>3m宜井点降水，水位降至坑底以下500mm；安全等级一、二级或深度≥5m监测；出现位移突增、管涌等报警。” | 错因较少；若数字错，可能转为 `E10` |
| 🔴待真人/专家裁决｜满分候选 | 支护选型不是只报名称，而能说明适用条件 | “淤泥质土且深度不宜大于7m可用水泥土重力式；低水位黏性土可用型钢桩横挡板；敏感区域排桩避免挤土效应大的桩型。” | `E01` 知识点缺失；`E07` 概念混淆 |
| 🔴待真人/专家裁决｜满分候选 | 降水能同时覆盖深度、渗透系数、周边环境 | “轻型井点≤6m，喷射井点8~20m，渗透系数较大用管井；周边沉降风险用截水或回灌。” | `E03` 关键词缺失；`M08` 规范数字混淆 |
| 🔴待真人/专家裁决｜压线候选 | 只写出主要方案，但缺少关键数字或缺少监测闭环 | “采用井点降水，加强监测，严禁超挖。” | `E02` 采分点遗漏；`E04` 口号化表达 |
| 🔴待真人/专家裁决｜压线候选 | 能说对支护或降水其中一半，但另一半泛化 | “采用排桩内支撑，做好降水和监测。” | `E02` 采分点遗漏；`E03` 关键词缺失 |
| 🔴待真人/专家裁决｜压线候选 | 写了监测对象，但没有项目、布点、频率、报警 | “一级、二级基坑必须监测。” | `E02` 采分点遗漏；`E12` 表达冗余 |
| 🔴待真人/专家裁决｜0分 near-miss候选 | 把所有软土、地下水丰富场景都写成“集水明排”，不看开挖深度和周边安全 | “软土有水，直接集水明排即可。” | `E10` 规范适用错误；`M10` 用常识替代规范判断 |
| 🔴待真人/专家裁决｜0分 near-miss候选 | 只写“加强安全管理/注意施工质量”，没有任何支护、降水、监测实质采分点 | “加强管理，按规范施工，确保安全。” | `E04` 口号化表达；`E02` 采分点遗漏 |
| 🔴待真人/专家裁决｜0分 near-miss候选 | 降水方法与条件反向匹配 | “渗透系数较大的土层优先轻型井点。” | `E07` 概念混淆；`M08` 规范数字混淆 |
| 🔴待真人/专家裁决｜0分 near-miss候选 | 忽略报警和应急，把危险征兆写成正常现象 | “位移突然增大可以继续观察。” | `E10` 规范适用错误；`E05` 审题错误 |

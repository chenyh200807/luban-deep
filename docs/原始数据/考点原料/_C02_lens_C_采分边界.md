# C02 进度款与计量计价：R5-R7 镜头

## R5 采分点

### 采分点1：工程量清单计价的基本口径

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_035_0046:0`

- 分部分项工程宜采用**单价计价**。
- 措施项目宜采用**总价计价**。
- 综合单价为**不含增值税的税前全费用价格**。
- 综合单价应包含人工费、材料费、施工机具使用费、企业管理费、利润及一定范围风险费用。

常见错因码：`E01` 知识点缺失、`E03` 关键词缺失、`E07` 概念混淆。

### 采分点2：工程量清单编制与应用责任

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_037_0048:0`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_037_0048:1`

- 工程量清单编制依据包括计价标准、工程量计算规则、招标文件、合同条款、招标图纸、技术规范、现场情况、地勘资料、工程特点及交付标准等。
- 工程量清单由招标人或造价咨询人编制，是招标文件组成部分。
- 总价合同中，清单缺陷通常由承包人负责。
- 单价合同中，清单缺陷通常由发包人负责。
- 暂定工程量在履约中需重新计量确认。

常见错因码：`E08` 背景信息提取失败、`E10` 规范适用错误、`M09` 题干条件提取不完整。

### 采分点3：计价风险责任划分

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_036_0047:0`

- 发包人承担：清单缺陷、原始数据和基准资料错误、工程变更、赶工等引起的计量与计价风险。
- 承包人承担：措施项目清单准确性、总价合同清单缺陷、自身施工方案变更、施工效率问题等风险。
- 答题时必须先识别合同类型、风险来源、责任主体，再判断能否调整价款。

常见错因码：`E05` 审题错误、`E07` 概念混淆、`E10` 规范适用错误。

### 采分点4：工程预付款计算与起扣点

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:0`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:1`  
🟢 **锚定**：`source=真题证据｜2015案例4`

- 工程预付款 = 合同价 × 预付款比例。
- 预付款起扣点 = 合同价 − 预付款 / 起扣比例。
- 若题干给出暂列金额，计算预付款时应注意是否扣除暂列金额。
- 2015案例4锚定：预付款计算涉及中标价、暂定金额、预付比例、主要材料所占比重，并计算起扣点。

常见错因码：`E09` 计算错误、`E08` 背景信息提取失败、`M08` 规范数字混淆。

### 采分点5：进度款拨付与累计扣回

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:2`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_042_0056:0`

- 当累计完成产值达到或超过起扣点时，开始扣回预付款。
- 每次拨款 = 当月完成产值 − 当期应扣预付款。
- 当期应付进度款 = `[累计已完成工程总值 × 支付比例 - 累计预付款扣回 - 前期累计已支付进度款] - 发包人累计扣除款项`。
- 计算题应区分：当月完成值、累计完成值、累计已支付、当期应付、累计扣回。

常见错因码：`E09` 计算错误、`E06` 程序顺序错误、`E02` 采分点遗漏。

### 采分点6：未约定支付比例的最低标准

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_042_0056:1`

- 合同未约定工程总值支付比例的，支付比例不宜低于累计完成工程总值的 **80%**。
- 答题应写清“未约定支付比例”这个前提，不能直接孤立写80%。

常见错因码：`E03` 关键词缺失、`M08` 规范数字混淆、`M09` 题干条件提取不完整。

### 采分点7：合同价款调整事项

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_040_0054:1`

- 合同履行中可调整合同价款的事项包括：工程量清单缺陷、暂列金额、暂估价、总承包服务费、计日工、物价变化、法律法规及政策性变化、工程变更、新增工程、工程索赔等。
- 答题时应先判断是否属于合同价款调整事项，再进入计算或责任划分。

常见错因码：`E01` 知识点缺失、`E10` 规范适用错误、`E11` 迁移失败。

### 采分点8：质量保证金与结算边界

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_044_0059:0`

- 累计预留质量保证金或以担保保函替代保证金的金额不得超过工程结算总价的 **3%**。
- 竣工结算题中，若涉及质量保证金，应从结算总价口径判断，不应随意按合同价或当期进度款计算。

常见错因码：`E09` 计算错误、`M08` 规范数字混淆、`E10` 规范适用错误。

## R6 答案骨架

### 骨架A：预付款与起扣点计算题

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:0`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:1`  
🟢 **锚定**：`source=真题证据｜2015案例4`

```markdown
1. 先确定预付款计算基数：
   合同价 / 扣除暂列金额后的合同价。

2. 计算工程预付款：
   工程预付款 = 预付款计算基数 × 预付款比例。

3. 计算预付款起扣点：
   预付款起扣点 = 合同价 − 工程预付款 ÷ 主要材料所占比重。

4. 说明起扣含义：
   当累计完成工程价款达到起扣点后，开始从进度款中扣回预付款。
```

### 骨架B：月度进度款计算题

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_043_0058:2`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_042_0056:0`

```markdown
1. 列出每月完成产值和累计完成产值。

2. 判断累计完成产值是否达到起扣点：
   - 未达到：当月进度款按合同约定比例或当月完成值支付。
   - 达到或超过：应计算当期应扣回预付款。

3. 计算当期应付进度款：
   当期应付进度款 =
   [累计已完成工程总值 × 支付比例
   - 累计预付款扣回
   - 前期累计已支付进度款]
   - 发包人累计扣除款项。

4. 写明当月应付和累计已付。
```

### 骨架C：清单计价与责任判断题

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_035_0046:0`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_036_0047:0`  
🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A432002_037_0048:1`

```markdown
1. 先判断合同类型：
   单价合同 / 总价合同 / 成本加酬金合同。

2. 判断清单或计价问题来源：
   清单缺陷、原始资料错误、工程变更、赶工、措施项目、承包人施工方案变化等。

3. 确定风险承担主体：
   - 发包人原因或单价合同清单缺陷：通常由发包人承担。
   - 承包人措施项目、总价合同清单缺陷、自身方案或效率问题：通常由承包人承担。

4. 再决定是否调整价款、是否重新计量、是否可索赔。
```

### 骨架D：未约定支付比例题

🟢 **锚定**：`source=教材锚源料｜point_id=kc:1A435000_042_0056:1`

```markdown
1. 说明前提：
   合同未约定工程总值支付比例。

2. 写出标准：
   支付比例不宜低于累计完成工程总值的80%。

3. 若需计算：
   应付进度款按累计完成工程总值、支付比例、已支付款、预付款扣回和其他扣除款综合计算。
```

## R7 边界候选

> 本段为评分边界候选，全部标记为🔴，需真人/专家裁决后才能转为正式采分规则。

### 边界1：预付款计算是否必须扣除暂列金额

🔴 **待真人/专家裁决**

- 满分候选：明确写出“预付款计算基数应扣除暂列金额”，并完成预付款、起扣点计算。
- 压线候选：公式正确，但未解释暂列金额处理，只在计算中体现扣除。
- 0分 near-miss 候选：直接用含暂列金额的合同总价计算，导致预付款和起扣点均错误。
- 可能错因码：`E08`、`E09`、`M09`。

### 边界2：起扣点公式写对但代数顺序错误

🔴 **待真人/专家裁决**

- 满分候选：写成“合同价 − 预付款 ÷ 主要材料所占比重”，并计算正确。
- 压线候选：文字说明达到“未完工程主要材料价值相当于预付款时开始扣回”，但公式表达不完整。
- 0分 near-miss 候选：写成“合同价 × 材料占比 − 预付款”或“预付款 ÷ 合同价”，属于公式结构错误。
- 可能错因码：`E09`、`E06`、`M08`。

### 边界3：进度款只算当月值，不算累计扣回

🔴 **待真人/专家裁决**

- 满分候选：逐月列出当月完成值、累计完成值、是否超过起扣点、当期扣回额、当期应付额、累计已付额。
- 压线候选：能算出当期应付进度款，但未完整列累计过程。
- 0分 near-miss 候选：每月均按当月产值直接支付，完全忽略起扣点和预付款扣回。
- 可能错因码：`E02`、`E06`、`E09`。

### 边界4：未约定支付比例时只写“80%”是否得分

🔴 **待真人/专家裁决**

- 满分候选：写明“合同未约定工程总值支付比例时，支付比例不宜低于累计完成工程总值的80%”。
- 压线候选：只写“最低80%”，但能结合进度款语境。
- 0分 near-miss 候选：把80%误写为预付款比例、质量保证金比例或材料占比。
- 可能错因码：`E03`、`M08`、`M02`。

### 边界5：清单缺陷责任按合同类型判断

🔴 **待真人/专家裁决**

- 满分候选：区分单价合同与总价合同，并说明单价合同清单缺陷通常由发包人承担、总价合同清单缺陷通常由承包人承担。
- 压线候选：能指出清单缺陷属于计价风险，但未完整区分合同类型。
- 0分 near-miss 候选：不看合同类型，一律判为发包人或承包人承担。
- 可能错因码：`E07`、`E10`、`M09`。

### 边界6：质量保证金计算基数

🔴 **待真人/专家裁决**

- 满分候选：明确以工程结算总价为基数，累计预留不超过3%。
- 压线候选：写出“不超过3%”，但未说明基数。
- 0分 near-miss 候选：按合同价、当期进度款或预付款计算质量保证金上限。
- 可能错因码：`E09`、`M08`、`E10`。

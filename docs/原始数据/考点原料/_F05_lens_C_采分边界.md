## R6 答案骨架

### 1. 先判部位

- 🟢 若题干出现地下防水施工缝渗漏，优先从“清理、接槎、浇捣密实性”三类原因诊断：施工缝未清理干净、未按规范处理、钢筋密集导致浇捣困难。锚：`kc:1A434000_074_0116:0`
- 🟢 若题干出现防水混凝土裂缝渗漏，治理抓“养护、防水设防、保护层质量”。锚：`kc:1A434000_075_0117:0`
- 🟢 若题干出现管道穿墙渗漏，按“表面清理、止水环、振捣、避免振动、灌浆堵漏”作答。锚：`kc:1A434000_075_0117:1`
- 🟢 若题干出现卷材屋面流淌，答“切割法、局部切除重铺、钉钉子法”。锚：`kc:1A434000_076_0118:0`
- 🟢 若题干出现卷材起鼓，先看直径：小于100mm抽气灌胶；大于等于100mm割开、清理、吹干、重贴。锚：`kc:1A434000_076_0119:0`
- 🟢 若题干出现山墙或女儿墙漏水，围绕收口、压条、基层干燥、覆盖新卷材、防水油膏封口、压顶砂浆修复、分层压入新卷材作答。锚：`kc:1A434000_077_0120:0`

### 2. 再按“原因 → 措施 → 验证”组织

- 🔵 答案结构建议：先定位渗漏部位，再写可能原因，再写对应治理措施，最后写试验或观察验证。
- 🟢 屋面防水层施工完成后，可进行雨后观察或淋水、蓄水试验；淋水2h、蓄水24h。锚：`2021 案例题(一)`
- 🟢 有防水要求的厨房、卫生间和外墙面的防渗漏最低保修期限为5年，保修期自竣工验收合格之日起计算。锚：`2016 第15题`

### 3. 满分表达模板

> 🟢 本题应先判断渗漏部位。若为施工缝渗漏，原因可从施工缝未清理干净导致粘结不良、未按规范处理导致接槎明显、钢筋密集导致浇捣困难和混凝土不密实三方面分析。治理时应针对原因处理。若为防水混凝土裂缝渗漏，应及时保湿养护，设置多道设防、刚柔结合的防水层，并保证防水层保护层质量。若为管道穿墙渗漏，应清理管道表面，设置止水环，振捣密实，避免振动，必要时灌浆堵漏。若为屋面卷材问题，流淌按切割法、局部切除重铺或钉钉子法处理；起鼓按直径区分，小于100mm抽气灌胶，大于等于100mm割开、清理、吹干、重贴。若为山墙或女儿墙漏水，应清除旧胶结料，烤干基层，重新钉压条，覆盖新卷材，用防水油膏封口，并修复压顶砂浆、分层压入新卷材加铺一层。完工后可结合雨后观察、淋水或蓄水试验验证。  
> 锚：`kc:1A434000_074_0116:0`、`kc:1A434000_075_0117:0`、`kc:1A434000_075_0117:1`、`kc:1A434000_076_0118:0`、`kc:1A434000_076_0119:0`、`kc:1A434000_077_0120:0`、`2021 案例题(一)`

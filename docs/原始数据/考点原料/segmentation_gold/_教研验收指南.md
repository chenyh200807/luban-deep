# 案例题切分 · 双教研验收指南(一页纸)

> 给两名教研:你们**独立**审这 5 道题的切分,填各自 `<qid>.review.json` 的 verdict 字段。
> DeepSeek 已产 `proposed_sub_no` 候选(仅建议,**不是真值**);你们的判定才是真值。
> 一道题两人填完 → 主控合 consensus,不一致处仲裁 → 过了才进白名单出轻练。

## 你要对每个采分点填 4 个判定

| 字段 | 填什么 | 判据 |
|---|---|---|
| `proposed_sub_no` | 该采分点属于第几小问(1,2,3…) | 看 DeepSeek 候选是否对;错就改。**一个小问一个号,绝不跨小问揉一起** |
| `is_atomic` | `true`/`false` | 见下「原子四判据」。false = 还能再拆,`split_suggestion` 写怎么拆 |
| `anchor_ok` | `true`/`false` | 该采分点能否锚到**教材原文或真题官方答案**;锚不到 → false(标可疑) |
| 非平点结构 | 见下 | 顺序敏感/找错改正/列举封顶的采分点必须标出来 |

## 原子四判据(is_atomic=true 的条件,四条全满足)

1. **独立可判**:不用看别的采分点,单独就能判这一条学员答没答到。
2. **互斥**:和同小问其它采分点不重叠(不是同一件事换个说法)。
3. **可证伪**:能明确说出"答成什么样算没踩到"。
4. **有锚**:对得上教材/真题官方答案原文(不是编出来的)。

> 典型反例(判 false 要拆):把「喷灯烘烤 + 分层剥开 + 重新粘贴」打包成一个采分点 →
> 拆成 3 个原子点(尤其「分层剥开」是关键区分点,必须独立成点单独计分)。

## 非平点结构(有就标,判分靠它)

- `conjunction_group`(合取组,**找错∧改正**):判断改正题——「找出错误」和「改正」是
  同一采分点的两半,**必须都答对才给分**。给这对采分点填同一个组名(如 `"g1"`)。
- `ordering_group`(顺序组):工序题——采分点有先后,答错顺序要扣分。同组填同名 +
  在 `notes` 写正确次序。
- `list_cap`(列举封顶):「答 N 点给 M 分」的题,填 M(封顶给分数)。
- `practice_grading_kind`(**小问级判分 kind,只标这 3 种**):小问是**造价/计算链**填
  `"calc_dag"`;**荷载组合(勾选集合)**填 `"set_membership"`;**关键线路点选**填
  `"cpm_critical_path"`。判断改正/工序/列举**不用填**(上面 3 个结构字段已够派生)。
  普通采分点点选题也**不用填**(留空=默认点选)。同一小问所有点填同一个值。

## 流程

1. 打开 `<qid>.review.json`,逐点填上面字段(`consensus`/`arbitration` 先别动,主控填)。
2. 在 `reviewers` 数组加一条 `{"name":"你名","at":"日期","done":true}`。
3. 两人都填完 → 交主控。不一致的点 → 三人仲裁 → 写进 `consensus`。
4. consensus 通过的题才进 `case_light_practice_whitelist.v0.json` → 才允许对学员出轻练。

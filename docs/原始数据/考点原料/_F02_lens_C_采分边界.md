# F02｜卷材防水施工顺序与搭接方向｜R5-R7镜头

## R5 采分点

### 1. 施工顺序：先细部，后大面；由低向高铺贴
- 🟢锚定：`kc:1A413030_123_0234:0`
- 🟢真题锚：2016年第27题
- 采分表达：
  - 卷材防水层施工应先进行细部构造处理，再施工大面积卷材。
  - 铺贴应从屋面最低标高处开始，向高处铺贴。
- 易错点：
  - 只写“先铺卷材”但不写“细部先行”。
  - 把施工顺序写成“从高向低”，属于程序顺序错误。
- 对应错因码：
  - `E06 程序顺序错误`
  - `E02 采分点遗漏`

### 2. 搭接方向：搭接缝应顺流水方向
- 🟢锚定：`kc:1A413030_123_0234:0`
- 🟢真题锚：2016年第27题
- 采分表达：
  - 平行屋脊方向的搭接缝应顺流水方向。
  - 搭接不能形成迎水口，避免雨水倒灌。
- 🔵工程通识：
  - 记忆画面：水从高处往低处流，卷材搭接像鱼鳞，后一片压住前一片，让水顺着搭接面滑走。
- 对应错因码：
  - `E07 概念混淆`
  - `E10 规范适用错误`

### 3. 错缝要求：短边错开不小于500mm
- 🟢锚定：`kc:1A413030_123_0234:0`
- 🟢锚定：`kc:1A422000_029_0049:0`
- 采分表达：
  - 同层相邻两幅卷材的短边搭接缝应错开。
  - 短边搭接错缝距离不应小于500mm。
- 易错点：
  - 把“500mm”写成搭接宽度，而不是短边错缝距离。
  - 漏写短边错缝的数值。
- 对应错因码：
  - `E03 关键词缺失`
  - `M08 规范数字混淆`

### 4. 长边及上下层错缝：不小于1/3幅宽
- 🟢锚定：`kc:1A413030_123_0234:0`
- 🟢锚定：`kc:1A422000_029_0049:0`
- 🟢真题锚：2016年第27题
- 采分表达：
  - 双层铺贴时，上下两层卷材的接缝应错开。
  - 长边搭接缝错开不应小于卷材幅宽的1/3。
- 易错点：
  - 只写“错开”不写“1/3幅宽”。
  - 把短边500mm和长边1/3幅宽混用。
- 对应错因码：
  - `E02 采分点遗漏`
  - `M08 规范数字混淆`

### 5. 上下层铺贴关系：不得相互垂直铺贴
- 🟢锚定：`kc:1A422000_041_0065:0`
- 🟢锚定：`kc:1A422000_029_0049:0`
- 🟢真题锚：2016年第27题
- 采分表达：
  - 上下层卷材不得相互垂直铺贴。
  - 应保持合理铺贴方向并错开接缝。
- 易错点：
  - 误认为上下层垂直铺贴可以增强防水。
- 对应错因码：
  - `E07 概念混淆`
  - `M10 用常识替代规范判断`

## R6 答案骨架

### 满分要点版
卷材防水层施工应先做细部构造处理，再进行大面积铺贴；铺贴时应由屋面最低处向高处进行。搭接缝应顺流水方向设置，避免形成迎水缝。同层相邻两幅卷材短边搭接缝应错开，错缝距离不应小于500mm；双层铺贴时，上下层及相邻两幅卷材接缝应错开，长边搭接缝错开不应小于卷材幅宽的1/3，且上下层卷材不得相互垂直铺贴。

### 采分短句版
1. 先细部，后大面。
2. 由低向高铺贴。
3. 搭接缝顺流水方向。
4. 短边错缝不小于500mm。
5. 长边或上下层接缝错开不小于1/3幅宽。
6. 上下层卷材不得垂直铺贴。

### 记忆压缩版
先细后面，低处往高；搭缝顺水，短边500，长边三分一，上下不垂直。

## R7 边界候选

> R7为候选边界，全部标注🔴待真人/专家裁决。

### 满分候选
- 🔴待真人/专家裁决：答出“先细部后大面、由低向高、顺流水方向、短边错开≥500mm、长边或上下层错开≥1/3幅宽、不得垂直铺贴”，可判满分。
- 🔴待真人/专家裁决：若题目只问“施工顺序与搭接方向”，答出“先细部后大面、由低向高、搭接缝顺流水方向”，并补充错缝要求，通常可视为高质量满分答案。

### 压线候选
- 🔴待真人/专家裁决：只答“先细部后大面、搭接缝顺水流方向”，但漏写“由低向高”和错缝数值，可能压线得分。
- 🔴待真人/专家裁决：只答“短边500mm、长边1/3幅宽”，但没有写施工顺序和顺流水方向，可能只能拿搭接构造分。
- 🔴待真人/专家裁决：写“搭接缝错开、不得垂直铺贴”，但缺少500mm和1/3幅宽，属于关键词不足，可能低分通过。

### 0分/near-miss候选
- 🔴待真人/专家裁决：写成“先大面后细部”，核心施工顺序反了，可能不得该采分点。
- 🔴待真人/专家裁决：写成“由高向低铺贴”，与规范顺序相反，可能不得施工顺序分。
- 🔴待真人/专家裁决：写“搭接缝逆流水方向”或形成迎水缝，可能不得搭接方向分。
- 🔴待真人/专家裁决：把“500mm”说成“50mm”或把“1/3幅宽”写成“1/2幅宽”，属于规范数字混淆，可能不得对应数值分。
- 🔴待真人/专家裁决：将卷材防水与涂膜防水混答，例如只写“前后遍方向垂直”，可能因对象混淆不得分。

# 临时用电三级配电两级保护

## 错误心智模型与对症解药

### 误区1: 送电与停电顺序混淆
- **现象**: 施工人员在送电时先开启开关箱，再开启分配电箱和总配电箱；停电时则相反。
- **错误心智模型**: 认为从最末端开始操作可以更快地完成任务。
- **对症解药**: 严格按照规范操作，送电顺序应为总配电箱 → 分配电箱 → 开关箱；停电顺序应为开关箱 → 分配电箱 → 总配电箱。**锚定源**: 🔵kc:1A431011_015_0016:1
- **错因码**: E02 (操作顺序错误)

### 误区2: 未使用专用开关箱
- **现象**: 多台用电设备共用一个开关箱。
- **错误心智模型**: 认为这样可以节省成本和空间。
- **对症解药**: 每台用电设备必须有各自专用的开关箱，不得用同一个开关箱直接控制2台及以上用电设备（含插座）。**锚定源**: 🔵kc:1A431011_014_0015:2
- **错因码**: E03 (配置不当)

### 误区3: 动力与照明配电未分离
- **现象**: 动力配电箱与照明配电箱合并设置，且未分路配电。
- **错误心智模型**: 认为合并设置更方便管理。
- **对症解药**: 动力配电箱与照明配电箱宜分别设置；若合并，则动力和照明应分路配电，且动力开关箱与照明开关箱必须分设。**锚定源**: 🔵kc:1A431011_014_0015:3
- **错因码**: E04 (设计不合理)

### 误区4: 电缆埋地深度不足
- **现象**: 电缆直接埋地敷设的深度小于0.7m。
- **错误心智模型**: 认为浅埋可以减少施工难度。
- **对症解药**: 电缆直接埋地敷设的深度不应小于0.7m。**锚定源**: 🔵kc:1A431011_014_0015:0
- **错因码**: E05 (施工不达标)

### 误区5: 特殊环境下未使用安全电压
- **现象**: 在潮湿、隧道或人防工程中使用超过36V的电压。
- **错误心智模型**: 认为常规电压足够安全。
- **对症解药**: 不同环境下的安全电压限值：潮湿/隧道/人防 → ≤36V；易触及带电体 → ≤24V；金属容器/锅炉 → ≤12V。**锚定源**: 🔵kc:1A431011_015_0016:2
- **错因码**: E06 (安全意识不足)

### 误区6: 电工无证上岗
- **现象**: 电工未经职业资格考试合格即上岗工作。
- **错误心智模型**: 认为经验丰富的电工无需持证。
- **对症解药**: 电工应经职业资格考试合格后，持证上岗工作。**锚定源**: 🔵kc:1A431011_014_0015:4
- **错因码**: E07 (资质不符)

### 误区7: 未进行定期检查
- **现象**: 施工现场未定期进行用电检查。
- **错误心智模型**: 认为只要安装了保护装置就无需频繁检查。
- **对症解药**: 施工用电检查评定保证项目包括外电防护、接地与接零保护系统、配电线路、配电箱与开关箱等。**锚定源**: 🔵kc:1A436000_107_0174:0
- **错因码**: M02 (缺乏维护)

### 误区8: 未使用漏电保护装置
- **现象**: 电动冲击夯等设备未装有漏电保护装置。
- **错误心智模型**: 认为设备本身已经足够安全。
- **对症解药**: 必须装有漏电保护装置，操作人员戴绝缘手套、穿绝缘鞋，严禁冒雨作业。**锚定源**: 🔵kc:1A436000_126_0200:0
- **错因码**: E08 (安全措施缺失)

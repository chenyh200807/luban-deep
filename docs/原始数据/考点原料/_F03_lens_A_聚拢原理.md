## (3) 原理因果层  
**底层因果链——水怎么进来 → 混凝土/节点为什么会漏 → 我们的措施堵在哪里**

```
【成因】  
 水驱动力：重力（雨水积水/地下静水压）、毛细作用、蒸汽分压（内侧水汽冷凝）。
 力学损伤开口：结构变形、接缝、裂缝、穿管孔洞。

            ↓
【机理：水入侵路径 & 材料失效机制】  
 屋面：雨水→积水→(毛细/静压)→卷材接缝/收头/泛水根部渗入→保温层积水失效→顶层渗漏。
 地下：地下水压(P) > 混凝土透水阈值 → 混凝土毛细孔+微裂缝透水 + 施工缝/后浇带形成通道。
 薄弱环节：『缝』(施工缝/变形缝/后浇带)、『根』(管根/女儿墙根)、『收头』(卷材末端)。

            ↓
【为什么这些措施有效（逐条对应机理）】

① 多道设防（屋面≥3道/地下≥3道）→ 破坏容错 + 路径阻断
   水突破第一道防水层后仍有后手，不直接进入结构；层间形成压差缓冲带。

② “以防为主，以排为辅”坡度设置（屋面≥2%，天沟≥1%）→ 削减驱动势  
   缩短水停留时间=减小静水压作用时长+避免积水结冰反复冻融开裂。

③ 隔汽层在保温层下 + 高出保温层≥150mm → 切断水汽凝结路径  
   室内湿汽上升在保温层底遇冷会凝露积水→降低保温性能；隔汽层密封阻止湿迁移。

④ 泛水部位、管根设附加层 + 卷材收头金属压条钉压密封 → 应力集中点柔性加强  
   这些部位是变形集中+水流汇集区，附加层分散应力+封闭渗水捷径。

⑤ 施工缝≥2种防水措施 + 水平缝高出底板≥300mm → 结构弱面加固  
   单一止水条失效则另一措施(外贴/中埋止水带)可兜底；抬高位置避开最大弯矩区(底板与侧墙拐角剪力最大)。

⑥ 遇水膨胀止水条缓胀性（7d≤60%最终膨胀率）→ 给混凝土留稳定时间再膨胀堵孔  
   膨胀太快会把还没终凝的混凝土挤开裂；最终膨胀≥220%保证压实管壁/缝面。

⑦ 防水混凝土水胶比≤0.50(侵蚀环境≤0.45) + 胶材≥320kg/m³ → 减少毛细孔+提高密实度  
   水胶比越低，水化后残留孔隙越少；足够胶材保证包裹骨料密实，切断连续透水通道。

⑧ 地下防水混凝土“试配抗渗提高0.2MPa” → 弥补施工离散性  
   试件理想环境下的测试值需预留施工富余度，使得现场浇筑后抗渗实际值不低于设计值。

⑨ 大体积混凝土低水化热+延长设计龄期(60d/90d)+养护≥14d → 抑制温度裂缝  
   松散裂缝是高压水流的优先通道，控制温升=控制早期裂缝=提升自防水能力。
```

**⚡学生记忆锚点**  
把防水工程从“背条目”转成“缝与根的战争”——  
🚿 **屋面=水从上往下打** → 卷材铺顺坡、缝要错开、收头要钉死、泛水根加附加层  
🌊 **地下=水从四面围攻** → 混凝土做密实(低水胶比+试配提档)、缝最多两层设防、膨胀条别急胀  
🏠 **室内=精准堵漏** → 淋浴2000、盆区1200、管根密封套管高出20mm

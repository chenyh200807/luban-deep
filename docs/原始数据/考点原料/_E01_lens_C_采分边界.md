## R6 答案骨架

### 1. 判断类题骨架

> 先判定对象，再落责任，再给依据。

- 🟢 若题干问“清单计价方式”，先答：分部分项工程宜单价计价，措施项目宜总价计价。锚定：`kc:1A432002_035_0046:0`
- 🟢 若题干问“综合单价”，必须写出：不含增值税、税前全费用、含人材机管利风险。锚定：`kc:1A432002_035_0046:0`
- 🟢 若题干问“清单由谁编制”，答：招标人或造价咨询人编制，是招标文件组成部分。锚定：`kc:1A432002_037_0048:1`
- 🟢 若题干问“清单缺陷谁负责”，先看合同类型：单价合同发包人负责，总价合同承包人负责。锚定：`kc:1A432002_037_0048:1`
- 🔵工程通识：答题时不要只写“甲方/乙方”，应使用“发包人/承包人”，避免主体不规范。

### 2. 风险责任类题骨架

> 风险题不要按“谁吃亏谁负责”作答，要按责任来源归类。

- 🟢 发包人侧：清单缺陷、原始数据错误、工程变更、赶工。锚定：`kc:1A432002_036_0047:0`
- 🟢 承包人侧：措施清单准确性、总价合同缺陷、自身方案变更、施工效率问题。锚定：`kc:1A432002_036_0047:0`
- 🟢 合同适用：工程量不确定选单价合同；工程量明确选总价合同；紧急抢险或复杂工程可用成本加酬金。锚定：`kc:1A432002_036_0047:1`

### 3. 编制依据类题骨架

> “清单编制依据”要按文件、规则、现场、工程特征四组记。

- 🟢 规则依据：计价标准、工程量计算规则。锚定：`kc:1A432002_037_0048:0`
- 🟢 合同与招标依据：招标文件、合同条款、招标图纸、技术规范。锚定：`kc:1A432002_037_0048:0`
- 🟢 现场依据：现场情况、地勘资料。锚定：`kc:1A432002_037_0048:0`
- 🟢 项目特征依据：工程特点及交付标准。锚定：`kc:1A432002_037_0048:0`

### 4. 计算类题骨架

> 计算题按“费用构成 → 分项公式 → 汇总 → 税金/总价一致性”顺序写。

- 🟢 建安费构成：人工费、材料费、施工机具使用费、企业管理费、利润、税金。锚定：`kc:1A435000_038_0050:0`
- 🟢 分部分项工程费：Σ（工程量 × 综合单价）。锚定：`kc:1A435000_038_0050:1`
- 🟢 措施项目费：按单价计量或按总价计量。锚定：`kc:1A435000_038_0050:2`
- 🟢 若给出人材机、管理费率、利润率，先算管理费，再算利润，再形成分部分项工程费。锚定：`kc:1A435000_039_0053:0`
- 🔵工程通识：计算题最好逐步列式，少写心算结果；错一步但列式清楚，通常比只给最终数更容易保住过程分。

### 5. 投标与合同价款类题骨架

> 投标边界先判合法性，价款调整再判触发事项。

- 🟢 投标报价不得低于成本价，也不得高于最高投标限价。锚定：`kc:1A435000_040_0054:0`；真题锚=`2016案例4`
- 🟢 可调整合同价款事项包括清单缺陷、暂列金额、暂估价、总承包服务费、计日工、物价变化、法律法规变化、工程变更、新增工程、工程索赔。锚定：`kc:1A435000_040_0054:1`
- 🟢 投标总价应与分部分项工程、措施项目、其他项目、增值税合计一致。锚定：`kc:1A435000_040_0054:2`
- 🟢 预付款、暂列金额、起扣点类计算在真题中出现过。真题锚=`2015案例4`

## R7 边界候选

> 本段仅给判分候选，全部为 🔴待真人/专家裁决，不冒充正式评分规则。

| 题型 | 满分候选 | 压线候选 | 0分 near-miss 候选 |
|---|---|---|---|
| 清单计价方式 | 🔴待真人/专家裁决：同时写出分部分项单价计价、措施项目总价计价，并说明综合单价为不含增值税的税前全费用价格，含人材机管利风险。 | 🔴待真人/专家裁决：只写出“分部分项单价、措施总价”，但未完整解释综合单价构成。 | 🔴待真人/专家裁决：把措施项目一概写成单价计价，或把综合单价写成含增值税总价。 |
| 清单编制依据 | 🔴待真人/专家裁决：能列出计价标准、工程量计算规则、招标文件、合同条款、图纸、技术规范、现场/地勘、工程特点等核心依据。 | 🔴待真人/专家裁决：能答出招标文件、图纸、规范、工程量计算规则等主要项，但漏现场情况或工程特点。 | 🔴待真人/专家裁决：把施工单位内部施工方案、投标人报价习惯写成清单编制依据。 |
| 清单缺陷责任 | 🔴待真人/专家裁决：能区分总价合同与单价合同，写明总价合同承包人负责、单价合同发包人负责。 | 🔴待真人/专家裁决：只写“看合同类型确定责任”，但未明确两类合同对应主体。 | 🔴待真人/专家裁决：不分合同类型，一律写“发包人负责”或一律写“承包人负责”。 |
| 风险责任划分 | 🔴待真人/专家裁决：能把清单缺陷、数据错误、变更、赶工归发包人，把措施清单准确性、自身方案变更、施工效率归承包人。 | 🔴待真人/专家裁决：能正确归类大部分风险，但漏“赶工”或“施工效率问题”。 | 🔴待真人/专家裁决：按“谁报价谁承担全部风险”作答，忽略发包人责任事项。 |
| 合同类型适用 | 🔴待真人/专家裁决：能准确对应单价合同=工程量不确定，总价合同=工程量明确，成本加酬金=紧急抢险/复杂工程。 | 🔴待真人/专家裁决：能答出单价合同和总价合同适用场景，但漏成本加酬金。 | 🔴待真人/专家裁决：把工程量不确定场景选为总价合同，或把工程量明确场景选为成本加酬金。 |
| 建安费构成 | 🔴待真人/专家裁决：完整列出人工费、材料费、施工机具使用费、企业管理费、利润、税金。 | 🔴待真人/专家裁决：列出人材机、管理费、利润、税金，但漏“施工机具使用费”规范表述。 | 🔴待真人/专家裁决：把规费、暂列金额、暂估价混作费用构成要素。 |
| 造价计算 | 🔴待真人/专家裁决：列式顺序正确，管理费、利润、措施费、其他项目费、税金计算基数清楚，最终合价与过程一致。 | 🔴待真人/专家裁决：公式思路正确但存在小额算术误差，可识别主要采分步骤。 | 🔴待真人/专家裁决：直接用人材机费用乘总费率，未体现管理费、利润、措施费等计算层级。 |
| 投标报价边界 | 🔴待真人/专家裁决：同时写出不得低于成本价、不得高于最高投标限价，并能据题干判断报价是否合法。 | 🔴待真人/专家裁决：只写出不得高于最高投标限价，漏不得低于成本价。 | 🔴待真人/专家裁决：认为只要中标即报价当然有效，忽略成本价和最高投标限价边界。 |
| 合同价款调整 | 🔴待真人/专家裁决：能识别清单缺陷、暂列金额、暂估价、计日工、物价/法律变化、工程变更、索赔等调整事项。 | 🔴待真人/专家裁决：能答出工程变更、索赔、物价变化等高频项，但漏暂列金额或暂估价。 | 🔴待真人/专家裁决：认为合同签订后所有价款均不得调整。 |
| 投标总价一致性 | 🔴待真人/专家裁决：指出投标总价应与分部分项、措施项目、其他项目、增值税合计一致；不一致时保持总价不变调整清单。 | 🔴待真人/专家裁决：只指出“总价与各项合计应一致”，未说明不一致时处理原则。 | 🔴待真人/专家裁决：发现不一致后直接改投标总价，未保持总价不变。 |

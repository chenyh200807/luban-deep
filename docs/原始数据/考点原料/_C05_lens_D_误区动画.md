# 镜头：C05 钢筋连接选用

## 误区与解药

### 误区1
**现象**：施工人员在钢筋绑扎时，将所有交叉点都采用相隔交错的方式绑扎。
**错误心智模型**：认为相隔交错绑扎可以节省时间且不影响结构安全。
**对症解药**：应每点扎牢（逐点绑扎），确保钢筋网的牢固性。（E03）

### 误区2
**现象**：在梁钢筋接头位置设置时，上部钢筋接头设在梁端1/3跨度范围内，下部钢筋接头设在跨中1/3跨度范围内。
**错误心智模型**：误以为这样可以更好地分散应力。
**对症解药**：框架梁的上部钢筋接头位置宜设置在跨中1/3跨度范围内，下部钢筋接头位置宜设置在梁端1/3跨度范围内。（E04）

### 误区3
**现象**：在进行钢筋焊接时，未使用专用吊具，直接用钢丝绳绑扎吊装。
**错误心智模型**：认为钢丝绳绑扎方便快捷，不会影响钢筋质量。
**对症解药**：必须使用专用吊具装卸和转运钢筋，严禁直接采用钢丝绳绑扎吊装。（E06）

### 误区4
**现象**：在钢筋冷拉调直过程中，HPB300级钢筋冷拉率超过4%。
**错误心智模型**：认为冷拉率越大，钢筋越直。
**对症解药**：HPB300级钢筋冷拉率不宜大于4%，HRB400/HRB500级钢筋冷拉率不宜大于1%。（E07）

### 误区5
**现象**：在钢筋绑扎时，绑扎点的方向一致。
**错误心智模型**：认为绑扎方向一致更美观。
**对症解药**：绑扎点的方向应不同，丝扣呈八字形（八字扣）。（E08）

### 误区6
**现象**：在钢筋焊接时，未进行预热处理。
**错误心智模型**：认为预热处理没有必要，会增加施工时间。
**对症解药**：钢筋焊接前应进行预热处理，以减少焊接应力和变形。（E09）

### 误区7
**现象**：在钢筋绑扎时，未设置垫块或垫块数量不足。
**错误心智模型**：认为垫块可有可无，不影响整体结构。
**对症解药**：钢筋绑扎时应设置足够的垫块，保证钢筋保护层厚度符合设计要求。（E10）

### 误区8
**现象**：在钢筋焊接时，焊缝长度不足。
**错误心智模型**：认为焊缝长度不影响焊接质量。
**对症解药**：焊缝长度应满足设计和规范要求，确保焊接质量。（E11）

第 1 题 漏选 B/C/D

防水层施工采取绿色施工措施，正确说法有哪些？

A 采用符合要求的防水材料，并控制现场材料损耗。
B 施工过程采取节水措施，废水按要求收集和处理。
C 控制扬尘、噪声和有害挥发物，减少环境影响。
D 加强成品保护，减少返工和材料浪费。
你的答案 A
正确答案 ABCD

简单解析：这题考“绿色施工措施”的完整枚举。你只选了材料控制，漏掉了节水、污染控制和成品保护。

题干关键词

防水层施工 绿色施工措施 规定的说法

为什么错

你的判断停在“防水材料是否绿色”，但题干问的是“防水层施工采取绿色施工措施”。绿色施工覆盖材料、用水、污染控制、成品保护和减少返工，范围比单一材料更大。

原因分析

这类多选题容易漏选，是因为每个选项看起来都不是“唯一核心”。正确做法是先把题干限定词圈出来，再判断每个选项是否属于同一类措施。

采分点

采分点不是背一个词，而是能完整识别：节材、节水、污染控制、成品保护、减少返工都属于施工阶段绿色措施。

选项拆解

A 你选对了：属于材料与施工过程控制。 已选
B 漏选：节水和施工废水控制同样属于绿色施工。 漏选
C 漏选：扬尘、噪声、污染控制不是口号，是施工措施。 漏选
D 漏选：成品保护可减少返工和材料浪费。 漏选

记忆口诀

绿色施工看“四节一环保”：节材、节水、节能、节地，再看扬尘、废水、噪声控制。

易错点

多选题不要只找最像关键词的选项。凡是能减少资源消耗、污染和返工的措施，都可能是正确项。

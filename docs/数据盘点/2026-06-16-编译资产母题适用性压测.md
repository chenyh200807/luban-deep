## 二、总裁决:**合格原料,非成品;大部分够 + 局部二次优化**

### 优秀级现成料(直接拼)
M1 来源、M5 标准答案骨架、M3 出题人意图、M8 变题空间。**知识卡的"结构化规则(条件/要求/后果)+ 易错点 + grading_keywords/算例" 是质量最高的单层资产。**

### 二次优化分两类(价钱差很大)
**① 工程性优化(便宜——料在,只是没抽进字段/没打通):**
1. **题级总分回填**:94% 真题有 `score`,直接抽进 `official_total_score`(便宜)。**注:per-point 分值不在此列,见 §补订——它是轻标定,不是纯解析。**
2. **粒度修复**:一个 slice 塞多个采分点 → 按官方①②③切独立点。
3. **去术语化**:删 v3.2 `kc:` 裸 chunk 标题点,留 `ca:` 真采分点。
4. **跨层打通**:C层公式/procedures ↔ v3.2 计算 leaf(现公式只在讲义候选,v3.2 计算叶只有定义)。

**② 真缺料优化(贵——须新编译/采集):**
1. **不变量因果链**(措施型短板):C层只深编译了讲义水泥选型页,**未深编译温控标准 GB50496** = corpus 覆盖缺口。
2. **误解码映射**:案例 option_reasoning 空,common_mistakes 须结构化成 ERROR_CODE_REGISTRY 码。
3. **边界答案/弱表达 + 真实学生答卷 = 0**(两考点人审边界样本都空)——唯一壁垒缺口,**只能靠真人采集**(留存实验进入人审队列)。
4. 计算题**数值比对判据** + 网络图机器可读结构。

### 关键洞察:母题质量不均匀
- **计算型(进度)不变量/误解层最强**(有可执行公式 procedures),只缺步骤分+数值判据;
- **措施型(混凝土)答案骨架/变题最强**,缺力学因果链(对应标准没深编译);
- → 一个考点能否"几乎直接拼成优秀母题",取决于它的标准/讲义**有没有进 C 层深编译**。

## 三、行动建议
1. **先做便宜的工程优化**(分值回填 + 粒度修复 + 去术语化 + 跨层打通)→ 把 1 个考点拼成优秀母题样板;
2. **真缺料里"边界答案+真实作答"由留存实验喂**(两件事合一);
3. **"因果链/标准深编译"是定点补料**(按要做的母题缺哪个标准就补编译哪个,如混凝土补 GB50496 温控段);
4. 选样板考点优先级:**进度网络计划**(不变量/误解已优秀,只差分值化)或 **混凝土温控**(骨架/变题优秀,需补因果链)——前者更快,但"分值化"是轻标定非纯工程(见 §补订)。

## §补订(2026-06-16 真题分值核查,纠正上文"分值在原文"的过度转述)

全 11 年 218 案例题直接扫描(脚本,正则 `[（(]?\d+(\.\d+)?\s*分`):

| 项 | 实测 |
|---|---|
| 题级总分 `score` 非空 | **206/218(94%)**,如 5.0 / 25.0 —— 可直接抽,便宜 |
| 答案文本含 per-point 内联分值 | **仅 16/218(7%)**,219 处标记 |
| 这 7% 的性质 | **是"估计"非官方**。样本(2017):"措施项目费=809万元(**估计 4 分**)…A 单位应承担主要义务(**估计满分 5 分,每项 1 分**)"——"估计"二字在原文 |

**结论订正**:真题给"满分答案 + 题级总分(94%)+ 可抽判据",**唯独不给"每采分点几分"**(中国一建人工踩点、分值口径不公开)。故 M4 的 per-point 分值不是"解析器没抽"的便宜活,而是**轻标定**:(a) 规则分配(题级总分÷采分点数;列举/措施型常"每项均分"较稳;计算型步骤分不等额,不能均分)、(b) 借 7% 估计值+教研判断、(c) 真实阅卷标定(精确口径,指回唯一壁垒)。per_question 侧 `per_point_score_authority` 字段在但 `pending`,与真题一致:**题级有、点级待标定**。

## §补订-2(2026-06-16 真题 PDF 视觉核查,再次订正:§补订 也错了)

§补订 基于结构化 JSON 扫描,判"per-point 分值仅 7%、是估计、属轻标定"——**这个结论也错了,因为 JSON 把分值丢了**。视觉读真题 PDF 解析(佑森独家解析),**每个采分点的分值齐刷刷全标着**,且含**计算题逐步骤分**、**网络计划步骤分**、**0.5 分粒度**、**部分给分规则**("写出3项即得3分")。详见 [真题PDF分值视觉核查](2026-06-16-真题PDF分值视觉核查.md)。

**M4 最终定级**:per-point 分值不是缺料、不是标定,是**"视觉抽取"任务(中等工程)**——把 6 份真题 PDF 解析的分值抽出来回填 per_question 的 482 个 `score:null` 即可。性质是培训机构(佑森)资深教师解析估分(非官方,但采分点级+步骤分+部分给分,质量高);官方精确口径仍要真实阅卷。**这使计算型/案例型母题判分比此前两版结论都更可建。**

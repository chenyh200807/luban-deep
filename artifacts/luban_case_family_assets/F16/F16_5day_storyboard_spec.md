## 0. 每日闭环骨架(7 步,每天同构)

| 步 | 名称 | 内容 | 红线 |
|---|---|---|---|
| 1 | 今日一刀 | 只给 1 个最高收益任务卡(2 分钟) | 不堆任务列表 |
| 2 | 表皮试探 | 2-3 道 MCQ / 半写,**每个干扰项都是诊断探针** | 干扰项必须是真误解非凑数 |
| 3 | 透视揭底 | 表皮 → 不变量 → 出题人意图 → 你的误解 | 不是长解析,是"看穿" |
| 4 | 定位证据 | 教材 chunk + 采分点 + `error_code` + misconception | 错因只引用 E 系列,不新建 |
| 5 | 一句纠正(**暖**) | "你方向对了,就差一步"——先捧→点差距→给安全网 | **绝不毒舌**(见 [[wow-see-through-must-be-warm-not-harsh]]) |
| 6 | 明日换皮约定 | "明天换个场景测你这个魂" | 留一个"未闭合悬念" |
| 7 | 证据入账 | 轻练只写 light signal;掌握**等复测读回** | 前端不自算掌握 |

**暖版 wow 公式**(每天第 5 步统一):`先肯定他对的那一半 → 指出"就差最划算的一步" → "我相信你" + 安全网`。

## Day 1 — 顺水搭接方向(深题 D1 · 因果 why)

- **不变量**:水沿坡从高处往低处流;顺水搭接 = 高处卷材压住低处卷材的边缘,让水从上层表面跨过缝口,而不是钻进缝里。
- **今日一刀**:`2 分钟看穿:卷材到底从哪头往哪头铺`
- **表皮试探(MCQ = D1)**:某屋面北高南低,雨水北→南流,两名工人争论搭接方向,哪种最能解释"顺水搭接"本质?(正确 A)
  - 干扰项探针:
    - B 从北高往南低铺、"后铺压先铺总是对的" → **误解:把口诀当绝对规则** → `E11 迁移失败`
    - C 只要搭接宽度够,坡向缝口不影响 → **误解:只看宽度不看方向/缝口** → `E07 概念混淆`(采纳 Opus SEV-3 订正,原 E03)
    - D 垂直屋脊铺、缝向由施工方便定 → **误解:用施工方便替代铺贴方向** → `E10 规范适用错误`
- **透视揭底**:表皮(把坡向改成北高南低)→ 不变量(缝口要背向来水)→ 出题人意图(坡向一反,逼你代入水流,而不是背"顺水搭接"四个字)→ 你的误解(若选 B:你把"后铺压先铺"当成了绝对规则)。
- **定位证据**:
  - 教材 `1A434000_068_0104`:检查卷材铺贴方向及顺序、搭接长度及搭接缝位置
  - 讲义 `lecture_teaching_cards.jsonl:347`:防水层由低向高铺贴、搭接缝顺水方向
  - error_code:E11 / E07 / E10;misconception:"后铺压先铺机械套用"
- **一句纠正(暖)**:"你方向感是对的——知道要顺水。就差最后一步:把'谁压谁'交给**水流**来定,而不是交给'后铺'这个口诀。水从北来,就让北边那张压住南边那张的边。这步想通,这类题再骗不到你。"
- **明日约定**:"明天我换成地下室外墙,水从外面的土里来——还是'水从哪来'这个判断,换个场景测你。"
- **入账**:light signal only(轻练不写掌握)。

## Day 2 — 迎水面设防(深题 D3 · 鉴别 discriminate)

- **不变量**:迎水面 = 水首先作用的一侧(屋面在上、地下室外墙在外侧)。防水放迎水面 → 水压把它压贴基层;放背水面 → 结构先被水侵入、防水还可能被顶离。
- **复测 banner(承接 Day1)**:"先复测昨天:你昨天看穿了'水从哪来,定谁压谁'。今天还是这个魂,换地下室。"
- **今日一刀**:`换个场景:地下室防水到底贴里还是贴外`
- **表皮试探(MCQ = D3)**:地下室外墙外侧是回填土+地下水,为赶工想把卷材主要贴内侧("好施工、漏了好补"),哪个判断最准?(正确 A)
  - 干扰项探针:
    - B 只要材料防水,内外侧没区别 → `E07 概念混淆`
    - C 内侧好检修,所以内侧永远优于外侧 → `E10 规范适用错误`
    - D 错,但只因"屋面防水在上表面"照搬 → `E11 迁移失败`
- **透视揭底**:表皮(赶工想贴内侧)→ 不变量(迎水面 = 外侧)→ 意图(用"好施工/好维修"诱你离开迎水面原则)→ 你的误解(若选 C:用检修便利替代了迎水面)。
- **定位证据**:
  - 教材 `1A413030_134_0258`:外墙体防水层应设置在迎水面
  - 教材 `1A413030_130_0247`:外设防水层
  - error_code:E07 / E10 / E11
- **一句纠正(暖)**:"你没说错,内侧确实好修。但这题考的不是好不好修,是水从哪边压过来。地下室的水从外面土里来,迎水面就是外侧——贴外侧,水压帮你把防水压在墙上;贴内侧,水先泡了墙、还想把防水顶下来。记住'迎水面=水来的那面',屋面和地下室就统一了。"
- **明日约定**:"明天不换'水从哪来'了,换个新魂:**节点**。看你会不会被'后补也行'骗到。"
- **入账**:light signal + **Day1 same-node 复测读回信号**。

## Day 3 — 节点先行(深题 D2 · 因果 why)

- **不变量**:节点(管根 / 阴角 / 收口)是渗漏起点。先在合格基层处理节点,再让大面防水与节点附加处理**连续搭接**;后贴在表面的"补丁"边缘 = 新的张口和窜水路径。
- **复测 banner**:"复测前天 + 昨天:水从哪来你已经会判了。今天看你会不会被'多补点总没错'带偏。"
- **今日一刀**:`管根阴角:先做节点,还是先铺大面`
- **表皮试探(MCQ = D2)**:工人说"先把大面卷材铺完,再在管根阴角上贴附加层补强也行",哪项反驳最准?(正确 A)
  - 干扰项探针:
    - B 只要后补附加层面积更大,顺序不影响 → `E06 程序顺序错误`
    - C 大面已覆盖基层,节点附加层只是美观增强 → `E07 概念混淆`
    - D 不行,但只因"教材写了先节点后大面",不解释 → `E04 口号化表达`
- **透视揭底**:表皮(先大面后补附加层)→ 不变量(节点先行 + 连续搭接)→ 意图(用"后补面积更大"诱你)→ 你的误解(若选 B:用面积补偿了顺序)。
- **定位证据**:
  - 教材 `1A434000_068_0104`:附加层、细部构造处理
  - 教材 `1A434000_075_0117`:穿墙管设置止水环
  - 教材 `1A434000_077_0120`:卷材收口处张口、固定不牢、未分层搭槎会造成问题
  - error_code:E06 / E07 / E04
- **一句纠正(暖)**:"你想'多补点总没错'——这份谨慎是好的。但防水不是补得多,是不给水留缝。节点是水最先钻的地方,先做它、再让大面压上去连成一片,补丁才不会变成新缝。顺序对了,你那份谨慎才真正生效。"
- **明日约定**:"前三天你练的是'判断'。明天换一种——**你自己写**,AI 按真实阅卷采分点给你批,看你写的能不能踩到分。"
- **入账**:light signal + Day2 复测读回。

## Day 4 — 屋面卷材起鼓割补(半写题 · Q18 P10/P11 · 真 AI 批改)

> **这一天是全 5 天唯一走已签发判分工件的真批改日**,也是"AI 真的按采分点看我写的"那个 wow 的兑现点。

- **不变量(工序)**:起鼓卷材割补 = 先放气排出鼓内气体 / 擦干清除旧胶结料 → 喷灯烘烤、分层剥开旧卷材、重贴新卷材并连续搭接。
- **今日一刀**:`今天不选答案。屋面卷材起鼓了,你来写怎么割补——AI 按真实采分点告诉你哪句踩到分、哪句差一口气`
- **半写题**:Q18-1A434000 屋面卷材防水起鼓割补法工序。`task_scope = {P10, P11}`,范围外点 `not_evaluated`。
  - **P10**(`exact_required`,0.75 分):放气 / 擦干 / 清除旧胶结料
  - **P11**(`high_risk_review`,0.75 分):喷灯烘烤 / 分层剥开 / 重贴新卷材
- **批改展示(踩点制)**:
  - 命中:绿色"你写到了:'清除旧胶结料' → 踩中 P10"
  - 漏点:琥珀"你没写到:重贴前要**分层剥开**旧卷材 → P11 差这一句"
  - 范围外:`not_evaluated`(不在本次 task_scope,不算漏答)
  - error_code(display-only):P10/P11 → `E06 程序顺序错误` + `E03 关键词缺失`
- **一句纠正(暖)**:"你已经写出了割补的大框架,这很不容易——很多人连'要先放气'都想不到。就差一个动作:重贴新卷材前要'分层剥开',这是把新旧卷材连成一体的关键。补上这一句,这 0.75 分稳稳到手。"
- **明日约定**:"明天总复测——屋面、地下室、穿墙管三处一起上,换一个你没见过的工地,看这 5 天是真进了脑子,还是只记住了原题。"
- **入账**:semi-write evidence(`evidence_weight=diagnostic`),写 learning_evidence **候选**(经既有 authority 消费),前端不自算掌握。
- **诚实边界(钉在剧本)**:判分 authority = `Q18-1A434000::qga_v0_20260604`(published,但属 `training_org_analysis` 估分口径,**非官方阅卷**);task_scope 外 `not_evaluated`;这是真实签发点的真 AI 批改,**不是合成题**。

## Day 5 — 三处防水换皮综合复测(深题 D4 · 元认知)

- **不变量**:同一个"控水路"原则在三个场景保持不变——屋面看坡向 / 地下室看迎水侧 / 管根看节点止水。
- **今日一刀**:`总复测:换个新工地,三处防水一起判。这不是新知识,是把这 5 天的魂用一次`
- **表皮试探(MCQ = D4)**:某工程同一天处理屋面天沟卷材 / 地下室外墙卷材 / 穿墙管根,哪套安排最能说明"真懂防水"而非背清单?(正确 A)
  - 干扰项探针:B(宽度够/内侧好修/补一圈)`E07`;C(三处先大面、最后统一补节点)`E06`;D(哪方便贴哪、材料合格即可)`E10`
- **透视揭底(这次是回放,不揭新底)**:"回看你这 5 天看穿了什么:Day1 顺水 → Day2 迎水面 → Day3 节点先行 → 今天三个一次用上。"
- **进步收据(暖 · 留存关键)**:"5 天前你大概会选 C(先大面、最后统一补节点,看起来最整齐)。今天你选了 A。你不是背下了答案——这 5 天每天那个'水从哪来、缝口避水、节点先行'的判断,今天一次用上了三个。这就是真懂和背过的区别。"
- **掌握鉴别 + 诚实边界**:Day5 是复测读回点;但**诚实标注**——D1-D4 是 inference-validated(非逐字 G-SRC),且起鼓割补工序**无 same-point 复测题**,Day5 综合题是 `same-node` 深化,**不得伪装成 point-level 干净提升**;掌握结论由 `LearnerStateService` / `learning_evidence` / `revalidation_queue` 消费后产生,**前端不自算**。
- **安全网(暖)**:"就算今天还错一两处也没关系——错的那处正好告诉我们明天先陪你练哪个。你已经连续来了 5 天,这件事本身就比答案更重要。"

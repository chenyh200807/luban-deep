1. **我不是一建防水命题专家。** 下面的题干、选项、正确答案是按防水施工的工程逻辑（工序因果、迎水面、搭接顺水）推演的草稿，**正确答案与"教材第几章"必须由你或佑森老师对照 2026 一建建筑实务教材/真题核对后再发**（这正是 schema 的 G-SRC 门：内容必须可溯源教材原文）。带 `〔待核〕` 的地方是占位。
2. **error_code 用的是真实 `ERROR_CODE_REGISTRY`（E 轴）**：E02 采分点遗漏 / E03 关键词缺失 / E06 程序顺序错误 / E09 计算过程缺失。不私造。
3. **这是验证"留存"的工具，不是验证"题库规模"的。** 8-12 题足够跑 5 天，别先扩到一堆。

## 第 1 组（D1）—— 工序 / 搭接 / 节点（schema 已建的三个失分形态）

### Q1（FM-ORDER 工序顺序）
铺贴防水卷材时，下列工序顺序正确的是：
- A. 基层处理 → 节点附加层 → 大面铺贴 → 保护层　**（正确）**
- B. 基层处理 → 大面铺贴 → 节点附加层 → 保护层
- C. 大面铺贴 → 基层处理 → 节点附加层 → 保护层
- D. 节点附加层 → 基层处理 → 大面铺贴 → 保护层

**选错即诊断：**
- 选 B → 盲点 **MC-NODE-LAST**「先大面再补节点也行」｜`E06 程序顺序错误`｜教材〔防水工程·施工工序，待核章节〕｜纠正：**节点（阴阳角/管根）是渗漏高发区，必须先做附加层保护，再铺大面**；先大面后补节点，节点处搭接被破坏。
- 选 C → 盲点「基层可以后处理」｜`E06`｜纠正：基层处理（清理、找平、干燥）是一切的前提，基层不合格大面必空鼓/渗漏。
- 选 D → 盲点「节点先于基层」｜`E06`｜纠正：节点附加层也要做在合格基层上，不能先于基层处理。
- 👉 明天复测：再给你一道"工序找错"题。

### Q2（FM-LAP 搭接方向）
卷材搭接，下列做法正确的是：
- A. 搭接缝顺流水方向、上层压下层　**（正确）**
- B. 搭接缝逆流水方向，只要搭接长度够就行
- C. 下层压上层，方向无所谓
- D. 相邻两幅对缝拼接，不搭接

**选错即诊断：**
- 选 B → 盲点 **MC-LAP-DIR**「搭接只要够长，方向无所谓」｜`E03 关键词缺失`（漏"顺水/迎水"关键词）｜教材〔防水·卷材搭接，待核〕｜纠正：**搭接必须顺流水方向、上层压下层**；逆水搭接 = 引水进缝，长度再够也漏。
- 选 C → 盲点「上下层压向无所谓」｜`E03`｜纠正：必须上层压下层（顺水），下压上会兜水。
- 选 D → 盲点「可以对缝不搭接」｜`E02 采分点遗漏`｜纠正：必须搭接并满足最小搭接宽度〔待核 mm〕，对缝必漏。
- 👉 明天复测：换一个"地下室外墙搭接"场景考你同一个点。

### Q3（FM-NODE 节点先行 / 迎水面，鉴别题雏形）
同样做防水，**屋面**和**地下室外墙**的迎水面（防水层该贴哪一侧）：
- A. 都贴上表面
- B. 屋面贴上（顶面）、地下室外墙贴迎水的外侧　**（正确）**
- C. 都贴结构内侧（背水面）
- D. 看施工方便，哪面好贴贴哪面

**选错即诊断（这是"真懂 vs 背过"鉴别题 D1）：**
- 选 A → 盲点「把屋面做法照搬到地下室」｜`E06`｜教材〔防水·迎水面原理，待核〕｜纠正：防水层永远做在**迎水面**——屋面水从上来贴顶面，地下室水从外侧压来贴外墙外侧；背水面做防水会被水压顶脱。
- 选 C → 同上盲点（背水面）｜纠正：背水面防水抵不住水压，必失效。
- 选 D → 盲点「迎水面不重要」｜`E06`｜纠正：迎水面是防水第一原则，不能凭施工方便。
- 👉 背了"屋面做法"的人会栽在 A/C，真懂"迎水面"的人选 B——**这道题就是用来区分真懂和背答案的**。

## 第 2-4 组（D2-D4）—— 扩展防水点（草稿，需教材核对）

> 下面给"题点 + 盲点 + error_code"骨架，题干/选项/正确答案/章节按教材填实。每个点都要能出"选错即诊断"。

| 题点 | 考点本质 | 典型盲点（misconception） | error_code |
|---|---|---|---|
| 基层含水率/干燥要求 | 基层不干燥 → 卷材起鼓 | "基层湿一点没关系" | E03/E06 |
| 附加层宽度/位置（阴阳角、管根、变形缝） | 节点附加层尺寸不足 | "节点随便加一块就行" | E02 |
| 卷材最小搭接宽度〔待核 mm〕 | 搭接宽度不够 | "搭上就行，不看宽度" | E03 |
| 防水层厚度/道数 | 厚度/道数不达标 | "刷一道差不多" | E02 |
| 保护层作用与时机 | 不做保护层 → 防水被破坏 | "防水做完就完事" | E06 |
| 蓄水/淋水试验时长〔待核 h〕 | 不做闭水试验 | "看不出漏就行" | E02 |
| 防水材料选择（柔性/刚性、相容性） | 材料用错/不相容 | "防水材料都差不多" | E03 |
| 穿墙管/套管防水构造 | 管根不处理 | "管根抹点砂浆" | E06 |

**D2-D5 的"复测"** = 把用户 D1 选错的那个盲点（如 MC-NODE-LAST），换一道同采分点不同场景的题再考一次（schema 的 `binding_level: same_point`）。答对 = 该盲点回暖；这就是"看见进步"。

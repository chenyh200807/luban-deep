# type-value_memory · (七) 数值/记忆原型 —— 不动画化

- **何时选**:考点本质是"静态定义/数值阈值/名词辨析/条文背诵",没有时序/空间/计算/判断结构。
- **代表考点**:定义、规范数值(如搭接长度/温度限值)、参数辨析、材料分类、条文罗列。
- **展现形式**:**不做动画**——静态图表 / 卡片 / 对照表 / 一句话记忆钩子。过度动画化反而增外在认知负荷(报告 + 研究明确)。
- **语义色**(引用 style-guide):中性为主;易混点用 `--partial` 琥珀标,正确值 `--correct` 绿。
- **交互**:间隔复习(翻卡 / 自测),不做炫交互。
- **祖师爷参照**:**间隔重复卡**(Anki SM-2 / Quizlet)+ 助记法 / 记忆宫殿——**靠检索练习 + 间隔,不靠动画**;数值对照用静态表。
- **schema body**:不进图解微课 schema 的动画 body;走"记忆卡 / 对照表 / 钩子"轻结构(可挂在 MCQ 轻练池)。
- **验收点(原型专属)**:不强行动画化;数值/条文带 source_ref 溯源(教材/规范);记忆钩子准确不误导。
- **现状**:报告已定"别动画化";作为**反例护栏**——选原型时若发现是此类,**停手,别做动画卡**,转静态/记忆路径。

# type-section · ② 构造/空间原型

- **何时选**:考点难在"空间/层次/节点关系",纯文字想象不出画面。
- **代表考点**:防水节点、屋面/地下室防水构造层次、钢筋锚固、后浇带、变形缝、梁板柱节点、幕墙、楼梯。
- **展现形式**:剖面分层 / 爆炸图(分层显露 + 局部放大)。
- **语义色**(引用 style-guide 层色编码):基层灰 / 防水层蓝 / 附加层绿 / 保护层琥珀,**一层一色、跨卡一致**;错误节点用 `--wrong` 红对比。
- **交互**:点选某层看解释 / 逐层显露;不做旋转 3D(成本失控)。
- **祖师爷参照**:**交互式爆炸/剖切图学术线**(Wilmot Li, SIGGRAPH 2008《Automated Interactive 3D Exploded View Diagrams》)——核心是**用"结构化层/爆炸参数"驱动剖切揭示**(正对我们 schema 思路);解剖 App(层 toggle)。**我们做 2D SVG 层切换,不上 3D/CAD。**
- **schema body**:`layers[]`(待定:每层 `id/name/color_token/svg_layer/explain/order`)+ 复用 `scoring_points`/`common_errors` 脊柱。
- **验收点(原型专属)**:层次顺序正确、节点边界清晰、构造关系不画错(教研+专业双签);只做 2D 剖面,2D 实在讲不清才追加极简爆炸。
- **现状**:⚠️ **待建**(最难)——先建"层分解 schema + 确定性 SVG 渲染"的图元库(这是构造型量产的真瓶颈)。

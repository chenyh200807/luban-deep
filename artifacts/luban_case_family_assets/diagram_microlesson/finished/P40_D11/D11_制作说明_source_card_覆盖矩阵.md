## 1. source_card

- **main_exam_action**：抹灰工程做法「数字达标 + 适用对象」判断（判对错 / 找不妥并改正 / 部位枚举 / 交接防裂措施）。
- **wrong_idea**：抹得越厚越结实、基层湿点天冷点没事、加强网随便搭、含水率一个数糊到底、厨卫用普通腻子、把外保温薄抹灰当一般抹灰。
- **teaching_spine（五关）**：控厚度 → 交接防裂 → 控含水率 → 控环境 → 控材料。
- **facts（🟢 全部锚定）**：
  1. 抹灰总厚度≥35mm 须采取加强措施（分层 + 加强网）
  2. 内墙普通抹灰层平均总厚度≤20mm、高级≤25mm（真题 {2023·26} 侧锚）
  3. 不同材料基体交接处设加强网，与各基体搭接≥100mm
  4. 基层含水率：溶剂型涂料≤8% / 乳液型≤10% / 木材≤12%
  5. 室内抹灰环境温度一般不低于 5℃（真题 {2023·26} 侧锚）
  6. 厨房 / 卫生间 / 地下室等潮湿部位找平层用耐水腻子
  7. 涂饰应在抹灰等湿作业完成后进行（🔵 外延·工序衔接）
- **common_errors → error_code**：35mm 不加强(M08/E02)、搭接 50/80mm(M08/E03)、温度 0℃(M08/E10)、层厚 20/25 写反或当单层(M08/E07)、含水率不分对象(M08/E07)、厨卫普通腻子 / 漏地下室(E07/M03/M06/M07)、薄抹灰当一般抹灰(E11/E07)、涂饰抢跑(E06)。
- **practice_blueprint**：判断纠错三段式 + 内容清单枚举（部位）+ 交接防裂措施（裁剪）+ 采分诊断末题。

## 2. 分集方案与理由：**一集完整覆盖（不分集）**

- 讲解全覆盖预估时长 **约 4 分 50 秒（DUR=290s）**，在 5 分钟体验上限内。

  beat 数（7）落在 design-system 允许的 5–8 主讲 beat 内，无需为控时长删减采分点。

## 4. visual_archetype_decision（冻结）

- **primary_archetype**：`threshold_trigger`（阈值触发）——本考点是「数值阈值密集 + 条件维」考点，指针 / 液柱滑过临界即触发后续做法对象出现。
- **secondary_archetype**：`顺逆/镜像对比`——加强网搭接 50 vs ≥100、普通腻子 vs 耐水腻子，两侧几何必须真不同。
- **visual_primitive**：墙体剖面（基层 + 抹灰层）、厚度标尺、加强网跨缝、含水率水位条、温度计、腻子墙面。
- **motion_grammar**：对象级进入 / 指针滑动 / 触发出现 / 命中高亮 / 掉粉退出，非整页淡入淡出。
- **why_this_visual**：所有采分点都是「数字达标 + 对象判断」，用标尺 / 温度计 / 对比墙把抽象阈值变成看得见的命中与因果。
- **why_not_text**：纯数字清单记不牢、易张冠李戴；动画把「为什么这个数、超了会怎样」画出来。

## 5. domain_visual_plan + 每 beat 对象验收判据

- **b0 破误区**：基层墙 + 过厚抹灰面 + 裂纹 + 空鼓鼓包 + 误区气泡 + 红章。
  判据：*正确当且仅当画出基层 + 过厚抹灰面 + 可见裂纹 + 带标签的空鼓鼓包。*
- **b1 控厚度**：墙体剖面（分层 + 加强网）+ 0–40mm 厚度标尺（20/25/35 刻度）+ 指针滑到 35 触发加强面板。
  判据：*正确当且仅当标尺画出 20/25/35 三刻度、指针滑过 35 触发「分层+加强网」对象出现。*
- **b2 交接防裂**：左「搭 50」短网 + 缝裂到面 vs 右「搭≥100」长网 + 应力分摊；两侧混凝土/砖墙真基体。
  判据：*正确当且仅当左右网长度不同、左有通缝右无缝，判别特征（搭接长度+裂缝有无）画出。*
- **b3 控含水率**：溶剂型/乳液型/木材三条含水率水位条 + 各自 8/10/12 阈值线 + 因果注（太湿→鼓泡空鼓）。
  判据：*正确当且仅当三种对象可区分、各带自己的阈值刻度且落浅底可读。*
- **b4 控环境**：温度计液柱 + 5℃ 临界带 + 0℃ 坑标注 + <5℃冻胀空鼓/≥5℃正常两结果。
  判据：*正确当且仅当画出液柱、5℃临界带、0℃坑与两条因果结果。*
- **b5 控材料**：普通腻子墙（掉粉/脱落缺口）vs 耐水腻子墙（完好+✓）+ 水滴 + 厨/卫/地下室部位枚举。
  判据：*正确当且仅当左墙有掉粉/脱落、右墙完好——两侧真不同，且部位含地下室。*
- **b6 五关链**：五张语义色卡（厚度/交接/含水率/环境/材料）各带关键数值。
  判据：*正确当且仅当五关各自的关键数值都在卡上。*

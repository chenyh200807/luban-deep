## §A 规范增补（贴进 readme.md 的「红线汇总」或新开一节）

**全屏播放（母版内置 · 讲解页）**：讲解页必须支持一键全屏——

- **真全屏＝模拟全屏**：`body.luban-fs` 把 `.lz-card` 固定铺满视口（`position:fixed;inset:0;100dvh;背景#000`），不依赖原生 `requestFullscreen`（iPad Safari 对任意元素不支持，原生调用仅作 best-effort）。
- **只留教学画面**：全屏下头部、底部控制条（`.lz-chrome`）隐藏，只剩舞台（动画＋字幕）。
- **等比自适应**：舞台固定 390×462，按 `scale = min(vw/390, vh/462)` 居中缩放、四周留黑边**不裁切内容**；监听 `resize`/`orientationchange` 实时重算，适配 iPad 竖屏/横屏与转屏。
- **点屏唤出控制**：轻触画面 `tapToggle` 浮出底部控制条（播放/进度/旁白开关/退出）；播放中约 3.5s 无操作自动隐藏，暂停时保持可见。
- **默认手机屏**：不点全屏时维持 390 手机卡原样。

> 一句话红线：`讲解页全屏＝模拟全屏铺满 + 舞台 min(vw/390,vh/462) 等比居中留边不裁切 + 只留动画字幕 + 点屏唤出控制 3.5s 自隐 + 适配 iPad 竖横屏`。

## §B 母版改动清单（AnimatedLecture.dc.html）

### B1 · 注入 CSS（`componentDidMount` 里的 `lz-fs-style`，替换 textContent）

```js
s.textContent='body.luban-fs .lz-card{position:fixed!important;top:0!important;right:0!important;bottom:0!important;left:0!important;width:100%!important;max-width:100%!important;height:100vh!important;height:100dvh!important;overflow:hidden!important;z-index:9999!important;box-shadow:none!important;background:#000!important}body.luban-fs{overflow:hidden}body.luban-fs .lz-chrome{display:none!important}body.luban-fs .lz-stagewrap{position:absolute!important;top:0!important;right:0!important;bottom:0!important;left:0!important;display:flex!important;align-items:center!important;justify-content:center!important}body.luban-fs .lz-stage{width:390px!important;height:462px!important;flex:none!important;transform:scale(var(--fs-scale,1))!important;transform-origin:center center!important}';
```

紧接着（还在 `componentDidMount` 内）加监听：

```js
this._onResize=()=>{ if(this.state.fs) this.updateFsScale(); };
window.addEventListener('resize', this._onResize);
window.addEventListener('orientationchange', this._onResize);
```

### B2 · state 加 `ctrlHidden`

```js
state = { t:0, playing:false, askOpen:false, askText:"", askLoading:false, askAnswer:"", fs:false, ctrlHidden:false, muted:false };
```

### B3 · `componentWillUnmount` 清理

```js
componentWillUnmount(){ this._dead=true; if(this._raf)cancelAnimationFrame(this._raf); this.stopSpeak(); if(this._hideT)clearTimeout(this._hideT); try{ window.removeEventListener('resize',this._onResize); window.removeEventListener('orientationchange',this._onResize); }catch(e){} }
```

### B4 · 替换 `fullscreen()` 并新增三个方法

```js
fullscreen(){ const n=!this.state.fs; this.setState({fs:n,ctrlHidden:false}); document.body.classList.toggle('luban-fs',n);
  if(n){ this.updateFsScale(); this.scheduleHide(); } else if(this._hideT){ clearTimeout(this._hideT); this._hideT=null; }
  try{ const el=this._phone||document.documentElement; let p;
    if(!n){p=(document.exitFullscreen||function(){}).call(document);} else {p=(el.requestFullscreen||function(){}).call(el);}
    if(p&&p.catch)p.catch(function(){}); }catch(e){} }
updateFsScale(){ try{ const sc=Math.min(window.innerWidth/390, window.innerHeight/462); document.body.style.setProperty('--fs-scale', String(sc)); }catch(e){} }
scheduleHide(){ if(this._hideT){clearTimeout(this._hideT);this._hideT=null;} if(this.state.fs&&!this.state.ctrlHidden){ this._hideT=setTimeout(()=>{ if(this.state.playing)this.setState({ctrlHidden:true}); },3500); } }
tapToggle(){ if(!this.state.fs)return; const h=!this.state.ctrlHidden; this.setState({ctrlHidden:h}); if(!h)this.scheduleHide(); }
```

`toggle()` 末尾（方法闭合前）加一句，让播放开始后自动隐藏：

```js
if(this.state.fs)this.scheduleHide();
```

## §C 验收（回灌后过一遍）

- 手机默认屏无变化（不点全屏＝原样）。
- 点全屏：头部/底部消失，只剩动画+字幕，舞台等比铺满、留黑边不裁切。
- iPad 竖屏、横屏、转屏：缩放实时重算、内容不溢出不裁切。
- 点屏：控制条浮现；播放中 ~3.5s 自动隐藏；暂停时保持可见；退出按钮 ⊠ 可回手机屏。

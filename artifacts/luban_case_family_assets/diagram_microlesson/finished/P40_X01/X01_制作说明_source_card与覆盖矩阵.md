## 1. source_card（从成品 MD 提炼）

- **main_exam_action**：给平面布置示意图/设计要点清单，识别各区、补全内容、写「布置理由」因果句；MCQ 辨识图内容/垂直运输设备/围挡数字。判分核心 = **布置内容齐全 + 布置位置合理 + 布置理由落到因果句**。
- **wrong_idea**：① 画了拟建建筑就算布置图；② 各区标名字 + 写「布置合理」就得分；③ 只设一个大门；④ 塔吊「放中间能吊到就行」；⑤ 泵/升降机因素混搭；⑥ 布置步骤乱序；⑦ 围挡一刀切 1.8m；⑧ 五牌一图答「挂些牌子」；⑨ 吊篮当垂直运输。
- **teaching_spine**：识别约束（有限场地×密集功能）→ 分区+流线布置各设施 → 校核内容/理由/法规完整。自然阶段：**上集=布置什么·怎么布置（图·原则·设施）**；**下集=怎么落地（步骤·围护·布置理由）**。
- **facts**（全部 🟢 教材/真题锚，见 MD §5 R5）：图内容六项、设计原则七条、大门≥2、塔吊八因素、泵四因素、升降机七因素、临设布置步骤、仓库位置、围挡三档、五牌一图六项、布置理由因果句、垂直运输设备辨识。
- **common_errors**（映射 registry，MD §6）：E02 采分点遗漏 / E03 关键词缺失 / E04 口号化 / E06 程序顺序 / E07 概念混淆 / E08 背景提取失败 / E10 规范适用 / M03 客观题概念混淆 / M08 规范数字混淆。
- **practice_blueprint**：图示题卡 + 完整采分句选项 + 每错项三段解析 + 薄弱点诊断，末题为「工期/答案诊断」型的综合采分诊断。

## 3. visual_archetype_decision

- **primary_archetype**：`site_plan`（俯视施工总平面图）——场地矩形 + 中心拟建建筑 + 四周分区/设施逐个落位。平面布置本体就是「在有限平面上安排设施」，俯视图是其天然领域对象。
- **secondary_archetype**：`checklist_on_plan`（图内容六项/塔吊八因素/五牌一图=对象钉在平面/墙面上点亮，非文字框）、`threshold_ruler`（围挡三档高度标尺）、`report_pipeline`（临设布置步骤有向节点+道路串联）、`cause_bubble`（布置理由=各区因果句同步弹出）。
- **visual_primitive**：绝对定位 CSS 形状——场地框、拟建建筑块、分区色块、大门缺口、塔吊+覆盖圈、泵管+罐车、升降机+附墙、围挡分段（路口 repeating-linear-gradient 竖条=通透）、五牌一图色顶条卡片、示意图编号点 + 因果 chip。
- **motion_grammar**：对象级动作（落位/覆盖圈扩张/命中/分流/因果弹出/退出），每 beat 一个动作、切层 lo{i}、不累积画面；相位顺序与字幕句序对齐（W(a,b) 窗口）。
- **why_this_visual**：判分核心是「布置在平面上的位置与相互关系」，只有俯视平面图能同时表达「布置了什么 + 摆在哪 + 为什么」。
- **why_not_text**：纯文字框/判断框只能列清单，表达不了「靠近材料运输」「覆盖圈罩全楼」「路口通透留视距」这类**空间关系**——而空间关系正是采分点，文字框会把布置题降维成背诵题。

## 4. domain_visual_plan（每 beat 领域对象 + 验收判据）

**上集**
- **b0 破误区**：俯视场地框 + 中心拟建建筑 + 四周 4 块虚线「?」空区脉冲 + 误区气泡 + 红「误区✕」章。*判据：正确当且仅当画出俯视场地边界+中心建筑+四周待布置空区(带?)，且误区指向「只画建筑」。*
- **b1 图内容六项**：场地框上 6 个带色顶条编号卡逐个点亮（②=中心建筑内嵌）。*判据：六项逐项点亮且每项钉在平面对应位置（非纯文字清单）。*
- **b2 设计原则+分区流线**：场地切 3 分区色块（加工/储存/办公生活）+ 储存→使用点最短红线（scaleX 生长）+ 7 原则 chip。*判据：≥3 分区色块 + 一条到使用点的最短流线，体现减少二次搬运。*
- **b3 大门≥2**：围墙框 + 单门红车拥堵 → 第二门开 + 绿车两处分流。*判据：围墙上≥2 个门缺口 + 进出分流，对比单门拥堵。*
- **b4 塔吊八因素**：中心塔吊 + 覆盖圈 scale 罩主楼 + 第二塔吊留防撞间距 + 8 因素 chip 环绕。*判据：覆盖圈罩住主楼 + 群塔防撞间距画出 + 八因素齐。*
- **b5 泵+升降机**：左泵+泵管 scaleX 到浇筑点+罐车+4 因素；右升降机贴主楼+附墙+轿厢升+7 因素。*判据：泵管指向浇筑点、升降机贴楼有附墙，两列因素不混。*
- **b6 口诀**：6 张色顶条卡逐张亮（图/原则/大门/塔吊/泵/升降机）。*判据：六卡各对应一采分点、收官句出现。*

**下集**
- **b0 破误区**：名字-only 三区块 + 「布置合理」注 + 红「0 分✕」章。*判据：只标名字的区+口号注+0分判定，指向「合理≠采分」。*
- **b1 布置步骤**：5 个编号设施块按序落位（仓库堆场→加工厂→道路带→房屋→水电）。*判据：五步按固定顺序出现，先仓库堆场、最后水电。*
- **b2 仓库位置**：材料库→使用点短绿线（近）；危险品库←→火源虚线安全距离（远）。*判据：材料库近使用点、危险品库远火源，两者几何真不同。*
- **b3 围挡三档**：地面线 + 市区 2.5（高实）/一般 1.8（中实）/路口（上部竖条通透+下部实）。*判据：三段高度真不同 + 路口段上部可见通透竖条。*
- **b4 五牌一图**：入口墙 + 6 块色顶条牌逐块亮（5 牌 + 1 图）。*判据：六块齐、含总平面图。*
- **b5 布置理由（climax）**：左示意图 7 个编号区点 + 右 7 条「①区→因果」chip 同步弹出。*判据：每区配一句因果理由、强调「非合理二字」。*
- **b6 口诀**：5 张卡（步骤/仓库/围挡/五牌一图/布置理由）。*判据：五卡各对应采分点、收官句「写因果不写合理」。*

## 5. 分集方案与理由

- **分 2 集 + 1 合并练习**。理由：12 个采分点全覆盖后单集预估 >5 分钟；按 teaching_spine 自然阶段拆分——**上集=布置什么·怎么布置**（图内容/原则/大门/塔吊/泵/升降机/垂直运输辨识 7 点），**下集=怎么落地**（布置步骤/仓库/围挡/五牌一图/布置理由 5 点）。不在任一采分动作中间硬切。每集独立完整：自己的破误区 hook、7 主讲 beat、领域对象、4 QA（每问带迷你领域图）、收官终屏、上/下集与做练习导航。
- **练习采用合并策略**：一套 `施工平面布置原则_练习.dc.html`，15 题候选覆盖上下集全部采分点，随机抽 5 题；学生端无 pack/R5/point_id 等制作词。选项均为完整采分句，正确项经运行时独立洗牌（位置不固定）、且长度与错项相当（不靠选最长蒙对）。

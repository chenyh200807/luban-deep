## 1 · source_card

- **main_exam_action**：给定「直径 × 受力性质 × 荷载性质 × 部位/抗震」四输入，匹配「绑扎搭接 / 机械连接 / 焊接」之一；选定后把接头位置、检具、灌浆料、代换守恒对上。
- **wrong_idea**：把连接选用当「记哪种最牢」；把小直径受压规则误用到大直径受拉/动力构件（端点搞反）；把「不应超过50%」弱化成「不宜」；接头位置写反；代换只看面积、把等刚度当基本要求、把裂缝验算/配筋率当构造要求。
- **teaching_spine**：① 判型（四输入 → 三方式，越大直径·受拉·动力·抗震关键越往机械端）→ ② 端点（受拉Φ28/桁架/行车梁不宜绑扎、受压Φ25可绑扎）→ ③ 动力荷载 → 机械连接 + 接头面积百分率不应超过50% → ④ 装配式竖向连接（边缘逐根/非边缘≤600/套筒灌浆）‖ 平行下游：⑤ 接头位置（梁上部跨中1/3、下部梁端1/3；柱≥500/H6/b 取最大）→ ⑥ 代换守恒（等强度+等面积+构造+设计同意）→ ⑦ 下游验收（直螺纹检具通/止/量规、灌浆料40×40×160·每层≥3组·标养28d）。

## 2 · 分集方案与理由

采分点共 12 组（Q1 三类 / Q2 套筒最常用 / Q3 动力50% / Q4 端点 / Q5 冷拉率 / L1 梁位置 / L2 柱位置 / Z1 装配式 / D1 代换基本 / D2 代换构造 / X1 检具 / X2 灌浆料），是 N03 母版（6 采分句）的两倍。一集塞不下且会挤掉采分点 → **按 teaching_spine 自然阶段拆 2 集**，不为控时长删点。

- **上集《选哪种》= 选用决策主线**：破误区+三类连接对象 → 判型标尺 → 端点 → 动力50% → 装配式竖向。覆盖 Q1/Q2/Q3/Q4/Z1，冷拉率 Q5 落 QA。
- **下集《选定之后》= 平行下游模块**：接头位置（梁/柱）→ 代换守恒 → 代换构造vs设计 → 下游验收（检具/灌浆料）。覆盖 L1/L2/D1/D2/X1/X2。

拆点落在 teaching_spine 的天然缝（选用 vs 选定后的位置/代换/验收），不在任一采分动作中间硬切。每集都是完整学习卡（独立 hook + 5–6 主讲 beat + 4 QA + 收官终屏 + 上一集/下一集/做练习导航）。

**练习采用合并策略**：一个 `C05_钢筋连接选用_练习.dc.html` 覆盖全集知识点，题库 ≥15 道、每次随机抽 5 道；题 tag 标阶段（判型/端点/动力/装配式/位置/代换/验收/加工），学生端不出现 pack/R5/point_id 等制作词。

## 4 · visual_archetype_decision（冻结）

- **primary_archetype**：`threshold_ruler`（判型标尺：四输入→绑扎/机械轴指针命中）+ `threshold_trigger`（动力荷载指针滑过临界→触发机械连接+50%面板）。
- **secondary_archetype**：顺逆/镜像对比（端点：受拉Φ28 vs 受压Φ25 两侧几何不同）+ 现场剪影（梁弯矩图接头滑移、柱标尺、装配式剪力墙、代换天平、答题纸/检具扫描）。
- **visual_primitive**：CSS 形状钢筋（带肋圆钢=横纹渐变条）、直螺纹套筒（螺纹条+咬合两端）、焊缝热影响区（红晕圈）、绑扎搭接（两条搭接+八字丝扣）、判型标尺三档带+探针、面积百分率剖面条、弯矩抛物线、代换天平、检具卡尺、灌浆料长方体试件。
- **motion_grammar**：对象级进入/滑移/命中/淘汰/配平/扫描，缓动 `eo(p)=1-(1-p)^3`，窗口 `W(a,b)` 绑到 caption 分页；每 beat 切层不累积。
- **why_this_visual**：选用是「四输入→匹配」的决策，标尺+探针把「越大直径·受拉·动力·抗震越往机械端」画成可见的吸附动作；代换是守恒，用天平配平/失衡画守恒 vs 破坏。
- **why_not_text**：纯文字框只能罗列「三种方式/50%/取最大」，无法表达「端点搞反」「不应vs不宜」「等刚度失衡」这类判别，学生记不住方向。

## 5 · domain_visual_plan + 每 beat 对象验收判据

### 上集
- **b0 破误区**：三类连接物理对象（焊缝+红热影响区 / 直螺纹套筒咬合 / 绑扎搭接+八字丝扣）自左进入 → 误区气泡「哪种最牢就选哪种？大直径受拉图省事绑扎？」→ 红章「误区✕」砸下 → 套筒亮「最常用」。**判据**：正确当且仅当三种连接画成可区分的物理对象（熔缝带HAZ ≠ 螺纹套筒 ≠ 搭接绑丝），且误区被红章淘汰、直螺纹套筒标最常用。
- **b1 判型标尺**：四输入旋钮（直径/受力/荷载/部位）→ 探针在「绑扎搭接 — 机械连接」轴滑动，越大直径·受拉·动力·抗震越吸机械端并命中高亮。**判据**：正确当且仅当四个输入作为输入出现，且探针沿绑扎↔机械轴按输入滑动命中。
- **b2 端点判断**：左 受拉Φ28 搭接→红✕「不宜绑扎」→应机械连接；右 受压Φ25 搭接→绿✓「可绑扎」。**判据**：正确当且仅当两侧钢筋直径/受力标注不同，一侧因受拉大直径被否、一侧因受压中径被准（几何真不同，非换标签）。
- **b3 动力荷载+50%**：吊车梁动力荷载（振动/移动轮）→ 探针滑过临界→机械连接锁定→接头面积百分率剖面条填到 50% 红线，强调「不应」。**判据**：正确当且仅当动力荷载被画出（振动/移动载）触发机械连接，且 50% 阈值条+「不应」关键词出现。
- **b4 装配式竖向连接**：预制剪力墙，边缘构件竖筋逐根套筒灌浆连接、非边缘竖筋间距≤600mm，灌浆料注入套筒。**判据**：正确当且仅当边缘逐根 vs 非边缘≤600 两区几何不同 + 套筒灌浆动作。
- **b5 口诀回扣**：判型·端点·动力50%·装配式 四卡点亮。

### 下集
- **b1 梁接头位置**：框架梁+弯矩抛物线，接头方块从最大拉应力区（红）滑到 上部跨中1/3 / 下部梁端1/3（绿）。**判据**：正确当且仅当梁上有弯矩图，接头方块从应力大区滑到 1/3 区并亮绿。
- **b2 柱接头位置**：柱身+标尺弹出 ≥500mm / ≥H/6 / ≥b 取最大，箍筋交错八字形。**判据**：正确当且仅当三条下限并列且「取最大」被标出 + 八字丝扣。
- **b3 代换天平**：左盘原配筋、右盘代换配筋；「等强度/等面积」配平亮绿、「等刚度」砝码放上失衡报红，标「须设计单位同意」。**判据**：正确当且仅当天平因等强度/等面积配平、因等刚度失衡（守恒 vs 破坏可见）。
- **b4 代换构造vs设计**：把 token 分拣进两筐——构造要求筐（钢筋间距/保护层/锚固长度）绿、设计要求筐（裂缝宽度验算/配筋率）灰，防类别错配。**判据**：正确当且仅当两类被真分拣到不同筐、干扰项落设计筐。
- **b5 下游验收**：直螺纹检具 通规/止规/量规（绿）+ 直尺（红✕）；灌浆料 40×40×160 长方体试件（绿）vs 70.7 立方体（红✕），标每层≥3组·标养28d。**判据**：正确当且仅当检具三件+直尺✕，长方体试件+立方体✕，且数值出现。
- **b6 口诀回扣**：位置·代换·验收 三卡。

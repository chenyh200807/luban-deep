## 1. source_card

- **main_exam_action**：防水细部节点错误辨析 + 细部施工顺序/关键数值判别 —— 判「节点做法对不对 + 关键数值准不准 + 节点是否先做」。

- **teaching_spine**：
  - 阶段一（竖向/室内细部 + 顺序）：先细部后大面 → 阴阳角圆弧/45度 → 薄弱节点先做附加层夹胎体 → 管根/穿楼板套管密封嵌填·高出≥20mm。

- **common_errors（error_code 按 registry 真义）**：阴阳角直角(E10/M03)、不做/后做附加层(E02/E06)、泛水写200(E10/M08)、附加层/坡度/伸入数值错(M08)、只密封不压条(E02/M01)、平顶不排水(E10)、先大面后细部(E06)、把大面铺贴/设防道数答进细部(M03)。

## 4. visual_archetype_decision

- **primary_archetype**：`threshold_ruler / dimension_check`（泛水250、附加层250、套管≥20、坡5%、伸入50 等数值命中）。
- **secondary_archetype**：`mirror_contrast`（阴阳角 直角翘空 vs 圆弧平顺；压顶 平顶积水 vs 向内坡排水）+ `layer_buildup`（附加层先做→大面后铺）+ `report_pipeline`（先细部后大面 节点顺序）+ `lock_edge`（收头 负风压掀→压条钉压锁边）。
- **visual_primitive**：CSS 形状——卷材条(#46627e)、基层/墙(#cbc4b2)、附加层(#cf8a44)、涂膜/命中(#2c8a5b)、积水(#7fb0d8)、金属压条/套管(#8a949a/#6f7d86)、红标尺/误区(#cf4436)。
- **motion_grammar**：对象级进入/生长/命中/掀起/落条/滴水/退出，`eo(p)=1-(1-p)^3` 缓动、`W(a,b)` 窗口把每对象绑到对应字幕页；相位顺序与旁白句序一致。
- **why_this_visual / why_not_text**：本考点判分眼是「几何做法对错 + 关键数值达标」，纯文字框无法让学生看出「直角翘空 vs 圆弧平顺」「泛水200差50mm」「压条锁自由边」——必须画领域对象、动作演示；决策树/流程框/答案框一律判失败。

## 5. domain_visual_plan（每 beat 领域对象 + 对象验收判据）

**上集**
- b0 破误区：墙/屋面阴角 + 直角硬折卷材(翘空红弧) + 未密封管根(红虚框)。判据：正确当且仅当画出「直角处卷材翘空缺口」和「管根缺密封标记」两处错。
- b1 先细部后大面：节点①→连线→大面② + 错误顺序划掉。判据：当且仅当「先节点后大面」两节点有序+错误分支被红叉。
- b2 阴阳角对比：左直角(硬折+翘空+应力红点) vs 右圆弧(填角+卷材沿弧+✓)。判据：两侧几何真不同——左尖折、右圆弧，判别特征=卷材是否沿圆弧平顺。
- b3 附加层：基层→橙附加层(贴内角+胎体条纹)→深大面(盖外侧) + 图例。判据：当且仅当附加层在节点、位于大面之下且先出现。
- b4 管根套管：楼板+管+套管+橙密封嵌填+绿管根密封+「高出装饰面≥20mm」标尺。判据：当且仅当套管高出装饰面且标出≥20mm。
- b5 口诀：4 卡（顺序/阴阳角/附加层/管根）。

**下集**
- b0 破误区：女儿墙+平顶积水+泛水只翻200。判据：画出「压顶积水」「泛水200不足」两处。
- b1 泛水标尺：卷材翻起生长 + 200红档(不够) + 250绿档(命中)。判据：当且仅当探针/膜到250才命中、200判不足。
- b2 女儿墙附加层：阴角+橙附加层 + 立面≥250竖标尺 + 平面≥250横标尺。判据：当且仅当平、立面两向都标≥250。
- b3 压顶对比：左平顶(蓝积水+红回渗) vs 右向内坡(斜压顶+绿涂膜下压顶下+↘)。判据：两侧压顶几何真不同（平 vs 斜内坡）。
- b4 收头：卷材收头 + 负风压红▲(掀) + 金属压条落下+钉点 + 密封 + 下端鹰嘴+滴水珠。判据：当且仅当压条钉压卷材自由边 + 鹰嘴滴水槽出现。
- b5 檐口·水落口：檐口800满粘绿带+鹰嘴 / 水落口杯+涂膜附加层+伸入≥50+周边500坡。判据：当且仅当檐口标800满粘、水落口标伸入≥50。
- b6 口诀：5 采分句竖列。

每集 ≥4 主讲 beat 出现真实领域对象（上集 b0-b4 全部；下集 b0-b5 全部），无「只有决策树/流程框/答案框」的 beat。

## 6. 390px 手机截图检查结论

- 三卡均按 390×462 舞台 + 390 宽手机卡设计，截图在 390 基准通过。
- 领域对象 top 均 ≥48px 安全区（顶部旁白/胶囊/全屏钮带未被压）。
- 文字标签不压深色卷材/套管：灰/红字均落浅底(#f4f3ec)或对象白字；深色卷材上不放灰字。
- 对比类（阴阳角、压顶）两侧几何真不同，判别特征可辨；已修正 beat3/beat5 面板嵌套宽度导致的竖排换行、beat5 水落口标签重叠。
- 练习：选项每题独立洗牌（正确项不固定首位）、正确项非最长、三段解析+错因码+采分句模型框渲染正常，结果页表现分析/薄弱点/继续补练/问鲁班齐全。

## 1. source_card

- **main_exam_action**：凡地基验槽与地基处理，都按「先诊断（验槽：备资料→观察法为主/钎探辅→可不触探三情况判免）→ 再对症处理（浅层软弱换填／松散厚层强夯／水位以上湿陷黄土灰土挤密／软土搅拌·CFG·注浆）→ 最后验收（承载力检验频率／强夯休止后检）」逐项裁决。
- **wrong_idea**：①验槽=拿仪器猛探、主方法答成钎探；②天然地基必须触探（漏「可不触探三情况」）；③把「均匀密实砂>1.5m」记成「>1m」；④换填墙角下接缝/缝距随意/灰土隔日铺填；⑤强夯有效深度从「终夯后地面/锤顶面」算；⑥灰土挤密用到水位以下、不试验；⑦地下水流动仍用单液浆。
- **teaching_spine**：诊断（验槽）→ 治疗（地基处理选型+参数）→ 验收（检验）。自然分两阶段 → **两集**。
- **facts（全 🟢 锚定，见主源 §1/§5）**：
  - 验槽资料：五方到场+设计文件+勘察报告+轻型动力触探记录+地基处理/深基础检测报告+基底保护层≤100mm（A1）
  - 可不触探三情况：承压水头高于坑底 / 砾石卵石层>1m / 均匀密实砂层>1.5m（A2）
  - 验槽方法：观察法为主（槽壁槽底土质与勘察一致/开挖深度/土质未破坏），钎探辅（A3）
  - 轻型动力触探用途：持力层强度/均匀性/软弱层/古井/墓穴/空洞（A4）
  - 复合地基现场验槽：查桩间土情况（A5，真题 {2022,第12题}）
  - 换填：浅层软弱土0.5~3m；素土/灰土/砂石/粉煤灰；灰土比2:8或3:7；分层200~300mm；压实系数灰土粉煤灰≥0.95其他≥0.97（B1/B2）
  - 换填接缝：禁柱基/墙角/承重窗间墙下接缝；上下层缝距≥500mm夯压密实；灰土当日铺填（B3，真题 {2022,第13题}）
  - 强夯参数：夯锤10~60t；锤底静接地压力25~80kPa；排气孔300~400mm（C1）
  - 强夯有效加固深度：从最初起夯面起算（C2，真题 {2017,第5题}）
  - 强夯施工后检验：承载力/地基土强度/变形指标/其他设计要求（C3）
  - 灰土挤密：水位以上粉土/黏性土/素填土/杂填土/湿陷黄土；厚3~15m；含水>24%或饱和度>65%需试验（D1）
  - 软土选型：搅拌桩禁大孤石/密实砂/渗流区；注浆水流禁单液浆；CFG按水位选工艺（水位以上长螺旋/水位以下泥浆护壁）（D2）
  - 承载力检验频率：每300m²≥1点；超3000m²每500m²≥1点；每单位工程≥3点（E1）
  - 强夯休止（🔵法规外延）：砂土≥7d/粉性土≥14d/黏性土≥28d（E2）
- **common_errors**（映射 registry）：E02 采分点遗漏 / E03 关键词缺失 / E07 概念混淆 / E10 规范适用错误 / E11 迁移失败 / M03 概念混淆 / M04 选项陷阱 / M08 规范数字混淆 / M10 常识替代规范判断。
- **practice_blueprint**：判定链（可不触探/换填参数/选型适用）+ 判断纠错（验槽方法/换填做法）+ 内容清单枚举（验槽资料/触探查项）+ 采分诊断末题。

## 3. visual_archetype_decision

- **上集（验槽/诊断）**
  - primary_archetype：`answer_sheet`（验槽资料文件夹清单展开 + 缺项闪红）+ `site_scene`（基槽剖面 + 放大镜观察 / 钎杆触探）
  - secondary_archetype：`threshold_trigger`（可不触探三情况判据）
  - visual_primitive：基槽剖面、文件夹/公文、放大镜、钎杆、条件卡、增强体桩+桩间土
  - motion_grammar：文档逐份飞入围合、放大镜扫过槽壁点亮、钎杆下插、条件卡逐点亮、硬触探→坑底冒水涌砂淘汰
  - why_this_visual / why_not_text：验槽是「看+探」的现场动作，纯文字框无法表达「主方法是看不是探」与「哪三种情况可以不探」；用剖面+放大镜+钎杆的相对主次画出「观察为主、钎探辅」。
- **下集（地基处理/治疗+验收）**
  - primary_archetype：`handling_chain`/病因→工法对症面板 + 换填分层夯实剖面 + 强夯起算面标尺
  - secondary_archetype：`threshold_trigger`（灰土挤密水位条件）+ `answer_sheet`（承载力检验网格）
  - visual_primitive：软土坑、换填分层块、压实仪表、接缝位置图、夯锤+起算面标尺、水位线、检验网格
  - motion_grammar：病因卡→工法卡连线触发、软土挖除→分层回填夯实、夯锤落下+标尺从最初起夯面量深、水位线上下判定、网格布点
  - why_this_visual / why_not_text：地基处理是「病因→对症工法→参数」的因果，纯判断框会退化成选项记忆；强夯起算面必须画出「从哪条线量」才讲得清 C2。

## 4. domain_visual_plan（每集 ≥4 主讲 beat 有领域对象）

**上集**
- b1 文件夹展开6份验槽资料，逐份飞入；漏一份文件夹闪红✗。**判据：正确当且仅当6份资料（含"五方到场"与"保护层≤100mm"）都作为独立文档画出。**
- b2 基槽剖面：放大镜（主）扫槽壁槽底点亮"土质一致/深度达标/未破坏"，钎杆（辅）下插标"强度/均匀性/软弱层/古井墓穴空洞"；放大镜比钎杆大、先动。**判据：正确当且仅当放大镜是主视觉、钎杆明显为辅（大小/先后可辨），二者分别标注各自查项。**
- b3 可不触探标尺：三张条件卡点亮①承压水头高②砾卵石>1m③密实砂>1.5m；硬触探承压水→坑底冒水涌砂✗。**判据：正确当且仅当"砾卵石>1m"与"密实砂>1.5m"两个阈值在画面上分别标注、数值不同。**
- b4 增强体复合地基：桩+桩间土剖面，放大镜对准"桩间土"✓、对准"均匀性报告/湿陷效果"✗。**判据：正确当且仅当放大镜命中的是"桩间土"，干扰项以✗区分。**

**下集**
- b1 病因→工法对症：4 病因卡（浅层软弱/松散厚层/水位以上湿陷黄土/软土）连线到 4 工法（换填/强夯/灰土挤密/搅拌·CFG·注浆）。**判据：正确当且仅当病因与工法一一连线对应、非并列 token 堆。**
- b2 换填剖面：软土坑挖除→灰土分层块回填（标200~300mm）→压实仪表升到≥0.95→接缝位置图（墙角✗、避开✓、缝距≥500mm）。**判据：正确当且仅当"分层200~300mm""压实≥0.95""接缝避墙角+缝距≥500mm"三者都以对象画出。**
- b3 强夯起算面标尺：夯锤（10~60t）落下，标尺从"最初起夯面"向下量有效深度；对照"终夯后地面/锤顶面"起算→标尺错位✗。**判据：正确当且仅当标尺零点画在"最初起夯面"、且与错误起算面形成可辨对比。**
- b4 选型条件（threshold）：水位线，灰土挤密桩在水位以上✓（含水>24%→试验标记）；搅拌桩遇密实砂/大孤石✗；注浆水流禁单液浆。**判据：正确当且仅当"水位线上下"决定灰土挤密可否，且画出至少一个禁用条件。**
- b5 验收网格：承载力检验网格每300m²布1点（含每单位工程≥3点）+ 强夯休止 7/14/28d 时间轴。**判据：正确当且仅当"每300m²1点"以网格布点画出。**

## 5. 分集方案与理由

- **两集**：上=验槽（诊断），下=地基处理（治疗）+验收。
- **理由**：15 条 R5 采分点（A/B/C/D/E 五组）+ 各集 4 QA + 领域对象动画，单集覆盖全部预计 >5 分钟；teaching_spine 天然分「诊断 / 治疗」两阶段，在此切分不打断任何单个采分动作。上集 6 主讲 beat（约 4 分），下集 7 主讲 beat（约 4.6 分），各自独立可播放、各有 hook / QA / 收官终屏 / 互链。
- **练习**：采用**合并练习**（一套 `_练习.dc.html`），题库 ≥15 覆盖全集 A/B/C/D/E，每次随机抽 5；学生端不出现 pack/R5/point_id 等制作词。

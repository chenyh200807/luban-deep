# 项目约定（鲁班智考 动画学习卡）

## 图标 / 符号：禁用装饰性「→」箭头（用户定，全局适用）
- **按钮 / CTA / 导航标签**不带箭头后缀：写「做练习」「下一题」「查看结果」「上一集/下一集」，**不写**「做练习 →」这类。
- **文案 / 口诀 / 流程说明 / 卡片标签**里不用「→」符号作连接：用「·」「、」或直接用文字（如「先审核再审查」）表达。
- **流程/管道图的方向**由「节点顺序 + 连线 + 动画（载体流转）」表达，节点之间**不用「→」字符**（本项目已统一改为中点「·」或省略）。
- 适用范围：所有讲解页 / 练习页 / 母版（本项目 `AnimatedLecture.dc.html`、`templates/practice-quiz/PracticeQuiz.dc.html` 已同步）。
- **设计系统源母版在只读项目内，无法在此改动；需在设计系统侧（design-system.md / 母版_讲解 / 母版_练习）同步注明并落地此约定。**

## 练习题：防「按规律蒙对」（用户定，全局适用）
- **正确项不得固定在 A**：每题选项显示顺序必须独立洗牌（Fisher-Yates），重做时重新洗；作答/判分按源下标，洗牌只改显示位与 A/B/C/D 字母。已在 `pickOptOrders()`/`optOrderFor()` 实现，本项目练习页与 `templates/practice-quiz/PracticeQuiz.dc.html` 已同步。
- **正确项不得总是最长**：干扰项必须写成与正确项长度相当的「完整采分句」，不能是短关键词标签——否则「选最长」就能蒙对。诊断/枚举类正确项确实偏长时，须把干扰项一并加长、并适度精简正确项，缩小长度差。
- 出题自检：随机看几遍，确认正确项的位置和长度都不构成可套用的规律。
- **设计系统源母版在只读项目内，无法在此改动；需在设计系统侧（母版_练习）同步落地洗牌与选项等长两条约定。**

## 备注
- 「箭头」约定源于用户反馈：装饰性 → 箭头是 UI 俗套（尤其按钮后缀），不符合本卡「用领域对象讲知识、少装饰」的取向。
- 「防蒙对」约定源于用户反馈：原练习正确项恒为 A 且恒为最长，学生不理解也能按规律答对，是重大漏洞。

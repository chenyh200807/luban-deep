- **main_exam_action**：给幕墙防火/防雷/层间封堵做法，判正误 + 案例纠错并写正确采分句。

- **teaching_spine（堵—隔—疏—选材）**：幕墙空腔=烟囱/引雷体 → 堵（层间封堵）→ 隔（防火构造尺寸）→ 疏（防雷连接）→ 选材（有机堵料）。
- **facts（全部锚定，直取 MD §1/§5）**：实体墙≥1.2m｜挑檐≥1.0m 且长≥开口宽｜空腔填塞≥200mm｜承托板≥1.5mm 镀锌钢板不得铝板｜楼板缝封堵不燃岩棉/矿棉≥100mm+耐火极限+水平防火烟带+防火密封胶｜同一玻璃单元不跨两个防火分区｜金属框架连主体防雷体系｜立柱≤10m 一根柔性导线连通上下柱｜预埋件圆钢/扁钢焊均压环、一般每三层｜有镀膜除镀膜层｜防雷连接必做隐蔽验收｜有机堵料可塑/遇火发泡/水密气密/可重复使用。
- **common_errors**：M1 单位(1.5m)｜M2 铝板承托｜M3 200/100 混｜M4 防雷不验收｜M5 立柱不连｜M6 漏均压环/除膜｜M7 漏水平烟带/密封胶｜M8 跨分区｜M9 堵料不可重复(反)。

## 2. 分集方案与理由

**判定：拆两集 + 一套合并练习。**

- **为什么必须拆**：11 采分点 + 9 误区，两条独立防线（防火/封堵 vs 防雷）+ 材料外延。全覆盖一集实测远超 5 分钟上限；按红线「完全覆盖优先于时长，超 5 分钟必须分集，不许删采分点」拆分。
- **拆分边界（按 teaching_spine 自然阶段，不在采分动作中间切）**：
  - **上集「防火关 · 堵+隔」**（DUR≈4′58″，7 主讲 beat + 4 QA）：烟囱效应/定性 → 层间封堵五要素 → 钢 vs 铝 → 防火尺寸（实体墙/挑檐/空腔）→ 不跨分区 + 200/100 部位。
  - **下集「防雷关 · 疏+选材」**（DUR≈4′58″，7 主讲 beat + 4 QA）：引雷/框架连主体 → 立柱柔性导线跨缝 → 预埋件焊均压环每三层 → 除镀膜+隐蔽验收 → 有机堵料。
- **练习策略：合并**。一套 `_练习.dc.html` 覆盖上下两集全部采分点，Q[] 15 道候选、每次随机抽 5。理由：客观/案例采分点交织，合并更贴近真题综合作答；学生端不出现 pack/R5/point_id 等制作词。互链：上集底「下一集」→下集；下集底「上一集/做练习」；练习头「看讲解」→上集，结果页「问鲁班」→上集。

## 4. visual_archetype_decision（冻结）

- **primary_archetype**：`threshold_ruler` / 条件维阈值（防火尺寸 1.2/1.0/200/100/1.5、立柱 10m）。
- **secondary_archetype**：`site_scene`（幕墙剖面/楼层空腔）+ `report_pipeline`（雷电流通路）+ 顺逆/镜像对比（钢vs铝、跨分区vs不跨、有导线vs断路）。
- **visual_primitive**：幕墙立面/剖面、楼层空腔、火焰、岩棉块、承托板、玻璃单元、防火分区界线、金属框架、雷电流脉冲、均压环、柔性导线、镀膜/验收章、有机堵料块。
- **motion_grammar**：火沿空腔上蹿；铝板受热下垂+岩棉坠落 / 钢板挺立；探针/标尺命中；玻璃单元跨界高亮红；电流脉冲沿框架下泄入地；断缝跳火 vs 柔性导线跨缝导通；均压环滑入+焊点脉冲；镀膜被刮除后电流通过；堵料遇火发泡膨胀。
- **why_this_visual**：数值密集 + 材料选型 + 连接路径，靠"标尺命中 + 对象对决 + 电流通路"才能让陌生学生只看图分清对错。
- **why_not_text**：纯文字卡记不住 1.2/1.0/200/100/1.5 之间的部位差、也分不清钢/铝、断路/连通——必须画出判别特征。

## 5. domain_visual_plan + 每 beat 对象验收判据

**上集（防火关）**
- b0 破误区：岩棉+铝色承托板+红章。判据：*正确当且仅当画出承托板托着岩棉、且标出"铝板/1.5m"被红章否定。*
- b1 烟囱效应：主体墙+楼板×3+玻璃幕墙+空腔火焰上蹿。判据：*正确当且仅当火焰在"楼板端与玻璃之间的竖向空腔"内自下而上移动。*
- b2 层间封堵：楼板缝岩棉+水平黄烟带+钢承托板+红密封胶+火被截单层。判据：*正确当且仅当五要素（岩棉≥100/耐火/水平烟带/钢承托/密封胶）随旁白逐条出现。*
- b3 钢vs铝：左铝板下垂+岩棉坠落✗ / 右钢板挺立+岩棉稳✓（两侧几何真不同）。判据：*正确当且仅当左侧承托板明显塌垂且岩棉下落、右侧平直，二者不靠换标签区分。*
- b4 防火尺寸：上/下开口+实体墙标尺≥1.2m+挑檐≥1.0m+空腔填塞≥200mm。判据：*正确当且仅当实体墙的竖向量尺与挑檐的横向挑出被分别画出。*
- b5 不跨分区+部位：左1块玻璃跨红分区界✗ / 右两单元不跨✓ + 200(空腔)/100(楼板缝)两卡。判据：*正确当且仅当左侧单元矩形骑在分区界线上、右侧单元落在界线一侧。*
- b6 口诀：堵/隔/材料/分区四卡。判据：*正确当且仅当四张卡分别承载封堵/尺寸/钢板/不跨分区四句。*

**下集（防雷关）**
- b0 破误区：金属框架+雷电+断点火花+红章。判据：*正确当且仅当画出框架某连接点断开打火、被红章否定。*
- b1 引雷+框架：金属框架+雷击+电流脉冲下泄+绿连接节点+地线。判据：*正确当且仅当亮色电流脉冲沿框架自上而下运动到接地节点。*
- b2 立柱导线：左断缝跳火✗ / 右柔性导线弧跨缝+电流贯通✓。判据：*正确当且仅当右侧有跨伸缩缝的导线弧且电流延伸到下柱、左侧电流止于缝口火花。*
- b3 均压环：立柱+楼层线+每三层橙均压环+红焊点。判据：*正确当且仅当均压环恰落在每第三条楼层线上、且立柱与环交点有焊点。*
- b4 除膜+验收：构件蓝膜+刮除缺口+电流通过+隐蔽验收"合格✓"章。判据：*正确当且仅当连接处的膜被刮出缺口、电流仅在缺口处通过。*
- b5 有机堵料：穿墙电缆+堵料遇火发泡膨胀+可重复使用标注。判据：*正确当且仅当堵料在火焰逼近时体积增大（发泡）。*
- b6 口诀：框架/立柱/均压环/验收四卡+选材注。判据：*正确当且仅当四卡分别承载防雷四要素、底注为有机堵料。*

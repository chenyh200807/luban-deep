## 1. source_card（从成品 MD 提炼）

- **main_exam_action**：判一个索赔事件「成不成立、工期/费用/利润各赔多少」。计算型 + 判断型双核。
- **wrong_idea（最高频）**：① 工期费用绑死（工期不成立→说费用也不成立，E07）；② 责任在对方就判工期顺延（不看总时差）；③ 不可抗力损失一刀切全给发包人（E10）；④ 非关键延误几月赔几月（不减总时差，E09）；⑤ 费用机械相加不分层。
- **teaching_spine**：成因三分 → 立案（28天）→ 双闸门裁决（工期闸：关键线路/总时差三分支 ‖ 费用闸：责任归属+不可抗力分担+利润）→ 互不蕴含裂点 →〔算多少〕工期定量（网络分析法）→ 费用分层（成本+管理费+利润）→ 利润归属 → 赶工优选 → 证据程序。
- **facts（全部锚 MD §1–§5，🟢真题）**：28天书面意向通知（未约定）；工期三分支；不可抗力分担（永久工程/已进场材料/清理归发包人，承包人机具自担）；2015·C 工期顺延1月/费用27.2万全额；2015·E 32.7万中设备8.2万自担、清理24.5万可索；费用分层 300+30+16.5=346.5万（2021案例四）；赶工优选主体2700元可压2天先于装修3000元（2017案例一）；证据四性。
- **common_errors（映射 ERROR_CODE_REGISTRY，勿自造）**：E02 采分点遗漏 / E03 关键词缺失 / E05 审题错误 / E06 程序顺序错误 / E07 概念混淆 / E08 背景提取失败 / E09 计算错误 / E10 规范适用错误。
- **practice_blueprint**：完整采分句选项 + 每错项三段（为什么容易选/为什么扣分带错因码/正确补哪句）+ 薄弱点诊断结果页。

## 2. 分集方案与理由

**拆 2 集**（自然阶段边界＝「判成立」vs「算多少」，不在任一采分动作中间硬切）。

- 完整覆盖成因/立案/工期三分支/费用责任/不可抗力切分/互不蕴含/工期定量/费用分层/利润/赶工/证据程序，预估远超 5 分钟单集上限；按红线「超 5 分钟必须分集、不许删采分点」拆集。
- 上集 = 判断核（双闸门互不蕴含），下集 = 计算核（列式判定链）。每集独立 6 主讲 beat + 4 QA + 收官终屏 + 导航，约 4 分 54 秒。
- **练习采用合并练习一套**（16 题覆盖两集知识点，随机抽 5），学生端不出现 pack/R5/point_id 等制作词。

## 4. visual_archetype_decision（冻结）

- **primary_archetype**：`双闸门`（本卡自造核心隐喻，R2 不变量可视化）——两道并排闸门（工期闸/费用闸），同一事件分别落入，可一开一封。
- **secondary_archetype**：`threshold_ruler / 缓冲弹簧`（总时差缓冲 + 延误溢出顶动竣工）、`责任筛`（investigation/handling 变体）、`资金堆叠`（费用分层）、`天平比价`（赶工优选）。
- **visual_primitive**：CSS 形状——道闸（立柱+旋转横杆）、缓冲区+溢出条+竣工节点、责任筛+双盘、堆叠柱、天平（三角支点+横梁+两盘）、沙漏、证据印章。
- **motion_grammar**：对象级动作——闸杆旋转（工期闸半开-30°/费用闸全开-76°）、延误条 scaleX 生长、竣工节点 translateX 顶出、损失块下落分盘、堆叠层逐层显、天平横梁 rotate 倾向主体、印章逐枚点亮。全程 RAF 驱动 `t`→标量，W(a,b) 窗口对齐字幕翻页。
- **why_this_visual**：索赔「双核」的命门是「工期闸与费用闸互不蕴含」；文字框/判断框会强化「绑死」误判。两道可独立开合的闸门把「各判各的」变成可见的机械动作。
- **why_not_text**：纯文字/流程框无法让学生「看见」工期封顶而费用全开；把独立性画成两闸一封一开，学生只看图即可分清。

## 5. domain_visual_plan（每 beat 的领域对象 + 进入/动作/退出）

**讲解·上（判成立）**
- b0 破误区：两误区气泡（责任→顺延？/ 工期黄→费用黄？）弹入 → 红章「想当然✕」压下 → 底部双闸门（两道道闸）点亮上移。退出：整层淡出。
- b1 成因立案：三源芯片（发包人/不可抗力/承包人）淡入 → 连线汇入「立案闸✓」（非承包人）/ 红虚线支路「✕反索赔」（承包人）→ 沙漏 28 天升起。
- b2 工期闸：三行缓冲装置分层显（关键/非关键超/非关键未超）→ 延误红条 scaleX 生长 → 行B 溢出段显（顺延1）、行C 全被绿缓冲吸收（不索赔）→ 各行判语弹出。
- b3 费用闸·责任筛：总额 32.7万 → 两损失块（设备8.2/清理24.5）下落穿过责任筛 → 落入承包人自担盘（灰）/发包人盘（绿）→ 发包人原因+利润 chip。
- b4 互不蕴含 HERO：C 事件卡下落 → 工期闸杆半开（amber，顺延1月）‖ 费用闸杆全开（green ✓，27.2万）→ 红 banner「工期封顶≠费用封顶」。
- b5 口诀：4 卡（定责任/立案/工期闸/费用闸）逐张显 + 「互不蕴含各判各的」脚条。

**讲解·下（算多少）**
- b0 破误区：两误区气泡 + 红章「漏步✕」→ 底部四步「计算判定链」卡（亮公式/代入/数值/回判）点亮。
- b1 算工期：总时差绿缓冲 + 延误红条 scaleX 生长 + 溢出段 → 竣工节点竖线 translateX 顶出（+1）→ 「顺延=延误2−总时差1=1月」banner + 网络分析法注 + 关键线路注。
- b2 算费用：三层柱逐层堆叠（成本300→管理费30→利润16.5）+ 右侧逐层公式 → 顶部「346.5万」→ 「利润基数=成本+管理费」注。
- b3 利润归属：左「发包人原因」面板（硬币✓费用 + 钞票✓利润）/ 右「不可抗力」面板（硬币✓分担 + 钞票✕利润）逐面板显。
- b4 赶工优选：天平横梁 rotate 倾向主体 → 主体盘绿高亮「✓先压」/ 装修盘灰「后压」→ 三条规则 chip → 脚注「压非关键不缩工期·赶工费发包人担」。
- b5 证据程序：沙漏 28天 → 四性印章逐枚点亮（真实/全面/法律效力/及时）→ 计算判定链四步脚条。

> 每集 ≥4 主讲 beat 出现真实领域对象（上集 b0/b1/b2/b3/b4；下集 b1/b2/b3/b4/b5 均有），无「只有 decision_tree / process_flow / answer_box」的 beat。

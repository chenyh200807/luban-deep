## 2 · 原理因果层：四联因果链「成因→部位→预防→治理」

把散点通病压成可讲逻辑链。每链标三色。

### 链 1 · 蜂窝/麻面/露筋/孔洞（混凝土密实度失效）🟢

```
成因（密实度不足，同根三分支）：
  模板侧 ── 接缝不严·漏浆·脱模剂不匀·未湿润 ┐
  布料侧 ── 自由倾落过高·离析·一次下料过厚 ┤→ 砂浆流失/包裹气泡/骨料外露
  振捣侧 ── 漏振·欠振·钢筋过密浇捣困难     ┘   → 蜂窝(石子外露空隙)·麻面(表面凹点)
                                              → 露筋(垫块缺失)·孔洞(大体积未振实/卡料)
        ↓ 部位：梁底·柱根·墙面·钢筋密集区·模板接缝处
        ↓ 预防 〔🟢 kc:1A434000_072_0112:0 quote〕
  模板清理+湿润 / 隔离剂均匀 / 合理布料分层 / 分层振捣避免离析 / 控制下料高度
        ↓ 治理 〔🟢 真题2023案例一(问题4) 逐字〕
  清理表面→支设模板→洒水湿润→涂抹界面剂→【用高一强度等级的细石混凝土仔细浇筑密实】→保温保湿养护不少于7天
```
判分锚：找错型问"哪项**不是**麻面成因"；防治型逐字得分点（界面剂 / 高一强度等级细石混凝土 / 养护不少于7天 三关键不可漏）。

### 链 2 · 空鼓（界面粘结失效）🟢

```
成因（粘结界面失效，跨载体同理）：
  基层未清理/浮渣/浮浆 ┐
  油性防护剂阻隔粘结 / 未浸砖吸走砂浆水分 ┤→ 砂浆与基/面层界面脱开 → 空鼓
  水灰比失当/赶压不当/养护不足 ┘
        ↓ 部位：板块地面(B011)·外保温(B015)·瓷砖石材(R04/R05)·裱糊饰面
        ↓ 预防+治理 〔🟢 kc:...078_0123:0 / ca:...078_0123 / kc:...140_0273:1〕
  基层清理 / 水泥基粘结材料 / 油性防护石材用界面剂+背砂 / 大面积设伸缩缝 / 养护到位 / 瓷砖浸砖阴干
```
判分锚：空鼓是**界面**问题，与蜂窝（**本体密实**）分属两条链，禁混。

### 链 3 · 裂缝（约束应力 > 抗拉，按来源分三支）🟢/🔵

```
成因分支（按来源区分，部位各异）：
  收缩温度侧(B036) ── 含泥量大/水胶比坍落度大/养护不足 → 表面收缩裂缝
  地基沉降侧(砌体域) ── 地基不均匀下沉 → 纵墙端斜裂缝·窗洞对角裂缝（🔵真题2016第12特征）
  交接·约束侧(填充墙) ── 填充墙与主体变形不协调 → 柱边·梁底·门窗洞口裂缝
        ↓ 预防+治理
  收缩：合理配比·加强振捣·〔初凝前二次抹压=statement派生🔵〕·及时养护  〔quote 仅四收缩类型🟢〕
  填充墙：【间距500mm的2φ6钢筋】·【下部墙砌完14d后砌】·半砖斜砌·窗台细石混凝土配筋·加强网片 〔🟢 ca:...074_0116 quote + 真题2024〕
```
判分锚（高频）：真题2024第14页(问题3) 逐字考填充墙裂缝**部位（柱边/梁底/门窗洞口）+ 措施（500mm的2φ6、砌完14d后砌）**。

### 链 4 · 渗漏（防水通路失效，节点为先）🟢

```
成因（连续防水路径断裂）：
  施工缝未清理→混凝土松散·骨料集中·接槎明显 ┐
  钢筋密集→浇捣困难→混凝土不密实 ┤→ 形成渗水通路 → 渗漏
  穿墙管壁未清/无止水环 ┘
        ↓ 部位：施工缝·穿墙管根·阴阳角·变形缝·地下室
        ↓ 预防 〔🟢 kc:...075_0117:0/:1 / kc:...074_0116:3 quote〕
  保湿养护 / 多道设防刚柔结合 / 穿墙管设止水环+灌浆 / 施工缝清理凿毛
```
判分锚：渗漏落点在**节点构造与施工缝处理**；与"密实度链"在"混凝土不密实"处交汇（同根可联讲）。

## 3 · R2 不变量（一句 + ≥5 场景，**拆五类，不一句吞全部**）

> **不变量**：**任何混凝土/抹灰/砌体/防水通病，答题都必须把「现象 → 成因（模板/材料/振捣/养护/构造）→ 部位 → 防治措施（带规范数值或标准术语）」四件套对齐，缺一即失分；治理工艺要按「清理→处理→同/高强度材料修补→规范养护」的顺序，不能只报现象。**

> ⚠️ **Codex SEV-3 修正**：本不变量是"答题动作模板"，**不代表五类通病同源**。五类各有独立成因—部位—防治，分别投影如下，禁用一条不变量吞掉全部机理。

5 类场景投影：

1. **表面缺陷（密实度）·麻面**：现象=拆模后表面麻点 → 成因=模板不光滑/接缝不严漏浆/未湿润/隔离剂不匀 → 部位=构件表面 → 防治=模板清理湿润、隔离剂均匀、分层振捣。🟢 `ca:1A434000_072_0112` + `kc:...072_0112:0`
2. **表面缺陷·蜂窝/露筋/孔洞**：成因=振捣不实/离析/配筋过密 → 防治=分层振捣、避免离析、垫块到位。🟢 `kc:...072_0112:0`
3. **收缩裂缝（混凝土自身）**：成因=含泥量大/水胶比坍落度偏大/养护不足 → 防治=控原材料、合理配比、加强振捣、及时养护〔二次抹压=派生🔵〕。🟢 `ca:...073_0114` + `kc:...073_0114:0`（quote 仅四收缩类型）
4. **空鼓（界面粘结）**：成因=基层未清理/水灰比不合理/油性防护剂削减粘结/未浸砖 → 防治=基层清理、水泥基粘结材料、界面剂+背砂、伸缩缝、养护到位。🟢 `ca:...078_0123` + `kc:...078_0123:0` + `ca:...140_0273`
5. **填充墙裂缝（交接约束）**：成因=刚度突变/未待沉降稳定 → 部位=柱边/梁底/门窗洞口 → 防治=间距500mm的2φ6钢筋、下部墙砌完14d后砌、加强网片。🟢 `ca:...074_0116`(quote) + 真题 `2024第14页(问题3)`
6. **渗漏（防水通路）**：成因=施工缝松散接槎明显/穿墙管无止水环/养护不佳 → 防治=保湿养护、多道设防刚柔结合、穿墙管止水环。🟢 `kc:...075_0117:0/:1` + `kc:...074_0116:3`(施工缝渗漏 quote)

## 6 · R8 误区库（误区 → 错因码 → 解药）

> 每误区 = 现象 + ❌错误心智模型 + ✅解药（教材锚 quote） + 错因码（注册表真码） + 真题锚（无则🔴）。

### 误区1 — "缺陷长得都差不多，反正都是没振好"（四缺陷不分）
- **现象**：拆模后坑/麻点/露筋一律写"蜂窝"或张冠李戴。
- **❌心智模型**："表面缺陷是一种东西的不同程度，叫什么不重要，成因都是振捣。"
- **✅解药**：四缺陷不同形貌不同主因——麻面=模板/缺浆；露筋=保护层缺失；蜂窝=石子成堆缺砂浆；孔洞=配筋过密卡料。逐图对号入座。🟢 `kc:1A434000_072_0112:0` + `ca:1A434000_072_0112`
- **错因码**：**E07 概念混淆**（code_application，`error_codes.py` L51）。
- **真题锚**：🟢 `2023案例一(问题2)` 逐图命名（图1-1麻面…图1-6蜂窝）；🟢 `2022第(三)题(问题3)`。

### 误区2 — "出现蜂窝，抹层砂浆糊上就行"（治理=随手抹平）
- **现象**：孔洞治理只答"凿掉→水泥砂浆抹平"，漏湿润/界面剂/强度等级/养护天数。
- **❌心智模型**："缺陷治理就是表面修补，看不见就算好。"
- **✅解药**：孔洞治理是**有强度要求的结构性修补**：清理表面→支设模板→洒水湿润→涂界面剂→**用高一强度等级的细石混凝土仔细浇筑密实**→**保温保湿养护不少于7天**（源料明示"不能用普通砂浆"）。🟢 真题 `2023案例一(问题4)` 逐字。
- **错因码**：**E06 程序顺序错误**（transfer，L50）。
- **真题锚**：🟢 `2023案例一(问题4)`。

### 误区3 — "强度没上来，早点拆模赶工期"（拆模凭手感）
- **现象**：未达强度提前拆模 → 梁底麻面/蜂窝/夹渣；拆模强度凭印象填。
- **❌心智模型**："模板能拆就拆，差不多就行；缺陷是拆模时蹭的。"

## 1. source_card（从知识主源提炼）

- **main_exam_action**：判断/纠错 + 程序 + 记忆三合一——判「施工缝**该不该留**（连续浇筑/初凝前）→ **留在哪**（受剪力较小 + 各构件 1/3 位置）→ **旧缝怎么接**（达强度→凿毛→清理→砂浆→养护）→ **后浇带怎么处理**（微膨胀+提高一级+≥28d封闭+≥14d养护）」。
- **wrong_idea**：① 缝留在受剪力较大处/墙任意位置；② 浇筑长时间中断又不留缝；③ 旧缝不达强度/先浇后凿/不铺砂浆直接接；④ 后浇带当普通施工缝（同强度、不加强养护）；⑤ 底板后浇带提前封闭（10d）；⑥ 钢丝网剔除/接槎不清理/模板独立支设；⑦ 后浇带措施漏项；⑧ 答案空泛口号化。
- **teaching_spine**：**「巧断 → 重连 →（超长结构的）延迟重连」**。天然分两阶段：
  - 阶段Ⅰ 普通施工缝 = 留不留 + 留哪里 + 旧缝怎么接（**上集**）。
  - 阶段Ⅱ 后浇带 = 补偿收缩 + 强度提高一级 + 28d 封闭 + 14d 养护 + 界面/模板（**下集**）。
- **facts（全 🟢 锚定）**：柱/墙水平缝距上表面 0~100mm(柱)/0~300mm(墙)；次梁跨中 1/3；墙洞口连梁跨中 1/3 或墙交接处；楼梯梯段端部 1/3；单向板平行短边任意位置；双向板按设计；初凝前浇完次层否则留缝；受剪力较小处 + 必要时经设计单位确认；防水混凝土连续浇筑宜少留缝、不留剪力最大处或底板与侧墙交接处、养护≥14d；处理工序 1.2N/mm²→凿毛→清理松动浮浆→30mm 砂浆→浇筑振捣；后浇带微膨胀混凝土、强度提高一级、≥14d 养护、底板≥28d 封闭、接缝按施工缝处理、收口网浇前拆除并凿毛、钢丝网保留、模板不独立支设（案例判分以真题为准）。
- **common_errors（错因码 ∈ registry）**：M1→E10/M04；M2→E06/E02；M3→E06/E03；M4→E07/E10；M5→M08/E10；M6→E10/E03；M7→E02；M8→E04。
- **practice_blueprint**：位置判断（真题 {2021·第8题} ACDE）、防水混凝土综合（{2015·第26题} ABE）、后浇带指错+技术措施（{2018·案例三·问题3}）、处理工序排序、何时留缝判断、后浇带封闭天数、采分句诊断。

## 3. visual_archetype_decision

### 上集（施工缝篇）
- **primary_archetype**：`threshold_ruler` + 顺逆/位置对比（剪力梁上的缝位命中）。
- **secondary_archetype**：`handling_chain`（处理工序重连链）+ `threshold_trigger`（初凝阈值触发留缝）。
- **visual_primitive**：梁/柱/墙 CSS 截面、剪力大小色带（红=剪力大 / 绿=剪力小）、1/3 标尺、初凝时间轴+指针、强度计、凿毛麻面纹理、30mm 砂浆层、咬合齿。
- **motion_grammar**：指针滑过初凝临界 → 触发留缝对象出现；缝位在剪力带上命中高亮；工序步骤沿链依次点亮、界面咬合。
- **why_this_visual**：施工缝考的是「留不留/留哪里/怎么接」——本质是**位置在受力场上的命中**与**工序因果链**，必须画出受力场与咬合过程，纯文字框无法表达"为什么这个位置对、这一步不能省"。
- **why_not_text**：判断框只能列"受剪力较小处"这句话，学生记不住"为什么"；剪力色带 + 命中让"力最小处才留缝"一眼可见。

### 下集（后浇带篇）
- **primary_archetype**：补偿收缩对比（`threshold_trigger` 因果）+ 顺逆对比（模板/钢丝网）。
- **secondary_archetype**：`handling_chain`（技术措施 6 步清单）+ 时间轴（28d 封闭）。
- **visual_primitive**：超长结构梁 + 后浇带缺口、两侧收缩箭头(向内)/后浇带膨胀箭头(向外)、裂缝张开/合拢、收缩时间轴+封闭指针、C→C+1 强度标、钢丝网、模板支撑架。
- **motion_grammar**：普通同强度混凝土→收缩箭头内推→缝拉裂✕；微膨胀混凝土→膨胀箭头外撑→缝合拢✓；时间轴指针滑到 10d 封闭→拉裂 / 滑到 28d 封闭→稳。
- **why_this_visual**：后浇带核心是"用膨胀预压抵消收缩拉应力"——是**力的方向对抗**，只有画出收缩(内)与膨胀(外)两组箭头 + 裂缝开合，才能讲清"后浇带≠普通施工缝"。
- **why_not_text**：流程框只能写"微膨胀混凝土、提高一级、28d"，讲不出"膨胀怎么把缝撑住"；对抗箭头把因果画出来。

## 4. domain_visual_plan（每 beat 领域对象 + 进入/动作 + 验收判据）

### 上集
- **b0 破误区**：连续梁 + 剪力色带（两端红=剪力大、中间绿=剪力小）。误区①缝留在支座红区→红✗撕裂；误区②长时间中断不留缝→通缝渗漏。红章"误区✕"盖下。
  - 判据：正确当且仅当**画出剪力色带（端红中绿）+ 缝错留在红区 + 裂缝**，学生能看出"留错位置"。
- **b1 何时留（A1/M2）**：初凝时间轴（0—初凝临界—超时），浇筑指针滑动。指针在初凝前到达→次层压上融为一体(绿·无缝)；指针越过初凝临界→触发"留置施工缝"对象出现(因果)。
  - 判据：正确当且仅当**画出初凝临界刻度 + 指针越过临界才触发留缝对象**（因果非并列）。
- **b2 受剪力较小（A2/M1）**：一根梁 + 剪力色带，缝位指针从支座(红)滑到跨中(绿)命中高亮；旁标"必要时经设计单位确认"。
  - 判据：正确当且仅当**缝停在绿区(受剪力较小)并高亮、红区打✗**。
- **b3 各构件位置清单（B1/B2/B3）**：建筑框架小截面——柱(梁板顶面，缝距上表面标 0~100mm)、墙(0~300mm)、有主次梁楼板(次梁跨中 1/3 带)、楼梯梯段(端部 1/3 带)。各缝位绿色高亮 + 数值端标。
  - 判据：正确当且仅当**每个构件画出具体缝位 + 标出 0~100/0~300/1/3 的位置带**，非只列文字。
- **b4 防水混凝土缝（B4/E1）**：地下室底板+侧墙 L 形截面。底板与侧墙交接处红✗(不留)、剪力最大处红✗；连续浇筑少留缝(绿箭头连续)；养护水滴 ≥14d 标。
  - 判据：正确当且仅当**画出底板-侧墙 L 截面 + 交接处红✗ + 养护≥14d**。
- **b5 处理工序（C1/C2/M3）**：重连工序链——旧混凝土面 → 强度计跳到 1.2N/mm² → 凿毛(麻面纹理出现) → 清理浮浆 → 30mm 砂浆层 → 新混凝土浇下咬合(齿咬合)。每步依次点亮。
  - 判据：正确当且仅当**工序 5 步按序点亮 + 1.2N/mm²/凿毛麻面/30mm 砂浆层三个关键对象可辨**。

### 下集
- **b0 后浇带≠普通缝（M4）**：超长结构梁中间留后浇带缺口。当普通缝用同强度混凝土填→两侧收缩箭头向内→缝拉裂✕。红章"当普通缝×"。
  - 判据：正确当且仅当**画出后浇带缺口 + 同强度填充 + 收缩内箭头 + 拉裂缝**。
- **b1 微膨胀补偿收缩（D1）**：对比——左：普通混凝土(收缩内箭头→裂)✕；右：微膨胀混凝土(膨胀外箭头→撑住缝合拢)✓。两侧几何真不同（箭头方向相反、缝开/合）。
  - 判据：正确当且仅当**左右箭头方向相反(内 vs 外)、左缝张开右缝合拢**，非只换标签。
- **b2 强度提高一级（D1）**：后浇带块强度标从原结构 C30 跳到 C35（提高一级），色深一档、内聚支撑膨胀。
  - 判据：正确当且仅当**画出 C→C+1 的等级跳变对象**。
- **b3 封闭 28d（D2/M5）**：收缩时间轴——两侧主体收缩曲线随天数收敛。指针停 10d 提前封闭→两侧还在收缩→后浇带被拉裂✕；指针滑到 28d→收缩基本完成→填充稳✓。
  - 判据：正确当且仅当**时间轴 + 10d(拉裂✕) 与 28d(稳✓) 两个封闭时机的不同结果**。
- **b4 技术措施清单（D1/M7）**：6 步链依次点亮——整理钢筋→冲洗松动→微膨胀混凝土→强度提高一级→≥14d 湿润养护→接缝按施工缝处理。
  - 判据：正确当且仅当**6 项措施逐项作为对象出现、可数**（防清单坍缩）。
- **b5 界面/模板（D3/M6）**：后浇带界面——快易收口网(浇前拆除并凿毛)、钢丝网(保留防漏浆，✓)；模板：独立支设(✕) vs 与主体同步支撑(✓)，两种支撑架几何真不同。
  - 判据：正确当且仅当**钢丝网保留✓ + 模板独立支设✕/同步支撑✓ 的支撑架几何区别可辨**。

## 6. 分集方案与理由

- **分两集**：施工缝篇（上）+ 后浇带篇（下），按 teaching_spine 阶段边界切分，未在任一采分动作中间硬切。
- 每集独立完整：自有 hook、6 主讲 beat、QA 4 问（各带迷你领域图）、收官终屏、上一/下一集 + 做练习导航。
- **练习合并一套**（≥15 题随机抽 5），phase tag 标阶段，学生端无制作词。

## 7. 仍需人工复核的风险
- C1 处理工序数值（1.2N/mm²/30mm/凿毛）为 EP 关键词级 🟢（知识源 §8.2 C5），完整规范 quote 待补。
- D3 后浇带模板"独立支设"教材/真题张力：本卡按真题判"独立支设=不妥、应同步支撑"（知识源 §8.2 C4）。
- R7 给分档位全为 🔴 待裁决；练习"命中/漏分"为教学示范，非官方判分。
- 剪力大小与缝位关系（受剪力较小=跨中）为工程通识表达，用于讲懂，判分以"受剪力较小处 + 各构件位置"采分句为准。

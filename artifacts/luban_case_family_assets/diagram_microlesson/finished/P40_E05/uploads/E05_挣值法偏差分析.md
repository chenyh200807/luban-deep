## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写因果链；汇编层把散文链收成「三段因果链 + 每段挂 point_id」，无锚的机理外推（三线曲线、降维解释）保留为 🔵 讲解性表述，不充判分。

**核心因果链（讲懂层骨架）：**

```
成因：传统「计划花钱 vs 实际花钱」割裂对比，无法剥离「工程量完成度」与「单价」两个混杂因素
   │  （月底花了100万、计划120万 —— 不知是省钱还是只干了一半活）
   ▼
机理：引入「挣值 BCWP=已完成工程量×预算单价」作为统一价值标尺   kc:1A435020_095_0156:0  🟢
   │  用不变的预算单价衡量已完工程量 = 在成本与进度之间架桥
   ▼
分离成本偏差：把工程量锁在「已完成」，只暴露单价差异
   ├ CV = BCWP − ACWP   （>0 节支 / <0 超支）       kc:1A435020_095_0156:1  🟢
   └ CPI = BCWP / ACWP  （>1 节支 / <1 超支，可横比效率） kc:1A435020_095_0156:2  🟢
   ▼
分离进度偏差：把价格锁在「预算单价」，只暴露工程量差异
   ├ SV = BCWP − BCWS   （>0 提前 / <0 延误）       kc:1A435020_095_0156:1  🟢
   └ SPI = BCWP / BCWS  （>1 提前 / <1 延误）        kc:1A435020_096_0157:0  🟢
   ▼
效果 = 用三个参数 + 加减除法穿透迷雾，精准诊断「价格问题」还是「量的问题」
```

**为什么措施有效（讲解性，🔵 不充判分）：**
- **CV/SV 用减法、CPI/SPI 用除法**：减法给「绝对偏差额（货币量）」，除法给「相对效率（可横向对比的比值）」—— 两套指标互补。
- **BCWP 用「预算单价」而非实际单价**：把价格波动隔离在外，使进度度量（SV/SPI）只反映「干了多少量」，不被涨价/降价污染。
- **三线曲线（BCWP 居 ACWP 与 BCWS 之间）**：直观图，便于一眼看出成本/进度状态。属理解工具，无独立 point_id，标 🔵。

> 三色提醒：因果链的**公式与判别结论**（CV=BCWP−ACWP、CV>0 节支…）全部 🟢 锚定；链条里的**降维/隔离价格的机理解释**是讲懂用语，标 🔵，不得作为采分点输出。

### examiner_intent (出题人意图)

挣值法是**纯计算考点**，出题人**只考「会不会算 + 会不会判读」，不考叙述**。三层意图：

- **意图① 抓「三值取对 + 四公式代入」(计算) —— 最高频。**
  给 BCWP/BCWS/ACWP 三个数（或换算成已完成量×单价让你先求 BCWP），要你套 CV=BCWP−ACWP、SV=BCWP−BCWS、CPI=BCWP/ACWP、SPI=BCWP/BCWS 算出四个值。埋点：把三值含义说反（让你把「实际成本」当「预算成本」代入）、或被减数减数顺序诱导写反。
  🟢 锚：`ca:1A435020_095_0156`、`ca:1A435020_097_0160`；教材锚 `kc:1A435020_095_0156:1/2`、`kc:1A435020_097_0160:1`。

- **意图② 抓「偏差方向判读」(分析) —— 与计算同等高分。**
  算出数后必须判读：CV/SV>0 是节支/提前，<0 是超支/延误；CPI/SPI>1 是节支/提前，<1 是超支/延误。埋点：算对数值但方向判反（CV>0 说成超支），或只写「好/不好」不写规范词「节支/超支/提前/延误」。
  🟢 锚：`kc:1A435020_095_0156:1`、`kc:1A435020_095_0156:2`、`kc:1A435020_096_0157:0`。

- **意图③ 抓「指标含义辨析」(概念 MCQ) —— 客观题。**
  问 BCWP/BCWS/ACWP 各自构成（哪个用预算单价、哪个用计划量），或问某指标公式。埋点：四个选项把分子分母/被减数减数排列组合做干扰。
  🟢 锚：`kc:1A435020_095_0156:0`、`kc:1A435020_096_0158:0`、`kc:1A435020_097_0160:0`。

> **一句话**：出题人把挣值法当成「公式默写 × 算术 × 方向判读」三重过滤器 —— 记忆层考「四个公式写对吗」，计算层考「代入算对吗」，判读层考「正负/大于 1 的方向说对吗」。

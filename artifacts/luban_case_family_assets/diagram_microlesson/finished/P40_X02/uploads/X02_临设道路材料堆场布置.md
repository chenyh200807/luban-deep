## 2. 原理因果层 (L2)

> 来源谱系：镜头 A(DeepSeek) 主写「物理隔离：把能烧的和能点的拉开、把逃生路和救援路留出」因果链；汇编层把镜头 A 的散点压成「成因→机理→对症措施→为什么有效」+每链挂 point_id，**镜头 A node_code 片段改挂真 point_id**；镜头 A 的「断线摆幅/卤钨灯表面温度/灭火覆盖半径」等机理解释无 point_id，保留为 🔵 讲解性表述、不充判分。

**核心因果链(讲懂层骨架)：临设布置的本质=用「数字距离/面积/宽度」做物理隔离——把「能烧的」和「能点的」拉开，把「逃生路」和「救援路」留出截面**

```
布置总则: 高密度共存的现场 → 用规格数值做物理隔离 → 防火灾蔓延/防坍塌/保消防通行/保材料质量   🔵讲懂骨架
   │
   ├─ 链一·间距隔离(防火灾蔓延): 危险品/易燃品 与 在建工程/明火/作业区 拉开距离
   │     危险品仓库距在建≥15m / 易燃仓库下风向+距明火≥30m / 电气线距堆垛≥杆高×1.5   kc:1A431011_012_0013:0、kc:1A437000_146_0235:0、kc:1A437000_147_0236:1  🟢
   │
   ├─ 链二·分区限量(防火势串烧): 仓库分防火区、单间限面积、配灭火器
   │     可燃库≤30m²·易燃库≤20m²·每500m²防火墙·任一点到疏散门≤10m / 临建每100㎡2只灭火器   kc:1A437000_147_0236:0、kc:1A437000_146_0233:0  🟢
   │
   ├─ 链三·通行净宽(保消防救援): 道路宽度/回车场/转弯半径满足消防车进出掉头
   │     单行≥4m双行≥6m·消防车道≥4m·回车场12m×12m·转弯半径≥15m·消防通道≥6m   kc:1A431011_012_0013:1、kc:1A437000_146_0235:0  🟢
   │
   └─ 链四·堆放保管(保材料质量+防失稳): 码放限高、下垫上盖、进场验收挂牌
         料具码放≤1.5m·库外下垫上盖·进场验收三要素挂牌台账·不合格退场   kc:1A438000_150_0241:0/:1/:2  🟢
```

**为什么措施有效(讲解性，🔵 不充判分)：**
- **危险品仓库距在建≥15m**：在建工程动火/焊接火花飞溅在 10m 级，15m 外加实体隔离=物理屏障（机理 🔵）。
- **易燃库设下风向**：火灾烟气+热浪由风推动，下风向布设使一旦起火火焰/毒烟吹离作业区而非覆盖（机理 🔵，真题 `{2015,第30题}` D 选项恰考此点上风✗下风✓）。
- **分区限面积（可燃≤30m²/每500m²防火墙）**：把单区可燃物总量压到「即使烧完也不至蔓延」量级，防火墙阻断水平传播（机理 🔵）。
- **回车场12m×12m/转弯半径≥15m**：专门解决「消防车进得去倒不出来」，截面不足则初期火灾变失控大火（机理 🔵）。
- **码放≤1.5m+下垫上盖**：限高防重心上移失稳坍塌+取料滑落伤人；下垫防潮防锈、上盖防雨淋变质（机理 🔵）。

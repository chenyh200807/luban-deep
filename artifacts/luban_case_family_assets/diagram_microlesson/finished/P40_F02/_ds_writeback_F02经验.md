## A. 并入 §7 生产流程（新增「采分点覆盖矩阵」步骤，置于 storyboard 之前）

**写白板 storyboard 前，先做采分点覆盖矩阵——这是 gate 的第一条轴。**
1. 把数据 §5 R5 的**每一条 point_id 逐行**填表，每条标"映射到哪个 beat / 哪个 QA"。任何一条不允许空白，除非数据用 Option B 显式 curate（且照抄其省略理由）。
2. `teaching_spine`（叙事主线）≠ 采分点全集。主线只组织顺序；数据 §0"五维/N 维"命中的每一维都得在动画里出现（标题写"四关"没关系，但条件维等采分点必须有自己的画面）。
3. **beat 数按覆盖定，不按默认**。§7 已允许 5–8 beat、5 分钟内可长；先数采分点再定 beat 数，别拿"6 beat / less is more"当上限把采分点挤掉。
4. **练习覆盖 ≠ 动画覆盖**。用户要"动画讲知识"，条件维进了 practice Q 不算讲解页已讲；两份产物各自过一遍矩阵。
> 复盘：F02 第一版动画漏了条件维（满粘/坡度>25%钉压/热熔阈值）、平行屋脊、檐口800满粘——根因正是把"四关链主线"当成了采分点全集 + 把练习覆盖当动画覆盖。

## B. 并入 §5 动画原则（新增「双轴验收 + 证伪式自查」红线）

**自查要验"正确且能读懂"，不是"渲染成功/对象出现"。**
1. **建每个领域对象前，先写一句验收判据**：`这个对象正确当且仅当 ___`，点名它必须画出的**判别特征**。自查只查这一句。例：顺流水≠逆流水的判别量＝"搭接台阶相对水流的朝向（顺＝台阶顺流而下水盖过；逆＝迎水唇水钻进）"。
2. **对比类视觉做证伪式自查**：不问"它对吗"，问"啥都不懂的学生能不能只看图分清这俩？区分二者的唯一特征画出来了吗"——主动证明"这俩看着一样 / 这标签压在深底上"，证伪不了才算过。
3. **以陌生学生的眼睛读，且改完必重载后截那个 beat**（作者的眼会脑补屏幕上没有的意图）。
4. **gate 两轴都要过**：①覆盖轴（A 节矩阵）②正确轴（逐对象判据 + 可读性：几何/语义对不对、每个标签是否在浅底、每组对比判别特征可辨）。任一缺口不进 finished。
5. **把判据喂给独立核验**：fork 的 verifier 若只被告知"看看渲染"也只会查渲染；要把每个对象的判据列给它，才可能查到语义错（异源裁判查"意义"非"像素"）。
6. 用户每抓到一个问题，先归类"哪一类自查能拦住它"，把那一类补进清单——而非只修当前这处。
> 复盘：条件维漏、beat0/beat1 压字、顺逆流水两边雷同——四次同一病根：自查验的是"渲染成功"、且作者兼裁判同源盲点。

## C. 并入 §9.④ 排版纪律（补三条 STAGE 叠压铁律）

舞台固定 390×462、全绝对定位；每个 beat 收尾（全 opacity）人工过一遍叠压：
1. **文字标签绝不压深色领域对象**（卷材条 `#3a5168/#46627e`、深 band）。灰字 `#5c6469`/红字 `#cf4436` 压深底＝低对比＝被挡。标签要么落浅底 `#f4f3ec`，要么改对象内白字。坐标/端标（檐口·低/屋脊·高）放对象**两侧或上方**留白带。
2. **同一行的左右标签统一 top、放对象下方留白**，别一个压对象一个不压。
3. **环/点标记与对象留 ≥4px**（`ring.top+h < strip.top`）。长说明句（>16 字）起点靠左、整句落浅底，箭头指对象即可、句体别压对象。

## D. 并入 §6 文案配音（新增「画面结合旁白」硬规则）

**主讲画面分相位必须跟着旁白页走。** 视觉相位的**出现顺序**与旁白句序一致；用 `W(a,b)` 窗口把每个对象的 opacity/位移对齐到对应 caption 页的 `lp` 区间——讲到哪句、屏上就出现那句对应的对象。例：beat④讲"钉压"时出钉头、讲"180~200℃"时温度计水银升进高亮带。验收时截中段帧，确认 caption 文字与可见对象同步。

## E. 并入 §5 visual_library（新增母题：阈值触发）

**threshold_trigger（条件维专用）**：阈值尺（0—临界—上限）+ 指针滑过临界刻度 → 临界区高亮 + 触发后续做法对象出现（因果，非并列分类）。例：坡度尺指针滑到 28% 越过 25% → 绿区亮 →"满粘+钉压"面板+钉头出现。条件维（满粘/热熔阈值等）禁用并列 token 分类图，改用本母题的"滑过即触发"动作；练习页静态版也要画成"指针在 X、落入临界区 → 结果"的因果图，不堆等价 token。

# 鲁班案例题作答层

> **定位**:案例题"测"维度的【写作答】模态——把 pack 的**知识层**(R5 采分点/R6 答案骨架/R8 误区)**可写化 + 训练化**成**作答能力**。
> **加层不重造**:本 skill 是依附已有深 pack 的**纯派生层**,知识全来自已 signed 的 R5;造母题/讲懂动画/闯关看穿调 `luban-learning-pack-factory`+`luban-diagram-microlesson`,本 skill 不重复。
> **样板**:`docs/原始数据/考点原料/成品/J01_案例题作答层样板.md`(J01 危大,已验证"会看答案→会写答案"跃迁)。

## 0. 第一性原理(为什么要作答层)

一建实务案例题(5 道、写完整答案)失分**不是"不会",是"会一点但写不成分"**——漏采分点 / 答非所问 / 只写结论不写理由 / 程序顺序错 / 主体写错。知识层(pack R5/R6/R8)解决"知道什么";**作答层解决"按阅卷友好结构写全采分点"**。这是案例题"稳定拿分"的真杠杆,也是 learning-pack-factory 的"测"(闯关分档/看穿识别)缺的一环:从【选/判】到【写】。

## 1. 核心方法(五件,样板已验证)

### ① 采分点可写化(从 R5 派生,不另造)
pack 每个 R5 采分点(知识层)→ 补**四件套**:
- **必写关键词**:阅卷必须出现、缺则不得该分的词(≈ R8 误区"关键词缺失"的反面)。**必写性来源须可溯**:来自 `R5 required_terms`(硬必写) / `R8 误区反面`(高频失分点) / `工程通识`(逻辑必然)——异源审常报"必写性夸大",防线是**不把非 R5 required_terms 的词当 R5 硬性必写冒充**(标来源即合规,不必删)。
- **标准表达**:能直接抄上答题纸的阅卷友好短句(🔵 作答策略,非判分眼本身)。
- **易错表达/常见漏写**:典型失分写法,**映射 pack R8 误区的 error_code**(归 registry)。
- **版本状态**(见 §1.⑤):`现行有效` / `旧说法仅背景` / `新规范优先·旧表述必须改写`——**写过期表述照样丢分**,这一件不可省。
> 派生规则:采分点/锚**逐字来自已 signed 的 R5**,作答层只补这四列。**采分点本身不增不改**(ground truth 归 R5 signed)。
>
> **锚硬规则(机器闸 `docs/原始数据/考点原料/verify_answer_layer.py` 确定性强制,提交前必跑全绿)** —— 每个采分点行按三类**择一**,违者返工:
> 1. **🟢 有 signed point_id**(`ca:`/`kc:`/`m35:`):正常采分点,真题只作**附加印证**写在 point_id 之后,不能替代 point_id。内容是否忠实 point_id 真值(防 K01 W5 式"方法张冠李戴")归异源门核,机器闸不管。
> 2. **🟢→真题侧诚实披露**:若该采分点编译库**零教材锚**(coarse_review pack 常见),版本状态列**必标**`真题侧·待补规范锚`(或`真题应用印证`),锚证据包内真实真题号——**这是合规的**(S07 实证)。
> 3. **🔵 非采分点**:无 point_id 又非真题侧的事实(工程通识/对照背景/邻接材料),**必标 🔵 降级为作答策略,不充独立采分点**。
>
> **铁违规(机器闸 🔴)= 真题锚而无 point_id、又标"现行有效"/坐 🟢 簇却不披露真题侧** = **冒充教材锚**(K01 W8、Q01 B/C/V 实证)。修法:补回 point_id,或诚实降为第 2 类(真题侧)/第 3 类(🔵),**禁止**用真题给一个没有 signed 来源的采分点撑场面。

### ② 五维框架(采分点分类器)
案例采分点几乎都归**五维**之一:**主体**(谁做)/**程序**(什么顺序)/**条件**(达什么阈值才做)/**记录/计算表达**(留什么书面/签字/必含内容;**计算题在此维写算式链+数值结论**,N01 实证扩名,不另造第六维)/**后果**(违反或达标后会怎样)。命题人就按这五维把规范条款变案例题。给每个采分点标命中哪维 → 学生答题"**五维自检**",漏哪维一目了然,比"逐字找差"更快定位"差哪句"。

### ③ 句式模板库(跨母题复用,全局共享一份)
研究方案的 9 类标准答题结构,**全局只写一次,40 pack 共用**(fat skill,不在 pack 内重造):
- **判断纠错**:"不妥。理由:违反…要求。正确做法:应…"(三段式)
- **措施**:"应从人员/材料/机械/方法工艺/环境与成品保护/检验验收记录 六维补充"
- **程序**:"应按顺序:编制→审核→审批(论证)→技术交底→实施→检查→验收→形成记录"(箭头链)
- **验收**:"施工单位自检合格后报验→监理/建设单位组织验收→相关主体参加→形成验收记录→合格后进入下道工序"
- **索赔**:四步,但第二步**分叉成双闸门**(K01 实证:工期/费用互不蕴含,合并会强化最高频错 E07 工期费用绑死)——"先判责任归属(非承包人原因)→过【工期闸:是否影响关键线路→给工期顺延】‖【费用闸:是否属发包人应担风险→给费用】两条**独立**判→再判是否按合同约定及时提出→最后判证据是否充分"
- **计算判定链**(计算题专用,A01 强度判定/N01 关键线路时差/K01 索赔金额三方实测撞同一缺口后补入):"先**亮判据/公式**(如 f≥0.88·f_cu,k / 关键线路=最长路径·总时差为零 / 索赔额=顺延工期×费率)→**代入题干数据列式**→**得数值结论**→**回判**规范阈值或合同条款定性(合格否 / 是否关键线路 / 索赔成立否)"。**数值与结论都要写**(只写结论丢过程分);数值正确性归 signed scoring artifact + 判分内核,本句式只管**作答结构**、不判数值对错。计算采分点的算式表达落在 §1.② 的"记录/计算表达"维。
- 另:**主体定位 / 内容清单枚举 / 事故处理**(立即停止→保护现场救援→报告→调查→处理方案→整改复验记录)
> 每个 pack 从这份全局库**勾选用到的几类**,不新造句式。

### ④ AI 批改训练闭环(验证"会看答案→会写答案"跃迁)
对一道真题案例(场景+问法),完整跑:
1. **学生盲写**(检索练习 > 重复阅读,学习科学硬证据)。
2. **AI 按采分点批改**(对照可写化采分点):①列参考采分点 ②逐点判命中/半命中/漏 ③标作答错因(§2 的 16 类)④用句式模板**改写**成标准答案 ⑤给**明天复练 2 道同类题**方向(补未练到的维,形成五维闭环)。
3. **间隔检索复测**:次日盲写复现 + 一周后同类母题混编复测(分散+交错练习)。
> 批改是【指漏+改写+教句式】,**给分档位继承 pack R7 的 🔴 待裁决状态**,`official_score_allowed=false`——指漏不定分。

**训练节奏**(学习科学骨架,作答层运营给学习闭环用):最小闭环 = **今日做题 → 当日拆采分点 → 次日盲写复现 → 一周后混编复测**(检索+间隔+交错);五段 = 建框架感(真题拆解)→ 建采分点库 → 练模板化表达 → 整套限时 → 考前压缩(按 §3 采分点索引)。

**三个进步指标**(作答层是否有效的判据,喂学情):① 同类母题**盲写命中率**↑;② 错因标签从"答非所问/漏点"**转向"细节不足"**;③ 能否**不看答案**用规范语言写出完整程序/主体/记录。三者向好=真进步;只刷题不动这三指标=忙而无效。

### ⑤ 三角校验 + 版本治理(写得"对且不过期")
作答层不只要"写得全",还要"写得**对且不过期**"。每个可写化采分点过**三角校验**:**教材怎么说 / 真题怎么问 / 现行规范怎么定**(三者一致→必背;教材略但规范细且大纲点名→案例补强;讲义猛但教材真题规范弱→了解即可;**旧讲义与新规范冲突→以现行规范为准**)。这是我们三色铁律🟢(教材锚)+真题锚+两闸的作答层延伸。
**版本治理(案例题丢分高发区,与 RichLeaf 版本治理同构)**:新通用规范**覆盖旧强条**(如 GB55032-2022 覆盖 GB50300-2013 部分强条),学生背了过期表述照样丢分。每个采分点标 §1.① 的**版本状态**三标签;`新规范优先·旧表述必须改写`的,标准表达写**新规范语言**、旧表述只留 🔵 背景注。安全管理同样封版(危大 37 号令/31 号文/63 号缺陷清单)。

漏采分点 / 答非所问 / 只写结论不写理由 / 只写理由不写正确做法 / 表达过泛 / 术语不准 / 未结合题干 / 场景混用 / 规范理解错误 / 计算步骤缺失 / 关键线路判断错 / 工期与费用索赔混淆 / 质量与安全混淆 / 程序顺序错 / 责任主体写错 / 记忆碎片化。
> 每个错因标签**映射 ERROR_CODE_REGISTRY 的 E/M 码**(漏点=E02、程序错=E06、主体错=E06/E08…);标签是"作答行为"层、error_code 是"错因归属"层,标签**引用**码不替代 registry。

## 3. 怎么铺 40 pack(高效 + 单一权威)

每个 case pack 三步(①③可 LLM 半自动,人工降到逐 pack 审校):
1. **R5 逐行派生可写化表**(机械:补三件套+五维)。
2. **从全局 §1.③ 句式库勾选**用到的几类(不新造)。
3. **跑一道作答训练闭环**(取证据包真题→模拟"会一点写不全"答案→AI 批改→验证按采分点给分+指漏)。
> 句式模板全局共享是关键杠杆——只写一次。审校重点:必写关键词的"必写性"、错因码贴切度、改写是否回 signed 采分点、真题锚是否证据包内真实题号。

**四套索引(产出的组织方式,缺一不可)**:作答层产物同步建四索引——① **按模块**(回教材)② **按场景**(同类比较)③ **按问法**(练模板,=§1.③ 句式库)④ **按采分点**(**考前压缩**)。第④套是案例题复习命门:把全部可写化采分点按高频/重要度压成"**考前必写清单**",学生考前只过这套。只按模块=知识树、只按真题=题库,四套齐才是"能复用+能压缩+能迭代"的作答系统。

## 4. 红线(违反即返工)

1. **采分点 ground truth 归已 signed 的 pack R5**:可写化从 R5 派生,**不另造采分点**。**机器强制**:每采分点行按 §1.① 锚硬规则三类择一,提交前跑 `verify_answer_layer.py` 必**零 🔴 冒充**;铁违规=真题锚冒充教材锚(真题给无 signed 来源的采分点撑场面)。同源自检自打勾"红线全守"不可信,机器闸 + 异源门双门把关(memory:同源自嗨 18 样板被异源审抓出系统性 SEV)。
2. **判分归 signed grading artifact / CaseGradingSkillKernel**:批改标 `official_score_allowed=false` = 候选教学示范,**指漏不定分**,给分档位继承 pack R7 🔴 待真人/专家裁决。
3. **错因归 `deeptutor/contracts/error_codes.py` ERROR_CODE_REGISTRY**:16 类作答标签**映射**已注册 E/M 码,禁自造码。
4. **学情归 LearnerStateService**:作答层不写学习证据。
5. **真题只用 pack 证据包 `_<ID>_exam_evidence.json` 内的,锚证据包真实题号**(如 `{2019,第2题}` 非"案例二");禁编造 `{年份+题号}`(memory:异源裁判抓出过编造真题锚=SEV-1)。
6. **加层不造第二 authority**:作答层依附已 signed pack,句式库全局共享(fat),不在 pack 内重造;三色继承 pack(🟢锚R5/🔵作答策略/🔴判分边界)。
7. **铺量异源抽检**:每 pack ≥3 次异源裁判一致性抽检批改,防同源盲点把"漏点"误判"命中"(memory:异源裁判也有共享盲点)。
8. **版本状态必标**(§1.⑤):可写化采分点必带版本状态;`新规范优先`项标准表达写**新规范语言**、旧表述只留 🔵 背景——**写过期表述 = 丢分,等同事实层漂移**。

## 5. Prompt 模组库(把方法论变可运行,直接用)

作答层的可运行 AI 模组,与本 skill 方法一一对应(均依附已 signed pack,守 §4 红线):
- **真题拆解**:输入真题→输出 场景/命题意图/问法类型/标准答案拆句/每句采分点/必写关键词/教材依据/规范依据/关联母题/变形方向/常见丢分点/可直接上答题纸的标准表达;资料不足标"需核验"不猜。
- **采分点卡片**:输入知识点/真题答案→输出可入库卡片(§1.① 四件套 + 高频程度 + 重要程度 + 记忆压缩版 + 可组合采分点),不输出散文。
- **三角校验**:输入内容→输出 教材表述/真题命题/现行规范/有无版本冲突/以哪版为最终背诵版/转写为答题语言/是否适合模板/是否需核验(=§1.⑤)。
- **AI 批改**:=§1.④(按采分点给分→逐点命中评价→指漏→标准答案改写→错因标签→明天复练 2 题)。
- **变式题生成**:同母题不同场景 3 道,不脱离现行大纲、问法不同、采分点高度相关、难度略升,带标准答案+采分点+错因提醒。
- **每日任务**:输入错因标签+近 7 天训练记录+高频母题库→输出今日任务(1 道深拆+2 模板复写+1 组采分点默写+1 道一周前错题复测+1 个规范冲突点回顾),标预计耗时+完成标准。**这条是把静态 pack 变动态学习系统的核心**。
> 这 6 个模组的事实层全部回 signed pack(采分点/真题/error_code),Prompt 只组织输出形态,不产生知识、不定分、不写学情。

## 6. 与其他 skill 关系(单一权威,不重叠)

- **luban-learning-pack-factory**:本 skill 是它"测"维度的【写作答】模态(它的闯关/看穿是【识别/判断】测);它编排研/教/测量产,本 skill 是"测·写作答"的造法,被它指针调用、不重复它。
- **luban-diagram-microlesson**:它的"看穿幕"是识别测(真懂vs背过),本 skill 是写作答测;上线可把作答批改闭环接它的 `render_archetype_journey`(学生先写→AI批改卡片交互),批改逻辑不变(仍对照 R5)。
- **判分内核**(CaseGradingSkillKernel/grading artifact):本 skill 产作答训练设计,**不调判分 runtime**;批改是教学示范,真判分仍归内核。
